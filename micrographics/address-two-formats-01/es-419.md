# BD-V-036-01 A Bitcoin address as text and QR code

## Alt text

La pantalla para recibir pagos de una billetera muestra una dirección de Bitcoin de ejemplo dos veces: como código QR y como texto. Ambas formas contienen la misma información pública para recibir pagos, y ninguna permite autorizar gastos.

## Texts

### screen-title

Recibir

### f1-label

Dirección

### f1

bc1qmp7pyt3fe0nv2ulh48425m96rp9qdlmd22j5n5

### stamp

Solo de muestra. No realice pagos.

### note

Información pública para recibir pagos. No permite autorizar gastos.
