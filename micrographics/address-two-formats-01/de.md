# BD-V-036-01 A Bitcoin address as text and QR code

## Alt text

Der Empfangsbildschirm einer Wallet zeigt eine Beispiel-Bitcoin-Adresse zweimal: als QR-Code und als Text. Beides ist dieselbe öffentliche Empfangsinformation, und keines von beiden kann Ausgaben autorisieren.

## Texts

### screen-title

Empfangen

### f1-label

Adresse

### f1

bc1qmp7pyt3fe0nv2ulh48425m96rp9qdlmd22j5n5

### stamp

Nur ein Beispiel. Nicht bezahlen.

### note

Öffentliche Empfangsinformation. Sie kann keine Ausgaben autorisieren.
