# BD-V-094-01 Seven-step module builder

## Alt text

Seven planning steps lead from the local context and need to a focused, verified task, a safe teaching sequence, clear assessment and a debrief. The existing alternative stays in view, and an unsuitable option returns to planning.

## Texts

### boundary

Keep the existing non-Bitcoin alternative in view at every step.

### s1-title

Learn the context

### s1-text

Study local conditions and consult local people.

### s2-title

Define the need

### s2-text

Name one local need, not a product.

### s3-title

Select the task

### s3-text

Pick one primary task, plus one more at most.

### s4-title

Verify the facts

### s4-text

Check facts, tools and expertise, with dates.

### s5-title

Design the sequence

### s5-text

Plan Presentation, then Practice, then Production.

### s6-title

Plan the evidence

### s6-text

Define the observable evidence before class.

### s7-title

Debrief

### s7-text

Choose the smallest safe next step with learners.

### loop

Not suitable or not safe? Return to planning.
