# BD-V-031-01 Roles in Bitcoin

## Alt text

Four roles for Bitcoin: people wey dey use am dey receive, keep and send bitcoin, nodes dey check di rules by demself, people wey dey mine dey build blocks wey dem fit add to di blockchain with proof of work, and people wey dey develop software dey suggest software. No single role dey control di network.

## Texts

### r1

Pesin wey dey use am

### r1-text

Pesin wey dey use am dey receive, keep and send bitcoin.

### r2

Node

### r2-text

Node dey check di rules by itself and dey pass correct data go other nodes.

### r3

Pesin wey dey mine

### r3-text

Pesin wey dey mine dey build blocks wey dem fit add to di blockchain and dey do proof of work.

### r4

Pesin wey dey develop software

### r4-text

Pesin wey dey develop software dey review, write and suggest software.
