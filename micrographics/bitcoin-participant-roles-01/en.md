# BD-V-031-01 Roles in Bitcoin

## Alt text

Four roles in Bitcoin: users receive, hold and send bitcoin, nodes independently verify the rules, miners build candidate blocks with proof of work, and developers propose software. No single role controls the network.

## Texts

### r1

User

### r1-text

A user receives, holds and sends bitcoin.

### r2

Node

### r2-text

A node checks the rules for itself and relays valid data.

### r3

Miner

### r3-text

A miner builds candidate blocks and performs proof of work.

### r4

Developer

### r4-text

A developer reviews, writes and proposes software.
