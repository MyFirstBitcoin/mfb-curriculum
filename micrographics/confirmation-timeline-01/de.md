# BD-V-046-01 Confirmation timeline

## Alt text

Eine Transaktion wartet unbestätigt in der Warteschlange, wird dann in Block N als erste Bestätigung aufgenommen, und jeder weitere Block fügt eine weitere Bestätigung hinzu.
