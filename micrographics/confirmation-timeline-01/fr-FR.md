# BD-V-046-01 Confirmation timeline

## Alt text

Une transaction non confirmée reste dans la file d’attente, puis est incluse dans le bloc N, ce qui constitue sa première confirmation. Chaque bloc suivant ajoute une confirmation supplémentaire.
