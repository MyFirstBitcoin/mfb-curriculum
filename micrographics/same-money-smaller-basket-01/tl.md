# BD-V-018-01 Same money, smaller basket

## Alt text

Mabibili ng parehong 100 yunit ng salapi ang lahat ng pangunahing bilihin sa basket kapag ang halaga nito ay 100, ngunit hindi kapag ang halaga ng parehong basket ay 110. Tumaas ang antas ng presyo at bumaba ang kakayahang bumili ng pera.
