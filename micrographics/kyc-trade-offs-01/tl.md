# BD-V-064-01 KYC and no-KYC trade-offs

## Alt text

Ibinibigay ng isang tao ang isang dokumento ng pagkakakilanlan, gaya ng lisensiya sa pagmamaneho, at sinusuri at iniimbak ito ng computer system ng serbisyo. Ito ang pagberipika ng pagkakakilanlan na hinihingi sa proseso ng KYC.

## Texts

### f1

Ibigay ninyo ang inyong ID

### f1-text

Nagpapakita ang isang tao ng dokumento ng pagkakakilanlan, gaya ng lisensiya sa pagmamaneho.

### f2

Sinusuri ito ng sistema

### f2-text

Sinusuri ng computer ng serbisyo ang dokumento at iniimbak ang mga detalye.
