# BD-V-006-01 How you learn each idea

## Alt text

سیکھنے کا پانچ مرحلوں پر مشتمل طریقہ: ایک بنیادی تصور سیکھیں، دکھائیں کہ آپ کیا سمجھا سکتے ہیں یا اس کا اطلاق کر سکتے ہیں، تصور کا اطلاق کریں، اسے اپنے الفاظ میں سمجھائیں، اور جائزہ لیں کہ اس کا اگلے ماڈیول سے کیا تعلق ہے۔

تصور کا اطلاق کریں
