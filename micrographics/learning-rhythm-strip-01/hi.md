# BD-V-006-01 How you learn each idea

## Alt text

सीखने की पाँच-चरणीय प्रक्रिया: एक मुख्य विचार सीखें, दिखाएँ कि आप क्या समझा सकते हैं या लागू कर सकते हैं, विचार को लागू करें, उसे अपने शब्दों में समझाएँ, और समीक्षा करें कि वह अगले मॉड्यूल से कैसे जुड़ता है।
