# BD-V-006-01 How you learn each idea

## Alt text

Μια μαθησιακή διαδικασία πέντε βημάτων: μάθετε μια βασική έννοια, δείξτε τι μπορείτε να εξηγήσετε ή να εφαρμόσετε, εφαρμόστε την έννοια, εξηγήστε την με δικά σας λόγια και επανεξετάστε πώς συνδέεται με την επόμενη ενότητα.
