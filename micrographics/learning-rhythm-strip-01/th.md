# BD-V-006-01 How you learn each idea

## Alt text

กระบวนการเรียนรู้ห้าขั้นตอน: เรียนรู้แนวคิดสำคัญ แสดงสิ่งที่คุณสามารถอธิบายหรือนำไปใช้ได้ นำแนวคิดไปใช้ อธิบายด้วยคำพูดของคุณเอง และทบทวนว่าแนวคิดนั้นเชื่อมโยงกับบทเรียนถัดไปอย่างไร
