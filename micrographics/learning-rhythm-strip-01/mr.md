# BD-V-006-01 How you learn each idea

## Alt text

पाच टप्प्यांचा अध्ययनक्रम: एक महत्त्वाची संकल्पना शिका, आपण काय समजावून सांगू शकता किंवा वापरू शकता ते दाखवा, संकल्पना वापरून पाहा, ती आपल्या स्वतःच्या शब्दांत समजावून सांगा आणि तिचा पुढील घटकाशी कसा संबंध आहे याचा आढावा घ्या.
