# BD-V-006-01 How you learn each idea

## Alt text

পাঁচ ধাপের একটি শেখার ছন্দ: একটি মূল ধারণা শিখুন, আপনি কী ব্যাখ্যা করতে বা প্রয়োগ করতে পারেন তা দেখান, ধারণাটি প্রয়োগ করুন, আপনার নিজের ভাষায় সেটি ব্যাখ্যা করুন এবং পরবর্তী মডিউলের সঙ্গে সেটি কীভাবে যুক্ত তা পর্যালোচনা করুন।
