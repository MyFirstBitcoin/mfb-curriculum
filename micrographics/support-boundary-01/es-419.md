# BD-V-084-01 Permitted support boundary

## Alt text

El educador puede brindar el apoyo permitido para la preparación y el acceso, y detener una acción insegura. Aun así, el estudiante debe dar la explicación que se evalúa, seleccionar los detalles pertinentes y tomar o indicar las decisiones requeridas.

El educador puede

### c1-n1

### c1-n2

Proporcionar una traducción o adaptación aprobada.

### c1-n3

Proporcionar los materiales o el entorno preparados.

### c1-n4

Detener una acción insegura o reiniciar la simulación.
