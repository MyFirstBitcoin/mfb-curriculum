# BD-V-035-01 A wallet manages keys

## Alt text

Un portefeuille contient les clés. Grâce à elles, vous pouvez recevoir et envoyer du bitcoin, tandis que le bitcoin lui-même reste inscrit sur le registre partagé, et non dans le téléphone ou l’appareil.

## Texts

### start

Votre portefeuille contient les clés

### b1-head

Recevoir

### b1-n1

Partagez une adresse de réception

### b2-head

Envoyer

### b2-n1

Signez avec votre clé

### end

Le bitcoin reste sur le registre partagé
