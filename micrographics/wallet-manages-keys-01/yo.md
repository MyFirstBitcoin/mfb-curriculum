# BD-V-035-01 A wallet manages keys

## Alt text

Àpò owó kan ló tọ́jú àwọn kọ́kọ́rọ́ náà. Pẹ̀lú wọn, ẹ lè gba bitcoin, kí ẹ sì fi ránṣẹ́, nígbà tí bitcoin fúnra rẹ̀ ṣì wà ní àkọsílẹ̀ lórí ìwé àkọsílẹ̀ àjọpín, kì í ṣe nínú fóònù tàbí ẹ̀rọ.
