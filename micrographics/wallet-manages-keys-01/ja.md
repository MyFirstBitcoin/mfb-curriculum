# BD-V-035-01 A wallet manages keys

## Alt text

ウォレットは鍵を保管します。その鍵を使って、ビットコインを受け取ったり送ったりすることができます。一方、ビットコインそのものはスマートフォンやデバイスの中ではなく、共有台帳上に記録されたままです。

## Texts

### start

ウォレットは鍵を保管します

### b1-head

受け取る

### b1-n1

受取用アドレスを共有します

### b2-head

送る

### b2-n1

ご自身の鍵で署名します

### end

ビットコインは共有台帳上にとどまります
