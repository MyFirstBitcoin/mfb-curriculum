# BD-V-035-01 A wallet manages keys

## Alt text

Eine Wallet verwahrt die Schlüssel. Mit ihnen können Sie bitcoin empfangen und senden, während die bitcoin selbst im gemeinsamen Kassenbuch verzeichnet bleiben, nicht im Telefon oder Gerät.

## Texts

### start

Ihre Wallet verwahrt die Schlüssel

### b1-head

Empfangen

### b1-n1

Eine Empfangsadresse teilen

### b2-head

Senden

### b2-n1

Mit Ihrem Schlüssel signieren

### end

Die bitcoin bleiben im gemeinsamen Kassenbuch
