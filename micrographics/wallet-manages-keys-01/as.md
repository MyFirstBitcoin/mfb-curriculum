# BD-V-035-01 A wallet manages keys

## Alt text

এটা ৱালেটত চাবিবোৰ থাকে। সেইবোৰৰ সহায়ত আপুনি বিটকইন গ্ৰহণ আৰু প্ৰেৰণ কৰিব পাৰে, আনহাতে বিটকইন নিজে ফোন বা ডিভাইচৰ ভিতৰত নহয়, উমৈহতীয়া খতিয়ানতহে লিপিবদ্ধ হৈ থাকে।
