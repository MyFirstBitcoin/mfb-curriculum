# BD-V-053-01 Self-custody responsibility checks

## Alt text

Ένας πίνακας με έξι εργασίες αυτοφύλαξης, τι να προστατεύσετε ή να ελέγξετε σε καθεμία και τι μπορεί να συμβεί αν κάτι πάει στραβά: αντίγραφο ασφαλείας, λήψη, αποστολή, φύλαξη, επιλογή εργαλείου και απόκτηση.

## Texts

### corner

Εργασία

### col1

Τι να προστατεύσετε ή να ελέγξετε

### col2

Αν κάτι πάει στραβά

### row1

Αντίγραφο ασφαλείας

### c1-1

Διατηρείτε τη φράση ανάκτησης εκτός σύνδεσης και μυστική.

### c1-2

Καμία εταιρεία δεν μπορεί να επαναφέρει ένα χαμένο αντίγραφο ασφαλείας.

### row2

Λήψη

### c2-1

Κοινοποιείτε μόνο τη διεύθυνση ή το αίτημα πληρωμής.

### c2-2

Η κοινοποίηση μυστικών στοιχείων επιτρέπει σε άλλους να ξοδέψουν τα bitcoin σας.

### row3

Αποστολή

### c3-1

Ελέγξτε τη μέθοδο, τον προορισμό, το ποσό και την τελική οθόνη.

### c3-2

Μια πληρωμή που έχει αποσταλεί είναι συνήθως δύσκολο να αντιστραφεί.

### row4

Φύλαξη

### c4-1

Να γνωρίζετε ποιος κατέχει τα κλειδιά.

### c4-2

Μια υπηρεσία μπορεί να περιορίσει ή να καθυστερήσει τις αναλήψεις.

### row5

Επιλογή εργαλείου

### c5-1

Ελέγξτε την πηγή λήψης και τη μέθοδο ανάκτησης.

### c5-2

Ένα πλαστό πορτοφόλι μπορεί να κλέψει τα κλειδιά σας.

### row6

Απόκτηση

### c6-1

Συγκρίνετε το συνολικό κόστος, τα στοιχεία ταυτότητας και τα όρια.

### c6-2

Κρυφές χρεώσεις ή ένας ανέντιμος συναλλασσόμενος μπορεί να σας κοστίσουν χρήματα.
