# BD-V-062-01 Bitcoin ATM off-ramp

## Alt text

Eine Person an einem Bitcoin-Geldautomaten sendet bitcoin von ihrem Smartphone und erhält Bargeld in lokaler Währung: ein Beispiel für einen Ausstiegsweg von bitcoin in lokales Geld. Es handelt sich um eine Veranschaulichung, nicht um eine Empfehlung.

## Texts

### f1

Vom Smartphone senden

### f1-text

Eine Person an einem Bitcoin-Geldautomaten sendet bitcoin von ihrem Smartphone.

### f2

Bargeld entnehmen

### f2-text

Der Automat zahlt Bargeld in lokaler Währung aus.
