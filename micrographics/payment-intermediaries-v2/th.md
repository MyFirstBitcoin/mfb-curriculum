# Payment Intermediaries v2

## Alt text

การเปรียบเทียบเส้นทางการชำระเงินสองแบบ: การชำระเงินด้วยดอลลาร์เดินทางจากผู้ส่งถึงผู้รับผ่านผู้ประมวลผลการชำระเงิน ธนาคารผู้ออกบัตร และธนาคารของร้านค้า ขณะที่การชำระเงินด้วยบิตคอยน์ส่งตรงจากผู้ส่งถึงผู้รับ

## Texts

### processor

ผู้ประมวลผลการชำระเงิน

### issuing-bank

ธนาคาร<br>ผู้ออกบัตร

### merchant-bank

ธนาคาร<br>ของร้านค้า

### note

การชำระเงินด้วยบัตรต้องผ่านตัวกลางสามราย ส่วนการชำระเงินด้วยบิตคอยน์ส่งตรงจากผู้ส่งถึงผู้รับ
