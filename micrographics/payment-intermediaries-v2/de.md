# Payment Intermediaries v2

## Alt text

Zwei Zahlungswege im Vergleich: Eine Dollarzahlung gelangt vom Sender über einen Zahlungsdienstleister, eine kartenausgebende Bank und die Bank des Händlers zum Empfänger, während eine Bitcoin-Zahlung direkt vom Sender zum Empfänger geht.

## Texts

### processor

Kartenausgebende<br>Bank

Bank des<br>Händlers

### note

Eine Kartenzahlung läuft über drei Vermittler. Eine Bitcoin-Zahlung geht direkt vom Sender zum Empfänger.
