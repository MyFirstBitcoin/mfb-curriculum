# BD-V-071-01 Optional ways to join the network

## Alt text

பிட்காயின் கல்வி வலையமைப்பில் நடைபெறும் நட்பான காணொலி அழைப்பை ஆறு சின்னங்கள் குறிக்கின்றன: ஒரு தொலைபேசி, மக்கள், ஒரு புன்னகை, ஓர் உரையாடல், ஓர் இணைப்பு மற்றும் ஒத்துழைப்பு. பங்கேற்பது விருப்பத்திற்குரியது.
