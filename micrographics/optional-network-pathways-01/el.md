# BD-V-071-01 Optional ways to join the network

## Alt text

Έξι εικονίδια συμβολίζουν μια φιλική βιντεοκλήση στο Δίκτυο Εκπαίδευσης για το Bitcoin: ένα τηλέφωνο, ανθρώπους, ένα χαμόγελο, μια συνομιλία, μια σύνδεση και τη συνεργασία. Η συμμετοχή είναι προαιρετική.
