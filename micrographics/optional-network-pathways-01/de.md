# BD-V-071-01 Optional ways to join the network

## Alt text

Sechs Symbole stehen für einen freundlichen Videoanruf im Bitcoin Education Network: ein Telefon, Menschen, ein Lächeln, ein Gespräch, eine Verbindung und Zusammenarbeit. Die Teilnahme ist freiwillig.
