# BD-V-071-01 Optional ways to join the network

## Alt text

ਛੇ ਪ੍ਰਤੀਕ ਬਿਟਕੋਇਨ ਸਿੱਖਿਆ ਨੈੱਟਵਰਕ ਵਿੱਚ ਇੱਕ ਦੋਸਤਾਨਾ ਵੀਡੀਓ ਕਾਲ ਨੂੰ ਦਰਸਾਉਂਦੇ ਹਨ: ਇੱਕ ਫ਼ੋਨ, ਲੋਕ, ਇੱਕ ਮੁਸਕਰਾਹਟ, ਗੱਲਬਾਤ, ਜੁੜਾਅ ਅਤੇ ਸਹਿਯੋਗ। ਸ਼ਾਮਲ ਹੋਣਾ ਵਿਕਲਪਿਕ ਹੈ।
