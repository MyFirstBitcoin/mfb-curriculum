# BD-V-024-01 Five-part answer to double spending

## Alt text

Cinco elementos se combinan para resolver el problema del doble gasto: una red entre pares, firmas digitales, bloques y minería, verificación independiente y un historial compartido con la mayor prueba de trabajo acumulada. Juntos permiten que la red rechace un segundo gasto sin una autoridad central.
