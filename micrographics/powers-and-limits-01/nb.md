# BD-V-026-01 Participant powers and limits

## Alt text

Brukere, noder, minere, utviklere og tjenester har alle en viss innflytelse på Bitcoins felles regler og offentlige hovedbok, men ingen kan alene endre hovedboken eller reglene for alle.

## Texts

### i1

Brukere

### i1-text

Kan gjennomføre transaksjoner uten konto. Kan ikke endre reglene for alle.

### i2

Noder

### i2-text

Kan kontrollere hver transaksjon og blokk. Kan ikke påtvinge andre regler.

### i3

Minere

### i3-text

Kan foreslå blokker. Kan ikke gjøre en ugyldig blokk gyldig.

### center

Felles regler og offentlig hovedbok

### i4

Utviklere

### i4-text

Kan skrive programvare med åpen kildekode. Endringer må tas i bruk frivillig.

### i5

Tjenester

### i5-text

Kan skape avhengighet. Kan ikke omskrive hovedboken.
