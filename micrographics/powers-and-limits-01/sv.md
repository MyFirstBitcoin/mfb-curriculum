# BD-V-026-01 Participant powers and limits

## Alt text

Användare, noder, utvinnare, utvecklare och tjänster har var och en ett visst inflytande över Bitcoins gemensamma regler och offentliga liggare, men ingen kan på egen hand ändra liggaren eller reglerna för alla.

## Texts

### i1

Användare

### i1-text

Kan genomföra transaktioner utan konto. Kan inte ändra reglerna för alla.

### i2

Noder

### i2-text

Kan kontrollera varje transaktion och block. Kan inte tvinga på andra regler.

### i3

Utvin­nare

### i3-text

Kan föreslå block. Kan inte göra ett ogiltigt block giltigt.

### center

Gemensamma regler och offentlig liggare

### i4

Utvecklare

### i4-text

Kan skriva programvara med öppen källkod. Ändringar måste införas frivilligt.

### i5

Tjänster

### i5-text

Kan skapa beroenden. Kan inte skriva om liggaren.
