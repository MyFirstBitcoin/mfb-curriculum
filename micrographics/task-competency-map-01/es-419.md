# BD-V-083-01 Tasks to competencies

## Alt text

Las interacciones teóricas T1 a T3 aportan evidencia de las competencias C1 a C5, y las rutas prácticas P6a, P6b y P7 aportan evidencia de C6 y C7. Luego, cada competencia recibe un resultado de Sí o Todavía no.

### c1-n1

### c1-n2

### c1-n3

### c1-f1-label
