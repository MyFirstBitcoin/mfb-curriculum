# BD-V-083-01 Tasks to competencies

## Alt text

T1 முதல் T3 வரையிலான கோட்பாட்டுக் கலந்துரையாடல்கள் C1 முதல் C5 வரையிலான திறன்களுக்குச் சான்றுகளை வழங்குகின்றன; P6a, P6b மற்றும் P7 ஆகிய செய்முறை வழிகள் C6 மற்றும் C7 ஆகியவற்றுக்குச் சான்றுகளை வழங்குகின்றன. பின்னர் ஒவ்வொரு திறனுக்கும் ஆம் அல்லது இன்னும் இல்லை என்ற ஒரு முடிவு வழங்கப்படுகிறது.
