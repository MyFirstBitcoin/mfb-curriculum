# BD-V-083-01 Tasks to competencies

## Alt text

กิจกรรมโต้ตอบภาคทฤษฎี T1 ถึง T3 ให้หลักฐานสำหรับสมรรถนะ C1 ถึง C5 และแนวทางภาคปฏิบัติ P6a, P6b และ P7 ให้หลักฐานสำหรับ C6 และ C7 จากนั้นแต่ละสมรรถนะจะได้รับผลการประเมินหนึ่งรายการว่า ใช่ หรือ ยังไม่ผ่าน
