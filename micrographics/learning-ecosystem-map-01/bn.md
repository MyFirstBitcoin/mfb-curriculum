# BD-V-086-01 The learning ecosystem

## Alt text

শিক্ষার্থী নির্দেশিকা ব্যাখ্যা প্রদান করে, শিক্ষক নির্দেশিকা পাঠদানে সহায়তা করে এবং শিক্ষা উপকরণ কেন্দ্রের নির্বাচিত কার্যক্রম অনুশীলনে সহায়তা করে। মূল্যায়ন ছক মূল্যায়নের গোপনীয় ফলাফল সংরক্ষণ করে।
