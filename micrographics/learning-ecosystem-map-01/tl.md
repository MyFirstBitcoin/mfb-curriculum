# BD-V-086-01 The learning ecosystem

## Alt text

Ang Gabay para sa Mag-aaral ay nagbibigay ng mga paliwanag, ang Gabay para sa Tagapagturo ay sumusuporta sa pagtuturo, at ang mga piling gawain sa Sentro ng mga Mapagkukunan ay sumusuporta sa pagsasanay. Ang Talahanayan ng Pagtatasa ay naglalaman ng mga pribadong resulta ng pagtatasa.
