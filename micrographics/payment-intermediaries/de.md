# Payment Intermediaries

## Alt text

Eine Dollar-Zahlung gelangt vom Zahler über einen Zahlungsdienstleister, eine kartenausgebende Bank und eine Händlerbank zum Zahlungsempfänger, während eine Bitcoin-Zahlung direkt vom Zahler zum Zahlungsempfänger geht.
