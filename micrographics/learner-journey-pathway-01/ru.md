# BD-V-077-01 Learner journey pathway

## Alt text

Один из возможных путей обучения начинается с курса «Введение в биткоин», продолжается курсом «Диплом по биткоину», затем программой подготовки преподавателей, после чего вы можете стать преподавателем, работающим по учебной программе My First Bitcoin, и присоединиться к Сети биткоин-образования. Каждый следующий шаг — это выбор, а не требование.
