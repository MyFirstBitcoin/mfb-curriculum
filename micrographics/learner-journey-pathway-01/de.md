# BD-V-077-01 Learner journey pathway

## Alt text

Ein optionaler Lernweg führt von der Einführung in Bitcoin zum Bitcoin-Diplom, dann zum Ausbildungsprogramm für Lehrkräfte, weiter zur Tätigkeit als Lehrkraft, die mit dem Lehrplan von My First Bitcoin unterrichtet, und schließlich zum Beitritt zum Bitcoin-Bildungsnetzwerk. Jeder weitere Schritt ist eine Wahl, keine Pflicht.
