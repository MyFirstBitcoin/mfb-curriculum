# BD-V-048-01 Ways to receive bitcoin

## Alt text

Eine Person kann bitcoin auf vier verschiedenen Wegen erhalten: indem sie ihn durch Arbeit oder Verkäufe verdient, lokales Bargeld mit einer anderen Person tauscht, eine Börse oder einen Broker nutzt oder einen Automaten verwendet. Jeder Weg endet in Selbstverwahrung oder einem verwahrten Guthaben, und keiner wird gegenüber den anderen empfohlen.

### b1-head

### b2-head

Bargeld persönlich tauschen.

### b3-head

Börse

### b3-n1

Bei einem Dienst kaufen.

### b4-head

Automat

### b4-n1

### end

Selbstverwahrung oder verwahrtes Guthaben
