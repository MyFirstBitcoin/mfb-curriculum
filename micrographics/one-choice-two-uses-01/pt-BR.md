# BD-V-012-01 One choice, two uses

## Alt text

Um consumidor com dinheiro limitado observa as opções à sua frente: comida para hoje, transporte ou poupar para depois. Escolher uma significa abrir mão das outras, o que é o custo de oportunidade, e nenhuma opção está marcada como a certa.

## Texts

### start

Um consumidor com dinheiro limitado avalia as opções

### b1-head

Comida

### b1-n1

Comer bem hoje.

### b2-head

Transporte

### b2-n1

Chegar ao trabalho.

### b3-head

Poupar

### b3-n1

Guardar para depois.

### end

Cada escolha abre mão das outras: o custo de oportunidade
