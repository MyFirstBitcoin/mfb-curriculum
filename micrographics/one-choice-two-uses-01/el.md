# BD-V-012-01 One choice, two uses

## Alt text

Ένα άτομο που ψωνίζει με περιορισμένα χρήματα εξετάζει τις επιλογές που έχει μπροστά του: φαγητό για σήμερα, μετακίνηση ή αποταμίευση για αργότερα. Επιλέγοντας μία, παραιτείται από τις άλλες, κάτι που αποτελεί το κόστος ευκαιρίας, και καμία επιλογή δεν επισημαίνεται ως η σωστή.

## Texts

### start

Ένα άτομο που ψωνίζει με περιορισμένα χρήματα σταθμίζει τις επιλογές του

### b1-head

Φαγητό

### b1-n1

Να φάει καλά σήμερα.

### b2-head

Μετακίνηση

### b2-n1

Να πάει στη δουλειά.

### b3-head

Αποταμίευση

### b3-n1

Να κρατήσει τα χρήματα για αργότερα.

### end

Κάθε επιλογή σημαίνει παραίτηση από τις άλλες: το κόστος ευκαιρίας
