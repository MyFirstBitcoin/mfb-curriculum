# BD-V-012-01 One choice, two uses

## Alt text

Una persona con dinero limitado para sus compras observa las opciones que tiene delante: comida para hoy, transporte o ahorrar para después. Elegir una implica renunciar a las demás, lo que constituye el costo de oportunidad, y ninguna opción está marcada como la correcta.

### b1-n1

### b2-head

### end
