# BD-V-100-01 Three trust models compared

## Alt text

Bitcoin, un model generic de monedă stabilă și un model generic de alt tip de token sunt comparate în funcție de cine controlează oferta, pe ce se bazează, ce poate verifica un cursant și ce contrapărți există. Portofelele și serviciile adaugă propriile riscuri în toate cele trei cazuri, așadar un ecran similar nu înseamnă același model de încredere.
