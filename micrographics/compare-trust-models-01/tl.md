# BD-V-100-01 Three trust models compared

## Alt text

Inihahambing ang Bitcoin, isang pangkalahatang modelo ng stablecoin at isang pangkalahatang modelo ng iba pang token batay sa kung sino ang kumokontrol sa suplay, ano ang sumusuporta rito, ano ang maaaring beripikahin ng isang mag-aaral at sino ang mga kabilang panig sa transaksyon. Nagdaragdag ang mga wallet at serbisyo ng sarili nilang panganib sa lahat ng tatlo, kaya ang magkatulad na screen ay hindi nangangahulugang magkapareho ang modelo ng pagtitiwala.
