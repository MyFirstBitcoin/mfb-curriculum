# BD-V-068-01 Local resource record

## Alt text

Un tableau vierge pour recenser les ressources locales d’aide sur Bitcoin. Pour chaque ressource, les apprenants indiquent son nom, son utilité, la date à laquelle ils l’ont vérifiée, un contact ou un lieu, ainsi qu’une note de sécurité.
