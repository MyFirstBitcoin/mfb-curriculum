# BD-V-075-01 Checking a certificate

## Alt text

برای بررسی گواهی دیپلم بیت‌کوین، مدرس یا سازمان صادرکنندهٔ آن را پیدا کنید و از آن‌ها بپرسید. My First Bitcoin سرویس مرکزی برای تأیید اعتبار گواهی‌ها ندارد؛ فقط صادرکننده می‌تواند گواهی را تأیید، اصلاح یا لغو کند.
