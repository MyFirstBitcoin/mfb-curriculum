# BD-V-057-01 What to verify in a tool

## Alt text

Zece aspecte de verificat înainte de a utiliza un instrument Bitcoin local: scop, custodie, sursă, continuitatea proiectului, recuperare, confidențialitate, cost, compatibilitate, asistență și legislație, fiecare cu întrebarea sa. Notați data la care ați făcut verificarea.

## Texts

### boundary

Notați data la care ați făcut verificarea. O versiune nouă necesită o nouă verificare.

Scop

### s1-text

Ce problemă rezolvă instrumentul? Este necesar?

### s2-title
