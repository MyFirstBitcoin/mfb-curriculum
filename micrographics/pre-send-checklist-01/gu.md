# BD-V-045-01 Pre-send checklist

## Alt text

ચુકવણીને મંજૂરી આપતાં પહેલાં, મોકલનાર પ્રાપ્તકર્તા અને હેતુ, ચુકવણીની પદ્ધતિ, ગંતવ્ય તેમજ રકમ, એકમ, ફી અથવા સમયમર્યાદા તપાસે છે અને પ્રક્રિયાથી અજાણ હોય ત્યારે નાનું પરીક્ષણ કરે છે. જો કંઈપણ અલગ હોય, તો તેઓ રોકાય છે અને ચકાસે છે; બધું મેળ ખાતું હોય ત્યારે જ મંજૂરી આપે છે અને પછી પરિણામ તપાસે છે.

## Texts

### screen-title

તમે મોકલો તે પહેલાં

### f1-label

✓ પ્રાપ્તકર્તા

### f1

વિશ્વસનીય માધ્યમ દ્વારા કોને અને શા માટે મોકલી રહ્યાં છો તેની ખાતરી કરો.

### f2-label

✓ ચુકવણીની પદ્ધતિ

### f2

ચુકવણી ઑન-ચેઇન છે કે લાઇટનિંગ દ્વારા છે તેની ખાતરી કરો.

### f3-label

✓ ગંતવ્ય

### f3

તેની સરખામણી વિશ્વસનીય ચુકવણી સ્વીકારવાની સ્ક્રીન સાથે કરો.

### f4-label

✓ રકમ અને ફી

### f4

રકમ, એકમ, ફી અથવા સમયમર્યાદા તપાસો.

### f5-label

✓ નાનું પરીક્ષણ

### f5

જો પ્રક્રિયા નવી હોય, તો પહેલાં નાની રકમ મોકલો.

### f6-label

✓ મંજૂરી આપો

### f6

બધું મેળ ખાતું હોય ત્યારે જ મંજૂરી આપો.

### note

શું કંઈક અલગ છે, તાત્કાલિક કરવાની જરૂર લાગે છે અથવા રિકવરીની માહિતી માગવામાં આવે છે? રોકાઓ અને ચકાસો. મોકલ્યા પછી, પરિણામ તપાસો.
