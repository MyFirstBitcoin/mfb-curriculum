# BD-V-045-01 Pre-send checklist

## Alt text

在批准付款之前，付款人会核对收款人及付款目的、支付方式、目标地址，以及金额、单位、手续费或有效期；如果流程不熟悉，会先进行小额测试。若有任何不一致，付款人会停下来核实；仅在所有信息一致时才批准，然后检查结果。

## Texts

### screen-title

发送前

### f1-label

✓ 收款人

### f1

通过可信渠道确认收款人身份及付款原因。

### f2-label

✓ 支付方式

### f2

确认是链上支付还是闪电网络支付。

### f3-label

✓ 目标地址

### f3

将其与可信的收款界面进行核对。

### f4-label

✓ 金额与手续费

### f4

检查金额、单位、手续费或有效期。

### f5-label

✓ 小额测试

### f5

如果流程不熟悉，请先发送一笔小额款项。

### f6-label

✓ 批准

### f6

仅在所有信息一致时才批准。

### note

有任何不一致、令人感到紧迫，或要求提供恢复信息？请停下来核实。发送后，请检查结果。
