# BD-V-045-01 Pre-send checklist

## Alt text

Перш ніж підтвердити платіж, відправник перевіряє одержувача й мету, спосіб оплати, призначення платежу, а також суму, одиницю, комісію або строк дії, надсилаючи невеликий тестовий платіж, якщо процедура незнайома. Якщо щось не збігається, відправник зупиняється й перевіряє; підтверджує платіж, лише коли всі дані збігаються, а потім перевіряє результат.

## Texts

### screen-title

Перш ніж надіслати

### f1-label

✓ Одержувач

### f1

Підтвердьте, кому й навіщо надсилаєте кошти, через надійний канал зв’язку.

### f2-label

✓ Спосіб оплати

### f2

Уточніть, чи це платіж у блокчейні, чи через Lightning.

### f3-label

✓ Призначення платежу

### f3

Звірте його з даними на надійному екрані отримання платежу.

### f4-label

✓ Сума й комісія

### f4

Перевірте суму, одиницю, комісію або строк дії.

### f5-label

✓ Невеликий тестовий платіж

### f5

Спочатку надішліть невелику суму, якщо процедура для вас нова.

### f6-label

✓ Підтвердження

### f6

Підтверджуйте платіж, лише коли всі дані збігаються.

### note

Щось не збігається, вас кваплять або просять надати дані для відновлення доступу? Зупиніться й перевірте. Після надсилання перевірте результат.
