# BD-V-045-01 Pre-send checklist

## Alt text

ก่อนอนุมัติการชำระเงิน ผู้ส่งตรวจสอบผู้รับและวัตถุประสงค์ วิธีชำระเงิน ปลายทาง รวมถึงจำนวนเงิน หน่วย ค่าธรรมเนียม หรือเวลาหมดอายุ โดยทดลองส่งจำนวนเล็กน้อยเมื่อยังไม่คุ้นเคย หากมีข้อมูลใดไม่ตรงกัน ผู้ส่งจะหยุดและตรวจสอบ โดยจะอนุมัติเฉพาะเมื่อข้อมูลทุกอย่างตรงกันเท่านั้น แล้วจึงตรวจสอบผลลัพธ์

## Texts

### screen-title

ก่อนที่คุณจะส่ง

### f1-label

✓ ผู้รับ

### f1

ยืนยันตัวตนผู้รับและเหตุผลในการส่งผ่านช่องทางที่เชื่อถือได้

### f2-label

✓ วิธีชำระเงิน

### f2

ยืนยันว่าจะส่งแบบออนเชนหรือผ่านไลต์นิง

### f3-label

✓ ปลายทาง

### f3

เปรียบเทียบปลายทางกับข้อมูลบนหน้าจอรับเงินที่เชื่อถือได้

### f4-label

✓ จำนวนเงินและค่าธรรมเนียม

### f4

ตรวจสอบจำนวนเงิน หน่วย ค่าธรรมเนียม หรือเวลาหมดอายุ

### f5-label

✓ ทดลองส่งจำนวนเล็กน้อย

### f5

หากยังไม่คุ้นเคยกับขั้นตอน ให้ทดลองส่งจำนวนเล็กน้อยก่อน

### f6-label

✓ อนุมัติ

### f6

อนุมัติเฉพาะเมื่อข้อมูลทุกอย่างตรงกันเท่านั้น

### note

มีข้อมูลใดไม่ตรงกัน รู้สึกว่าถูกเร่งรัด หรือมีการขอข้อมูลสำหรับกู้คืนหรือไม่? ให้หยุดและตรวจสอบ หลังส่งแล้ว ให้ตรวจสอบผลลัพธ์
