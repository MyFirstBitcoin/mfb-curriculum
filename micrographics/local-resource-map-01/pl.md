# BD-V-067-01 Local resource map

## Alt text

Mapa lokalnych zasobów zawiera sprzedawców, edukatorów, spotkania, wsparcie techniczne, informacje o giełdach, informacje prawne lub podatkowe oraz brakujące wsparcie. Wpis to punkt wyjścia, a nie dowód: każdy zawiera datę weryfikacji i uwagę dotyczącą bezpieczeństwa.
