# BD-V-067-01 Local resource map

## Alt text

Egy helyi erőforrástérkép kereskedőket, oktatókat, találkozókat, technikai támogatást, tőzsdei információkat, jogi vagy adózási információkat és hiányzó támogatást sorol fel. Egy bejegyzés kiindulópont, nem bizonyíték: mindegyik tartalmazza az ellenőrzés dátumát és egy biztonsági megjegyzést.
