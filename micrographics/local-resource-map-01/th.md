# BD-V-067-01 Local resource map

## Alt text

แผนที่แหล่งทรัพยากรในท้องถิ่นแสดงรายชื่อร้านค้า ผู้ให้ความรู้ กิจกรรมพบปะ การสนับสนุนด้านเทคนิค ข้อมูลการแลกเปลี่ยน ข้อมูลด้านกฎหมายหรือภาษี และการสนับสนุนที่ยังขาดอยู่ รายการแต่ละรายการเป็นเพียงจุดเริ่มต้น ไม่ใช่หลักฐานยืนยัน โดยแต่ละรายการจะระบุวันที่ตรวจสอบและข้อควรระวังด้านความปลอดภัย
