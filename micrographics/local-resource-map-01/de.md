# BD-V-067-01 Local resource map

## Alt text

Eine lokale Ressourcenkarte listet Händler, Lehrkräfte, Meetups, technischen Support, Informationen zu Börsen, rechtliche oder steuerliche Informationen sowie fehlende Unterstützung auf. Ein Eintrag ist ein Ausgangspunkt, kein Beweis: Jeder Eintrag trägt das Datum seiner Überprüfung und einen Sicherheitshinweis.
