# BD-V-067-01 Local resource map

## Alt text

Une carte des ressources locales répertorie les commerçants, les éducateurs, les rencontres, l’assistance technique, les informations sur les plateformes d’échange, les informations juridiques ou fiscales et les besoins d’accompagnement non couverts. Une fiche est un point de départ, pas une preuve : chacune indique sa date de vérification et comporte une note de sécurité.
