# BD-V-067-01 Local resource map

## Alt text

Տեղական ռեսուրսների քարտեզում նշված են առևտրականներ, կրթողներ, հանդիպումներ, տեխնիկական աջակցություն, փոխանակման վերաբերյալ տեղեկություններ, իրավական կամ հարկային տեղեկություններ և աջակցության բացեր։ Գրառումը մեկնակետ է, ոչ թե ապացույց․ յուրաքանչյուր գրառում պարունակում է իր ստուգման ամսաթիվը և անվտանգության նշում։
