# BD-V-067-01 Local resource map

## Alt text

Una mappa delle risorse locali elenca commercianti, formatori, meetup, supporto tecnico, informazioni sugli exchange, informazioni legali o fiscali e il supporto mancante. Una voce è un punto di partenza, non una prova: ciascuna riporta la data in cui è stata verificata e una nota di sicurezza.
