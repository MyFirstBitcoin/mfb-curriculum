# BD-V-067-01 Local resource map

## Alt text

સ્થાનિક સંસાધનોનો નકશો વેપારીઓ, શિક્ષકો, મિલન કાર્યક્રમો, તકનીકી સહાય, એક્સચેન્જ સંબંધિત માહિતી, કાનૂની અથવા કરવેરા સંબંધિત માહિતી અને અનુપલબ્ધ સહાયની યાદી આપે છે. સૂચિબદ્ધ સંસાધન એ શરૂઆતનું બિંદુ છે, પુરાવો નહીં: દરેક સાથે તેની ચકાસણીની તારીખ અને સલામતી અંગેની નોંધ આપેલી હોય છે.
