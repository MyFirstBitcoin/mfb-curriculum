# BD-V-020-01 Alternatives for saving value

## Alt text

טבלה המציגה שלוש חלופות להחזקת מזומן (מתכות יקרות, נדל״ן ומניות), ולכל אחת מהן הסיבות שבגללן אנשים עשויים לבחור בה והפשרות החשובות הכרוכות בבחירה. אף חלופה אינה מדורגת מעל האחרות.

### col2
