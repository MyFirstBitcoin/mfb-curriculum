# BD-V-020-01 Alternatives for saving value

## Alt text

Taulukko kolmesta vaihtoehdosta käteisen hallussapidolle (jalometallit, kiinteistöt ja osakkeet). Kunkin kohdalla kerrotaan, miksi ihmiset saattavat valita sen ja mitkä ovat sen keskeiset haittapuolet. Mitään vaihtoehtoa ei aseteta muiden edelle.
