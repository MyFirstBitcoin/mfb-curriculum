# BD-V-089-01 Same competency, any route

## Alt text

લાઇવ સાધનો, કાગળ પરનાં અનુકરણો અને મંજૂર સુલભ માર્ગો એક જ ક્ષમતા કેળવવામાં મદદરૂપ થઈ શકે છે, જો શીખનાર જરૂરી નિર્ણયો જાતે લે અને શિક્ષક સમકક્ષ પુરાવાનું મૂલ્યાંકન કરી શકે. સમકક્ષતા ન હોય તો પ્રમાણપત્ર આપતાં પહેલાં બીજો માર્ગ તૈયાર કરો.

### start

લાઇવ સાધન

### b1-n1

ઑનલાઇન વૉલેટ, એક્સપ્લોરર અથવા ચુકવણી

કાગળ પર અનુકરણ

### b2-n1

### b3-head

સુલભ માર્ગ

### end
