# BD-V-089-01 Same competency, any route

## Alt text

학습자가 여전히 필요한 결정을 내리고 교육자가 동등한 증거를 평가할 수 있다면, 실제 도구, 종이 시뮬레이션, 승인된 접근성 경로 모두 같은 역량을 뒷받침할 수 있어요. 동등성이 확보되지 않으면 인증 전에 다른 경로를 준비하세요.
