# BD-V-089-01 Same competency, any route

## Alt text

يمكن للأدوات الفعلية والمحاكاة الورقية والمسارات الميسّرة المعتمدة أن تدعم الكفاية نفسها، ما دام المتعلم يتخذ القرارات المطلوبة ويستطيع المعلّم تقييم أدلة متكافئة. في غياب التكافؤ، أعدّوا مسارًا آخر قبل منح الشهادة.

## Texts

### start

كفاية واحدة لتدريسها والتحقق من اكتسابها

### b1-head

أداة فعلية

### b1-n1

محفظة أو مستكشف أو عملية دفع عبر الإنترنت

### b2-head

محاكاة ورقية

### b2-n1

شاشات مطبوعة وبطاقات ورقية

### b3-head

مسار ميسّر

### b3-n1

مسار مكافئ يلائم المتعلم

### end

يتخذ المتعلم القرارات نفسها، ويقيّم المعلّم أدلة متكافئة

### loop

ألا يوجد تكافؤ؟ أعدّوا مسارًا آخر قبل منح الشهادة.
