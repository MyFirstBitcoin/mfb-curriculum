# BD-V-089-01 Same competency, any route

## Alt text

Realiai veikiančios priemonės, popierinės simuliacijos ir patvirtinti prieinami būdai gali padėti ugdyti tą pačią kompetenciją, jei besimokantysis vis tiek priima reikiamus sprendimus, o pedagogas gali vertinti lygiaverčius įrodymus. Jei lygiavertiškumo nėra, prieš sertifikavimą parenkite kitą būdą.
