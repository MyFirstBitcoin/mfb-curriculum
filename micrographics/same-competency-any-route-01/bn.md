# BD-V-089-01 Same competency, any route

## Alt text

সরাসরি ব্যবহারের টুল, কাগজভিত্তিক অনুশীলন এবং অনুমোদিত অভিগম্য পদ্ধতি একই দক্ষতা অর্জনে সহায়তা করতে পারে, যদি শিক্ষার্থী প্রয়োজনীয় সিদ্ধান্তগুলো নিজেই নেন এবং শিক্ষক সমতুল্য প্রমাণ মূল্যায়ন করতে পারেন। সমতুল্যতা না থাকলে, সনদ দেওয়ার আগে অন্য একটি পদ্ধতি প্রস্তুত করুন।

## Texts

### start

শেখানো ও যাচাই করার জন্য একটি দক্ষতা

### b1-head

সরাসরি ব্যবহারের টুল

### b1-n1

অনলাইনে ওয়ালেট, এক্সপ্লোরার বা পেমেন্ট

### b2-head

কাগজভিত্তিক অনুশীলন

### b2-n1

স্ক্রিনের মুদ্রিত প্রতিরূপ ও কাগজের কার্ড

### b3-head

অভিগম্য পদ্ধতি

### b3-n1

শিক্ষার্থীর উপযোগী একটি সমতুল্য পদ্ধতি

### end

শিক্ষার্থী একই সিদ্ধান্তগুলো নেন, এবং শিক্ষক সমতুল্য প্রমাণ মূল্যায়ন করেন

### loop

সমতুল্য নয়? সনদ দেওয়ার আগে অন্য একটি পদ্ধতি প্রস্তুত করুন।
