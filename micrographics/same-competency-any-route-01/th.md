# BD-V-089-01 Same competency, any route

## Alt text

เครื่องมือที่ใช้งานจริง การจำลองบนกระดาษ และแนวทางที่เข้าถึงได้ซึ่งผ่านการอนุมัติ สามารถสนับสนุนสมรรถนะเดียวกันได้ หากผู้เรียนยังคงตัดสินใจในเรื่องที่กำหนด และผู้สอนสามารถประเมินหลักฐานที่เทียบเท่ากันได้ หากไม่เทียบเท่ากัน ให้เตรียมแนวทางอื่นก่อนการรับรอง

## Texts

### start

สมรรถนะหนึ่งด้านที่จะสอนและประเมิน

### b1-head

เครื่องมือที่ใช้งานจริง

### b1-n1

กระเป๋าเงิน เครื่องมือสำรวจบล็อกเชน หรือการชำระเงินออนไลน์

### b2-head

การจำลองบนกระดาษ

### b2-n1

ภาพหน้าจอที่พิมพ์ออกมาและบัตรกระดาษ

### b3-head

แนวทางที่เข้าถึงได้

### b3-n1

แนวทางที่เทียบเท่ากันและเหมาะกับผู้เรียน

### end

ผู้เรียนตัดสินใจในเรื่องเดียวกัน และผู้สอนประเมินหลักฐานที่เทียบเท่ากัน

### loop

ไม่เทียบเท่ากันหรือไม่? ให้เตรียมแนวทางอื่นก่อนการรับรอง
