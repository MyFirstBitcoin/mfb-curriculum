# BD-V-089-01 Same competency, any route

## Alt text

学習者が必要な判断を自ら行い、教育者が同等の根拠に基づいて評価できるのであれば、実際のツール、紙によるシミュレーション、承認されたアクセシブルなルートのいずれでも同じコンピテンシーを支えることができます。同等性が確保できない場合は、認定の前に別のルートを用意してください。

## Texts

### start

指導し確認する1つのコンピテンシー

### b1-head

実際のツール

### b1-n1

オンラインのウォレット、エクスプローラー、または支払い

### b2-head

紙によるシミュレーション

### b2-n1

印刷した画面と紙のカード

### b3-head

アクセシブルなルート

### b3-n1

学習者に合った同等の方法

### end

学習者は同じ判断を行い、教育者は同等の根拠に基づいて評価します

### loop

同等でない場合は、認定の前に別のルートを用意してください。
