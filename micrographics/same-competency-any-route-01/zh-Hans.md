# BD-V-089-01 Same competency, any route

## Alt text

在线工具、纸质模拟以及经批准的无障碍路径都可以支持同一项能力，前提是学习者仍需做出所要求的决定，且教育者能够评判等效的证据。如果不等效，请在认证前准备另一条路径。

## Texts

### start

一项需要教授和检验的能力

### b1-head

在线工具

### b1-n1

在线使用钱包、区块浏览器或进行支付

### b2-head

纸质模拟

### b2-n1

打印的屏幕截图和纸质卡片

### b3-head

无障碍路径

### b3-n1

一条适合学习者的等效路径

### end

学习者做出相同的决定，教育者评判等效的证据

### loop

不等效？请在认证前准备另一条路径。
