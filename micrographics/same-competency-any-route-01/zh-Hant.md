# BD-V-089-01 Same competency, any route

## Alt text

只要學習者仍做出必要的決定，且教育者能夠評估同等的證據，實際工具、紙本模擬及經核准的無障礙途徑都能支援同一項能力。若不具同等性，請在認證前準備另一種途徑。

## Texts

### start

一項需要教授並檢核的能力

### b1-head

實際工具

### b1-n1

線上的錢包、區塊瀏覽器或付款

### b2-head

紙本模擬

### b2-n1

印出的畫面與紙卡

### b3-head

無障礙途徑

### b3-n1

適合學習者的同等途徑

### end

學習者做出相同的決定，教育者評估同等的證據

### loop

不具同等性？請在認證前準備另一種途徑。
