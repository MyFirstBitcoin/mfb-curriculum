# BD-V-097-01 Translation workflow

## Alt text

Překlad je proces kontroly a testování: připravte srozumitelný anglický text, přeložte jeho význam, zkontrolujte jej s jazykovým odborníkem a pedagogem, otestujte bezpečnostní pokyny se studenty a poté potvrďte rovnocennost standardů. Pokud jsou bezpečnostní pokyny nejasné, vraťte se k jejich formulaci.
