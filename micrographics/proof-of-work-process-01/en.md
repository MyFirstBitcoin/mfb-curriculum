# BD-V-032-01 Proof of work

## Alt text

A miner hashes a proposed block over and over until one result is below the network's target, then broadcasts the block. Nodes check the proof and every rule quickly before the block joins the blockchain: work is costly to produce and easy to verify.

## Texts

### f1

The miner finds a block

### f1-text

A mining machine hashes again and again until one result meets the target

### f2

The miner broadcasts it

### f2-text

The block goes out to the network

### f3

Nodes check it

### f3-text

Every node checks the proof and the rules for itself

### f4

It joins the blockchain

### f4-text

The accepted block is added to the chain
