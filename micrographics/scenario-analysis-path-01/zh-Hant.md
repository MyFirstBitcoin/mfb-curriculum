# BD-V-101-01 Scenario analysis path

## Alt text

一個虛構情境，從當事人的目標與已查證的事實出發，依序探討誰擁有控制權、有哪些選項、可能出什麼問題，以及最小且安全的下一步。改變一個條件時，推理便會回到受該條件影響的那項決定。
