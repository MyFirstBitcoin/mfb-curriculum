# BD-V-101-01 Scenario analysis path

## Alt text

Egy kitalált helyzet elemzése az adott személy céljától és az ellenőrzött tényektől halad annak tisztázásáig, hogy kinél van az irányítás, milyen lehetőségek vannak, mi romolhat el, és mi a legkisebb biztonságos következő lépés. Egy feltétel megváltoztatása visszavezeti a gondolatmenetet az érintett döntéshez.
