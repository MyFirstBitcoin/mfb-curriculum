# BD-V-101-01 Scenario analysis path

## Alt text

Ένα φανταστικό σενάριο ξεκινά από τον στόχο του ατόμου και τα επαληθευμένα στοιχεία και προχωρά στο ποιος έχει τον έλεγχο, στις επιλογές, στο τι θα μπορούσε να πάει στραβά και στο μικρότερο ασφαλές επόμενο βήμα. Η αλλαγή μίας συνθήκης επαναφέρει τη συλλογιστική στην απόφαση που επηρεάζεται.
