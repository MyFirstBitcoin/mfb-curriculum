# BD-V-101-01 Scenario analysis path

## Alt text

एका काल्पनिक प्रसंगात, व्यक्तीचे उद्दिष्ट आणि पडताळलेली तथ्ये यांपासून सुरुवात करून नियंत्रण कोणाकडे आहे, कोणते पर्याय आहेत, काय बिघडू शकते आणि पुढचे सर्वात लहान सुरक्षित पाऊल कोणते आहे यांचा क्रमाने विचार केला जातो. एखादी अट बदलल्यास, त्या अटीचा ज्या निर्णयावर परिणाम होतो त्या निर्णयाचा पुन्हा विचार केला जातो.
