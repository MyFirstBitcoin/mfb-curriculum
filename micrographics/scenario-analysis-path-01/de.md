# BD-V-101-01 Scenario analysis path

## Alt text

Ein fiktives Szenario führt vom Ziel der Person und den überprüften Fakten über die Frage, wer die Kontrolle hat, die Optionen und das, was schiefgehen könnte, bis zum kleinsten sicheren nächsten Schritt. Wird eine Bedingung geändert, kehrt die Überlegung zu der Entscheidung zurück, die davon betroffen ist.
