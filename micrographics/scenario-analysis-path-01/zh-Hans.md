# BD-V-101-01 Scenario analysis path

## Alt text

一个虚构情境从当事人的目标和已核实的事实出发，依次分析谁拥有控制权、有哪些选项、可能出现什么问题，以及最小且安全的下一步。改变一个条件，推理就会回到受其影响的那项决定。
