# BD-V-101-01 Scenario analysis path

## Alt text

એક કાલ્પનિક પરિસ્થિતિ વ્યક્તિના ધ્યેય અને ચકાસાયેલાં તથ્યોથી શરૂ થઈને કોનું નિયંત્રણ છે, કયા વિકલ્પો છે, શું નિષ્ફળ જઈ શકે છે અને આગળનું સૌથી નાનું સલામત પગલું કયું છે તે તરફ આગળ વધે છે. એક શરત બદલવાથી વિચારપ્રક્રિયા તેનાથી પ્રભાવિત થતા નિર્ણય તરફ પાછી ફરે છે.
