# BD-V-101-01 Scenario analysis path

## Alt text

Et fiktivt scenario går fra personens mål og bekreftede fakta til hvem som har kontroll, alternativene, hva som kan gå galt, og det minste trygge neste steget. Når én betingelse endres, føres resonnementet tilbake til beslutningen som påvirkes.
