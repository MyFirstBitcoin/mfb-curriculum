# BD-V-101-01 Scenario analysis path

## Alt text

Разбор вымышленной ситуации начинается с цели человека и проверенных фактов, затем рассматриваются вопросы о том, у кого находится контроль, какие есть варианты, что может пойти не так и каков минимальный безопасный следующий шаг. Изменение одного условия возвращает рассуждение к решению, на которое оно влияет.
