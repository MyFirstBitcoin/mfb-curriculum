# BD-V-101-01 Scenario analysis path

## Alt text

Ett fiktivt scenario går från personens mål och verifierade fakta till vem som har kontrollen, vilka alternativ som finns, vad som kan gå fel och det minsta säkra nästa steget. Om ett villkor ändras förs resonemanget tillbaka till det beslut som påverkas.
