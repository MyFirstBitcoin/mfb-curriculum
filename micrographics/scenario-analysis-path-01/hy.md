# BD-V-101-01 Scenario analysis path

## Alt text

Հորինված իրավիճակի վերլուծությունը սկսվում է անձի նպատակից և ստուգված փաստերից, ապա անցնում նրան, թե ում ձեռքում է վերահսկողությունը, ինչ տարբերակներ կան, ինչը կարող է ձախողվել, և որն է հաջորդ ամենափոքր անվտանգ քայլը։ Մեկ պայմանի փոփոխությունը դատողության ընթացքը վերադարձնում է այն որոշմանը, որի վրա այդ փոփոխությունն ազդում է։
