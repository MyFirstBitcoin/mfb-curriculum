# BD-V-101-01 Scenario analysis path

## Alt text

Et fiktivt scenarie bevæger sig fra personens mål og verificerede fakta til, hvem der har kontrollen, hvilke muligheder der findes, hvad der kan gå galt, og det mindste sikre næste skridt. Når én betingelse ændres, føres overvejelserne tilbage til den beslutning, som ændringen påvirker.
