# BD-V-101-01 Scenario analysis path

## Alt text

架空のシナリオが、その人の目標と確認済みの事実から始まり、誰が管理しているか、選択肢、何がうまくいかない可能性があるか、そして安全に踏み出せる最小の次の一歩へと進みます。条件を1つ変えると、その条件が影響する判断まで考えを戻すことになります。
