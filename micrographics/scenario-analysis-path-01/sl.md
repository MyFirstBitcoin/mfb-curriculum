# BD-V-101-01 Scenario analysis path

## Alt text

Izmišljeni scenarij vodi od cilja osebe in preverjenih dejstev do vprašanja, kdo ima nadzor, katere možnosti so na voljo, kaj bi lahko šlo narobe in kateri je najmanjši varen naslednji korak. Sprememba enega pogoja vrne razmislek k odločitvi, na katero ta sprememba vpliva.
