# BD-V-101-01 Scenario analysis path

## Alt text

ஒரு கற்பனைச் சூழல், அந்த நபரின் இலக்கு மற்றும் சரிபார்க்கப்பட்ட உண்மைகளிலிருந்து தொடங்கி, யாரிடம் கட்டுப்பாடு உள்ளது, என்னென்ன தேர்வுகள் உள்ளன, எதில் தவறு நேரக்கூடும், பாதுகாப்பாக எடுக்கக்கூடிய மிகச் சிறிய அடுத்த படி என்ன என்பவற்றை நோக்கி நகர்கிறது. ஒரு நிபந்தனையை மாற்றும்போது, அது பாதிக்கும் முடிவை மீண்டும் ஆராய வேண்டியதாகிறது.
