# BD-V-101-01 Scenario analysis path

## Alt text

Kuvitteellinen tilanne etenee henkilön tavoitteesta ja tarkistetuista tosiasioista siihen, kenellä on määräysvalta, mitä vaihtoehtoja on, mikä voisi mennä pieleen ja mikä on pienin turvallinen seuraava askel. Yhden ehdon muuttaminen palauttaa päättelyn siihen päätökseen, johon muutos vaikuttaa.
