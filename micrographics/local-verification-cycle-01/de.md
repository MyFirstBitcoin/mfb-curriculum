# BD-V-099-01 Local verification cycle

## Alt text

Lehrkräfte erkennen jede veränderliche lokale Aussage, überprüfen sie anhand einer aktuellen Quelle, halten das Datum und ihre Grenzen fest, unterrichten sie mit vorsichtigen Formulierungen und prüfen sie vor der erneuten Verwendung noch einmal. Ist eine Tatsache unsicher, verwenden sie ein sichereres Beispiel oder eine Ausweichlösung.

## Texts

### s1-title

Die Aussage erkennen

### s1-text

Finden Sie die lokale Tatsache, die sich ändern kann.

### s2-title

Die Quelle prüfen

### s2-text

Überprüfen Sie sie anhand einer maßgeblichen Primärquelle.

### s2-aside

Unsicher? Verwenden Sie ein sicheres Beispiel oder eine Ausweichlösung.

### s3-title

Das Datum festhalten

### s3-text

Notieren Sie, wann Sie geprüft haben und was sich ändern kann.

### s4-title

Mit Sorgfalt unterrichten

### s4-text

Verwenden Sie für den Unterricht vorsichtige, eingeschränkte Formulierungen.

### s5-title

Erneut prüfen

### s5-text

Prüfen Sie es erneut, bevor Sie es das nächste Mal verwenden.

### loop

Hat sich etwas geändert? Beginnen Sie erneut bei der Aussage.
