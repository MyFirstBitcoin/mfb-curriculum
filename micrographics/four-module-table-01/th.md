# BD-V-005-01 The four modules at a glance

## Alt text

ตารางแสดงโมดูลทั้งสี่ พร้อมบทบาท คำถามนำ และสิ่งที่ผู้เรียนจะได้ฝึกฝนในแต่ละโมดูล ได้แก่ ทำความเข้าใจเงิน บิตคอยน์ทำงานอย่างไร ใช้บิตคอยน์อย่างปลอดภัย และบิตคอยน์ในชุมชนของคุณ

### c4-3

เชื่อมโยงสิ่งที่เรียนรู้กับความต้องการในท้องถิ่นและขั้นตอนถัดไป
