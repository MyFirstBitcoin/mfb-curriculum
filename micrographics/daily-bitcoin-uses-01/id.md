# BD-V-060-01 Ways to use Bitcoin in daily life

## Alt text

Tujuh cara berbeda untuk menggunakan Bitcoin dalam kehidupan sehari-hari: memperoleh penghasilan, menabung, menerima, mengirim, berbelanja, berdonasi, serta penetapan harga dan akuntansi. Masing-masing merupakan pilihan penggunaan, bukan langkah yang wajib dilakukan.
