# BD-V-060-01 Ways to use Bitcoin in daily life

## Alt text

Առօրյա կյանքում Բիթքոյնի օգտագործման յոթ տարբեր եղանակ՝ վաստակել, խնայել, ստանալ, ուղարկել, ծախսել, նվիրաբերել, ինչպես նաև գնագոյացում և հաշվապահություն։ Դրանցից յուրաքանչյուրը հնարավոր կիրառություն է, ոչ թե պարտադիր քայլ։
