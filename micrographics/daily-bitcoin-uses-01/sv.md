# BD-V-060-01 Ways to use Bitcoin in daily life

## Alt text

Sju olika sätt att använda Bitcoin i vardagen: tjäna, spara, ta emot, skicka, spendera, donera samt prissättning och bokföring. Vart och ett är ett möjligt användningsområde, inte ett obligatoriskt steg.
