# BD-V-060-01 Ways to use Bitcoin in daily life

## Alt text

அன்றாட வாழ்வில் பிட்காயினைப் பயன்படுத்தக்கூடிய ஏழு வெவ்வேறு வழிகள்: சம்பாதித்தல், சேமித்தல், பெறுதல், அனுப்புதல், செலவழித்தல், நன்கொடை அளித்தல், விலை நிர்ணயமும் கணக்குப்பதிவும். இவை ஒவ்வொன்றும் சாத்தியமான ஒரு பயன்பாடே தவிர, கட்டாயமாகப் பின்பற்ற வேண்டிய படிநிலை அல்ல.
