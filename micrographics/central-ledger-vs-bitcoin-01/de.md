# BD-V-022-01 Central ledger and Bitcoin network

## Alt text

Bei einem Zahlungsdienstleister führt eine einzige Organisation das Kontobuch und genehmigt jede Überweisung. Bei Bitcoin signiert der Sender eine Transaktion, unabhängige Nodes prüfen sie und Miner fügen sie einem gemeinsamen Kontobuch hinzu, sodass der Empfänger weniger von einer zentralen Instanz abhängt.
