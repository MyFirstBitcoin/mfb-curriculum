# BD-V-037-01 Private key and public information

## Alt text

Из секретного закрытого ключа, которым никогда нельзя делиться, получают общедоступные данные, которыми можно делиться: открытый ключ и созданный на его основе адрес для получения. Тот же закрытый ключ создаёт подписи, которые узлы проверяют, не узнавая сам закрытый ключ.

## Texts

### start

Закрытый ключ: никогда никому его не сообщайте. Любой, у кого он есть, может потратить ваши биткоины.

### b1-head

Получение: можно безопасно делиться

### b1-n1

Открытый ключ, полученный из закрытого ключа

### b1-n2

Адрес для получения, созданный на основе данных открытого ключа

### b2-head

Расходование: ключ остаётся в секрете

### b2-n1

Закрытый ключ создаёт цифровую подпись

### b2-n2

Узлы проверяют подпись, не узнавая закрытый ключ
