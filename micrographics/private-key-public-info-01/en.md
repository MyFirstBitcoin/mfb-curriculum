# BD-V-037-01 Private key and public information

## Alt text

A secret private key, which must never be shared, leads to public information that can be shared: a public key derived from it and a receiving address created from that. The same private key creates signatures that nodes verify without ever learning the private key.

## Texts

Private key: never share it. Anyone with it can spend your bitcoin.

### b1-n1

### b1-n2

### b2-n2
