# BD-V-037-01 Private key and public information

## Alt text

คีย์ส่วนตัวที่เป็นความลับและห้ามเปิดเผยโดยเด็ดขาด ใช้สร้างข้อมูลสาธารณะที่เปิดเผยได้ ได้แก่ คีย์สาธารณะที่ได้มาจากคีย์ส่วนตัว และที่อยู่สำหรับรับที่สร้างจากคีย์สาธารณะนั้น คีย์ส่วนตัวเดียวกันนี้ใช้สร้างลายเซ็นที่โหนดตรวจสอบได้โดยไม่ต้องทราบคีย์ส่วนตัวเลย

## Texts

### start

คีย์ส่วนตัว: ห้ามเปิดเผยให้ผู้อื่นทราบโดยเด็ดขาด ใครก็ตามที่มีคีย์นี้สามารถใช้จ่ายบิตคอยน์ของคุณได้

### b1-head

การรับ: เปิดเผยได้อย่างปลอดภัย

### b1-n1

คีย์สาธารณะที่ได้มาจากคีย์ส่วนตัว

### b1-n2

ที่อยู่สำหรับรับที่สร้างจากข้อมูลคีย์สาธารณะ

### b2-head

การใช้จ่าย: คีย์ยังคงเป็นความลับ

### b2-n1

คีย์ส่วนตัวใช้สร้างลายเซ็นดิจิทัล

### b2-n2

โหนดตรวจสอบลายเซ็นโดยไม่ต้องทราบคีย์ส่วนตัว
