# BD-V-037-01 Private key and public information

## Alt text

一把必须保密、切勿与他人分享的私钥，可以推导出能够公开分享的信息：由私钥推导出的公钥，以及由公钥生成的收款地址。同一把私钥还会生成签名，节点可以验证这些签名，却始终无法得知私钥。

## Texts

### start

私钥：切勿与他人分享。任何持有私钥的人都可以花费您的比特币。

### b1-head

收款：可以安全分享

### b1-n1

公钥，由私钥推导而来

### b1-n2

收款地址，根据公钥信息生成

### b2-head

花费：私钥始终保密

### b2-n1

私钥生成数字签名

### b2-n2

节点验证签名，但无法得知私钥
