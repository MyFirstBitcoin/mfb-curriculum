# BD-V-037-01 Private key and public information

## Alt text

En hemlig privat nyckel, som aldrig får delas med någon, ligger till grund för publik information som kan delas: en publik nyckel som härleds från den och en mottagaradress som skapas utifrån den publika nyckeln. Samma privata nyckel skapar signaturer som noder verifierar utan att någonsin få kännedom om den privata nyckeln.

## Texts

### start

### b1-head

### b1-n1

### b1-n2

### b2-head

### b2-n1

### b2-n2
