# BD-V-037-01 Private key and public information

## Alt text

Salaisesta yksityisestä avaimesta, jota ei saa koskaan jakaa, saadaan tietoja, joita voi jakaa: siitä johdettu julkinen avain ja sen tiedoista luotu vastaanotto-osoite. Sama yksityinen avain luo allekirjoituksia, jotka solmut tarkistavat saamatta koskaan tietää yksityistä avainta.

## Texts

### start

Yksityinen avain: älkää koskaan jakako sitä. Kuka tahansa, jolla se on, voi käyttää bitcoininne.

### b1-head

Vastaanottaminen: turvallista jakaa

### b1-n1

Julkinen avain, joka on johdettu yksityisestä avaimesta

### b1-n2

Vastaanotto-osoite, joka on luotu julkisen avaimen tiedoista

### b2-head

Käyttäminen: avain pysyy salassa

### b2-n1

Yksityinen avain luo digitaalisen allekirjoituksen

### b2-n2

Solmut tarkistavat allekirjoituksen saamatta tietää yksityistä avainta
