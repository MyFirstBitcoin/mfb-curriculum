# BD-V-037-01 Private key and public information

## Alt text

Із секретного приватного ключа, який ніколи не можна розголошувати, отримують публічну інформацію, якою можна ділитися: публічний ключ і створену на його основі адресу для отримання. Той самий приватний ключ створює підписи, які вузли перевіряють, ніколи не дізнаючись приватного ключа.

## Texts

### start

Приватний ключ: ніколи не розголошуйте його. Кожен, хто має його, може витратити ваші біткоїни.

### b1-head

Отримання: можна безпечно ділитися

### b1-n1

Публічний ключ, отриманий із приватного ключа

### b1-n2

Адреса для отримання, створена на основі даних публічного ключа

### b2-head

Витрачання: ключ залишається таємним

### b2-n1

Приватний ключ створює цифровий підпис

### b2-n2

Вузли перевіряють підпис, не дізнаючись приватного ключа
