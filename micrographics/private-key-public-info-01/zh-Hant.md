# BD-V-037-01 Private key and public information

## Alt text

一把絕不可分享的秘密私鑰，可衍生出能夠分享的公開資訊：由私鑰推導出的公鑰，以及再由公鑰產生的收款地址。同一把私鑰也會產生簽章，節點能驗證這些簽章，卻永遠不會得知私鑰。

## Texts

### start

私鑰：切勿與他人分享。任何持有私鑰的人都能花用您的比特幣。

### b1-head

收款：可安全分享

### b1-n1

公鑰，由私鑰推導而來

### b1-n2

收款地址，由公鑰資訊產生

### b2-head

花費：私鑰始終保密

### b2-n1

私鑰產生數位簽章

### b2-n2

節點驗證簽章，但不會得知私鑰
