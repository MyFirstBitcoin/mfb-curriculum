# BD-V-037-01 Private key and public information

## Alt text

Од таен приватен клуч, кој никогаш не смее да се споделува, се добиваат јавни информации што може да се споделуваат: јавен клуч изведен од него и адреса за примање создадена од тој јавен клуч. Истиот приватен клуч создава потписи што јазлите ги проверуваат без воопшто да го дознаат приватниот клуч.

## Texts

### start

Приватен клуч: никогаш не го споделувајте. Секој што го има може да ги потроши Вашите биткоини.

### b1-head

Примање: безбедно за споделување

### b1-n1

Јавен клуч, изведен од приватниот клуч

### b1-n2

Адреса за примање, создадена од информациите за јавниот клуч

### b2-head

Трошење: клучот останува таен

### b2-n1

Приватниот клуч создава дигитален потпис

### b2-n2

Јазлите го проверуваат потписот без да го дознаат приватниот клуч
