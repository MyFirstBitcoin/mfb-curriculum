# BD-V-037-01 Private key and public information

## Alt text

Una clave privada secreta, que nunca debe compartirse, da lugar a información pública que sí se puede compartir: una clave pública derivada de ella y una dirección de recepción creada a partir de esa clave pública. La misma clave privada crea firmas que los nodos verifican sin llegar a conocer la clave privada.

## Texts

Clave privada: nunca la comparta. Cualquiera que la tenga puede gastar sus bitcoin.

### b1-head

Para recibir: se puede compartir de forma segura

### b1-n1

Clave pública, derivada de la clave privada

### b1-n2

### b2-head

### b2-n1

### b2-n2
