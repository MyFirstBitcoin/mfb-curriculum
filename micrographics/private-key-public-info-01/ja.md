# BD-V-037-01 Private key and public information

## Alt text

決して共有してはならない秘密の秘密鍵から、共有しても問題のない公開情報が生まれます。秘密鍵から導き出される公開鍵と、その公開鍵から作成される受取用アドレスです。同じ秘密鍵は署名も作成し、ノードは秘密鍵を一切知ることなくその署名を検証します。

## Texts

### start

秘密鍵：決して他人に教えないでください。秘密鍵を持つ人は誰でも、あなたのビットコインを使うことができます。

### b1-head

受け取り：共有しても安全です

### b1-n1

公開鍵：秘密鍵から導き出されます

### b1-n2

受取用アドレス：公開鍵の情報から作成されます

### b2-head

支払い：鍵は秘密のままです

### b2-n1

秘密鍵がデジタル署名を作成します

### b2-n2

ノードは秘密鍵を知ることなく署名を検証します
