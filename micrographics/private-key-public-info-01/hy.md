# BD-V-037-01 Private key and public information

## Alt text

Գաղտնի պահվող մասնավոր բանալիից, որով երբեք չի կարելի կիսվել, ստացվում են հանրային տվյալներ, որոնցով կարելի է կիսվել՝ դրանից ստացված հանրային բանալի և այդ հանրային բանալու տվյալներից ստեղծված ստացման հասցե։ Նույն մասնավոր բանալին ստեղծում է ստորագրություններ, որոնք հանգույցները ստուգում են՝ առանց երբևէ մասնավոր բանալին իմանալու։

## Texts

### start

Մասնավոր բանալի․ երբեք մի՛ կիսվեք դրանով։ Այն ունեցող ցանկացած անձ կարող է ծախսել ձեր բիթքոյնները։

### b1-head

Ստացում․ անվտանգ է կիսվել

### b1-n1

Հանրային բանալի՝ ստացված մասնավոր բանալիից

### b1-n2

Ստացման հասցե՝ ստեղծված հանրային բանալու տվյալներից

### b2-head

Ծախսում․ բանալին մնում է գաղտնի

### b2-n1

Մասնավոր բանալին ստեղծում է թվային ստորագրություն

### b2-n2

Հանգույցները ստուգում են ստորագրությունը՝ առանց մասնավոր բանալին իմանալու
