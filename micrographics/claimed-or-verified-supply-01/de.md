# BD-V-027-01 Claimed or verified supply

## Alt text

Eine Mengenbegrenzung, die auf einer Website oder in der Datenbank eines Emittenten steht, kann von diesem Emittenten stillschweigend geändert werden. Die Angebotsregel von Bitcoin ist öffentlich, und Signaturen, eine öffentliche Historie, Proof of Work und die Überprüfung durch Nodes verhindern gemeinsam, dass neue Coins erfunden oder derselbe bitcoin zweimal ausgegeben wird.
