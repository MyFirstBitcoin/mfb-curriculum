# BD-V-004-01 The learning path

## Alt text

แผนการเรียนรู้สี่ขั้นตอน: ปัญหา ทำความเข้าใจเรื่องเงิน; ทางออก บิตคอยน์ทำงานอย่างไร; ลงมือทำ ใช้บิตคอยน์อย่างปลอดภัย; และเชื่อมโยง บิตคอยน์ในชุมชนของคุณ โดยแต่ละขั้นตอนมีคำถามนำทาง

## Texts

### i1

ปัญหา

### i1-note

ทำความเข้าใจเรื่องเงิน: ระบบการเงินทำงานและเปลี่ยนแปลงอย่างไร?

### i2

ทางออก

### i2-note

บิตคอยน์ทำงานอย่างไร: เหตุใดจึงมีการสร้างบิตคอยน์ขึ้นมา และบิตคอยน์ตอบโจทย์ปัญหาอย่างไร?

### i3

ลงมือทำ

### i3-note

ใช้บิตคอยน์อย่างปลอดภัย: คุณจะรับผิดชอบต่อการใช้และการรักษาความปลอดภัยของบิตคอยน์ได้อย่างไร?

### i4

เชื่อมโยง

### i4-note

บิตคอยน์ในชุมชนของคุณ: ปัญหา ทางออก และการลงมือทำอย่างปลอดภัยเชื่อมโยงกับชุมชนนี้อย่างไร?
