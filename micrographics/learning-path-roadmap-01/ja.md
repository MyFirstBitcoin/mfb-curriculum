# BD-V-004-01 The learning path

## Alt text

4つの段階からなるロードマップ：課題（お金を理解する）、解決策（ビットコインの仕組み）、行動（ビットコインを安全に使う）、つながる（地域社会におけるビットコイン）。それぞれに指針となる問いが添えられています。

### i2

### i3

行動

### i3-note
