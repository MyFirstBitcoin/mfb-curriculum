# BD-V-004-01 The learning path

## Alt text

ოთხეტაპიანი გზამკვლევი: პრობლემა — ფულის გააზრება; გადაწყვეტა — როგორ მუშაობს ბიტკოინი; მოქმედება — ბიტკოინის უსაფრთხოდ გამოყენება; და დაკავშირება — ბიტკოინი თქვენს თემში. თითოეულ ეტაპს თავისი მიმართულების მიმცემი კითხვა ახლავს.
