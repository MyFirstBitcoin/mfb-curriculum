# BD-V-095-01 Module 4 readiness gate

## Alt text

Восемь проверок охватывают цель, компетенцию, возможности преподавателя, инструменты, местные нормы, безопасность, доступ и наблюдение. Для проведения занятия в реальных условиях все проверки должны дать удовлетворительный результат; при выявлении пробела нужно выбрать более безопасный путь или пересмотреть план, а затем повторно оценить готовность.
