# BD-V-011-01 Same water, different value

## Alt text

La même bouteille d’eau potable coûte peu dans le réfrigérateur d’un magasin où l’eau est facile à trouver, et a beaucoup plus de valeur dans un désert brûlant en période de pénurie. La disponibilité, le besoin et les circonstances modifient la valeur et le prix.
