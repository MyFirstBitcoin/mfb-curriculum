# BD-V-011-01 Same water, different value

## Alt text

தண்ணீர் எளிதாகக் கிடைக்கும் இடத்தில் உள்ள ஒரு கடையின் குளிர்சாதனப் பெட்டியில் சுத்தமான தண்ணீர் பாட்டிலின் விலை குறைவாக உள்ளது. அதே பாட்டில், தட்டுப்பாடு நிலவும் வெப்பமான பாலைவனத்தில் மிகவும் மதிப்புமிக்கதாக உள்ளது. கிடைக்கும் தன்மை, தேவை, சூழ்நிலைகள் ஆகியவை மதிப்பையும் விலையையும் மாற்றுகின்றன.
