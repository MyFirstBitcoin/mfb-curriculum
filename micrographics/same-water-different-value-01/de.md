# BD-V-011-01 Same water, different value

## Alt text

Dieselbe Flasche sauberen Wassers ist im Kühlschrank eines Ladens, wo Wasser leicht zu finden ist, günstig und während einer Knappheit in einer heißen Wüste viel wertvoller. Verfügbarkeit, Bedarf und Umstände verändern Wert und Preis.
