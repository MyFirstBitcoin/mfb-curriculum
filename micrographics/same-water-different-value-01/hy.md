# BD-V-011-01 Same water, different value

## Alt text

Մաքուր ջրի նույն շիշը էժան է խանութի սառնարանում, որտեղ ջուր գտնելը հեշտ է, և շատ ավելի արժեքավոր է շոգ անապատում՝ ջրի պակասի ժամանակ։ Հասանելիությունը, կարիքն ու հանգամանքները փոխում են արժեքն ու գինը։
