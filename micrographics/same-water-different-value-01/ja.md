# BD-V-011-01 Same water, different value

## Alt text

同じきれいな水のボトルでも、水が簡単に手に入るお店の冷蔵庫では安く、水が不足している暑い砂漠でははるかに価値が高くなります。手に入りやすさ、必要性、状況によって、価値と価格は変わります。
