# BD-V-011-01 Same water, different value

## Alt text

Aceeași sticlă de apă curată este ieftină în frigiderul unui magazin unde apa se găsește ușor și mult mai valoroasă într-un deșert fierbinte, în timpul unei penurii. Disponibilitatea, nevoia și circumstanțele schimbă valoarea și prețul.
