# How Transations Work

## Alt text

Alice कडून Bob ला बिटकॉइन देयक पाठवण्याची प्रक्रिया दाखवणारा उभा सात-टप्प्यांचा प्रवाह: व्यवहार तयार करणे व त्यावर स्वाक्षरी करणे, त्याचे प्रसारण करणे, नोड्सद्वारे पडताळणी, मेमपूल, मायनिंगद्वारे ब्लॉकमध्ये समावेश आणि पुष्टींची संख्या वाढत असताना ब्लॉक ब्लॉकचेनमध्ये जोडला जाणे.
