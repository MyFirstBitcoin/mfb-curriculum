# Maallaqni Maali?

**Maallaqni meeshaa waljijjiirraati.**

Namni kamiyyuu maallaqa maallaqa taʼuu isaatiif qofa hin barbaadu. Wanta inni bituu dandaʼuuf isa barbaanna. Maallaqni waraqaa, waraqaa tokko qofa. Wanti faayidaa akka qabaatu isa godhu, namoonni biroon wantoota nuti dhugumaan barbaannuuf bakka buusanii isa fudhachuu isaaniiti; sababni isaas, boodarra namoonni biroonis ni fudhatu jedhanii eegu.

Wanti maallaqa waljijjiirraa meeshaa meeshaadhaan irraa adda baasu kana.

Sirna waljijjiirraa meeshaa meeshaadhaan keessatti, daldalli kan milkaaʼu namoonni lamaan yeroo tokkotti, hamma mijataa taʼeen, wanta inni kaan qabu yoo barbaadan qofadha. Ogeeyyiin dinagdee kana **fedhiin gama lamaanii yeroo tokkotti walitti dhufuu** jedhu. Isin ruuzii kan oomishtan yoo taatanii fi kophee yoo barbaaddan, namni kophee hojjetu ruuzii osoo hin taane zayita nyaataa barbaaduu dandaʼa. Maallaqni gurguruu bituu irraa adda baasuudhaan rakkoo kana fura: ruuzii keessan nama tokkoof gurgurtanii nama biraa irraa kophee bitattu.

**Maallaqni yeroo baayʼee hojii sadii hojjeta.**

Inni **giddugaleessa waljijjiirraa** dha: namoonni kaffaltiidhaaf isa fudhatu. Inni **yuunitii herregaa** dha: gatiin ittiin ibsama; kanaaf gatii wantoota adda addaa walbira qabnee ilaaluu dandeenya. Akkasumas inni **kuusaa gatii** dha: gatii harʼaa gara fuulduraatti dabarsa. Maallaqni kamiyyuu gatii guutummaatti hin kuusu; garuu gosoonni tokko tokko humna bittaa isaanii kanneen biroo caalaa suuta dhabu.

Seenaa keessatti wantoonni hedduun akka maallaqaatti tajaajilaniiru: qola bineensota bishaanii, soogidda, callee, beeylada, sibiila diimaa, meetii fi warqee. Sibiilonni gatii guddaa qaban muraasa, yeroo dheeraa kan turanii fi balʼinaan fudhatama kan qaban waan taʼaniif itti fayyadamni isaanii babalʼate. Garuu sibiila baachuu fi eeguun rakkisaa waan taʼeef, baankonni waraqaa hamma sibiilaa murtaaʼe tokko ittiin gaafachuun argachuun dandaʼamu kennuu jalqaban. Gosoota adda addaa **istaandaardii warqee** jalatti, yuunitiin maallaqaa hamma warqee tokko waliin seeraan walqabsiifamee ture. Seerotni akka bakkaatii fi yeroo adda addaatti garaagarummaa qabu turan.

Yeroo darbaa deemuun, maallaqni sibiila caalaa dhaabbilee fi waadaawwan irratti hundaaʼuu jalqabe. Bara 1971, Yunaayitid Isteetis mootummoonni alaa fi baankonni giddugaleessaa doolaara warqeetti akka jijjiiratan kan hayyamu waljijjiirraa seera qabeessa dhaabde. Harʼa, maallaqoonni biyyoolessaa irra caalaan **maallaqa fiyaat** dha: maallaqa aangoo mootummaatiin, yeroo baayʼee karaa baankii giddugaleessaa, kennamu kan hamma warqee murtaaʼe yookaan meeshaa gurgurtaa biraa kamittiyyuu jijjiiramuu hin dandeenye. Jechi fiyaat afaan Laatiiniitiin "haa raawwatamu" jechuu dha; yeroo baayʼee akka "ajajaan" jedhutti hubatama.

Maallaqni fiyaat kan hojjetu namoonni, dhaabbileen daldalaa, baankonnii fi mootummoonni waan isa fudhataniifi. Seeronni yeroo baayʼee maallaqa kaffaltiidhaaf seeraan fudhatama qabu isa godhu; gibira kaffaluufis akka itti fayyadaman dirqisiisu. Namoonnis namni naannoo isaanii jiru hundi waan itti fayyadamuuf isa barbaadu.

**Maallaqa waan tokkoon deeggaramu irraa gara maallaqa amantaa nama tokko irratti qabnuun deeggaramutti ceene.**
