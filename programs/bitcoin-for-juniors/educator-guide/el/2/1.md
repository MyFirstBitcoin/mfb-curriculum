# 2.1 Επισκόπηση

#### Πρόλογος

Αυτό το κεφάλαιο βοηθά τους μαθητές να αντιληφθούν ότι ο χρόνος και η ενέργεια είναι πολύτιμοι πόροι. Οι μαθητές θα διερευνήσουν πώς η προσπάθεια, η ξεκούραση, η τύχη, οι κανόνες και η υπομονή μπορούν να διαμορφώσουν τις ανταμοιβές που λαμβάνουν οι άνθρωποι, αναπτύσσοντας παράλληλα το λεξιλόγιό τους για τη δικαιοσύνη και για τις επιλογές που επηρεάζουν το μέλλον.

#### Γενικοί στόχοι

* Να παρατηρήσουν πώς ο χρόνος, η ενέργεια, η προσπάθεια και η ξεκούραση επηρεάζουν τις καθημερινές αποφάσεις.
* Να συγκρίνουν συστήματα ανταμοιβής που βασίζονται στη δικαιοσύνη, στην τύχη και στην προσπάθεια.
* Να εξετάσουν τις βραχυπρόθεσμες επιλογές σε συνάρτηση με τα μακροπρόθεσμα αποτελέσματά τους.

#### Τι να περιμένετε

Οι μαθητές θα χαρτογραφήσουν τις καθημερινές τους συνήθειες, θα παρακολουθήσουν τα επίπεδα ενέργειάς τους στη διάρκεια μιας ημέρας, θα παίξουν παιχνίδια με διαφορετικά συστήματα ανταμοιβής, θα συζητήσουν μια ιστορία για τη δικαιοσύνη, θα ξαναθυμηθούν _Τα τρία γουρουνάκια_ και θα σχεδιάσουν έναν υπερήρωα που κάνει έξυπνες επιλογές. Οι εκπαιδευτικοί μπορούν να περιμένουν ειλικρινείς προβληματισμούς και χρήσιμες συζητήσεις για την ισορροπία, την προσπάθεια, την τύχη και τη μακροπρόθεσμη σκέψη.

#### Γιατί έχει σημασία για το Bitcoin

Το Bitcoin βασίζεται στον χρόνο, στην ενέργεια και σε κοινούς κανόνες: η απόδειξη εργασίας συνδέει την προσπάθεια με την ασφάλεια του δικτύου. Οι μικροί μαθητές δεν χρειάζεται ακόμη να κατανοήσουν πλήρως τις τεχνικές του λεπτομέρειες· χρειάζονται ευκαιρίες να σκεφτούν γιατί η εργασία έχει αξία, γιατί οι κανόνες έχουν σημασία και γιατί μια επιλογή που γίνεται με υπομονή μπορεί μερικές φορές να οδηγήσει σε ένα καλύτερο αποτέλεσμα.
