# 5.1 Επισκόπηση

#### Πρόλογος

Αυτό το κεφάλαιο συνδυάζει όσα έχουν μάθει ήδη οι μαθητές για την αξία, τον χρόνο, την ενέργεια, την επιλογή και τη δικαιοσύνη σε μια κοινή οικονομία της τάξης. Οι μαθητές θα διαπιστώσουν ότι οι αποφάσεις για τα χρήματα περιλαμβάνουν σχεδιασμό, ευκαιρίες, κινδύνους και συνεργασία — και ότι οι ίδιοι κανόνες μπορούν παρ’ όλα αυτά να οδηγήσουν τους ανθρώπους σε διαφορετικά αποτελέσματα.

#### Γενικοί στόχοι

* Να εφαρμόσουν έννοιες σχετικές με την απόκτηση εισοδήματος, την αποταμίευση, τις επενδύσεις, τον δανεισμό και το εμπόριο.
* Να λαμβάνουν αποφάσεις και να αναστοχάζονται πάνω σε αυτές υπό κοινούς κανόνες, περιορισμούς και συνθήκες αβεβαιότητας.
* Να συνδέουν τις ατομικές επιλογές με τα αποτελέσματά τους σε μια ευρύτερη οικονομία.

#### Τι να περιμένετε

Σε ένα εκτεταμένο παιχνίδι ρόλων, οι μαθητές θέτουν προσωπικούς στόχους και μετακινούνται ανάμεσα σε σταθμούς που αναπαριστούν το σπίτι, το αγρόκτημα, το εργοστάσιο, την αγορά και την τράπεζα, για να αποκτήσουν εισόδημα, να αποταμιεύσουν, να επενδύσουν, να δανειστούν και να κάνουν συναλλαγές. Οι εκπαιδευτικοί μπορούν να αναμένουν ότι θα παρατηρήσουν στρατηγική σκέψη, διαπραγμάτευση και αναστοχαστική συζήτηση, καθώς οι μαθητές δοκιμάζουν τις αποφάσεις τους σε ένα περιβάλλον χωρίς σοβαρές συνέπειες.

#### Γιατί έχει σημασία για το Bitcoin

Το Bitcoin ανοίγει μια ευρύτερη συζήτηση για το πώς λειτουργούν τα νομισματικά συστήματα και ποιοι συμμετέχουν σε αυτά. Προσφέροντας στους μικρούς μαθητές μια απτή εμπειρία οικονομικών επιλογών, τους βοηθάμε να προσεγγίσουν αυτή τη συζήτηση με τη δυνατότητα να δρουν αυτόνομα: μπορούν να αναγνωρίζουν τα κίνητρα, να αναρωτιούνται αν οι κανόνες είναι δίκαιοι και να κατανοούν ότι τα χρηματοοικονομικά εργαλεία διαμορφώνουν τις ζωές πραγματικών ανθρώπων.
