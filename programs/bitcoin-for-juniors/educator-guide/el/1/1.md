# 1.1 Επισκόπηση

#### Πρόλογος

Αυτό το κεφάλαιο προσφέρει στους μικρούς μαθητές μια πρακτική αφετηρία για να σκεφτούν γιατί οι άνθρωποι κάνουν ανταλλαγές, γιατί τα πράγματα έχουν σημασία για διαφορετικούς ανθρώπους και πώς διαμορφώνονται οι τιμές. Οι μαθητές θα ανακαλύψουν ότι η αξία είναι προσωπική, η σπανιότητα έχει σημασία και η τιμή ενός πράγματος δεν ταυτίζεται με το τι σημαίνει αυτό για εμάς.

#### Γενικοί στόχοι

* Εξερευνήστε την ανταλλαγή, τη σπανιότητα, την αξία και την τιμή μέσα από την άμεση εμπειρία.
* Αναγνωρίστε ότι οι άνθρωποι μπορούν να αποδίδουν διαφορετική αξία στο ίδιο πράγμα.
* Εξασκηθείτε στο να εξηγείτε τις επιλογές σας, να ακούτε τους άλλους και να σταθμίζετε τι κερδίζετε και τι θυσιάζετε με κάθε επιλογή.

#### Τι να περιμένετε

Μέσα από μια δοκιμασία ανταλλαγών με σενάριο ναυαγίου, μια ζωντανή δημοπρασία κοχυλιών, δραστηριότητες ταξινόμησης και συζήτησης και μια κοινή γραμμή τιμών, οι μαθητές θα διαπραγματευτούν, θα κάνουν επιλογές, θα συγκρίνουν ιδέες και θα δουν τις τιμές να διαμορφώνονται σε πραγματικό χρόνο. Οι εκπαιδευτικοί μπορούν να προσβλέπουν σε ουσιαστικές συζητήσεις γύρω από τις επιθυμίες, τις ανάγκες, τη δικαιοσύνη και τις διαφορετικές απόψεις.

#### Γιατί έχει σημασία για το Bitcoin

Το Bitcoin καλεί τους ανθρώπους να θέσουν θεμελιώδη ερωτήματα για το χρήμα: Τι δίνει αξία σε κάτι; Γιατί έχει σημασία η σπανιότητα; Πώς συμφωνούν οι άνθρωποι να κάνουν ανταλλαγές; Η γνωριμία με αυτές τις ιδέες από μικρή ηλικία βοηθά τους μαθητές να συμμετέχουν με κριτική σκέψη στην οικονομική ζωή, να μπορούν να αμφισβητούν τις τιμές, να κατανοούν τι κερδίζουν και τι θυσιάζουν με κάθε επιλογή και να αναγνωρίζουν ότι το χρήμα είναι ένα εργαλείο που χρησιμοποιούν οι άνθρωποι για να συντονίζονται μεταξύ τους.
