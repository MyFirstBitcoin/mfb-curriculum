# 前言

我们的孩子将要继承的世界，此刻正在被塑造。货币、信息以及协作工具的演变速度，已超出大多数教育体系的跟进能力。下一代面对那个世界时，是清晰而自信，还是困惑而依赖，很大程度上取决于我们今天教给他们什么。

教育从来不只是信息的传递。它的目的是培养独立的思考者，使他们能够提出质疑、作出评估，并得出自己的结论。这种能力在今天比以往任何时候都更加重要。

My First Bitcoin的存在，正是为了构建这样的教育。我们相信，当前的货币体系已经失灵，而比特币代表着数字时代的[健全货币](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money)。我们相信，教育应当开源，并且不受经济利益的驱动。赋予学习者独立思考的能力，而不是告诉他们该怎么想，才是最重要的工作。

「少儿比特币」为面向儿童的比特币教育树立了新标准。它不是我们「比特币文凭」课程的简化版，而是一次全新的构想。通过寓教于乐、适合年龄且互动性强的学习方式，8至12岁的儿童将探索一系列核心概念，例如[价值](https://curriculum.myfirstbitcoin.org/lexicon/en/#value)、[稀缺性](https://curriculum.myfirstbitcoin.org/lexicon/en/#scarcity)、交换、公平、[隐私](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)以及责任。它不是一门技术课程，也不宣扬任何信仰。它为孩子们提供思考的基石，让他们得出自己的结论。

教育者是倍增器。本项目为教师和社区教育者提供实用工具，帮助他们开展引人入胜、适合年龄的教学。我们的目标不是培养比特币的信徒，而是培养思维更清晰的人：他们能够质疑各种体系，并参与到一个开放、去中心化的世界中。

下一代不需要别人告诉他们该如何看待货币。他们需要的是自己去弄明白的基础。「少儿比特币」正是提供了这样的基础。
