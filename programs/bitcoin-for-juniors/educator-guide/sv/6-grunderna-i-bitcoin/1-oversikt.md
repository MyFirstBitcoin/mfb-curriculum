# 6.1 Översikt

#### Förord

Det här kapitlet samlar kursens idéer – värde, knapphet, tid och energi, teknik, integritet och gemensamma regler – och kopplar dem till Bitcoin. Eleverna får möta Bitcoin som ett mänskligt svar på problem med pengar och som ett nätverk som upprätthålls av människor som samarbetar.

#### Övergripande mål

* Koppla tidigare kunskaper till Bitcoins ursprung, regler och nätverk.
* Beskriva Bitcoin med åldersanpassade ord och konkreta exempel.
* Ställa genomtänkta frågor om pengar, teknik, säkerhet och deltagande.

#### Vad som väntar

Eleverna får höra berättelsen om Satoshi och genesisblocket, skapa berättelser om ett olöst mysterium och simulera utvinning genom att hitta kortpar och bekräfta transaktioner. Lärare kan se fram emot stunder då eleverna knyter ihop sina kunskaper genom att använda välbekanta idéer och nya ord för att förklara ett komplext system med egna ord.

#### Varför det är viktigt för Bitcoin

Unga människor kommer att växa upp i en värld som präglas av digitala pengar och nätverk. Att möta Bitcoin nu innebär inte att de förväntas börja använda det; det ger dem en grund för att ställa frågor om hur ett monetärt system fungerar, vem som bestämmer dess regler, hur det skyddas och vilket ansvar det innebär att delta.
