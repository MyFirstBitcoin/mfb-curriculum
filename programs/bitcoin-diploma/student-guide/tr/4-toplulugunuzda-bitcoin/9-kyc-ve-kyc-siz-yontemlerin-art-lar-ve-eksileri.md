# 4.9 KYC ve KYC'siz Yöntemlerin Artıları ve Eksileri

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ve [KYC'siz](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) yollar farklı [ödünleşimler](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off) içerir. Hiçbir etiket, dikkatli değerlendirme ihtiyacını ortadan kaldırmaz.


<!-- card: callout -->
> **Gizlilik, yasal riskleri veya fiziksel güvenlik risklerini ortadan kaldırmaz**
>
> Ne [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ne de [KYC'siz](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) yol kendiliğinden en iyisidir. Gerçek yolu karşılaştırın, kurallar belirsiz olduğunda güncel yerel rehberliğe başvurun ve [gizlilik](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) uğruna yerel yasaları çiğnemeyin veya kendinizi fiziksel tehlikeye atmayın.


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Bir [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) gerektiren hizmet; yasal adınızı, kimlik belgenizi, adresinizi, fotoğrafınızı, fon kaynağı bilgilerinizi veya başka kayıtları talep edebilir. Bu, hizmetin yerel kurallara uymasını, bankalarla bağlantı kurmasını, daha yüksek limitler belirlemesini veya hesap kurtarmayı desteklemesini sağlayabilir.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) aynı zamanda veri riski de yaratır. Hizmet; kimlik, ödeme yöntemleri ve bitcoin [işlemleri](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) arasında kalıcı bir bağlantı saklayabilir. Bir veri ihlali, yasal talep, kurum içi kötüye kullanım veya politika değişikliği bu bilgileri ifşa edebilir ya da kısıtlayabilir.

Bir [KYC'siz](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) yol daha az kimlik bilgisi toplayabilir. Bu, finansal [gizliliği](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) artırabilir. Ancak aynı zamanda daha az düzenlenmiş karşı taraflar, daha düşük likidite, daha yüksek [fiyatlar](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), daha az destek, daha yüksek dolandırıcılık riski veya yasal kısıtlamalar da içerebilir.

Gerçek yolu karşılaştırın:


| Soru | KYC yolu | KYC'siz yol |
| --- | --- | --- |
| Hangi kimlik verileri toplanıyor? |  |  |
| Verileri kim, ne kadar süreyle saklıyor? |  |  |
| İşlem zincir üzerinde ilişkilendirilebilir mi? |  |  |
| Hangi dolandırıcılık koruması mevcut? |  |  |
| Hangi karşı taraf riski mevcut? |  |  |
| Hangi limitler ve ücretler geçerli? |  |  |
| Hangi yerel yasalar geçerli? |  |  |
| Bir anlaşmazlık durumunda ne olur? |  |  |


[Gizlilik](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy), her riskten saklı kalmak demek değildir. Kendinizle ilgili bilgileri kontrol edebilme yeteneğidir. [Gizlilik](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) uğruna yerel yasaları çiğnemeyin veya kendinizi fiziksel tehlikeye atmayın. Kurallar belirsiz olduğunda nitelikli bir kişiden güncel yerel rehberlik alın.
