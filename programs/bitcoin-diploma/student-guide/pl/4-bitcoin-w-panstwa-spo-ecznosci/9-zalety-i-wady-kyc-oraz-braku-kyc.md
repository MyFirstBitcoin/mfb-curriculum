# 4.9 Zalety i wady KYC oraz braku KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) i [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) to ścieżki, które wiążą się z różnymi [kompromisami](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Żadne z tych określeń nie zwalnia z konieczności starannej oceny.


<!-- card: callout -->
> **Prywatność nie eliminuje ryzyka prawnego ani zagrożeń dla bezpieczeństwa fizycznego**
>
> Ani [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ani [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) nie jest automatycznie najlepszym rozwiązaniem. Proszę porównać konkretną ścieżkę, korzystać z aktualnych lokalnych wytycznych, gdy przepisy są niejasne, i nie łamać lokalnego prawa ani nie narażać się na niebezpieczeństwo fizyczne w dążeniu do [prywatności](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Usługa [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) może wymagać podania imienia i nazwiska zgodnych z dokumentami, dokumentu tożsamości, adresu, zdjęcia, informacji o źródle środków lub innych danych. Może to umożliwić usługodawcy przestrzeganie lokalnych przepisów, współpracę z bankami, ustalanie wyższych limitów lub pomoc w odzyskiwaniu dostępu do konta.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) stwarza również ryzyko związane z danymi. Usługodawca może trwale przechowywać powiązanie między tożsamością, metodami płatności i bitcoinowymi [transakcjami](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Wyciek danych, żądanie organów prawnych, wewnętrzne nadużycie lub zmiana polityki mogą doprowadzić do ujawnienia tych informacji lub ograniczenia dostępu do nich.

Ścieżka [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) może wiązać się z gromadzeniem mniejszej ilości informacji o tożsamości. Może to poprawić finansową [prywatność](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Może się jednak również wiązać z mniej regulowanymi kontrahentami, niższą płynnością, wyższymi [cenami](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), ograniczonym wsparciem, większym ryzykiem oszustwa lub ograniczeniami prawnymi.

Proszę porównać konkretne ścieżki:


| Pytanie | Ścieżka KYC | Ścieżka no-KYC |
| --- | --- | --- |
| Jakie dane dotyczące tożsamości są gromadzone? |  |  |
| Kto przechowuje dane i jak długo? |  |  |
| Czy transakcję można powiązać z tożsamością na podstawie danych w łańcuchu bloków? |  |  |
| Jakie zabezpieczenia przed oszustwami są dostępne? |  |  |
| Jakie ryzyko wiąże się z kontrahentem? |  |  |
| Jakie limity i opłaty obowiązują? |  |  |
| Jakie lokalne przepisy mają zastosowanie? |  |  |
| Co się dzieje w przypadku sporu? |  |  |


[Prywatność](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) nie oznacza ukrycia się przed każdym ryzykiem. To możliwość kontrolowania informacji o sobie. Proszę nie łamać lokalnego prawa ani nie narażać się na niebezpieczeństwo fizyczne w dążeniu do [prywatności](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Gdy przepisy są niejasne, proszę zasięgnąć aktualnej porady dotyczącej lokalnych regulacji u wykwalifikowanej osoby.
