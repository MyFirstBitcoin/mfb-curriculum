# Quiz – Jak działa Bitcoin: krótki sprawdzian

## Pytanie 1

Ta sama jednostka cyfrowa służy do zapłaty dwa razy. System musi:

* [x] Odrzucić próbę podwójnego wydatkowania
* [ ] Ukryć płatność
* [ ] Podnieść jej cenę
* [ ] Usunąć opłaty

### Wyjaśnienie

Informacje cyfrowe można kopiować, więc system pieniężny musi zapobiegać dwukrotnemu wydaniu tej samej jednostki i ustalać, która transakcja jest prawidłowa. Proszę wrócić do podręcznika dla uczniów, modułu 2, „Wczesne próby stworzenia pieniądza cyfrowego i problem podwójnego wydatkowania”.

## Pytanie 2

Decentralizacja Bitcoina oznacza:

* [ ] Jedna firma zatwierdza płatności
* [x] Niezależne egzekwowanie zasad
* [ ] Górnicy dowolnie zmieniają zasady
* [ ] Jednakowy wpływ dla wszystkich

### Wyjaśnienie

Bitcoin rozdziela weryfikację i egzekwowanie zasad między niezależnych uczestników. Decentralizacja nie oznacza, że jedna firma kontroluje sieć ani że wszyscy mają jednakowy wpływ. Proszę wrócić do podręcznika dla uczniów, modułu 2, „Decentralizacja”.

## Pytanie 3

Węzeł sieci Bitcoin:

* [x] Sprawdza zgodność z zasadami sieci
* [ ] Tworzy bitcoiny
* [ ] Przechowuje bitcoiny
* [ ] Gwarantuje płatność

### Wyjaśnienie

Węzły niezależnie sprawdzają zgodność z zasadami Bitcoina i odrzucają nieprawidłowe dane. Nie tworzą bitcoinów na żądanie ani nie przechowują bitcoinów wewnątrz telefonu. Proszę wrócić do podręcznika dla uczniów, modułu 2, „Użytkownicy, węzły i górnicy”.

## Pytanie 4

Dlaczego Bitcoin jest określany jako zdrowy pieniądz?

* [ ] Cena zawsze rośnie
* [x] Publicznie znana, ograniczona podaż
* [ ] Kontroluje go jedna firma
* [ ] Płatności są prywatne

### Wyjaśnienie

Niektórzy określają Bitcoin jako zdrowy pieniądz, ponieważ zasady jego podaży są publicznie znane, a emisja jest ograniczona. Jest to uzasadniona ocena, a nie obietnica dotycząca ceny czy prywatności. Proszę wrócić do podręcznika dla uczniów, modułu 2, „Bitcoin jako zdrowy pieniądz cyfrowy”.
