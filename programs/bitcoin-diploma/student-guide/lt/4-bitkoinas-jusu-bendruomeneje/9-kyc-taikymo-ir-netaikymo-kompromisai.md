# 4.9 KYC taikymo ir netaikymo kompromisai

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ir [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) būdai pasižymi skirtingais [kompromisais](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Nė vienas iš šių pavadinimų nepanaikina būtinybės atidžiai įvertinti konkretų būdą.


<!-- card: callout -->
> **Privatumas nepanaikina teisinės rizikos ar rizikos fiziniam saugumui**
>
> Nei [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) nei [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) savaime nėra geriausias pasirinkimas. Palyginkite konkretų būdą, kai taisyklės neaiškios, vadovaukitės naujausiomis vietinėmis rekomendacijomis ir nepažeiskite vietos įstatymų bei nekelkite sau fizinio pavojaus siekdami [privatumo](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Tam tikra [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) paslauga gali reikalauti pateikti oficialų vardą ir pavardę, asmens tapatybės dokumentą, adresą, nuotrauką, informaciją apie lėšų kilmę ar kitus dokumentus. Tai gali leisti paslaugos teikėjui laikytis vietos taisyklių, bendradarbiauti su bankais, nustatyti didesnius limitus ar padėti atkurti prieigą prie paskyros.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) taip pat kelia riziką duomenų saugumui. Paslaugos teikėjas gali saugoti nuolatinį ryšį tarp asmens tapatybės, mokėjimo būdų ir bitkoinų [sandorių](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Dėl duomenų saugumo pažeidimo, teisinio reikalavimo, netinkamo naudojimo organizacijos viduje ar politikos pakeitimo ši informacija gali būti atskleista arba prieiga prie jos gali būti apribota.

Tam tikras [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) būdas gali apimti mažesnės apimties tapatybės duomenų rinkimą. Tai gali padidinti finansinį [privatumą](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Tačiau jis taip pat gali būti susijęs su mažiau reguliuojamomis sandorio šalimis, mažesniu likvidumu, didesnėmis [kainomis](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), mažesne pagalbos apimtimi, didesne sukčiavimo rizika ar teisiniais apribojimais.

Palyginkite konkretų būdą:


| Klausimas | KYC būdas | No-KYC būdas |
| --- | --- | --- |
| Kokie tapatybės duomenys renkami? |  |  |
| Kas saugo duomenis ir kiek laiko? |  |  |
| Ar sandorį blokų grandinėje galima susieti su asmens tapatybe? |  |  |
| Kokios apsaugos nuo sukčiavimo priemonės taikomos? |  |  |
| Kokia yra sandorio šalies rizika? |  |  |
| Kokie limitai ir mokesčiai taikomi? |  |  |
| Kokie vietos įstatymai taikomi? |  |  |
| Kas vyksta kilus ginčui? |  |  |


[Privatumas](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) nereiškia slaptumo, apsaugančio nuo bet kokios rizikos. Tai gebėjimas kontroliuoti informaciją apie save. Nepažeiskite vietos įstatymų ir nekelkite sau fizinio pavojaus siekdami [privatumo](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Kai taisyklės neaiškios, kreipkitės į kvalifikuotą specialistą dėl naujausių vietinių rekomendacijų.
