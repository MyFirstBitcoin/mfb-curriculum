# 4.9 KYC ਅਤੇ ਗੈਰ-KYC ਦੇ ਫ਼ਾਇਦੇ-ਨੁਕਸਾਨ

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ਅਤੇ [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ਦੇ ਰਸਤਿਆਂ ਵਿੱਚ ਵੱਖੋ-ਵੱਖਰੇ [ਲਾਭ-ਨੁਕਸਾਨ ਦੇ ਸਮਝੌਤੇ](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off) ਹੁੰਦੇ ਹਨ। ਕਿਸੇ ਵੀ ਲੇਬਲ ਨਾਲ ਧਿਆਨ ਨਾਲ ਮੁਲਾਂਕਣ ਕਰਨ ਦੀ ਲੋੜ ਖ਼ਤਮ ਨਹੀਂ ਹੁੰਦੀ।


<!-- card: callout -->
> **ਨਿੱਜਤਾ ਨਾਲ ਕਾਨੂੰਨੀ ਜਾਂ ਸਰੀਰਕ ਸੁਰੱਖਿਆ ਦੇ ਖ਼ਤਰੇ ਖ਼ਤਮ ਨਹੀਂ ਹੁੰਦੇ**
>
> ਨਾ ਤਾਂ [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ਅਤੇ ਨਾ ਹੀ [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ਆਪਣੇ ਆਪ ਵਿੱਚ ਸਭ ਤੋਂ ਵਧੀਆ ਹੈ। ਅਸਲ ਰਸਤੇ ਦੀ ਤੁਲਨਾ ਕਰੋ, ਨਿਯਮ ਅਸਪਸ਼ਟ ਹੋਣ 'ਤੇ ਮੌਜੂਦਾ ਸਥਾਨਕ ਮਾਰਗਦਰਸ਼ਨ ਲਵੋ, ਅਤੇ ਸਥਾਨਕ ਕਾਨੂੰਨ ਦੀ ਉਲੰਘਣਾ ਨਾ ਕਰੋ ਜਾਂ ਆਪਣੇ ਆਪ ਨੂੰ ਸਰੀਰਕ ਖ਼ਤਰੇ ਵਿੱਚ ਨਾ ਪਾਓ, ਭਾਵੇਂ ਤੁਹਾਡਾ ਮਕਸਦ ਹੋਵੇ [ਨਿੱਜਤਾ](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)।


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

ਇੱਕ [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ਸੇਵਾ ਕਾਨੂੰਨੀ ਨਾਮ, ਪਛਾਣ ਦਸਤਾਵੇਜ਼, ਪਤਾ, ਤਸਵੀਰ, ਧਨ ਦੇ ਸਰੋਤ ਬਾਰੇ ਜਾਣਕਾਰੀ ਜਾਂ ਹੋਰ ਰਿਕਾਰਡ ਮੰਗ ਸਕਦੀ ਹੈ। ਇਸ ਨਾਲ ਸੇਵਾ ਨੂੰ ਸਥਾਨਕ ਨਿਯਮਾਂ ਦੀ ਪਾਲਣਾ ਕਰਨ, ਬੈਂਕਾਂ ਨਾਲ ਜੁੜਨ, ਉੱਚੀਆਂ ਹੱਦਾਂ ਤੈਅ ਕਰਨ ਜਾਂ ਖਾਤੇ ਦੀ ਮੁੜ-ਬਹਾਲੀ ਵਿੱਚ ਮਦਦ ਕਰਨ ਦੀ ਸਹੂਲਤ ਮਿਲ ਸਕਦੀ ਹੈ।

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ਨਾਲ ਡਾਟਾ ਸਬੰਧੀ ਖ਼ਤਰਾ ਵੀ ਪੈਦਾ ਹੁੰਦਾ ਹੈ। ਸੇਵਾ ਪਛਾਣ, ਭੁਗਤਾਨ ਦੇ ਤਰੀਕਿਆਂ ਅਤੇ ਬਿਟਕੋਇਨ [ਲੈਣ-ਦੇਣ](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) ਵਿਚਕਾਰ ਇੱਕ ਸਥਾਈ ਸੰਬੰਧ ਸੰਭਾਲ ਕੇ ਰੱਖ ਸਕਦੀ ਹੈ। ਡਾਟਾ ਵਿੱਚ ਸੰਨ੍ਹ, ਕਾਨੂੰਨੀ ਬੇਨਤੀ, ਅੰਦਰੂਨੀ ਦੁਰਵਰਤੋਂ ਜਾਂ ਨੀਤੀ ਵਿੱਚ ਤਬਦੀਲੀ ਕਾਰਨ ਉਹ ਜਾਣਕਾਰੀ ਉਜਾਗਰ ਹੋ ਸਕਦੀ ਹੈ ਜਾਂ ਉਸ ਤੱਕ ਪਹੁੰਚ ਸੀਮਤ ਹੋ ਸਕਦੀ ਹੈ।

ਇੱਕ [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ਰਸਤਾ ਪਛਾਣ ਸਬੰਧੀ ਘੱਟ ਜਾਣਕਾਰੀ ਇਕੱਠੀ ਕਰ ਸਕਦਾ ਹੈ। ਇਸ ਨਾਲ ਵਿੱਤੀ [ਨਿੱਜਤਾ](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) ਵਿੱਚ ਸੁਧਾਰ ਹੋ ਸਕਦਾ ਹੈ। ਇਸ ਵਿੱਚ ਘੱਟ ਨਿਯਮਿਤ ਲੈਣ-ਦੇਣ ਦੀਆਂ ਦੂਜੀਆਂ ਧਿਰਾਂ, ਘੱਟ ਤਰਲਤਾ, ਵੱਧ [ਕੀਮਤਾਂ](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), ਘੱਟ ਸਹਾਇਤਾ, ਧੋਖਾਧੜੀ ਦਾ ਵਧੇਰੇ ਖ਼ਤਰਾ ਜਾਂ ਕਾਨੂੰਨੀ ਪਾਬੰਦੀਆਂ ਵੀ ਸ਼ਾਮਲ ਹੋ ਸਕਦੀਆਂ ਹਨ।

ਅਸਲ ਰਸਤੇ ਦੀ ਤੁਲਨਾ ਕਰੋ:


| ਸਵਾਲ | KYC ਰਸਤਾ | No-KYC ਰਸਤਾ |
| --- | --- | --- |
| ਪਛਾਣ ਸਬੰਧੀ ਕਿਹੜਾ ਡਾਟਾ ਇਕੱਠਾ ਕੀਤਾ ਜਾਂਦਾ ਹੈ? |  |  |
| ਡਾਟਾ ਕੌਣ ਅਤੇ ਕਿੰਨੇ ਸਮੇਂ ਲਈ ਸੰਭਾਲ ਕੇ ਰੱਖਦਾ ਹੈ? |  |  |
| ਕੀ ਲੈਣ-ਦੇਣ ਨੂੰ ਬਲਾਕਚੇਨ ਉੱਤੇ ਜੋੜਿਆ ਜਾ ਸਕਦਾ ਹੈ? |  |  |
| ਧੋਖਾਧੜੀ ਤੋਂ ਬਚਾਅ ਲਈ ਕੀ ਸੁਰੱਖਿਆ ਹੈ? |  |  |
| ਲੈਣ-ਦੇਣ ਦੀ ਦੂਜੀ ਧਿਰ ਨਾਲ ਜੁੜਿਆ ਕੀ ਖ਼ਤਰਾ ਹੈ? |  |  |
| ਕਿਹੜੀਆਂ ਹੱਦਾਂ ਅਤੇ ਫ਼ੀਸਾਂ ਲਾਗੂ ਹੁੰਦੀਆਂ ਹਨ? |  |  |
| ਕਿਹੜਾ ਸਥਾਨਕ ਕਾਨੂੰਨ ਲਾਗੂ ਹੁੰਦਾ ਹੈ? |  |  |
| ਵਿਵਾਦ ਹੋਣ 'ਤੇ ਕੀ ਹੁੰਦਾ ਹੈ? |  |  |


[ਨਿੱਜਤਾ](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) ਦਾ ਮਤਲਬ ਹਰ ਖ਼ਤਰੇ ਤੋਂ ਲੁਕੇ ਰਹਿਣਾ ਨਹੀਂ ਹੈ। ਇਹ ਆਪਣੇ ਬਾਰੇ ਜਾਣਕਾਰੀ ਨੂੰ ਕੰਟਰੋਲ ਕਰਨ ਦੀ ਸਮਰੱਥਾ ਹੈ। ਸਥਾਨਕ ਕਾਨੂੰਨ ਦੀ ਉਲੰਘਣਾ ਨਾ ਕਰੋ ਜਾਂ ਆਪਣੇ ਆਪ ਨੂੰ ਸਰੀਰਕ ਖ਼ਤਰੇ ਵਿੱਚ ਨਾ ਪਾਓ, ਭਾਵੇਂ ਤੁਹਾਡਾ ਮਕਸਦ ਹੋਵੇ [ਨਿੱਜਤਾ](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)। ਨਿਯਮ ਅਸਪਸ਼ਟ ਹੋਣ 'ਤੇ ਕਿਸੇ ਯੋਗ ਵਿਅਕਤੀ ਤੋਂ ਮੌਜੂਦਾ ਸਥਾਨਕ ਮਾਰਗਦਰਸ਼ਨ ਲਵੋ।
