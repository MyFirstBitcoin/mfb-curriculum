# 4.9 المفاضلات بين تطبيق متطلبات معرفة العميل وعدم تطبيقها

[التحقق من هوية العميل](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) و [عدم التحقق من هوية العميل](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) مساران يختلفان في [المفاضلات التي ينطويان عليها](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). ولا تُغني أيٌّ من التسميتين عن ضرورة التقييم المتأني.


<!-- card: callout -->
> **الخصوصية لا تزيل المخاطر القانونية أو المخاطر على السلامة الجسدية**
>
> لا يُعدّ [التحقق من هوية العميل](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ولا [عدم التحقق من هوية العميل](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) الخيار الأفضل تلقائيًا. قارنوا المسار الفعلي، واستعينوا بالإرشادات المحلية السارية عندما تكون القواعد غير واضحة، ولا تخالفوا القانون المحلي أو تعرّضوا أنفسكم لخطر جسدي سعيًا إلى [الخصوصية](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

خدمة [التحقق من هوية العميل](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) قد تطلب الاسم القانوني، أو وثيقة هوية، أو عنوانًا، أو صورة شخصية، أو معلومات عن مصدر الأموال، أو سجلات أخرى. وقد يتيح ذلك للخدمة الامتثال للقواعد المحلية، والتعامل مع البنوك، ووضع حدود أعلى، أو دعم استعادة الحساب.

[التحقق من هوية العميل](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ينشئ أيضًا مخاطر تتعلق بالبيانات. فقد تحتفظ الخدمة برابط دائم بين الهوية ووسائل الدفع وبيتكوين من خلال [المعاملات](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). وقد يؤدي اختراق، أو طلب قانوني، أو سوء استخدام داخلي، أو تغيير في السياسة إلى كشف تلك المعلومات أو تقييدها.

مسار [دون تحقق من هوية العميل](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) قد يجمع معلومات أقل عن الهوية. ويمكن أن يعزّز ذلك [الخصوصية المالية](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). وقد ينطوي أيضًا على أطراف مقابلة تخضع لرقابة تنظيمية أقل، وسيولة أقل، وارتفاع في [الأسعار](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)، ودعم أقل، ومخاطر احتيال أكبر، أو قيود قانونية.

قارنوا المسار الفعلي:


| السؤال | مسار التحقق من هوية العميل | مسار دون تحقق من هوية العميل |
| --- | --- | --- |
| ما بيانات الهوية التي تُجمع؟ |  |  |
| من يحتفظ بالبيانات، ولأي مدة؟ |  |  |
| هل يمكن ربط المعاملة بالهوية على سلسلة الكتل؟ |  |  |
| ما الحماية المتاحة من الاحتيال؟ |  |  |
| ما المخاطر المرتبطة بالطرف المقابل؟ |  |  |
| ما الحدود والرسوم المطبّقة؟ |  |  |
| ما القانون المحلي المطبّق؟ |  |  |
| ماذا يحدث عند نشوء نزاع؟ |  |  |


[الخصوصية](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) لا تعني السرية التي تحمي من كل المخاطر. بل هي القدرة على التحكم في المعلومات المتعلقة بكم. لا تخالفوا القانون المحلي أو تعرّضوا أنفسكم لخطر جسدي سعيًا إلى [الخصوصية](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). اطلبوا إرشادات محلية محدّثة من شخص مؤهل عندما تكون القواعد غير واضحة.
