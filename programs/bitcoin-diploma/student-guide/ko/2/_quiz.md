# Quiz – 비트코인의 작동 원리: 간단 점검

## 문제 1

하나의 디지털 단위로 두 번 지불했어요. 시스템은 어떻게 해야 할까요?

* [x] 이중 지불을 거부한다
* [ ] 지불을 숨긴다
* [ ] 가격을 올린다
* [ ] 수수료를 없앤다

### 해설

디지털 정보는 복사될 수 있으므로, 화폐 시스템은 같은 단위가 두 번 사용되는 것을 막고 어떤 거래가 유효한지 확정해야 해요. 학생 가이드 모듈 2의 “초기 디지털 화폐 시도와 이중 지불 문제”를 복습해 보세요.

## 문제 2

비트코인의 탈중앙화란 무엇을 의미할까요?

* [ ] 한 회사가 지불을 승인한다
* [x] 독립적인 규칙 집행
* [ ] 채굴자가 규칙을 마음대로 바꾼다
* [ ] 모든 사람의 동등한 영향력

### 해설

비트코인은 검증과 규칙 집행을 독립적인 참여자들에게 분산시켜요. 탈중앙화는 한 회사가 네트워크를 통제한다는 뜻도, 모든 사람이 동등한 영향력을 가진다는 뜻도 아니에요. 학생 가이드 모듈 2의 “탈중앙화”를 복습해 보세요.

## 문제 3

비트코인 노드는:

* [x] 네트워크 규칙을 확인한다
* [ ] 비트코인을 만든다
* [ ] 비트코인을 저장한다
* [ ] 지불을 보장한다

### 해설

노드는 비트코인의 규칙을 독립적으로 확인하고 유효하지 않은 데이터를 거부해요. 요청에 따라 비트코인을 만들거나 휴대폰 안에 비트코인을 저장하지는 않아요. 학생 가이드 모듈 2의 “사용자, 노드, 채굴자”를 복습해 보세요.

## 문제 4

비트코인을 왜 건전한 화폐라고 부를까요?

* [ ] 가격이 항상 오른다
* [x] 공개되고 제한된 공급량
* [ ] 한 회사가 통제한다
* [ ] 지불이 비공개다

### 해설

일부 사람들은 비트코인의 공급 규칙이 공개되어 있고 발행량이 제한되어 있기 때문에 비트코인을 건전한 화폐라고 설명해요. 이것은 근거를 갖춘 판단이지, 가격이나 프라이버시에 대한 약속이 아니에요. 학생 가이드 모듈 2의 “건전한 디지털 화폐로서의 비트코인”을 복습해 보세요.
