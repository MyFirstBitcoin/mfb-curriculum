# 4.9 KYC와 비KYC의 장단점

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) 경로와 [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) 경로는 서로 다른 [트레이드오프](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)를 가지고 있어요. 어느 쪽 이름표도 신중하게 평가해야 할 필요성을 없애 주지는 않아요.


<!-- card: callout -->
> **프라이버시가 법적 위험이나 신체적 안전 위험을 없애 주지는 않아요**
>
> 이름이 [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)든 [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)든 저절로 최선이 되는 것은 아니에요. 실제 경로를 비교하고, 규칙이 불분명할 때는 최신 현지 지침을 참고하세요. 또한 [프라이버시](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)를 추구하느라 현지 법을 어기거나 스스로를 신체적 위험에 노출하지 마세요.


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

일반적으로 [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) 서비스는 법적 이름, 신분증, 주소, 사진, 자금 출처 정보 또는 기타 기록을 요구할 수 있어요. 이를 통해 서비스는 현지 규정을 준수하고, 은행과 연결하고, 더 높은 한도를 설정하거나, 계정 복구를 지원할 수 있어요.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)는 데이터 위험도 만들어요. 서비스가 신원, 결제 수단, 비트코인 [거래](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) 사이의 영구적인 연결 정보를 저장할 수 있어요. 데이터 유출, 법적 요청, 내부 오용 또는 정책 변경으로 인해 그 정보가 노출되거나 제한될 수 있어요.

반면 [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) 경로는 신원 정보를 더 적게 수집할 수 있어요. 이는 금융 [프라이버시](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)를 향상시킬 수 있어요. 하지만 규제가 덜한 거래 상대방, 낮은 유동성, 더 높은 [가격](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), 부족한 지원, 더 큰 사기 위험 또는 법적 제한이 따를 수도 있어요.

실제 경로를 비교해 보세요:


| 질문 | KYC 경로 | No-KYC 경로 |
| --- | --- | --- |
| 어떤 신원 데이터를 수집하나요? |  |  |
| 누가 데이터를 얼마나 오래 보관하나요? |  |  |
| 거래가 온체인에서 연결될 수 있나요? |  |  |
| 어떤 사기 방지 장치가 있나요? |  |  |
| 어떤 거래 상대방 위험이 있나요? |  |  |
| 어떤 한도와 수수료가 적용되나요? |  |  |
| 어떤 현지 법이 적용되나요? |  |  |
| 분쟁이 생기면 어떻게 되나요? |  |  |


[프라이버시](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)는 모든 위험으로부터 숨는 비밀 유지가 아니에요. 자신에 관한 정보를 스스로 통제할 수 있는 능력이에요. [프라이버시](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)를 추구하느라 현지 법을 어기거나 스스로를 신체적 위험에 노출하지 마세요. 규칙이 불분명할 때는 자격을 갖춘 사람에게 최신 현지 지침을 구하세요.
