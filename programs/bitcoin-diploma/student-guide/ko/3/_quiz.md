# Quiz – 비트코인 안전하게 사용하기: 간단 점검

## 문제 1

비트코인 지갑은:

* [ ] bitcoin을 보관해요
* [x] 키를 관리하고 서명해요
* [ ] 비밀 정보 보호를 해제해요
* [ ] 거래를 되돌려요

### 해설

비트코인은 공유 원장에 기록되고, 지갑은 비트코인에 접근하고 사용하는 데 필요한 정보를 관리해요. 학생 가이드 3단원의 “지갑”을 복습해 보세요.

## 문제 2

bitcoin을 받으려면 공유할 것:

* [ ] 시드 문구
* [ ] 개인 키
* [x] 수신 주소
* [ ] 비밀번호

### 해설

수신 주소는 결제를 받기 위해 공유해도 돼요. 시드 문구, 개인 키, 비밀번호는 반드시 비밀로 유지해야 해요. 학생 가이드 3단원의 “주소”와 “키”를 복습해 보세요.

## 문제 3

시드를 온라인에 입력했어요. 가장 안전한 다음 단계는?

* [ ] 기다린다
* [ ] 고객 지원에 보낸다
* [x] 새 시드를 만든 후 자금을 옮긴다
* [ ] 시드를 재사용한다

### 해설

온라인에 입력한 시드 문구는 유출된 것으로 간주하세요. 새 시드로 새 지갑을 만든 다음, 받는 곳을 확인한 후에만 자금을 옮기세요. 학생 가이드 3단원의 “시드 문구”를 복습해 보세요.

## 문제 4

수탁형 사용과 자기 수탁형 사용의 주요 차이점은 무엇인가요?

* [x] 누가 키를 통제하는지
* [ ] 결제 취소 가능 여부
* [ ] 공급 한도
* [ ] 거래 수수료

### 해설

수탁형 사용과 자기 수탁형 사용은 누가 키를 통제하고 그에 따른 책임을 지는지에서 차이가 나요. 어느 쪽도 안전이나 취소 가능성을 보장하지 않아요. 학생 가이드 3단원의 “수탁형 및 비수탁형 사용”을 복습해 보세요.
