# 4.9 Compromis entre KYC et absence de KYC

[Les parcours KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) et [sans KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) impliquent différents [compromis](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Aucune de ces appellations ne dispense d’une évaluation rigoureuse.


<!-- card: callout -->
> **La protection de la vie privée n’élimine pas les risques juridiques ou les risques pour la sécurité physique**
>
> Ni le parcours [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ni le parcours [sans KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) n’est automatiquement préférable. Comparez le parcours réel, consultez des recommandations locales à jour lorsque les règles manquent de clarté, et n’enfreignez pas la législation locale ni ne vous exposez à un danger physique pour protéger votre [vie privée](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Un service [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) peut demander un nom légal, une pièce d’identité, une adresse, une photographie, des informations sur l’origine des fonds ou d’autres documents. Cela peut lui permettre de respecter les règles locales, de se connecter aux banques, de fixer des plafonds plus élevés ou de faciliter la récupération d’un compte.

[Le KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) crée aussi des risques liés aux données. Le service peut conserver un lien permanent entre l’identité, les moyens de paiement et les [transactions en bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Une fuite de données, une demande des autorités, une utilisation abusive en interne ou un changement de politique peut exposer ces informations ou en restreindre l’accès.

Un parcours [sans KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) peut recueillir moins d’informations d’identité. Cela peut améliorer la protection de votre [vie privée](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) financière. Il peut aussi impliquer des contreparties moins réglementées, une liquidité plus faible, des [prix](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) plus élevés, une assistance réduite, un risque de fraude accru ou des restrictions légales.

Comparez le parcours réel :


| Question | Parcours KYC | Parcours sans KYC |
| --- | --- | --- |
| Quelles données d’identité sont recueillies ? |  |  |
| Qui conserve les données et pendant combien de temps ? |  |  |
| La transaction peut-elle être reliée à une identité sur la blockchain ? |  |  |
| Quelle protection contre la fraude est prévue ? |  |  |
| Quel est le risque de contrepartie ? |  |  |
| Quels plafonds et frais s’appliquent ? |  |  |
| Quelle législation locale s’applique ? |  |  |
| Que se passe-t-il en cas de litige ? |  |  |


[La protection de la vie privée](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) ne signifie pas être à l’abri de tous les risques grâce au secret. Elle consiste à pouvoir maîtriser les informations vous concernant. N’enfreignez pas la législation locale et ne vous exposez pas à un danger physique pour protéger votre [vie privée](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Lorsque les règles manquent de clarté, demandez à une personne qualifiée des conseils à jour adaptés au contexte local.
