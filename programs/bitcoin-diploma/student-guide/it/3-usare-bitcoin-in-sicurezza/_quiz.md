# Quiz – Usare Bitcoin in sicurezza: verifica rapida

## Domanda 1

Un wallet Bitcoin:

* [ ] Conserva i bitcoin
* [x] Gestisce le chiavi e firma
* [ ] Elimina la protezione dei segreti
* [ ] Annulla le transazioni

### Spiegazione

I bitcoin sono registrati sul registro condiviso; un wallet gestisce le informazioni necessarie per accedervi e utilizzarli. Riveda la Guida dello studente, Modulo 3, «Wallet».

## Domanda 2

Cosa condividere per ricevere bitcoin:

* [ ] Seed phrase
* [ ] Chiave privata
* [x] Indirizzo di ricezione
* [ ] Password

### Spiegazione

Un indirizzo di ricezione può essere condiviso per ricevere un pagamento. Seed phrase, chiavi private e password devono restare segrete. Riveda la Guida dello studente, Modulo 3, «Indirizzi» e «Chiavi».

## Domanda 3

Seed phrase inserita online. Qual è il passo successivo più sicuro?

* [ ] Aspettare
* [ ] Inviarla all'assistenza
* [x] Nuova seed phrase, poi trasferire i fondi
* [ ] Riutilizzare la seed phrase

### Spiegazione

Consideri compromessa una seed phrase inserita online. Crei un nuovo wallet con una nuova seed phrase, quindi trasferisca i fondi solo dopo aver verificato la destinazione. Riveda la Guida dello studente, Modulo 3, «Seed phrase».

## Domanda 4

Qual è la differenza principale tra l'uso custodial e l'uso in autocustodia?

* [x] Chi controlla le chiavi
* [ ] Reversibilità dei pagamenti
* [ ] Limite di offerta
* [ ] Commissioni di transazione

### Spiegazione

L'uso custodial e quello in autocustodia differiscono per chi controlla le chiavi e si assume la relativa responsabilità. Nessuno dei due garantisce sicurezza o reversibilità. Riveda la Guida dello studente, Modulo 3, «Uso custodial e non custodial».
