# 4.9 Compromessi tra KYC e no-KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) e [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) sono percorsi che comportano [compromessi](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off) diversi. Nessuna delle due etichette elimina la necessità di una valutazione attenta.


<!-- card: callout -->
> **La privacy non elimina i rischi legali o per la sicurezza fisica**
>
> Né il [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) né il [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) è automaticamente la scelta migliore. Confronti il percorso concreto, segua le indicazioni locali aggiornate quando le regole non sono chiare e non violi la legge locale né si esponga a pericoli fisici per ottenere [privacy](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Un servizio [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) può richiedere il nome legale, un documento d'identità, l'indirizzo, una fotografia, informazioni sull'origine dei fondi o altra documentazione. Ciò può consentire al servizio di rispettare le norme locali, collegarsi alle banche, fissare limiti più elevati o supportare il recupero dell'account.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) comporta anche rischi per i dati. Il servizio può conservare un collegamento permanente tra identità, metodi di pagamento e [transazioni](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) in bitcoin. Una violazione dei dati, una richiesta legale, un uso improprio interno o un cambiamento delle politiche possono esporre o limitare tali informazioni.

Un percorso [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) può raccogliere meno informazioni sull'identità. Questo può migliorare la [privacy](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) finanziaria. Può però comportare anche controparti meno regolamentate, minore liquidità, [prezzi](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) più alti, assistenza ridotta, maggiore rischio di frode o restrizioni legali.

Confronti il percorso reale:


| Domanda | Percorso KYC | Percorso no-KYC |
| --- | --- | --- |
| Quali dati identificativi vengono raccolti? |  |  |
| Chi conserva i dati e per quanto tempo? |  |  |
| La transazione può essere collegata on-chain? |  |  |
| Quale protezione contro le frodi esiste? |  |  |
| Quale rischio di controparte esiste? |  |  |
| Quali limiti e commissioni si applicano? |  |  |
| Quale legge locale si applica? |  |  |
| Che cosa succede in caso di controversia? |  |  |


[La privacy](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) non è segretezza rispetto a ogni rischio. È la capacità di controllare le informazioni che La riguardano. Non violi la legge locale né si esponga a pericoli fisici per ottenere [privacy](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Quando le regole non sono chiare, chieda indicazioni locali aggiornate a una persona qualificata.
