# 4.9 Компромиси при използване и неизползване на KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) и [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) подходите предполагат различни [компромиси](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Нито едно от тези обозначения не премахва необходимостта от внимателна оценка.


<!-- card: callout -->
> **Поверителността не премахва правните рискове или рисковете за физическата безопасност**
>
> Нито [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc), нито [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) е автоматично най-добрият избор. Сравнете конкретния подход, използвайте актуални местни насоки, когато правилата са неясни, и не нарушавайте местното законодателство и не се излагайте на физическа опасност в стремежа си към [поверителност](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Дадена [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) услуга може да изисква име по документ за самоличност, документ за самоличност, адрес, снимка, информация за произхода на средствата или други документи. Това може да позволи на услугата да спазва местните правила, да се свързва с банки, да определя по-високи лимити или да подпомага възстановяването на достъпа до акаунта.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) създава и риск за данните. Услугата може да съхранява постоянна връзка между самоличността, методите на плащане и биткойн [трансакциите](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Пробив в сигурността, искане по законов ред, вътрешна злоупотреба или промяна в политиката може да доведе до разкриване на тази информация или до ограничаване на достъпа до нея.

Даден [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) подход може да събира по-малко информация за самоличността. Това може да подобри финансовата [поверителност](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Той може също да включва по-слабо регулирани контрагенти, по-ниска ликвидност, по-високи [цени](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), по-ограничена поддръжка, по-голям риск от измами или законови ограничения.

Сравнете конкретния подход:


| Въпрос | KYC подход | No-KYC подход |
| --- | --- | --- |
| Какви данни за самоличността се събират? |  |  |
| Кой съхранява данните и за колко време? |  |  |
| Може ли трансакцията да бъде свързана с други данни в блокчейна? |  |  |
| Каква защита от измами съществува? |  |  |
| Какъв риск, свързан с контрагента, съществува? |  |  |
| Какви лимити и такси се прилагат? |  |  |
| Кое местно законодателство се прилага? |  |  |
| Какво се случва при спор? |  |  |


[Поверителността](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) не означава скритост, която предпазва от всеки риск. Тя е способността да контролирате информацията за себе си. Не нарушавайте местното законодателство и не се излагайте на физическа опасност в стремежа си към [поверителност](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Потърсете актуални местни насоки от квалифицирано лице, когато правилата са неясни.
