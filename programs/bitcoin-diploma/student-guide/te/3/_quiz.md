# Quiz – బిట్‌కాయిన్‌ను సురక్షితంగా ఉపయోగించడం: సంక్షిప్త పరీక్ష

## ప్రశ్న 1

బిట్‌కాయిన్ వాలెట్:

* [ ] బిట్‌కాయిన్‌ను నిల్వ చేస్తుంది
* [x] కీలను నిర్వహిస్తుంది, సంతకాలు చేస్తుంది
* [ ] రహస్య రక్షణను తొలగిస్తుంది
* [ ] లావాదేవీలను వెనక్కి మళ్లిస్తుంది

### వివరణ

బిట్‌కాయిన్ ఉమ్మడి లెడ్జర్‌లో నమోదవుతుంది; దాన్ని యాక్సెస్ చేయడానికి, ఉపయోగించడానికి అవసరమైన సమాచారాన్ని వాలెట్ నిర్వహిస్తుంది. విద్యార్థి మార్గదర్శిని, మాడ్యూల్ 3, “వాలెట్లు” విభాగాన్ని సమీక్షించండి.

## ప్రశ్న 2

బిట్‌కాయిన్‌ను స్వీకరించడానికి పంచుకోవాల్సినది:

* [ ] సీడ్ పదబంధం
* [ ] ప్రైవేట్ కీ
* [x] స్వీకరణ చిరునామా
* [ ] పాస్‌వర్డ్

### వివరణ

చెల్లింపును స్వీకరించడానికి స్వీకరణ చిరునామాను పంచుకోవచ్చు. సీడ్ పదబంధాలు, ప్రైవేట్ కీలు, పాస్‌వర్డ్‌లు రహస్యంగా ఉండాలి. విద్యార్థి మార్గదర్శిని, మాడ్యూల్ 3, “చిరునామాలు”, “కీలు” విభాగాలను సమీక్షించండి.

## ప్రశ్న 3

సీడ్‌ను ఆన్‌లైన్‌లో నమోదు చేశారు. తర్వాత తీసుకోవాల్సిన అత్యంత సురక్షితమైన చర్య ఏమిటి?

* [ ] వేచి ఉండండి
* [ ] దాన్ని సహాయ బృందానికి పంపండి
* [x] కొత్త సీడ్, ఆపై నిధులను తరలించండి
* [ ] అదే సీడ్‌ను మళ్లీ ఉపయోగించండి

### వివరణ

ఆన్‌లైన్‌లో నమోదు చేసిన సీడ్ పదబంధం గోప్యత కోల్పోయినట్లుగా పరిగణించండి. కొత్త సీడ్‌తో కొత్త వాలెట్‌ను సృష్టించండి, ఆపై గమ్యస్థానాన్ని ధృవీకరించిన తర్వాత మాత్రమే నిధులను తరలించండి. విద్యార్థి మార్గదర్శిని, మాడ్యూల్ 3, “సీడ్ పదబంధాలు” విభాగాన్ని సమీక్షించండి.

## ప్రశ్న 4

కస్టడీ విధానాల మధ్య తేడా ఏమిటి?

* [x] కీలను ఎవరు నియంత్రిస్తారు
* [ ] చెల్లింపును వెనక్కి మళ్లించగలగడం
* [ ] సరఫరా పరిమితి
* [ ] బాధ్యత

### వివరణ

కస్టోడియల్, స్వీయ కస్టడీ వినియోగ విధానాల మధ్య తేడా కీలను ఎవరు నియంత్రిస్తారు, సంబంధిత బాధ్యతను ఎవరు వహిస్తారు అనేదానిలో ఉంటుంది. ఏ విధానమూ భద్రతకు గానీ, లావాదేవీలను వెనక్కి మళ్లించగలగడానికి గానీ హామీ ఇవ్వదు. విద్యార్థి మార్గదర్శిని, మాడ్యూల్ 3, “కస్టోడియల్, నాన్-కస్టోడియల్ వినియోగం” విభాగాన్ని సమీక్షించండి.
