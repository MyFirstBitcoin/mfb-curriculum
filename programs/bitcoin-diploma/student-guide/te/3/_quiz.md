# Quiz – బిట్‌కాయిన్‌ను సురక్షితంగా ఉపయోగించడం: సంక్షిప్త పరీక్ష

## ప్రశ్న 1

బిట్‌కాయిన్ వాలెట్:

* [ ] బిట్‌కాయిన్‌ను నిల్వ చేస్తుంది
* [x] కీలను నిర్వహిస్తుంది, సంతకాలు చేస్తుంది
* [ ] రహస్య రక్షణను తొలగిస్తుంది
* [ ] లావాదేవీలను వెనక్కి తిప్పుతుంది

### వివరణ

బిట్‌కాయిన్ ఉమ్మడి లెడ్జర్‌లో నమోదవుతుంది; దాన్ని పొందడానికి, ఉపయోగించడానికి అవసరమైన సమాచారాన్ని వాలెట్ నిర్వహిస్తుంది. విద్యార్థి మార్గదర్శినిలోని మాడ్యూల్ 3, “వాలెట్లు” విభాగాన్ని సమీక్షించండి.

## ప్రశ్న 2

బిట్‌కాయిన్‌ను స్వీకరించడానికి పంచుకోవాల్సినది:

* [ ] సీడ్ పదబంధం
* [ ] ప్రైవేట్ కీ
* [x] స్వీకరణ చిరునామా
* [ ] పాస్‌వర్డ్

### వివరణ

చెల్లింపును స్వీకరించడానికి స్వీకరణ చిరునామాను పంచుకోవచ్చు. సీడ్ పదబంధాలు, ప్రైవేట్ కీలు, పాస్‌వర్డ్‌లను రహస్యంగా ఉంచాలి. విద్యార్థి మార్గదర్శినిలోని మాడ్యూల్ 3, “చిరునామాలు”, “కీలు” విభాగాలను సమీక్షించండి.

## ప్రశ్న 3

సీడ్‌ను ఆన్‌లైన్‌లో నమోదు చేశారు. తర్వాత తీసుకోవాల్సిన అత్యంత సురక్షితమైన చర్య ఏమిటి?

* [ ] వేచి ఉండండి
* [ ] దాన్ని సహాయ సిబ్బందికి పంపండి
* [x] కొత్త సీడ్‌ను సృష్టించి, ఆపై నిధులను బదిలీ చేయండి
* [ ] అదే సీడ్‌ను మళ్లీ ఉపయోగించండి

### వివరణ

ఆన్‌లైన్‌లో నమోదు చేసిన సీడ్ పదబంధం రహస్యంగా లేదని భావించండి. కొత్త సీడ్‌తో కొత్త వాలెట్‌ను సృష్టించండి, ఆపై గమ్యస్థానాన్ని ధృవీకరించిన తర్వాత మాత్రమే నిధులను బదిలీ చేయండి. విద్యార్థి మార్గదర్శినిలోని మాడ్యూల్ 3, “సీడ్ పదబంధాలు” విభాగాన్ని సమీక్షించండి.

## ప్రశ్న 4

ఇతరుల సంరక్షణలో ఉపయోగించడానికి, స్వీయ సంరక్షణలో ఉపయోగించడానికి మధ్య ప్రధాన తేడా ఏమిటి?

* [x] కీలపై నియంత్రణ ఎవరిది
* [ ] చెల్లింపును వెనక్కి తిప్పగలగడం
* [ ] సరఫరా పరిమితి
* [ ] లావాదేవీ రుసుములు

### వివరణ

కీలపై నియంత్రణ ఎవరిది, సంబంధిత బాధ్యత ఎవరు వహిస్తారు అనే అంశాల్లో ఇతరుల సంరక్షణలో ఉపయోగించడానికి, స్వీయ సంరక్షణలో ఉపయోగించడానికి మధ్య తేడా ఉంటుంది. ఈ రెండింటిలో ఏదీ భద్రతకు లేదా లావాదేవీలను వెనక్కి తిప్పగలగడానికి హామీ ఇవ్వదు. విద్యార్థి మార్గదర్శినిలోని మాడ్యూల్ 3, “ఇతరుల సంరక్షణలో, ఇతరుల సంరక్షణ లేకుండా ఉపయోగించడం” విభాగాన్ని సమీక్షించండి.
