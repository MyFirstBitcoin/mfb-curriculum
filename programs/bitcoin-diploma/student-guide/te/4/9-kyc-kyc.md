# 4.9 KYC మరియు KYC-రహిత విధానాల లాభనష్టాలు

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) మరియు [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) మార్గాల్లో వేర్వేరుగా ఉండేవి [లాభనష్టాల మధ్య రాజీలు](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). ఏ పేరుతో ఉన్నా జాగ్రత్తగా మూల్యాంకనం చేయాల్సిన అవసరం తొలగిపోదు.


<!-- card: callout -->
> **గోప్యత చట్టపరమైన లేదా శారీరక భద్రతకు సంబంధించిన ప్రమాదాలను తొలగించదు**
>
> అటు [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) గానీ ఇటు [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) గానీ స్వతహాగా ఉత్తమమైనది కాదు. వాస్తవ మార్గాన్ని పోల్చి చూడండి, నియమాలు అస్పష్టంగా ఉన్నప్పుడు ప్రస్తుత స్థానిక మార్గదర్శకాలను అనుసరించండి, స్థానిక చట్టాలను ఉల్లంఘించకండి లేదా మిమ్మల్ని మీరు శారీరక ప్రమాదంలోకి నెట్టుకోకండి—మీరు సాధించాలనుకుంటున్నది [గోప్యత](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

ఒక [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) సేవ చట్టబద్ధమైన పేరు, గుర్తింపు పత్రం, చిరునామా, ఫొటో, నిధుల మూలానికి సంబంధించిన సమాచారం లేదా ఇతర రికార్డులను కోరవచ్చు. దీనివల్ల ఆ సేవ స్థానిక నియమాలను పాటించడం, బ్యాంకులతో అనుసంధానం కావడం, అధిక పరిమితులను నిర్ణయించడం లేదా ఖాతా పునరుద్ధరణకు సహాయపడడం సాధ్యమవవచ్చు.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) వల్ల డేటాకు సంబంధించిన ప్రమాదం కూడా ఏర్పడుతుంది. ఈ సేవ శాశ్వత సంబంధాన్ని నిల్వ చేయవచ్చు: గుర్తింపు, చెల్లింపు పద్ధతులు, బిట్‌కాయిన్ [లావాదేవీల మధ్య](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). డేటా భద్రతా ఉల్లంఘన, చట్టపరమైన అభ్యర్థన, అంతర్గత దుర్వినియోగం లేదా విధానంలో మార్పు వల్ల ఆ సమాచారం బహిర్గతం కావచ్చు లేదా దాని వినియోగంపై పరిమితులు ఏర్పడవచ్చు.

ఒక [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) మార్గం తక్కువ గుర్తింపు సమాచారాన్ని సేకరించవచ్చు. దీనివల్ల మెరుగుపడగల అంశం ఆర్థిక [గోప్యత](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). ఇందులో తక్కువ నియంత్రణకు లోబడే లావాదేవీ అవతలి పక్షాలు, తక్కువ ద్రవ్యత, అధిక [ధరలు](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), తగ్గిన సహాయం, ఎక్కువ మోసపు ప్రమాదం లేదా చట్టపరమైన ఆంక్షలు కూడా ఉండవచ్చు.

వాస్తవ మార్గాన్ని పోల్చి చూడండి:


| ప్రశ్న | KYC మార్గం | No-KYC మార్గం |
| --- | --- | --- |
| ఏ గుర్తింపు డేటాను సేకరిస్తారు? |  |  |
| డేటాను ఎవరు, ఎంతకాలం నిల్వ చేస్తారు? |  |  |
| బ్లాక్‌చెయిన్‌పై లావాదేవీని అనుసంధానించగలరా? |  |  |
| మోసం నుంచి ఎలాంటి రక్షణ ఉంది? |  |  |
| లావాదేవీ అవతలి పక్షానికి సంబంధించి ఎలాంటి ప్రమాదం ఉంది? |  |  |
| ఏ పరిమితులు, రుసుములు వర్తిస్తాయి? |  |  |
| ఏ స్థానిక చట్టం వర్తిస్తుంది? |  |  |
| వివాదం తలెత్తినప్పుడు ఏమి జరుగుతుంది? |  |  |


[గోప్యత](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) అంటే ప్రతి ప్రమాదం నుంచి దాచిపెట్టుకోవడం కాదు. అది మీ గురించిన సమాచారాన్ని నియంత్రించగల సామర్థ్యం. స్థానిక చట్టాలను ఉల్లంఘించకండి లేదా మిమ్మల్ని మీరు శారీరక ప్రమాదంలోకి నెట్టుకోకండి—మీరు సాధించాలనుకుంటున్నది [గోప్యత](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). నియమాలు అస్పష్టంగా ఉన్నప్పుడు అర్హత కలిగిన వ్యక్తి నుంచి ప్రస్తుత స్థానిక మార్గదర్శకాలను పొందండి.
