# 4.9 Výhody a nevýhody KYC a přístupu bez KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) a [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) postupy přinášejí různé [kompromisy](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Ani jedno označení neodstraňuje potřebu pečlivého posouzení.


<!-- card: callout -->
> **Soukromí neodstraňuje právní rizika ani rizika pro fyzickou bezpečnost**
>
> Ani [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc), ani [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) není automaticky nejlepší volbou. Porovnejte konkrétní postup, při nejasných pravidlech se řiďte aktuálními místními doporučeními a ve snaze o ochranu [soukromí](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) neporušujte místní zákony ani se nevystavujte fyzickému nebezpečí.


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Služba s [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) může požadovat jméno podle úředních dokladů, doklad totožnosti, adresu, fotografii, informace o původu finančních prostředků nebo jiné záznamy. Díky tomu může služba splňovat místní předpisy, spolupracovat s bankami, nastavovat vyšší limity nebo umožňovat obnovení přístupu k účtu.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) také vytváří rizika spojená s daty. Služba může uchovávat trvalé propojení mezi totožností, platebními metodami a bitcoinovými [transakcemi](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Únik dat, právně podložený požadavek, interní zneužití nebo změna zásad mohou vést ke zveřejnění těchto informací nebo k omezení přístupu k nim.

Postup [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) může shromažďovat méně údajů o totožnosti. To může zlepšit finanční [soukromí](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Může však také zahrnovat méně regulované protistrany, nižší likviditu, vyšší [ceny](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), omezenější podporu, větší riziko podvodu nebo právní omezení.

Porovnejte konkrétní postup:


| Otázka | Postup KYC | Postup no-KYC |
| --- | --- | --- |
| Jaké údaje o totožnosti se shromažďují? |  |  |
| Kdo údaje uchovává a jak dlouho? |  |  |
| Lze transakci propojit s dalšími údaji v blockchainu? |  |  |
| Jaká ochrana proti podvodům je k dispozici? |  |  |
| Jaké riziko protistrany existuje? |  |  |
| Jaké limity a poplatky platí? |  |  |
| Jaké místní právní předpisy se uplatňují? |  |  |
| Co se děje v případě sporu? |  |  |


[Soukromí](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) neznamená utajení, které vás ochrání před každým rizikem. Je to schopnost mít kontrolu nad informacemi o sobě. Ve snaze o ochranu [soukromí](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) neporušujte místní zákony ani se nevystavujte fyzickému nebezpečí. Pokud jsou pravidla nejasná, vyžádejte si aktuální místní doporučení od kvalifikované osoby.
