# Quiz – Using Bitcoin Safely: quick check

## Question 1

A Bitcoin wallet:

* [ ] Stores bitcoin
* [x] Manages keys and signs
* [ ] Removes secret protection
* [ ] Reverses transactions

### Explanation

Bitcoin is recorded on the shared ledger; a wallet manages the information used to access and use it. Review Student Guide, Module 3, “Wallets.”

## Question 2

Share to receive bitcoin:

* [ ] Seed phrase
* [ ] Private key
* [x] Receiving address
* [ ] Password

### Explanation

A receiving address can be shared for payment. Seed phrases, private keys, and passwords must remain secret. Review Student Guide, Module 3, “Addresses” and “Keys.”

## Question 3

Seed entered online. Safest next step?

* [ ] Wait
* [ ] Send it to support
* [x] New seed, then move funds
* [ ] Reuse the seed

### Explanation

Treat a seed phrase entered online as compromised. Create a new wallet with a new seed, then move funds only after verifying the destination. Review Student Guide, Module 3, “Seed phrases.”

## Question 4

Custody difference?

* [x] Who controls keys
* [ ] Payment reversibility
* [ ] Supply limit
* [ ] Responsibility

### Explanation

Custodial and self-custodial use differ in who controls the keys and carries the related responsibility. Neither guarantees safety or reversibility. Review Student Guide, Module 3, “Custodial and non-custodial use.”
