# Quiz – How Bitcoin Works: quick check

## Question 1

One digital unit pays twice. The system must:

* [x] Reject the double spend
* [ ] Hide the payment
* [ ] Raise its price
* [ ] Remove fees

### Explanation

Digital information can be copied, so a money system must prevent the same unit from being spent twice and establish which transaction is valid. Review Student Guide, Module 2, “Early digital-money attempts and the double-spend problem.”

## Question 2

Bitcoin decentralization means:

* [ ] One company approves payments
* [x] Independent rule enforcement
* [ ] Miners change rules freely
* [ ] Equal influence for everyone

### Explanation

Bitcoin distributes verification and rule enforcement across independent participants. Decentralization does not mean one company controls the network or that everyone has equal influence. Review Student Guide, Module 2, “Decentralization.”

## Question 3

A Bitcoin node:

* [x] Checks network rules
* [ ] Creates bitcoin
* [ ] Stores bitcoin
* [ ] Guarantees payment

### Explanation

Nodes independently check Bitcoin’s rules and reject invalid data. They do not create bitcoin on request or store bitcoin inside a phone. Review Student Guide, Module 2, “Users, nodes, and miners.”

## Question 4

Why call Bitcoin sound money?

* [ ] Price always rises
* [x] Public, limited supply
* [ ] One company controls it
* [ ] Payments are private

### Explanation

Some people describe Bitcoin as sound money because its supply rules are public and its issuance is limited. This is a reasoned judgment, not a promise about price or privacy. Review Student Guide, Module 2, “Bitcoin as sound digital money.”
