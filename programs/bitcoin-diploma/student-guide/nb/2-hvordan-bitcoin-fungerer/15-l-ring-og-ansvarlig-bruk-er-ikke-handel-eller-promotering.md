# 2.15 Læring og ansvarlig bruk er ikke handel eller promotering

Å lære hvordan Bitcoin fungerer, er noe annet enn å forsøke å tjene på kortsiktige [prismessige](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) endringer, overtale andre til å kjøpe et token eller behandle spekulasjon som opplæring. Handel og spekulasjon kan innebære raske beslutninger, tap, plattformrisiko og press om å handle uten en klar begrunnelse. Markedsføring av tokener kan skape interessekonflikter og belønne overtalelse fremfor tydelige forklaringer.

Formålet med Bitcoin-diplomet er å hjelpe Dem med å forklare Bitcoin, stille bedre spørsmål og ta tryggere beslutninger. Det gir ikke investeringsråd og forteller Dem heller ikke hva De bør kjøpe, selge eller beholde.
