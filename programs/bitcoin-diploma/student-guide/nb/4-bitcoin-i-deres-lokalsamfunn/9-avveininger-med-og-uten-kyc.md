# 4.9 Avveininger med og uten KYC

[KYC-baserte](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) og [KYC-frie](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) fremgangsmåter innebærer ulike [avveininger](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Ingen av betegnelsene fjerner behovet for en grundig vurdering.


<!-- card: callout -->
> **Personvern fjerner ikke juridisk risiko eller risiko for fysisk sikkerhet**
>
> Verken [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) eller [fravær av KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) er automatisk best. Sammenlign den faktiske fremgangsmåten, søk oppdatert lokal veiledning når reglene er uklare, og ikke bryt lokal lovgivning eller utsett Dem for fysisk fare i jakten på [personvern](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

En [KYC-basert](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) tjeneste kan be om juridisk navn, identitetsdokument, adresse, fotografi, opplysninger om midlenes opprinnelse eller annen dokumentasjon. Dette kan gjøre det mulig for tjenesten å overholde lokale regler, knytte seg til banker, fastsette høyere grenser eller tilby gjenoppretting av kontoer.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) medfører også risiko knyttet til data. Tjenesten kan lagre en permanent kobling mellom identitet, betalingsmåter og bitcoinbaserte [transaksjoner](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Et datainnbrudd, et rettslig krav, internt misbruk eller en endring i retningslinjene kan gjøre disse opplysningene tilgjengelige for andre eller begrense tilgangen til dem.

En [KYC-fri](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) fremgangsmåte kan innebære innsamling av færre identitetsopplysninger. Dette kan styrke det økonomiske [personvernet](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Det kan også innebære mindre regulerte motparter, lavere likviditet, høyere [priser](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), mindre brukerstøtte, større svindelrisiko eller juridiske begrensninger.

Sammenlign den faktiske fremgangsmåten:


| Spørsmål | Fremgangsmåte med KYC | Fremgangsmåte uten KYC |
| --- | --- | --- |
| Hvilke identitetsopplysninger samles inn? |  |  |
| Hvem lagrer opplysningene, og hvor lenge? |  |  |
| Kan transaksjonen knyttes til Dem via blokkjeden? |  |  |
| Hvilken beskyttelse mot svindel finnes? |  |  |
| Hvilken motpartsrisiko finnes? |  |  |
| Hvilke grenser og gebyrer gjelder? |  |  |
| Hvilken lokal lovgivning gjelder? |  |  |
| Hva skjer ved en tvist? |  |  |


[Personvern](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) betyr ikke hemmelighold som beskytter mot enhver risiko. Det er muligheten til å ha kontroll over opplysninger om Dem selv. Ikke bryt lokal lovgivning eller utsett Dem for fysisk fare i jakten på [personvern](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Søk oppdatert lokal veiledning fra en kvalifisert person når reglene er uklare.
