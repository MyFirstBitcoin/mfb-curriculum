# Quiz – बिटकॉइनचा सुरक्षित वापर: झटपट चाचणी

## प्रश्न 1

बिटकॉइन वॉलेट:

* [ ] बिटकॉइन साठवते
* [x] कळांचे व्यवस्थापन करते आणि स्वाक्षरी करते
* [ ] गोपनीयतेचे संरक्षण काढून टाकते
* [ ] व्यवहार उलटवते

### स्पष्टीकरण

बिटकॉइनची नोंद सामायिक खातेवहीत असते; वॉलेट त्यात प्रवेश मिळवण्यासाठी आणि ते वापरण्यासाठी आवश्यक माहितीचे व्यवस्थापन करते. विद्यार्थी मार्गदर्शिकेतील मॉड्यूल 3, “वॉलेट्स” पुन्हा पाहा.

## प्रश्न 2

बिटकॉइन मिळवण्यासाठी हे शेअर करा:

* [ ] सीड वाक्यांश
* [ ] खाजगी कळ
* [x] प्राप्तीचा पत्ता
* [ ] पासवर्ड

### स्पष्टीकरण

पेमेंट मिळवण्यासाठी प्राप्तीचा पत्ता शेअर करता येतो. सीड वाक्यांश, खाजगी कळा आणि पासवर्ड गुप्त ठेवले पाहिजेत. विद्यार्थी मार्गदर्शिकेतील मॉड्यूल 3, “पत्ते” आणि “कळा” पुन्हा पाहा.

## प्रश्न 3

सीड ऑनलाइन प्रविष्ट केला आहे. पुढील सर्वात सुरक्षित पाऊल कोणते?

* [ ] वाट पाहा
* [ ] तो सहाय्य विभागाला पाठवा
* [x] नवीन सीड तयार करा, मग निधी हस्तांतरित करा
* [ ] तोच सीड पुन्हा वापरा

### स्पष्टीकरण

ऑनलाइन प्रविष्ट केलेला सीड वाक्यांश उघड झाला आहे असे समजा. नवीन सीडसह नवीन वॉलेट तयार करा, त्यानंतर गंतव्य पत्त्याची पडताळणी केल्यावरच निधी हस्तांतरित करा. विद्यार्थी मार्गदर्शिकेतील मॉड्यूल 3, “सीड वाक्यांश” पुन्हा पाहा.

## प्रश्न 4

इतरांच्या ताब्यातील आणि स्वतःच्या ताब्यातील वापर यांतील मुख्य फरक कोणता?

* [x] कळांवर कोणाचे नियंत्रण असते
* [ ] पेमेंट उलटवता येणे
* [ ] पुरवठ्याची मर्यादा
* [ ] व्यवहार शुल्क

### स्पष्टीकरण

कळांवर नियंत्रण कोणाचे असते आणि त्यासंबंधीची जबाबदारी कोण सांभाळते, यावरून इतरांच्या ताब्यातील आणि स्वतःच्या ताब्यातील वापर यांत फरक पडतो. दोन्हीपैकी कोणताही प्रकार सुरक्षिततेची किंवा व्यवहार उलटवता येण्याची हमी देत नाही. विद्यार्थी मार्गदर्शिकेतील मॉड्यूल 3, “इतरांच्या ताब्यातील आणि इतरांच्या ताब्यात नसलेला वापर” पुन्हा पाहा.
