# Quiz – पैसा समजून घेऊया: झटपट चाचणी

## प्रश्न 1

पैसा का स्वीकारला जातो?

* [x] इतर लोक तो स्वीकारतील अशी अपेक्षा असते
* [ ] तो वस्तूंचे मूल्य समान करतो
* [ ] तो सर्व नियम काढून टाकतो
* [ ] तो सेवांचे वस्तूंमध्ये रूपांतर करतो

### स्पष्टीकरण

इतर लोक पुढेही पैसा स्वीकारतील अशी अपेक्षा असल्यामुळे, पैसा अनोळखी व्यक्तींना वेगवेगळ्या वेळी देवाणघेवाण करण्यास मदत करतो. तरीही तो विश्वास, नियम आणि सामाजिक स्वीकार यांवर अवलंबून असतो. विद्यार्थी मार्गदर्शिकेतील विभाग 1, “पैसा का अस्तित्वात आहे” याची उजळणी करा.

## प्रश्न 2

किंमत ठरवणे, पैसे देणे, बचत करणे: पैशाच्या कोणत्या भूमिका?

* [ ] मूल्यसंचय; लेखा एकक; विनिमयाचे माध्यम
* [x] लेखा एकक; विनिमयाचे माध्यम; मूल्यसंचय
* [ ] विनिमयाचे माध्यम; मूल्यसंचय; लेखा एकक
* [ ] दुर्मिळता; दुर्मिळता; दुर्मिळता

### स्पष्टीकरण

लेखा एकक किमती व्यक्त करते, विनिमयाचे माध्यम देयक म्हणून स्वीकारले जाते आणि मूल्यसंचय भविष्यासाठी मूल्य जतन करतो. विद्यार्थी मार्गदर्शिकेतील विभाग 1, “पैशाची कार्ये आणि गुणधर्म” याची उजळणी करा.

## प्रश्न 3

तांदळाच्या बदल्यात बूट मिळत नाहीत: का?

* [ ] वेगवेगळ्या किमती
* [x] परस्परांच्या गरजा जुळत नाहीत
* [ ] बँकेची मंजुरी नाही
* [ ] तांदळाचा विनिमय करता येत नाही

### स्पष्टीकरण

प्रत्येक व्यक्तीला दुसरी व्यक्ती देऊ करत असलेली वस्तू एकाच वेळी हवी नसल्यास थेट वस्तुविनिमय करणे कठीण होते. यालाच गरजांचा दुहेरी संयोग म्हणतात. विद्यार्थी मार्गदर्शिकेतील विभाग 1, “वस्तुविनिमय आणि गरजांचा दुहेरी संयोग” याची उजळणी करा.

## प्रश्न 4

किमती +10%, उत्पन्न +5%: क्रयशक्तीचे काय होईल?

* [ ] वाढते
* [ ] तशीच राहते
* [x] कमी होते
* [ ] सांगता येत नाही

### स्पष्टीकरण

पैशाने किती खरेदी करता येते, म्हणजेच क्रयशक्ती. उत्पन्नापेक्षा किमती वेगाने वाढल्यास, त्या उत्पन्नातून कमी खरेदी करता येते. विद्यार्थी मार्गदर्शिकेतील विभाग 1, “महागाई आणि क्रयशक्ती” याची उजळणी करा.
