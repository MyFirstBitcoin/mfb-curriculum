# 4.9 KYC आणि KYC-विरहित पद्धतींचे फायदे-तोटे

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) आणि [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) या मार्गांमध्ये वेगवेगळ्या प्रकारच्या [तडजोडी असतात](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). यांपैकी कोणतेही नाव काळजीपूर्वक मूल्यमापन करण्याची गरज दूर करत नाही.


<!-- card: callout -->
> **गोपनीयतेमुळे कायदेशीर किंवा शारीरिक सुरक्षिततेविषयीचे धोके नाहीसे होत नाहीत**
>
> ना [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ना [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) हा पर्याय आपोआप सर्वोत्तम ठरतो. प्रत्यक्ष मार्गांची तुलना करा, नियम अस्पष्ट असतील तेव्हा अद्ययावत स्थानिक मार्गदर्शन घ्या आणि स्थानिक कायदा मोडू नका किंवा स्वतःला शारीरिक धोक्यात घालू नका, अगदी [गोपनीयतेसाठीही](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

एखादी [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) सेवा कायदेशीर नाव, ओळखपत्र, पत्ता, छायाचित्र, निधीच्या स्रोताची माहिती किंवा इतर नोंदी मागू शकते. यामुळे त्या सेवेला स्थानिक नियमांचे पालन करणे, बँकांशी जोडणी करणे, अधिक उच्च मर्यादा ठरवणे किंवा खात्याचा प्रवेश पुन्हा मिळवण्यासाठी मदत करणे शक्य होऊ शकते.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) मुळे माहितीशी संबंधित धोकेही निर्माण होतात. सेवेकडे कायमस्वरूपी परस्परांशी जोडलेली माहिती साठवली जाऊ शकते—ओळख, देयकाच्या पद्धती आणि बिटकॉइन [व्यवहार](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). माहितीची गळती, कायदेशीर मागणी, अंतर्गत गैरवापर किंवा धोरणातील बदल यांमुळे ती माहिती उघड होऊ शकते किंवा तिच्यावरील प्रवेश मर्यादित होऊ शकतो.

एखादा [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) मार्ग ओळखीविषयी कमी माहिती गोळा करू शकतो. यामुळे सुधारू शकते आपली आर्थिक [गोपनीयता](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). यात कमी नियमन असलेले व्यवहारातील दुसरे पक्ष, कमी तरलता, अधिक [किंमती](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), कमी सहाय्य, फसवणुकीचा अधिक धोका किंवा कायदेशीर निर्बंध यांचाही समावेश असू शकतो.

प्रत्यक्ष मार्गांची तुलना करा:


| प्रश्न | KYC मार्ग | No-KYC मार्ग |
| --- | --- | --- |
| ओळखीविषयी कोणती माहिती गोळा केली जाते? |  |  |
| माहिती कोण साठवते आणि किती काळासाठी? |  |  |
| व्यवहाराचा संबंध ब्लॉकचेनवरील नोंदींशी जोडता येतो का? |  |  |
| फसवणुकीपासून संरक्षणासाठी कोणत्या उपाययोजना आहेत? |  |  |
| व्यवहारातील दुसऱ्या पक्षाशी संबंधित कोणता धोका आहे? |  |  |
| कोणत्या मर्यादा आणि शुल्क लागू होतात? |  |  |
| कोणता स्थानिक कायदा लागू होतो? |  |  |
| वाद उद्भवल्यास काय होते? |  |  |


[गोपनीयता](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) म्हणजे प्रत्येक धोक्यापासून लपून राहणे नव्हे. ती म्हणजे स्वतःविषयीच्या माहितीवर नियंत्रण ठेवण्याची क्षमता. स्थानिक कायदा मोडू नका किंवा स्वतःला शारीरिक धोक्यात घालू नका, अगदी [गोपनीयतेसाठीही](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). नियम अस्पष्ट असतील तेव्हा पात्र व्यक्तीकडून अद्ययावत स्थानिक मार्गदर्शन घ्या.
