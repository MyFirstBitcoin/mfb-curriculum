# 4.9 Avvägningar med och utan KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) och [icke-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) innebär olika [avvägningar](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Ingen av beteckningarna undanröjer behovet av en noggrann bedömning.


<!-- card: callout -->
> **Integritet undanröjer inte juridiska risker eller risker för den fysiska säkerheten**
>
> Varken [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) eller [icke-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) är automatiskt bäst. Jämför det faktiska tillvägagångssättet, sök aktuell lokal vägledning när reglerna är oklara och bryt inte mot lokal lagstiftning eller utsätt Er för fysisk fara i strävan efter [integritet](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

En [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)-tjänst kan begära ett juridiskt namn, en identitetshandling, en adress, ett fotografi, uppgifter om medlens ursprung eller andra handlingar. Detta kan göra det möjligt för tjänsten att följa lokala regler, ansluta till banker, erbjuda högre beloppsgränser eller stödja kontoåterställning.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) medför också datarisker. Tjänsten kan lagra en permanent koppling mellan identitet, betalningsmetoder och bitcoinrelaterade [transaktioner](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Ett dataintrång, en rättslig begäran, internt missbruk eller en policyändring kan röja denna information eller begränsa tillgången till den.

Ett [icke-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)-alternativ kan samla in färre identitetsuppgifter. Detta kan stärka den finansiella [integriteten](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Det kan också innebära mindre reglerade motparter, lägre likviditet, högre [priser](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), sämre support, större bedrägeririsk eller rättsliga begränsningar.

Jämför det faktiska tillvägagångssättet:


| Fråga | KYC-alternativ | Icke-KYC-alternativ |
| --- | --- | --- |
| Vilka identitetsuppgifter samlas in? |  |  |
| Vem lagrar uppgifterna och hur länge? |  |  |
| Kan transaktionen kopplas till en identitet via blockkedjan? |  |  |
| Vilket skydd mot bedrägerier finns? |  |  |
| Vilken motpartsrisk finns? |  |  |
| Vilka beloppsgränser och avgifter gäller? |  |  |
| Vilken lokal lagstiftning gäller? |  |  |
| Vad händer vid en tvist? |  |  |


[Integritet](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) innebär inte att hemlighållande skyddar mot alla risker. Det är förmågan att kontrollera information om Er själv. Bryt inte mot lokal lagstiftning och utsätt Er inte för fysisk fara i strävan efter [integritet](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Sök aktuell lokal vägledning från en kvalificerad person när reglerna är oklara.
