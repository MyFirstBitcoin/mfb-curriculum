# Quiz – Att förstå pengar: snabbtest

## Fråga 1

Varför accepteras pengar?

* [x] Andra förväntas acceptera dem
* [ ] De gör varor lika värdefulla
* [ ] De undanröjer alla regler
* [ ] De förvandlar tjänster till varor

### Förklaring

Pengar hjälper människor som inte känner varandra att samordna utbyten över tid, eftersom de förväntar sig att andra ska acceptera pengarna senare. Det bygger fortfarande på tillit, regler och social acceptans. Läs igenom elevhandledningen, modul 1, ”Varför pengar finns”.

## Fråga 2

Prissätta, betala, spara: vilka funktioner?

* [ ] Värdebevarare; räkneenhet; bytesmedel
* [x] Räkneenhet; bytesmedel; värdebevarare
* [ ] Bytesmedel; värdebevarare; räkneenhet
* [ ] Knapphet; knapphet; knapphet

### Förklaring

En räkneenhet uttrycker priser, ett bytesmedel accepteras som betalning och en värdebevarare för värde in i framtiden. Läs igenom elevhandledningen, modul 1, ”Pengars funktioner och egenskaper”.

## Fråga 3

Att byta ris mot skor misslyckas: varför?

* [ ] Olika priser
* [x] Behoven matchar inte
* [ ] Inget godkännande från banken
* [ ] Ris kan inte användas i byteshandel

### Förklaring

Direkt byteshandel är svår när båda parter inte samtidigt vill ha det som den andra erbjuder. Detta är problemet med dubbel överensstämmelse mellan behov. Läs igenom elevhandledningen, modul 1, ”Byteshandel och dubbel överensstämmelse mellan behov”.

## Fråga 4

Priser +10 %, inkomst +5 %: köpkraft?

* [ ] Ökar
* [ ] Förblir oförändrad
* [x] Minskar
* [ ] Går inte att avgöra

### Förklaring

Köpkraft är vad pengar kan köpa. Om priserna stiger snabbare än inkomsten räcker inkomsten till mindre. Läs igenom elevhandledningen, modul 1, ”Inflation och köpkraft”.
