# 4.9 Untung Rugi KYC dan Tanpa KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) dan [non-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) melibatkan perbedaan dalam [kompromi](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Kedua label tersebut tidak menghilangkan perlunya evaluasi yang cermat.


<!-- card: callout -->
> **Privasi tidak menghilangkan risiko hukum atau risiko terhadap keselamatan fisik**
>
> Baik [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) maupun [non-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) tidak otomatis menjadi pilihan terbaik. Bandingkan jalur yang sebenarnya, gunakan panduan setempat yang terkini ketika aturannya tidak jelas, dan jangan melanggar hukum setempat atau membahayakan keselamatan fisik Anda demi [privasi](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Layanan [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) dapat meminta nama resmi, dokumen identitas, alamat, foto, informasi sumber dana, atau catatan lainnya. Hal ini dapat memungkinkan layanan tersebut untuk mematuhi aturan setempat, terhubung dengan bank, menetapkan batas yang lebih tinggi, atau mendukung pemulihan akun.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) juga menimbulkan risiko data. Layanan tersebut dapat menyimpan keterkaitan permanen antara identitas, metode pembayaran, dan bitcoin yang digunakan dalam [transaksi](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Kebocoran data, permintaan hukum, penyalahgunaan internal, atau perubahan kebijakan dapat mengungkap informasi tersebut atau membatasi akses terhadapnya.

Jalur [non-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) dapat mengumpulkan lebih sedikit informasi identitas. Hal ini dapat meningkatkan [privasi keuangan](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Jalur ini juga dapat melibatkan pihak lawan transaksi yang kurang diawasi oleh regulator, likuiditas yang lebih rendah, [harga yang lebih tinggi](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), dukungan yang lebih terbatas, risiko penipuan yang lebih besar, atau pembatasan hukum.

Bandingkan jalur yang sebenarnya:


| Pertanyaan | Jalur KYC | Jalur non-KYC |
| --- | --- | --- |
| Data identitas apa yang dikumpulkan? |  |  |
| Siapa yang menyimpan data dan untuk berapa lama? |  |  |
| Apakah transaksi dapat dikaitkan melalui data di blockchain? |  |  |
| Perlindungan terhadap penipuan apa yang tersedia? |  |  |
| Apa saja risiko terkait pihak lawan transaksi? |  |  |
| Batas dan biaya apa yang berlaku? |  |  |
| Hukum setempat apa yang berlaku? |  |  |
| Apa yang terjadi ketika timbul sengketa? |  |  |


[Privasi](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) bukan berarti kerahasiaan yang melindungi dari segala risiko. Privasi adalah kemampuan untuk mengendalikan informasi tentang diri Anda. Jangan melanggar hukum setempat atau membahayakan keselamatan fisik Anda demi [privasi](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Mintalah panduan setempat yang terkini dari orang yang berkualifikasi ketika aturannya tidak jelas.
