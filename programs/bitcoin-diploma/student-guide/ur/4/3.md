# 4.3 عملی ورکشاپس اور مظاہرے

آپ تین مراحل سے گزریں گے: **پیشکش**، جس میں آپ کے استاد طریقۂ کار اور اس کے خطرات دکھاتے ہیں؛ **مشق**، جس میں آپ محفوظ تربیتی مواد استعمال کرتے ہوئے رہنمائی کے تحت ایک طریقۂ کار پر عمل کرتے ہیں؛ اور **عملی انجام دہی**، جس میں آپ آزادانہ طور پر کوئی کام مکمل کرتے ہیں یا کسی فیصلے کی وضاحت کرتے ہیں۔


<!-- micrographic: presentation-practice-production-01 -->


آپ کی ورکشاپ میں یہ سرگرمیاں شامل ہو سکتی ہیں:

* یہ پہچاننا کہ آیا والیٹ تحویلی ہے یا خود تحویلی
* وصولی کی اسکرین تلاش کرنا، بغیر کوئی اصل [سیڈ فریز](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) بنائے یا ظاہر کیے
* آن چین ایڈریس کا موازنہ ایک [لائٹننگ انوائس](https://curriculum.myfirstbitcoin.org/lexicon/en/#lightning-invoice) سے کرنا
* ایک [ٹرانزیکشن](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) کو والیٹ یا [بلاک ایکسپلورر](https://curriculum.myfirstbitcoin.org/lexicon/en/#block-explorer) میں جانچنا
* مختلف مقامی طریقوں میں فیس اور موصول ہونے والی رقوم کا موازنہ کرنا
* دھوکا دہی کی علامات پہچاننا
* کسی تاجر کو ادائیگی یا کمیونٹی کے لیے عطیہ دینے کے عمل کی منصوبہ بندی کرنا
* ایک متعین مقصد کے لیے مقامی وسائل کی نشاندہی اور جانچ کرنا

کسی بھی براہِ راست عملی مظاہرے سے پہلے، یقینی بنائیں کہ آپ جانتے ہیں:

* کہ آلے اور ہدایات کی حال ہی میں جانچ کی گئی ہے
* کہ استاد بحالی کی وضاحت کیسے کریں گے اور اگر کوئی چیز کام نہ کرے تو کیا ہوگا
* کہ آیا حقیقی رقوم استعمال ہوں گی اور رازداری، سلامتی اور نقصان کے کیا خطرات ہیں
* کہ آپ پر سافٹ ویئر نصب کرنے یا مالی معلومات ظاہر کرنے کے لیے دباؤ نہیں ڈالا جائے گا
* کہ عملی مظاہرے میں استعمال ہونے والی کوئی بھی رقم اتنی کم ہوگی کہ اس کا نقصان ایک سبق بنے، بحران نہیں
* کہ آف لائن یا رقوم کے بغیر کیا جانے والا متبادل دستیاب ہے
* کہ اگر نتیجہ منصوبے سے مختلف ہو تو کلاس کیسے روکی جائے گی

آپ کی ورکشاپ کا نتیجہ کوئی وضاحت یا مہارت ہونا چاہیے، نہ کہ صرف ایک مکمل شدہ [ٹرانزیکشن](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction)۔
