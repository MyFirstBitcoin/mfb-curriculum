# 4.9 KYC اور بغیر KYC کے فوائد و نقصانات

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) اور [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) کے طریقوں میں مختلف [فوائد اور نقصانات ہوتے ہیں](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)۔ ان میں سے کوئی بھی نام محتاط جائزے کی ضرورت ختم نہیں کرتا۔


<!-- card: callout -->
> **رازداری قانونی یا جسمانی سلامتی کے خطرات ختم نہیں کرتی**
>
> نہ [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) اور نہ ہی [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) بذاتِ خود بہترین ہے۔ اصل طریقے کا موازنہ کریں، قواعد واضح نہ ہوں تو موجودہ مقامی رہنمائی سے رجوع کریں، اور مقامی قانون نہ توڑیں اور نہ ہی خود کو جسمانی خطرے میں ڈالیں، چاہے مقصد ہو [رازداری](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)۔


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

ایک [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) سروس قانونی نام، شناختی دستاویز، پتا، تصویر، رقوم کے ماخذ کی معلومات یا دیگر ریکارڈ طلب کر سکتی ہے۔ اس سے سروس کو مقامی قواعد کی تعمیل کرنے، بینکوں سے منسلک ہونے، زیادہ حدیں مقرر کرنے یا اکاؤنٹ کی بازیابی میں مدد دینے کی سہولت مل سکتی ہے۔

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ڈیٹا سے متعلق خطرات بھی پیدا کرتا ہے۔ سروس ان چیزوں کو مستقل طور پر باہم منسلک کر کے محفوظ کر سکتی ہے: شناخت، ادائیگی کے طریقے اور بٹ کوائن کے [لین دین](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction)۔ ڈیٹا کی سلامتی میں نقب، قانونی درخواست، اندرونی غلط استعمال یا پالیسی میں تبدیلی اس معلومات کو افشا کر سکتی ہے یا اس تک رسائی محدود کر سکتی ہے۔

ایک [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) طریقے میں شناخت سے متعلق کم معلومات جمع کی جا سکتی ہیں۔ اس سے مالی [رازداری بہتر ہو سکتی ہے](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)۔ اس میں کم ضابطہ بند فریقوں سے لین دین، کم سیالیت، زیادہ [قیمتیں](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)، کم معاونت، دھوکا دہی کا زیادہ خطرہ یا قانونی پابندیاں بھی شامل ہو سکتی ہیں۔

اصل طریقے کا موازنہ کریں:


| سوال | KYC طریقہ | no-KYC طریقہ |
| --- | --- | --- |
| شناخت سے متعلق کون سا ڈیٹا جمع کیا جاتا ہے؟ |  |  |
| ڈیٹا کون اور کتنی مدت تک محفوظ رکھتا ہے؟ |  |  |
| کیا لین دین کو بلاک چین پر شناخت سے منسلک کیا جا سکتا ہے؟ |  |  |
| دھوکا دہی سے بچاؤ کے کیا انتظامات موجود ہیں؟ |  |  |
| دوسرے فریق سے متعلق کیا خطرہ موجود ہے؟ |  |  |
| کون سی حدیں اور فیسیں لاگو ہوتی ہیں؟ |  |  |
| کون سا مقامی قانون لاگو ہوتا ہے؟ |  |  |
| تنازعے کی صورت میں کیا ہوتا ہے؟ |  |  |


[رازداری](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) کا مطلب ہر خطرے سے پوشیدہ رہنا نہیں ہے۔ یہ اپنے بارے میں معلومات پر اختیار رکھنے کی صلاحیت ہے۔ مقامی قانون نہ توڑیں اور نہ ہی خود کو جسمانی خطرے میں ڈالیں، چاہے مقصد ہو [رازداری](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)۔ قواعد واضح نہ ہوں تو کسی اہل شخص سے موجودہ مقامی رہنمائی حاصل کریں۔
