# 4.9 Предности и недостатоци со KYC и без KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) и [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) пристапите подразбираат различни [компромиси](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Ниту една од овие ознаки не ја отстранува потребата од внимателна процена.


<!-- card: callout -->
> **Приватноста не ги отстранува правните ризици или ризиците за физичката безбедност**
>
> Ниту [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ниту [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) е автоматски најдобриот избор. Споредете го конкретниот пристап, користете актуелни локални насоки кога правилата се нејасни и не ги прекршувајте локалните закони ниту изложувајте се на физичка опасност во потрага по [приватност](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Една [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) услуга може да побара име и презиме според официјалните документи, документ за идентификација, адреса, фотографија, информации за потеклото на средствата или други податоци. Тоа може да ѝ овозможи на услугата да ги исполнува локалните прописи, да се поврзе со банки, да постави повисоки лимити или да овозможи обновување на пристапот до сметката.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) создава и ризик за податоците. Услугата може да зачува трајна врска меѓу идентитетот, начините на плаќање и биткоин [трансакциите](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Нарушување на безбедноста, правно барање, внатрешна злоупотреба или промена на политиката може да ги открие тие информации или да го ограничи пристапот до нив.

Еден [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) пристап може да собира помалку податоци за идентитетот. Тоа може да ја подобри финансиската [приватност](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Исто така, може да вклучува помалку регулирани договорни страни, пониска ликвидност, повисоки [цени](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), намалена поддршка, поголем ризик од измама или законски ограничувања.

Споредете го конкретниот пристап:


| Прашање | KYC пристап | No-KYC пристап |
| --- | --- | --- |
| Кои податоци за идентитетот се собираат? |  |  |
| Кој ги чува податоците и колку долго? |  |  |
| Може ли трансакцијата да се поврзе со идентитет преку податоците на блокчејнот? |  |  |
| Каква заштита од измама постои? |  |  |
| Каков ризик постои од другата договорна страна? |  |  |
| Кои лимити и надоместоци важат? |  |  |
| Кои локални закони важат? |  |  |
| Што се случува во случај на спор? |  |  |


[Приватноста](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) не значи тајност што штити од секој ризик. Таа е способност да ги контролирате информациите за себе. Не ги прекршувајте локалните закони ниту изложувајте се на физичка опасност во потрага по [приватност](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Побарајте актуелни локални насоки од квалификувано лице кога правилата се нејасни.
