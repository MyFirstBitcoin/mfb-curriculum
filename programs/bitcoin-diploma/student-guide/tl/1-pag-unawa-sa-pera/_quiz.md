# Quiz – Pag-unawa sa Pera: maikling pagsusulit

## Tanong 1

Bakit tinatanggap ang pera?

* [x] Inaasahang tatanggapin ito ng iba
* [ ] Ginagawa nitong magkakapantay ang halaga ng mga kalakal
* [ ] Inaalis nito ang lahat ng tuntunin
* [ ] Ginagawa nitong kalakal ang mga serbisyo

### Paliwanag

Tinutulungan ng pera ang mga taong hindi magkakakilala na makipagpalitan sa magkakaibang panahon dahil inaasahan nilang tatanggapin din ito ng iba sa hinaharap. Nakadepende pa rin ito sa tiwala, mga tuntunin, at pagtanggap ng lipunan. Balikan po ninyo ang Gabay ng Mag-aaral, Modyul 1, “Bakit may pera.”

## Tanong 2

Pagtatakda ng presyo, pagbabayad, pag-iimpok: aling mga tungkulin?

* [ ] Tagapag-imbak; panukat; midyum
* [x] Panukat; midyum; tagapag-imbak
* [ ] Midyum; tagapag-imbak; panukat
* [ ] Kakapusan; kakapusan; kakapusan

### Paliwanag

Ang panukat ng halaga ay ginagamit sa pagpapahayag ng mga presyo, ang midyum ng palitan ay tinatanggap bilang bayad, at ang tagapag-imbak ng halaga ay nagpapanatili ng halaga para sa hinaharap. Balikan po ninyo ang Gabay ng Mag-aaral, Modyul 1, “Mga tungkulin at katangian ng pera.”

## Tanong 3

Hindi matuloy ang palitan ng bigas para sa sapatos: bakit?

* [ ] Magkaibang presyo
* [x] Hindi magkatugma ang mga kagustuhan
* [ ] Walang pag-apruba ng bangko
* [ ] Hindi maaaring ipagpalit ang bigas

### Paliwanag

Mahirap ang direktang palitan kapag hindi sabay na gusto ng bawat panig ang iniaalok ng isa. Ito ang tinatawag na pangangailangang magkatugma ang kagustuhan ng magkabilang panig. Balikan po ninyo ang Gabay ng Mag-aaral, Modyul 1, “Direktang palitan at ang pagtutugma ng kagustuhan ng magkabilang panig.”

## Tanong 4

Mga presyo +10%, kita +5%: kakayahang bumili?

* [ ] Tumataas
* [ ] Nananatiling pareho
* [x] Bumababa
* [ ] Hindi matukoy

### Paliwanag

Ang kakayahang bumili ay tumutukoy sa kung ano ang mabibili ng pera. Kung mas mabilis tumaas ang mga presyo kaysa sa kita, mas kaunti ang mabibili ng kita. Balikan po ninyo ang Gabay ng Mag-aaral, Modyul 1, “Implasyon at kakayahang bumili.”
