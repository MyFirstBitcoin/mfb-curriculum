# 2.16 Talatakdaan ng Pinagmulan ng Bitcoin

Lumitaw ang Bitcoin sa pamamagitan ng isang maikling serye ng mga pampublikong pangyayari.


<!-- micrographic: bitcoin-origin-timeline-01 -->


Suriin ninyo ang mga orihinal na tala: basahin ang [whitepaper ng Bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-whitepaper) ([orihinal na PDF](https://bitcoin.org/bitcoin.pdf)), siyasatin ang [Blokeng Genesis](https://curriculum.myfirstbitcoin.org/lexicon/en/#genesis-block) ([tala ng bloke](https://mempool.space/block/000000000019d6689c085ae165831e934ff763ae46a2a6c172b3f1b60a8ce26f)) at ang unang naitalang [transaksiyon sa pagitan ng dalawang tao](https://curriculum.myfirstbitcoin.org/lexicon/en/#person-to-person-transaction) ([tala ng transaksiyon](https://mempool.space/tx/f4184fc596403b9d638783cf57adfe4c75c605f6356fbc91338530e9831e9e16)), at basahin ang [orihinal na kahilingan para sa pizza](https://bitcointalk.org/index.php?topic=137.0). Ang [tagasiyasat ng bloke](https://curriculum.myfirstbitcoin.org/lexicon/en/#block-explorer) ay isang madaling gamiting interface para sa pampublikong datos, hindi isang pangunahing awtoridad sa mga tuntunin ng Bitcoin.

[**Satoshi Nakamoto**](https://curriculum.myfirstbitcoin.org/lexicon/en/#satoshi-nakamoto) ang sagisag-panulat na ginamit ng hindi kilalang lumikha o mga lumikha ng Bitcoin. [Si Satoshi](https://curriculum.myfirstbitcoin.org/lexicon/en/#satoshi-nakamoto) ay nakipag-ugnayan online, inilabas ang software bilang open source, at kalaunan ay tumigil sa pakikilahok.

Walang sentral na kompanyang nagmamay-ari ng Bitcoin. Nagpatuloy ang software at mga tuntunin dahil pinili ng ibang mga tao na patakbuhin, suriin, at paunlarin ang mga ito. Mahalaga ang pinagmulang ito: hindi nanatili ang lumikha bilang isang permanenteng pinuno na maaaring maglabas ng mas maraming barya o mag-apruba ng mga [transaksiyon](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction).

Ang [Blokeng Genesis](https://curriculum.myfirstbitcoin.org/lexicon/en/#genesis-block) at ang krisis sa pananalapi noong 2008 ay nagbibigay ng mahalagang kontekstong pangkasaysayan sa Bitcoin. Gayunman, suriin ninyo ang Bitcoin batay sa disenyo at paggana nito, hindi lamang sa isang kuwento tungkol sa lumikha nito.

Noong Oktubre 2008, [si Satoshi Nakamoto](https://curriculum.myfirstbitcoin.org/lexicon/en/#satoshi-nakamoto) ay nag-anunsyo ng [whitepaper ng Bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-whitepaper). Simple ang pangunahing tanong nito: **paano makapagbabayad online ang mga tao nang hindi hinahayaang magastos nang dalawang beses ang iisang digital na yunit o binibigyan ang isang [tagapamagitan](https://curriculum.myfirstbitcoin.org/lexicon/en/#intermediary) ng kontrol?**
