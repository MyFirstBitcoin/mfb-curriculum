# 2.8 Paglilipat nang P2P

**Peer-to-peer** ay nangangahulugang nakikipag-ugnayan ang mga kalahok sa pamamagitan ng isang network nang hindi nangangailangan ng sentral na tagapag-ugnay. Ang isang gumagamit ng Bitcoin ay maaaring gumawa at lumagda sa isang [transaksiyon](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction), at pagkatapos ay [ipakalat](https://curriculum.myfirstbitcoin.org/lexicon/en/#broadcast) ito sa network. Hindi kailangan ng tatanggap ng account sa bangko ng nagpapadala dahil ang Bitcoin mismo ang nagbibigay ng iisang sistema ng pag-aayos ng mga pagbabayad.

Ang peer-to-peer ay hindi laging nangangahulugang dalawang computer lamang ang direktang nag-uugnayan. Ang isang [transaksiyon](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) ay maaaring dumaan sa mga wallet, internet provider, at maraming network [node](https://curriculum.myfirstbitcoin.org/lexicon/en/#node). Ang mahalagang punto ay walang sentral na operator ng Bitcoin na kailangang mag-apruba sa nagpapadala o tatanggap.

Maaari pa ring pumili ang mga gumagamit ng mga [tagapamagitan](https://curriculum.myfirstbitcoin.org/lexicon/en/#intermediary). Maaaring maghawak ng bitcoin ang isang palitan para sa mga kostumer. Maaaring gawing mas simple ng isang serbisyo sa pagbabayad ang isang invoice. Maaaring mamahala ng mga susi ang isang wallet na pinapatakbo ng isang tagapagbigay ng serbisyo. Maaaring magbigay ng kaginhawahan ang mga serbisyong ito, ngunit nakadepende na ang gumagamit sa mga patakaran at seguridad ng serbisyo.

Ginagawang posible ng Bitcoin ang direktang pagmamay-ari at paglilipat; hindi nito pinipilit ang bawat gumagamit na iwasan ang lahat ng serbisyo. Ang [paraan ng pag-iingat ng mga pondo](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) na pinili ang nagtatakda kung sino ang may aktuwal na kontrol.

Maaaring maging kapaki-pakinabang ang peer-to-peer na paglilipat kapag nasa magkakaibang lugar ang mga tao o gumagamit sila ng magkakaibang sistema ng pagbabangko. May kaakibat din itong pananagutan. Ang isang wastong [transaksiyon](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) na ipinadala sa maling address ay karaniwang hindi na mababawi.
