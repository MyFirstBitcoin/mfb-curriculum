# 2.6 Desentralisasyon

Ang [sentralisadong sistema](https://curriculum.myfirstbitcoin.org/lexicon/en/#centralized-system) ay may isang sentro ng kontrol. Kinokontrol ng isang bangko ang [talaan ng mga transaksiyon ng mga kliyente nito](https://curriculum.myfirstbitcoin.org/lexicon/en/#ledger). Kinokontrol ng isang kompanya ng pagbabayad ang sarili nitong network. Kinokontrol ng isang pamahalaan ang mga tuntunin sa pag-isyu ng [salapi nito](https://curriculum.myfirstbitcoin.org/lexicon/en/#currency).


> **Definition – Desentralisasyon**
>
> Ang [desentralisadong sistema](https://curriculum.myfirstbitcoin.org/lexicon/en/#decentralized-system) ay namamahagi ng mga tungkulin at pagpapatupad ng mga desisyon sa maraming independiyenteng kalahok. Walang sentral na tanggapan ang Bitcoin na maaaring gumawa ng mga account, magbago ng mga balanse, o mag-apruba ng pagiging kasapi.


Sa Bitcoin, ang [desentralisasyon](https://curriculum.myfirstbitcoin.org/lexicon/en/#decentralization) ay nagmumula sa ilang katangian:

* maaaring i-download at suriin ng sinuman ang [open-source na software](https://curriculum.myfirstbitcoin.org/lexicon/en/#open-source-software)
* maaaring makipagtransaksiyon ang mga gumagamit nang hindi nagbubukas ng account sa [network ng Bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-network)
* ang mga independiyenteng [node](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) ay sumusuri ng mga [transaksiyon](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) at block
* [ang mga minero](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) ay nakikipagpaligsahan upang magmungkahi ng mga block
* walang [minero](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) na makagagawang katanggap-tanggap ang isang di-wastong block sa mga tapat na [node](https://curriculum.myfirstbitcoin.org/lexicon/en/#node)
* ang mga pagbabago sa mga tuntunin ay nangangailangan ng kusang-loob na pagtanggap ng mga kalahok
* ang [talaan ng mga transaksiyon](https://curriculum.myfirstbitcoin.org/lexicon/en/#ledger) ay kinokopya sa maraming computer at lokasyon

[Ang desentralisasyon](https://curriculum.myfirstbitcoin.org/lexicon/en/#decentralization) ay hindi katumbas ng pantay-pantay na impluwensiya. [Pangminang](https://curriculum.myfirstbitcoin.org/lexicon/en/#proof-of-work) kagamitan, teknikal na kaalaman, pera, access sa internet, at pagbuo ng software ay hindi pantay-pantay na naipamamahagi. Maaaring maging sentro ng pagdepende ng sarili nilang mga gumagamit ang malalaking tagapagbigay ng serbisyo. Mas limitado ang ipinapahayag ng Bitcoin: walang iisang kalahok ang may awtoridad na mag-isang baguhin ang [talaan ng mga transaksiyon](https://curriculum.myfirstbitcoin.org/lexicon/en/#ledger) o ang mga tuntunin sa pananalapi para sa lahat.

[Ang desentralisasyon](https://curriculum.myfirstbitcoin.org/lexicon/en/#decentralization) ay mayroon ding mga kaakibat na kapalit. Maaaring maging mas mabagal ang koordinasyon. Kailangang tiyakin ng mga gumagamit ang katumpakan ng impormasyon at umako ng higit na pananagutan. Walang sentral na tanggapan ng suporta para sa [network ng Bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-network). Ang mga [kapalit na ito](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off) ay bahagi ng disenyo, hindi mga di-sinasadyang depekto na maaaring alisin nang hindi binabago ang sistema.
