# Quiz – Paano Gumagana ang Bitcoin: maikling pagsusulit

## Tanong 1

Ginamit nang dalawang beses sa pagbabayad ang iisang digital na yunit. Dapat gawin ng sistema ang sumusunod:

* [x] Tanggihan ang dobleng paggastos
* [ ] Itago ang pagbabayad
* [ ] Itaas ang presyo nito
* [ ] Alisin ang mga bayarin

### Paliwanag

Maaaring kopyahin ang digital na impormasyon, kaya dapat pigilan ng isang sistema ng pera ang paggastos nang dalawang beses sa iisang yunit at tukuyin kung aling transaksiyon ang wasto. Balikan po ninyo ang Gabay ng Mag-aaral, Modyul 2, “Mga unang pagtatangka sa digital na pera at ang problema ng dobleng paggastos.”

## Tanong 2

Ang desentralisasyon ng Bitcoin ay nangangahulugan ng:

* [ ] Iisang kompanya ang nag-aapruba ng mga pagbabayad
* [x] Independiyenteng pagpapatupad ng mga tuntunin
* [ ] Malayang binabago ng mga minero ang mga tuntunin
* [ ] Pantay na impluwensiya para sa lahat

### Paliwanag

Ipinamamahagi ng Bitcoin ang pagberipika at pagpapatupad ng mga tuntunin sa mga independiyenteng kalahok. Hindi nangangahulugan ang desentralisasyon na iisang kompanya ang kumokontrol sa network o na pantay-pantay ang impluwensiya ng lahat. Balikan po ninyo ang Gabay ng Mag-aaral, Modyul 2, “Desentralisasyon.”

## Tanong 3

Ang isang node ng Bitcoin ay:

* [x] Nagsusuri ng pagsunod sa mga tuntunin ng network
* [ ] Lumilikha ng bitcoin
* [ ] Nag-iimbak ng bitcoin
* [ ] Gumagarantiya ng pagbabayad

### Paliwanag

Independiyenteng sinusuri ng mga node ang pagsunod sa mga tuntunin ng Bitcoin at tinatanggihan ang di-wastong datos. Hindi sila lumilikha ng bitcoin kapag hiniling o nag-iimbak ng bitcoin sa loob ng isang telepono. Balikan po ninyo ang Gabay ng Mag-aaral, Modyul 2, “Mga gumagamit, node, at minero.”

## Tanong 4

Bakit tinatawag na matatag na pera ang Bitcoin?

* [ ] Palaging tumataas ang presyo
* [x] Bukas sa publiko ang impormasyon sa suplay at limitado ito
* [ ] Iisang kompanya ang kumokontrol dito
* [ ] Pribado ang mga pagbabayad

### Paliwanag

Inilalarawan ng ilan ang Bitcoin bilang matatag na pera dahil bukas sa publiko ang mga tuntunin nito sa suplay at limitado ang paglalabas nito. Isa itong paghatol na may batayan, hindi isang pangako tungkol sa presyo o pagkapribado. Balikan po ninyo ang Gabay ng Mag-aaral, Modyul 2, “Bitcoin bilang matatag na digital na pera.”
