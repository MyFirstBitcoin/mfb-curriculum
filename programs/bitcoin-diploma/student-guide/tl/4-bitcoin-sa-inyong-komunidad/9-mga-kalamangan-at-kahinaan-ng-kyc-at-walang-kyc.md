# 4.9 Mga Kalamangan at Kahinaan ng KYC at Walang KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) at [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) na mga paraan ay may magkakaibang [pakinabang at kapalit na panganib](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Hindi inaalis ng alinman sa mga katawagang ito ang pangangailangan para sa maingat na pagsusuri.


<!-- card: callout -->
> **Hindi inaalis ng pagkapribado ang panganib na legal o sa pisikal na kaligtasan**
>
> Hindi ang [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) o ang [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ang awtomatikong pinakamahusay. Ihambing po ninyo ang aktuwal na paraan, gumamit ng napapanahong lokal na gabay kapag hindi malinaw ang mga tuntunin, at huwag labagin ang lokal na batas o ilagay ang inyong sarili sa pisikal na panganib sa paghahangad ng [pagkapribado](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Ang isang [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) na serbisyo ay maaaring humingi ng legal na pangalan, dokumentong nagpapatunay ng pagkakakilanlan, tirahan, litrato, impormasyon tungkol sa pinagmulan ng pondo, o iba pang mga tala. Maaari nitong bigyang-daan ang serbisyo na sumunod sa mga lokal na tuntunin, makipag-ugnayan sa mga bangko, magtakda ng mas matataas na limitasyon, o tumulong sa pagbawi ng account.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ay lumilikha rin ng panganib sa datos. Maaaring mag-imbak ang serbisyo ng permanenteng ugnayan sa pagitan ng pagkakakilanlan, mga paraan ng pagbabayad, at mga bitcoin [na transaksiyon](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Ang paglabag sa seguridad, legal na kahilingan, maling paggamit sa loob ng organisasyon, o pagbabago sa patakaran ay maaaring maglantad sa impormasyong iyon o maghigpit sa paggamit nito.

Ang isang [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) na paraan ay maaaring mangolekta ng mas kaunting impormasyon tungkol sa pagkakakilanlan. Maaari nitong mapabuti ang pinansiyal na [pagkapribado](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Maaari rin itong may kasamang mga katransaksiyong hindi gaanong napapailalim sa regulasyon, mas mababang likididad, mas matataas na [presyo](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), mas kaunting suporta, mas malaking panganib ng pandaraya, o mga legal na paghihigpit.

Ihambing po ninyo ang aktuwal na paraan:


| Tanong | Paraang KYC | Paraang no-KYC |
| --- | --- | --- |
| Anong datos tungkol sa pagkakakilanlan ang kinokolekta? |  |  |
| Sino ang nag-iimbak ng datos at gaano ito katagal iniimbak? |  |  |
| Maaari bang maiugnay ang transaksiyon sa mga tala sa blockchain? |  |  |
| Anong proteksiyon laban sa pandaraya ang mayroon? |  |  |
| Anong panganib mula sa katransaksiyon ang mayroon? |  |  |
| Anong mga limitasyon at bayarin ang naaangkop? |  |  |
| Anong lokal na batas ang naaangkop? |  |  |
| Ano ang nangyayari kapag may hindi pagkakaunawaan? |  |  |


[Ang pagkapribado](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) ay hindi pagtatago mula sa lahat ng panganib. Ito ang kakayahang kontrolin ang impormasyon tungkol sa inyong sarili. Huwag po ninyong labagin ang lokal na batas o ilagay ang inyong sarili sa pisikal na panganib sa paghahangad ng [pagkapribado](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Humingi po kayo ng napapanahong lokal na gabay mula sa isang taong may angkop na kwalipikasyon kapag hindi malinaw ang mga tuntunin.
