# 3.3 Mga Address

<!-- card: definition -->
> **Definition – Bitcoin address**
>
> Ang [Bitcoin address](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-address) ay pampublikong impormasyon para sa pagtanggap ng isang [pagbabayad na on-chain](https://curriculum.myfirstbitcoin.org/lexicon/en/#on-chain-payment). Karaniwang ipinapakita ito ng wallet bilang teksto at QR code upang makapagpadala sa inyo ng bitcoin ang ibang tao. Hindi tulad ng password o [pribadong susi](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key), hindi makapagpapahintulot ng paggastos ang isang address.



<!-- micrographic: address-two-formats-01 -->
[Ipinapakita sa screen ng wallet para sa pagtanggap ang isang halimbawang Bitcoin address sa dalawang anyo: bilang QR code at bilang teksto. Pareho ang pampublikong impormasyon para sa pagtanggap sa dalawang ito, at wala sa mga ito ang makapagpapahintulot ng paggastos.](/micrographics/address-two-formats-01/tl.md)


Kung nais ninyong tumanggap ng isang [pagbabayad na on-chain](https://curriculum.myfirstbitcoin.org/lexicon/en/#on-chain-payment), saan dapat manggaling ang address? Buksan ang wallet na nais ninyong gamitin at gamitin ang screen nito para sa pagtanggap. Maaaring i-scan ng nagpapadala ang QR code o kopyahin ang address. Naiiwasan nito ang mga pagkakamaling maaaring mangyari kapag manu-manong tina-type ang mahahabang hanay ng mga karakter.

Para sa bawat kahilingan sa pagbabayad, tiyakin ang nilalayong paraan ng pagbabayad. Ang isang on-chain address at isang [Lightning invoice](https://curriculum.myfirstbitcoin.org/lexicon/en/#lightning-invoice) ay magkaiba. Pagkatapos mag-scan o kumopya, ihambing ang destinasyon sa pinagkakatiwalaang screen para sa pagtanggap bago aprubahan ang isang pagbabayad. Bakit kailangang suriin pagkatapos kumopya? Maaaring palitan ng mapaminsalang software ang nakopyang impormasyon ng address. Ang paggamit ng bagong on-chain address para sa bawat bagong pagtanggap ay maaaring mapahusay ang [pagkapribado](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Ang muling paggamit ng iisang address ay maaaring magpadali para sa ibang tao na pag-ugnayin ang magkakahiwalay na pagbabayad. Nababawasan ng bagong address ang kadalian ng pag-uugnay na iyon; hindi nito ginagawang anonimo ang isang pagbabayad.

<!-- card: light -->
> Kapag mahalaga ang isang pagbabayad, huwag ipagpalagay na ligtas ang isang address dahil lamang mukhang pamilyar ito. Tiyakin ang nilalayong tatanggap, tamang [network ng Bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-network), destinasyon, at paraan ng pagbabayad. Magsagawa muna ng pagsubok gamit ang maliit na halaga kapag hindi kayo pamilyar sa proseso o halaga.
