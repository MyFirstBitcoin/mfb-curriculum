# 4.9 KYC અને બિન-KYCના ફાયદા-ગેરફાયદા

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) અને [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) માર્ગોમાં જુદાં જુદાં [સમાધાનો કરવા પડે છે](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). બંનેમાંથી કોઈ પણ નામ સાવચેતીપૂર્વક મૂલ્યાંકન કરવાની જરૂરિયાત દૂર કરતું નથી.


<!-- card: callout -->
> **ગોપનીયતા કાનૂની કે શારીરિક સલામતીનું જોખમ દૂર કરતી નથી**
>
> ન તો [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ન તો [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) આપમેળે શ્રેષ્ઠ છે. વાસ્તવિક માર્ગની તુલના કરો, નિયમો અસ્પષ્ટ હોય ત્યારે હાલનું સ્થાનિક માર્ગદર્શન લો, અને સ્થાનિક કાયદો ન તોડો કે પોતાને શારીરિક જોખમમાં ન મૂકો, ભલે તમારો હેતુ હોય [ગોપનીયતા](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

એક [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) સેવા કાનૂની નામ, ઓળખ દસ્તાવેજ, સરનામું, ફોટોગ્રાફ, ભંડોળના સ્ત્રોતની માહિતી અથવા અન્ય રેકોર્ડ માગી શકે છે. આનાથી સેવા સ્થાનિક નિયમોનું પાલન કરી શકે છે, બેંકો સાથે જોડાઈ શકે છે, વધુ ઊંચી મર્યાદાઓ નક્કી કરી શકે છે અથવા ખાતું પુનઃપ્રાપ્ત કરવામાં સહાય કરી શકે છે.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ડેટાનું જોખમ પણ ઊભું કરે છે. સેવા કાયમી જોડાણ સંગ્રહિત કરી શકે છે, જે જોડે છે ઓળખ, ચુકવણીની પદ્ધતિઓ અને બિટકોઇન [વ્યવહારોને](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). ડેટાની સુરક્ષામાં ભંગ, કાનૂની માંગ, આંતરિક દુરુપયોગ અથવા નીતિમાં ફેરફારથી તે માહિતી ખુલ્લી પડી શકે છે અથવા તેના પર પ્રતિબંધ લાગી શકે છે.

એક [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) માર્ગ ઓળખની ઓછી માહિતી એકત્રિત કરી શકે છે. આનાથી સુધરી શકે છે નાણાકીય [ગોપનીયતા](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). તેમાં ઓછા નિયમન હેઠળના સામા પક્ષો, ઓછી તરલતા, વધુ ઊંચા [ભાવ](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), ઓછી સહાય, છેતરપિંડીનું વધુ જોખમ અથવા કાનૂની પ્રતિબંધો પણ સામેલ હોઈ શકે છે.

વાસ્તવિક માર્ગની તુલના કરો:


| પ્રશ્ન | KYC માર્ગ | No-KYC માર્ગ |
| --- | --- | --- |
| ઓળખ સંબંધિત કયો ડેટા એકત્રિત કરવામાં આવે છે? |  |  |
| ડેટા કોણ સંગ્રહિત કરે છે અને કેટલા સમય માટે? |  |  |
| શું વ્યવહારને ઓન-ચેઇન જોડી શકાય છે? |  |  |
| છેતરપિંડી સામે કયું રક્ષણ ઉપલબ્ધ છે? |  |  |
| સામા પક્ષને લગતું કયું જોખમ છે? |  |  |
| કઈ મર્યાદાઓ અને ફી લાગુ પડે છે? |  |  |
| કયો સ્થાનિક કાયદો લાગુ પડે છે? |  |  |
| વિવાદ દરમિયાન શું થાય છે? |  |  |


[ગોપનીયતા](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) એટલે દરેક જોખમથી છુપાયેલા રહેવું નહીં. તે પોતાના વિશેની માહિતી પર નિયંત્રણ રાખવાની ક્ષમતા છે. સ્થાનિક કાયદો ન તોડો કે પોતાને શારીરિક જોખમમાં ન મૂકો, ભલે તમારો હેતુ હોય [ગોપનીયતા](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). નિયમો અસ્પષ્ટ હોય ત્યારે યોગ્ય લાયકાત ધરાવતી વ્યક્તિ પાસેથી હાલનું સ્થાનિક માર્ગદર્શન મેળવો.
