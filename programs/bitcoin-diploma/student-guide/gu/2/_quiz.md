# Quiz – બિટકોઇન કેવી રીતે કાર્ય કરે છે: ઝડપી ચકાસણી

## પ્રશ્ન 1

એક જ ડિજિટલ એકમથી બે વાર ચુકવણી થાય છે. પ્રણાલીએ શું કરવું જોઈએ?

* [x] બેવડા ખર્ચને નકારવો
* [ ] ચુકવણી છુપાવવી
* [ ] તેની કિંમત વધારવી
* [ ] ફી દૂર કરવી

### સમજૂતી

ડિજિટલ માહિતીની નકલ કરી શકાય છે, તેથી નાણાકીય પ્રણાલીએ એક જ એકમ બે વાર ખર્ચાતો અટકાવવો જોઈએ અને કયો વ્યવહાર માન્ય છે તે નક્કી કરવું જોઈએ. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 2, “ડિજિટલ નાણાંના પ્રારંભિક પ્રયાસો અને બેવડા ખર્ચની સમસ્યા”ની સમીક્ષા કરો.

## પ્રશ્ન 2

બિટકોઇનના વિકેન્દ્રીકરણનો અર્થ છે:

* [ ] એક કંપની ચુકવણીઓને મંજૂરી આપે છે
* [x] નિયમોનું સ્વતંત્ર અમલીકરણ
* [ ] માઇનર્સ મનસ્વી રીતે નિયમો બદલે છે
* [ ] દરેકનો સમાન પ્રભાવ

### સમજૂતી

બિટકોઇન ચકાસણી અને નિયમોના અમલીકરણનું કાર્ય સ્વતંત્ર સહભાગીઓ વચ્ચે વહેંચે છે. વિકેન્દ્રીકરણનો અર્થ એ નથી કે એક કંપની નેટવર્કને નિયંત્રિત કરે છે અથવા દરેકનો સમાન પ્રભાવ હોય છે. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 2, “વિકેન્દ્રીકરણ”ની સમીક્ષા કરો.

## પ્રશ્ન 3

બિટકોઇન નોડ:

* [x] નેટવર્કના નિયમો અનુસાર ચકાસણી કરે છે
* [ ] બિટકોઇન બનાવે છે
* [ ] બિટકોઇન સંગ્રહે છે
* [ ] ચુકવણીની ખાતરી આપે છે

### સમજૂતી

નોડ્સ સ્વતંત્ર રીતે બિટકોઇનના નિયમો અનુસાર ચકાસણી કરે છે અને અમાન્ય ડેટાને નકારે છે. તેઓ વિનંતી કરવામાં આવે ત્યારે બિટકોઇન બનાવતા નથી કે ફોનની અંદર બિટકોઇન સંગ્રહતા નથી. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 2, “વપરાશકર્તાઓ, નોડ્સ અને માઇનર્સ”ની સમીક્ષા કરો.

## પ્રશ્ન 4

બિટકોઇનને મજબૂત નાણાં શા માટે કહેવાય છે?

* [ ] કિંમત હંમેશાં વધે છે
* [x] જાહેર, મર્યાદિત પુરવઠો
* [ ] એક કંપની તેને નિયંત્રિત કરે છે
* [ ] ચુકવણીઓ ખાનગી હોય છે

### સમજૂતી

કેટલાક લોકો બિટકોઇનને મજબૂત નાણાં કહે છે કારણ કે તેના પુરવઠાના નિયમો જાહેર છે અને નવા બિટકોઇનનું જારીકરણ મર્યાદિત છે. આ તર્ક આધારિત અભિપ્રાય છે, કિંમત કે ગોપનીયતા વિશેનું વચન નથી. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 2, “મજબૂત ડિજિટલ નાણાં તરીકે બિટકોઇન”ની સમીક્ષા કરો.
