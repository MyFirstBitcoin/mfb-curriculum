# Quiz – નાણાંને સમજીએ: ઝડપી ચકાસણી

## પ્રશ્ન 1

નાણાં શા માટે સ્વીકારવામાં આવે છે?

* [x] અન્ય લોકો તેનો સ્વીકાર કરશે એવી અપેક્ષા હોય છે
* [ ] તે ચીજવસ્તુઓને સમાન મૂલ્યની બનાવે છે
* [ ] તે બધા નિયમો દૂર કરે છે
* [ ] તે સેવાઓને ચીજવસ્તુઓમાં ફેરવે છે

### સમજૂતી

નાણાં અજાણ્યા લોકોને જુદા જુદા સમયે વિનિમય કરવામાં મદદ કરે છે, કારણ કે લોકો અપેક્ષા રાખે છે કે અન્ય લોકો પણ પછીથી તેનો સ્વીકાર કરશે. તેમ છતાં, નાણાં વિશ્વાસ, નિયમો અને સામાજિક સ્વીકૃતિ પર આધાર રાખે છે. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 1, “નાણાં શા માટે અસ્તિત્વમાં છે”ની સમીક્ષા કરો.

## પ્રશ્ન 2

કિંમત નક્કી કરવી, ચુકવણી કરવી, બચત કરવી: કઈ ભૂમિકાઓ?

* [ ] મૂલ્યનો સંગ્રહ; હિસાબનું એકમ; વિનિમયનું માધ્યમ
* [x] હિસાબનું એકમ; વિનિમયનું માધ્યમ; મૂલ્યનો સંગ્રહ
* [ ] વિનિમયનું માધ્યમ; મૂલ્યનો સંગ્રહ; હિસાબનું એકમ
* [ ] અછત; અછત; અછત

### સમજૂતી

હિસાબનું એકમ કિંમતો દર્શાવે છે, વિનિમયનું માધ્યમ ચુકવણીમાં સ્વીકારવામાં આવે છે અને મૂલ્યનો સંગ્રહ મૂલ્યને ભવિષ્ય માટે જાળવી રાખે છે. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 1, “નાણાંનાં કાર્યો અને ગુણધર્મો”ની સમીક્ષા કરો.

## પ્રશ્ન 3

ચોખાના બદલામાં પગરખાં મેળવવાનો પ્રયાસ નિષ્ફળ જાય છે: શા માટે?

* [ ] અલગ અલગ કિંમતો
* [x] જરૂરિયાતોનો મેળ ન હોવો
* [ ] બેંકની મંજૂરી ન હોવી
* [ ] ચોખાનો વિનિમય થઈ શકતો નથી

### સમજૂતી

જ્યારે એક વ્યક્તિ જે આપે છે તે જ સમયે બીજી વ્યક્તિને જોઈતું ન હોય, ત્યારે સીધો વસ્તુવિનિમય મુશ્કેલ બને છે. આ જરૂરિયાતોના બેવડા સંયોગની સમસ્યા છે. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 1, “વસ્તુવિનિમય અને જરૂરિયાતોનો બેવડો સંયોગ”ની સમીક્ષા કરો.

## પ્રશ્ન 4

કિંમતો +10%, આવક +5%: ખરીદશક્તિનું શું થાય?

* [ ] વધે છે
* [ ] સમાન રહે છે
* [x] ઘટે છે
* [ ] કહી શકાય નહીં

### સમજૂતી

નાણાંથી શું ખરીદી શકાય છે તે ખરીદશક્તિ છે. જો આવક કરતાં કિંમતો વધુ ઝડપથી વધે, તો તે આવકથી ઓછી ચીજવસ્તુઓ ખરીદી શકાય છે. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 1, “ફુગાવો અને ખરીદશક્તિ”ની સમીક્ષા કરો.
