# Quiz – બિટકોઇનનો સુરક્ષિત ઉપયોગ: ટૂંકી કસોટી

## પ્રશ્ન 1

બિટકોઇન વૉલેટ:

* [ ] બિટકોઇન સંગ્રહે છે
* [x] કીઓનું સંચાલન કરે છે અને સહી કરે છે
* [ ] ગુપ્ત માહિતીનું રક્ષણ દૂર કરે છે
* [ ] વ્યવહારોને ઉલટાવે છે

### સમજૂતી

બિટકોઇનની નોંધ સહિયારા ખાતાવહીમાં રાખવામાં આવે છે; વૉલેટ તેને મેળવવા અને વાપરવા માટે જરૂરી માહિતીનું સંચાલન કરે છે. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 3, “વૉલેટ” ફરી જુઓ.

## પ્રશ્ન 2

બિટકોઇન મેળવવા માટે શું શેર કરવું:

* [ ] સીડ ફ્રેઝ
* [ ] ખાનગી કી
* [x] પ્રાપ્તિ સરનામું
* [ ] પાસવર્ડ

### સમજૂતી

ચુકવણી મેળવવા માટે પ્રાપ્તિ સરનામું શેર કરી શકાય છે. સીડ ફ્રેઝ, ખાનગી કીઓ અને પાસવર્ડ ગુપ્ત જ રાખવા જોઈએ. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 3, “સરનામાં” અને “કીઓ” ફરી જુઓ.

## પ્રશ્ન 3

સીડ ઑનલાઇન દાખલ કરી દીધું છે. હવે સૌથી સુરક્ષિત પગલું કયું?

* [ ] રાહ જુઓ
* [ ] તેને સહાયતા ટીમને મોકલો
* [x] નવું સીડ બનાવો, પછી ભંડોળ ખસેડો
* [ ] સીડનો ફરી ઉપયોગ કરો

### સમજૂતી

ઑનલાઇન દાખલ કરેલા સીડ ફ્રેઝની ગુપ્તતા ભંગ થઈ ગઈ છે એમ માનો. નવા સીડ સાથે નવું વૉલેટ બનાવો, પછી ગંતવ્યની ચકાસણી કર્યા બાદ જ ભંડોળ ખસેડો. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 3, “સીડ ફ્રેઝ” ફરી જુઓ.

## પ્રશ્ન 4

કસ્ટડીમાં શું તફાવત છે?

* [x] કીઓ પર કોનું નિયંત્રણ છે
* [ ] ચુકવણી ઉલટાવી શકવાની ક્ષમતા
* [ ] પુરવઠાની મર્યાદા
* [ ] જવાબદારી

### સમજૂતી

કસ્ટોડિયલ અને સ્વ-કસ્ટોડિયલ ઉપયોગ વચ્ચેનો તફાવત એ છે કે કીઓ પર કોનું નિયંત્રણ છે અને સંબંધિત જવાબદારી કોણ સંભાળે છે. બંનેમાંથી કોઈ પણ સુરક્ષા કે વ્યવહારો ઉલટાવી શકવાની ખાતરી આપતું નથી. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 3, “કસ્ટોડિયલ અને નોન-કસ્ટોડિયલ ઉપયોગ” ફરી જુઓ.
