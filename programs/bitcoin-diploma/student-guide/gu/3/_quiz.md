# Quiz – બિટકોઇનનો સુરક્ષિત ઉપયોગ: ટૂંકી કસોટી

## પ્રશ્ન 1

બિટકોઇન વૉલેટ:

* [ ] બિટકોઇન સંગ્રહે છે
* [x] કીઓનું સંચાલન કરે છે અને સહી કરે છે
* [ ] ગુપ્ત માહિતીનું રક્ષણ દૂર કરે છે
* [ ] વ્યવહારો ઉલટાવે છે

### સમજૂતી

બિટકોઇનની નોંધ સહિયારા ખાતાવહીમાં હોય છે; વૉલેટ તેને મેળવવા અને વાપરવા માટે જરૂરી માહિતીનું સંચાલન કરે છે. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 3, “વૉલેટ” ફરી વાંચો.

## પ્રશ્ન 2

બિટકોઇન મેળવવા માટે આ શેર કરો:

* [ ] સીડ ફ્રેઝ
* [ ] ખાનગી કી
* [x] પ્રાપ્તિ સરનામું
* [ ] પાસવર્ડ

### સમજૂતી

ચુકવણી મેળવવા માટે પ્રાપ્તિ સરનામું શેર કરી શકાય છે. સીડ ફ્રેઝ, ખાનગી કીઓ અને પાસવર્ડ ગુપ્ત જ રહેવા જોઈએ. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 3, “સરનામાં” અને “કીઓ” ફરી વાંચો.

## પ્રશ્ન 3

સીડ ઑનલાઇન દાખલ કરી છે. હવે સૌથી સુરક્ષિત પગલું કયું છે?

* [ ] રાહ જુઓ
* [ ] તેને સહાય ટીમને મોકલો
* [x] નવી સીડ બનાવો, પછી ભંડોળ ખસેડો
* [ ] સીડનો ફરીથી ઉપયોગ કરો

### સમજૂતી

ઑનલાઇન દાખલ કરેલી સીડ ફ્રેઝને અસુરક્ષિત થઈ ગયેલી માનો. નવી સીડ સાથે નવું વૉલેટ બનાવો, પછી ગંતવ્ય સરનામાની ચકાસણી કર્યા બાદ જ ભંડોળ ખસેડો. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 3, “સીડ ફ્રેઝ” ફરી વાંચો.

## પ્રશ્ન 4

કસ્ટોડિયલ અને સ્વ-કસ્ટોડિયલ ઉપયોગ વચ્ચે મુખ્ય તફાવત શું છે?

* [x] કીઓ પર નિયંત્રણ કોનું છે
* [ ] ચુકવણી ઉલટાવી શકવાની ક્ષમતા
* [ ] પુરવઠાની મર્યાદા
* [ ] વ્યવહારની ફી

### સમજૂતી

કસ્ટોડિયલ અને સ્વ-કસ્ટોડિયલ ઉપયોગ વચ્ચેનો તફાવત એ છે કે કીઓ પર નિયંત્રણ કોનું છે અને તેની સંબંધિત જવાબદારી કોણ વહન કરે છે. બંનેમાંથી કોઈ પણ સુરક્ષા કે વ્યવહારો ઉલટાવી શકવાની ખાતરી આપતું નથી. વિદ્યાર્થી માર્ગદર્શિકા, મોડ્યુલ 3, “કસ્ટોડિયલ અને નૉન-કસ્ટોડિયલ ઉપયોગ” ફરી વાંચો.
