# 4.9 Compromisuri între KYC și non-KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) și [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) sunt modalități care implică diferite [compromisuri](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Niciuna dintre aceste etichete nu elimină necesitatea unei evaluări atente.


<!-- card: callout -->
> **Confidențialitatea nu elimină riscurile juridice sau cele pentru siguranța fizică**
>
> Nici [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc), nici [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) nu este automat cea mai bună opțiune. Comparați modalitățile concrete, solicitați îndrumări locale actualizate când regulile sunt neclare și nu încălcați legislația locală și nu vă expuneți pericolelor fizice în căutarea [confidențialității](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Un serviciu [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) poate solicita numele legal, un act de identitate, adresa, o fotografie, informații despre proveniența fondurilor sau alte documente. Acest lucru îi poate permite serviciului să respecte regulile locale, să se conecteze la bănci, să stabilească limite mai mari sau să ofere asistență pentru recuperarea contului.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) creează și riscuri legate de date. Serviciul poate păstra o legătură permanentă între identitate, metodele de plată și [tranzacțiile cu bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). O breșă de securitate, o solicitare legală, utilizarea abuzivă la nivel intern sau o schimbare a politicii poate expune aceste informații sau poate restricționa accesul la ele.

O modalitate [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) poate colecta mai puține informații de identificare. Acest lucru poate îmbunătăți [confidențialitatea financiară](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). De asemenea, poate implica contrapărți mai puțin reglementate, lichiditate mai scăzută, [prețuri mai mari](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), asistență redusă, un risc mai mare de fraudă sau restricții legale.

Comparați modalitățile concrete:


| Întrebare | Modalitate KYC | Modalitate no-KYC |
| --- | --- | --- |
| Ce date de identificare sunt colectate? |  |  |
| Cine stochează datele și pentru cât timp? |  |  |
| Poate fi asociată tranzacția cu identitatea dumneavoastră pe blockchain? |  |  |
| Ce protecție împotriva fraudei există? |  |  |
| Ce risc de contraparte există? |  |  |
| Ce limite și comisioane se aplică? |  |  |
| Ce legislație locală se aplică? |  |  |
| Ce se întâmplă în cazul unui litigiu? |  |  |


[Confidențialitatea](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) nu înseamnă păstrarea secretului în fața oricărui risc. Este capacitatea de a controla informațiile despre dumneavoastră. Nu încălcați legislația locală și nu vă expuneți pericolelor fizice în căutarea [confidențialității](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Solicitați îndrumări locale actualizate de la o persoană calificată atunci când regulile sunt neclare.
