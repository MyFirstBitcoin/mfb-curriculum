# 3.8 Відновлення гаманця та перевірка seed-фрази

Що б ви зробили, якби початковий пристрій вийшов із ладу? План відновлення має давати змогу відновити потрібний гаманець, не розкриваючи даних для відновлення. Практикуйтеся лише з підготовленими викладачем, порожніми або імітаційними матеріалами. Скористайтеся офіційним способом відновлення гаманця без сторонніх, переконайтеся, що відновлено саме потрібний навчальний гаманець, і безпечно скиньте або поверніть тимчасові матеріали.

Викладач може спостерігати за вашими діями, не бачачи жодних [слів для відновлення](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase). Ніколи не вводьте справжню [фразу відновлення](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) на вебсайті, у повідомленні чи звичайній комп’ютерній формі.

Не використовуйте навчальний гаманець або його дані для відновлення для зберігання значних коштів після завершення курсу «Диплом із Біткоїна». Особистий гаманець, якщо ви вирішите створити його пізніше, потрібно налаштувати заново без сторонніх і створити для нього нові дані для відновлення.

Мета не в тому, щоб відновлення здавалося легким. Важливо зрозуміти цей процес до того, як вихід пристрою з ладу створить стресову ситуацію.
