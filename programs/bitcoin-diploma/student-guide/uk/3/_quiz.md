# Quiz – Безпечне використання Біткоїна: коротка перевірка

## Запитання 1

Біткоїн-гаманець:

* [ ] Зберігає біткоїни
* [x] Керує ключами та підписує
* [ ] Скасовує захист секретних даних
* [ ] Скасовує транзакції

### Пояснення

Біткоїн обліковується у спільному реєстрі; гаманець керує інформацією, потрібною для доступу до нього та його використання. Перегляньте розділ «Гаманці» модуля 3 посібника для учнів.

## Запитання 2

Що можна надати іншим для отримання біткоїнів?

* [ ] Сід-фразу
* [ ] Приватний ключ
* [x] Адресу для отримання
* [ ] Пароль

### Пояснення

Адресу для отримання можна надати для здійснення платежу. Сід-фрази, приватні ключі та паролі мають залишатися в таємниці. Перегляньте розділи «Адреси» та «Ключі» модуля 3 посібника для учнів.

## Запитання 3

Сід-фразу введено в інтернеті. Який наступний крок найбезпечніший?

* [ ] Зачекати
* [ ] Надіслати її службі підтримки
* [x] Створити нову сід-фразу, потім переказати кошти
* [ ] Повторно використати сід-фразу

### Пояснення

Вважайте сід-фразу, введену в інтернеті, скомпрометованою. Створіть новий гаманець із новою сід-фразою, а потім перекажіть кошти, попередньо перевіривши адресу призначення. Перегляньте розділ «Сід-фрази» модуля 3 посібника для учнів.

## Запитання 4

У чому різниця між кастодіальним і самостійним зберіганням?

* [x] Хто контролює ключі
* [ ] Можливість скасування платежів
* [ ] Обмеження пропозиції
* [ ] Відповідальність

### Пояснення

Кастодіальне та самостійне зберігання відрізняються тим, хто контролює ключі та несе пов’язану з цим відповідальність. Жоден із цих способів не гарантує безпеки чи можливості скасування транзакцій. Перегляньте розділ «Кастодіальне та некастодіальне використання» модуля 3 посібника для учнів.
