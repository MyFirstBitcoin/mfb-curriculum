# Quiz – Безпечне використання Біткоїна: коротка перевірка

## Запитання 1

Біткоїн-гаманець:

* [ ] Зберігає біткоїни
* [x] Керує ключами та підписує
* [ ] Скасовує захист секретних даних
* [ ] Скасовує транзакції

### Пояснення

Біткоїн обліковується у спільному реєстрі; гаманець керує інформацією, яка потрібна для доступу до нього та його використання. Перегляньте розділ «Гаманці» в модулі 3 посібника для учнів.

## Запитання 2

Що можна повідомити, щоб отримати біткоїни:

* [ ] Сід-фразу
* [ ] Приватний ключ
* [x] Адресу для отримання
* [ ] Пароль

### Пояснення

Адресу для отримання можна повідомити для приймання платежу. Сід-фрази, приватні ключі та паролі мають залишатися в таємниці. Перегляньте розділи «Адреси» та «Ключі» в модулі 3 посібника для учнів.

## Запитання 3

Сід-фразу введено в інтернеті. Який наступний крок найбезпечніший?

* [ ] Зачекати
* [ ] Надіслати її службі підтримки
* [x] Створити нову сід-фразу, а потім переказати кошти
* [ ] Повторно використати сід-фразу

### Пояснення

Вважайте сід-фразу, введену в інтернеті, скомпрометованою. Створіть новий гаманець із новою сід-фразою, а потім перекажіть кошти, обов’язково перевіривши адресу призначення. Перегляньте розділ «Сід-фрази» в модулі 3 посібника для учнів.

## Запитання 4

У чому головна відмінність між кастодіальним використанням і самостійним зберіганням?

* [x] Хто контролює ключі
* [ ] Можливість скасування платежів
* [ ] Обмеження пропозиції
* [ ] Комісії за транзакції

### Пояснення

Кастодіальне використання та самостійне зберігання відрізняються тим, хто контролює ключі та несе пов’язану з цим відповідальність. Жоден із цих способів не гарантує безпеки чи можливості скасування транзакцій. Перегляньте розділ «Кастодіальне та некастодіальне використання» в модулі 3 посібника для учнів.
