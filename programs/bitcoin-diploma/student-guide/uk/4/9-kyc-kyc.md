# 4.9 Компроміси між KYC та відсутністю KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) та [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) підходи передбачають різні [компроміси](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Жодна з цих позначок не скасовує потреби в ретельному оцінюванні.


<!-- card: callout -->
> **Приватність не усуває правових ризиків чи загроз фізичній безпеці**
>
> Ні [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc), ні [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) не є автоматично найкращим варіантом. Порівнюйте конкретні способи дій, користуйтеся актуальними місцевими рекомендаціями, коли правила незрозумілі, і не порушуйте місцевого законодавства та не наражайте себе на фізичну небезпеку заради [приватності](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Сервіс із [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) може запитувати офіційне ім’я, документ, що посвідчує особу, адресу, фотографію, відомості про джерело коштів або інші дані. Це може давати сервісу змогу дотримуватися місцевих правил, взаємодіяти з банками, встановлювати вищі ліміти або забезпечувати відновлення доступу до облікового запису.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) також створює ризики для даних. Сервіс може зберігати постійний зв’язок між особою, способами оплати та біткоїновими [транзакціями](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Витік даних, запит на правових підставах, внутрішні зловживання або зміна політики можуть призвести до розкриття цієї інформації чи обмеження доступу до неї.

Підхід [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) може передбачати збирання меншого обсягу ідентифікаційних даних. Це може покращити фінансову [приватність](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Він також може передбачати взаємодію з менш регульованими контрагентами, нижчу ліквідність, вищі [ціни](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), меншу підтримку, більший ризик шахрайства або правові обмеження.

Порівняйте конкретні способи дій:


| Запитання | Підхід із KYC | Підхід без KYC |
| --- | --- | --- |
| Які ідентифікаційні дані збирають? |  |  |
| Хто зберігає дані й протягом якого часу? |  |  |
| Чи можна встановити зв’язок із транзакцією за даними блокчейну? |  |  |
| Який захист від шахрайства передбачено? |  |  |
| Який ризик пов’язаний із контрагентом? |  |  |
| Які ліміти та комісії діють? |  |  |
| Яке місцеве законодавство застосовується? |  |  |
| Що відбувається в разі спору? |  |  |


[Приватність](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) — це не приховування інформації від усіх можливих загроз. Це здатність контролювати інформацію про себе. Не порушуйте місцевого законодавства та не наражайте себе на фізичну небезпеку заради [приватності](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Коли правила незрозумілі, звертайтеся до кваліфікованого фахівця по актуальні рекомендації щодо місцевих вимог.
