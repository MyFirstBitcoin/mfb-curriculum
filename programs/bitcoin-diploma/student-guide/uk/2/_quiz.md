# Quiz – Як працює Біткоїн: коротка перевірка знань

## Запитання 1

Одну цифрову одиницю витрачають двічі. Система має:

* [x] Відхилити подвійне витрачання
* [ ] Приховати платіж
* [ ] Підвищити її ціну
* [ ] Скасувати комісії

### Пояснення

Цифрову інформацію можна копіювати, тому грошова система має запобігати повторному витрачанню тієї самої одиниці та визначати, яка транзакція є дійсною. Перегляньте посібник для учнів, модуль 2, «Перші спроби створення цифрових грошей і проблема подвійного витрачання».

## Запитання 2

Децентралізація Біткоїна означає:

* [ ] Одна компанія схвалює платежі
* [x] Незалежне забезпечення дотримання правил
* [ ] Майнери вільно змінюють правила
* [ ] Однаковий вплив для всіх

### Пояснення

Біткоїн розподіляє перевірку та забезпечення дотримання правил між незалежними учасниками. Децентралізація не означає, що одна компанія контролює мережу або що всі мають однаковий вплив. Перегляньте посібник для учнів, модуль 2, «Децентралізація».

## Запитання 3

Вузол Біткоїна:

* [x] Перевіряє дотримання правил мережі
* [ ] Створює біткоїни
* [ ] Зберігає біткоїни
* [ ] Гарантує платіж

### Пояснення

Вузли незалежно перевіряють дотримання правил Біткоїна та відхиляють недійсні дані. Вони не створюють біткоїни на запит і не зберігають біткоїни всередині телефона. Перегляньте посібник для учнів, модуль 2, «Користувачі, вузли та майнери».

## Запитання 4

Чому Біткоїн називають надійними грошима?

* [ ] Ціна завжди зростає
* [x] Відкриті правила та обмежена пропозиція
* [ ] Його контролює одна компанія
* [ ] Платежі конфіденційні

### Пояснення

Дехто називає Біткоїн надійними грошима, тому що правила його пропозиції є відкритими, а емісія — обмеженою. Це обґрунтоване судження, а не обіцянка щодо ціни чи конфіденційності. Перегляньте посібник для учнів, модуль 2, «Біткоїн як надійні цифрові гроші».
