# 4.9 KYC und No-KYC: Vor- und Nachteile

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)- und [No-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)-Wege gehen unterschiedliche [Kompromisse](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off) ein. Keine der beiden Bezeichnungen macht eine sorgfältige Prüfung überflüssig.


<!-- card: callout -->
> **Privatsphäre beseitigt keine rechtlichen Risiken und keine Risiken für die körperliche Sicherheit**
>
> Weder [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) noch [No-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ist automatisch die beste Wahl. Vergleichen Sie den tatsächlichen Weg, ziehen Sie aktuelle lokale Orientierungshilfen heran, wenn die Regeln unklar sind, und verstoßen Sie weder gegen geltendes Recht, noch bringen Sie sich in körperliche Gefahr, um Ihre [Privatsphäre](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) zu schützen.


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Ein [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)-Dienst kann den amtlichen Namen, ein Ausweisdokument, die Adresse, ein Foto, Angaben zur Herkunft der Mittel oder andere Unterlagen verlangen. Dadurch kann der Dienst lokale Vorschriften erfüllen, mit Banken zusammenarbeiten, höhere Limits festlegen oder die Wiederherstellung von Konten unterstützen.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) birgt zudem Datenrisiken. Der Dienst kann eine dauerhafte Verknüpfung zwischen Identität, Zahlungsmethoden und Bitcoin-[Transaktionen](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) speichern. Ein Datenleck, eine behördliche Anfrage, interner Missbrauch oder eine Änderung der Richtlinien können diese Informationen offenlegen oder den Zugang dazu einschränken.

Ein [No-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)-Weg erfasst möglicherweise weniger Identitätsdaten. Dies kann die finanzielle [Privatsphäre](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) verbessern. Er kann jedoch auch mit weniger regulierten Gegenparteien, geringerer Liquidität, höheren [Preisen](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), eingeschränktem Support, größerem Betrugsrisiko oder rechtlichen Einschränkungen verbunden sein.

Vergleichen Sie den tatsächlichen Weg:


| Frage | KYC-Weg | No-KYC-Weg |
| --- | --- | --- |
| Welche Identitätsdaten werden erfasst? |  |  |
| Wer speichert die Daten und wie lange? |  |  |
| Kann die Transaktion on-chain verknüpft werden? |  |  |
| Welcher Schutz vor Betrug besteht? |  |  |
| Welches Gegenparteirisiko besteht? |  |  |
| Welche Limits und Gebühren gelten? |  |  |
| Welches lokale Recht gilt? |  |  |
| Was geschieht im Streitfall? |  |  |


[Privatsphäre](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) bedeutet nicht Schutz vor jedem Risiko. Sie ist die Fähigkeit, Informationen über sich selbst zu kontrollieren. Verstoßen Sie weder gegen geltendes Recht, noch bringen Sie sich in körperliche Gefahr, um Ihre [Privatsphäre](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) zu schützen. Holen Sie aktuellen Rat bei einer qualifizierten Person vor Ort ein, wenn die Regeln unklar sind.
