# 3.5 Seed-Phrasen

> **Definition – Seed-Phrase**
>
> Eine [Seed-Phrase](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase), auch [Wiederherstellungsphrase](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) genannt, ist eine geordnete Liste von Wörtern, mit der viele Wallets eine Reihe von [Privaten Schlüsseln](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) ableiten und wiederherstellen. Ein [Privater Schlüssel](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) autorisiert eine Ausgabe; die [Seed-Phrase](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) ist normalerweise die Sicherung, mit der sich die Schlüssel der Wallet neu erstellen lassen. Übliche Längen sind 12 oder 24 Wörter, wobei sich die Wallet-Designs unterscheiden.


Reihenfolge und Schreibweise der Wörter sind wichtig. Wer die [Seed-Phrase](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) besitzt, kann die Wallet oft auf einem anderen kompatiblen Gerät wiederherstellen und die Mittel ausgeben. Die [Seed-Phrase](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) ist daher nicht nur eine Sicherung. Sie bedeutet vollen Zugriff.


> **Callout – Geben Sie niemals Wiederherstellungsinformationen weiter**
>
> Öffentliche Empfangsinformationen dürfen geteilt werden. Ein [Privater Schlüssel](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key), eine [Seed-Phrase](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase), ein Passwort oder ein Wiederherstellungscode müssen geheim bleiben. Keine seriöse Lehrkraft, kein Wallet-Unternehmen, kein Mitarbeiter einer Börse, kein Support-Mitarbeiter und kein Bitcoin-Entwickler benötigt sie. Falls eine [Seed-Phrase](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) gesehen, kopiert, online eingegeben oder auf einem nicht vertrauenswürdigen Gerät gespeichert worden sein könnte, behandeln Sie sie als kompromittiert und holen Sie sich Hilfe, ohne sie preiszugeben.

Schützen Sie eine [Seed-Phrase](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) mit diesen Regeln:

* Schreiben Sie sie bei der Erstellung der Wallet unbeobachtet und genau auf
* Befolgen Sie die offiziellen Sicherungsanweisungen der Wallet
* Bewahren Sie sie offline auf
* Fotografieren Sie sie niemals, speichern Sie sie nicht in Cloud-Notizen, verschicken Sie sie nicht per E-Mail und senden Sie sie nicht in einer Nachricht
* Geben Sie sie niemals auf einer Website oder in ein gewöhnliches Computerformular ein
* Halten Sie sie von Kameras, Mikrofonen und den Blicken anderer Menschen fern sowie von Orten, an denen sie beschädigt werden, verloren gehen oder gefunden werden könnte

Manche Wallets verwenden zusätzliche Passphrasen, mehrere Schlüssel oder andere Sicherungssysteme. Diese gehören zum Bereich [Fortgeschrittenes Lernen](https://curriculum.myfirstbitcoin.org/programs/advanced-modules/). Fügen Sie keine Komplexität hinzu, die Sie nicht erklären und aus der Sie nicht sicher wiederherstellen können. Falls eine [Seed-Phrase](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) gesehen, kopiert, online eingegeben oder auf einem nicht vertrauenswürdigen Gerät gespeichert worden sein könnte, behandeln Sie sie als kompromittiert: Holen Sie sich Rat, ohne sie preiszugeben, und nutzen Sie einen neuen, vertrauenswürdigen Wiederherstellungsprozess.
