# 3.3 Adressen

> **Definition – Bitcoin-Adresse**
>
> Eine [Bitcoin-Adresse](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-address) ist eine öffentliche Empfangsinformation für eine [On-Chain-Zahlung](https://curriculum.myfirstbitcoin.org/lexicon/en/#on-chain-payment). Eine Wallet zeigt sie normalerweise als Text und als QR-Code an, damit eine andere Person Ihnen bitcoin zusenden kann. Anders als ein Passwort oder ein [privater Schlüssel](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) kann eine Adresse keine Ausgaben autorisieren.



<!-- micrographic: address-two-formats-01 -->


Wenn Sie eine [On-Chain-Zahlung](https://curriculum.myfirstbitcoin.org/lexicon/en/#on-chain-payment) empfangen möchten, woher sollte die Adresse stammen? Öffnen Sie die vorgesehene Wallet und verwenden Sie deren Empfangsbildschirm. Eine sendende Person kann den QR-Code scannen oder die Adresse kopieren. So vermeiden Sie Fehler, die beim Abtippen langer Zeichenfolgen von Hand entstehen können.

Bestätigen Sie bei jeder Zahlungsanforderung die vorgesehene Zahlungsmethode. Eine On-Chain-Adresse und eine [Lightning-Rechnung](https://curriculum.myfirstbitcoin.org/lexicon/en/#lightning-invoice) sind verschiedene Dinge. Vergleichen Sie nach dem Scannen oder Kopieren das Ziel mit dem vertrauenswürdigen Empfangsbildschirm, bevor Sie eine Zahlung freigeben. Warum sollten Sie nach dem Kopieren prüfen? Schadsoftware kann kopierte Adressinformationen ersetzen. Eine neue On-Chain-Adresse für jeden neuen Zahlungseingang kann die [Privatsphäre](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) verbessern. Die Wiederverwendung einer Adresse kann es anderen erleichtern, getrennte Zahlungen miteinander in Verbindung zu bringen. Eine neue Adresse erschwert diese einfache Verknüpfung; sie macht eine Zahlung jedoch nicht anonym.


<!-- micrographic: sample-lightning-invoice-01 -->



> **Light**
>
> Wenn es auf eine Zahlung ankommt, halten Sie eine Adresse nicht allein deshalb für sicher, weil sie Ihnen vertraut vorkommt. Bestätigen Sie den vorgesehenen Empfänger, das richtige [Bitcoin-Netzwerk](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-network), das Ziel und die Zahlungsmethode. Führen Sie zunächst einen kleinen Test durch, wenn Ihnen der Ablauf oder der Betrag ungewohnt ist.
