# 3.12 Sicherheits-Checkliste

**Übung 3: Ein Risiko erkennen und sicher stoppen**

Was würde Sie vor einer Zahlung oder Installation innehalten lassen? Betrachten Sie Folgendes als Warnsignale: Jemand gibt sich als Support oder Lehrkraft aus; erzeugt Zeitdruck oder verlangt Geheimhaltung; verspricht garantierte Renditen; fordert Sie auf, zuerst bitcoin zu senden; ändert ein Zahlungsziel; oder verlangt Schlüssel, [Wiederherstellungswörter](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase), Fernzugriff oder eine Vorabgebühr.


<!-- micrographic: scam-red-flags-01 -->


Die sichere Reaktion lautet immer: **Innehalten. Nichts preisgeben. Nichts senden. Den Kommunikationskanal schließen. Unabhängig über eine bekannte Quelle überprüfen. Um Hilfe bitten, ohne Geheimnisse preiszugeben.** Eine bekannte Quelle ist eine offizielle Website, ein App-Store-Eintrag oder ein Kontaktweg, den Sie selbstständig aufgerufen haben – nicht über eine Werbeanzeige, eine Direktnachricht oder einen unerwarteten Link. Prüfen Sie den Herausgeber und die Webadresse, vergleichen Sie sie mit der offiziellen Dokumentation und suchen Sie Kontaktdaten separat heraus. Wenn die Quelle, die Anweisungen oder die Zahlungsdaten vom vorgeführten Ablauf abweichen, halten Sie inne und holen Sie sich Hilfe bei Ihrer Lehrkraft oder einer vertrauenswürdigen Anlaufstelle vor Ort, ohne eine [Seed-Phrase](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) oder einen [privaten Schlüssel](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) preiszugeben. Eine echte Gelegenheit hält einer sorgfältigen Prüfung stand; ein Betrug ist oft darauf angewiesen, eine solche zu verhindern.

Schützen Sie Ihre Wiederherstellungsinformationen: Eine [Seed-Phrase](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) kann die [privaten Schlüssel](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) einer Wallet wiederherstellen. Bewahren Sie sie offline und vor fremden Blicken geschützt auf. Überprüfen Sie Zahlungsziele, indem Sie nach dem Kopieren oder Scannen die Zahlungsmethode, den Empfänger, die Adresse oder Rechnung, den Betrag und den abschließenden Bildschirm kontrollieren. Verwenden Sie für jede Wallet und jeden Dienst offizielle Anleitungen und eine überprüfte Quelle; seien Sie vorsichtig bei gesponserten Suchergebnissen, Links in Direktnachrichten und täuschend ähnlichen Websites. Beginnen Sie mit sicherem Üben, einer Simulation oder einem kleinen, freigegebenen Betrag; leihen Sie sich niemals Geld, um zu experimentieren.

**Probieren Sie es aus:** Identifizieren Sie in einer vorbereiteten Nachricht oder auf einem Zahlungsbildschirm das Warnsignal, was verloren gehen könnte, und den ersten sicheren Schritt.
