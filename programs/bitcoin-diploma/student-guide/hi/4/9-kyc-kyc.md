# 4.9 KYC और बिना KYC के विकल्पों के लाभ और हानियाँ

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) और [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) के तरीकों में अलग-अलग [लाभ-हानि संबंधी समझौते करने पड़ते हैं](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)। इनमें से कोई भी नाम सावधानीपूर्वक मूल्यांकन की आवश्यकता को समाप्त नहीं करता।


<!-- card: callout -->
> **निजता से कानूनी या शारीरिक सुरक्षा संबंधी जोखिम समाप्त नहीं होते**
>
> न तो [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) और न ही [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) अपने-आप में सर्वोत्तम है। वास्तविक तरीके की तुलना करें, नियम अस्पष्ट होने पर मौजूदा स्थानीय मार्गदर्शन लें, और स्थानीय कानून न तोड़ें या स्वयं को शारीरिक खतरे में न डालें, भले ही आपका उद्देश्य हो [निजता](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)।


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

एक [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) सेवा कानूनी नाम, पहचान दस्तावेज़, पता, तस्वीर, धन के स्रोत की जानकारी या अन्य अभिलेख माँग सकती है। इससे सेवा को स्थानीय नियमों का पालन करने, बैंकों से जुड़ने, अधिक ऊँची सीमाएँ तय करने या खाते की पुनर्प्राप्ति में सहायता देने की सुविधा मिल सकती है।

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) से डेटा संबंधी जोखिम भी पैदा होता है। सेवा इन सबके बीच स्थायी संबंध का रिकॉर्ड रख सकती है: पहचान, भुगतान के तरीके और बिटकॉइन [लेन-देन](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction)। डेटा में सेंध, कानूनी अनुरोध, आंतरिक दुरुपयोग या नीति में बदलाव से वह जानकारी उजागर हो सकती है या उस तक पहुँच सीमित हो सकती है।

एक [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) तरीका पहचान संबंधी कम जानकारी एकत्र कर सकता है। इससे बेहतर हो सकती है वित्तीय [निजता](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)। इसमें कम विनियमित प्रतिपक्ष, कम तरलता, अधिक [कीमतें](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), कम सहायता, धोखाधड़ी का अधिक जोखिम या कानूनी प्रतिबंध भी शामिल हो सकते हैं।

वास्तविक तरीके की तुलना करें:


| प्रश्न | KYC तरीका | No-KYC तरीका |
| --- | --- | --- |
| पहचान संबंधी कौन-सा डेटा एकत्र किया जाता है? |  |  |
| डेटा कौन संग्रहीत करता है और कितने समय तक? |  |  |
| क्या लेन-देन को ऑन-चेन जोड़ा जा सकता है? |  |  |
| धोखाधड़ी से बचाव के क्या उपाय हैं? |  |  |
| प्रतिपक्ष से जुड़ा क्या जोखिम है? |  |  |
| कौन-सी सीमाएँ और शुल्क लागू होते हैं? |  |  |
| कौन-सा स्थानीय कानून लागू होता है? |  |  |
| विवाद होने पर क्या होता है? |  |  |


[निजता](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) का अर्थ हर जोखिम से छिपे रहना नहीं है। यह अपने बारे में जानकारी को नियंत्रित करने की क्षमता है। स्थानीय कानून न तोड़ें या स्वयं को शारीरिक खतरे में न डालें, भले ही आपका उद्देश्य हो [निजता](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)। नियम अस्पष्ट होने पर किसी योग्य व्यक्ति से मौजूदा स्थानीय मार्गदर्शन लें।
