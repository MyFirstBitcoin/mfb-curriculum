# Quiz – ბიტკოინის უსაფრთხოდ გამოყენება: მოკლე შემოწმება

## Question 1

ბიტკოინის საფულე:

* [ ] ინახავს ბიტკოინს
* [x] მართავს გასაღებებს და ხელს აწერს
* [ ] აუქმებს საიდუმლო ინფორმაციის დაცვას
* [ ] აუქმებს ტრანზაქციებს

### Explanation

ბიტკოინი აღირიცხება საერთო რეესტრში; საფულე მართავს მასზე წვდომისა და მისი გამოყენებისთვის საჭირო ინფორმაციას. გადახედეთ სტუდენტის სახელმძღვანელოს, მოდული 3, „საფულეები“.

## Question 2

ბიტკოინის მისაღებად გააზიარეთ:

* [ ] აღდგენის ფრაზა
* [ ] პირადი გასაღები
* [x] მიღების მისამართი
* [ ] პაროლი

### Explanation

გადახდის მისაღებად შეგიძლიათ მიღების მისამართის გაზიარება. აღდგენის ფრაზები, პირადი გასაღებები და პაროლები საიდუმლოდ უნდა დარჩეს. გადახედეთ სტუდენტის სახელმძღვანელოს, მოდული 3, „მისამართები“ და „გასაღებები“.

## Question 3

აღდგენის ფრაზა ონლაინ შეიყვანეთ. რომელია ყველაზე უსაფრთხო შემდეგი ნაბიჯი?

* [ ] დაელოდეთ
* [ ] გაუგზავნეთ ის მხარდაჭერის სამსახურს
* [x] შექმენით ახალი აღდგენის ფრაზა, შემდეგ გადაიტანეთ თანხა
* [ ] ხელახლა გამოიყენეთ იგივე აღდგენის ფრაზა

### Explanation

ონლაინ შეყვანილი აღდგენის ფრაზა გამჟღავნებულად მიიჩნიეთ. შექმენით ახალი საფულე ახალი აღდგენის ფრაზით, შემდეგ კი თანხა მხოლოდ მიმღების მისამართის გადამოწმების შემდეგ გადაიტანეთ. გადახედეთ სტუდენტის სახელმძღვანელოს, მოდული 3, „აღდგენის ფრაზები“.

## Question 4

რა განსხვავებაა კასტოდიურ და თვითკასტოდიურ გამოყენებას შორის?

* [x] ვინ აკონტროლებს გასაღებებს
* [ ] გადახდის გაუქმების შესაძლებლობა
* [ ] მიწოდების ზღვარი
* [ ] პასუხისმგებლობა

### Explanation

კასტოდიური და თვითკასტოდიური გამოყენება განსხვავდება იმით, თუ ვინ აკონტროლებს გასაღებებს და ვინ იღებს შესაბამის პასუხისმგებლობას. არცერთი არ იძლევა უსაფრთხოების ან ტრანზაქციის გაუქმების გარანტიას. გადახედეთ სტუდენტის სახელმძღვანელოს, მოდული 3, „კასტოდიური და არაკასტოდიური გამოყენება“.
