# Quiz – ბიტკოინის უსაფრთხოდ გამოყენება: მოკლე შემოწმება

## კითხვა 1

ბიტკოინის საფულე:

* [ ] ინახავს ბიტკოინს
* [x] მართავს გასაღებებს და ქმნის ხელმოწერებს
* [ ] ხსნის საიდუმლო ინფორმაციის დაცვას
* [ ] აუქმებს ტრანზაქციებს

### ახსნა

ბიტკოინი აღირიცხება საერთო რეესტრში; საფულე მართავს მასზე წვდომისა და მისი გამოყენებისთვის საჭირო ინფორმაციას. გადახედეთ სტუდენტის სახელმძღვანელოს, მოდულს 3, „საფულეები“.

## კითხვა 2

ბიტკოინის მისაღებად გააზიარეთ:

* [ ] აღდგენის ფრაზა
* [ ] პირადი გასაღები
* [x] მიღების მისამართი
* [ ] პაროლი

### ახსნა

გადახდის მისაღებად შეგიძლიათ მიღების მისამართის გაზიარება. აღდგენის ფრაზები, პირადი გასაღებები და პაროლები საიდუმლოდ უნდა დარჩეს. გადახედეთ სტუდენტის სახელმძღვანელოს, მოდულს 3, „მისამართები“ და „გასაღებები“.

## კითხვა 3

აღდგენის ფრაზა ონლაინ შეიყვანეთ. რომელია ყველაზე უსაფრთხო შემდეგი ნაბიჯი?

* [ ] დაელოდეთ
* [ ] გაუგზავნეთ ის მხარდაჭერის სამსახურს
* [x] შექმენით ახალი აღდგენის ფრაზა, შემდეგ გადაიტანეთ თანხები
* [ ] ხელახლა გამოიყენეთ იგივე აღდგენის ფრაზა

### ახსნა

ონლაინ შეყვანილი აღდგენის ფრაზა გამჟღავნებულად მიიჩნიეთ. შექმენით ახალი საფულე ახალი აღდგენის ფრაზით, შემდეგ კი თანხები მხოლოდ მიმღების მისამართის გადამოწმების შემდეგ გადაიტანეთ. გადახედეთ სტუდენტის სახელმძღვანელოს, მოდულს 3, „აღდგენის ფრაზები“.

## კითხვა 4

რა არის მთავარი განსხვავება კასტოდიურ და თვითკასტოდიურ გამოყენებას შორის?

* [x] ვინ აკონტროლებს გასაღებებს
* [ ] გადახდების გაუქმების შესაძლებლობა
* [ ] მიწოდების ლიმიტი
* [ ] ტრანზაქციის საკომისიოები

### ახსნა

კასტოდიური და თვითკასტოდიური გამოყენება განსხვავდება იმით, თუ ვინ აკონტროლებს გასაღებებს და ვის ეკისრება შესაბამისი პასუხისმგებლობა. არცერთი არ იძლევა უსაფრთხოების ან ტრანზაქციების გაუქმების გარანტიას. გადახედეთ სტუდენტის სახელმძღვანელოს, მოდულს 3, „კასტოდიური და არაკასტოდიური გამოყენება“.
