# 4.9 KYC-ის გამოყენებისა და გამოუყენებლობის დადებითი და უარყოფითი მხარეები

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) და [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) გზები განსხვავებულ [კომპრომისებს მოითხოვს](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). არცერთი სახელწოდება არ გამორიცხავს გულდასმით შეფასების საჭიროებას.


<!-- card: callout -->
> **კონფიდენციალურობა არ გამორიცხავს სამართლებრივ ან ფიზიკური უსაფრთხოების რისკებს**
>
> არც [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) და არც [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) არ არის ავტომატურად საუკეთესო არჩევანი. შეადარეთ კონკრეტული გზები, თუ წესები გაურკვეველია, იხელმძღვანელეთ მოქმედი ადგილობრივი რეკომენდაციებით და ნუ დაარღვევთ ადგილობრივ კანონმდებლობას ან ნუ ჩაიგდებთ თავს ფიზიკურ საფრთხეში, მაშინაც კი, თუ თქვენი მიზანია [კონფიდენციალურობის დაცვა](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

ერთმა [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) სერვისმა შეიძლება მოითხოვოს ოფიციალური სახელი და გვარი, პირადობის დამადასტურებელი დოკუმენტი, მისამართი, ფოტოსურათი, ინფორმაცია თანხების წარმომავლობის შესახებ ან სხვა ჩანაწერები. ეს შეიძლება სერვისს დაეხმაროს ადგილობრივი წესების დაცვაში, ბანკებთან დაკავშირებაში, უფრო მაღალი ლიმიტების დაწესებაში ან ანგარიშის აღდგენის უზრუნველყოფაში.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ასევე ქმნის მონაცემებთან დაკავშირებულ რისკს. სერვისმა შეიძლება შეინახოს მუდმივი კავშირი პირადობის მონაცემებს, გადახდის მეთოდებსა და ბიტკოინის [ტრანზაქციებს შორის](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). მონაცემთა გაჟონვამ, სამართლებრივმა მოთხოვნამ, შიდა ბოროტად გამოყენებამ ან პოლიტიკის ცვლილებამ შეიძლება გამოიწვიოს ამ ინფორმაციის გამჟღავნება ან მასზე წვდომის შეზღუდვა.

ერთმა [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) გზამ შეიძლება ნაკლები პირადობის მონაცემები შეაგროვოს. ამან შეიძლება გააუმჯობესოს ფინანსური [კონფიდენციალურობა](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). ამ გზას ასევე შეიძლება ახლდეს ნაკლებად რეგულირებული კონტრაგენტები, დაბალი ლიკვიდურობა, უფრო მაღალი [ფასები](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), ნაკლები მხარდაჭერა, თაღლითობის უფრო მაღალი რისკი ან სამართლებრივი შეზღუდვები.

შეადარეთ კონკრეტული გზები:


| კითხვა | KYC გზა | No-KYC გზა |
| --- | --- | --- |
| პირადობის რომელი მონაცემები გროვდება? |  |  |
| ვინ ინახავს მონაცემებს და რამდენი ხნით? |  |  |
| შესაძლებელია თუ არა ტრანზაქციის დაკავშირება სხვა მონაცემებთან ბლოკჩეინზე? |  |  |
| თაღლითობისგან დაცვის რა მექანიზმები არსებობს? |  |  |
| კონტრაგენტთან დაკავშირებული რა რისკები არსებობს? |  |  |
| რა ლიმიტები და საკომისიოები მოქმედებს? |  |  |
| რომელი ადგილობრივი კანონმდებლობა ვრცელდება? |  |  |
| რა ხდება დავის შემთხვევაში? |  |  |


[კონფიდენციალურობა](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) არ ნიშნავს საიდუმლოების შენარჩუნებას ყველა რისკის წინაშე. ეს არის საკუთარი თავის შესახებ ინფორმაციის კონტროლის შესაძლებლობა. ნუ დაარღვევთ ადგილობრივ კანონმდებლობას ან ნუ ჩაიგდებთ თავს ფიზიკურ საფრთხეში, მაშინაც კი, თუ თქვენი მიზანია [კონფიდენციალურობის დაცვა](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). თუ წესები გაურკვეველია, მიმართეთ კვალიფიციურ პირს მოქმედი ადგილობრივი რეკომენდაციებისთვის.
