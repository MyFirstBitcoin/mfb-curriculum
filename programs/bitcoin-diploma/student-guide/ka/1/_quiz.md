# Quiz – ფულის გააზრება: ცოდნის მოკლე შემოწმება

## Question 1

რატომ იღებენ ფულს?

* [x] მოსალოდნელია, რომ მას სხვებიც მიიღებენ
* [ ] ის საქონელს თანაბარ ღირებულებას ანიჭებს
* [ ] ის ყველა წესს აუქმებს
* [ ] ის მომსახურებას საქონლად აქცევს

### Explanation

ფული უცნობ ადამიანებს დროში გაცვლის კოორდინირებაში ეხმარება, რადგან ისინი ელიან, რომ მას მოგვიანებით სხვებიც მიიღებენ. ფული კვლავ ნდობაზე, წესებსა და საზოგადოების მიერ მის აღიარებაზეა დამოკიდებული. გადახედეთ სტუდენტის გზამკვლევის მოდულ 1-ს, „რატომ არსებობს ფული“.

## Question 2

ფასის განსაზღვრა, გადახდა, დაზოგვა: რომელ ფუნქციებს შეესაბამება?

* [ ] ღირებულების შენახვა; საანგარიშო ერთეული; გაცვლის საშუალება
* [x] საანგარიშო ერთეული; გაცვლის საშუალება; ღირებულების შენახვა
* [ ] გაცვლის საშუალება; ღირებულების შენახვა; საანგარიშო ერთეული
* [ ] შეზღუდული რაოდენობა; შეზღუდული რაოდენობა; შეზღუდული რაოდენობა

### Explanation

ფასები საანგარიშო ერთეულით გამოიხატება, გაცვლის საშუალებას გადახდისას იღებენ, ხოლო ღირებულების შენახვის საშუალება ღირებულებას მომავლისთვის ინარჩუნებს. გადახედეთ სტუდენტის გზამკვლევის მოდულ 1-ს, „ფულის ფუნქციები და თვისებები“.

## Question 3

ბრინჯი ფეხსაცმელში ვერ იცვლება: რატომ?

* [ ] ფასები განსხვავდება
* [x] სურვილები ერთმანეთს არ ემთხვევა
* [ ] ბანკის თანხმობა არ არის
* [ ] ბრინჯის გაცვლა შეუძლებელია

### Explanation

პირდაპირი ბარტერი რთულია, როდესაც ორივე ადამიანს ერთდროულად არ სურს ის, რასაც მეორე სთავაზობს. ამას სურვილების ორმაგი დამთხვევის პრობლემა ეწოდება. გადახედეთ სტუდენტის გზამკვლევის მოდულ 1-ს, „ბარტერი და სურვილების ორმაგი დამთხვევა“.

## Question 4

ფასები +10%, შემოსავალი +5%: რა ემართება მსყიდველუნარიანობას?

* [ ] იზრდება
* [ ] უცვლელი რჩება
* [x] მცირდება
* [ ] განსაზღვრა შეუძლებელია

### Explanation

მსყიდველუნარიანობა გვიჩვენებს, რისი შეძენა შეიძლება ფულით. თუ ფასები შემოსავალზე სწრაფად იზრდება, ამ შემოსავლით ნაკლების შეძენაა შესაძლებელი. გადახედეთ სტუდენტის გზამკვლევის მოდულ 1-ს, „ინფლაცია და მსყიდველუნარიანობა“.
