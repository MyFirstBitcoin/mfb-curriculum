# 2.13 ბიტკოინი, როგორც მყარი ციფრული ფული

როგორც **1-ელ მოდულში** აღინიშნა, [**მყარი ფული**](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money) აღნიშნავს ფულს, რომლის მიწოდების გაზრდა რთულია და რომლის თვისებებიც დროთა განმავლობაში მის საიმედო გამოყენებას უწყობს ხელს. ეს ტერმინი კრიტერიუმებზე დაფუძნებულ შეფასებას გამოხატავს, ამიტომ ის უნდა განვიხილოთ და არა უბრალოდ იარლიყად მივიღოთ.

ბიტკოინი აერთიანებს თვისებებს, რომლებიც მანამდე ერთად არ არსებობდა ერთ [აქტივში](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset):

[ბიტკოინი ფულის შვიდ თვისებას ერთ აქტივში აერთიანებს: გამძლეობას, პორტაბელურობას, დაყოფადობას, ურთიერთჩანაცვლებადობას, შეზღუდულობას, შემოწმებადობასა და მიღებადობას. თითოეულ მათგანს პრაქტიკული შეზღუდვები აქვს, როგორიცაა გასაღებების უსაფრთხოდ შენახვის აუცილებლობა და მიღების დონე, რომელიც ბევრ საზოგადოებაში ჯერ კიდევ დაბალია.](/micrographics/bitcoin-money-properties-01/ka.md)



| თვისება | ახსნა მარტივი ენით |
| --- | --- |
| გამძლეობა | რეესტრის ასლები მრავალ კვანძზე ინახება. წვდომა მოქმედი გასაღებების შენარჩუნებაზეა დამოკიდებული. |
| გადატანის სიმარტივე | ხელმოწერილი ტრანზაქციით შესაძლებელია ღირებულების გადაცემა საკომუნიკაციო ქსელის მეშვეობით. |
| დაყოფადობა | ერთი ბიტკოინი (1 BTC) იყოფა 100 000 000 სატოშად. |
| ურთიერთჩანაცვლებადობა | თანაბარი ოდენობების დახარჯვა პროტოკოლის ერთნაირი წესებით არის შესაძლებელი, თუმცა ტრანზაქციების საჯარო ისტორიამ შეიძლება გავლენა მოახდინოს იმაზე, თუ როგორ ეპყრობა ზოგიერთი სერვისი კონკრეტულ სახსრებს. |
| შეზღუდული რაოდენობა | ემისია საჯარო წესებს ექვემდებარება და მისი მაქსიმალური ზღვარი 21 მილიონია. |
| შემოწმებადობა | კვანძს შეუძლია გადაამოწმოს მიწოდება, ტრანზაქციების წესები და საკუთრების დამადასტურებელი მტკიცებულებები. |
| მიმღებლობა | ზოგან მისი მიღება იზრდება, თუმცა ბევრ საზოგადოებაში ის კვლავ გაცილებით ნაკლებად არის მიღებული, ვიდრე ეროვნული ვალუტები. |


ბიტკოინს შეუძლია ფულის სამივე ფუნქციის შესრულება, თუმცა არა ყველგან თანაბრად:

* როგორც [**ღირებულების შენახვის საშუალება**](https://curriculum.myfirstbitcoin.org/lexicon/en/#store-of-value), ის პროგნოზირებადი მიწოდებით გამოირჩევა, თუმცა მისი საბაზრო [ფასი](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) მერყევია.
* როგორც [**გაცვლის საშუალება**](https://curriculum.myfirstbitcoin.org/lexicon/en/#medium-of-exchange), ის შეიძლება გადაირიცხოს ბანკის გარეშე, თუმცა მისი მიღება, საკომისიოები და გადახდის ინსტრუმენტები განსხვავდება.
* როგორც [**საანგარიშო ერთეული**](https://curriculum.myfirstbitcoin.org/lexicon/en/#unit-of-account), ის თანხების გამოხატვის საშუალებას იძლევა ბიტკოინებში ან [სატოშებში](https://curriculum.myfirstbitcoin.org/lexicon/en/#satoshi), თუმცა საქონლის უმეტესობის ფასი კვლავ ფიატურ [ვალუტაში](https://curriculum.myfirstbitcoin.org/lexicon/en/#currency).

ამგვარად, ბიტკოინს აქვს როგორც უპირატესობები, ისე [კომპრომისული მხარეები](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off).

**პოტენციური უპირატესობები** მოიცავს უშუალო საკუთრებას, პროგნოზირებად მიწოდებას, გლობალურ გადარიცხვებს, ღია მონაწილეობას, გამჭვირვალე წესებსა და ცალმხრივი ცენზურისადმი მდგრადობას.

[**კომპრომისები**](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off) მოიცავს [ფასის](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) [მერყეობას](https://curriculum.myfirstbitcoin.org/lexicon/en/#volatility), პირად უსაფრთხოებაზე პასუხისმგებლობას, იმ ფაქტს, რომ მოქმედი გადახდის გაუქმება, ჩვეულებრივ, რთულია ან შეუძლებელი, ცვალებად [ტრანზაქციის საკომისიოებს](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction-fee), ციფრული გადარიცხვებისთვის ელექტროენერგიასა და საკომუნიკაციო საშუალებებზე დამოკიდებულებას, საჯარო [ტრანზაქციების](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) ჩანაწერებს და შეზღუდულ მიმღებლობას.

მიიჩნევთ თუ არა ბიტკოინს [ჯანსაღ ფულად](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money) თქვენი კრიტერიუმებით უნდა განისაზღვროს. შეადარეთ ის [ფიატურ ფულს](https://curriculum.myfirstbitcoin.org/lexicon/en/#fiat-money), ძვირფას ლითონებსა და სხვა [აქტივებს](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset) ერთნაირი სტანდარტების გამოყენებით.

**ადგილობრივი ღირებულების შემოწმება:** აქვს თუ არა ბიტკოინს [ღირებულება](https://curriculum.myfirstbitcoin.org/lexicon/en/#value) თქვენს თემში? პასუხში ერთმანეთისგან გამიჯნეთ სამი კითხვა: რა საბაზრო [ფასი](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) ფიქსირდება? სად მიიღება ის, თუ საერთოდ სადმე მიიღება? რომელი პირადი უპირატესობა ან [მიკერძოება](https://curriculum.myfirstbitcoin.org/lexicon/en/#bias) ახდენს გავლენას თქვენს შეფასებაზე? [ფასი](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), ადგილობრივი სარგებლიანობა და პირადი მოწონება ერთმანეთთან დაკავშირებულია, მაგრამ იდენტური არ არის.
