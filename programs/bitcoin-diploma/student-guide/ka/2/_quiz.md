# Quiz – როგორ მუშაობს ბიტკოინი: ცოდნის მოკლე შემოწმება

## კითხვა 1

ერთი ციფრული ერთეულით ორჯერ იხდიან. სისტემამ უნდა:

* [x] უარყოს ორმაგი ხარჯვა
* [ ] დამალოს გადახდა
* [ ] გაზარდოს მისი ფასი
* [ ] გააუქმოს საკომისიოები

### ახსნა

ციფრული ინფორმაციის კოპირება შესაძლებელია, ამიტომ ფულადმა სისტემამ უნდა აღკვეთოს ერთი და იმავე ერთეულის ორჯერ დახარჯვა და დაადგინოს, რომელი ტრანზაქციაა ვალიდური. გადახედეთ სტუდენტის გზამკვლევის მოდულ 2-ს, „ციფრული ფულის შექმნის ადრეული მცდელობები და ორმაგი ხარჯვის პრობლემა“.

## კითხვა 2

ბიტკოინის დეცენტრალიზაცია ნიშნავს:

* [ ] გადახდებს ერთი კომპანია ამტკიცებს
* [x] წესების დამოუკიდებლად აღსრულებას
* [ ] მაინერები წესებს თავისუფლად ცვლიან
* [ ] ყველასთვის თანაბარ გავლენას

### ახსნა

ბიტკოინი შემოწმებისა და წესების აღსრულების ფუნქციებს დამოუკიდებელ მონაწილეებს შორის ანაწილებს. დეცენტრალიზაცია არ ნიშნავს, რომ ქსელს ერთი კომპანია აკონტროლებს ან რომ ყველას თანაბარი გავლენა აქვს. გადახედეთ სტუდენტის გზამკვლევის მოდულ 2-ს, „დეცენტრალიზაცია“.

## კითხვა 3

ბიტკოინის კვანძი:

* [x] ამოწმებს ქსელის წესების დაცვას
* [ ] ქმნის ბიტკოინს
* [ ] ინახავს ბიტკოინს
* [ ] გადახდის გარანტიას იძლევა

### ახსნა

კვანძები დამოუკიდებლად ამოწმებენ ბიტკოინის წესების დაცვას და უარყოფენ არავალიდურ მონაცემებს. ისინი მოთხოვნის საფუძველზე ბიტკოინს არ ქმნიან და არც ტელეფონში ინახავენ ბიტკოინს. გადახედეთ სტუდენტის გზამკვლევის მოდულ 2-ს, „მომხმარებლები, კვანძები და მაინერები“.

## კითხვა 4

რატომ უწოდებენ ბიტკოინს მყარ ფულს?

* [ ] ფასი ყოველთვის იზრდება
* [x] მიწოდება საჯარო და შეზღუდულია
* [ ] მას ერთი კომპანია აკონტროლებს
* [ ] გადახდები კონფიდენციალურია

### ახსნა

ზოგი ადამიანი ბიტკოინს მყარ ფულად მიიჩნევს, რადგან მისი მიწოდების წესები საჯაროა, ემისია კი შეზღუდულია. ეს დასაბუთებული შეფასებაა და არა ფასის ან კონფიდენციალურობის შესახებ დაპირება. გადახედეთ სტუდენტის გზამკვლევის მოდულ 2-ს, „ბიტკოინი, როგორც მყარი ციფრული ფული“.
