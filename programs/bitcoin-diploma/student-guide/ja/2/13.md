# 2.13 健全なデジタルマネーとしてのビットコイン

すでに**モジュール1**で紹介したように、[**健全な貨幣（サウンドマネー）**](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money)とは、供給の拡大が難しく、その特性によって長期にわたり信頼して使用できる貨幣を指します。この用語は基準に基づく判断を表すものであるため、単なるレッテルとして受け入れるのではなく、吟味すべきものです。

ビットコインは、これまで1つのものに同時に備わることのなかった複数の特性をあわせ持つ[資産](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset)です：


<!-- micrographic: bitcoin-money-properties-01 -->



| 特性 | わかりやすい説明 |
| --- | --- |
| 耐久性 | 台帳は多数のノードに複製されています。アクセスできるかどうかは、有効な鍵を保管し続けられるかにかかっています。 |
| 携帯性 | 署名されたトランザクションによって、通信ネットワークを通じて価値を移転できます。 |
| 分割可能性 | 1ビットコイン（1 BTC）は100,000,000 satsに分割できます。 |
| 代替可能性 | 同じ金額であれば同じプロトコルのルールのもとで使用できますが、公開されている取引履歴によって、一部のサービスが特定の資金をどのように扱うかが左右されることがあります。 |
| 希少性 | 発行は、上限を2,100万とする公開されたルールに従います。 |
| 検証可能性 | ノードは、供給量、トランザクションのルール、所有権の証明を検証できます。 |
| 受容性 | 一部の地域では受け入れが広がっていますが、多くのコミュニティでは依然として各国の通貨に比べてはるかに低い水準にとどまっています。 |


ビットコインは貨幣の3つの機能を果たすことができますが、どの場所でも同じように果たせるわけではありません：

* 第一に、[**価値の保存手段**](https://curriculum.myfirstbitcoin.org/lexicon/en/#store-of-value)としては、供給量は予測可能ですが、市場[価格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)は大きく変動します。
* 第二に、[**交換手段**](https://curriculum.myfirstbitcoin.org/lexicon/en/#medium-of-exchange)としては、銀行を介さずに移動できますが、受け入れ状況、手数料、決済ツールは場所によって異なります。
* 第三に、[**計算単位**](https://curriculum.myfirstbitcoin.org/lexicon/en/#unit-of-account)としては、金額をビットコインまたは[sats](https://curriculum.myfirstbitcoin.org/lexicon/en/#satoshi)で表すことができますが、ほとんどの商品の価格はいまだに法定[通貨建てです](https://curriculum.myfirstbitcoin.org/lexicon/en/#currency)。

したがって、ビットコインには利点があると同時に、[トレードオフも存在します](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)。

**潜在的な利点**としては、直接的な所有、予測可能な供給、国境を越えた送金、オープンな参加、透明なルール、一方的な検閲への耐性などが挙げられます。

[**トレードオフ**](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)としては、[価格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)の[変動性](https://curriculum.myfirstbitcoin.org/lexicon/en/#volatility)、個人が負うセキュリティ上の責任、有効な支払いは通常取り消すことが困難または不可能であること、変動する[取引手数料](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction-fee)、デジタル送金における電力と通信への依存、公開される[取引](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction)記録、そして限られた受け入れ先などがあります。

ビットコインを[健全な貨幣](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money)と呼ぶかどうかは、ご自身の基準に基づいて判断すべきです。同じ基準を用いて、ビットコインを[法定通貨](https://curriculum.myfirstbitcoin.org/lexicon/en/#fiat-money)、貴金属、その他の[資産](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset)と比較してください。

**地域における価値の確認：**ご自身の地域社会において、ビットコインには[価値](https://curriculum.myfirstbitcoin.org/lexicon/en/#value)がありますか？回答では、次の3つの問いを分けて考えてください。観察できる市場[価格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)はどのくらいですか？受け入れられている場所があるとすれば、それはどこですか？どのような個人的な好みや[バイアス](https://curriculum.myfirstbitcoin.org/lexicon/en/#bias)がご自身の判断に影響していますか？[価格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)、地域での有用性、個人的な評価は互いに関連していますが、同一ではありません。
