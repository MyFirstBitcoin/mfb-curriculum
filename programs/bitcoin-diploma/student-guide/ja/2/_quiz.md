# Quiz – ビットコインの仕組み：確認テスト

## Question 1

1つのデジタル単位で2回支払いが行われました。システムがすべきことは：

* [x] 二重支払いを拒否する
* [ ] 支払いを隠す
* [ ] 価格を引き上げる
* [ ] 手数料をなくす

### Explanation

デジタル情報はコピーできるため、お金のシステムは同じ単位が2回使われることを防ぎ、どの取引が有効かを確定しなければなりません。学生ガイドのモジュール2「初期のデジタルマネーの試みと二重支払いの問題」を復習してください。

## Question 2

ビットコインの分散化とは：

* [ ] 1つの企業が支払いを承認する
* [x] 独立した参加者がルールを執行する
* [ ] マイナーが自由にルールを変更する
* [ ] 全員が等しい影響力を持つ

### Explanation

ビットコインは、検証とルールの執行を独立した参加者たちに分散させています。分散化とは、1つの企業がネットワークを管理することでも、全員が等しい影響力を持つことでもありません。学生ガイドのモジュール2「分散化」を復習してください。

## Question 3

ビットコインのノードは：

* [x] ネットワークのルールを確認する
* [ ] ビットコインを作り出す
* [ ] ビットコインを保管する
* [ ] 支払いを保証する

### Explanation

ノードはビットコインのルールを独立して確認し、無効なデータを拒否します。要求に応じてビットコインを作り出したり、スマートフォンの中にビットコインを保管したりするものではありません。学生ガイドのモジュール2「ユーザー、ノード、マイナー」を復習してください。

## Question 4

ビットコインが健全な通貨と呼ばれるのはなぜでしょうか？

* [ ] 価格が常に上がるから
* [x] 供給が公開され、限られているから
* [ ] 1つの企業が管理しているから
* [ ] 支払いが秘匿されるから

### Explanation

ビットコインの供給ルールは公開されており、発行量が限られているため、ビットコインを健全な通貨と表現する人もいます。これは根拠に基づく判断であり、価格やプライバシーを約束するものではありません。学生ガイドのモジュール2「健全なデジタルマネーとしてのビットコイン」を復習してください。
