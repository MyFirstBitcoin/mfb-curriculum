# 4.9 KYCありとKYCなしのトレードオフ

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)あり（本人確認あり）の経路と[KYCなし](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)の経路では、それぞれ異なる[トレードオフ](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)があります。どちらの呼び名であっても、慎重に評価する必要があることに変わりはありません。


<!-- card: callout -->
> **プライバシーがあっても、法的リスクや身体的安全のリスクがなくなるわけではありません**
>
> 「[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)あり」と「[KYCなし](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)」のどちらかが自動的に最善というわけではありません。実際の経路を比較し、ルールが不明確な場合は最新の地域のガイダンスを参照してください。また、[プライバシー](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)を求めるあまり、地域の法律に違反したり、身体的な危険に身をさらしたりしないでください。


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

一般に、[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)ありのサービスでは、法的な氏名、身分証明書、住所、写真、資金源に関する情報、その他の記録の提出を求められることがあります。これにより、サービスは地域のルールを満たしたり、銀行と接続したり、より高い利用限度額を設定したり、アカウントの復旧を支援したりできる場合があります。

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)はデータに関するリスクも生み出します。サービスは、身元、支払い方法、ビットコインの[取引](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction)の間の結び付きを永続的に保存する可能性があります。情報漏えい、法的な開示請求、内部での不正利用、方針の変更などにより、その情報が公開されたり制限されたりする可能性があります。

一方、[KYCなし](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)の経路では、収集される身元情報が少なくなる場合があります。これにより、金融上の[プライバシー](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)を高めることができます。ただし、規制の緩い取引相手、低い流動性、より高い[価格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)、限られたサポート、より大きな詐欺リスク、法的な制約などが伴う場合もあります。

実際の経路を比較してみましょう。


| 質問 | KYCありの経路 | KYCなしの経路 |
| --- | --- | --- |
| どのような身元データが収集されますか？ |  |  |
| 誰がデータを保存し、その期間はどのくらいですか？ |  |  |
| 取引はオンチェーンで結び付けられる可能性がありますか？ |  |  |
| どのような詐欺対策がありますか？ |  |  |
| どのような取引相手リスクがありますか？ |  |  |
| どのような限度額と手数料が適用されますか？ |  |  |
| どの地域の法律が適用されますか？ |  |  |
| 紛争が起きた場合はどうなりますか？ |  |  |


[プライバシー](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)とは、あらゆるリスクから身を隠すことではありません。自分自身に関する情報をコントロールできる能力のことです。[プライバシー](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)を求めるあまり、地域の法律に違反したり、身体的な危険に身をさらしたりしないでください。ルールが不明確な場合は、資格のある専門家から最新の地域のガイダンスを得てください。
