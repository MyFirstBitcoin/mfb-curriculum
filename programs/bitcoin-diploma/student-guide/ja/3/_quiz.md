# Quiz – ビットコインを安全に使う：確認クイズ

## 問題 1

ビットコインウォレットは：

* [ ] bitcoinを保管する
* [x] 鍵を管理し、署名する
* [ ] 秘密情報の保護を解除する
* [ ] 取引を取り消す

### 解説

bitcoinは共有台帳に記録されています。ウォレットは、それにアクセスして使用するための情報を管理します。学生ガイド、モジュール3「ウォレット」を復習してください。

## 問題 2

bitcoinを受け取るために共有するもの：

* [ ] シードフレーズ
* [ ] 秘密鍵
* [x] 受取アドレス
* [ ] パスワード

### 解説

受取アドレスは支払いのために共有できます。シードフレーズ、秘密鍵、パスワードは秘密にしておかなければなりません。学生ガイド、モジュール3「アドレス」と「鍵」を復習してください。

## 問題 3

シードをオンラインで入力してしまいました。最も安全な次の行動は？

* [ ] 様子を見る
* [ ] サポートに送る
* [x] 新しいシードを作成してから資金を移す
* [ ] シードを使い回す

### 解説

オンラインで入力したシードフレーズは漏洩したものとみなしてください。新しいシードで新しいウォレットを作成し、送金先を確認してから資金を移してください。学生ガイド、モジュール3「シードフレーズ」を復習してください。

## 問題 4

カストディアル利用とセルフカストディアル利用の主な違いは何ですか？

* [x] 誰が鍵を管理するか
* [ ] 支払いの取り消し可能性
* [ ] 供給上限
* [ ] 取引手数料

### 解説

カストディアル利用とセルフカストディアル利用の違いは、誰が鍵を管理し、それに伴う責任を負うかにあります。どちらも安全性や取り消し可能性を保証するものではありません。学生ガイド、モジュール3「カストディアル利用とノンカストディアル利用」を復習してください。
