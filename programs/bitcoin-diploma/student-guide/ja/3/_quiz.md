# Quiz – ビットコインを安全に使う：確認クイズ

## 問題 1

ビットコインのウォレットとは：

* [ ] ビットコインを保管する
* [x] 鍵を管理し、署名する
* [ ] 秘密情報の保護を解除する
* [ ] 取引を取り消す

### 解説

ビットコインは共有台帳に記録されており、ウォレットはそれにアクセスし利用するための情報を管理します。学習者ガイド、モジュール3「ウォレット」を復習してください。

## 問題 2

ビットコインを受け取るために共有するもの：

* [ ] シードフレーズ
* [ ] 秘密鍵
* [x] 受取用アドレス
* [ ] パスワード

### 解説

受取用アドレスは支払いのために共有できます。シードフレーズ、秘密鍵、パスワードは秘密にしておかなければなりません。学習者ガイド、モジュール3「アドレス」と「鍵」を復習してください。

## 問題 3

シードをオンラインで入力してしまいました。最も安全な次の行動は？

* [ ] 様子を見る
* [ ] サポートに送る
* [x] 新しいシードを作り、資金を移動する
* [ ] そのシードを使い続ける

### 解説

オンラインで入力したシードフレーズは漏洩したものとして扱ってください。新しいシードで新しいウォレットを作成し、送金先を確認したうえで資金を移動します。学習者ガイド、モジュール3「シードフレーズ」を復習してください。

## 問題 4

カストディの違いとは？

* [x] 誰が鍵を管理するか
* [ ] 支払いの取り消し可能性
* [ ] 供給量の上限
* [ ] 責任

### 解説

カストディアル型とセルフカストディ型の違いは、誰が鍵を管理し、それに伴う責任を負うかにあります。どちらも安全性や取り消し可能性を保証するものではありません。学習者ガイド、モジュール3「カストディアル型とノンカストディアル型の利用」を復習してください。
