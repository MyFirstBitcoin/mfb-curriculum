# 3.3 アドレス

> **Definition – ビットコインアドレス**
>
> 「[ビットコインアドレス](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-address)」とは、[オンチェーン決済](https://curriculum.myfirstbitcoin.org/lexicon/en/#on-chain-payment)を受け取るための公開情報です。ウォレットは通常、他の人があなたにbitcoinを送れるよう、これを文字列とQRコードで表示します。パスワードや[秘密鍵](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key)とは異なり、アドレスで支出を承認することはできません。



<!-- micrographic: address-two-formats-01 -->


ご自身が[オンチェーン決済](https://curriculum.myfirstbitcoin.org/lexicon/en/#on-chain-payment)を受け取りたい場合、アドレスはどこから取得すべきでしょうか？受け取りに使うウォレットを開き、その受け取り画面を使用してください。送金者はQRコードをスキャンするか、アドレスをコピーできます。こうすることで、長い文字列を手入力する際に起こりうる間違いを防げます。

支払いを請求するたびに、意図した支払い方法を確認してください。オンチェーンアドレスと[ライトニングインボイス](https://curriculum.myfirstbitcoin.org/lexicon/en/#lightning-invoice)は異なるものです。スキャンやコピーをした後は、支払いを承認する前に、送金先を信頼できる受け取り画面と照らし合わせてください。なぜコピーした後に確認するのでしょうか？悪意のあるソフトウェアが、コピーしたアドレス情報を置き換えることがあるからです。新しい受け取りのたびに新しいオンチェーンアドレスを使うと、[プライバシー](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)を高めることができます。1つのアドレスを使い回すと、別々の支払いを他人が結びつけやすくなります。新しいアドレスはそうした結びつけやすさを減らしますが、支払いを匿名にするわけではありません。

> **Light**
>
> 重要な支払いでは、見覚えがあるというだけでアドレスを安全だと判断しないでください。意図した受取人、正しい[ビットコインネットワーク](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-network)、送金先、支払い方法を確認してください。手順や金額に慣れていない場合は、まず少額でテストしてください。
