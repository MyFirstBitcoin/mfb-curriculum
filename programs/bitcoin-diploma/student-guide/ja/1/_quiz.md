# Quiz – お金を理解する：確認テスト

## Question 1

お金はなぜ受け取ってもらえるのでしょうか？

* [x] 他の人も受け取ると期待されているから
* [ ] あらゆる商品の価値を等しくするから
* [ ] すべてのルールをなくすから
* [ ] サービスを商品に変えるから

### Explanation

人々は後で他の人もお金を受け取ってくれると期待しているため、お金は見知らぬ人同士が時間をまたいで交換を調整するのに役立ちます。それでもお金は、信頼、ルール、社会的な受け入れに依存しています。学生ガイドのモジュール1「お金はなぜ存在するのか」を復習してください。

## Question 2

値段をつける、支払う、貯める：それぞれどの役割でしょうか？

* [ ] 価値の保存、価値の尺度、交換の手段
* [x] 価値の尺度、交換の手段、価値の保存
* [ ] 交換の手段、価値の保存、価値の尺度
* [ ] 希少性、希少性、希少性

### Explanation

価値の尺度は価格を表し、交換の手段は支払いとして受け取られ、価値の保存は価値を将来へと移します。学生ガイドのモジュール1「お金の機能と特性」を復習してください。

## Question 3

お米と靴の交換がうまくいきません。なぜでしょうか？

* [ ] 価格が異なるから
* [x] 欲しいものが一致しないから
* [ ] 銀行の承認がないから
* [ ] お米は交換できないから

### Explanation

互いが相手の差し出すものを同時に欲しいと思っていない場合、直接の物々交換は困難です。これを「欲求の二重の一致」の問題といいます。学生ガイドのモジュール1「物々交換と欲求の二重の一致」を復習してください。

## Question 4

物価が10％上昇し、収入が5％増えました。購買力はどうなるでしょうか？

* [ ] 上がる
* [ ] 変わらない
* [x] 下がる
* [ ] 判断できない

### Explanation

購買力とは、お金で買えるものの量です。物価が収入よりも速く上昇すると、その収入で買えるものは減ります。学生ガイドのモジュール1「インフレと購買力」を復習してください。
