# 4.9 Преимущества и недостатки KYC и отказа от KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) и [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) предполагают разные [компромиссы](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Ни одно из этих обозначений не отменяет необходимости тщательной оценки.


<!-- card: callout -->
> **Конфиденциальность не устраняет юридические риски и угрозы физической безопасности**
>
> Ни [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc), ни [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) не является заведомо лучшим вариантом. Сравнивайте конкретные способы, обращайтесь к актуальным местным рекомендациям, если правила неясны, и не нарушайте местное законодательство и не подвергайте себя физической опасности ради [конфиденциальности](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Сервис с [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) может запросить официальное имя, документ, удостоверяющий личность, адрес, фотографию, сведения об источнике средств или другие документы. Это может позволить сервису соблюдать местные требования, взаимодействовать с банками, устанавливать более высокие лимиты или обеспечивать восстановление доступа к аккаунту.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) также создаёт риски для данных. Сервис может хранить постоянную связь между личностью, способами оплаты и биткоин-[транзакциями](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Утечка данных, официальный запрос, злоупотребления со стороны сотрудников или изменение политики могут привести к раскрытию этой информации или ограничению доступа к ней.

Способ [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) может предусматривать сбор меньшего объёма идентификационных данных. Это может повысить финансовую [конфиденциальность](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). При этом он также может подразумевать взаимодействие с менее регулируемыми контрагентами, более низкую ликвидность, более высокие [цены](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), менее полноценную поддержку, повышенный риск мошенничества или юридические ограничения.

Сравните конкретные способы:


| Вопрос | Способ с KYC | Способ без KYC |
| --- | --- | --- |
| Какие идентификационные данные собираются? |  |  |
| Кто хранит данные и как долго? |  |  |
| Можно ли установить связь с транзакцией по данным блокчейна? |  |  |
| Какая защита от мошенничества предусмотрена? |  |  |
| Каков риск, связанный с контрагентом? |  |  |
| Какие лимиты и комиссии действуют? |  |  |
| Какое местное законодательство применяется? |  |  |
| Что происходит при возникновении спора? |  |  |


[Конфиденциальность](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) — это не полная скрытность, защищающая от всех рисков. Это возможность контролировать информацию о себе. Не нарушайте местное законодательство и не подвергайте себя физической опасности ради [конфиденциальности](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Если правила неясны, обратитесь к квалифицированному специалисту за актуальными рекомендациями с учётом местных требований.
