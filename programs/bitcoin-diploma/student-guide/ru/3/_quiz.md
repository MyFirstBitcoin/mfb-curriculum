# Quiz – Безопасное использование биткоина: краткая проверка знаний

## Question 1

Биткоин-кошелёк:

* [ ] Хранит биткоины
* [x] Управляет ключами и подписывает транзакции
* [ ] Снимает защиту секретных данных
* [ ] Отменяет транзакции

### Explanation

Биткоин учитывается в общем реестре; кошелёк управляет данными, необходимыми для доступа к нему и его использования. Повторите раздел «Кошельки» модуля 3 учебного пособия.

## Question 2

Что можно сообщить для получения биткоинов?

* [ ] Сид-фразу
* [ ] Приватный ключ
* [x] Адрес для получения
* [ ] Пароль

### Explanation

Адрес для получения можно сообщить для приёма платежа. Сид-фразы, приватные ключи и пароли должны оставаться в секрете. Повторите разделы «Адреса» и «Ключи» модуля 3 учебного пособия.

## Question 3

Вы ввели сид-фразу в интернете. Какой следующий шаг наиболее безопасен?

* [ ] Подождать
* [ ] Отправить её в службу поддержки
* [x] Создать новую сид-фразу, затем перевести средства
* [ ] Повторно использовать ту же сид-фразу

### Explanation

Считайте сид-фразу, введённую в интернете, скомпрометированной. Создайте новый кошелёк с новой сид-фразой, затем переведите средства, предварительно проверив адрес назначения. Повторите раздел «Сид-фразы» модуля 3 учебного пособия.

## Question 4

В чём различие между кастодиальным и самостоятельным хранением?

* [x] В том, кто контролирует ключи
* [ ] В возможности отмены платежей
* [ ] В предельном объёме эмиссии
* [ ] В ответственности

### Explanation

Кастодиальное и самостоятельное хранение различаются тем, кто контролирует ключи и несёт связанную с этим ответственность. Ни один из этих вариантов не гарантирует безопасность или возможность отмены транзакций. Повторите раздел «Кастодиальное и некастодиальное использование» модуля 3 учебного пособия.
