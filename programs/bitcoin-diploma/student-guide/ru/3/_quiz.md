# Quiz – Безопасное использование биткоина: краткая проверка знаний

## Вопрос 1

Биткоин-кошелёк:

* [ ] Хранит биткоины
* [x] Управляет ключами и подписывает транзакции
* [ ] Снимает защиту секретных данных
* [ ] Отменяет транзакции

### Объяснение

Биткоины учитываются в общем реестре; кошелёк управляет информацией, необходимой для доступа к ним и их использования. Повторите раздел «Кошельки» в модуле 3 учебного пособия.

## Вопрос 2

Чтобы получить биткоины, сообщите:

* [ ] Сид-фразу
* [ ] Приватный ключ
* [x] Адрес для получения
* [ ] Пароль

### Объяснение

Адрес для получения можно сообщать другим для приёма платежей. Сид-фразы, приватные ключи и пароли должны оставаться в секрете. Повторите разделы «Адреса» и «Ключи» в модуле 3 учебного пособия.

## Вопрос 3

Вы ввели сид-фразу в интернете. Какой следующий шаг наиболее безопасен?

* [ ] Подождать
* [ ] Отправить её в службу поддержки
* [x] Создать новую сид-фразу, затем перевести средства
* [ ] Повторно использовать ту же сид-фразу

### Объяснение

Считайте сид-фразу, введённую в интернете, скомпрометированной. Создайте новый кошелёк с новой сид-фразой, затем переведите средства, предварительно проверив адрес назначения. Повторите раздел «Сид-фразы» в модуле 3 учебного пособия.

## Вопрос 4

В чём основное различие между кастодиальным использованием и самостоятельным хранением?

* [x] Кто контролирует ключи
* [ ] Возможность отмены платежей
* [ ] Ограничение предложения
* [ ] Комиссии за транзакции

### Объяснение

Кастодиальное использование и самостоятельное хранение различаются тем, кто контролирует ключи и несёт связанную с этим ответственность. Ни один из вариантов не гарантирует безопасность или возможность отмены транзакций. Повторите раздел «Кастодиальное и некастодиальное использование» в модуле 3 учебного пособия.
