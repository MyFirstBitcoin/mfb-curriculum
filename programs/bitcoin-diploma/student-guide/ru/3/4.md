# 3.4 Ключи

Владение биткоинами обеспечивается с помощью криптографических ключей.


<!-- card: definition -->
> **Definition – Закрытый ключ**
>
> Такой [закрытый ключ](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) — это секретная информация, которая позволяет кошельку создавать действительные [цифровые подписи](https://curriculum.myfirstbitcoin.org/lexicon/en/#digital-signature). Подпись разрешает расходование биткоинов, контролируемых соответствующим ключом. Любой, кто получит [закрытый ключ](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key), как правило, сможет потратить эти средства.


Такой [**открытый ключ**](https://curriculum.myfirstbitcoin.org/lexicon/en/#public-key) математически выводится из [закрытого ключа](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key). Он помогает проверить подпись, не раскрывая [закрытый ключ](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key). Адреса создаются на основе [связанной с открытым ключом](https://curriculum.myfirstbitcoin.org/lexicon/en/#public-key) информации.

Главное правило простое:

**Открытой информацией для получения средств можно делиться. Закрытая информация для расходования средств должна оставаться в тайне.**

Такая [цифровая подпись](https://curriculum.myfirstbitcoin.org/lexicon/en/#digital-signature) доказывает, что необходимый [закрытый ключ](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) был использован для авторизации [транзакции](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). При этом [закрытый ключ](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) не помещается внутрь [транзакции](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). [Узлы](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) проверяют подпись, прежде чем принять расходование средств.

Большинство кошельков для начинающих используют [одну подпись](https://curriculum.myfirstbitcoin.org/lexicon/en/#single-signature): один закрытый ключ авторизует транзакцию. Современные кошельки автоматически управляют множеством ключей. Начинающим не следует копировать или обрабатывать отдельные [содержащие закрытые ключи](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) строки. Защищайте резервную копию кошелька, созданную рекомендованным способом, и следуйте предусмотренной для него процедуре восстановления.

Ни добросовестному преподавателю, ни компании — разработчику кошелька, ни сотруднику биржи, ни специалисту технической поддержки, ни разработчику биткоина не нужен ваш [закрытый ключ](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) или [сид-фраза](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase). Любого, кто запрашивает эту информацию, следует считать угрозой.


<!-- card: light -->
> **Попробуйте:** Распределите подготовленные примеры по трём группам: информация для получения средств, которой безопасно делиться; секретная информация для расходования средств; информация, которая может быть общедоступной, но которую всё же следует сохранять в тайне, если она связана с конкретным человеком.
