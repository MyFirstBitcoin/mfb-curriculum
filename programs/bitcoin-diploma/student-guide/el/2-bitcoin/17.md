# 2.17 Ενδυνάμωση, κίνδυνος και ευθύνη

Οι δημόσιοι κανόνες του Bitcoin, [το δίκτυο ομότιμων κόμβων](https://curriculum.myfirstbitcoin.org/lexicon/en/#peer-to-peer-network), και [οι ψηφιακές υπογραφές](https://curriculum.myfirstbitcoin.org/lexicon/en/#digital-signature) δίνουν στους συμμετέχοντες ουσιαστικούς ρόλους. Οι χρήστες μπορούν να επιλέξουν να **λαμβάνουν**, **διακρατούν**, και **στέλνουν** bitcoin· [οι κόμβοι](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) μπορούν να επαληθεύουν ανεξάρτητα τους κανόνες· [οι εξορύκτες](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) μπορούν να προτείνουν μπλοκ· και οι προγραμματιστές μπορούν να προτείνουν αλλαγές στο λογισμικό. Κανένας μεμονωμένος ρόλος δεν ελέγχει το δίκτυο για λογαριασμό όλων.



Αυτές οι ιδιότητες μπορούν να ενδυναμώσουν τους συμμετέχοντες, αλλά τους επιφορτίζουν και με περισσότερες ευθύνες. Χωρίς μια κεντρική αρχή που να εγκρίνει [συναλλαγές](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction), να αποκαθιστά την πρόσβαση ή να αναιρεί πολλά σφάλματα, κάθε άτομο πρέπει να μπορεί να αναγνωρίζει τον ρόλο και τους κινδύνους που αποδέχεται.

![](https://cdn.sanity.io/images/vje9ehw2/production/046836e98fde3a839b4969cfce7f63bfaf59b23f-1536x1024.svg)

Για ένα άτομο που επιλέγει την [αυτοθεματοφυλακή](https://curriculum.myfirstbitcoin.org/lexicon/en/#self-custody), ο έλεγχος των κλειδιών παρέχει άμεσο έλεγχο των bitcoin. Καμία εταιρεία δεν μπορεί να παγώσει ένα υπόλοιπο στην αλυσίδα του οποίου ο έλεγχος ασκείται σωστά. Καμία εταιρεία δεν μπορεί επίσης να αποκαταστήσει μια χαμένη [φράση ανάκτησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) ούτε.

[Η αυτοθεματοφυλακή](https://curriculum.myfirstbitcoin.org/lexicon/en/#self-custody) δεν είναι επομένως απλώς ένα τεχνικό χαρακτηριστικό. Απαιτεί την προστασία των αντιγράφων ασφαλείας, την επαλήθευση των διευθύνσεων, τον έλεγχο της συμπεριφοράς του πορτοφολιού και τη δημιουργία ενός σχεδίου ανάκτησης. Η επόμενη ενότητα εξηγεί πώς να διακρατείτε και να χρησιμοποιείτε bitcoin με προσοχή, καθώς και πώς να διαχειρίζεστε αυτούς τους κινδύνους και τις ευθύνες.


<!-- card: light -->
> Η προσωπική ευθύνη δεν σημαίνει ότι ενεργείτε μόνοι σας ή ότι αρνείστε τη βοήθεια. Ένα προσεκτικό άτομο που μαθαίνει μπορεί να αξιοποιεί την εκπαίδευση, τον έλεγχο από ομοτίμους, τις τεκμηριωμένες διαδικασίες και τις δοκιμές μικρής κλίμακας, χωρίς να δίνει σε κανέναν πρόσβαση σε μυστικές πληροφορίες.
