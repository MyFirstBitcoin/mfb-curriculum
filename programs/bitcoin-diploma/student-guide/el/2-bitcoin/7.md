# 2.7 Ψηφιακές υπογραφές

[Οι ψηφιακές υπογραφές](https://curriculum.myfirstbitcoin.org/lexicon/en/#digital-signature) αποτελούν ένα από τα βασικά στοιχεία του σχεδιασμού του Bitcoin που περιγράφονται στη λευκή βίβλο. Στο Bitcoin, ένα πορτοφόλι χρησιμοποιεί ένα [ιδιωτικό κλειδί](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) για να δημιουργήσει μια [ψηφιακή υπογραφή](https://curriculum.myfirstbitcoin.org/lexicon/en/#digital-signature) που εγκρίνει μια [συναλλαγή](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Ένα πορτοφόλι είναι συνήθως μια εφαρμογή που διαχειρίζεται τα κλειδιά και δημιουργεί αυτές τις υπογραφές για τον χρήστη. Μόνο ο κάτοχος του απαιτούμενου [ιδιωτικού κλειδιού](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) μπορεί να εγκρίνει τη δαπάνη· το δίκτυο μπορεί να επαληθεύσει την υπογραφή χωρίς να μάθει το [ιδιωτικό κλειδί](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) αυτό καθαυτό.

Αυτό επιτρέπει σε ένα άτομο να ελέγχει bitcoin χωρίς να ζητά άδεια από μια τράπεζα ή άλλον κεντρικό φορέα. Σημαίνει επίσης ότι ο έλεγχος του [ιδιωτικού κλειδιού](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) είναι κρίσιμος: όποιος το αποκτήσει μπορεί συνήθως να εγκρίνει μια δαπάνη, ενώ η απώλεια ενός κλειδιού μπορεί να καταστήσει τα bitcoin μη ανακτήσιμα.

Αυτή είναι η βάση της [αυτοθεματοφυλακής](https://curriculum.myfirstbitcoin.org/lexicon/en/#self-custody): να ελέγχετε εσείς οι ίδιοι τα κλειδιά αντί να βασίζεστε σε μια υπηρεσία για τον έλεγχό τους. **Η Ενότητα 3** εξηγεί τις πρακτικές ευθύνες ασφάλειας που αφορούν τα κλειδιά, τα αντίγραφα ασφαλείας και την ανάκτηση.
