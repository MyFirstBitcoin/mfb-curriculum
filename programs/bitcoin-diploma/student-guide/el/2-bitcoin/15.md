# 2.15 Η μάθηση και η υπεύθυνη χρήση δεν συνιστούν συναλλαγές ή προώθηση

Το να μαθαίνετε πώς λειτουργεί το Bitcoin διαφέρει από το να προσπαθείτε να αποκομίσετε κέρδος από βραχυπρόθεσμες [τιμολογιακές](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) μεταβολές, να πείθετε άλλους να αγοράσουν ένα ψηφιακό διακριτικό ή να αντιμετωπίζετε την κερδοσκοπία ως εκπαίδευση. Οι συναλλαγές και η κερδοσκοπία μπορεί να συνεπάγονται βιαστικές αποφάσεις, απώλειες, κινδύνους που σχετίζονται με τις πλατφόρμες και πίεση να ενεργήσετε χωρίς σαφές σκεπτικό. Η προώθηση ψηφιακών διακριτικών μπορεί να δημιουργεί συγκρούσεις συμφερόντων και να επιβραβεύει την πειθώ αντί για τη σαφή εξήγηση.

Σκοπός του Διπλώματος Bitcoin είναι να σας βοηθήσει να εξηγείτε το Bitcoin, να θέτετε καλύτερα ερωτήματα και να λαμβάνετε ασφαλέστερες αποφάσεις. Δεν παρέχει επενδυτικές συμβουλές ούτε σας υποδεικνύει τι να αγοράσετε, να πουλήσετε ή να διακρατήσετε.
