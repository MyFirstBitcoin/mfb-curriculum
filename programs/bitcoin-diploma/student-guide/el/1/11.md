# 1.11 Εναλλακτικές για αποταμίευση και διατήρηση της αξίας

Οι άνθρωποι συχνά αναζητούν εναλλακτικές λύσεις αντί της διακράτησης μετρητών όταν πιστεύουν ότι αυτά θα χάσουν [αγοραστική δύναμη](https://curriculum.myfirstbitcoin.org/lexicon/en/#purchasing-power). Συνήθεις επιλογές είναι τα πολύτιμα μέταλλα, τα ακίνητα και οι μετοχές. Τα πολύτιμα μέταλλα έχουν επίσης χρησιμοποιηθεί ως χρήμα σε πολλούς τόπους και περιόδους. Κάθε επιλογή έχει οφέλη και κινδύνους.

Ένα [περιουσιακό στοιχείο](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset) είναι κάτι που ένα άτομο μπορεί να κατέχει ή να διεκδικεί και που ενδέχεται να έχει [αξία](https://curriculum.myfirstbitcoin.org/lexicon/en/#value)· δεν επιτελεί αυτομάτως όλες τις λειτουργίες του χρήματος. Μια κατοικία μπορεί να αποθηκεύει [αξία](https://curriculum.myfirstbitcoin.org/lexicon/en/#value) αλλά δεν είναι πρακτική για την αγορά τροφίμων. Μια μετοχή μπορεί να πωλείται εύκολα σε μια χώρα, αλλά να μην είναι διαθέσιμη σε κάποιον που δεν διαθέτει χρηματιστηριακό λογαριασμό. [Ο χρυσός](https://curriculum.myfirstbitcoin.org/lexicon/en/#gold) έχει χρησιμοποιηθεί ως χρήμα για μεγάλες περιόδους της ιστορίας, αλλά μπορεί να είναι δύσκολο να ελεγχθεί η γνησιότητά του ή να διαιρεθεί κατά τη διάρκεια μιας μικρής συναλλαγής.

![](https://cdn.sanity.io/images/vje9ehw2/staging/73bd09407fd1c7ac48ccf9725918a1227c355533-1536x1024.svg)

Οι άνθρωποι μπορεί επίσης να επιλέξουν ξένο [νόμισμα](https://curriculum.myfirstbitcoin.org/lexicon/en/#currency), κρατικά [ομόλογα](https://curriculum.myfirstbitcoin.org/lexicon/en/#bond), ιδιωτικές επιχειρήσεις, γη, εργαλεία, εκπαίδευση ή άλλα [περιουσιακά στοιχεία](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset). Κάθε επιλογή ενέχει [κόστος ευκαιρίας](https://curriculum.myfirstbitcoin.org/lexicon/en/#opportunity-cost) και κίνδυνο. Δεν υπάρχει [περιουσιακό στοιχείο](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset) που να εγγυάται [αγοραστική δύναμη](https://curriculum.myfirstbitcoin.org/lexicon/en/#purchasing-power) σε κάθε περίοδο και κατάσταση.

**Σημείωση:** Η φορολογική μεταχείριση μπορεί επίσης να διαμορφώσει αυτές τις αποφάσεις. Οι κανόνες για το εισόδημα, τα κέρδη, την περιουσία και τις [συναλλαγές](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) μπορούν να μεταβάλουν το κόστος ή το όφελος από τη διακράτηση, την πώληση ή τη χρήση ενός [περιουσιακού στοιχείου](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset). Οι φορολογικοί κανόνες διαφέρουν ανά δικαιοδοσία και μπορούν να αλλάξουν με την πάροδο του χρόνου· αυτό το μάθημα δεν παρέχει φορολογικές συμβουλές.

Το Bitcoin εμφανίστηκε ως μια ακόμη προτεινόμενη εναλλακτική λύση: ένα σπάνιο [ψηφιακό περιουσιακό στοιχείο](https://curriculum.myfirstbitcoin.org/lexicon/en/#digital-asset) που μπορεί να διακρατείται και να μεταβιβάζεται χωρίς κεντρικό [εκδότη](https://curriculum.myfirstbitcoin.org/lexicon/en/#issuer). Για να αξιολογήσουμε αυτόν τον ισχυρισμό, πρέπει να μελετήσουμε γιατί δημιουργήθηκε το Bitcoin και πώς λειτουργούν οι κανόνες του.
