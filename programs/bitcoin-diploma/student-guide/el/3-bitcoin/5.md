# 3.5 Φράσεις ανάκτησης

> **Definition – Φράση αρχικοποίησης**
>
> Μια [φράση αρχικοποίησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase), που ονομάζεται επίσης [φράση ανάκτησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase), είναι μια διατεταγμένη λίστα λέξεων που πολλά πορτοφόλια χρησιμοποιούν για την παραγωγή και την ανάκτηση ενός συνόλου [ιδιωτικών κλειδιών](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key). Ένα [ιδιωτικό κλειδί](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) εξουσιοδοτεί τη δαπάνη χρημάτων· η [φράση αρχικοποίησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) είναι συνήθως το αντίγραφο ασφαλείας που μπορεί να αναδημιουργήσει τα κλειδιά του πορτοφολιού. Συνήθως αποτελείται από 12 ή 24 λέξεις, αν και ο σχεδιασμός των πορτοφολιών διαφέρει.


Η σειρά και η ορθογραφία των λέξεων έχουν σημασία. Αν κάποιος έχει τη [φράση αρχικοποίησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase), μπορεί συχνά να επαναφέρει το πορτοφόλι σε άλλη συμβατή συσκευή και να ξοδέψει τα χρήματα. Επομένως, η [φράση αρχικοποίησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) δεν είναι απλώς ένα αντίγραφο ασφαλείας. Παρέχει πλήρη πρόσβαση.


> **Callout – Μην κοινοποιείτε ποτέ πληροφορίες ανάκτησης**
>
> Τα δημόσια στοιχεία λήψης χρημάτων μπορούν να κοινοποιούνται. Ένα [ιδιωτικό κλειδί](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key), [μια φράση αρχικοποίησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase), ένας κωδικός πρόσβασης ή ένας κωδικός ανάκτησης πρέπει να παραμένουν απόρρητα. Κανένας νόμιμος εκπαιδευτής, εταιρεία πορτοφολιών, υπάλληλος ανταλλακτηρίου, εργαζόμενος στην υποστήριξη ή προγραμματιστής του Bitcoin δεν χρειάζεται αυτές τις πληροφορίες. Αν μια [φράση αρχικοποίησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) ενδέχεται να έχει γίνει ορατή σε άλλους, να έχει αντιγραφεί, να έχει εισαχθεί στο διαδίκτυο ή να έχει αποθηκευτεί σε μη έμπιστη συσκευή, θεωρήστε ότι έχει εκτεθεί και αναζητήστε βοήθεια χωρίς να την αποκαλύψετε.

Προστατέψτε μια [φράση αρχικοποίησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) ακολουθώντας αυτούς τους κανόνες:

* καταγράψτε την με ακρίβεια και χωρίς να σας βλέπουν άλλοι κατά τη δημιουργία του πορτοφολιού
* ακολουθήστε τις επίσημες οδηγίες του πορτοφολιού για τη δημιουργία αντιγράφων ασφαλείας
* διατηρήστε την εκτός διαδικτύου
* μην τη φωτογραφίζετε ποτέ, μην την αποθηκεύετε σε σημειώσεις στο νέφος και μην τη στέλνετε με ηλεκτρονικό ταχυδρομείο ή σε μήνυμα
* μην την πληκτρολογείτε ποτέ σε ιστότοπο ή σε συνηθισμένη φόρμα υπολογιστή
* κρατήστε την μακριά από κάμερες, μικρόφωνα, τα βλέμματα άλλων και μέρη όπου μπορεί να καταστραφεί, να χαθεί ή να βρεθεί

Ορισμένα πορτοφόλια χρησιμοποιούν πρόσθετες φράσεις πρόσβασης, πολλαπλά κλειδιά ή άλλα συστήματα δημιουργίας αντιγράφων ασφαλείας. Αυτά αποτελούν θέματα για [Προχωρημένη μάθηση](https://curriculum.myfirstbitcoin.org/programs/advanced-modules/). Μην προσθέτετε πολυπλοκότητα που δεν μπορείτε να εξηγήσετε και που δεν σας επιτρέπει να πραγματοποιήσετε ανάκτηση με ασφάλεια. Αν μια [φράση αρχικοποίησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) ενδέχεται να έχει γίνει ορατή σε άλλους, να έχει αντιγραφεί, να έχει εισαχθεί στο διαδίκτυο ή να έχει αποθηκευτεί σε μη έμπιστη συσκευή, θεωρήστε ότι έχει εκτεθεί: αναζητήστε καθοδήγηση χωρίς να την αποκαλύψετε και χρησιμοποιήστε μια νέα, αξιόπιστη διαδικασία ανάκτησης.
