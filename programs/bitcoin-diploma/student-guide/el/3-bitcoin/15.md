# 3.15 Έλεγχος πρακτικών δεξιοτήτων υπό την επίβλεψη εκπαιδευτικού

Πριν από την αξιολόγηση, θα εξασκηθείτε με υποστήριξη και θα γνωρίζετε την εργασία και τα όρια ασφαλείας. Ο εκπαιδευτής σας θα σας παρατηρήσει καθώς χρησιμοποιείτε ένα εγκεκριμένο, προετοιμασμένο περιβάλλον, ένα περιβάλλον προσομοίωσης ή ένα περιβάλλον χαμηλού ρίσκου — η αξιολόγηση δεν θα βασιστεί στην παρουσία σας ή σε όσα αναφέρετε εσείς.

Θα δείξετε ότι μπορείτε να ανοίξετε το προετοιμασμένο πορτοφόλι ή να πλοηγηθείτε σε αυτό, να ολοκληρώσετε μια εγκεκριμένη διαδικασία αρχικής πρόσβασης, να εντοπίσετε και να ελέγξετε τα στοιχεία λήψης και να λάβετε bitcoin ή να προσομοιώσετε με ασφάλεια τη λήψη τους. Θα ολοκληρώσετε επίσης ή θα προσομοιώσετε με ασφάλεια μια διαδικασία λήψης ή αποστολής και θα δείξετε ότι είστε έτοιμοι για ανάκτηση χρησιμοποιώντας προετοιμασμένο υλικό, διατηρώντας παράλληλα όλα τα μυστικά στοιχεία σας απόρρητα. Μπορείτε να εξασκηθείτε στην ασφαλή αντιμετώπιση μιας ασυμφωνίας ή μιας απάτης μέσα από καθοδηγούμενα σενάρια. Αν δεν είστε ακόμη έτοιμοι, θα πρέπει να λάβετε ανατροφοδότηση, περισσότερη εξάσκηση και μια ακόμη ευκαιρία να επιδείξετε τη δεξιότητα.
