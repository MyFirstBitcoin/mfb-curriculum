# 3.1 Ασφαλής χρήση του Bitcoin

Αυτή η ενότητα αφορά τα πρώτα ασφαλή βήματα, όχι το να γίνετε ειδικοί ή να αναλάβετε χρηματοοικονομικό κίνδυνο. Θα εξασκηθείτε με προετοιμασμένες προσομοιώσεις, δοκιμαστικά περιβάλλοντα, εκπαιδευτικά πορτοφόλια ή, όπου ο εκπαιδευτής σας το κρίνει κατάλληλο, με μια δραστηριότητα με πραγματικές συναλλαγές μικρής αξίας.


> **Dark**
>
> Δεν χρειάζεται να αγοράσετε ή να αποκτήσετε με άλλον τρόπο bitcoin, ούτε να χρησιμοποιήσετε προσωπικά χρήματα, για να ολοκληρώσετε το Δίπλωμα Bitcoin.


Ποιες πληροφορίες μπορείτε να κοινοποιήσετε με ασφάλεια; Ποιες πληροφορίες θα μπορούσαν να δώσουν τον έλεγχο σε κάποιο άλλο άτομο; Πώς θα αντιλαμβανόσασταν ότι ένα αίτημα πληρωμής έχει αλλάξει; Αυτά τα ερωτήματα έχουν σημασία προτού αποκτήσει σημασία οποιοδήποτε πορτοφόλι, πληρωμή ή αντίγραφο ασφαλείας.

Εφαρμόζετε αυτούς τους τρεις κανόνες σε όλη τη διάρκεια της ενότητας:

1. **Κοινοποιείτε στοιχεία λήψης, ποτέ μυστικά στοιχεία.** Μια διεύθυνση ή ένα αίτημα πληρωμής μπορεί να χρησιμοποιηθεί για τη λήψη bitcoin. Ένα [ιδιωτικό κλειδί](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) ή [μια φράση ανάκτησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) μπορεί να δώσει τον έλεγχό τους.
1. **Κάντε μια παύση πριν εγκρίνετε μια αποστολή.** Ελέγξτε το άτομο, τη μέθοδο πληρωμής, τον προορισμό, το ποσό και την τελική οθόνη.
1. **Περιορίστε τις συνέπειες των λαθών.** Σταματήστε και ζητήστε βοήθεια όταν ένα αίτημα είναι ασαφές, σας πιέζει να βιαστείτε ή ζητά μυστικά στοιχεία.

Στο τέλος, θα πρέπει να μπορείτε να εξηγήσετε ποιος ελέγχει τα κλειδιά, να ολοκληρώσετε με υποστήριξη μια πρακτική άσκηση λήψης ή αποστολής, να αντιδράσετε με ασφάλεια σε μια απάτη ή αναντιστοιχία και να δείξετε ότι είστε έτοιμοι για ανάκτηση χωρίς να αποκαλύψετε κανένα πραγματικό μυστικό στοιχείο. Ο στόχος δεν είναι η ταχύτητα. Είναι να γνωρίζετε πότε να κάνετε μια παύση.

Η ενότητα οργανώνεται γύρω από τρία πρακτικά ερωτήματα:

1. **Τι μπορώ να κοινοποιήσω και τι πρέπει να παραμείνει μυστικό;**
1. **Τι πρέπει να ελέγξω πριν λάβω ή στείλω;**
1. **Πότε πρέπει να σταματήσω και να ζητήσω βοήθεια;**

Χρησιμοποιήστε τις παρακάτω εξηγήσεις για να προετοιμαστείτε για τις τρεις καθοδηγούμενες ασκήσεις: έναν έλεγχο της οθόνης λήψης, έναν έλεγχο αποστολής και επαλήθευσης και ένα σενάριο ετοιμότητας για ανάκτηση ή αντίδρασης σε απάτη.
