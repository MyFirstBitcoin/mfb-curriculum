# 3.6 Χρήση με και χωρίς θεματοφυλακή

> **Definition – Θεματοφυλακή**
>
> [Η θεματοφυλακή](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) απαντά σε ένα πρακτικό ερώτημα: ποιος ελέγχει τα κλειδιά που απαιτούνται για να δαπανηθούν τα bitcoin;


Σε μια **θεματοφυλακτική** υπηρεσία, μια εταιρεία ή κάποιο άλλο πρόσωπο ελέγχει τα κλειδιά. Το υπόλοιπο που εμφανίζεται στον λογαριασμό σας είναι μια υπόσχεση από τον [θεματοφύλακα](https://curriculum.myfirstbitcoin.org/lexicon/en/#custodian). Συνήθως συνδέεστε με έναν λογαριασμό και ζητάτε από την υπηρεσία να διεκπεραιώσει μια ανάληψη ή πληρωμή.

Αυτή η διαφορά είναι σημαντική για την επαλήθευση. Οι κανόνες και η συνολική προσφορά του Bitcoin μπορούν να ελεγχθούν ανεξάρτητα, αλλά αν δεν ελέγχετε τα κλειδιά, δεν μπορείτε να ελέγξετε ανεξάρτητα αν το υπόλοιπο που εμφανίζεται στον λογαριασμό σας αντιστοιχεί σε bitcoin που κατέχει η υπηρεσία και θα σας διαθέσει. Η δημόσια αλυσίδα μπλοκ μπορεί να δείξει bitcoin που ελέγχονται μέσω κλειδιών· δεν μπορεί να δείξει ότι μια υπηρεσία οφείλει σε έναν συγκεκριμένο πελάτη το υπόλοιπο που εμφανίζεται σε έναν λογαριασμό. Μέχρι να μπορείτε να κάνετε ανάληψη και να ελέγχετε τα κλειδιά, το υπόλοιπό σας είναι η υπόσχεση της υπηρεσίας να σας παρέχει bitcoin, όχι bitcoin που μπορείτε να επαληθεύσετε άμεσα και να δαπανήσετε εσείς οι ίδιοι.

Σε ένα **μη θεματοφυλακτικό** ή **αυτοθεματοφυλακτικό** πορτοφόλι, ΕΣΕΙΣ ελέγχετε τα κλειδιά. Το πορτοφόλι υπογράφει [συναλλαγές](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) με τη δική σας εξουσιοδότηση. Ενδέχεται να εξακολουθούν να υπάρχουν εξαρτήσεις από λογισμικό, υλικό, διακομιστές ή δίκτυα, αλλά κανένας [θεματοφύλακας](https://curriculum.myfirstbitcoin.org/lexicon/en/#custodian) δεν χρειάζεται να εγκρίνει μια έγκυρη δαπάνη στην αλυσίδα.

[Η θεματοφυλακή](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) δεν είναι πάντα εμφανής από τη διεπαφή. Αν δεν μπορείτε να ελέγχετε τη μέθοδο ανάκτησης και χρειάζεστε την έγκριση μιας εταιρείας για μια ανάληψη, πιθανότατα χρησιμοποιείτε έναν [θεματοφύλακα](https://curriculum.myfirstbitcoin.org/lexicon/en/#custodian). [Η αυτοθεματοφυλακή](https://curriculum.myfirstbitcoin.org/lexicon/en/#self-custody) δεν αποτελεί δοκιμασία της προσωπικής σας αξίας· το σημαντικό βήμα είναι να αναγνωρίσετε την εμπιστοσύνη που απαιτείται και τον κίνδυνο που ενέχεται.

**Δοκιμάστε το:** Διαβάστε δύο έτοιμες περιγραφές πορτοφολιών. Για καθεμία, αναφέρετε ποιος ελέγχει τα κλειδιά, ποιος θα μπορούσε να αποκαταστήσει την πρόσβαση και έναν κίνδυνο που πρέπει να ελέγξετε πριν χρησιμοποιήσετε το πορτοφόλι.
