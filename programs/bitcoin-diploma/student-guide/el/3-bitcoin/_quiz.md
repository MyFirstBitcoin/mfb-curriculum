# Quiz – Ασφαλής χρήση του Bitcoin: σύντομος έλεγχος γνώσεων

## Question 1

Ένα πορτοφόλι Bitcoin:

* [ ] Αποθηκεύει bitcoin
* [x] Διαχειρίζεται κλειδιά και υπογράφει
* [ ] Καταργεί την προστασία των μυστικών στοιχείων
* [ ] Αντιστρέφει συναλλαγές

### Explanation

Το Bitcoin καταγράφεται στο κοινόχρηστο καθολικό· ένα πορτοφόλι διαχειρίζεται τις πληροφορίες που χρησιμοποιούνται για την πρόσβαση σε αυτό και τη χρήση του. Ανατρέξτε στον Οδηγό Σπουδαστή, Ενότητα 3, «Πορτοφόλια».

## Question 2

Τι κοινοποιείτε για να λάβετε bitcoin;

* [ ] Φράση ανάκτησης
* [ ] Ιδιωτικό κλειδί
* [x] Διεύθυνση λήψης
* [ ] Κωδικός πρόσβασης

### Explanation

Μια διεύθυνση λήψης μπορεί να κοινοποιηθεί για να λάβετε μια πληρωμή. Οι φράσεις ανάκτησης, τα ιδιωτικά κλειδιά και οι κωδικοί πρόσβασης πρέπει να παραμένουν μυστικά. Ανατρέξτε στον Οδηγό Σπουδαστή, Ενότητα 3, «Διευθύνσεις» και «Κλειδιά».

## Question 3

Καταχωρίσατε τη φράση ανάκτησης στο διαδίκτυο. Ποιο είναι το ασφαλέστερο επόμενο βήμα;

* [ ] Περιμένετε
* [ ] Στείλτε τη στην υποστήριξη
* [x] Νέα φράση ανάκτησης και έπειτα μεταφορά χρημάτων
* [ ] Χρησιμοποιήστε ξανά τη φράση ανάκτησης

### Explanation

Θεωρήστε ότι μια φράση ανάκτησης που καταχωρίστηκε στο διαδίκτυο έχει διαρρεύσει. Δημιουργήστε ένα νέο πορτοφόλι με νέα φράση ανάκτησης και έπειτα μεταφέρετε τα χρήματα μόνο αφού επαληθεύσετε τον προορισμό. Ανατρέξτε στον Οδηγό Σπουδαστή, Ενότητα 3, «Φράσεις ανάκτησης».

## Question 4

Ποια είναι η κύρια διαφορά μεταξύ της χρήσης με θεματοφυλακή και της χρήσης με αυτοθεματοφυλακή;

* [x] Ποιος ελέγχει τα κλειδιά
* [ ] Η δυνατότητα αντιστροφής πληρωμών
* [ ] Το όριο προσφοράς
* [ ] Τα τέλη συναλλαγών

### Explanation

Η χρήση με θεματοφυλακή και η χρήση με αυτοθεματοφυλακή διαφέρουν ως προς το ποιος ελέγχει τα κλειδιά και φέρει τη σχετική ευθύνη. Καμία από τις δύο δεν εγγυάται ασφάλεια ή δυνατότητα αντιστροφής των συναλλαγών. Ανατρέξτε στον Οδηγό Σπουδαστή, Ενότητα 3, «Χρήση με και χωρίς θεματοφυλακή».
