# Quiz – Ασφαλής χρήση του Bitcoin: σύντομος έλεγχος γνώσεων

## Question 1

Ένα πορτοφόλι Bitcoin:

* [ ] Αποθηκεύει bitcoin
* [x] Διαχειρίζεται κλειδιά και υπογράφει
* [ ] Καταργεί την προστασία των μυστικών στοιχείων
* [ ] Αντιστρέφει συναλλαγές

### Explanation

Το Bitcoin καταγράφεται στο κοινόχρηστο καθολικό· ένα πορτοφόλι διαχειρίζεται τις πληροφορίες που χρησιμοποιούνται για την πρόσβαση σε αυτό και τη χρήση του. Ανατρέξτε στον Οδηγό Εκπαιδευομένου, Ενότητα 3, «Πορτοφόλια».

## Question 2

Τι κοινοποιείτε για να λάβετε bitcoin;

* [ ] Φράση ανάκτησης
* [ ] Ιδιωτικό κλειδί
* [x] Διεύθυνση λήψης
* [ ] Κωδικός πρόσβασης

### Explanation

Μπορείτε να κοινοποιήσετε μια διεύθυνση λήψης για να λάβετε μια πληρωμή. Οι φράσεις ανάκτησης, τα ιδιωτικά κλειδιά και οι κωδικοί πρόσβασης πρέπει να παραμένουν μυστικά. Ανατρέξτε στον Οδηγό Εκπαιδευομένου, Ενότητα 3, «Διευθύνσεις» και «Κλειδιά».

## Question 3

Καταχωρίσατε τη φράση ανάκτησης στο διαδίκτυο. Ποιο είναι το ασφαλέστερο επόμενο βήμα;

* [ ] Περιμένετε
* [ ] Τη στέλνετε στην υποστήριξη
* [x] Δημιουργείτε νέα φράση ανάκτησης και μετά μεταφέρετε τα χρήματα
* [ ] Χρησιμοποιείτε ξανά την ίδια φράση ανάκτησης

### Explanation

Θεωρήστε ότι μια φράση ανάκτησης που καταχωρίστηκε στο διαδίκτυο έχει εκτεθεί. Δημιουργήστε ένα νέο πορτοφόλι με νέα φράση ανάκτησης και, στη συνέχεια, μεταφέρετε τα χρήματα μόνο αφού επαληθεύσετε τον προορισμό. Ανατρέξτε στον Οδηγό Εκπαιδευομένου, Ενότητα 3, «Φράσεις ανάκτησης».

## Question 4

Ποια είναι η διαφορά μεταξύ θεματοφυλακής και αυτοθεματοφυλακής;

* [x] Ποιος ελέγχει τα κλειδιά
* [ ] Δυνατότητα αντιστροφής πληρωμών
* [ ] Όριο προσφοράς
* [ ] Ευθύνη

### Explanation

Η χρήση με θεματοφυλακή και η χρήση με αυτοθεματοφυλακή διαφέρουν ως προς το ποιος ελέγχει τα κλειδιά και φέρει τη σχετική ευθύνη. Καμία από τις δύο δεν εγγυάται ασφάλεια ή δυνατότητα αντιστροφής των συναλλαγών. Ανατρέξτε στον Οδηγό Εκπαιδευομένου, Ενότητα 3, «Χρήση με και χωρίς θεματοφυλακή».
