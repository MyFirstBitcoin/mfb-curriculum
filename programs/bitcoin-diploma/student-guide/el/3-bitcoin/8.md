# 3.8 Ανάκτηση πορτοφολιού και έλεγχος φράσης ανάκτησης

Τι θα κάνατε αν η αρχική συσκευή παρουσίαζε βλάβη; Ένα σχέδιο ανάκτησης θα πρέπει να σας επιτρέπει να επαναφέρετε το αναμενόμενο πορτοφόλι χωρίς να εκθέτετε τις πληροφορίες ανάκτησης. Εξασκηθείτε μόνο με υλικό που έχει προετοιμάσει ο εκπαιδευτής, με κενό υλικό ή με υλικό προσομοίωσης. Ακολουθήστε την επίσημη μέθοδο ανάκτησης του πορτοφολιού σε ιδιωτικό περιβάλλον, επιβεβαιώστε ότι πρόκειται για το αναμενόμενο εκπαιδευτικό πορτοφόλι και επαναφέρετε στην αρχική του κατάσταση ή επιστρέψτε το προσωρινό υλικό με ασφάλεια.

Ένας εκπαιδευτής μπορεί να παρακολουθεί τη διαδικασία σας χωρίς να βλέπει καμία από τις [λέξεις ανάκτησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase). Μην εισάγετε ποτέ μια πραγματική [φράση ανάκτησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) σε ιστότοπο, μήνυμα ή συνηθισμένη φόρμα υπολογιστή.

Μη χρησιμοποιείτε ένα εκπαιδευτικό πορτοφόλι ή τις πληροφορίες ανάκτησής του για τη φύλαξη σημαντικών χρηματικών ποσών μετά το Δίπλωμα. Ένα προσωπικό πορτοφόλι, αν επιλέξετε να δημιουργήσετε ένα αργότερα, χρειάζεται νέα ρύθμιση σε ιδιωτικό περιβάλλον και νέες πληροφορίες ανάκτησης.

Ο στόχος δεν είναι να φαίνεται εύκολη η ανάκτηση. Είναι να κατανοήσετε τη διαδικασία προτού μια βλάβη της συσκευής δημιουργήσει πίεση.
