# 3.4 Κλειδιά

Η ιδιοκτησία στο Bitcoin διασφαλίζεται μέσω κρυπτογραφικών κλειδιών.


<!-- card: definition -->
> **Definition – Ιδιωτικό κλειδί**
>
> Ένα [ιδιωτικό κλειδί](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) είναι μυστική πληροφορία που επιτρέπει σε ένα πορτοφόλι να δημιουργεί έγκυρες [ψηφιακές υπογραφές](https://curriculum.myfirstbitcoin.org/lexicon/en/#digital-signature). Μια υπογραφή εξουσιοδοτεί τη δαπάνη των bitcoin που ελέγχονται από το αντίστοιχο κλειδί. Όποιος αποκτήσει το [ιδιωτικό κλειδί](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) μπορεί συνήθως να δαπανήσει αυτά τα κεφάλαια.


Ένα [**δημόσιο κλειδί**](https://curriculum.myfirstbitcoin.org/lexicon/en/#public-key) παράγεται μαθηματικά από το [ιδιωτικό κλειδί](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key). Βοηθά στην επαλήθευση μιας υπογραφής χωρίς να αποκαλύπτει το [ιδιωτικό κλειδί](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key). Οι διευθύνσεις δημιουργούνται από σχετικές με [δημόσια κλειδιά](https://curriculum.myfirstbitcoin.org/lexicon/en/#public-key) πληροφορίες.

Ο βασικός κανόνας είναι απλός:

**Οι δημόσιες πληροφορίες για τη λήψη χρημάτων μπορούν να κοινοποιούνται. Οι ιδιωτικές πληροφορίες για τη δαπάνη χρημάτων πρέπει να παραμένουν μυστικές.**

Μια [ψηφιακή υπογραφή](https://curriculum.myfirstbitcoin.org/lexicon/en/#digital-signature) αποδεικνύει ότι το απαιτούμενο [ιδιωτικό κλειδί](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) εξουσιοδότησε μια [συναλλαγή](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Δεν τοποθετεί το [ιδιωτικό κλειδί](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) μέσα στη [συναλλαγή](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). [Οι κόμβοι](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) επαληθεύουν την υπογραφή πριν αποδεχτούν τη δαπάνη.

Τα περισσότερα πορτοφόλια για αρχάριους χρησιμοποιούν [μία μόνο υπογραφή](https://curriculum.myfirstbitcoin.org/lexicon/en/#single-signature): ένα ιδιωτικό κλειδί εξουσιοδοτεί μια συναλλαγή. Τα σύγχρονα πορτοφόλια διαχειρίζονται αυτόματα πολλά κλειδιά. Οι αρχάριοι δεν πρέπει να αντιγράφουν ή να χειρίζονται μεμονωμένα [ιδιωτικά κλειδιά](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) σε μορφή συμβολοσειράς. Προστατεύστε το εγκεκριμένο αντίγραφο ασφαλείας του πορτοφολιού και ακολουθήστε τη διαδικασία ανάκτησής του.

Κανένας νόμιμος εκπαιδευτής, εταιρεία πορτοφολιών, υπάλληλος ανταλλακτηρίου, εργαζόμενος τεχνικής υποστήριξης ή προγραμματιστής του Bitcoin δεν χρειάζεται το [ιδιωτικό κλειδί](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) ή τη [φράση ανάκτησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase). Όποιος σας τα ζητά θα πρέπει να αντιμετωπίζεται ως απειλή.


<!-- card: light -->
> **Δοκιμάστε το:** Ταξινομήστε τα έτοιμα παραδείγματα σε τρεις ομάδες: πληροφορίες που μπορούν να κοινοποιηθούν με ασφάλεια για τη λήψη χρημάτων, μυστικές πληροφορίες για τη δαπάνη χρημάτων και πληροφορίες που μπορεί να είναι δημόσιες αλλά θα πρέπει και πάλι να παραμένουν ιδιωτικές όταν συνδέονται με ένα πρόσωπο.
