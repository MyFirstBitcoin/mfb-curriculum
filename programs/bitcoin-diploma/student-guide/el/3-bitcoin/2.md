# 3.2 Πορτοφόλια

> **Definition – Πορτοφόλι Bitcoin**
>
> Ένα [πορτοφόλι Bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-wallet) είναι ένα εργαλείο που διαχειρίζεται τις πληροφορίες που απαιτούνται για τη λήψη και την έγκριση [συναλλαγών Bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Μπορεί να είναι μια εφαρμογή, μια ειδική συσκευή ή μια υπηρεσία. Το Bitcoin καταγράφεται ως [συναλλακτικό](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) ιστορικό στο κοινόχρηστο [καθολικό](https://curriculum.myfirstbitcoin.org/lexicon/en/#ledger)· ένα πορτοφόλι διαχειρίζεται τα κλειδιά που ελέγχουν τη δαπάνη, αντί να αποθηκεύει bitcoin σε ένα τηλέφωνο ή σε άλλη συσκευή.


Τι θα συνέβαινε αν το τηλέφωνό σας σταματούσε να λειτουργεί; Το αρχείο καταγραφής του Bitcoin θα εξακολουθούσε να υπάρχει, αλλά η πρόσβαση θα εξαρτιόταν από τα κλειδιά και τη μέθοδο ανάκτησης που χρησιμοποιεί το πορτοφόλι. Ένα πορτοφόλι βοηθά στη δημιουργία πληροφοριών λήψης, στην εμφάνιση υπολοίπων και [συναλλακτικού](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) ιστορικού, καθώς και στην έγκριση δαπανών. Δεν καταργεί την ανάγκη να κατανοείτε ποιος ελέγχει την πρόσβαση.

> **Dark – Ένα πορτοφόλι διαχειρίζεται την πρόσβαση· δεν περιέχει bitcoin**
>
> Το Bitcoin καταγράφεται στο κοινόχρηστο [καθολικό](https://curriculum.myfirstbitcoin.org/lexicon/en/#ledger), όχι μέσα στο τηλέφωνό σας. Πριν χρησιμοποιήσετε ένα πορτοφόλι, πρέπει να γνωρίζετε ποιος ελέγχει τα κλειδιά, πώς ανακτάται η πρόσβαση και τι θα συνέβαινε αν η συσκευή ή η υπηρεσία έπαυε να λειτουργεί.

Η πρώτη ερώτηση για οποιοδήποτε πορτοφόλι είναι: **ποιος ελέγχει τα κλειδιά;** Πριν χρησιμοποιήσετε ένα εργαλείο, ελέγξτε ποιος μπορεί να εγκρίνει μια πληρωμή, πώς ανακτάται η πρόσβαση και ποιες μεθόδους πληρωμής υποστηρίζει. [**Το λογισμικό ανοικτού κώδικα**](https://curriculum.myfirstbitcoin.org/lexicon/en/#open-source-software) δημοσιεύει τον κώδικά του ώστε να μπορεί οποιοσδήποτε να τον επιθεωρήσει και να τον ελέγξει. Αυτό μπορεί να ενισχύσει τη διαφάνεια και να διευκολύνει τον εντοπισμό λαθών, αλλά αποτελεί μόνο έναν χρήσιμο παράγοντα: δεν αποδεικνύει ότι ένα εργαλείο είναι ασφαλές, συντηρείται, έχει εγκατασταθεί σωστά ή είναι κατάλληλο για τις ανάγκες σας.

Συγκρίνετε τη [θεματοφυλακή](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), την ανάκτηση, το κατά πόσο ο κώδικας είναι διαθέσιμος για δημόσιο έλεγχο, τη συμβατότητα, την [ιδιωτικότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy), το κόστος, τη συντήρηση και τη διαθέσιμη υποστήριξη, χωρίς να θεωρείτε κανένα πορτοφόλι ως την κατάλληλη επιλογή για όλους. Ξεκινήστε με ένα περιβάλλον που έχει προετοιμάσει ο εκπαιδευτής σας· μην επιλέγετε ένα εργαλείο επειδή σας το προτείνει κάποιος άγνωστος.


> **Callout – Εκπαιδευτικά και προσωπικά πορτοφόλια**
>
> Κατά τη διάρκεια του Διπλώματος, ενδέχεται να δημιουργήσετε ένα πορτοφόλι ή να σημειώσετε [λέξεις ανάκτησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) στο πλαίσιο της εξάσκησης. Η τάξη είναι ένα περιβάλλον μάθησης: οι πληροφορίες μπορεί κατά λάθος να γίνουν ορατές, να αντιγραφούν, να κοινοποιηθούν ή να εκτεθούν. Για τον λόγο αυτό, ένα εκπαιδευτικό πορτοφόλι θα πρέπει κανονικά να είναι άδειο ή προσομοιωμένο και δεν θα πρέπει να χρησιμοποιείται για τη φύλαξη σημαντικών χρηματικών ποσών. Όπου είναι πρακτικά εφικτό, κλείνει, επαναφέρεται ή επιστρέφεται στο τέλος του Διπλώματος. Ο εκπαιδευτής σας μπορεί να επιλέξει μια δραστηριότητα με πραγματικές συναλλαγές μικρής αξίας, αλλά θα πρέπει να εξηγήσει τον σκοπό της και τους πρόσθετους κινδύνους για την ιδιωτικότητα, την ασφάλεια και την απώλεια χρημάτων πριν συμμετάσχει οποιοσδήποτε. Ένα πορτοφόλι που προορίζεται για τη φύλαξη σημαντικών χρηματικών ποσών χρειάζεται νέα ρύθμιση σε ιδιωτικό περιβάλλον και νέες πληροφορίες ανάκτησης. Ο εκπαιδευτής σας μπορεί να εξηγήσει τη διαφορά, αλλά σε καμία περίπτωση δεν απαιτείται να δημιουργήσετε προσωπικό πορτοφόλι για να ολοκληρώσετε το Δίπλωμα.
