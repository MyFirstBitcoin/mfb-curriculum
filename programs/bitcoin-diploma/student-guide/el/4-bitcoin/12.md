# 4.12 Χάρτες τοπικών πόρων και γνωριμία με την κοινότητα

Οι αναλυτικές δραστηριότητες για τους τοπικούς πόρους, οι πίνακες καταγραφής και οι καταχωρίσεις που υπόκεινται σε αλλαγές ανήκουν στον [Κόμβο Πόρων](https://curriculum.myfirstbitcoin.org/resources/?search=map). Οι χάρτες και οι κοινοτικοί κατάλογοι μπορούν να σας βοηθήσουν να βρείτε εμπόρους, εκπαιδευτικούς, συναντήσεις και κυκλικές οικονομίες, αλλά οι καταχωρίσεις μπορεί να είναι ελλιπείς ή παρωχημένες.

Προτού βασιστείτε σε μια καταχώριση, ελέγξτε πότε επαληθεύτηκε, επιβεβαιώστε τις πληροφορίες ανεξάρτητα και φροντίστε να έχετε έναν εναλλακτικό τρόπο πληρωμής ή συμμετοχής. Μια τοπική κοινότητα μπορεί να προσφέρει πρακτική υποστήριξη, αλλά η ιδιότητα του μέλους δεν αποτελεί απόδειξη αξιοπιστίας. Μην αποκαλύπτετε [φράσεις ανάκτησης](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase), υπόλοιπα, διευθύνσεις κατοικίας ή μέτρα ασφαλείας σε μια συνάντηση. Να είστε επιφυλακτικοί όταν μια νέα γνωριμία προσφέρει διαχείριση επενδύσεων, ιδιωτική ανταλλαγή, εγγυημένες αποδόσεις ή επείγουσα βοήθεια.
