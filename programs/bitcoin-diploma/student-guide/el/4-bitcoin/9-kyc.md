# 4.9 Πλεονεκτήματα και μειονεκτήματα με και χωρίς KYC

[Οι KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) και [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) διαδρομές συνεπάγονται διαφορετικούς [συμβιβασμούς](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Καμία από τις δύο ετικέτες δεν αναιρεί την ανάγκη για προσεκτική αξιολόγηση.


<!-- card: callout -->
> **Η ιδιωτικότητα δεν εξαλείφει τους νομικούς κινδύνους ή τους κινδύνους για τη σωματική ασφάλεια**
>
> Ούτε το [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ούτε το [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) είναι αυτομάτως η καλύτερη επιλογή. Συγκρίνετε την πραγματική διαδρομή, ανατρέξτε σε επικαιροποιημένες τοπικές οδηγίες όταν οι κανόνες είναι ασαφείς και μην παραβιάζετε την τοπική νομοθεσία ούτε να εκθέτετε τον εαυτό σας σε σωματικό κίνδυνο επιδιώκοντας την [ιδιωτικότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Μια [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) υπηρεσία ενδέχεται να ζητήσει το νόμιμο ονοματεπώνυμό σας, έγγραφο ταυτοποίησης, διεύθυνση, φωτογραφία, πληροφορίες για την προέλευση των κεφαλαίων ή άλλα στοιχεία. Αυτό μπορεί να επιτρέπει στην υπηρεσία να συμμορφώνεται με τους τοπικούς κανόνες, να συνδέεται με τράπεζες, να ορίζει υψηλότερα όρια ή να υποστηρίζει την ανάκτηση λογαριασμού.

[Το KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) δημιουργεί επίσης κινδύνους για τα δεδομένα. Η υπηρεσία ενδέχεται να αποθηκεύει μια μόνιμη σύνδεση μεταξύ της ταυτότητας, των μεθόδων πληρωμής και των σε bitcoin [συναλλαγών](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Μια παραβίαση δεδομένων, ένα νομικό αίτημα, μια εσωτερική κατάχρηση ή μια αλλαγή πολιτικής ενδέχεται να εκθέσει αυτές τις πληροφορίες ή να περιορίσει την πρόσβαση σε αυτές.

Μια [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) διαδρομή ενδέχεται να συλλέγει λιγότερα στοιχεία ταυτότητας. Αυτό μπορεί να ενισχύσει την οικονομική [ιδιωτικότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Ενδέχεται επίσης να περιλαμβάνει αντισυμβαλλομένους που υπόκεινται σε λιγότερη ρυθμιστική εποπτεία, χαμηλότερη ρευστότητα, υψηλότερες [τιμές](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), μειωμένη υποστήριξη, μεγαλύτερο κίνδυνο απάτης ή νομικούς περιορισμούς.

Συγκρίνετε την πραγματική διαδρομή:

[Η ιδιωτικότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) δεν είναι μυστικότητα που εξαλείφει κάθε κίνδυνο. Είναι η δυνατότητα να ελέγχετε τις πληροφορίες που σας αφορούν. Μην παραβιάζετε την τοπική νομοθεσία ούτε να εκθέτετε τον εαυτό σας σε σωματικό κίνδυνο επιδιώκοντας την [ιδιωτικότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Αναζητήστε επικαιροποιημένη καθοδήγηση για την περιοχή σας από κατάλληλα καταρτισμένο άτομο όταν οι κανόνες είναι ασαφείς.
