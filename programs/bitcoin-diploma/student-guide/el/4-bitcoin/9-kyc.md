# 4.9 Πλεονεκτήματα και μειονεκτήματα με και χωρίς KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) και [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ως διαδικασίες συνεπάγονται διαφορετικούς [συμβιβασμούς](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Κανένας από τους δύο χαρακτηρισμούς δεν αναιρεί την ανάγκη προσεκτικής αξιολόγησης.


<!-- card: callout -->
> **Η ιδιωτικότητα δεν εξαλείφει τους νομικούς κινδύνους ούτε τους κινδύνους για τη σωματική ασφάλεια**
>
> Ούτε η διαδικασία [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ούτε η διαδικασία [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) είναι αυτομάτως η καλύτερη επιλογή. Συγκρίνετε την πραγματική διαδικασία, αναζητήστε επικαιροποιημένη καθοδήγηση για τα τοπικά δεδομένα όταν οι κανόνες είναι ασαφείς και μην παραβιάζετε την τοπική νομοθεσία ούτε να εκθέτετε τον εαυτό σας σε σωματικό κίνδυνο επιδιώκοντας την [ιδιωτικότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Μια υπηρεσία [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) μπορεί να ζητήσει το νόμιμο ονοματεπώνυμό σας, έγγραφο ταυτοποίησης, διεύθυνση, φωτογραφία, πληροφορίες για την προέλευση των κεφαλαίων ή άλλα στοιχεία. Αυτό μπορεί να επιτρέψει στην υπηρεσία να συμμορφώνεται με τους τοπικούς κανόνες, να συνδέεται με τράπεζες, να ορίζει υψηλότερα όρια ή να υποστηρίζει την ανάκτηση λογαριασμού.

[Το KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) δημιουργεί επίσης κινδύνους για τα δεδομένα. Η υπηρεσία ενδέχεται να αποθηκεύει μια μόνιμη σύνδεση μεταξύ της ταυτότητας, των μεθόδων πληρωμής και των σε bitcoin [συναλλαγών](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Μια παραβίαση δεδομένων, ένα νομικό αίτημα, μια εσωτερική κατάχρηση ή μια αλλαγή πολιτικής μπορεί να εκθέσει αυτές τις πληροφορίες ή να περιορίσει την πρόσβαση σε αυτές.

Μια διαδικασία [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ενδέχεται να συλλέγει λιγότερα στοιχεία ταυτοποίησης. Αυτό μπορεί να βελτιώσει την οικονομική [ιδιωτικότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Μπορεί επίσης να περιλαμβάνει αντισυμβαλλομένους που υπόκεινται σε λιγότερη εποπτεία, χαμηλότερη ρευστότητα, υψηλότερες [τιμές](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), μειωμένη υποστήριξη, μεγαλύτερο κίνδυνο απάτης ή νομικούς περιορισμούς.

Συγκρίνετε την πραγματική διαδικασία:


| Ερώτηση | Διαδικασία KYC | Διαδικασία no-KYC |
| --- | --- | --- |
| Ποια στοιχεία ταυτοποίησης συλλέγονται; |  |  |
| Ποιος αποθηκεύει τα δεδομένα και για πόσο καιρό; |  |  |
| Μπορεί η συναλλαγή να συσχετιστεί με την ταυτότητά σας μέσω της αλυσίδας συστοιχιών; |  |  |
| Τι προστασία από απάτη παρέχεται; |  |  |
| Ποιος κίνδυνος αντισυμβαλλομένου υπάρχει; |  |  |
| Ποια όρια και ποιες χρεώσεις ισχύουν; |  |  |
| Ποια τοπική νομοθεσία εφαρμόζεται; |  |  |
| Τι συμβαίνει σε περίπτωση διαφοράς; |  |  |


[Η ιδιωτικότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) δεν σημαίνει μυστικότητα που σας προφυλάσσει από κάθε κίνδυνο. Είναι η δυνατότητα να ελέγχετε τις πληροφορίες που σας αφορούν. Μην παραβιάζετε την τοπική νομοθεσία ούτε να εκθέτετε τον εαυτό σας σε σωματικό κίνδυνο επιδιώκοντας την [ιδιωτικότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Ζητήστε επικαιροποιημένη καθοδήγηση για τα τοπικά δεδομένα από αρμόδιο επαγγελματία όταν οι κανόνες είναι ασαφείς.
