# 4.9 KYC ও KYC-বিহীন পদ্ধতির সুবিধা-অসুবিধা

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) এবং [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) পথে থাকে ভিন্ন ধরনের [সুবিধা-অসুবিধার ভারসাম্য](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)। কোনো নামই সতর্কভাবে মূল্যায়নের প্রয়োজন দূর করে না।


<!-- card: callout -->
> **গোপনীয়তা আইনি বা শারীরিক নিরাপত্তার ঝুঁকি দূর করে না**
>
> না [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) না [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)—কোনোটিই আপনা-আপনি সেরা নয়। বাস্তব পথটি তুলনা করুন, নিয়ম অস্পষ্ট হলে হালনাগাদ স্থানীয় নির্দেশনা অনুসরণ করুন, এবং স্থানীয় আইন ভেঙে বা নিজেকে শারীরিক বিপদের মুখে ফেলে অর্জন করতে যাবেন না [গোপনীয়তা](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)।


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

একটি [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) পরিষেবা আইনগত নাম, পরিচয়পত্র, ঠিকানা, ছবি, অর্থের উৎসের তথ্য বা অন্যান্য নথি চাইতে পারে। এর ফলে পরিষেবাটি স্থানীয় নিয়ম মেনে চলতে, ব্যাংকের সঙ্গে সংযুক্ত হতে, উচ্চতর সীমা নির্ধারণ করতে বা অ্যাকাউন্ট পুনরুদ্ধারে সহায়তা করতে পারে।

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) তথ্যসংক্রান্ত ঝুঁকিও তৈরি করে। পরিষেবাটি স্থায়ীভাবে যোগসূত্রযুক্ত করে রাখতে পারে পরিচয়, অর্থ পরিশোধের পদ্ধতি এবং বিটকয়েন [লেনদেন](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction)। তথ্য ফাঁস, আইনি অনুরোধ, অভ্যন্তরীণ অপব্যবহার বা নীতি পরিবর্তনের ফলে সেই তথ্য প্রকাশিত হতে পারে অথবা তার ব্যবহার সীমিত হতে পারে।

একটি [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) পথে পরিচয়সংক্রান্ত তথ্য কম সংগ্রহ করা হতে পারে। এতে উন্নত হতে পারে আর্থিক [গোপনীয়তা](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)। এতে যুক্ত থাকতে পারে কম নিয়ন্ত্রণাধীন লেনদেনের অপর পক্ষ, কম তারল্য, বেশি [দাম](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), কম সহায়তা, প্রতারণার বেশি ঝুঁকি বা আইনি বিধিনিষেধও।

বাস্তব পথটি তুলনা করুন:


| প্রশ্ন | KYC পথ | No-KYC পথ |
| --- | --- | --- |
| পরিচয়সংক্রান্ত কী কী তথ্য সংগ্রহ করা হয়? |  |  |
| তথ্য কে সংরক্ষণ করে এবং কত দিনের জন্য? |  |  |
| লেনদেনটির সঙ্গে অন-চেইন যোগসূত্র স্থাপন করা যায় কি? |  |  |
| প্রতারণা থেকে সুরক্ষার কী ব্যবস্থা আছে? |  |  |
| লেনদেনের অপর পক্ষকে ঘিরে কী ঝুঁকি আছে? |  |  |
| কী কী সীমা ও ফি প্রযোজ্য? |  |  |
| কোন স্থানীয় আইন প্রযোজ্য? |  |  |
| বিরোধ দেখা দিলে কী হয়? |  |  |


[গোপনীয়তা](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) মানে সব ঝুঁকি থেকে আড়ালে থাকা নয়। এটি নিজের সম্পর্কে তথ্য নিয়ন্ত্রণ করার সক্ষমতা। স্থানীয় আইন ভেঙে বা নিজেকে শারীরিক বিপদের মুখে ফেলে অর্জন করতে যাবেন না [গোপনীয়তা](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)। নিয়ম অস্পষ্ট হলে একজন যোগ্য ব্যক্তির কাছ থেকে হালনাগাদ স্থানীয় নির্দেশনা নিন।
