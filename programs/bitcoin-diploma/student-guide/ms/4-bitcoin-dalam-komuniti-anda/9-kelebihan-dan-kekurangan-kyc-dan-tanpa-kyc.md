# 4.9 Kelebihan dan Kekurangan KYC dan Tanpa KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) dan [tanpa KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) melibatkan [kompromi yang berbeza](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Kedua-dua label ini tidak menghapuskan keperluan untuk penilaian yang teliti.


<!-- card: callout -->
> **Privasi tidak menghapuskan risiko undang-undang atau risiko terhadap keselamatan fizikal**
>
> Baik [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) mahupun [tanpa KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) tidak semestinya pilihan terbaik. Bandingkan laluan sebenar, gunakan panduan tempatan terkini apabila peraturan tidak jelas, dan jangan melanggar undang-undang tempatan atau mendedahkan diri anda kepada bahaya fizikal demi [privasi](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Sesebuah perkhidmatan [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) mungkin meminta nama sah, dokumen pengenalan diri, alamat, gambar, maklumat sumber dana, atau rekod lain. Ini mungkin membolehkan perkhidmatan tersebut mematuhi peraturan tempatan, berhubung dengan bank, menetapkan had yang lebih tinggi, atau menyokong pemulihan akaun.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) juga mewujudkan risiko data. Perkhidmatan tersebut mungkin menyimpan perkaitan kekal antara identiti, kaedah pembayaran, dan [transaksi bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Kebocoran data, permintaan undang-undang, penyalahgunaan dalaman, atau perubahan dasar mungkin mendedahkan maklumat tersebut atau menyekat akses kepadanya.

Laluan [tanpa KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) mungkin mengumpulkan kurang maklumat identiti. Ini boleh meningkatkan [privasi kewangan](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Laluan ini juga mungkin melibatkan pihak niaga yang kurang dikawal selia, kecairan yang lebih rendah, [harga yang lebih tinggi](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), sokongan yang berkurangan, risiko penipuan yang lebih besar, atau sekatan undang-undang.

Bandingkan laluan sebenar:


| Soalan | Laluan KYC | Laluan tanpa KYC |
| --- | --- | --- |
| Apakah data identiti yang dikumpulkan? |  |  |
| Siapakah yang menyimpan data tersebut dan untuk berapa lama? |  |  |
| Bolehkah transaksi tersebut dikaitkan melalui rekod pada rantaian blok? |  |  |
| Apakah perlindungan terhadap penipuan yang tersedia? |  |  |
| Apakah risiko pihak niaga yang wujud? |  |  |
| Apakah had dan fi yang dikenakan? |  |  |
| Apakah undang-undang tempatan yang terpakai? |  |  |
| Apakah yang berlaku semasa pertikaian? |  |  |


[Privasi](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) bukanlah kerahsiaan yang melindungi daripada segala risiko. Privasi ialah keupayaan untuk mengawal maklumat tentang diri anda. Jangan melanggar undang-undang tempatan atau mendedahkan diri anda kepada bahaya fizikal demi [privasi](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Dapatkan panduan tempatan terkini daripada individu yang berkelayakan apabila peraturan tidak jelas.
