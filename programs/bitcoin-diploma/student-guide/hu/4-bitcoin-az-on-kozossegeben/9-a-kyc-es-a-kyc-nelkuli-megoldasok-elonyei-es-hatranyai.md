# 4.9 A KYC és a KYC nélküli megoldások előnyei és hátrányai

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) és [KYC nélküli](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) megoldások különböző [kompromisszumokkal járnak](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Egyik megjelölés sem teszi szükségtelenné a körültekintő értékelést.


<!-- card: callout -->
> **A magánszféra védelme nem szünteti meg a jogi vagy a testi épséget fenyegető kockázatokat**
>
> A [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) és a [KYC nélküli](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) megoldás közül egyik sem automatikusan a legjobb választás. Hasonlítsa össze a tényleges megoldásokat, támaszkodjon naprakész helyi útmutatásra, ha a szabályok nem egyértelműek, és ne sértse meg a helyi jogszabályokat, illetve ne tegye ki magát fizikai veszélynek a [magánszféra védelméért](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

A [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) szolgáltató kérheti a hivatalos nevét, személyazonosító okmányát, lakcímét, fényképét, a pénzeszközei eredetére vonatkozó információkat vagy más dokumentumokat. Ez lehetővé teheti a szolgáltató számára, hogy megfeleljen a helyi szabályoknak, banki kapcsolatokat alakítson ki, magasabb limiteket állapítson meg, vagy támogassa a fiókhoz való hozzáférés helyreállítását.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) esetén adatbiztonsági kockázat is keletkezik. A szolgáltató tartósan tárolhatja a személyazonosság, a fizetési módok és a bitcoin[-tranzakciók közötti kapcsolatot](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Egy adatvédelmi incidens, hatósági megkeresés, belső visszaélés vagy szabályzatváltozás felfedheti ezeket az információkat, vagy korlátozhatja a hozzájuk való hozzáférést.

A [KYC nélküli](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) megoldás kevesebb személyazonosító adatot gyűjthet. Ez javíthatja a pénzügyi [magánszféra védelmét](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Ugyanakkor kevésbé szabályozott partnerekkel, alacsonyabb likviditással, magasabb [árakkal](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), kevesebb ügyféltámogatással, nagyobb csalási kockázattal vagy jogi korlátozásokkal is járhat.

Hasonlítsa össze a tényleges megoldásokat:


| Kérdés | KYC megoldás | KYC nélküli megoldás |
| --- | --- | --- |
| Milyen személyazonosító adatokat gyűjtenek? |  |  |
| Ki tárolja az adatokat, és mennyi ideig? |  |  |
| Összekapcsolható-e a tranzakció a személyazonossággal a blokkláncon? |  |  |
| Milyen védelem létezik a csalások ellen? |  |  |
| Milyen partnerkockázat áll fenn? |  |  |
| Milyen limitek és díjak érvényesek? |  |  |
| Milyen helyi jogszabályok vonatkoznak rá? |  |  |
| Mi történik vita esetén? |  |  |


[A magánszféra védelme](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) nem jelent minden kockázattal szemben védelmet nyújtó titkosságot. Azt jelenti, hogy Ön rendelkezhet a saját adatai felett. Ne sértse meg a helyi jogszabályokat, és ne tegye ki magát fizikai veszélynek a [magánszféra védelméért](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Kérjen naprakész helyi útmutatást megfelelően képzett szakembertől, ha a szabályok nem egyértelműek.
