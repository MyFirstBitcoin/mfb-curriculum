# Quiz – ทำความเข้าใจเรื่องเงิน: แบบทดสอบสั้น

## คำถาม 1

เหตุใดเงินจึงเป็นที่ยอมรับ?

* [x] คาดว่าผู้อื่นจะยอมรับเงินนั้น
* [ ] เงินทำให้สินค้ามีมูลค่าเท่ากัน
* [ ] เงินขจัดกฎเกณฑ์ทั้งหมด
* [ ] เงินเปลี่ยนบริการให้เป็นสินค้า

### คำอธิบาย

เงินช่วยให้คนที่ไม่รู้จักกันแลกเปลี่ยนกันได้แม้ในเวลาที่ต่างกัน เพราะผู้คนคาดหวังว่าผู้อื่นจะยอมรับเงินนั้นในภายหลัง ทั้งนี้ยังต้องอาศัยความไว้วางใจ กฎเกณฑ์ และการยอมรับทางสังคม โปรดทบทวนคู่มือผู้เรียน บทที่ 1 “เหตุใดจึงมีเงิน”

## คำถาม 2

ตั้งราคา ชำระเงิน ออมเงิน: ตรงกับหน้าที่ใดตามลำดับ?

* [ ] เครื่องรักษามูลค่า; หน่วยวัดมูลค่า; สื่อกลางในการแลกเปลี่ยน
* [x] หน่วยวัดมูลค่า; สื่อกลางในการแลกเปลี่ยน; เครื่องรักษามูลค่า
* [ ] สื่อกลางในการแลกเปลี่ยน; เครื่องรักษามูลค่า; หน่วยวัดมูลค่า
* [ ] ความขาดแคลน; ความขาดแคลน; ความขาดแคลน

### คำอธิบาย

หน่วยวัดมูลค่าใช้แสดงราคา สื่อกลางในการแลกเปลี่ยนเป็นสิ่งที่ยอมรับในการชำระเงิน และเครื่องรักษามูลค่าช่วยเก็บมูลค่าไว้ใช้ในอนาคต โปรดทบทวนคู่มือผู้เรียน บทที่ 1 “หน้าที่และคุณสมบัติของเงิน”

## คำถาม 3

เหตุใดการนำข้าวไปแลกรองเท้าจึงไม่สำเร็จ?

* [ ] ราคาแตกต่างกัน
* [x] ความต้องการไม่ตรงกัน
* [ ] ไม่มีการอนุมัติจากธนาคาร
* [ ] ข้าวใช้แลกเปลี่ยนไม่ได้

### คำอธิบาย

การแลกเปลี่ยนสิ่งของโดยตรงทำได้ยากเมื่อแต่ละฝ่ายไม่ได้ต้องการสิ่งที่อีกฝ่ายเสนอในเวลาเดียวกัน นี่คือปัญหาความต้องการของทั้งสองฝ่ายที่ต้องตรงกัน โปรดทบทวนคู่มือผู้เรียน บทที่ 1 “การแลกเปลี่ยนสิ่งของและความต้องการของทั้งสองฝ่ายที่ต้องตรงกัน”

## คำถาม 4

ราคา +10% รายได้ +5%: กำลังซื้อเป็นอย่างไร?

* [ ] เพิ่มขึ้น
* [ ] เท่าเดิม
* [x] ลดลง
* [ ] ไม่สามารถระบุได้

### คำอธิบาย

กำลังซื้อคือความสามารถของเงินในการซื้อสิ่งต่าง ๆ หากราคาสูงขึ้นเร็วกว่ารายได้ รายได้นั้นจะซื้อของได้น้อยลง โปรดทบทวนคู่มือผู้เรียน บทที่ 1 “เงินเฟ้อและกำลังซื้อ”
