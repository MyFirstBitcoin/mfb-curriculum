# Quiz – การใช้บิตคอยน์อย่างปลอดภัย: แบบทดสอบสั้น

## คำถาม 1

กระเป๋าเงินบิตคอยน์:

* [ ] เก็บบิตคอยน์
* [x] จัดการกุญแจและลงลายมือชื่อ
* [ ] ยกเลิกการปกป้องความลับ
* [ ] ย้อนกลับธุรกรรม

### คำอธิบาย

บิตคอยน์ถูกบันทึกไว้ในบัญชีแยกประเภทที่ใช้ร่วมกัน ส่วนกระเป๋าเงินทำหน้าที่จัดการข้อมูลที่ใช้เข้าถึงและใช้งานบิตคอยน์ ทบทวนคู่มือผู้เรียน โมดูล 3 หัวข้อ “กระเป๋าเงิน”

## คำถาม 2

สิ่งที่แบ่งปันได้เพื่อรับบิตคอยน์:

* [ ] วลีกู้คืน
* [ ] กุญแจส่วนตัว
* [x] ที่อยู่สำหรับรับ
* [ ] รหัสผ่าน

### คำอธิบาย

สามารถแบ่งปันที่อยู่สำหรับรับเพื่อรับชำระเงินได้ ส่วนวลีกู้คืน กุญแจส่วนตัว และรหัสผ่านต้องเก็บเป็นความลับ ทบทวนคู่มือผู้เรียน โมดูล 3 หัวข้อ “ที่อยู่” และ “กุญแจ”

## คำถาม 3

เมื่อกรอกวลีกู้คืนทางออนไลน์แล้ว ขั้นตอนถัดไปที่ปลอดภัยที่สุดคืออะไร?

* [ ] รอ
* [ ] ส่งวลีกู้คืนให้ฝ่ายสนับสนุน
* [x] สร้างวลีกู้คืนใหม่ แล้วจึงย้ายเงิน
* [ ] ใช้วลีกู้คืนเดิมซ้ำ

### คำอธิบาย

ให้ถือว่าวลีกู้คืนที่กรอกทางออนไลน์รั่วไหลแล้ว สร้างกระเป๋าเงินใหม่ด้วยวลีกู้คืนใหม่ จากนั้นย้ายเงินหลังจากตรวจสอบปลายทางแล้วเท่านั้น ทบทวนคู่มือผู้เรียน โมดูล 3 หัวข้อ “วลีกู้คืน”

## คำถาม 4

ความแตกต่างหลักระหว่างการใช้งานแบบให้ผู้ให้บริการดูแลและแบบดูแลด้วยตนเองคืออะไร?

* [x] ใครเป็นผู้ควบคุมกุญแจ
* [ ] ความสามารถในการย้อนกลับการชำระเงิน
* [ ] ขีดจำกัดปริมาณเหรียญ
* [ ] ค่าธรรมเนียมธุรกรรม

### คำอธิบาย

การใช้งานแบบให้ผู้ให้บริการดูแลและแบบดูแลด้วยตนเองแตกต่างกันที่ผู้ควบคุมกุญแจและผู้รับผิดชอบในส่วนที่เกี่ยวข้อง ทั้งสองแบบไม่ได้รับประกันความปลอดภัยหรือความสามารถในการย้อนกลับธุรกรรม ทบทวนคู่มือผู้เรียน โมดูล 3 หัวข้อ “การใช้งานแบบให้ผู้ให้บริการดูแลและแบบไม่ให้ผู้ให้บริการดูแล”
