# Quiz – การใช้บิตคอยน์อย่างปลอดภัย: แบบทดสอบสั้น

## Question 1

กระเป๋าเงินบิตคอยน์:

* [ ] เก็บบิตคอยน์
* [x] จัดการกุญแจและลงลายมือชื่อ
* [ ] ยกเลิกการปกป้องข้อมูลลับ
* [ ] ย้อนกลับธุรกรรม

### Explanation

บิตคอยน์ถูกบันทึกไว้ในบัญชีแยกประเภทที่ใช้ร่วมกัน ส่วนกระเป๋าเงินจัดการข้อมูลที่ใช้ในการเข้าถึงและใช้งานบิตคอยน์ ทบทวนคู่มือผู้เรียน โมดูล 3 หัวข้อ “กระเป๋าเงิน”

## Question 2

ข้อมูลที่แบ่งปันเพื่อรับบิตคอยน์ได้:

* [ ] วลีกู้คืน
* [ ] กุญแจส่วนตัว
* [x] ที่อยู่รับบิตคอยน์
* [ ] รหัสผ่าน

### Explanation

สามารถแบ่งปันที่อยู่รับบิตคอยน์เพื่อรับชำระเงินได้ ส่วนวลีกู้คืน กุญแจส่วนตัว และรหัสผ่านต้องเก็บเป็นความลับ ทบทวนคู่มือผู้เรียน โมดูล 3 หัวข้อ “ที่อยู่” และ “กุญแจ”

## Question 3

เมื่อกรอกวลีกู้คืนทางออนไลน์แล้ว ขั้นตอนถัดไปที่ปลอดภัยที่สุดคืออะไร?

* [ ] รอ
* [ ] ส่งวลีกู้คืนให้ฝ่ายสนับสนุน
* [x] สร้างวลีกู้คืนใหม่ แล้วจึงย้ายเงิน
* [ ] ใช้วลีกู้คืนเดิมซ้ำ

### Explanation

ให้ถือว่าวลีกู้คืนที่กรอกทางออนไลน์รั่วไหลแล้ว สร้างกระเป๋าเงินใหม่ด้วยวลีกู้คืนใหม่ จากนั้นจึงย้ายเงินหลังจากตรวจสอบปลายทางแล้วเท่านั้น ทบทวนคู่มือผู้เรียน โมดูล 3 หัวข้อ “วลีกู้คืน”

## Question 4

การฝากดูแลกับการดูแลด้วยตนเองแตกต่างกันอย่างไร?

* [x] ผู้ควบคุมกุญแจ
* [ ] ความสามารถในการย้อนกลับการชำระเงิน
* [ ] ขีดจำกัดอุปทาน
* [ ] ความรับผิดชอบ

### Explanation

การใช้งานแบบฝากดูแลและแบบดูแลด้วยตนเองแตกต่างกันที่ผู้ควบคุมกุญแจและผู้รับผิดชอบในส่วนที่เกี่ยวข้อง ทั้งสองแบบไม่ได้รับประกันความปลอดภัยหรือความสามารถในการย้อนกลับธุรกรรม ทบทวนคู่มือผู้เรียน โมดูล 3 หัวข้อ “การใช้งานแบบฝากดูแลและแบบไม่ฝากดูแล”
