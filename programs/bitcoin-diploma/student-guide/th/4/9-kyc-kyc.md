# 4.9 ข้อดีและข้อเสียของการทำ KYC และการไม่ทำ KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) และ [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) เป็นแนวทางที่มีความแตกต่างกันในด้าน [ข้อแลกเปลี่ยน](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). ไม่ว่าจะเป็นแนวทางใด ก็ยังจำเป็นต้องประเมินอย่างรอบคอบ


<!-- card: callout -->
> **ความเป็นส่วนตัวไม่ได้ขจัดความเสี่ยงทางกฎหมายหรือความเสี่ยงต่อความปลอดภัยทางร่างกาย**
>
> ไม่ว่าจะเป็น [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) หรือ [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ก็ไม่ได้เป็นทางเลือกที่ดีที่สุดเสมอไป โปรดเปรียบเทียบแนวทางที่ใช้จริง อ้างอิงคำแนะนำในท้องถิ่นที่เป็นปัจจุบันเมื่อกฎเกณฑ์ไม่ชัดเจน และอย่าฝ่าฝืนกฎหมายท้องถิ่นหรือทำให้ตนเองตกอยู่ในอันตรายทางร่างกายเพื่อแสวงหา [ความเป็นส่วนตัว](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

บริการแบบ [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) อาจขอชื่อจริงตามกฎหมาย เอกสารยืนยันตัวตน ที่อยู่ รูปถ่าย ข้อมูลแหล่งที่มาของเงิน หรือบันทึกอื่น ๆ ซึ่งอาจช่วยให้ผู้ให้บริการปฏิบัติตามกฎเกณฑ์ท้องถิ่น เชื่อมต่อกับธนาคาร กำหนดวงเงินที่สูงขึ้น หรือรองรับการกู้คืนบัญชีได้

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ยังสร้างความเสี่ยงด้านข้อมูลด้วย ผู้ให้บริการอาจจัดเก็บความเชื่อมโยงอย่างถาวรระหว่างตัวตน วิธีการชำระเงิน และธุรกรรมบิตคอยน์ ซึ่งเป็น [ธุรกรรม](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) ที่อาจถูกเชื่อมโยงกับตัวตนได้ เหตุข้อมูลรั่วไหล คำร้องขอตามกฎหมาย การนำข้อมูลไปใช้ในทางที่ผิดภายในองค์กร หรือการเปลี่ยนแปลงนโยบาย อาจทำให้ข้อมูลดังกล่าวถูกเปิดเผยหรือถูกจำกัดการใช้งาน

แนวทางแบบ [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) อาจเก็บรวบรวมข้อมูลระบุตัวตนน้อยกว่า ซึ่งอาจช่วยเพิ่มระดับทางการเงินในด้าน [ความเป็นส่วนตัว](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). แต่ก็อาจเกี่ยวข้องกับคู่ธุรกรรมที่อยู่ภายใต้การกำกับดูแลน้อยกว่า สภาพคล่องที่ต่ำกว่า และระดับที่สูงขึ้นของ [ราคา](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), รวมถึงการสนับสนุนที่ลดลง ความเสี่ยงจากการฉ้อโกงที่มากขึ้น หรือข้อจำกัดทางกฎหมาย

เปรียบเทียบแนวทางที่ใช้จริง:


| คำถาม | แนวทางแบบ KYC | แนวทางแบบ no-KYC |
| --- | --- | --- |
| มีการเก็บรวบรวมข้อมูลระบุตัวตนอะไรบ้าง? |  |  |
| ใครเป็นผู้จัดเก็บข้อมูล และจัดเก็บไว้นานเท่าใด? |  |  |
| สามารถเชื่อมโยงธุรกรรมบนบล็อกเชนได้หรือไม่? |  |  |
| มีมาตรการป้องกันการฉ้อโกงอะไรบ้าง? |  |  |
| มีความเสี่ยงจากคู่ธุรกรรมอะไรบ้าง? |  |  |
| มีข้อจำกัดและค่าธรรมเนียมอะไรบ้าง? |  |  |
| อยู่ภายใต้กฎหมายท้องถิ่นใดบ้าง? |  |  |
| เมื่อเกิดข้อพิพาท จะมีการดำเนินการอย่างไร? |  |  |


[ความเป็นส่วนตัว](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) ไม่ใช่การปกปิดข้อมูลที่ทำให้พ้นจากความเสี่ยงทุกอย่าง แต่คือความสามารถในการควบคุมข้อมูลเกี่ยวกับตนเอง อย่าฝ่าฝืนกฎหมายท้องถิ่นหรือทำให้ตนเองตกอยู่ในอันตรายทางร่างกายเพื่อแสวงหา [ความเป็นส่วนตัว](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). โปรดขอคำแนะนำในท้องถิ่นที่เป็นปัจจุบันจากผู้มีคุณสมบัติเหมาะสมเมื่อกฎเกณฑ์ไม่ชัดเจน
