# 4.1 บิตคอยน์ในชุมชนของคุณ

![](https://cdn.sanity.io/images/vje9ehw2/production/119ea5325cea83e0cdbf15651f5a19becfb07cdf-1536x1024.svg)

นี่คือขั้น **เชื่อมโยง** ของหลักสูตรประกาศนียบัตรบิตคอยน์ ท่านจะเชื่อมโยงข้อบกพร่องของระบบเงินสมัยใหม่และ [ข้อแลกเปลี่ยน](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off) แนวทางตอบโจทย์ของบิตคอยน์ และความรับผิดชอบในการใช้งานอย่างปลอดภัยจาก **โมดูล 1–3** เข้ากับความต้องการหรือโอกาสในท้องถิ่น ทางเลือกที่เป็นไปได้จริง และงานฝึกปฏิบัติที่ปลอดภัย ไม่ได้มีการคาดหวังให้ท่านหันมาใช้บิตคอยน์หรือสรุปว่าบิตคอยน์เป็นทางเลือกที่ดีที่สุดในทุกสถานการณ์ในท้องถิ่น

บิตคอยน์เป็นโพรโทคอลเดียวที่ใช้ทั่วโลก แต่ผู้คนใช้งานภายใต้เงื่อนไขในท้องถิ่นที่แตกต่างกัน การเข้าถึงอินเทอร์เน็ต โทรศัพท์ กฎหมาย ภาษี [สกุลเงิน](https://curriculum.myfirstbitcoin.org/lexicon/en/#currency) ธนาคาร ร้านค้า ค่าธรรมเนียม ภาษา ความปลอดภัย และการสนับสนุนทางเทคนิค ล้วนส่งผลต่อสิ่งที่จะเป็นประโยชน์

ผู้สอนของท่านเป็นผู้เลือกกิจกรรมการเรียนรู้ในโมดูลนี้ เป้าหมายไม่ใช่การสาธิตเครื่องมือทุกชนิด แต่เป็นการเชื่อมโยงแนวคิดจาก **โมดูล 1–3** เข้ากับทางเลือกจริงในชุมชนของท่าน ผู้สอนอาจเชิญผู้เชี่ยวชาญในท้องถิ่นมาเมื่อจำเป็นต้องใช้ความรู้เฉพาะทาง

ใช้รายการตรวจสอบความปลอดภัยจาก **โมดูล 3** ตลอดทุกโมดูลที่เกี่ยวข้องกับท้องถิ่น การใช้บิตคอยน์หรือเครื่องมือที่ระบุชื่อในแบบฝึกหัดภายใต้การดูแลไม่ได้หมายความว่า My First Bitcoin หรือผู้สอนของท่านแนะนำให้ใช้งานบ่อยครั้ง อย่างต่อเนื่อง หรือด้วยมูลค่าที่สูงขึ้น จุดประสงค์คือเพื่อเปรียบเทียบทางเลือกและ [ข้อแลกเปลี่ยน](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off) ของทางเลือกนั้นให้เข้าใจเพียงพอที่จะตัดสินใจด้วยตนเอง

บันทึกประเด็นหลักของท่านสำหรับ **โมดูล 4**:


| ประเด็นหลักในการเรียนรู้เกี่ยวกับท้องถิ่น | บันทึกของท่าน |
| --- | --- |
| ปัญหาหรือโอกาสในท้องถิ่น |  |
| ทางเลือกที่เป็นไปได้จริง |  |
| การฝึกปฏิบัติหรือสถานการณ์จำลองที่ปลอดภัย |  |
| ประโยชน์และความเสี่ยงหลัก |  |
