# Quiz – บิตคอยน์ทำงานอย่างไร: แบบทดสอบสั้น

## คำถาม 1

เงินดิจิทัลหน่วยเดียวถูกใช้ชำระสองครั้ง ระบบต้อง:

* [x] ปฏิเสธการใช้จ่ายซ้ำ
* [ ] ซ่อนการชำระเงิน
* [ ] เพิ่มราคาของเงินนั้น
* [ ] ยกเลิกค่าธรรมเนียม

### คำอธิบาย

ข้อมูลดิจิทัลสามารถคัดลอกได้ ดังนั้นระบบเงินจึงต้องป้องกันไม่ให้เงินหน่วยเดียวกันถูกใช้จ่ายซ้ำสองครั้ง และระบุให้ได้ว่าธุรกรรมใดถูกต้องตามกฎ โปรดทบทวนคู่มือผู้เรียน บทที่ 2 “ความพยายามสร้างเงินดิจิทัลในยุคแรกและปัญหาการใช้จ่ายซ้ำ”

## คำถาม 2

การกระจายศูนย์ของบิตคอยน์หมายถึง:

* [ ] บริษัทเดียวอนุมัติการชำระเงิน
* [x] การบังคับใช้กฎโดยผู้เข้าร่วมที่เป็นอิสระต่อกัน
* [ ] นักขุดเปลี่ยนกฎได้อย่างอิสระ
* [ ] ทุกคนมีอิทธิพลเท่ากัน

### คำอธิบาย

บิตคอยน์กระจายการตรวจสอบและการบังคับใช้กฎไปยังผู้เข้าร่วมที่เป็นอิสระต่อกัน การกระจายศูนย์ไม่ได้หมายความว่ามีบริษัทเดียวควบคุมเครือข่าย หรือทุกคนมีอิทธิพลเท่ากัน โปรดทบทวนคู่มือผู้เรียน บทที่ 2 “การกระจายศูนย์”

## คำถาม 3

โหนดบิตคอยน์:

* [x] ตรวจสอบการปฏิบัติตามกฎของเครือข่าย
* [ ] สร้างบิตคอยน์
* [ ] เก็บบิตคอยน์
* [ ] รับประกันการชำระเงิน

### คำอธิบาย

โหนดตรวจสอบการปฏิบัติตามกฎของบิตคอยน์อย่างเป็นอิสระ และปฏิเสธข้อมูลที่ไม่ถูกต้องตามกฎ โหนดไม่ได้สร้างบิตคอยน์ตามคำขอหรือเก็บบิตคอยน์ไว้ในโทรศัพท์ โปรดทบทวนคู่มือผู้เรียน บทที่ 2 “ผู้ใช้ โหนด และนักขุด”

## คำถาม 4

เหตุใดจึงเรียกบิตคอยน์ว่าเงินที่มั่นคง?

* [ ] ราคาเพิ่มขึ้นเสมอ
* [x] อุปทานเปิดเผยต่อสาธารณะและมีจำกัด
* [ ] มีบริษัทเดียวควบคุม
* [ ] การชำระเงินเป็นส่วนตัว

### คำอธิบาย

บางคนอธิบายว่าบิตคอยน์เป็นเงินที่มั่นคง เพราะกฎด้านอุปทานเปิดเผยต่อสาธารณะและมีการจำกัดการออกเหรียญ นี่คือการประเมินโดยมีเหตุผลรองรับ ไม่ใช่คำรับรองเรื่องราคาหรือความเป็นส่วนตัว โปรดทบทวนคู่มือผู้เรียน บทที่ 2 “บิตคอยน์ในฐานะเงินดิจิทัลที่มั่นคง”
