# 2.13 บิตคอยน์ในฐานะเงินดิจิทัลที่มั่นคง

ดังที่ **โมดูล 1** ได้เกริ่นไว้ [**เงินที่มั่นคง**](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money) หมายถึงเงินที่เพิ่มปริมาณได้ยาก และมีคุณสมบัติที่เอื้อต่อการใช้งานอย่างเชื่อถือได้ตลอดช่วงเวลาที่ผ่านไป คำนี้แสดงถึงการประเมินตามเกณฑ์ จึงควรพิจารณาตรวจสอบแทนที่จะยอมรับว่าเป็นเพียงคำเรียก

บิตคอยน์รวมคุณสมบัติที่ไม่เคยมีอยู่ร่วมกันมาก่อนใน [สินทรัพย์หนึ่งเดียว](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset):


<!-- micrographic: bitcoin-money-properties-01 -->



| คุณสมบัติ | คำอธิบายด้วยภาษาที่เข้าใจง่าย |
| --- | --- |
| ความคงทน | บัญชีแยกประเภทถูกคัดลอกเก็บไว้ในหลายโหนด การเข้าถึงขึ้นอยู่กับการเก็บรักษาคีย์ที่ถูกต้องไว้ |
| ความสะดวกในการเคลื่อนย้าย | ธุรกรรมที่ลงลายมือชื่อแล้วสามารถโอนมูลค่าผ่านเครือข่ายการสื่อสารได้ |
| ความสามารถในการแบ่งเป็นหน่วยย่อย | หนึ่งบิตคอยน์ (1 BTC) แบ่งได้เป็น 100,000,000 แซต |
| ความสามารถในการใช้ทดแทนกัน | จำนวนเงินที่เท่ากันสามารถใช้จ่ายได้ภายใต้กฎของโพรโทคอลเดียวกัน แม้ว่าประวัติธุรกรรมที่เปิดเผยต่อสาธารณะอาจส่งผลต่อวิธีที่ผู้ให้บริการบางรายปฏิบัติต่อเงินบางส่วน |
| ความขาดแคลน | การออกเหรียญเป็นไปตามกฎที่เปิดเผยต่อสาธารณะ โดยมีปริมาณสูงสุด 21 ล้าน |
| ความสามารถในการตรวจสอบ | โหนดสามารถตรวจสอบปริมาณเหรียญ กฎของธุรกรรม และหลักฐานความเป็นเจ้าของได้ |
| การเป็นที่ยอมรับ | การยอมรับกำลังเพิ่มขึ้นในบางพื้นที่ แต่ในหลายชุมชนยังคงต่ำกว่าการยอมรับสกุลเงินประจำชาติอย่างมาก |


บิตคอยน์สามารถทำหน้าที่ทั้งสามประการของเงินได้ แต่ทำได้ไม่เท่ากันในทุกพื้นที่:

* ในฐานะ [**เครื่องเก็บรักษามูลค่า**](https://curriculum.myfirstbitcoin.org/lexicon/en/#store-of-value), ปริมาณของบิตคอยน์คาดการณ์ได้ แต่ในตลาด [ราคา](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) มีความผันผวน
* ในฐานะ [**สื่อกลางในการแลกเปลี่ยน**](https://curriculum.myfirstbitcoin.org/lexicon/en/#medium-of-exchange), บิตคอยน์สามารถโอนได้โดยไม่ต้องผ่านธนาคาร แต่การยอมรับ ค่าธรรมเนียม และเครื่องมือชำระเงินแตกต่างกันไป
* ในฐานะ [**หน่วยวัดมูลค่า**](https://curriculum.myfirstbitcoin.org/lexicon/en/#unit-of-account), สามารถระบุจำนวนเงินเป็นบิตคอยน์หรือ [แซต](https://curriculum.myfirstbitcoin.org/lexicon/en/#satoshi), แต่สินค้าส่วนใหญ่ยังคงกำหนดราคาเป็นเงินเฟียต [สกุลต่าง ๆ](https://curriculum.myfirstbitcoin.org/lexicon/en/#currency).

ดังนั้น บิตคอยน์จึงมีทั้งประโยชน์และ [ข้อแลกเปลี่ยน](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off).

**ประโยชน์ที่อาจได้รับ** ได้แก่ การเป็นเจ้าของโดยตรง ปริมาณที่คาดการณ์ได้ การโอนทั่วโลก การเปิดให้ทุกคนมีส่วนร่วม กฎที่โปร่งใส และความสามารถในการต้านทานการปิดกั้นโดยฝ่ายใดฝ่ายหนึ่ง

[**ข้อแลกเปลี่ยน**](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off) ได้แก่ [ราคา](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) [ที่ผันผวน](https://curriculum.myfirstbitcoin.org/lexicon/en/#volatility), ความรับผิดชอบในการรักษาความปลอดภัยด้วยตนเอง, ข้อเท็จจริงที่ว่าการชำระเงินที่ถูกต้องมักย้อนกลับได้ยากหรือย้อนกลับไม่ได้เลย, การเปลี่ยนแปลงของ [ค่าธรรมเนียมธุรกรรม](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction-fee), การพึ่งพาไฟฟ้าและการสื่อสารเพื่อโอนเงินในรูปแบบดิจิทัล, การที่สาธารณชนเข้าถึง [ธุรกรรม](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) ที่บันทึกไว้, และการยอมรับที่จำกัด

การที่ท่านจะเรียกบิตคอยน์ว่าเป็น [เงินที่มั่นคง](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money) ควรขึ้นอยู่กับเกณฑ์ของท่าน โปรดเปรียบเทียบบิตคอยน์กับ [เงินเฟียต](https://curriculum.myfirstbitcoin.org/lexicon/en/#fiat-money), โลหะมีค่า, และ [สินทรัพย์อื่น ๆ](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset) โดยใช้มาตรฐานเดียวกัน

**ตรวจสอบคุณค่าในชุมชน:** บิตคอยน์มี [คุณค่า](https://curriculum.myfirstbitcoin.org/lexicon/en/#value) ในชุมชนของท่านหรือไม่? ในคำตอบของท่าน โปรดแยกคำถามสามข้อออกจากกัน: ในตลาดมี [ราคา](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) ที่สังเกตได้เท่าใด? มีที่ใดยอมรับบิตคอยน์บ้างหรือไม่? ความชอบส่วนตัวหรือ [อคติ](https://curriculum.myfirstbitcoin.org/lexicon/en/#bias) ใดส่งผลต่อการตัดสินของท่าน? [ราคา](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), ประโยชน์ใช้สอยในชุมชน, และการยอมรับส่วนบุคคลมีความเกี่ยวข้องกัน แต่ไม่ใช่สิ่งเดียวกัน
