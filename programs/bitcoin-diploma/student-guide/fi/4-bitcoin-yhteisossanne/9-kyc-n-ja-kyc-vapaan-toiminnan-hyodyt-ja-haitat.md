# 4.9 KYC:n ja KYC-vapaan toiminnan hyödyt ja haitat

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ja [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ovat menettelyjä, joissa tehdään erilaisia [kompromisseja](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Kumpikaan nimitys ei poista huolellisen arvioinnin tarvetta.


<!-- card: callout -->
> **Yksityisyys ei poista oikeudellisia riskejä eikä fyysiseen turvallisuuteen kohdistuvia riskejä**
>
> Ei [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) eikä [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ole automaattisesti paras vaihtoehto. Vertailkaa käytännön menettelyjä, hyödyntäkää ajantasaista paikallista ohjeistusta sääntöjen ollessa epäselviä älkääkä rikkoko paikallista lakia tai altistako itseänne fyysiselle vaaralle tavoitellessanne [yksityisyyttä](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Yksittäinen [KYC-vaatimuksia noudattava](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) palvelu voi pyytää virallista nimeä, henkilöllisyystodistusta, osoitetta, valokuvaa, tietoja varojen alkuperästä tai muita asiakirjoja. Näin palvelu voi noudattaa paikallisia sääntöjä, luoda yhteyksiä pankkeihin, asettaa korkeampia käyttörajoja tai tukea tilin palauttamista.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) aiheuttaa myös tietoriskejä. Palvelu voi tallentaa pysyvän yhteyden henkilöllisyyden, maksutapojen ja bitcoinilla tehtyjen [siirtojen välille](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Tietomurto, viranomaisen tietopyyntö, sisäinen väärinkäyttö tai toimintaperiaatteiden muutos voi paljastaa nämä tiedot tai rajoittaa niiden käyttöä.

Yksittäinen [no-KYC-periaatetta noudattava](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) menettely voi kerätä vähemmän henkilöllisyystietoja. Tämä voi parantaa taloudellista [yksityisyyttä](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Siihen voi myös liittyä vähemmän säänneltyjä vastapuolia, heikompaa likviditeettiä, korkeampia [hintoja](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), vähäisempää tukea, suurempi petosriski tai oikeudellisia rajoituksia.

Vertailkaa käytännön menettelyjä:


| Kysymys | KYC-menettely | No-KYC-menettely |
| --- | --- | --- |
| Mitä henkilöllisyystietoja kerätään? |  |  |
| Kuka säilyttää tietoja ja kuinka kauan? |  |  |
| Voidaanko siirto yhdistää henkilöllisyyteen lohkoketjussa? |  |  |
| Millaista suojaa petoksia vastaan on tarjolla? |  |  |
| Millaisia vastapuoliriskejä on olemassa? |  |  |
| Mitä rajoja ja maksuja sovelletaan? |  |  |
| Mitä paikallista lainsäädäntöä sovelletaan? |  |  |
| Mitä riitatilanteessa tapahtuu? |  |  |


[Yksityisyys](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) ei tarkoita salassa pysymistä kaikilta riskeiltä. Se on kykyä hallita itseänne koskevia tietoja. Älkää rikkoko paikallista lakia tai altistako itseänne fyysiselle vaaralle tavoitellessanne [yksityisyyttä](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Pyytäkää pätevältä asiantuntijalta ajantasaista paikallista ohjeistusta, kun säännöt ovat epäselviä.
