# 4.9 KYC र गैर-KYC का फाइदा र बेफाइदा

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) र [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) मार्गहरूमा फरक हुन्छ [लाभ–हानिको सन्तुलन](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)। यीमध्ये कुनै पनि नामले सावधानीपूर्वक मूल्याङ्कन गर्नुपर्ने आवश्यकता हटाउँदैन।


<!-- card: callout -->
> **गोपनीयताले कानुनी वा शारीरिक सुरक्षासम्बन्धी जोखिम हटाउँदैन**
>
> न त [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) न [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) नै स्वतः सर्वोत्तम हुन्छ। वास्तविक मार्गको तुलना गर्नुहोस्, नियमहरू अस्पष्ट हुँदा अद्यावधिक स्थानीय मार्गदर्शन लिनुहोस्, र स्थानीय कानुन उल्लङ्घन गरेर वा आफूलाई शारीरिक खतरामा पारेर नखोज्नुहोस् [गोपनीयता](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)।


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

एउटा [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) सेवाले कानुनी नाम, परिचयपत्र, ठेगाना, तस्बिर, रकमको स्रोतसम्बन्धी जानकारी वा अन्य अभिलेख माग्न सक्छ। यसबाट उक्त सेवाले स्थानीय नियमहरू पालना गर्न, बैंकहरूसँग जोडिन, उच्च सीमा तोक्न वा खाता पुनःप्राप्तिमा सहयोग गर्न सक्छ।

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ले तथ्याङ्कसम्बन्धी जोखिम पनि सिर्जना गर्छ। सेवाले पहिचान र भुक्तानी विधिहरूसँग स्थायी रूपमा जोडेर राख्न सक्छ बिटक्वाइनका [कारोबारहरू](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction)। तथ्याङ्क चुहावट, कानुनी माग, आन्तरिक दुरुपयोग वा नीतिमा परिवर्तनले उक्त जानकारी उजागर गर्न वा त्यसमा पहुँच सीमित गर्न सक्छ।

एउटा [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) मार्गले पहिचानसम्बन्धी कम जानकारी सङ्कलन गर्न सक्छ। यसले सुधार गर्न सक्छ वित्तीय [गोपनीयता](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)। यसमा कम नियमन गरिएका कारोबारका अर्को पक्ष, कम तरलता, बढी [मूल्य](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), कम सहयोग, ठगीको बढी जोखिम वा कानुनी प्रतिबन्धहरू पनि हुन सक्छन्।

वास्तविक मार्गको तुलना गर्नुहोस्:


| प्रश्न | KYC मार्ग | no-KYC मार्ग |
| --- | --- | --- |
| पहिचानसम्बन्धी के-कस्ता तथ्याङ्क सङ्कलन गरिन्छन्? |  |  |
| तथ्याङ्क कसले र कति समयसम्म भण्डारण गर्छ? |  |  |
| के कारोबारलाई अन-चेन जोड्न सकिन्छ? |  |  |
| ठगीबाट जोगाउन कस्तो सुरक्षा व्यवस्था छ? |  |  |
| कारोबारको अर्को पक्षबाट कस्तो जोखिम छ? |  |  |
| के-कस्ता सीमा र शुल्क लागू हुन्छन्? |  |  |
| कुन स्थानीय कानुन लागू हुन्छ? |  |  |
| विवाद हुँदा के हुन्छ? |  |  |


[गोपनीयता](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) भनेको हरेक जोखिमबाट लुकेर बस्नु होइन। यो आफ्नो बारेमा रहेको जानकारी नियन्त्रण गर्ने क्षमता हो। स्थानीय कानुन उल्लङ्घन गरेर वा आफूलाई शारीरिक खतरामा पारेर नखोज्नुहोस् [गोपनीयता](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)। नियमहरू अस्पष्ट हुँदा योग्य व्यक्तिबाट अद्यावधिक स्थानीय मार्गदर्शन लिनुहोस्।
