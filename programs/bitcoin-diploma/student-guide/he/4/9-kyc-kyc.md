# 4.9 יתרונות וחסרונות של KYC ושל היעדר KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) וכן [ללא KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) הם מסלולים הכרוכים במגוון [פשרות](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). אף אחת מהתוויות אינה מבטלת את הצורך בבחינה קפדנית.


<!-- card: callout -->
> **פרטיות אינה מבטלת סיכונים משפטיים או סיכונים לביטחון האישי**
>
> לא מסלול [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ולא מסלול [ללא KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) הם בהכרח האפשרות הטובה ביותר. השוו את המסלולים בפועל, היעזרו בהנחיות מקומיות עדכניות כאשר הכללים אינם ברורים, ואל תפרו את החוק המקומי או תחשפו את עצמכם לסכנה פיזית במאמץ לשמור על [פרטיות](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

שירות [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) עשוי לבקש שם רשמי, מסמך מזהה, כתובת, תצלום, מידע על מקור הכספים או רשומות אחרות. הדבר עשוי לאפשר לשירות לעמוד בכללים המקומיים, להתחבר לבנקים, לקבוע תקרות גבוהות יותר או לתמוך בשחזור הגישה לחשבון.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) יוצר גם סיכון למידע. השירות עשוי לשמור קישור קבוע בין זהות, אמצעי תשלום וביצוע [עסקאות בביטקוין](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). פרצת אבטחה, דרישה משפטית, שימוש לרעה בידי גורמים פנימיים או שינוי במדיניות עלולים לחשוף את המידע הזה או להגביל את הגישה אליו.

מסלול [ללא KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) עשוי לאסוף פחות מידע מזהה. הדבר עשוי לשפר את [הפרטיות הפיננסית](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). הוא עשוי גם להיות כרוך בצדדים לעסקה הכפופים לפחות פיקוח, בנזילות נמוכה יותר, ברמה גבוהה יותר של [מחירים](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), בתמיכה מצומצמת יותר, בסיכון מוגבר להונאה או בהגבלות משפטיות.

השוו את המסלולים בפועל:


| שאלה | מסלול KYC | מסלול ללא KYC |
| --- | --- | --- |
| אילו נתוני זהות נאספים? |  |  |
| מי שומר את הנתונים ולכמה זמן? |  |  |
| האם ניתן לקשר את העסקה לזהות באמצעות נתונים בשרשרת הבלוקים? |  |  |
| איזו הגנה מפני הונאה קיימת? |  |  |
| איזה סיכון נובע מהצד שכנגד בעסקה? |  |  |
| אילו מגבלות ועמלות חלות? |  |  |
| איזה חוק מקומי חל? |  |  |
| מה קורה בעת מחלוקת? |  |  |


[פרטיות](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) אינה הסתרה המגינה מפני כל סיכון. היא היכולת לשלוט במידע על עצמכם. אל תפרו את החוק המקומי ואל תחשפו את עצמכם לסכנה פיזית במאמץ לשמור על [פרטיות](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). פנו לאדם מוסמך לקבלת הנחיות מקומיות עדכניות כאשר הכללים אינם ברורים.
