# Quiz – איך ביטקוין עובד: בדיקת ידע קצרה

## Question 1

אותה יחידה דיגיטלית משמשת לתשלום פעמיים. המערכת חייבת:

* [x] לדחות את הבזבוז הכפול
* [ ] להסתיר את התשלום
* [ ] להעלות את מחירה
* [ ] לבטל עמלות

### Explanation

אפשר להעתיק מידע דיגיטלי, ולכן מערכת כספית חייבת למנוע שימוש כפול באותה יחידה ולקבוע איזו עסקה תקפה. עיינו במדריך לתלמידים, יחידה 2, „ניסיונות מוקדמים ליצור כסף דיגיטלי ובעיית הבזבוז הכפול”.

## Question 2

משמעות הביזור בביטקוין היא:

* [ ] חברה אחת מאשרת תשלומים
* [x] אכיפת כללים באופן עצמאי
* [ ] כורים משנים את הכללים כרצונם
* [ ] השפעה שווה לכולם

### Explanation

ביטקוין מבזר את האימות ואת אכיפת הכללים בין משתתפים עצמאיים. ביזור אינו אומר שחברה אחת שולטת ברשת או שלכולם יש השפעה שווה. עיינו במדריך לתלמידים, יחידה 2, „ביזור”.

## Question 3

צומת ביטקוין:

* [x] בודק שכללי הרשת מתקיימים
* [ ] יוצר ביטקוין
* [ ] מאחסן ביטקוין
* [ ] מבטיח תשלום

### Explanation

צמתים בודקים באופן עצמאי שהכללים של ביטקוין מתקיימים ודוחים נתונים לא תקפים. הם אינם יוצרים ביטקוין לפי בקשה ואינם מאחסנים ביטקוין בתוך טלפון. עיינו במדריך לתלמידים, יחידה 2, „משתמשים, צמתים וכורים”.

## Question 4

מדוע מכנים את ביטקוין כסף איתן?

* [ ] המחיר תמיד עולה
* [x] היצע מוגבל וגלוי לציבור
* [ ] חברה אחת שולטת בו
* [ ] התשלומים פרטיים

### Explanation

יש המתארים את ביטקוין ככסף איתן משום שכללי ההיצע שלו גלויים לציבור והנפקתו מוגבלת. זו הערכה מנומקת, ולא הבטחה לגבי המחיר או הפרטיות. עיינו במדריך לתלמידים, יחידה 2, „ביטקוין ככסף דיגיטלי איתן”.
