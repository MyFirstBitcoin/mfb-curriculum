# Quiz – שימוש בטוח בביטקוין: בדיקת ידע קצרה

## שאלה 1

ארנק ביטקוין:

* [ ] מאחסן ביטקוין
* [x] מנהל מפתחות וחותם
* [ ] מסיר את ההגנה על מידע סודי
* [ ] מבטל עסקאות

### הסבר

ביטקוין נרשם בספר החשבונות המשותף; ארנק מנהל את המידע המשמש לגישה אליו ולשימוש בו. עיינו במדריך לתלמיד, יחידה 3, ״ארנקים״.

## שאלה 2

מה משתפים כדי לקבל ביטקוין:

* [ ] ביטוי שחזור
* [ ] מפתח פרטי
* [x] כתובת לקבלת תשלום
* [ ] סיסמה

### הסבר

אפשר לשתף כתובת לקבלת תשלום. ביטויי שחזור, מפתחות פרטיים וסיסמאות חייבים להישאר סודיים. עיינו במדריך לתלמיד, יחידה 3, ״כתובות״ ו״מפתחות״.

## שאלה 3

ביטוי שחזור הוזן באינטרנט. מהו הצעד הבא הבטוח ביותר?

* [ ] להמתין
* [ ] לשלוח אותו לתמיכה
* [x] ליצור ביטוי שחזור חדש, ואז להעביר את הכספים
* [ ] להשתמש שוב בביטוי השחזור

### הסבר

התייחסו לביטוי שחזור שהוזן באינטרנט כאילו נחשף. צרו ארנק חדש עם ביטוי שחזור חדש, ואז העבירו את הכספים רק לאחר אימות היעד. עיינו במדריך לתלמיד, יחידה 3, ״ביטויי שחזור״.

## שאלה 4

מהו ההבדל העיקרי בין שימוש במשמורת צד שלישי לבין שימוש במשמורת עצמית?

* [x] מי שולט במפתחות
* [ ] אפשרות לבטל תשלומים
* [ ] מגבלת ההיצע
* [ ] עמלות עסקה

### הסבר

שימוש במשמורת צד שלישי ושימוש במשמורת עצמית נבדלים בזהות הגורם ששולט במפתחות ונושא באחריות הנלווית לכך. אף אחת מהאפשרויות אינה מבטיחה בטיחות או אפשרות לבטל עסקאות. עיינו במדריך לתלמיד, יחידה 3, ״שימוש במשמורת צד שלישי וללא משמורת צד שלישי״.
