# Quiz – שימוש בטוח בביטקוין: בדיקת ידע קצרה

## Question 1

ארנק ביטקוין:

* [ ] מאחסן ביטקוין
* [x] מנהל מפתחות וחותם
* [ ] מסיר את ההגנה על מידע סודי
* [ ] מבטל עסקאות

### Explanation

ביטקוין נרשם בספר החשבונות המשותף; הארנק מנהל את המידע המשמש לגישה אליו ולשימוש בו. עיינו במדריך לתלמיד, יחידה 3, ״ארנקים״.

## Question 2

מה משתפים כדי לקבל ביטקוין:

* [ ] ביטוי שחזור
* [ ] מפתח פרטי
* [x] כתובת לקבלת תשלום
* [ ] סיסמה

### Explanation

אפשר לשתף כתובת לקבלת תשלום. ביטויי שחזור, מפתחות פרטיים וסיסמאות חייבים להישאר סודיים. עיינו במדריך לתלמיד, יחידה 3, ״כתובות״ ו״מפתחות״.

## Question 3

ביטוי שחזור הוזן באינטרנט. מהו הצעד הבא הבטוח ביותר?

* [ ] להמתין
* [ ] לשלוח אותו לתמיכה
* [x] ביטוי שחזור חדש, ואז העברת הכספים
* [ ] להשתמש שוב באותו ביטוי שחזור

### Explanation

התייחסו לביטוי שחזור שהוזן באינטרנט כאל ביטוי שנחשף. צרו ארנק חדש עם ביטוי שחזור חדש, ולאחר מכן העבירו את הכספים רק לאחר אימות היעד. עיינו במדריך לתלמיד, יחידה 3, ״ביטויי שחזור״.

## Question 4

מה ההבדל בין משמורת אצל צד שלישי למשמורת עצמית?

* [x] מי שולט במפתחות
* [ ] אפשרות לבטל תשלומים
* [ ] מגבלת ההיצע
* [ ] אחריות

### Explanation

ההבדל בין שימוש במשמורת אצל צד שלישי לבין שימוש במשמורת עצמית הוא מי שולט במפתחות ונושא באחריות הכרוכה בכך. אף אחת מהאפשרויות אינה מבטיחה בטיחות או אפשרות לבטל עסקאות. עיינו במדריך לתלמיד, יחידה 3, ״שימוש במשמורת אצל צד שלישי וללא משמורת אצל צד שלישי״.
