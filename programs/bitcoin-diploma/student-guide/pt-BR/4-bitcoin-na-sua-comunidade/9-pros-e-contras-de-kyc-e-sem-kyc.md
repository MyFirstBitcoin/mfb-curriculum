# 4.9 Prós e contras de KYC e sem KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) e [sem KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) são caminhos que envolvem diferentes [concessões](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Nenhum dos dois rótulos elimina a necessidade de uma avaliação cuidadosa.


<!-- card: callout -->
> **A privacidade não elimina riscos legais ou de segurança física**
>
> Nem o caminho [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) nem o [sem KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) é automaticamente o melhor. Compare o caminho real, consulte orientações locais atualizadas quando as regras não estiverem claras e não infrinja a lei local nem se exponha a perigos físicos em busca de [privacidade](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Um serviço [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) pode solicitar nome civil, documento de identidade, endereço, fotografia, informações sobre a origem dos recursos ou outros registros. Isso pode permitir que o serviço cumpra as regras locais, se conecte a bancos, defina limites mais altos ou ofereça suporte à recuperação de conta.

[O KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) também cria riscos relacionados a dados. O serviço pode armazenar uma conexão permanente entre identidade, meios de pagamento e [transações](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) em bitcoin. Um vazamento, uma solicitação judicial, um uso indevido interno ou uma mudança de política pode expor ou restringir essas informações.

Um caminho [sem KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) pode coletar menos informações de identidade. Isso pode melhorar a [privacidade](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) financeira. Também pode envolver contrapartes menos reguladas, menor liquidez, [preços](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) mais altos, suporte reduzido, maior risco de fraude ou restrições legais.

Compare o caminho real:


| Pergunta | Caminho KYC | Caminho sem KYC |
| --- | --- | --- |
| Quais dados de identidade são coletados? |  |  |
| Quem armazena os dados e por quanto tempo? |  |  |
| A transação pode ser vinculada on-chain? |  |  |
| Que proteção contra fraudes existe? |  |  |
| Que risco de contraparte existe? |  |  |
| Quais limites e taxas se aplicam? |  |  |
| Qual lei local se aplica? |  |  |
| O que acontece em caso de disputa? |  |  |


[Privacidade](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) não é estar protegido de todos os riscos. É a capacidade de controlar as informações sobre você. Não infrinja a lei local nem se exponha a perigos físicos em busca de [privacidade](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Procure orientação local atualizada com uma pessoa qualificada quando as regras não estiverem claras.
