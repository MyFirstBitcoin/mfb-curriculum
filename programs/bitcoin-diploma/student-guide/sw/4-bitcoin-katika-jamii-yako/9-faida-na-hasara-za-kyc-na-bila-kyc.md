# 4.9 Faida na hasara za KYC na bila KYC

[Njia za KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) na [zisizo za KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) zina [faida na hasara](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off) tofauti. Hakuna kati ya lebo hizi inayoondoa haja ya tathmini makini.


<!-- card: callout -->
> **Faragha haiondoi hatari za kisheria au za usalama wa mwili**
>
> Si [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) wala [njia isiyo ya KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) iliyo bora moja kwa moja. Linganisha njia halisi, tumia mwongozo wa sasa wa eneo lako pale sheria zisipokuwa wazi, na usivunje sheria za eneo lako wala kujiweka katika hatari ya kimwili kwa ajili ya kutafuta [faragha](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Huduma ya [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) inaweza kuomba jina halali, hati ya utambulisho, anwani, picha, taarifa kuhusu chanzo cha fedha, au kumbukumbu nyingine. Hili linaweza kuiwezesha huduma kutimiza kanuni za eneo husika, kuunganishwa na benki, kuweka viwango vya juu zaidi, au kusaidia kurejesha akaunti.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) pia husababisha hatari ya data. Huduma inaweza kuhifadhi uhusiano wa kudumu kati ya utambulisho, njia za malipo, na [miamala](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) ya bitcoin. Uvujaji wa data, ombi la kisheria, matumizi mabaya ya ndani, au mabadiliko ya sera yanaweza kufichua au kuzuia taarifa hiyo.

Njia [isiyo ya KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) inaweza kukusanya taarifa chache za utambulisho. Hili linaweza kuboresha [faragha](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) ya kifedha. Inaweza pia kuhusisha wahusika wenza wasiodhibitiwa sana, ukwasi mdogo, [bei](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) za juu zaidi, msaada mdogo, hatari kubwa zaidi ya udanganyifu, au vikwazo vya kisheria.

Linganisha njia halisi:


| Swali | Njia ya KYC | Njia isiyo ya KYC |
| --- | --- | --- |
| Ni data gani za utambulisho zinazokusanywa? |  |  |
| Nani anahifadhi data na kwa muda gani? |  |  |
| Je, muamala unaweza kuhusishwa kwenye mnyororo (on-chain)? |  |  |
| Kuna ulinzi gani dhidi ya udanganyifu? |  |  |
| Kuna hatari gani inayotokana na mhusika mwenza? |  |  |
| Ni viwango na ada gani zinazotumika? |  |  |
| Ni sheria gani ya eneo husika inayotumika? |  |  |
| Nini hutokea wakati wa mzozo? |  |  |


[Faragha](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) si kujificha dhidi ya kila hatari. Ni uwezo wa kudhibiti taarifa kukuhusu. Usivunje sheria za eneo lako wala kujiweka katika hatari ya kimwili kwa ajili ya kutafuta [faragha](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Tafuta mwongozo wa sasa wa eneo lako kutoka kwa mtu mwenye sifa stahiki pale sheria zisipokuwa wazi.
