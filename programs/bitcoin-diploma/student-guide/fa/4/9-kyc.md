# 4.9 مزایا و معایب احراز هویت (KYC) و عدم احراز هویت

[احراز هویت](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) و [عدم احراز هویت](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) مسیرهایی هستند که مستلزم [بده‌بستان‌های متفاوتی‌اند](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). هیچ‌یک از این دو برچسب، نیاز به ارزیابی دقیق را از بین نمی‌برد.


<!-- card: callout -->
> **حریم خصوصی، خطرات قانونی یا خطرات مربوط به ایمنی جسمی را از بین نمی‌برد**
>
> نه [احراز هویت](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) و نه [عدم احراز هویت](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) به‌خودی‌خود بهترین گزینه نیستند. مسیر واقعی را مقایسه کنید، هنگام روشن نبودن مقررات از راهنمایی‌های محلیِ به‌روز استفاده کنید و برای دستیابی به [حریم خصوصی](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)، قوانین محلی را نقض نکنید یا خود را در معرض خطر جسمی قرار ندهید.


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

یک سرویس [احراز هویت](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ممکن است نام قانونی، مدرک شناسایی، نشانی، عکس، اطلاعات مربوط به منشأ وجوه یا سوابق دیگری را درخواست کند. این کار ممکن است به سرویس امکان دهد مقررات محلی را رعایت کند، به بانک‌ها متصل شود، سقف‌های بالاتری تعیین کند یا از بازیابی حساب پشتیبانی کند.

[احراز هویت](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) همچنین خطراتی برای داده‌ها ایجاد می‌کند. سرویس ممکن است پیوندی دائمی میان هویت، روش‌های پرداخت و [تراکنش‌های بیت‌کوین](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) ذخیره کند. نشت داده‌ها، درخواست قانونی، سوءاستفادهٔ داخلی یا تغییر سیاست‌ها ممکن است این اطلاعات را افشا کند یا دسترسی به آن‌ها را محدود سازد.

یک مسیر [بدون احراز هویت](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ممکن است اطلاعات هویتی کمتری جمع‌آوری کند. این امر می‌تواند در حوزهٔ مالی به بهبود [حریم خصوصی](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) کمک کند. همچنین ممکن است با طرف‌های معامله‌ای که نظارت مقرراتی کمتری بر آن‌ها وجود دارد، نقدشوندگی کمتر، [قیمت‌های بالاتر](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)، پشتیبانی کمتر، خطر بیشتر کلاهبرداری یا محدودیت‌های قانونی همراه باشد.

مسیر واقعی را مقایسه کنید:


| پرسش | مسیر با احراز هویت | مسیر بدون احراز هویت |
| --- | --- | --- |
| چه داده‌های هویتی جمع‌آوری می‌شوند؟ |  |  |
| چه کسی داده‌ها را ذخیره می‌کند و برای چه مدتی؟ |  |  |
| آیا می‌توان تراکنش را روی زنجیره به هویت مرتبط کرد؟ |  |  |
| چه سازوکارهایی برای محافظت در برابر کلاهبرداری وجود دارد؟ |  |  |
| چه خطری از جانب طرف مقابل معامله وجود دارد؟ |  |  |
| چه محدودیت‌ها و کارمزدهایی اعمال می‌شوند؟ |  |  |
| کدام قانون محلی حاکم است؟ |  |  |
| در صورت بروز اختلاف چه اتفاقی می‌افتد؟ |  |  |


[حریم خصوصی](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) به معنای پنهان ماندن از هر خطری نیست، بلکه توانایی کنترل اطلاعات مربوط به خودتان است. برای دستیابی به [حریم خصوصی](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)، قوانین محلی را نقض نکنید یا خود را در معرض خطر جسمی قرار ندهید. هنگامی که مقررات روشن نیستند، از فردی واجد صلاحیت راهنمایی‌های محلیِ به‌روز بخواهید.
