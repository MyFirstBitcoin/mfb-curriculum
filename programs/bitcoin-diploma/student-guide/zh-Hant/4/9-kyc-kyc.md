# 4.9 KYC 與無 KYC 的利弊權衡

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)與[無 KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)途徑各有不同的[取捨](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)。無論哪一種標籤，都無法免除仔細評估的必要。


<!-- card: callout -->
> **隱私並不能消除法律或人身安全風險**
>
> 無論是[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)還是[無 KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)，都不必然是最佳選擇。請比較實際的途徑，在規則不明確時參考當地最新的指引，且不要為了追求[隱私](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)而觸犯當地法律或使自己陷入人身危險。


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

採用[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)的服務可能會要求您提供法定姓名、身分證件、地址、照片、資金來源資訊或其他紀錄。這可能讓該服務得以符合當地規定、與銀行連結、設定較高的額度，或支援帳戶復原。

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)也會產生資料風險。該服務可能會永久保存您的身分、付款方式與比特幣[交易](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction)之間的關聯。資料外洩、法律調閱要求、內部濫用或政策變更，都可能使這些資訊遭到揭露或受到限制。

若採用[無 KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)的途徑，可能會蒐集較少的身分資訊，這有助於提升財務[隱私](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)。但它也可能涉及監管較少的交易對手、較低的流動性、較高的[價格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)、較少的支援、較高的詐騙風險，或法律上的限制。

請比較實際的途徑：


| 問題 | KYC 途徑 | 無 KYC 途徑 |
| --- | --- | --- |
| 會蒐集哪些身分資料？ |  |  |
| 由誰保存資料？保存多久？ |  |  |
| 這筆交易能否在鏈上被追溯關聯？ |  |  |
| 有哪些詐騙防護措施？ |  |  |
| 存在哪些交易對手風險？ |  |  |
| 適用哪些限額與費用？ |  |  |
| 適用哪些當地法律？ |  |  |
| 發生爭議時會如何處理？ |  |  |


[隱私](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)並不是對所有風險都保密，而是掌控自身資訊的能力。請不要為了追求[隱私](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)而觸犯當地法律或使自己陷入人身危險。當規則不明確時，請向具備資格的專業人士尋求當地最新的指引。
