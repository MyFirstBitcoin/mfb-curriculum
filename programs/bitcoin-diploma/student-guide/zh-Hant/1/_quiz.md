# Quiz – 認識貨幣：小測驗

## Question 1

為什麼貨幣會被接受？

* [x] 預期他人也會接受它
* [ ] 它使所有商品價值相等
* [ ] 它消除一切規則
* [ ] 它將服務轉變為商品

### Explanation

由於人們預期他人日後也會接受貨幣，貨幣得以協助陌生人跨越時間協調交易。貨幣仍然仰賴信任、規則與社會的接受度。請複習《學生指南》第1單元「貨幣為何存在」。

## Question 2

標價、付款、儲蓄：分別對應哪些功能？

* [ ] 價值儲存；計價單位；交易媒介
* [x] 計價單位；交易媒介；價值儲存
* [ ] 交易媒介；價值儲存；計價單位
* [ ] 稀缺性；稀缺性；稀缺性

### Explanation

計價單位用來表示價格，交易媒介在付款時被接受，價值儲存則將價值轉移到未來。請複習《學生指南》第1單元「貨幣的功能與特性」。

## Question 3

以米換鞋失敗：原因為何？

* [ ] 價格不同
* [x] 需求無法相互配合
* [ ] 未獲銀行核准
* [ ] 米無法用於交易

### Explanation

當雙方並未在同一時間想要對方所提供的東西時，直接以物易物便難以進行。這就是需求的雙重巧合。請複習《學生指南》第1單元「以物易物與需求的雙重巧合」。

## Question 4

物價上漲10%，收入增加5%：購買力如何？

* [ ] 上升
* [ ] 維持不變
* [x] 下降
* [ ] 無法判斷

### Explanation

購買力是指貨幣能買到的東西。若物價上漲速度快於收入成長，收入能買到的東西就會變少。請複習《學生指南》第1單元「通貨膨脹與購買力」。
