# Quiz – 安全使用比特幣：快速測驗

## 問題 1

比特幣錢包：

* [ ] 儲存比特幣
* [x] 管理金鑰並進行簽署
* [ ] 移除機密保護
* [ ] 撤銷交易

### 解析

比特幣記錄在共享帳本上；錢包則管理用於存取和使用比特幣的資訊。請複習《學生指南》第 3 單元「錢包」。

## 問題 2

為了接收比特幣，應分享：

* [ ] 助記詞
* [ ] 私鑰
* [x] 收款地址
* [ ] 密碼

### 解析

收款地址可以分享以接收付款。助記詞、私鑰和密碼都必須保密。請複習《學生指南》第 3 單元「地址」與「金鑰」。

## 問題 3

助記詞已在網路上輸入。最安全的下一步是？

* [ ] 等待
* [ ] 將其傳送給客服
* [x] 建立新助記詞，再轉移資金
* [ ] 繼續使用原助記詞

### 解析

在網路上輸入過的助記詞應視為已外洩。請以新的助記詞建立新錢包，並在確認目標地址無誤後再轉移資金。請複習《學生指南》第 3 單元「助記詞」。

## 問題 4

託管式與自我託管式使用的主要差異是什麼？

* [x] 由誰掌控金鑰
* [ ] 付款是否可撤銷
* [ ] 供應量上限
* [ ] 交易手續費

### 解析

託管式與自我託管式使用的差別，在於由誰掌控金鑰並承擔相關責任。兩者都無法保證安全或交易可撤銷。請複習《學生指南》第 3 單元「託管式與非託管式使用」。
