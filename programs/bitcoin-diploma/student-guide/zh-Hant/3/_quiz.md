# Quiz – 安全使用比特幣：快速測驗

## Question 1

比特幣錢包：

* [ ] 儲存比特幣
* [x] 管理金鑰並進行簽署
* [ ] 移除機密保護
* [ ] 撤銷交易

### Explanation

比特幣記錄在共享帳本上；錢包管理的是用來存取及使用比特幣的資訊。請複習《學生手冊》第3單元「錢包」。

## Question 2

為了接收比特幣，應分享：

* [ ] 助記詞
* [ ] 私鑰
* [x] 收款地址
* [ ] 密碼

### Explanation

收款地址可以為了付款而分享。助記詞、私鑰和密碼則必須保密。請複習《學生手冊》第3單元「地址」與「金鑰」。

## Question 3

助記詞曾在網路上輸入。最安全的下一步是？

* [ ] 等待
* [ ] 傳送給客服
* [x] 建立新助記詞，再轉移資金
* [ ] 重複使用該助記詞

### Explanation

在網路上輸入過的助記詞應視為已外洩。請以新的助記詞建立新錢包，並在確認目的地址無誤後才轉移資金。請複習《學生手冊》第3單元「助記詞」。

## Question 4

託管方式的差異？

* [x] 由誰掌控金鑰
* [ ] 付款可否撤銷
* [ ] 供應量上限
* [ ] 責任歸屬

### Explanation

託管與自主託管的差異在於由誰掌控金鑰，以及由誰承擔相關責任。兩者都無法保證安全，也無法保證交易可撤銷。請複習《學生手冊》第3單元「託管與非託管使用」。
