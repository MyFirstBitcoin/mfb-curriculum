# 2.13 比特幣作為健全的數位貨幣

如**第 1 單元**所介紹，[**穩健貨幣**](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money)是指供給難以擴張、且其特性能支持長期可靠使用的貨幣。這個詞表達的是依據標準所作的判斷，因此應加以檢視，而非僅當作標籤接受。

比特幣結合了過去從未同時存在於單一[資產](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset)中的多項特性：


<!-- micrographic: bitcoin-money-properties-01 -->



| 特性 | 淺顯說明 |
| --- | --- |
| 耐久性 | 帳本複製於眾多節點之中。能否存取取決於是否妥善保存有效的金鑰。 |
| 可攜性 | 一筆經簽署的交易可透過通訊網路轉移價值。 |
| 可分割性 | 一枚比特幣（1 BTC）可分割為 100,000,000 聰。 |
| 可替代性 | 相同金額在同樣的協定規則下皆可花用，但公開的交易紀錄可能影響某些服務對待特定資金的方式。 |
| 稀缺性 | 發行遵循公開規則，上限為 2,100 萬枚。 |
| 可驗證性 | 節點可以驗證供給量、交易規則及所有權證明。 |
| 可接受性 | 在某些地方接受度正在提高，但在許多社群中仍遠低於國家貨幣。 |


比特幣能夠履行貨幣的三項功能，但並非在每個地方都同樣適用：

* 作為[**價值儲存**](https://curriculum.myfirstbitcoin.org/lexicon/en/#store-of-value)，其供給可預測，但其市場[價格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)波動劇烈。
* 作為[**交易媒介**](https://curriculum.myfirstbitcoin.org/lexicon/en/#medium-of-exchange)，它無需透過銀行即可轉移，但接受度、手續費及支付工具因地而異。
* 作為[**記帳單位**](https://curriculum.myfirstbitcoin.org/lexicon/en/#unit-of-account)，金額可以用比特幣或[聰](https://curriculum.myfirstbitcoin.org/lexicon/en/#satoshi)表示，但大多數商品仍以法定[貨幣](https://curriculum.myfirstbitcoin.org/lexicon/en/#currency)標價。

因此，比特幣同時具有優點與[取捨](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)。

**潛在優點**包括直接所有權、可預測的供給、全球轉帳、開放參與、透明的規則，以及抵抗單方面審查的能力。

[**取捨**](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)包括[價格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)[波動](https://curriculum.myfirstbitcoin.org/lexicon/en/#volatility)、個人須自行負責安全、有效付款通常難以或無法撤回、不斷變動的[交易手續費](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction-fee)、數位轉帳須仰賴電力與通訊、公開的[交易](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction)紀錄，以及有限的接受度。

您是否將比特幣稱為[健全貨幣](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money)，應取決於您的判斷標準。請以相同的標準，將它與[法定貨幣](https://curriculum.myfirstbitcoin.org/lexicon/en/#fiat-money)、貴金屬及其他[資產](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset)進行比較。

**在地價值檢核：**比特幣在您的社群中是否具有[價值](https://curriculum.myfirstbitcoin.org/lexicon/en/#value)？請在回答中區分三個問題：可觀察到的市場[價格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)是多少？它在哪些地方被接受（如果有的話）？哪些個人偏好或[偏見](https://curriculum.myfirstbitcoin.org/lexicon/en/#bias)影響了您的判斷？[價格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)、在地實用性與個人認同彼此相關，但並不相同。
