# Quiz – 比特幣如何運作：小測驗

## Question 1

同一個數位單位被用來付款兩次。系統必須：

* [x] 拒絕雙重支付
* [ ] 隱藏該筆付款
* [ ] 提高其價格
* [ ] 取消手續費

### Explanation

數位資訊可以被複製，因此貨幣系統必須防止同一單位被花費兩次，並確認哪一筆交易有效。請複習《學生指南》第2單元「早期數位貨幣的嘗試與雙重支付問題」。

## Question 2

比特幣的去中心化是指：

* [ ] 由一家公司核准付款
* [x] 由獨立參與者執行規則
* [ ] 礦工可隨意更改規則
* [ ] 每個人影響力相同

### Explanation

比特幣將驗證與規則執行分散於各個獨立參與者之間。去中心化並不代表由一家公司控制網路，也不代表每個人都擁有相同的影響力。請複習《學生指南》第2單元「去中心化」。

## Question 3

比特幣節點：

* [x] 檢查網路規則
* [ ] 產生比特幣
* [ ] 儲存比特幣
* [ ] 保證付款成功

### Explanation

節點會獨立檢查比特幣的規則，並拒絕無效的資料。節點不會應要求產生比特幣，也不會將比特幣儲存在手機裡。請複習《學生指南》第2單元「使用者、節點與礦工」。

## Question 4

為什麼稱比特幣為健全貨幣？

* [ ] 價格總是上漲
* [x] 供給公開且有限
* [ ] 由一家公司控制
* [ ] 付款具隱私性

### Explanation

有些人將比特幣形容為健全貨幣，是因為其供給規則公開，且發行量有限。這是經過推理的判斷，而非對價格或隱私的承諾。請複習《學生指南》第2單元「比特幣作為健全的數位貨幣」。
