# 4.9 Fordele og ulemper ved KYC og ikke-KYC

[KYC-baserede](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) og [ikke-KYC-baserede](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) løsninger indebærer forskellige [afvejninger](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Ingen af betegnelserne fjerner behovet for en omhyggelig vurdering.


<!-- card: callout -->
> **Privatliv fjerner ikke juridiske risici eller risici for den fysiske sikkerhed**
>
> Hverken [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) eller [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) er automatisk bedst. Sammenlign den konkrete løsning, benyt opdateret lokal vejledning, når reglerne er uklare, og overtræd ikke lokal lovgivning eller udsæt Dem selv for fysisk fare i bestræbelsen på at beskytte Deres [privatliv](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

En [KYC-baseret](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) tjeneste kan bede om et juridisk navn, et identitetsdokument, en adresse, et fotografi, oplysninger om midlernes oprindelse eller anden dokumentation. Dette kan gøre det muligt for tjenesten at overholde lokale regler, samarbejde med banker, fastsætte højere grænser eller hjælpe med at gendanne adgangen til en konto.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) skaber også datarisici. Tjenesten kan gemme en permanent forbindelse mellem identitet, betalingsmetoder og bitcoinrelaterede [transaktioner](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Et databrud, et juridisk krav, internt misbrug eller en ændring i politikken kan blotlægge disse oplysninger eller begrænse adgangen til dem.

En [ikke-KYC-baseret](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) løsning kan indsamle færre identitetsoplysninger. Dette kan forbedre beskyttelsen af Deres finansielle [privatliv](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Den kan også indebære mindre regulerede modparter, lavere likviditet, højere [priser](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), mindre support, større risiko for svindel eller juridiske begrænsninger.

Sammenlign den konkrete løsning:


| Spørgsmål | KYC-baseret løsning | Løsning uden KYC |
| --- | --- | --- |
| Hvilke identitetsoplysninger indsamles? |  |  |
| Hvem opbevarer oplysningerne, og hvor længe? |  |  |
| Kan transaktionen sammenkædes med andre oplysninger på blockchainen? |  |  |
| Hvilken beskyttelse mod svindel findes der? |  |  |
| Hvilken modpartsrisiko er der? |  |  |
| Hvilke grænser og gebyrer gælder? |  |  |
| Hvilken lokal lovgivning gælder? |  |  |
| Hvad sker der i tilfælde af en tvist? |  |  |


[Privatliv](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) betyder ikke hemmeligholdelse, der beskytter mod enhver risiko. Det er muligheden for at kontrollere oplysninger om Dem selv. Overtræd ikke lokal lovgivning eller udsæt Dem selv for fysisk fare i bestræbelsen på at beskytte Deres [privatliv](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Søg opdateret lokal vejledning hos en kvalificeret person, når reglerne er uklare.
