# Quiz – Forstå penge: kort test

## Spørgsmål 1

Hvorfor accepteres penge?

* [x] Andre forventes at acceptere dem
* [ ] De gør varer lige værdifulde
* [ ] De fjerner alle regler
* [ ] De forvandler tjenesteydelser til varer

### Forklaring

Penge hjælper fremmede med at koordinere udveksling over tid, fordi folk forventer, at andre vil acceptere dem senere. Det afhænger stadig af tillid, regler og social accept. Se elevvejledningen, modul 1, ”Hvorfor penge findes.”

## Spørgsmål 2

Prissat, betalt, opsparet: hvilke funktioner?

* [ ] Værdiopbevaringsmiddel; regneenhed; betalingsmiddel
* [x] Regneenhed; betalingsmiddel; værdiopbevaringsmiddel
* [ ] Betalingsmiddel; værdiopbevaringsmiddel; regneenhed
* [ ] Knaphed; knaphed; knaphed

### Forklaring

En regneenhed udtrykker priser, et betalingsmiddel accepteres som betaling, og et værdiopbevaringsmiddel bevarer værdi til fremtiden. Se elevvejledningen, modul 1, ”Penges funktioner og egenskaber.”

## Spørgsmål 3

Ris kan ikke byttes til sko: hvorfor?

* [ ] Forskellige priser
* [x] Intet sammenfald af behov
* [ ] Ingen godkendelse fra banken
* [ ] Ris kan ikke handles

### Forklaring

Direkte byttehandel er vanskelig, når begge parter ikke samtidig ønsker det, den anden tilbyder. Dette kaldes det dobbelte sammenfald af behov. Se elevvejledningen, modul 1, ”Byttehandel og det dobbelte sammenfald af behov.”

## Spørgsmål 4

Priser +10%, indkomst +5%: købekraft?

* [ ] Stiger
* [ ] Forbliver den samme
* [x] Falder
* [ ] Kan ikke afgøres

### Forklaring

Købekraft er det, penge kan købe. Hvis priserne stiger hurtigere end indkomsten, kan man købe mindre for indkomsten. Se elevvejledningen, modul 1, ”Inflation og købekraft.”
