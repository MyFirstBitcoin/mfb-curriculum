# 4.9 KYC மற்றும் KYC இல்லாத முறைகளின் சாதக பாதகங்கள்

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) மற்றும் [KYC இல்லாத](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) வழிமுறைகளில் வெவ்வேறு [விட்டுக்கொடுப்புகள் உள்ளன](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). எந்தப் பெயரில் அழைக்கப்பட்டாலும், கவனமாக மதிப்பிட வேண்டிய தேவை நீங்குவதில்லை.


<!-- card: callout -->
> **தனியுரிமை என்பது சட்டரீதியான அல்லது உடல் பாதுகாப்பு சார்ந்த ஆபத்தை நீக்குவதில்லை**
>
> எதுவும் — [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) அல்லது [KYC இல்லாத வழிமுறை](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) — தானாகவே சிறந்ததாகிவிடாது. நடைமுறையில் உள்ள வழிமுறையை ஒப்பிடுங்கள்; விதிகள் தெளிவாக இல்லாதபோது தற்போதைய உள்ளூர் வழிகாட்டுதலைப் பயன்படுத்துங்கள்; உள்ளூர் சட்டத்தை மீறவோ உங்களை உடல்ரீதியான ஆபத்துக்கு உள்ளாக்கிக்கொள்ளவோ வேண்டாம் — நீங்கள் நாடுவது [தனியுரிமையாக இருந்தாலும்](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

ஒரு [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) சேவை, சட்டப்பூர்வமான பெயர், அடையாள ஆவணம், முகவரி, புகைப்படம், நிதி எங்கிருந்து வந்தது என்பது பற்றிய தகவல் அல்லது பிற பதிவுகளைக் கோரலாம். இதன் மூலம் அந்தச் சேவையால் உள்ளூர் விதிகளைப் பின்பற்றவும், வங்கிகளுடன் இணைக்கவும், அதிக வரம்புகளை நிர்ணயிக்கவும் அல்லது கணக்கை மீட்டெடுக்க உதவவும் முடியலாம்.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) தரவு சார்ந்த ஆபத்தையும் உருவாக்குகிறது. அந்தச் சேவை நிரந்தரமாக இணைத்துச் சேமிக்கக்கூடியவை: அடையாளம், பணம் செலுத்தும் முறைகள் மற்றும் பிட்காயின் [பரிவர்த்தனைகள்](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). தரவுக் கசிவு, சட்டரீதியான கோரிக்கை, உள்நிறுவனத் தவறான பயன்பாடு அல்லது கொள்கை மாற்றம் ஆகியவை அந்தத் தகவலை வெளிப்படுத்தலாம் அல்லது அதற்கான அணுகலைக் கட்டுப்படுத்தலாம்.

ஒரு [KYC இல்லாத](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) வழிமுறை குறைவான அடையாளத் தகவல்களைச் சேகரிக்கலாம். இதனால் மேம்படக்கூடியது நிதிசார் [தனியுரிமை](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). இதில் குறைவான ஒழுங்குமுறைக் கண்காணிப்புக்கு உட்பட்ட எதிர்த்தரப்புகள், குறைந்த பணப்புழக்கம், அதிக [விலைகள்](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), குறைந்த ஆதரவு, அதிக மோசடி ஆபத்து அல்லது சட்டக் கட்டுப்பாடுகளும் இருக்கலாம்.

நடைமுறையில் உள்ள வழிமுறையை ஒப்பிடுங்கள்:


| கேள்வி | KYC வழிமுறை | KYC இல்லாத வழிமுறை |
| --- | --- | --- |
| எந்த அடையாளத் தரவுகள் சேகரிக்கப்படுகின்றன? |  |  |
| தரவுகளை யார் சேமிக்கிறார்கள், எவ்வளவு காலத்திற்குச் சேமிக்கிறார்கள்? |  |  |
| பரிவர்த்தனையை பிளாக்செயினில் தொடர்புபடுத்த முடியுமா? |  |  |
| மோசடிக்கு எதிராக என்ன பாதுகாப்பு உள்ளது? |  |  |
| எதிர்த்தரப்பு சார்ந்த என்ன ஆபத்து உள்ளது? |  |  |
| என்ன வரம்புகளும் கட்டணங்களும் பொருந்தும்? |  |  |
| எந்த உள்ளூர் சட்டம் பொருந்தும்? |  |  |
| சர்ச்சை ஏற்படும்போது என்ன நடக்கும்? |  |  |


[தனியுரிமை](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) என்பது எல்லா ஆபத்துகளிலிருந்தும் மறைந்திருப்பது அல்ல. அது உங்களைப் பற்றிய தகவல்களைக் கட்டுப்படுத்தும் திறன் ஆகும். உள்ளூர் சட்டத்தை மீறவோ உங்களை உடல்ரீதியான ஆபத்துக்கு உள்ளாக்கிக்கொள்ளவோ வேண்டாம் — நீங்கள் நாடுவது [தனியுரிமையாக இருந்தாலும்](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). விதிகள் தெளிவாக இல்லாதபோது, தகுதிவாய்ந்த ஒருவரிடமிருந்து தற்போதைய உள்ளூர் வழிகாட்டுதலைப் பெறுங்கள்.
