# Quiz – பிட்காயின் எவ்வாறு செயல்படுகிறது: விரைவுச் சோதனை

## Question 1

ஒரே மின்னணு அலகு இருமுறை செலவிடப்படுகிறது. அமைப்பு செய்ய வேண்டியது:

* [x] இருமுறை செலவிடுவதை நிராகரித்தல்
* [ ] பணம் செலுத்துவதை மறைத்தல்
* [ ] அதன் விலையை உயர்த்துதல்
* [ ] கட்டணங்களை நீக்குதல்

### Explanation

மின்னணுத் தகவல்களை நகலெடுக்க முடியும் என்பதால், ஒரு பண அமைப்பு ஒரே அலகு இருமுறை செலவிடப்படுவதைத் தடுத்து, எந்தப் பரிவர்த்தனை செல்லுபடியாகும் என்பதை உறுதிப்படுத்த வேண்டும். மாணவர் வழிகாட்டி, தொகுதி 2, “ஆரம்பகால மின்னணுப் பண முயற்சிகளும் இருமுறை செலவிடும் சிக்கலும்” என்பதை மீண்டும் படிக்கவும்.

## Question 2

பிட்காயினின் பரவலாக்கம் என்பதன் பொருள்:

* [ ] ஒரு நிறுவனம் பணம் செலுத்துதல்களுக்கு ஒப்புதல் அளிக்கிறது
* [x] சுயாதீனமாக விதிகளை நடைமுறைப்படுத்துதல்
* [ ] சுரங்கத் தொழிலாளர்கள் விதிகளைத் தன்னிச்சையாக மாற்றுகிறார்கள்
* [ ] அனைவருக்கும் சமமான செல்வாக்கு

### Explanation

சரிபார்த்தல் மற்றும் விதிகளை நடைமுறைப்படுத்துதல் ஆகியவற்றைச் சுயாதீனப் பங்கேற்பாளர்களிடையே பிட்காயின் பகிர்ந்தளிக்கிறது. பரவலாக்கம் என்பது ஒரு நிறுவனம் வலையமைப்பைக் கட்டுப்படுத்துவதையோ அனைவருக்கும் சமமான செல்வாக்கு இருப்பதையோ குறிக்காது. மாணவர் வழிகாட்டி, தொகுதி 2, “பரவலாக்கம்” என்பதை மீண்டும் படிக்கவும்.

## Question 3

ஒரு பிட்காயின் முனையம்:

* [x] வலையமைப்பின் விதிகளைச் சரிபார்க்கிறது
* [ ] பிட்காயினை உருவாக்குகிறது
* [ ] பிட்காயினைச் சேமிக்கிறது
* [ ] பணம் செலுத்தப்படுவதை உறுதிசெய்கிறது

### Explanation

முனையங்கள் பிட்காயினின் விதிகளைச் சுயாதீனமாகச் சரிபார்த்து, செல்லுபடியாகாத தரவுகளை நிராகரிக்கின்றன. அவை கோரிக்கையின் பேரில் பிட்காயினை உருவாக்குவதோ தொலைபேசிக்குள் பிட்காயினைச் சேமிப்பதோ இல்லை. மாணவர் வழிகாட்டி, தொகுதி 2, “பயனர்கள், முனையங்கள் மற்றும் சுரங்கத் தொழிலாளர்கள்” என்பதை மீண்டும் படிக்கவும்.

## Question 4

பிட்காயினை உறுதியான பணம் என்று ஏன் அழைக்கிறார்கள்?

* [ ] விலை எப்போதும் உயர்கிறது
* [x] பொதுவில் அறியக்கூடிய, வரம்புக்குட்பட்ட வழங்கல்
* [ ] ஒரு நிறுவனம் அதைக் கட்டுப்படுத்துகிறது
* [ ] பணம் செலுத்துதல்கள் தனியுரிமையுடன் நடைபெறுகின்றன

### Explanation

பிட்காயினின் வழங்கல் விதிகள் பொதுவில் உள்ளதாலும் அதன் வெளியீடு வரம்புக்குட்பட்டதாலும், சிலர் அதை உறுதியான பணம் என்று விவரிக்கிறார்கள். இது காரணங்களின் அடிப்படையிலான மதிப்பீடே தவிர, விலை அல்லது தனியுரிமை குறித்த வாக்குறுதி அல்ல. மாணவர் வழிகாட்டி, தொகுதி 2, “உறுதியான மின்னணுப் பணமாகப் பிட்காயின்” என்பதை மீண்டும் படிக்கவும்.
