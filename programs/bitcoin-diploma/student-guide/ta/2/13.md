# 2.13 நம்பகமான டிஜிட்டல் பணமாக பிட்காயின்

ஏற்கெனவே **தொகுதி 1** அறிமுகப்படுத்தியபடி, [**உறுதியான பணம்**](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money) என்பது, புழக்க அளவை அதிகரிப்பது கடினமாகவும், காலப்போக்கிலும் நம்பகமான பயன்பாட்டை ஆதரிக்கும் பண்புகளைக் கொண்டதாகவும் இருக்கும் பணத்தைக் குறிக்கிறது. இந்தச் சொல் சில அளவுகோல்களின் அடிப்படையிலான மதிப்பீட்டை வெளிப்படுத்துகிறது; எனவே, இதை வெறும் அடையாளச் சொல்லாக ஏற்றுக்கொள்வதற்குப் பதிலாக ஆராய வேண்டும்.

பிட்காயின் ஒருங்கிணைக்கும் பண்புகள், இதற்கு முன்பு ஒன்றாக இடம்பெற்றதில்லை எந்தவொரு தனி [சொத்திலும்](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset):

| பண்பு | எளிய மொழியில் விளக்கம் |
| --- | --- |
| நீடித்திருக்கும் தன்மை | பேரேடு பல கணுக்களில் நகலெடுக்கப்படுகிறது. செல்லுபடியாகும் சாவிகளைப் பாதுகாத்து வைத்திருப்பதையே அணுகல் சார்ந்துள்ளது. |
| எடுத்துச் செல்லும் தன்மை | கையொப்பமிடப்பட்ட பரிவர்த்தனையால் தகவல்தொடர்பு வலையமைப்பின் வழியாக மதிப்பைப் பரிமாற்ற முடியும். |
| பகுக்கக்கூடிய தன்மை | ஒரு பிட்காயினை (1 BTC) 10,00,00,000 சாட்களாகப் பிரிக்கலாம். |
| ஒன்றுக்கொன்று மாற்றீடாகும் தன்மை | சம அளவிலான தொகைகளை ஒரே நெறிமுறை விதிகளின்படி செலவிடலாம். இருப்பினும், பொதுவில் உள்ள பரிவர்த்தனை வரலாறு, குறிப்பிட்ட நிதிகளைச் சில சேவைகள் எவ்வாறு கையாளுகின்றன என்பதைப் பாதிக்கலாம். |
| அரிதான தன்மை | வெளியீடு பொதுவில் உள்ள விதிகளைப் பின்பற்றுகிறது; அதன் அதிகபட்ச வரம்பு 21 மில்லியன். |
| சரிபார்க்கக்கூடிய தன்மை | ஒரு கணுவால் புழக்க அளவு, பரிவர்த்தனை விதிகள் மற்றும் உரிமைச் சான்றுகளைச் சரிபார்க்க முடியும். |
| ஏற்றுக்கொள்ளப்படும் தன்மை | சில இடங்களில் இதை ஏற்றுக்கொள்வது அதிகரித்து வருகிறது. ஆனால் பல சமூகங்களில், தேசிய நாணயங்களை ஏற்றுக்கொள்ளும் அளவைவிட இது இன்னும் மிகவும் குறைவாகவே உள்ளது. |


பணத்தின் மூன்று செயல்பாடுகளையும் பிட்காயினால் நிறைவேற்ற முடியும்; ஆனால் எல்லா இடங்களிலும் ஒரே அளவில் அல்ல:

* ஒரு [**மதிப்புச் சேமிப்பாக**](https://curriculum.myfirstbitcoin.org/lexicon/en/#store-of-value), அதன் புழக்க அளவைக் கணிக்க முடியும்; ஆனால் அதன் சந்தை [விலை](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) ஏற்ற இறக்கங்களுக்கு உட்பட்டது.
* ஒரு [**பரிமாற்ற ஊடகமாக**](https://curriculum.myfirstbitcoin.org/lexicon/en/#medium-of-exchange), வங்கி இல்லாமலேயே அதைப் பரிமாற்ற முடியும்; ஆனால் ஏற்றுக்கொள்ளப்படும் அளவு, கட்டணங்கள் மற்றும் பணம் செலுத்தும் கருவிகள் மாறுபடுகின்றன.
* ஒரு [**கணக்கீட்டு அலகாக**](https://curriculum.myfirstbitcoin.org/lexicon/en/#unit-of-account), தொகைகளைக் குறிப்பிடப் பயன்படுத்தக்கூடியவை பிட்காயின் அல்லது [சாட்கள்](https://curriculum.myfirstbitcoin.org/lexicon/en/#satoshi); ஆனால் பெரும்பாலான பொருட்களின் விலையை நிர்ணயிக்க இன்னும் பயன்படுத்தப்படுவது ஃபியட் [நாணயம்](https://curriculum.myfirstbitcoin.org/lexicon/en/#currency).

எனவே, பிட்காயினில் இருப்பவை நன்மைகள் மட்டுமல்ல, [சில விட்டுக்கொடுப்புகளும்தான்](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off).

**சாத்தியமான நன்மைகளில்** நேரடி உரிமை, கணிக்கக்கூடிய புழக்க அளவு, உலகளாவிய பரிமாற்றம், திறந்த பங்கேற்பு, வெளிப்படையான விதிகள் மற்றும் ஒருதலைப்பட்சமான தணிக்கையை எதிர்க்கும் திறன் ஆகியவை அடங்கும்.

[**ஏற்றுக்கொள்ள வேண்டிய பாதக அம்சங்கள்**](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off) பின்வருமாறு: [விலை](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) [ஏற்ற இறக்கம்](https://curriculum.myfirstbitcoin.org/lexicon/en/#volatility), தனிப்பட்ட பாதுகாப்புக்கான பொறுப்பு, செல்லுபடியாகும் ஒரு பணம் செலுத்தலைத் திரும்பப் பெறுவது பொதுவாகக் கடினம் அல்லது சாத்தியமற்றது என்ற நிலை, மாறிவரும் [பரிவர்த்தனைக் கட்டணங்கள்](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction-fee), டிஜிட்டல் பரிமாற்றத்திற்கு மின்சாரம் மற்றும் தகவல்தொடர்புகளைச் சார்ந்திருத்தல், பொதுவில் கிடைக்கும் [பரிவர்த்தனை](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction) பதிவுகள் மற்றும் குறைவான ஏற்றுக்கொள்ளல்.

நீங்கள் பிட்காயினை [உறுதியான பணம்](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money) என்று அழைப்பதா என்பது உங்கள் அளவுகோல்களின் அடிப்படையில் அமைய வேண்டும். அதை [அரசு வெளியிடும் ஃபியட் பணம்](https://curriculum.myfirstbitcoin.org/lexicon/en/#fiat-money), விலைமதிப்புள்ள உலோகங்கள் மற்றும் பிற [சொத்துகள்](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset) ஆகியவற்றுடன் ஒரே அளவுகோல்களைப் பயன்படுத்தி ஒப்பிடுங்கள்.

**உள்ளூர் மதிப்புச் சரிபார்ப்பு:** பிட்காயினுக்கு [மதிப்பு](https://curriculum.myfirstbitcoin.org/lexicon/en/#value) உங்கள் சமூகத்தில் உள்ளதா? உங்கள் பதிலில் மூன்று கேள்விகளைத் தனித்தனியாகக் கையாளுங்கள்: எந்தச் சந்தை [விலையை](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) அவதானிக்க முடிகிறது? அது எங்கேனும் ஏற்றுக்கொள்ளப்படுகிறதா? அப்படியானால் எங்கே? எந்தத் தனிப்பட்ட விருப்பம் அல்லது [சார்பு](https://curriculum.myfirstbitcoin.org/lexicon/en/#bias) உங்கள் மதிப்பீட்டைப் பாதிக்கிறது? [விலை](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), உள்ளூர்ப் பயன்பாடு மற்றும் தனிப்பட்ட அங்கீகாரம் ஆகியவை ஒன்றுக்கொன்று தொடர்புடையவை; ஆனால் ஒரே மாதிரியானவை அல்ல.
