# Quiz – பிட்காயினைப் பாதுகாப்பாகப் பயன்படுத்துதல்: விரைவுச் சோதனை

## கேள்வி 1

ஒரு பிட்காயின் பணப்பை:

* [ ] பிட்காயினைச் சேமிக்கிறது
* [x] விசைகளை நிர்வகித்துக் கையொப்பமிடுகிறது
* [ ] ரகசியப் பாதுகாப்பை நீக்குகிறது
* [ ] பரிவர்த்தனைகளைத் திரும்பப்பெறுகிறது

### விளக்கம்

பிட்காயின் பகிரப்பட்ட பேரேட்டில் பதிவு செய்யப்படுகிறது; அதை அணுகவும் பயன்படுத்தவும் தேவையான தகவல்களைப் பணப்பை நிர்வகிக்கிறது. மாணவர் வழிகாட்டியின் தொகுதி 3-இல் உள்ள “பணப்பைகள்” பகுதியை மீள்பார்வையிடுங்கள்.

## கேள்வி 2

பிட்காயினைப் பெறுவதற்குப் பகிர வேண்டியது:

* [ ] மீட்புச் சொற்றொடர்
* [ ] தனிப்பட்ட விசை
* [x] பெறும் முகவரி
* [ ] கடவுச்சொல்

### விளக்கம்

பணம் பெறுவதற்குப் பெறும் முகவரியைப் பகிரலாம். மீட்புச் சொற்றொடர்கள், தனிப்பட்ட விசைகள் மற்றும் கடவுச்சொற்கள் ரகசியமாக வைக்கப்பட வேண்டும். மாணவர் வழிகாட்டியின் தொகுதி 3-இல் உள்ள “முகவரிகள்” மற்றும் “விசைகள்” பகுதிகளை மீள்பார்வையிடுங்கள்.

## கேள்வி 3

மீட்புச் சொற்றொடர் இணையத்தில் உள்ளிடப்பட்டுள்ளது. அடுத்ததாக எடுப்பதற்கு மிகவும் பாதுகாப்பான நடவடிக்கை எது?

* [ ] காத்திருங்கள்
* [ ] அதை ஆதரவுக் குழுவிற்கு அனுப்புங்கள்
* [x] புதிய மீட்புச் சொற்றொடரை உருவாக்கி, பின்னர் நிதியை மாற்றுங்கள்
* [ ] அதே மீட்புச் சொற்றொடரை மீண்டும் பயன்படுத்துங்கள்

### விளக்கம்

இணையத்தில் உள்ளிடப்பட்ட மீட்புச் சொற்றொடரின் ரகசியத்தன்மை பாதிக்கப்பட்டுவிட்டதாகக் கருதுங்கள். புதிய மீட்புச் சொற்றொடருடன் புதிய பணப்பையை உருவாக்குங்கள்; பின்னர், பெறுநர் முகவரியைச் சரிபார்த்த பின்னரே நிதியை மாற்றுங்கள். மாணவர் வழிகாட்டியின் தொகுதி 3-இல் உள்ள “மீட்புச் சொற்றொடர்கள்” பகுதியை மீள்பார்வையிடுங்கள்.

## கேள்வி 4

மூன்றாம் தரப்புக் கட்டுப்பாட்டிலான பயன்பாட்டிற்கும் சுயக் கட்டுப்பாட்டிலான பயன்பாட்டிற்கும் இடையிலான முக்கிய வேறுபாடு என்ன?

* [x] விசைகளை யார் கட்டுப்படுத்துகிறார்கள் என்பது
* [ ] பணம் செலுத்தியதைத் திரும்பப்பெறும் வசதி
* [ ] வழங்கல் வரம்பு
* [ ] பரிவர்த்தனைக் கட்டணங்கள்

### விளக்கம்

விசைகளை யார் கட்டுப்படுத்துகிறார்கள், அது தொடர்பான பொறுப்பை யார் ஏற்கிறார்கள் என்பதில்தான் மூன்றாம் தரப்புக் கட்டுப்பாட்டிலான பயன்பாடும் சுயக் கட்டுப்பாட்டிலான பயன்பாடும் வேறுபடுகின்றன. இரண்டுமே பாதுகாப்பையோ பரிவர்த்தனைகளைத் திரும்பப்பெறும் வசதியையோ உறுதிசெய்வதில்லை. மாணவர் வழிகாட்டியின் தொகுதி 3-இல் உள்ள “மூன்றாம் தரப்புக் கட்டுப்பாட்டிலான மற்றும் சுயக் கட்டுப்பாட்டிலான பயன்பாடு” பகுதியை மீள்பார்வையிடுங்கள்.
