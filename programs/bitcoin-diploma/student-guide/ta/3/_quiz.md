# Quiz – பிட்காயினைப் பாதுகாப்பாகப் பயன்படுத்துதல்: விரைவுச் சோதனை

## Question 1

ஒரு பிட்காயின் பணப்பை:

* [ ] பிட்காயினைச் சேமிக்கிறது
* [x] விசைகளை நிர்வகித்துக் கையொப்பமிடுகிறது
* [ ] ரகசியப் பாதுகாப்பை நீக்குகிறது
* [ ] பரிவர்த்தனைகளை மாற்றியமைக்கிறது

### Explanation

பிட்காயின் பகிரப்பட்ட பேரேட்டில் பதிவாகிறது; அதை அணுகவும் பயன்படுத்தவும் தேவையான தகவல்களைப் பணப்பை நிர்வகிக்கிறது. மாணவர் வழிகாட்டியின் தொகுதி 3-இல் உள்ள “பணப்பைகள்” பகுதியை மீண்டும் படிக்கவும்.

## Question 2

பிட்காயினைப் பெறுவதற்குப் பகிர வேண்டியது:

* [ ] மீட்புச் சொற்றொடர்
* [ ] தனிப்பட்ட விசை
* [x] பெறும் முகவரி
* [ ] கடவுச்சொல்

### Explanation

பணம் பெறுவதற்குப் பெறும் முகவரியைப் பகிரலாம். மீட்புச் சொற்றொடர்கள், தனிப்பட்ட விசைகள் மற்றும் கடவுச்சொற்கள் ரகசியமாகவே இருக்க வேண்டும். மாணவர் வழிகாட்டியின் தொகுதி 3-இல் உள்ள “முகவரிகள்” மற்றும் “விசைகள்” பகுதிகளை மீண்டும் படிக்கவும்.

## Question 3

மீட்புச் சொற்றொடர் இணையத்தில் உள்ளிடப்பட்டுள்ளது. அடுத்த பாதுகாப்பான நடவடிக்கை என்ன?

* [ ] காத்திருங்கள்
* [ ] அதை ஆதரவுச் சேவைக்கு அனுப்புங்கள்
* [x] புதிய மீட்புச் சொற்றொடரை உருவாக்கி, பின்னர் நிதியை மாற்றுங்கள்
* [ ] அதே மீட்புச் சொற்றொடரை மீண்டும் பயன்படுத்துங்கள்

### Explanation

இணையத்தில் உள்ளிடப்பட்ட மீட்புச் சொற்றொடரின் ரகசியத்தன்மை பாதிக்கப்பட்டதாகக் கருதுங்கள். புதிய மீட்புச் சொற்றொடருடன் புதிய பணப்பையை உருவாக்குங்கள்; பின்னர் பெறுநர் முகவரியைச் சரிபார்த்த பிறகே நிதியை மாற்றுங்கள். மாணவர் வழிகாட்டியின் தொகுதி 3-இல் உள்ள “மீட்புச் சொற்றொடர்கள்” பகுதியை மீண்டும் படிக்கவும்.

## Question 4

பிறர் பாதுகாப்பிலும் சுயப் பாதுகாப்பிலும் உள்ள வேறுபாடு என்ன?

* [x] விசைகளை யார் கட்டுப்படுத்துகிறார்கள் என்பது
* [ ] பணம் செலுத்தியதை மாற்றியமைக்கும் திறன்
* [ ] வழங்கல் வரம்பு
* [ ] பொறுப்பு

### Explanation

விசைகளை யார் கட்டுப்படுத்துகிறார்கள், அது தொடர்பான பொறுப்பை யார் ஏற்கிறார்கள் என்பதில் பிறர் பாதுகாப்பிலான பயன்பாடும் சுயப் பாதுகாப்பிலான பயன்பாடும் வேறுபடுகின்றன. இவற்றில் எதுவும் பாதுகாப்பையோ பரிவர்த்தனைகளை மாற்றியமைக்கும் திறனையோ உறுதிசெய்வதில்லை. மாணவர் வழிகாட்டியின் தொகுதி 3-இல் உள்ள “பிறர் பாதுகாப்பிலான மற்றும் சுயப் பாதுகாப்பிலான பயன்பாடு” பகுதியை மீண்டும் படிக்கவும்.
