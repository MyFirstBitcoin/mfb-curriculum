# 3.7 Billeteras calientes y frías

<!-- card: definition -->
> **Definition – Billetera caliente**
>
> Una [billetera caliente](https://curriculum.myfirstbitcoin.org/lexicon/en/#hot-wallet) administra claves en un dispositivo conectado a internet, como un celular o una computadora. Es práctica para pagos habituales, pero tiene una mayor superficie de ataque porque el software malicioso, las actualizaciones inseguras, el phishing, el acceso físico o la vulneración del dispositivo pueden dejar expuesta la billetera.



<!-- card: definition -->
> **Definition – Billetera fría**
>
> Una [billetera fría](https://curriculum.myfirstbitcoin.org/lexicon/en/#cold-wallet) describe una configuración que mantiene las claves de firma fuera de un dispositivo de uso general conectado a internet.



<!-- micrographic: hot-and-cold-wallets-01 -->
[Una billetera caliente guarda las claves de firma en un dispositivo conectado a internet, como un celular; una configuración en frío las mantiene alejadas de cualquier dispositivo conectado. Quién controla las claves es una cuestión aparte.](/micrographics/hot-and-cold-wallets-01/es-419.md)



<!-- card: definition -->
> **Definition – Billetera de hardware**
>
> Una [billetera de hardware](https://curriculum.myfirstbitcoin.org/lexicon/en/#hardware-wallet) describe un dispositivo especializado diseñado para generar, proteger y usar claves mientras las mantiene aisladas de la computadora o el celular conectado. Una [billetera de hardware](https://curriculum.myfirstbitcoin.org/lexicon/en/#hardware-wallet) puede servir para una configuración en frío, pero los términos no son intercambiables; [custodia](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) y recuperación son cuestiones distintas.

**Inténtelo:** Para un pago ficticio pequeño y un pago ficticio menos frecuente, explique qué [equilibrio entre ventajas y desventajas](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off) importa más. No elija una herramienta ni un monto para sus propios fondos.
