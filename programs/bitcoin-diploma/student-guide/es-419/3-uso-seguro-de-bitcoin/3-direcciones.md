# 3.3 Direcciones

<!-- card: definition -->
> **Definition – Dirección de Bitcoin**
>
> Una [dirección de Bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-address) es información pública de recepción para un [pago en cadena](https://curriculum.myfirstbitcoin.org/lexicon/en/#on-chain-payment). Una billetera normalmente la muestra como texto y como código QR para que otra persona pueda enviarle bitcoin. A diferencia de una contraseña o una [clave privada](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key), una dirección no puede autorizar el gasto de fondos.



<!-- micrographic: address-two-formats-01 -->
[La pantalla para recibir pagos de una billetera muestra una dirección de Bitcoin de ejemplo dos veces: como código QR y como texto. Ambas formas contienen la misma información pública para recibir pagos, y ninguna permite autorizar gastos.](/micrographics/address-two-formats-01/es-419.md)


Si usted quiere recibir un [pago en cadena](https://curriculum.myfirstbitcoin.org/lexicon/en/#on-chain-payment), ¿de dónde debe obtener la dirección? Abra la billetera en la que desea recibir el pago y use su pantalla de recepción. Quien envía el pago puede escanear el código QR o copiar la dirección. Esto evita los errores que pueden ocurrir al escribir manualmente cadenas largas de caracteres.

Para cada solicitud de pago, confirme el método de pago previsto. Una dirección en cadena y una [factura Lightning](https://curriculum.myfirstbitcoin.org/lexicon/en/#lightning-invoice) son diferentes. Después de escanear o copiar, compare el destino con el que aparece en la pantalla de recepción de confianza antes de aprobar un pago. ¿Por qué verificar después de copiar? El software malicioso puede reemplazar la información de la dirección copiada. Una nueva dirección en cadena para recibir un nuevo pago puede mejorar la [privacidad](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Reutilizar una dirección puede facilitar que otras personas vinculen pagos distintos entre sí. Una dirección nueva reduce la facilidad de establecer ese vínculo; no hace que un pago sea anónimo.

<!-- card: light -->
> Cuando un pago sea importante, no decida que una dirección es segura solo porque le resulta familiar. Confirme el destinatario previsto, la [red de Bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-network) correcta, el destino y el método de pago. Haga primero una prueba con un monto pequeño cuando el proceso o el monto no le resulten familiares.
