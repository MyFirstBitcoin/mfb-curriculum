# 3.1 Uso seguro de Bitcoin

Este módulo trata sobre dar los primeros pasos de forma segura, no sobre convertirse en experto ni asumir riesgos financieros. Usted practicará con simulaciones preparadas, entornos de prueba, billeteras de práctica o, cuando su docente lo considere apropiado, una actividad real de bajo riesgo.


> **Dark**
>
> No necesita comprar ni adquirir bitcoin de ninguna otra manera, ni usar fondos personales, para completar el Diplomado en Bitcoin.


¿Qué información puede compartir de forma segura? ¿Qué información podría darle el control a otra persona? ¿Cómo se daría cuenta de que una solicitud de pago ha cambiado? Estas preguntas importan antes de que cualquier billetera, pago o copia de seguridad cobre importancia.

Aplique estas tres reglas durante todo el módulo:

1. **Comparta información para recibir, nunca secretos.** Una dirección o solicitud de pago puede recibir bitcoin. Una [clave privada](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) o [frase de recuperación](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) puede controlarlo.
1. **Haga una pausa antes de aprobar un envío.** Verifique la persona, el método de pago, el destino, el monto y la pantalla final.
1. **Limite las consecuencias de los errores.** Deténgase y pida ayuda cuando una solicitud no sea clara, lo presione a actuar con prisa o le pida información secreta.

Al finalizar, usted debería poder explicar quién controla las claves, completar una tarea práctica guiada de recepción o envío, responder de forma segura ante una estafa o discrepancia y demostrar que está preparado para una recuperación sin exponer ningún secreto real. El objetivo no es la rapidez. Es saber cuándo hacer una pausa.

El módulo se organiza en torno a tres preguntas prácticas:

1. **¿Qué puedo compartir y qué debe permanecer en secreto?**
1. **¿Qué debo verificar antes de recibir o enviar?**
1. **¿Cuándo debo detenerme y pedir ayuda?**

Use las explicaciones a continuación para prepararse para las tres prácticas guiadas: una revisión de la pantalla de recepción, una revisión de envío y verificación, y un escenario de preparación para la recuperación o de respuesta ante una estafa.
