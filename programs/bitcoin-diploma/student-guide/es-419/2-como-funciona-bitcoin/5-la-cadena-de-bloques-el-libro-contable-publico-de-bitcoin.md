# 2.5 La cadena de bloques: el libro contable público de Bitcoin

A diferencia de los bancos, que tienen cada uno su propio registro de transacciones y deben coordinarse entre sí, las transacciones de Bitcoin se registran y almacenan en un ÚNICO libro contable digital, descentralizado y público. Este libro contable se almacena en un formato de datos conocido como “cadena de bloques”.

Un bloque contiene una serie de transacciones (en orden), y cada bloque es como una página de un libro contable. Las transacciones dentro de cada bloque están en un orden cronológico preciso y los bloques también se ordenan y se “encadenan” entre sí en orden cronológico.

Bitcoin está diseñado para agregar un nuevo bloque de transacciones a la cadena de bloques aproximadamente cada 10 minutos.La cadena de bloques básicamente solo permite agregar información, por lo que se considera “inmutable”, es decir, que no se puede alterar, un concepto fundamental para la exactitud, la seguridad y la estabilidad.
