# 4.4 Herramientas y recursos locales de Bitcoin

Los bitcoiners locales pueden usar billeteras, plataformas de intercambio, mercados entre pares, herramientas para comercios, mapas, encuentros, dispositivos físicos y recursos educativos. La disponibilidad y la calidad pueden cambiar rápidamente.

Usa esta comparación antes de adoptar una herramienta:


| Área | Qué verificar |
| --- | --- |
| Propósito | ¿Qué problema resuelve la herramienta? ¿Es necesaria? |
| Custodia | ¿Quién controla las claves y los fondos? |
| Fuente | ¿Quién la publica? ¿El dominio o la ficha en la tienda de aplicaciones son auténticos? |
| Código | ¿Es de código abierto? ¿Se revisa y se mantiene activamente? |
| Recuperación | ¿Qué pasa si el dispositivo, el servicio o la empresa desaparecen? |
| Privacidad | ¿Qué datos de identidad, transacciones, contactos o dispositivos se recopilan? |
| Costo | ¿Qué comisiones, diferenciales de cambio, suscripciones o costos de hardware se aplican? |
| Compatibilidad | ¿Es compatible con la billetera, la red, la dirección o la factura requeridas? |
| Soporte | ¿Hay ayuda local segura disponible sin tener que compartir información secreta? |
| Legislación | ¿Existen restricciones locales, obligaciones de presentar informes o consecuencias fiscales? |


Las herramientas mencionadas que se usan en clase son ejemplos locales, no recomendaciones de My First Bitcoin. Registra la fecha en que se verificó cada herramienta. Una herramienta que era adecuada el año pasado puede tener hoy otros propietarios, comisiones, funciones o riesgos.
