# 4.9 Ventajas y desventajas de operar con KYC y sin KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) y [sin KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) son vías que implican diferentes [ventajas y desventajas](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Ninguna de estas etiquetas elimina la necesidad de una evaluación cuidadosa.


<!-- card: callout -->
> **La privacidad no elimina los riesgos legales ni los riesgos para la seguridad física**
>
> Ni [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ni [sin KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) es automáticamente la mejor opción. Compare la vía concreta, consulte orientación local actualizada cuando las normas no estén claras y no infrinja la legislación local ni se exponga a peligros físicos en busca de [privacidad](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Un servicio con [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) puede solicitar el nombre legal, un documento de identidad, la dirección, una fotografía, información sobre el origen de los fondos u otros registros. Esto puede permitirle al servicio cumplir con las normas locales, conectarse con bancos, establecer límites más altos o facilitar la recuperación de la cuenta.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) también genera riesgos para los datos. El servicio puede almacenar un vínculo permanente entre la identidad, los métodos de pago y las [transacciones en bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Una filtración de datos, un requerimiento legal, un uso indebido interno o un cambio de política puede exponer esa información o restringir el acceso a ella.

Una vía [sin KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) puede recopilar menos información de identidad. Esto puede mejorar la [privacidad](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) financiera. También puede implicar contrapartes menos reguladas, menor liquidez, mayores [precios](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), menos asistencia, mayor riesgo de fraude o restricciones legales.

Compare la vía concreta:


| Pregunta | Vía con KYC | Vía sin KYC |
| --- | --- | --- |
| ¿Qué datos de identidad se recopilan? |  |  |
| ¿Quién almacena los datos y durante cuánto tiempo? |  |  |
| ¿Se puede vincular la transacción en la cadena de bloques? |  |  |
| ¿Qué protección contra el fraude existe? |  |  |
| ¿Qué riesgo de contraparte existe? |  |  |
| ¿Qué límites y comisiones se aplican? |  |  |
| ¿Qué legislación local se aplica? |  |  |
| ¿Qué ocurre durante una disputa? |  |  |


[La privacidad](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) no significa mantener todo en secreto frente a cualquier riesgo. Es la capacidad de controlar la información sobre usted. No infrinja la legislación local ni se exponga a peligros físicos en busca de [privacidad](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Busque orientación local actualizada de una persona calificada cuando las normas no estén claras.
