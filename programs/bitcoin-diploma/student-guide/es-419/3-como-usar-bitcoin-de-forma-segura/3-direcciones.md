# 3.3 Direcciones

Una **dirección de Bitcoin** es información pública que permite recibir un pago en cadena. Una billetera normalmente la muestra como texto y como código QR. No es una contraseña y no puede autorizar gastos por sí sola.

Si quieres recibir un pago en cadena, ¿de dónde debes obtener la dirección? Abre la billetera en la que deseas recibirlo y usa su pantalla de recepción. Quien envía el pago puede escanear el código QR o copiar la dirección. Esto evita los errores que pueden ocurrir al escribir a mano largas secuencias de caracteres.

Para cada solicitud de pago, confirma el método de pago previsto. Una dirección para pagos en cadena y una factura Lightning son diferentes. Después de escanear o copiar, compara el destino con el que aparece en la pantalla de recepción de confianza antes de aprobar un pago. ¿Por qué verificar después de copiar? Un software malicioso puede reemplazar la información de la dirección copiada. Usar una nueva dirección para cada pago recibido en cadena puede mejorar la privacidad.

Cuando un pago sea importante, no decidas que una dirección es segura solo porque te resulta familiar. Confirma el destinatario previsto, la red de Bitcoin correcta, el destino y el método de pago. Primero haz una prueba con un monto pequeño si no estás familiarizado con el proceso o el monto.
