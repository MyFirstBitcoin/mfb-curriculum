# 3.9 Recibir bitcoin

**Práctica 1: recibir de forma segura**

Recibir no autoriza la salida de fondos de tu billetera, pero aun así requiere una revisión cuidadosa. Comienza por preguntarte: ¿estoy usando la billetera y el método de pago previstos?

1. Abre la billetera preparada y elige **Recibir**.
1. Identifica si la solicitud es en cadena o por Lightning.
1. Comparte únicamente la dirección, el código QR o la solicitud de pago.
1. Si se muestra un monto, verifícalo con quien envía el pago.
1. Revisa el monto y el estado en tu propia billetera.

Un mensaje o una captura de pantalla que diga “enviado” no es una prueba. ¿Qué evidencia puedes ver por tu cuenta? Revisa la billetera receptora o la vista de transacciones autorizada. Para los pagos en cadena, una billetera puede mostrar inicialmente la transacción como pendiente. El estado de confirmación da mayor certeza de que el pago se ha liquidado; no corrige una dirección equivocada ni una estafa. Una billetera puede ofrecer una dirección nueva para recibir otro pago; las direcciones anteriores pueden seguir funcionando, pero usar direcciones nuevas puede dificultar que se vinculen los pagos entre sí.
