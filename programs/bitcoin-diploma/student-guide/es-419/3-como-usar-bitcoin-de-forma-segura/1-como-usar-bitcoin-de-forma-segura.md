# 3.1 Cómo usar Bitcoin de forma segura

Este módulo trata de dar los primeros pasos de forma segura, no de convertirte en experto ni de asumir riesgos financieros. Practicarás con una simulación preparada, fondos de prueba o un monto aprobado por tu docente. No necesitas comprar bitcoin en ningún momento para completar el Diplomado.

¿Qué información puedes compartir de forma segura? ¿Qué información podría darle el control a otra persona? ¿Cómo notarías que una solicitud de pago ha cambiado? Estas preguntas son importantes antes de pensar en cualquier billetera, pago o copia de seguridad.

Sigue estas tres reglas durante todo el módulo:

1. **Comparte información para recibir, nunca información secreta.** Una dirección o una solicitud de pago sirve para recibir bitcoin. Una clave privada o una frase de recuperación permite controlarlo.
1. **Haz una pausa antes de aprobar un envío.** Verifica la persona, el método de pago, el destino, el monto y la pantalla final.
1. **Limita las consecuencias de los errores.** Detente y pide ayuda cuando una solicitud no sea clara, te presione para actuar rápido o te pida información secreta.

Al finalizar, deberías poder explicar quién controla las claves, completar una práctica guiada de recepción o envío, responder de forma segura ante una estafa o una discrepancia y demostrar que sabes cómo realizar una recuperación sin exponer ninguna información secreta real. El objetivo no es la rapidez. Es saber cuándo hacer una pausa.

El módulo se organiza en torno a tres preguntas prácticas:

1. **¿Qué puedo compartir y qué debe permanecer en secreto?**
1. **¿Qué debo verificar antes de recibir o enviar?**
1. **¿Cuándo debo detenerme y pedir ayuda?**

Usa las explicaciones que aparecen a continuación para prepararte para las tres prácticas guiadas: una revisión de la pantalla de recepción, una revisión del envío y su verificación, y un escenario de preparación para la recuperación o de respuesta ante una estafa.
