# 3.7 Billeteras calientes y frías

Una **billetera caliente** administra las claves en un dispositivo conectado a internet, como un teléfono o una computadora. Es práctica para pagos frecuentes. También tiene una mayor superficie de ataque porque el software malicioso, las actualizaciones inseguras, el phishing, el acceso físico o un dispositivo comprometido pueden poner en riesgo la billetera.

Una **billetera fría** mantiene las claves utilizadas para firmar transacciones fuera de un dispositivo de uso general conectado a internet. Una **billetera de hardware** es un dispositivo especializado diseñado para generar, proteger y usar claves, manteniéndolas aisladas de la computadora o el teléfono al que está conectado.


| Modalidad | Ventaja habitual | Responsabilidad a tener en cuenta |
| --- | --- | --- |
| Billetera caliente | Acceso práctico para pagos frecuentes. | Un dispositivo conectado a internet puede sufrir ataques de malware o phishing, o perderse. |
| Billetera de hardware o fría | Claves de firma más aisladas. | El dispositivo, la copia de seguridad y el proceso de recuperación siguen necesitando protección. |
| Cuenta con custodia | Inicio de sesión familiar y soporte disponible. | Un proveedor controla el acceso y puede imponer límites. |


**Ponlo en práctica:** Para un pago ficticio de poco valor y otro pago ficticio menos frecuente, explica qué equilibrio entre ventajas y desventajas importa más. No elijas una herramienta ni un monto para tus propios fondos.
