# 3.2 Billeteras

Una **billetera de Bitcoin** es una herramienta que gestiona la información necesaria para recibir y autorizar transacciones de Bitcoin. Puede ser una aplicación, un dispositivo especializado o un servicio. Los bitcoins quedan registrados en el libro contable compartido; no se almacenan dentro de un teléfono.

¿Qué pasaría si tu teléfono dejara de funcionar? El registro de Bitcoin seguiría existiendo, pero el acceso dependería de las claves y del método de recuperación que utilice la billetera. Una billetera ayuda a generar información para recibir pagos, mostrar saldos e historial de transacciones y autorizar gastos. Esto no elimina la necesidad de entender quién controla el acceso.

La primera pregunta sobre cualquier billetera es: **¿quién controla las claves?** Antes de usar una herramienta, verifica quién puede autorizar un pago, cómo se recupera el acceso y qué métodos de pago admite. Cuando corresponda, prefiere software de billeteras de código abierto con una trayectoria consolidada, pero recuerda que el código abierto por sí solo no demuestra que una herramienta sea segura o adecuada. Empieza con un entorno preparado por un educador; no elijas una herramienta porque te la recomiende un desconocido.
