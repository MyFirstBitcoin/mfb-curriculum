# 4.9 Prednosti in slabosti pristopov s KYC in brez KYC

[Poti KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) in [brez KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) vključujejo različne [kompromise](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Nobena od teh oznak ne odpravlja potrebe po skrbni presoji.


<!-- card: callout -->
> **Zasebnost ne odpravlja pravnih tveganj ali tveganj za telesno varnost**
>
> Niti [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) niti [pristop brez KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ni samodejno najboljša izbira. Primerjajte konkretno pot, ob nejasnih pravilih upoštevajte aktualne lokalne smernice ter ne kršite lokalne zakonodaje in se ne izpostavljajte telesni nevarnosti v prizadevanju za [zasebnost](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Storitev [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) lahko zahteva uradno ime in priimek, osebni dokument, naslov, fotografijo, podatke o izvoru sredstev ali drugo dokumentacijo. To lahko storitvi omogoči izpolnjevanje lokalnih predpisov, povezovanje z bankami, določanje višjih omejitev ali podporo pri obnovitvi dostopa do računa.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ustvarja tudi tveganja v zvezi s podatki. Storitev lahko trajno hrani povezavo med identiteto, plačilnimi metodami in bitcoin [transakcijami](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Vdor, pravna zahteva, notranja zloraba ali sprememba pravilnika lahko privede do razkritja teh podatkov ali omejitve dostopa do njih.

Pot [brez KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) lahko vključuje zbiranje manj podatkov o identiteti. To lahko izboljša finančno [zasebnost](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Vključuje lahko tudi manj regulirane nasprotne stranke, nižjo likvidnost, višje [cene](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), manj podpore, večje tveganje prevar ali pravne omejitve.

Primerjajte konkretno pot:


| Vprašanje | Pot KYC | Pot brez KYC |
| --- | --- | --- |
| Kateri podatki o identiteti se zbirajo? |  |  |
| Kdo hrani podatke in kako dolgo? |  |  |
| Ali je mogoče transakcijo povezati z identiteto na podlagi podatkov v verigi blokov? |  |  |
| Kakšna zaščita pred prevarami je na voljo? |  |  |
| Kakšno tveganje predstavlja nasprotna stranka? |  |  |
| Katere omejitve in provizije veljajo? |  |  |
| Katera lokalna zakonodaja velja? |  |  |
| Kaj se zgodi v primeru spora? |  |  |


[Zasebnost](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) ne pomeni prikritosti, ki bi vas zaščitila pred vsemi tveganji. Pomeni možnost nadzora nad podatki o sebi. Ne kršite lokalne zakonodaje in se ne izpostavljajte telesni nevarnosti v prizadevanju za [zasebnost](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Kadar so pravila nejasna, pri usposobljeni osebi poiščite aktualne napotke za svoje lokalno okolje.
