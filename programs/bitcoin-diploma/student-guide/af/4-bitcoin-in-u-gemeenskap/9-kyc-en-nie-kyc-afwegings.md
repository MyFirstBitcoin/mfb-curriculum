# 4.9 KYC- en nie-KYC-afwegings

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) en [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) behels verskillende [afwegings](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Nie een van die twee etikette skakel die behoefte aan noukeurige evaluering uit nie.


<!-- card: callout -->
> **Privaatheid skakel nie regsrisiko of risiko vir fisieke veiligheid uit nie**
>
> Nóg [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) nóg [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) is outomaties die beste. Vergelyk die werklike benadering, gebruik bygewerkte plaaslike riglyne wanneer reëls onduidelik is, en moenie plaaslike wetgewing oortree of uself aan fisieke gevaar blootstel in u strewe na [privaatheid](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

'n [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) diens kan 'n wettige naam, identiteitsdokument, adres, foto, inligting oor die bron van fondse of ander rekords aanvra. Dit kan die diens in staat stel om aan plaaslike reëls te voldoen, by banke aan te sluit, hoër perke te stel of rekeningherstel te ondersteun.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) skep ook datarisiko. Die diens kan 'n permanente verband bewaar tussen identiteit, betaalmetodes en bitcoin [transaksies](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). 'n Databreuk, regsversoek, interne misbruik of beleidsverandering kan daardie inligting blootlê of toegang daartoe beperk.

'n [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) benadering kan minder identiteitsinligting insamel. Dit kan finansiële [privaatheid](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) verbeter. Dit kan ook minder gereguleerde teenpartye, laer likiditeit, hoër [pryse](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), minder ondersteuning, groter bedrogrisiko of wetlike beperkings behels.

Vergelyk die werklike benadering:


| Vraag | KYC-benadering | No-KYC-benadering |
| --- | --- | --- |
| Watter identiteitsdata word ingesamel? |  |  |
| Wie bewaar die data en vir hoe lank? |  |  |
| Kan die Transaksie op die blokketting gekoppel word? |  |  |
| Watter beskerming teen bedrog bestaan daar? |  |  |
| Watter teenpartyrisiko bestaan daar? |  |  |
| Watter perke en fooie geld? |  |  |
| Watter plaaslike wetgewing geld? |  |  |
| Wat gebeur tydens 'n geskil? |  |  |


[Privaatheid](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) beteken nie geheimhouding wat u teen elke risiko beskerm nie. Dit is die vermoë om inligting oor uself te beheer. Moenie plaaslike wetgewing oortree of uself aan fisieke gevaar blootstel in u strewe na [privaatheid](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Kry bygewerkte plaaslike leiding by 'n gekwalifiseerde persoon wanneer die reëls onduidelik is.
