# 4.9 Afwegingen tussen KYC en no-KYC

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)- en [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)-routes maken verschillende [afwegingen](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Geen van beide labels neemt de noodzaak van een zorgvuldige beoordeling weg.


<!-- card: callout -->
> **Privacy neemt juridische risico's en risico's voor uw fysieke veiligheid niet weg**
>
> Noch [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) noch [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) is automatisch de beste keuze. Vergelijk de daadwerkelijke route, raadpleeg actuele lokale richtlijnen wanneer de regels onduidelijk zijn, en overtreed geen lokale wetgeving en stel uzelf niet bloot aan fysiek gevaar in het streven naar [privacy](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Een [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)-dienst kan vragen om een wettelijke naam, een identiteitsbewijs, een adres, een foto, informatie over de herkomst van middelen of andere gegevens. Hierdoor kan de dienst voldoen aan lokale regels, verbinding maken met banken, hogere limieten instellen of accountherstel ondersteunen.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) brengt ook datarisico's met zich mee. De dienst kan een permanente koppeling opslaan tussen identiteit, betaalmethoden en bitcoin[transacties](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Een datalek, een juridisch verzoek, intern misbruik of een beleidswijziging kan die informatie blootleggen of beperken.

Een [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)-route verzamelt mogelijk minder identiteitsgegevens. Dit kan uw financiële [privacy](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) verbeteren. Het kan echter ook gepaard gaan met minder gereguleerde tegenpartijen, lagere liquiditeit, hogere [prijzen](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), minder ondersteuning, een groter risico op fraude of juridische beperkingen.

Vergelijk de werkelijke route:


| Vraag | KYC-route | No-KYC-route |
| --- | --- | --- |
| Welke identiteitsgegevens worden verzameld? |  |  |
| Wie slaat de gegevens op en hoe lang? |  |  |
| Kan de transactie on-chain worden gekoppeld? |  |  |
| Welke bescherming tegen fraude is er? |  |  |
| Welk tegenpartijrisico bestaat er? |  |  |
| Welke limieten en kosten gelden er? |  |  |
| Welke lokale wetgeving is van toepassing? |  |  |
| Wat gebeurt er bij een geschil? |  |  |


[Privacy](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) is geen bescherming tegen elk risico. Het is het vermogen om informatie over uzelf te beheren. Overtreed geen lokale wetgeving en stel uzelf niet bloot aan fysiek gevaar in het streven naar [privacy](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Vraag een deskundige om actuele lokale richtlijnen wanneer de regels onduidelijk zijn.
