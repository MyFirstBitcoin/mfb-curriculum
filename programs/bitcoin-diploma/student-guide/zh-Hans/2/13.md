# 2.13 比特币：稳健的数字货币

正如**第1单元**所介绍的，[**稳健货币**](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money)是指供应量难以扩张、其特性支持长期可靠使用的货币。这一术语表达的是基于一定标准的判断，因此应当加以审视，而不是作为标签直接接受。

比特币结合了以往从未同时存在于同一种[资产](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset)中的多种特性：


<!-- micrographic: bitcoin-money-properties-01 -->
[比特币在一种资产中结合了货币的七种属性：耐久性、便携性、可分割性、可替代性、稀缺性、可验证性和可接受性。每一种属性都有其实际局限，例如需要妥善保管密钥，以及在许多社区中接受度仍然较低。](/micrographics/bitcoin-money-properties-01/zh-Hans.md)



| 特性 | 通俗解释 |
| --- | --- |
| 耐久性 | 账本被复制到众多节点上。能否访问取决于是否妥善保存有效的密钥。 |
| 便携性 | 一笔已签名的交易可以通过通信网络转移价值。 |
| 可分割性 | 1个比特币（1 BTC）可分割为100,000,000聪。 |
| 可替代性 | 相同数额的资金在同样的协议规则下均可花费，但公开的交易历史可能会影响某些服务对特定资金的处理方式。 |
| 稀缺性 | 发行遵循公开规则，上限为2100万枚。 |
| 可验证性 | 节点可以验证供应量、交易规则和所有权证明。 |
| 可接受性 | 在一些地方，接受度正在提高，但在许多社区中仍远低于国家货币。 |


比特币能够履行货币的三大职能，但在不同地方的表现并不相同：

* 作为[**价值储存手段**](https://curriculum.myfirstbitcoin.org/lexicon/en/#store-of-value)，其供应量可预测，但其市场[价格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)波动较大。
* 作为[**交换媒介**](https://curriculum.myfirstbitcoin.org/lexicon/en/#medium-of-exchange)，它可以不经银行进行转移，但接受程度、手续费和支付工具各不相同。
* 作为[**记账单位**](https://curriculum.myfirstbitcoin.org/lexicon/en/#unit-of-account)，金额可以用比特币或[聪](https://curriculum.myfirstbitcoin.org/lexicon/en/#satoshi)来表示，但大多数商品仍以法定[货币](https://curriculum.myfirstbitcoin.org/lexicon/en/#currency)计价。

因此，比特币既带来好处，也存在[权衡取舍](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)。

**潜在好处**包括直接所有权、可预测的供应量、全球转账、开放参与、透明的规则，以及抵御单方面审查的能力。

[**权衡取舍**](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)包括[价格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)[波动](https://curriculum.myfirstbitcoin.org/lexicon/en/#volatility)、个人安全责任、有效付款通常难以甚至无法撤销、不断变化的[交易手续费](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction-fee)、数字转账对电力和通信的依赖、公开的[交易](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction)记录，以及有限的接受度。

您是否称比特币为[稳健货币](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money)，应当取决于您的评判标准。请用相同的标准，将其与[法定货币](https://curriculum.myfirstbitcoin.org/lexicon/en/#fiat-money)、贵金属以及其他[资产](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset)进行比较。

**本地价值检验：**比特币在您所在的社区是否具有[价值](https://curriculum.myfirstbitcoin.org/lexicon/en/#value)？请在回答中区分三个问题：可以观察到怎样的市场[价格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)？它在哪些地方被接受（如果有的话）？哪些个人偏好或[偏见](https://curriculum.myfirstbitcoin.org/lexicon/en/#bias)影响了您的判断？[价格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)、本地实用性和个人认可彼此相关，但并不相同。
