# Quiz – 比特币如何运作：快速测验

## 问题 1

同一个数字单位被支付了两次。系统必须：

* [x] 拒绝双重支付
* [ ] 隐藏该笔付款
* [ ] 提高其价格
* [ ] 取消手续费

### 解析

数字信息可以被复制，因此货币系统必须防止同一单位被花费两次，并确定哪笔交易有效。请复习《学生指南》第2单元「早期数字货币尝试与双重支付问题」。

## 问题 2

比特币的去中心化意味着：

* [ ] 由一家公司批准付款
* [x] 由独立参与者执行规则
* [ ] 矿工可随意更改规则
* [ ] 每个人影响力相同

### 解析

比特币将验证和规则执行分散到各个独立的参与者之中。去中心化并不意味着由一家公司控制网络，也不意味着每个人拥有同等的影响力。请复习《学生指南》第2单元「去中心化」。

## 问题 3

比特币节点：

* [x] 检查网络规则
* [ ] 创造bitcoin
* [ ] 存储bitcoin
* [ ] 保证付款成功

### 解析

节点独立检查比特币的规则，并拒绝无效数据。它们不会应要求创造bitcoin，也不会把bitcoin存储在手机里。请复习《学生指南》第2单元「用户、节点与矿工」。

## 问题 4

为什么称比特币为稳健货币？

* [ ] 价格总是上涨
* [x] 供应公开且有限
* [ ] 由一家公司控制
* [ ] 付款是私密的

### 解析

有些人将比特币描述为稳健货币，因为它的供应规则是公开的，且发行量有限。这是一种有理有据的判断，而非对价格或隐私的承诺。请复习《学生指南》第2单元「比特币作为稳健的数字货币」。
