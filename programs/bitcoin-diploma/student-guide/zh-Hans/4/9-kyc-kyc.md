# 4.9 KYC与非KYC的利弊权衡

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)与[无KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)途径各有不同的[权衡取舍](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)。无论哪种标签，都无法免除审慎评估的必要。


<!-- card: callout -->
> **隐私并不能消除法律风险或人身安全风险**
>
> 无论是[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)还是[无KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)，都不是天然的最佳选择。请比较实际的途径，在规则不明确时参考当地最新的指导意见，切勿为了追求[隐私](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)而违反当地法律或使自己面临人身危险。


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

某项[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)服务可能会要求您提供法定姓名、身份证件、地址、照片、资金来源信息或其他记录。这可能使该服务能够符合当地规定、与银行对接、设定更高的限额，或支持账户恢复。

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)同样会带来数据风险。服务方可能会永久保存您的身份、支付方式与比特币[交易](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction)之间的关联。数据泄露、法律调取、内部滥用或政策变更，都可能导致这些信息被曝光或受到限制。

某条[无KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc)途径收集的身份信息可能较少，这有助于提升金融[隐私](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)。但它也可能涉及监管较少的交易对手、较低的流动性、较高的[价格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)、较少的支持、较高的欺诈风险或法律限制。

请比较实际的途径：


| 问题 | KYC途径 | 无KYC途径 |
| --- | --- | --- |
| 会收集哪些身份数据？ |  |  |
| 谁保存这些数据？保存多久？ |  |  |
| 该交易能否在链上被关联？ |  |  |
| 有哪些防欺诈保护？ |  |  |
| 存在哪些交易对手风险？ |  |  |
| 适用哪些限额和费用？ |  |  |
| 适用哪些当地法律？ |  |  |
| 发生纠纷时会怎样？ |  |  |


[隐私](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)并不意味着能躲避一切风险，而是掌控自身信息的能力。切勿为了追求[隐私](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)而违反当地法律或使自己面临人身危险。在规则不明确时，请向具备资质的专业人士寻求当地最新的指导意见。
