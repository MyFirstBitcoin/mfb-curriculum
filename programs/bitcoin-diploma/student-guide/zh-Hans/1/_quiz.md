# Quiz – 认识货币：快速测验

## Question 1

货币为什么会被接受？

* [x] 人们预期他人会接受它
* [ ] 它使所有商品价值相等
* [ ] 它消除了所有规则
* [ ] 它把服务变成商品

### Explanation

货币帮助陌生人跨越时间协调交换，因为人们预期他人日后也会接受它。它仍然依赖于信任、规则和社会认可。请复习《学生指南》第1单元「货币为何存在」。

## Question 2

标价、付款、储蓄：分别对应哪种职能？

* [ ] 价值储藏；记账单位；交换媒介
* [x] 记账单位；交换媒介；价值储藏
* [ ] 交换媒介；价值储藏；记账单位
* [ ] 稀缺性；稀缺性；稀缺性

### Explanation

记账单位用于表示价格，交换媒介在付款时被接受，价值储藏将价值转移到未来。请复习《学生指南》第1单元「货币的职能与属性」。

## Question 3

用大米换鞋子失败了：为什么？

* [ ] 价格不同
* [x] 需求不匹配
* [ ] 没有银行批准
* [ ] 大米无法交易

### Explanation

当双方并不同时想要对方所提供的东西时，直接以物易物就很困难。这就是需求的双重巧合问题。请复习《学生指南》第1单元「以物易物与需求的双重巧合」。

## Question 4

物价上涨10%，收入增加5%：购买力如何变化？

* [ ] 上升
* [ ] 保持不变
* [x] 下降
* [ ] 无法判断

### Explanation

购买力是指货币能够买到的东西。如果物价上涨快于收入增长，同样的收入能买到的东西就会变少。请复习《学生指南》第1单元「通货膨胀与购买力」。
