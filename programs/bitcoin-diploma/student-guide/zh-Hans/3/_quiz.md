# Quiz – 安全使用比特币：快速自测

## Question 1

比特币钱包：

* [ ] 存储比特币
* [x] 管理密钥并进行签名
* [ ] 取消对秘密信息的保护
* [ ] 撤销交易

### Explanation

比特币记录在共享账本上；钱包管理的是用于访问和使用比特币的信息。请复习《学生指南》第3单元「钱包」。

## Question 2

为接收比特币，您可以分享：

* [ ] 助记词
* [ ] 私钥
* [x] 接收地址
* [ ] 密码

### Explanation

接收地址可以分享给他人用于付款。助记词、私钥和密码必须保密。请复习《学生指南》第3单元「地址」和「密钥」。

## Question 3

助记词已在网上输入过。最安全的下一步是什么？

* [ ] 等待
* [ ] 发送给客服
* [x] 生成新助记词，然后转移资金
* [ ] 继续使用该助记词

### Explanation

在网上输入过的助记词应视为已泄露。请使用新的助记词创建新钱包，并在核实目标地址后再转移资金。请复习《学生指南》第3单元「助记词」。

## Question 4

托管方式的区别在于？

* [x] 由谁控制密钥
* [ ] 付款是否可撤销
* [ ] 供应上限
* [ ] 责任

### Explanation

托管与自托管的区别在于由谁控制密钥并承担相应责任。两者都不能保证安全或交易可撤销。请复习《学生指南》第3单元「托管与非托管使用」。
