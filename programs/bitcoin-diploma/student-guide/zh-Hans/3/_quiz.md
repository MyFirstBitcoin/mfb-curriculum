# Quiz – 安全使用比特币：快速测验

## 问题 1

比特币钱包：

* [ ] 存储比特币
* [x] 管理密钥并进行签名
* [ ] 解除秘密信息的保护
* [ ] 撤销交易

### 解析

比特币记录在共享账本上；钱包管理的是用于访问和使用比特币的信息。请复习《学生指南》第3单元「钱包」。

## 问题 2

为接收比特币，您可以分享：

* [ ] 助记词
* [ ] 私钥
* [x] 收款地址
* [ ] 密码

### 解析

收款地址可以分享出去用于收款。助记词、私钥和密码必须保密。请复习《学生指南》第3单元「地址」和「密钥」。

## 问题 3

助记词已在网上输入过。最安全的下一步是？

* [ ] 等待观望
* [ ] 将其发送给客服
* [x] 使用新助记词，再转移资金
* [ ] 继续使用该助记词

### 解析

在网上输入过的助记词应视为已泄露。请使用新的助记词创建新钱包，并在核实目标地址后再转移资金。请复习《学生指南》第3单元「助记词」。

## 问题 4

托管式使用与自我托管式使用的主要区别是什么？

* [x] 由谁控制密钥
* [ ] 付款能否撤销
* [ ] 供应上限
* [ ] 交易手续费

### 解析

托管式使用与自我托管式使用的区别在于由谁控制密钥并承担相应责任。两者都不能保证安全，也不能保证交易可撤销。请复习《学生指南》第3单元「托管式与非托管式使用」。
