# 4.9 Prednosti i nedostaci KYC-a i pristupa bez KYC-a

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) i [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) pristupi podrazumevaju različite [kompromise](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off). Nijedna oznaka ne uklanja potrebu za pažljivom procenom.


<!-- card: callout -->
> **Privatnost ne uklanja pravne rizike niti rizike po fizičku bezbednost**
>
> Ni [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ni [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) nije automatski najbolji izbor. Uporedite konkretne pristupe, oslonite se na aktuelne lokalne smernice kada pravila nisu jasna i nemojte kršiti lokalne zakone niti se izlagati fizičkoj opasnosti u težnji ka [privatnosti](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy).


![](https://cdn.sanity.io/images/vje9ehw2/staging/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Jedna [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) usluga može zahtevati ime i prezime iz zvaničnih dokumenata, lični dokument, adresu, fotografiju, informacije o poreklu sredstava ili druge podatke. To može omogućiti pružaocu usluge da ispuni lokalne propise, poveže se sa bankama, postavi više limite ili podrži oporavak naloga.

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) takođe stvara rizik po podatke. Pružalac usluge može čuvati trajnu vezu između identiteta, načina plaćanja i bitcoin [transakcija](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction). Povreda bezbednosti podataka, zahtev nadležnih organa, interna zloupotreba ili promena pravila poslovanja mogu otkriti te informacije ili ograničiti pristup njima.

Jedan [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) pristup može podrazumevati prikupljanje manje podataka o identitetu. To može poboljšati finansijsku [privatnost](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Takođe može uključivati druge strane u transakciji koje podležu manjoj regulaciji, nižu likvidnost, više [cene](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), slabiju podršku, veći rizik od prevare ili zakonska ograničenja.

Uporedite konkretne pristupe:


| Pitanje | KYC pristup | No-KYC pristup |
| --- | --- | --- |
| Koji podaci o identitetu se prikupljaju? |  |  |
| Ko čuva podatke i koliko dugo? |  |  |
| Može li se transakcija povezati sa identitetom na blokčejnu? |  |  |
| Kakva zaštita od prevare postoji? |  |  |
| Kakav rizik nosi druga strana u transakciji? |  |  |
| Koji limiti i naknade važe? |  |  |
| Koji lokalni zakoni se primenjuju? |  |  |
| Šta se dešava u slučaju spora? |  |  |


[Privatnost](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) ne znači tajnost koja štiti od svakog rizika. Ona je mogućnost da kontrolišete informacije o sebi. Nemojte kršiti lokalne zakone niti se izlagati fizičkoj opasnosti u težnji ka [privatnosti](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy). Kada pravila nisu jasna, zatražite aktuelne lokalne smernice od stručne osobe.
