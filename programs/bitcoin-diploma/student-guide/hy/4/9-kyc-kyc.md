# 4.9 KYC-ով և առանց KYC-ի տարբերակների առավելություններն ու թերությունները

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) և [առանց KYC-ի](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ուղիները ենթադրում են տարբեր [փոխզիջումներ](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)։ Այս պիտակներից ոչ մեկը չի վերացնում մանրակրկիտ գնահատման անհրաժեշտությունը։


<!-- card: callout -->
> **Գաղտնիությունը չի վերացնում իրավական կամ ֆիզիկական անվտանգության ռիսկերը**
>
> Ո՛չ [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc), ո՛չ էլ [առանց KYC-ի](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ուղին ինքնաբերաբար լավագույնը չէ։ Համեմատեք իրական ուղին, օգտվեք տեղական արդի խորհրդատվությունից, երբ կանոնները հստակ չեն, և մի՛ խախտեք տեղական օրենքները կամ Ձեզ ֆիզիկական վտանգի ենթարկեք հանուն [գաղտնիության](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)։


![](https://cdn.sanity.io/images/vje9ehw2/production/7af8a2eb79ede0b36361dc0d1d6fe8f7ff404da2-1536x1024.svg)

Մի [KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc) ծառայություն կարող է պահանջել պաշտոնական անունը, անձը հաստատող փաստաթուղթ, հասցե, լուսանկար, միջոցների ծագման մասին տեղեկություններ կամ այլ տվյալներ։ Դա կարող է ծառայությանը հնարավորություն տալ պահպանելու տեղական կանոնները, կապ հաստատելու բանկերի հետ, սահմանելու ավելի բարձր սահմանաչափեր կամ աջակցելու հաշվի վերականգնմանը։

[KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#kyc)-ն նաև տվյալների հետ կապված ռիսկ է ստեղծում։ Ծառայությունը կարող է պահպանել մշտական կապ՝ ինքնության, վճարման եղանակների և բիթքոյնով [գործարքների միջև](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction)։ Տվյալների արտահոսքը, իրավական պահանջը, ներքին չարաշահումը կամ քաղաքականության փոփոխությունը կարող են հանգեցնել այդ տեղեկությունների բացահայտման կամ դրանց հասանելիության սահմանափակման։

Մի [առանց KYC-ի](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) ուղի կարող է հավաքել ինքնության վերաբերյալ ավելի քիչ տեղեկություններ։ Սա կարող է բարելավել ֆինանսական [գաղտնիությունը](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)։ Այն կարող է նաև ենթադրել պակաս կարգավորվող գործարքային կողմեր, ավելի ցածր իրացվելիություն, ավելի բարձր [գներ](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), ավելի սահմանափակ աջակցություն, խարդախության ավելի մեծ ռիսկ կամ իրավական սահմանափակումներ։

Համեմատեք իրական ուղին․


| Հարց | KYC ուղի | Առանց KYC-ի ուղի |
| --- | --- | --- |
| Ինքնության վերաբերյալ ի՞նչ տվյալներ են հավաքվում։ |  |  |
| Ո՞վ է պահում տվյալները և որքա՞ն ժամանակով։ |  |  |
| Հնարավո՞ր է գործարքը բլոկչեյնում կապել ինքնության հետ։ |  |  |
| Խարդախությունից ի՞նչ պաշտպանություն կա։ |  |  |
| Գործարքի մյուս կողմի հետ կապված ի՞նչ ռիսկ կա։ |  |  |
| Ի՞նչ սահմանաչափեր և վճարներ են կիրառվում։ |  |  |
| Տեղական ո՞ր օրենքն է կիրառվում։ |  |  |
| Ի՞նչ է տեղի ունենում վեճի դեպքում։ |  |  |


[Գաղտնիությունը](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) չի նշանակում ամեն տեսակի ռիսկից թաքնված լինել։ Դա Ձեր մասին տեղեկությունները վերահսկելու կարողությունն է։ Մի՛ խախտեք տեղական օրենքները կամ Ձեզ ֆիզիկական վտանգի ենթարկեք հանուն [գաղտնիության](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)։ Երբ կանոնները հստակ չեն, դիմեք որակավորված մասնագետի՝ տեղական արդի խորհրդատվություն ստանալու համար։
