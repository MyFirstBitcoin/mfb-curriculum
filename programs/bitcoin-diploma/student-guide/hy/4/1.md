# 4.1 Բիթքոյնը Ձեր համայնքում

![](https://cdn.sanity.io/images/vje9ehw2/staging/119ea5325cea83e0cdbf15651f5a19becfb07cdf-1536x1024.svg)

Սա **«Կապակցում»** փուլն է «Բիթքոյնի դիպլոմ» ծրագրի շրջանակում։ Դուք կկապակցեք ժամանակակից դրամական համակարգի թերություններն ու [փոխզիջումները](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off), Բիթքոյնի առաջարկած լուծումները և անվտանգ օգտագործման պատասխանատվությունը՝ վերցված **1–3 մոդուլներից**՝ տեղական կարիքի կամ հնարավորության, իրատեսական այլընտրանքի և անվտանգ գործնական առաջադրանքի հետ։ Ձեզնից չի ակնկալվում անցնել Բիթքոյնի օգտագործմանը կամ եզրակացնել, որ այն լավագույն տարբերակն է տեղական ցանկացած իրավիճակում։

Բիթքոյնը մեկ համաշխարհային արձանագրություն է, սակայն մարդիկ այն օգտագործում են տեղական տարբեր պայմաններում։ Համացանցի հասանելիությունը, հեռախոսները, օրենքները, հարկերը, [արժույթները](https://curriculum.myfirstbitcoin.org/lexicon/en/#currency), բանկերը, առևտրականները, վճարները, լեզուն, անվտանգությունն ու տեխնիկական աջակցությունը բոլորն էլ ազդում են այն բանի վրա, թե ինչն է օգտակար։

Ձեր դասավանդողն է ընտրում այս մոդուլի ուսումնական աշխատանքները։ Նպատակը յուրաքանչյուր գործիքը ցուցադրելը չէ։ Նպատակն է կապակցել հասկացությունները՝ վերցված **1–3 մոդուլներից**՝ ձեր համայնքում առկա իրական ընտրությունների հետ։ Երբ մասնագիտական գիտելիքներ են անհրաժեշտ, դասավանդողը կարող է հրավիրել տեղացի մասնագետի։

Օգտագործեք **3-րդ մոդուլի** անվտանգության ստուգաթերթը տեղական թեմաներին նվիրված յուրաքանչյուր մոդուլի ողջ ընթացքում։ Վերահսկվող վարժության ժամանակ բիթքոյն կամ որևէ անվանված գործիք օգտագործելը չի նշանակում, որ My First Bitcoin-ը կամ ձեր դասավանդողը խորհուրդ են տալիս այն օգտագործել հաճախակի, շարունակաբար կամ ավելի մեծ գումարներով։ Նպատակն է բավարար չափով համեմատել այդ տարբերակն ու դրա հետ կապված [փոխզիջումները](https://curriculum.myfirstbitcoin.org/lexicon/en/#trade-off)՝ սեփական որոշումը կայացնելու համար։

Գրանցեք ձեր ուսումնական ուղղվածությունը **4-րդ մոդուլում**:


| Տեղական ուսուցման ուղղվածությունը | Ձեր նշումները |
| --- | --- |
| Տեղական խնդիր կամ հնարավորություն |  |
| Իրատեսական այլընտրանք |  |
| Անվտանգ գործնական աշխատանք կամ սցենար |  |
| Հիմնական օգուտն ու ռիսկը |  |
| Հաջորդ անվտանգ քայլը |  |
