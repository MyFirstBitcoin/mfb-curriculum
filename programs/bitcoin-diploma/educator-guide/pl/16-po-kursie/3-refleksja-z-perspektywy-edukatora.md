# 16.3 Refleksja z perspektywy edukatora

Proszę dokonać tego przeglądu, póki kurs jest jeszcze świeżo w pamięci:


| Pytanie | Notatki i działania |
| --- | --- |
| Rozwijanie której kompetencji zajęło więcej lub mniej czasu, niż planowano? |  |
| Które błędne przekonanie wielokrotnie się powtarzało? |  |
| Które osoby uczestniczące w kursie były najrzadziej słyszane? |  |
| Który lokalny przykład pomógł osobom uczącym się lepiej wyjaśniać, porównywać lub wykonywać zadania? |  |
| Który przykład nabrał charakteru politycznego, promocyjnego lub zbyt osobistego? |  |
| Które ćwiczenie dostarczyło przydatnych dowodów uczenia się? |  |
| Które ćwiczenie doprowadziło do mylącego uproszczenia? |  |
| Czy wszystkie warunki przerwania ćwiczeń praktycznych okazały się skuteczne? |  |
| Czy jakieś narzędzie, łącze, opłata, zasada lub wpis przestały być aktualne? |  |
| Która decyzja dotycząca oceny wymaga weryfikacji pod kątem spójności oceniania? |  |
| Które dostosowanie w zakresie dostępności lub języka należy zachować? |  |
| Co się zmieni przed rozpoczęciem kursu przez kolejną grupę? |  |
