# 8.21 Podsumowanie i przejście do modułu 3

Proszę poprosić osoby uczące się o uzupełnienie tabeli:


| Problem systemu pieniądza fiducjarnego | Odpowiedź Bitcoina | Nowa odpowiedzialność lub kompromis |
| --- | --- | --- |
| Podaż może się zmieniać wskutek decyzji polityki pieniężnej |  |  |
| Płatności zależą od pośredników |  |  |
| Jeden podmiot prowadzący rejestr kontroluje zapisy |  |  |
| Dostęp zależy od instytucji |  |  |


Proszę wymagać jasnego wyjaśnienia, dlaczego [węzły](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) i [górnicy](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) pełnią różne role.

Następnie proszę skorzystać z **modułu 2** podręcznika dla osób uczących się i zawartego w nim pytania końcowego. Proszę zadbać, by odpowiedź pozostała prywatna lub była dobrowolna, zgodnie z powyższymi wskazówkami dotyczącymi krótkiej refleksji na zakończenie modułu.

Przejście do kolejnego modułu:

> Bitcoin może zmniejszyć zależność od podmiotu prowadzącego rachunek, ale bezpośrednia kontrola zależy od kluczy, weryfikacji, odzyskiwania dostępu i bezpiecznych decyzji. **Moduł 3** przekłada tę odpowiedzialność na praktykę.
