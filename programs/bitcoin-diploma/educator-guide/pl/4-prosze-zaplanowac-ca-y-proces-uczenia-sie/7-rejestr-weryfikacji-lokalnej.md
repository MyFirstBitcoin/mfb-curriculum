# 4.7 Rejestr weryfikacji lokalnej

Proszę wypełnić jeden wiersz dla każdej zmiennej informacji, usługi lub zasobu wykorzystywanego na zajęciach.


| Pozycja | Dlaczego to ważne | Źródło lub lokalny ekspert | Data weryfikacji | Co może się zmienić | Sformułowanie do użycia na zajęciach lub rozwiązanie zastępcze |
| --- | --- | --- | --- | --- | --- |
| Lokalna waluta i zasady płatności | Dyskusja w module 1 |  |  |  |  |
| Regulacje bankowe i ochrona depozytów | Część poświęcona rezerwie cząstkowej |  |  |  |  |
| Oficjalny wskaźnik inflacji i koszyk inflacyjny | Ćwiczenie dotyczące siły nabywczej |  |  |  |  |
| Status lub konstrukcja CBDC | Opcjonalne porównanie z lokalnymi rozwiązaniami |  |  |  |  |
| Portfel lub narzędzie płatnicze | Ćwiczenia praktyczne w module 3 lub 4 |  |  |  |  |
| Opłaty, spready i limity | Porównanie lokalnych ścieżek |  |  |  |  |
| Kontekst prawny, podatkowy, dotyczący prywatności lub obowiązków sprawozdawczych | Moduł lokalny |  |  |  |  |
| Sprzedawca, mapa, spotkanie lub zasób wsparcia | Poznawanie społeczności |  |  |  |  |


W odniesieniu do aktualnych przepisów proszę korzystać przede wszystkim z wiarygodnych źródeł pierwotnych. Jeśli dowody są niepełne, proszę to zaznaczyć. Proszę nie przedstawiać niepewnych informacji lokalnych jako uniwersalnych twierdzeń.
