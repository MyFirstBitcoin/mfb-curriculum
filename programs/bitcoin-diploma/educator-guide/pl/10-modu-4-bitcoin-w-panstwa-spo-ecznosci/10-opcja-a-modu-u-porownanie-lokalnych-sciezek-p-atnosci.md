# 10.10 Opcja A modułu: porównanie lokalnych ścieżek płatności

**Cel:** Porównanie pełnej ścieżki płatności realizowanej dotychczasową lokalną metodą, płatności w łańcuchu bloków oraz, w stosownych przypadkach, płatności przez Lightning.

**Przygotowanie:** Proszę przyjąć realistyczną, fikcyjną kwotę płatności i fikcyjnego odbiorcę. Proszę przygotować opatrzone datą informacje o lokalnych opłatach, wymianie walut, czasie realizacji, [przechowywaniu środków](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) i dostępie. Jeśli danych nie można zweryfikować, proszę wyraźnie oznaczyć je jako hipotetyczne.

**Zadanie dla osoby uczącej się:** Proszę uzupełnić:


| Pole | Dotychczasowa metoda | Bitcoin w łańcuchu bloków | Lightning, jeśli dotyczy |
| --- | --- | --- | --- |
| Wysłana kwota |  |  |  |
| Łączna otrzymana kwota |  |  |  |
| Czas realizacji i oczekiwania dotyczące rozrachunku |  |  |  |
| Opłaty i spread |  |  |  |
| Przechowywanie środków na każdym etapie |  |  |  |
| Tożsamość i prywatność |  |  |  |
| Cofnięcie płatności lub zwrot środków |  |  |  |
| Główny punkt ryzyka niepowodzenia |  |  |  |
| Lokalne wsparcie lub przepisy prawa |  |  |  |


**Wykonanie zadania:** Osoba ucząca się wybiera ścieżkę dla fikcyjnego przypadku, demonstruje odpowiednie żądanie płatności i jej weryfikację lub przedstawia kolejność tych czynności oraz wyjaśnia, dlaczego inna ścieżka mogłaby być lepsza po zmianie jednego z warunków.

**Omówienie:** Czy Bitcoin usprawnił całą ścieżkę, czy tylko jeden widoczny etap? Kto ponosi ryzyko związane ze zmiennością kursu, wymianą walut, [przechowywaniem środków](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) i niepowodzeniem płatności?

**Bezpieczeństwo:** Nie jest wymagany rzeczywisty przelew ani wskazanie konkretnego dostawcy usług. Proszę korzystać z wydrukowanych informacji o płatności.
