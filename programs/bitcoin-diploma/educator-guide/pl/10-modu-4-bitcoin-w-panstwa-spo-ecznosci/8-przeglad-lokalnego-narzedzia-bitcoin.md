# 10.8 Przegląd lokalnego narzędzia Bitcoin

Proszę nie prezentować narzędzia tylko dlatego, że jest popularne lokalnie. Proszę skorzystać z poniższego porównania:


| Obszar | Pytanie |
| --- | --- |
| Cel | Jaki problem rozwiązuje to narzędzie i czy jest potrzebne? |
| Przechowywanie środków | Kto kontroluje klucze i środki? |
| Źródło | Kto je publikuje i jak zweryfikowano autentyczność źródła? |
| Kod i utrzymanie | Czy kod jest otwarty, poddawany przeglądom, utrzymywany i bezpiecznie aktualizowany? |
| Odzyskiwanie dostępu | Co się stanie, gdy urządzenie zniknie, usługa przestanie być dostępna lub firma zakończy działalność? |
| Prywatność | Jakie dane dotyczące tożsamości, kontaktu, urządzenia, lokalizacji i transakcji są gromadzone? |
| Koszty | Jakie jawne opłaty, spready, opłaty abonamentowe oraz koszty zasilania konta i wypłat mają zastosowanie? |
| Kompatybilność | Jakie sieci, typy adresów, faktury, kopie zapasowe i urządzenia są obsługiwane? |
| Wsparcie | Czy osoby uczące się mogą uzyskać pomoc bez ujawniania poufnych informacji? |
| Prawo i dokumentacja | Jakie lokalne ograniczenia, przepisy dotyczące ochrony konsumentów oraz obowiązki podatkowe, księgowe lub sprawozdawcze mogą mieć znaczenie? |
| Alternatywa | Z czego mogą skorzystać osoby uczące się, jeśli narzędzie zawiedzie lub będzie niedostępne? |



> **Dark – Lokalne przykłady nie są globalnymi rekomendacjami**
>
> To narzędzie jest opatrzonym datą lokalnym przykładem służącym do nauki. Jego wykorzystanie na zajęciach nie stanowi globalnej rekomendacji ze strony My First Bitcoin ani obietnicy, że pozostanie ono odpowiednie.
