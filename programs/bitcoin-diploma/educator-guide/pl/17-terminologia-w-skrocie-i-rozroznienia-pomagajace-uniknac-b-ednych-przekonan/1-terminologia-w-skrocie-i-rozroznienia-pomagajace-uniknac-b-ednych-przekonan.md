# 17.1 Terminologia w skrócie i rozróżnienia pomagające uniknąć błędnych przekonań

Pełne definicje znajdą Państwo w Leksykonie. Proszę konsekwentnie stosować te rozróżnienia w wypowiedziach, na slajdach, w ćwiczeniach i podczas oceniania.


| Terminy | Rozróżnienie dla edukatorów |
| --- | --- |
| Pieniądz / waluta | Pieniądz to szersze pojęcie narzędzia lub aktywa służącego do wymiany, rozrachunku i przechowywania wartości w czasie; waluta to konkretna jednostka pieniężna lub system pieniężny. |
| Funkcja / właściwość | Funkcja określa, co robi pieniądz; właściwość to cecha wpływająca na to, jak dobrze spełnia on tę funkcję. |
| Rzadkość / wartość | Rzadkość ogranicza dostępność; wartość zależy również od zastosowania, popytu, preferencji, informacji i kontekstu. |
| Inflacja cen / wzrost pojedynczej ceny | Inflacja to utrzymujący się wzrost ogólnego poziomu cen; pojedyncza cena może zmieniać się z wielu powodów. |
| Depozyt bankowy / gotówka fizyczna | Depozyt bankowy jest wierzytelnością wobec banku; gotówka fizyczna jest inną formą pieniądza, emitowaną przez bank centralny lub państwo, zależnie od jurysdykcji. |
| Płynność / wypłacalność | Płynność dotyczy terminowego regulowania płatności; wypłacalność dotyczy tego, czy aktywa pokrywają zobowiązania. |
| CBDC / Bitcoin | CBDC to centralnie emitowany cyfrowy pieniądz fiducjarny; Bitcoin nie ma centralnego emitenta i opiera się na regułach, które można niezależnie weryfikować. |
| Bitcoin / bitcoin | Bitcoin oznacza sieć, protokół lub projekt; bitcoin oznacza aktywo lub jego jednostki. |
| Protokół Bitcoin / usługa związana z Bitcoinem | Protokół to wspólny system reguł; portfel, giełda, eksplorator lub firma płatnicza to odrębna usługa lub narzędzie. |
| Podpis cyfrowy / szyfrowanie | Podpis potwierdza autoryzację za pomocą klucza; szyfrowanie ukrywa czytelną treść. |
| Górnik / węzeł | Górnik proponuje bloki kandydujące poprzez dowód pracy; węzeł weryfikuje zgodność z regułami. |
| Propozycja programistów / zmiana reguł | Programiści proponują oprogramowanie; uczestnicy decydują, czy je przyjąć. |
| Czas bloku / harmonogram | Około dziesięciu minut to średnia długookresowa, a nie dokładnie wyznaczony termin. |
| Ograniczona podaż / gwarancja ceny | Przewidywalna maksymalna ilość jest właściwością podaży; nie gwarantuje popytu ani zysków. |
| Solidny pieniądz / fakt | Określenie „solidny pieniądz” jest oceną opartą na wskazanych kryteriach i kompromisach. |
| Portfel / przechowywanie bitcoinów | Portfel zarządza kluczami i transakcjami; bitcoin pozostaje zapisany we wspólnym rejestrze. |
| Adres / klucz prywatny | Adres służy do odbierania środków; klucz prywatny autoryzuje ich wydawanie. |
| Fraza odzyskiwania / hasło | Fraza odzyskiwania może odtworzyć klucze portfela i często umożliwia pełne odzyskanie dostępu; nie jest zwykłym hasłem, które można zresetować. |
| Powierniczy / samodzielnie zarządzany | Różnica polega na tym, kto kontroluje klucze. |
| Gorący / zimny | Różnica polega na ekspozycji kluczy na środowisko ogólnego przeznaczenia połączone z internetem. |
| On-chain / Lightning | Różnica dotyczy ścieżki płatności, a nie tego, kto sprawuje pieczę nad środkami. |
| Eksplorator / węzeł | Eksplorator to interfejs udostępniany przez podmiot trzeci; węzeł niezależnie weryfikuje zgodność z regułami. |
| Potwierdzenie / prawidłowa płatność | Potwierdzenie utrwala historię rozliczenia; nie koryguje odbiorcy ani nie potwierdza zasadności celu płatności. |
| Prywatność / tajność | Prywatność to kontrola nad informacjami; nie oznacza ona, że z daną działalnością nie wiążą się żadne publicznie dostępne dane ani obowiązki prawne. |
| KYC / no-KYC | W tych wariantach gromadzone są różne informacje o tożsamości, a każdy z nich wiąże się z innymi kompromisami dotyczącymi wsparcia, prywatności, ryzyka kontrahenta, oszustw i kwestii prawnych. Proszę konsekwentnie używać określenia no-KYC. |
| Lokalny przykład / rekomendacja | Zweryfikowany lokalny przykład wspiera naukę; nie stanowi uniwersalnej rekomendacji. |
