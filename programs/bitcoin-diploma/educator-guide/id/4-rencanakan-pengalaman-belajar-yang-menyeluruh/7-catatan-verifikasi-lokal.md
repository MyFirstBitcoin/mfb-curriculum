# 4.7 Catatan Verifikasi Lokal

Lengkapi satu baris untuk setiap fakta, layanan, atau sumber daya yang dapat berubah dan digunakan di kelas.


| Butir | Alasan pentingnya | Sumber atau pakar setempat | Tanggal pemeriksaan | Hal yang mungkin berubah | Rumusan untuk digunakan di kelas atau alternatif cadangan |
| --- | --- | --- | --- | --- | --- |
| Mata uang setempat dan aturan pembayaran | Diskusi Modul 1 |  |  |  |  |
| Regulasi perbankan dan perlindungan simpanan | Bagian tentang cadangan fraksional |  |  |  |  |
| Ukuran inflasi resmi dan keranjang barang dan jasa | Kegiatan tentang daya beli |  |  |  |  |
| Status atau rancangan CBDC | Perbandingan lokal opsional |  |  |  |  |
| Dompet atau alat pembayaran | Praktik Modul 3 atau 4 |  |  |  |  |
| Biaya, selisih harga beli dan jual, serta batasan | Perbandingan jalur akses setempat |  |  |  |  |
| Konteks hukum, pajak, privasi, atau pelaporan | Modul lokal |  |  |  |  |
| Pedagang, peta, pertemuan komunitas, atau sumber dukungan | Pengenalan komunitas |  |  |  |  |


Utamakan sumber primer yang berwenang untuk aturan yang berlaku saat ini. Jika bukti belum lengkap, nyatakan hal tersebut. Jangan mengubah informasi lokal yang belum pasti menjadi klaim yang berlaku universal.
