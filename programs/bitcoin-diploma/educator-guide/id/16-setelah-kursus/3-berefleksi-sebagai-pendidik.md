# 16.3 Berefleksi sebagai Pendidik

Lengkapi tinjauan ini selagi pelaksanaan kursus masih segar dalam ingatan Anda:


| Pertanyaan | Catatan dan tindakan |
| --- | --- |
| Kompetensi mana yang memerlukan waktu lebih lama atau lebih singkat daripada yang direncanakan? |  |
| Kesalahpahaman mana yang muncul berulang kali? |  |
| Suara peserta didik mana yang paling jarang terdengar? |  |
| Contoh lokal mana yang meningkatkan kemampuan peserta didik untuk menjelaskan, membandingkan, atau melakukan sesuatu? |  |
| Contoh mana yang menjadi bernuansa politik, bersifat promosi, atau terlalu pribadi? |  |
| Kegiatan mana yang menghasilkan bukti yang berguna? |  |
| Kegiatan mana yang menimbulkan penyederhanaan yang menyesatkan? |  |
| Apakah semua kondisi penghentian kegiatan praktik efektif? |  |
| Apakah ada alat, tautan, biaya, aturan, atau daftar yang sudah tidak mutakhir? |  |
| Keputusan penilaian mana yang perlu ditinjau bersama untuk memastikan konsistensi? |  |
| Penyesuaian aksesibilitas atau bahasa mana yang perlu dipertahankan? |  |
| Apa yang akan diubah sebelum angkatan berikutnya? |  |
