# 10.10 Opsi Modul A: Perbandingan Jalur Pembayaran Lokal

**Tujuan:** Membandingkan keseluruhan alur pembayaran lokal yang sudah digunakan, alur on-chain, dan alur Lightning jika sesuai.

**Persiapan:** Gunakan jumlah pembayaran dan penerima rekaan yang realistis. Siapkan informasi lokal bertanggal mengenai biaya, penukaran, waktu, [kustodi](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), dan akses. Jika data tidak dapat diverifikasi, tandai dengan jelas sebagai data hipotetis.

**Tugas peserta didik:** Lengkapi:


| Aspek | Metode yang sudah digunakan | Bitcoin on-chain | Lightning, jika relevan |
| --- | --- | --- | --- |
| Jumlah yang dikirim |  |  |  |
| Jumlah total yang diterima |  |  |  |
| Perkiraan waktu dan penyelesaian transaksi |  |  |  |
| Biaya dan selisih kurs |  |  |  |
| Kustodi pada setiap tahap |  |  |  |
| Identitas dan privasi |  |  |  |
| Pembatalan transaksi atau pengembalian dana |  |  |  |
| Titik kegagalan utama |  |  |  |
| Dukungan atau hukum setempat |  |  |  |


**Hasil kerja:** Peserta didik memilih alur untuk kasus rekaan tersebut, memperagakan atau mengurutkan langkah-langkah permintaan pembayaran dan verifikasi yang relevan, serta menjelaskan mengapa alur lain mungkin lebih baik jika kondisinya berubah.

**Refleksi:** Apakah Bitcoin memperbaiki keseluruhan alur, atau hanya satu langkah yang terlihat? Siapa yang menanggung risiko volatilitas, konversi, [kustodi](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), dan kegagalan?

**Keamanan:** Tidak diperlukan transfer sungguhan atau penyedia tertentu yang disebutkan namanya. Gunakan informasi pembayaran tercetak.
