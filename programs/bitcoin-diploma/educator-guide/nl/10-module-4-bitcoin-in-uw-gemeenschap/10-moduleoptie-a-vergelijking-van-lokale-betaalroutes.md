# 10.10 Moduleoptie A: vergelijking van lokale betaalroutes

**Doel:** Vergelijk de volledige route van een bestaande lokale betaling, een on-chain route en, waar van toepassing, een Lightning-route.

**Voorbereiding:** Gebruik een realistisch, verzonnen betalingsbedrag en een verzonnen ontvanger. Bereid gedateerde lokale informatie voor over kosten, wisselkoersen, tijdsduur, [bewaring](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) en toegang. Als gegevens niet kunnen worden geverifieerd, markeer ze dan duidelijk als hypothetisch.

**Opdracht voor de cursist:** Vul in:


| Veld | Bestaande methode | On-chain Bitcoin | Lightning, indien relevant |
| --- | --- | --- | --- |
| Verzonden bedrag |  |  |  |
| Totaal ontvangen bedrag |  |  |  |
| Verwachte tijdsduur en afwikkeling |  |  |  |
| Kosten en spread |  |  |  |
| Bewaring in elke fase |  |  |  |
| Identiteit en privacy |  |  |  |
| Terugboeking of terugbetaling |  |  |  |
| Belangrijkste faalpunt |  |  |  |
| Lokale ondersteuning of wetgeving |  |  |  |


**Product:** De cursist kiest een route voor het verzonnen geval, demonstreert of zet de relevante betalingsaanvraag en verificatie in de juiste volgorde, en legt uit waarom de andere route onder gewijzigde omstandigheden beter zou kunnen zijn.

**Nabespreking:** Heeft Bitcoin de volledige route verbeterd, of slechts één zichtbare stap? Wie draagt het risico van volatiliteit, omwisseling, [bewaring](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) en falen?

**Veiligheid:** Er is geen echte overboeking of genoemde aanbieder nodig. Gebruik geprinte betalingsinformatie.
