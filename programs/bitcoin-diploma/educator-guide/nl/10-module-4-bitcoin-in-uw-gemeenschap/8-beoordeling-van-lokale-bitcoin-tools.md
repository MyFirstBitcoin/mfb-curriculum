# 10.8 Beoordeling van lokale Bitcoin-tools

Demonstreer een tool niet alleen omdat deze lokaal populair is. Gebruik deze vergelijking:


| Onderdeel | Vraag |
| --- | --- |
| Doel | Welk probleem lost de tool op, en is deze nodig? |
| Bewaring | Wie beheert de sleutels en het geld? |
| Bron | Wie publiceert de tool, en hoe is de echte bron geverifieerd? |
| Code en onderhoud | Is de tool Open-source, gecontroleerd, onderhouden en wordt deze veilig bijgewerkt? |
| Herstel | Wat gebeurt er als het apparaat, de dienst of het bedrijf verdwijnt? |
| Privacy | Welke identiteits-, contact-, apparaat-, locatie- en transactiegegevens worden verzameld? |
| Kosten | Welke zichtbare vergoedingen, spreads, abonnementen, stortingskosten en opnamekosten zijn van toepassing? |
| Compatibiliteit | Welke netwerken, adrestypen, facturen, back-ups en apparaten worden ondersteund? |
| Ondersteuning | Kunnen deelnemers hulp krijgen zonder geheimen te delen? |
| Wetgeving en administratie | Welke lokale beperkingen, consumentenregels, belasting-, boekhoud- of rapportageverplichtingen kunnen van belang zijn? |
| Alternatief | Wat kunnen deelnemers gebruiken als de tool faalt of niet beschikbaar is? |



<!-- card: dark -->
> **Lokale voorbeelden zijn geen wereldwijde aanbevelingen**
>
> Deze tool is een gedateerd lokaal voorbeeld om van te leren. Het gebruik ervan in de les is geen wereldwijde aanbeveling van My First Bitcoin en ook geen belofte dat de tool geschikt zal blijven.
