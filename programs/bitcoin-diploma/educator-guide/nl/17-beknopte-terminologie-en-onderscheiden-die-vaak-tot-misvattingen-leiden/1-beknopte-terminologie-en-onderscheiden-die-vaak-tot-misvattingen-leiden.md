# 17.1 Beknopte terminologie en onderscheiden die vaak tot misvattingen leiden

Gebruik het Lexicon voor volledige definities. Houd deze onderscheidingen consistent in uw uitleg, dia's, activiteiten en toetsing.


| Begrippen | Onderscheid voor de docent |
| --- | --- |
| Geld / valuta | Geld is het bredere instrument of bezit dat wordt gebruikt voor ruil, als rekeneenheid en voor waarde over tijd; een valuta is een specifieke monetaire eenheid of een specifiek monetair systeem. |
| Functie / eigenschap | Een functie is wat geld doet; een eigenschap is een kwaliteit die bepaalt hoe goed het dat doet. |
| Schaarsheid / waarde | Schaarsheid beperkt de beschikbaarheid; waarde hangt ook af van gebruik, vraag, voorkeur, informatie en context. |
| Prijsinflatie / één prijsstijging | Inflatie is een aanhoudende stijging van het algemene prijsniveau; één prijs kan om vele redenen veranderen. |
| Banktegoed / fysiek contant geld | Een banktegoed is een vordering die de bank verschuldigd is; fysiek contant geld is een andere vorm van door de centrale bank of de staat uitgegeven geld, afhankelijk van het rechtsgebied. |
| Liquiditeit / solvabiliteit | Liquiditeit gaat over tijdige betaling; solvabiliteit gaat over de vraag of de bezittingen de verplichtingen dekken. |
| CBDC / Bitcoin | Een CBDC is centraal uitgegeven digitaal fiatgeld; Bitcoin heeft geen centrale uitgever en gebruikt onafhankelijk verifieerbare regels. |
| Bitcoin / bitcoin | Bitcoin verwijst naar het netwerk, het protocol of het project; bitcoin verwijst naar het activum of de eenheden. |
| Bitcoin-protocol / Bitcoin-dienst | Het protocol is het gedeelde regelsysteem; een Wallet, exchange, explorer of betaalbedrijf is een afzonderlijke dienst of tool. |
| Digitale handtekening / versleuteling | Een handtekening bewijst autorisatie met een sleutel; versleuteling verbergt leesbare inhoud. |
| Miner / Node | Een miner stelt kandidaat-blocks voor via Proof-of-Work; een Node verifieert de regels. |
| Voorstel van ontwikkelaars / regelwijziging | Ontwikkelaars stellen software voor; deelnemers kiezen zelf of ze die overnemen. |
| Blocktijd / dienstregeling | Ongeveer tien minuten is een gemiddelde op lange termijn, geen exacte afspraak. |
| Eindig aanbod / prijsgarantie | Een voorspelbaar maximum is een eigenschap van het aanbod; het garandeert geen vraag of rendement. |
| Gezond geld / feit | Gezond geld is een oordeel dat wordt gevormd op basis van expliciet benoemde criteria en afwegingen. |
| Wallet / opslag van bitcoin | Een Wallet beheert sleutels en transacties; bitcoin blijft geregistreerd in het gedeelde Grootboek. |
| Adres / Privé sleutel | Een adres ontvangt; een Privé sleutel autoriseert uitgaven. |
| Seed phrase / wachtwoord | Een seed phrase kan de sleutels van een Wallet opnieuw aanmaken en geeft vaak volledige hersteltoegang; het is geen gewoon wachtwoord dat u opnieuw kunt instellen. |
| Bewaring door derden / zelfbewaring | Het onderscheid is wie de sleutels beheert. |
| Hot / cold | Het onderscheid is de blootstelling van sleutels aan een online omgeving voor algemeen gebruik. |
| On-chain / Lightning | Het onderscheid is de betaalroute, niet de bewaring. |
| Explorer / Node | Een explorer is een interface van een derde partij; een Node verifieert de regels onafhankelijk. |
| Bevestiging / correcte betaling | Een bevestiging versterkt de afwikkelingsgeschiedenis; ze corrigeert de ontvanger niet en valideert het doel niet. |
| Privacy / geheimhouding | Privacy is controle over informatie; het betekent niet dat een activiteit geen openbare gegevens of wettelijke verplichtingen heeft. |
| KYC / no-KYC | Deze routes verzamelen verschillende identiteitsgegevens en brengen verschillende afwegingen met zich mee op het gebied van ondersteuning, privacy, tegenpartij, fraude en wetgeving. Gebruik overal de term no-KYC. |
| Lokaal voorbeeld / aanbeveling | Een gecontroleerd lokaal voorbeeld ondersteunt het leren; het is geen algemene aanbeveling. |
