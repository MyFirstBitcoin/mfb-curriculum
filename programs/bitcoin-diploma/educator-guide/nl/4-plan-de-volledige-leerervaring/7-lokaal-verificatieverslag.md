# 4.7 Lokaal verificatieverslag

Vul één rij in voor elk veranderlijk feit, elke dienst of elke bron die in de les wordt gebruikt.


| Onderdeel | Waarom het belangrijk is | Bron of lokale deskundige | Datum gecontroleerd | Wat kan veranderen | Formulering in de les of alternatief |
| --- | --- | --- | --- | --- | --- |
| Lokale munteenheid en betalingsregels | Discussie in module 1 |  |  |  |  |
| Bankregelgeving en depositogarantie | Onderdeel over fractioneel bankieren |  |  |  |  |
| Officiële inflatiemaatstaf en goederenmand | Activiteit over koopkracht |  |  |  |  |
| Status of ontwerp van de CBDC | Optionele lokale vergelijking |  |  |  |  |
| Wallet of betaalmiddel | Oefening in module 3 of 4 |  |  |  |  |
| Kosten, spreads en limieten | Vergelijking van lokale routes |  |  |  |  |
| Juridische, fiscale, privacy- of rapportagecontext | Lokale module |  |  |  |  |
| Handelaar, kaart, meetup of ondersteuningsbron | Gemeenschap ontdekken |  |  |  |  |


Geef voor actuele regels de voorkeur aan gezaghebbende primaire bronnen. Is het bewijs onvolledig, vermeld dat dan. Maak van onzekere lokale informatie geen universele bewering.
