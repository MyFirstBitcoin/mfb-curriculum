# 7.1 Objectif du module

**Module 1** donne aux apprenants le vocabulaire et les critères nécessaires pour examiner la monnaie. Il ne doit pas devenir un long réquisitoire contre tous les systèmes de monnaie fiduciaire. Son rôle est d’aider les apprenants à expliquer pourquoi la monnaie existe, comment fonctionnent les différents systèmes, quels compromis ils impliquent et quels problèmes Bitcoin tente ensuite de résoudre.

Question directrice :

> Comment la monnaie peut-elle dysfonctionner ?

Engagement de l’apprenant :

> Je peux expliquer les problèmes de la monnaie auxquels Bitcoin répond et appliquer ces notions.

**Si vous enseignez le module 1 pour la première fois :** Commencez par les questions d’ouverture et un exemple de paiement local familier. Ne commencez pas par un long cours d’histoire. Laissez les apprenants décrire ce qu’ils savent déjà, puis introduisez uniquement les termes nécessaires à l’activité suivante. Revenez aux notes sur la monnaie fiduciaire et le système bancaire locaux lorsque le groupe aborde ces sections.
