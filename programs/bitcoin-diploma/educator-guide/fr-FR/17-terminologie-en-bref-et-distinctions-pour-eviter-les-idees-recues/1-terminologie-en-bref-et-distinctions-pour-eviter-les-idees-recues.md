# 17.1 Terminologie en bref et distinctions pour éviter les idées reçues

Consultez le lexique pour les définitions complètes. Appliquez ces distinctions de manière cohérente à l’oral, dans les diapositives, les activités et les évaluations.


| Termes | Distinction pour les enseignants |
| --- | --- |
| Monnaie / devise | La monnaie désigne, au sens large, l’outil ou l’actif utilisé pour les échanges, comme unité de compte et pour conserver de la valeur dans le temps ; une devise est une unité ou un système monétaire particulier. |
| Fonction / propriété | Une fonction correspond à ce que fait la monnaie ; une propriété est une qualité qui influe sur sa capacité à remplir cette fonction. |
| Rareté / valeur | La rareté limite la disponibilité ; la valeur dépend aussi de l’usage, de la demande, des préférences, de l’information et du contexte. |
| Inflation des prix / hausse d’un seul prix | L’inflation est une hausse durable du niveau général des prix ; un prix particulier peut varier pour de nombreuses raisons. |
| Dépôt bancaire / espèces | Un dépôt bancaire est une créance sur la banque ; les espèces sont une autre forme de monnaie, émise par la banque centrale ou par l’État selon la juridiction. |
| Liquidité / solvabilité | La liquidité concerne la capacité à payer à temps ; la solvabilité concerne la capacité des actifs à couvrir les obligations. |
| MNBC / Bitcoin | Une MNBC est une monnaie fiduciaire numérique émise de manière centralisée ; Bitcoin n’a pas d’émetteur central et repose sur des règles vérifiables de manière indépendante. |
| Bitcoin / bitcoin | Bitcoin désigne le réseau, le protocole ou le projet ; bitcoin désigne l’actif ou les unités. |
| Protocole Bitcoin / service Bitcoin | Le protocole est le système de règles partagé ; un portefeuille, une plateforme d’échange, un explorateur ou une entreprise de paiement constitue un service ou un outil distinct. |
| Signature numérique / chiffrement | Une signature prouve l’autorisation donnée au moyen d’une clé ; le chiffrement masque le contenu lisible. |
| Mineur / nœud | Un mineur propose des blocs candidats au moyen de la preuve de travail ; un nœud vérifie le respect des règles. |
| Proposition des développeurs / modification des règles | Les développeurs proposent des logiciels ; les participants choisissent de les adopter ou non. |
| Intervalle entre les blocs / horaire fixé | Environ dix minutes est une moyenne à long terme, pas un rendez-vous à heure fixe. |
| Offre limitée / garantie de prix | Un maximum prévisible est une propriété de l’offre ; il ne garantit ni la demande ni les rendements. |
| Monnaie saine / fait | Qualifier une monnaie de saine relève d’un jugement fondé sur des critères et des compromis explicités. |
| Portefeuille / stockage de bitcoin | Un portefeuille gère les clés et les transactions ; bitcoin reste inscrit dans le registre partagé. |
| Adresse / clé privée | Une adresse sert à recevoir ; une clé privée autorise les dépenses. |
| Phrase de récupération / mot de passe | Une phrase de récupération peut recréer les clés du portefeuille et permet souvent de retrouver un accès complet ; ce n’est pas un mot de passe ordinaire que l’on peut réinitialiser. |
| Garde par un tiers / garde autonome | La distinction porte sur qui contrôle les clés. |
| À chaud / à froid | La distinction porte sur l’exposition des clés à un environnement informatique généraliste connecté à Internet. |
| Sur la blockchain / Lightning | La distinction porte sur le chemin emprunté par le paiement, pas sur la garde. |
| Explorateur / nœud | Un explorateur est une interface fournie par un tiers ; un nœud vérifie le respect des règles de manière indépendante. |
| Confirmation / paiement correct | Une confirmation renforce l’historique de règlement ; elle ne corrige pas le destinataire et ne valide pas l’objet du paiement. |
| Vie privée / secret | La confidentialité consiste à maîtriser les informations ; elle ne signifie pas qu’une activité ne comporte aucune donnée publique ni aucune obligation légale. |
| KYC / no-KYC | Ces approches recueillent des informations d’identité différentes et impliquent des compromis différents en matière d’assistance, de confidentialité, de contrepartie, de fraude et d’obligations légales. Utilisez le terme no-KYC dans l’ensemble du document. |
| Exemple local / recommandation | Un exemple local vérifié facilite l’apprentissage ; il ne constitue pas une recommandation universelle. |
