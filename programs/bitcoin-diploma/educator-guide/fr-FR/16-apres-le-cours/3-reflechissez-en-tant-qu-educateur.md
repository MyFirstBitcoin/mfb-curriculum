# 16.3 Réfléchissez en tant qu’éducateur

Faites ce bilan tant que le cours est encore frais dans votre mémoire :


| Question | Notes et action |
| --- | --- |
| Quelle compétence a nécessité plus ou moins de temps que prévu ? |  |
| Quelle idée fausse est revenue à plusieurs reprises ? |  |
| Quels apprenants ont eu le moins l’occasion de faire entendre leur voix ? |  |
| Quel exemple local a amélioré la capacité des apprenants à expliquer, à comparer ou à agir ? |  |
| Quel exemple a pris une tournure politique, promotionnelle ou trop personnelle ? |  |
| Quelle activité a fourni des éléments probants utiles ? |  |
| Quelle activité a conduit à une simplification trompeuse ? |  |
| Toutes les conditions d’arrêt des activités pratiques ont-elles été efficaces ? |  |
| Un outil, un lien, des frais, une règle ou une liste sont-ils devenus obsolètes ? |  |
| Quel jugement d’évaluation doit faire l’objet d’une harmonisation ? |  |
| Quelle adaptation en matière d’accessibilité ou de langue devrait être conservée ? |  |
| Qu’est-ce qui changera avant la prochaine cohorte ? |  |
