# 13.5 Choisissez les activités de manière réfléchie

Ne conservez pas une activité uniquement parce qu’elle vous est familière. Conservez-la lorsqu’elle améliore l’alignement sur les compétences, les éléments attestant les acquis des apprenants, la sécurité, l’accessibilité, la gestion du temps ou la pertinence dans le contexte local.
