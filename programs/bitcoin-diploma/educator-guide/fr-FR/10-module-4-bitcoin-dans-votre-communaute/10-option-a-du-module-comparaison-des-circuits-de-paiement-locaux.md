# 10.10 Option A du module : comparaison des circuits de paiement locaux

**Objectif :** Comparez le parcours complet d’un paiement local effectué avec une méthode existante, d’un paiement sur la blockchain et d’un paiement via Lightning, lorsque cela est pertinent.

**Préparation :** Utilisez un montant de paiement et un destinataire fictifs mais réalistes. Préparez des informations locales datées sur les frais, le change, les délais, la [conservation des fonds](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), et les conditions d’accès. Si les données ne peuvent pas être vérifiées, indiquez clairement qu’elles sont hypothétiques.

**Tâche de l’apprenant :** Complétez :


| Rubrique | Méthode existante | Bitcoin sur la blockchain | Lightning, si pertinent |
| --- | --- | --- | --- |
| Montant envoyé |  |  |  |
| Montant total reçu |  |  |  |
| Délai et attentes concernant le règlement |  |  |  |
| Frais et écart de change |  |  |  |
| Conservation des fonds à chaque étape |  |  |  |
| Identité et confidentialité |  |  |  |
| Annulation ou remboursement |  |  |  |
| Principal point de défaillance |  |  |  |
| Assistance locale ou législation |  |  |  |


**Production :** L’apprenant choisit un parcours pour le cas fictif, montre ou décrit dans l’ordre les étapes de la demande de paiement et de la vérification correspondantes, et explique pourquoi l’autre parcours pourrait être préférable si une condition changeait.

**Bilan :** Bitcoin a-t-il amélioré le parcours complet, ou seulement une étape visible ? Qui supporte les risques liés à la volatilité, à la conversion, à la [conservation des fonds](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), et aux défaillances ?

**Sécurité :** Aucun transfert réel ni prestataire désigné n’est requis. Utilisez des informations de paiement imprimées.
