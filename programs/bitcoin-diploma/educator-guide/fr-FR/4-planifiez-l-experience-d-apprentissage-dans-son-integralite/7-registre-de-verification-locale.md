# 4.7 Registre de vérification locale

Remplissez une ligne pour chaque fait susceptible d’évoluer, service ou ressource utilisé en classe.


| Élément | Pourquoi c’est important | Source ou expert local | Date de vérification | Ce qui peut changer | Formulation en classe ou solution de repli |
| --- | --- | --- | --- | --- | --- |
| Monnaie locale et règles de paiement | Discussion du module 1 |  |  |  |  |
| Réglementation bancaire et protection des dépôts | Section sur les réserves fractionnaires |  |  |  |  |
| Mesure officielle de l’inflation et panier de référence | Activité sur le pouvoir d’achat |  |  |  |  |
| Statut ou conception de la MNBC | Comparaison locale facultative |  |  |  |  |
| Portefeuille ou outil de paiement | Exercice pratique du module 3 ou 4 |  |  |  |  |
| Frais, écarts de prix et limites | Comparaison des parcours locaux |  |  |  |  |
| Contexte juridique, fiscal, de confidentialité ou d’obligations déclaratives | Module local |  |  |  |  |
| Commerçant, carte, rencontre ou ressource d’assistance | Découverte de la communauté |  |  |  |  |


Privilégiez les sources primaires faisant autorité pour les règles en vigueur. Si les éléments disponibles sont incomplets, dites-le. Ne transformez pas une information locale incertaine en affirmation universelle.
