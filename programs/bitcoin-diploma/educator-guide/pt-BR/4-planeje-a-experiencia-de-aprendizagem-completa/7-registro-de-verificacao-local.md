# 4.7 Registro de verificação local

Preencha uma linha para cada fato, serviço ou recurso sujeito a mudanças usado em sala de aula.


| Item | Por que é importante | Fonte ou especialista local | Data da verificação | O que pode mudar | Formulação em sala ou alternativa |
| --- | --- | --- | --- | --- | --- |
| Moeda local e regras de pagamento | Discussão do Módulo 1 |  |  |  |  |
| Regulação bancária e proteção de depósitos | Seção sobre reserva fracionária |  |  |  |  |
| Índice oficial de inflação e cesta de referência | Atividade sobre poder de compra |  |  |  |  |
| Situação ou desenho da CBDC | Comparação local opcional |  |  |  |  |
| Carteira ou ferramenta de pagamento | Prática dos Módulos 3 ou 4 |  |  |  |  |
| Taxas, spreads e limites | Comparação de opções locais |  |  |  |  |
| Contexto jurídico, tributário, de privacidade ou de declaração | Módulo local |  |  |  |  |
| Comerciante, mapa, encontro ou recurso de suporte | Descoberta da comunidade |  |  |  |  |


Dê preferência a fontes primárias oficiais para as regras vigentes. Se as evidências estiverem incompletas, deixe isso claro. Não transforme informações locais incertas em uma afirmação universal.
