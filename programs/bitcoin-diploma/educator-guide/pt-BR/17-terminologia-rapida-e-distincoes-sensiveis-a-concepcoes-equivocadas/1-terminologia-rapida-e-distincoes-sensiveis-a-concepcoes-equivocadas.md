# 17.1 Terminologia rápida e distinções sensíveis a concepções equivocadas

Use o Léxico para as definições completas. Mantenha estas distinções consistentes na fala, nos slides, nas atividades e na avaliação.


| Termos | Distinção para o educador |
| --- | --- |
| Dinheiro / moeda | Dinheiro é a ferramenta ou o ativo mais amplo usado para troca, unidade de conta e reserva de valor ao longo do tempo; moeda é uma unidade ou um sistema monetário específico. |
| Função / propriedade | Uma função é o que o dinheiro faz; uma propriedade é uma qualidade que afeta o quão bem ele faz isso. |
| Escassez / valor | A escassez limita a disponibilidade; o valor também depende de uso, demanda, preferência, informação e contexto. |
| Inflação de preços / aumento de um preço | Inflação é um aumento sustentado do nível geral de preços; um único preço pode mudar por muitos motivos. |
| Depósito bancário / dinheiro em espécie | Um depósito bancário é um direito de crédito que o banco deve ao depositante; o dinheiro em espécie é uma forma diferente de dinheiro emitido pelo banco central ou pelo Estado, dependendo da jurisdição. |
| Liquidez / solvência | Liquidez diz respeito ao pagamento em tempo hábil; solvência diz respeito a se os ativos cobrem as obrigações. |
| CBDC / Bitcoin | Uma CBDC é moeda fiduciária digital emitida de forma centralizada; o Bitcoin não tem emissor central e usa regras verificáveis de forma independente. |
| Bitcoin / bitcoin | Bitcoin se refere à rede, ao protocolo ou ao projeto; bitcoin se refere ao ativo ou às unidades. |
| Protocolo Bitcoin / serviço de Bitcoin | O protocolo é o sistema de regras compartilhado; uma carteira, uma corretora, um explorador ou uma empresa de pagamentos é um serviço ou uma ferramenta à parte. |
| Assinatura digital / criptografia | Uma assinatura comprova a autorização da chave; a criptografia oculta conteúdo legível. |
| Minerador / nó | Um minerador propõe blocos candidatos por meio de Prova de Trabalho (PoW); um nó verifica as regras. |
| Proposta de desenvolvedor / mudança de regra | Os desenvolvedores propõem software; os participantes escolhem se vão adotá-lo. |
| Tempo de bloco / horário fixo | Cerca de dez minutos é uma média de longo prazo, não um horário marcado com exatidão. |
| Oferta finita / garantia de preço | Um máximo previsível é uma propriedade da oferta; não garante demanda nem retornos. |
| Dinheiro sólido / fato | Dinheiro sólido é um julgamento feito com base em critérios explícitos e trade-offs. |
| Carteira / armazenamento de bitcoin | Uma carteira gerencia chaves e transações; o bitcoin permanece registrado no livro-razão compartilhado. |
| Endereço / chave privada | Um endereço recebe; uma chave privada autoriza o gasto. |
| Frase-semente / senha | Uma frase-semente pode recriar as chaves da carteira e muitas vezes dá acesso total de recuperação; não é uma senha comum que pode ser redefinida. |
| Custodial / autocustódia | A distinção é quem controla as chaves. |
| Quente / fria | A distinção é a exposição das chaves a um ambiente on-line de uso geral. |
| On-chain / Lightning | A distinção é o caminho do pagamento, não a custódia. |
| Explorador / nó | Um explorador é uma interface de terceiros; um nó verifica as regras de forma independente. |
| Confirmação / pagamento correto | Uma confirmação fortalece o histórico de liquidação; ela não corrige o destinatário nem valida a finalidade. |
| Privacidade / sigilo | Privacidade é controle sobre as informações; isso não significa que uma atividade não tenha dados públicos nem obrigações legais. |
| KYC / sem KYC | Esses caminhos coletam diferentes informações de identidade e criam diferentes compensações em termos de suporte, privacidade, contraparte, fraude e aspectos legais. Use "sem KYC" em todo o material. |
| Exemplo local / recomendação | Um exemplo local verificado apoia a aprendizagem; não é um endosso universal. |
