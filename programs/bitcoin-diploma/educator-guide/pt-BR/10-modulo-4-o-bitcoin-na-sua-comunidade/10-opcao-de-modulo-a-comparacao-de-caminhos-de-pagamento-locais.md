# 10.10 Opção de módulo A: comparação de caminhos de pagamento locais

**Objetivo:** Comparar o percurso completo de um pagamento local já existente, de um caminho on-chain e, quando for o caso, de um caminho via Lightning.

**Preparação:** Use um valor de pagamento e um destinatário fictícios, porém realistas. Prepare informações locais datadas sobre tarifas, câmbio, prazos, [custódia](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) e acesso. Se os dados não puderem ser verificados, identifique-os claramente como hipotéticos.

**Tarefa do aluno:** Preencha:

| Valor enviado |  |  |  |

| Prazo e expectativa de liquidação |  |  |  |

| Custódia em cada etapa |  |  |  |
| Identidade e privacidade |  |  |  |
| Estorno ou reembolso |  |  |  |
| Principal ponto de falha |  |  |  |
| Suporte local ou legislação |  |  |  |


**Produção:** O aluno escolhe um caminho para o caso fictício, demonstra ou ordena em sequência a solicitação de pagamento e a verificação correspondentes, e explica por que o outro caminho poderia ser melhor caso alguma condição mudasse.

**Discussão final:** O Bitcoin melhorou o percurso completo ou apenas uma etapa visível? Quem assume os riscos de volatilidade, conversão, [custódia](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) e falha?

**Segurança:** Nenhuma transferência real nem provedor específico é necessário. Use informações de pagamento impressas.
