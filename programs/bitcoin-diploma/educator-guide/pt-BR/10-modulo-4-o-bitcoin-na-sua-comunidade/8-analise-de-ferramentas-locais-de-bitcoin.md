# 10.8 Análise de ferramentas locais de Bitcoin

Não demonstre uma ferramenta apenas porque ela é popular localmente. Use esta comparação:


| Área | Pergunta |
| --- | --- |
| Finalidade | Qual problema a ferramenta resolve, e ela é necessária? |
| Custódia | Quem controla as chaves e os fundos? |
| Origem | Quem a publica, e como a origem autêntica foi verificada? |
| Código e manutenção | Ela é de código aberto, revisada, mantida e atualizada com segurança? |
| Recuperação | O que acontece quando o dispositivo, o serviço ou a empresa deixa de existir? |
| Privacidade | Quais dados de identidade, contato, dispositivo, localização e transações são coletados? |
| Custo | Quais taxas visíveis, spreads, assinaturas, custos de depósito e custos de saque se aplicam? |
| Compatibilidade | Quais redes, tipos de endereço, faturas, backups e dispositivos funcionam? |
| Suporte | Os alunos conseguem obter ajuda sem compartilhar segredos? |
| Legislação e registros | Quais restrições locais, normas de defesa do consumidor ou obrigações fiscais, contábeis ou de declaração podem ser relevantes? |
| Alternativa | O que os alunos podem usar se a ferramenta falhar ou estiver indisponível? |



<!-- card: dark -->
> **Exemplos locais não são recomendações globais**
>
> Esta ferramenta é um exemplo local, válido para um determinado momento, usado para fins de aprendizado. Seu uso em aula não é uma recomendação global da My First Bitcoin nem uma promessa de que ela continuará adequada.
