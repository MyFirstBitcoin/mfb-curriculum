# 16.3 Reflita como educador

Faça esta revisão enquanto o curso ainda está fresco na memória:


| Pergunta | Observações e ações |
| --- | --- |
| Qual competência levou mais ou menos tempo do que o planejado? |  |
| Qual concepção equivocada apareceu repetidamente? |  |
| Quais vozes de alunos foram menos ouvidas? |  |
| Qual exemplo local melhorou o que os alunos conseguiam explicar, comparar ou fazer? |  |
| Qual exemplo se tornou político, promocional ou pessoal demais? |  |
| Qual atividade produziu evidências úteis? |  |
| Qual atividade criou uma simplificação enganosa? |  |
| Todas as condições de interrupção das atividades práticas foram eficazes? |  |
| Alguma ferramenta, link, taxa, regra ou listagem ficou desatualizada? |  |
| Qual julgamento de avaliação precisa de moderação? |  |
| Qual adaptação de acessibilidade ou de idioma deve ser mantida? |  |
| O que mudará antes da próxima turma? |  |
