# 16.3 教育者としての振り返り

講座の記憶が新しいうちに、この振り返りを行ってください：


| 質問 | メモと対応 |
| --- | --- |
| 予定より時間がかかった、または短く済んだコンピテンシーはどれですか？ |  |
| 繰り返し見られた誤解は何ですか？ |  |
| 発言が最も少なかった学習者は誰ですか？ |  |
| 学習者が説明、比較、実践できることを向上させた地域の事例はどれですか？ |  |
| 政治的、宣伝的、または個人的になりすぎた事例はどれですか？ |  |
| 有用な根拠を生み出した活動はどれですか？ |  |
| 誤解を招く単純化を生んだ活動はどれですか？ |  |
| 実習の中止条件はすべて有効に機能しましたか？ |  |
| 古くなったツール、リンク、手数料、規則、掲載情報はありましたか？ |  |
| 調整が必要な評価判断はどれですか？ |  |
| 今後も継続すべきアクセシビリティや言語面の調整はどれですか？ |  |
| 次の受講グループまでに何を変更しますか？ |  |
