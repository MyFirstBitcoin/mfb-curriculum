# 4.3 繰り返し使える2時間のモジュールのリズム

これは厳密な台本ではなく、計画を立てる際のパターンとしてご活用ください。


| 時間 | 目的 | 教育者の動き |
| --- | --- | --- |
| 0〜10分 | 歓迎と振り返り | 前回の学習内容から短い質問をし、理解があいまいな点を明らかにします。 |
| 10〜30分 | 第1の概念 | 簡潔に説明し、視覚資料や身近な例を用いて、学習者から観察可能な反応を引き出します。 |
| 30〜55分 | 主要な交流活動 | 比較、ゲーム、シナリオ、役割マップ、デモンストレーション、またはガイド付き演習を進行します。 |
| 55〜65分 | 振り返り | 体験をコンピテンシーと結びつけ、活動では示しきれなかった点を補正します。 |
| 65〜80分 | 第2の概念またはデモンストレーション | 次に重要な考え方を加え、必要に応じて一連のプロセス全体を実演します。 |
| 80〜105分 | 演習と成果物の作成 | 学習者は、支援を徐々に減らしながら、応用、判断、説明、または実践を行います。 |
| 105〜115分 | 理解度の確認または実技のエビデンス | 形成的なフィードバックを集め、コンピテンシーに沿った教育者の応答を促し、または実技スキルを観察します。 |
| 115〜120分 | まとめと次への橋渡し | 重要なポイント、未解決の疑問、次のモジュールとのつながりを明示します。 |


実技の観察には、このパターンで想定されている以上の時間が必要になることがよくあります。**モジュール3**と**モジュール4**については、コースのスケジュール内でステーション、別の教育者、または少人数グループを計画してください。各学習者の判断や安全に関わる行動を確認できない場合は、複数の学習者を同時に評価しないでください。

このパターンは、教育者主導の評価にどれだけの時間が必要かを定めるものではありません。個別のエビデンス、フィードバック、再評価、記録のために、スケジュール内に十分な時間を確保してください。任意の形成的な復習は、評価スケジュールを変更することなく学習を支援できます。
