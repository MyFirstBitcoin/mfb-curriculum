# 4.7 現地検証記録

授業で使用する、変化し得る事実、サービス、リソースごとに1行ずつ記入してください。


| 項目 | 重要な理由 | 情報源または地域の専門家 | 確認日 | 変わる可能性のある点 | 授業での説明文または代替案 |

| 公式のインフレ指標と品目バスケット | 購買力のアクティビティ |  |  |  |  |
| CBDCの状況または設計 | 任意の地域比較 |  |  |  |  |
| ウォレットまたは決済ツール | モジュール3または4の実習 |  |  |  |  |
| 手数料、スプレッド、上限 | 地域の利用経路の比較 |  |  |  |  |

現行の規則については、信頼できる一次情報源を優先してください。根拠が不十分な場合は、その旨を明記してください。不確かな地域の情報を普遍的な主張として扱わないでください。
