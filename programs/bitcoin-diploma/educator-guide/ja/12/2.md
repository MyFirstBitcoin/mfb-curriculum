# 12.2 変わらない概念と変化する事実を区別する

| 安定したカリキュラムの概念 | 変化する地域の事実 |
| --- | --- |
| 銀行預金は銀行に対する請求権である | 地域の預金保護の上限額と対象条件 |
| インフレ指標は選定されたバスケットと手法を用いる | 現在の地域のインフレ率、バスケットのウェイト、公表方法 |
| CBDCは中央銀行が発行する法定通貨である | 地域の中央銀行がCBDCを研究中か、試験運用中か、発行済みか |
| カストディとは鍵の管理を意味する | 現行バージョンのウォレットのカストディモデル |
| 手数料と流動性は支払い経路に影響する | 現在の手数料の見積もり、サービスのスプレッド、ライトニングの流動性 |
| KYCありとKYCなしでは異なるトレードオフが生じる | 現在の本人確認規則と法的要件 |
| 地図の掲載情報は古くなることがある | 地域の店舗が現在ビットコインを受け付けているかどうか |


変化する事実には日付を記し、何が変わる可能性があるかを学習者に伝えてください。地域の例を準備する際は、[Bitcoin Diploma AIアシスタント](https://ai.myfirstbitcoin.org)に、どの主張に確認が必要か、どのような根拠を探すべきかを提案してもらうことができます。元の情報源はご自身で開き、それぞれの主張を裏付けていることを確認したうえで、情報源と日付を記録してください。AIの回答は、その事実が最新であることの根拠にはなりません。
