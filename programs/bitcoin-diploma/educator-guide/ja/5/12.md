# 5.12 メディアとツールの代替手段

「Student Guide」には、Bitcoin Diplomaに必要な定義、比較、安全上のルール、復習問題が収録されています。補足的な学習リンクや、それらにアクセスするためのQRコードは任意です。これらは最新情報、まとめ資料、元ファイル、またはつながるための手段を提供する場合があります。学習者はこれらの補足資料を使わなくてもコースを修了できます。

承認された同等の方法で能力を確保できる場合、Bitcoin Diplomaの必須の説明、教育者による形成的確認、練習アクティビティ、または直接観察による実技の証拠のいずれも、動画、ライブのウェブサイト、特定のサービス、または学習者所有の端末に依存すべきではありません。

デモンストレーションにインターネット接続が必要な場合は、可能な限りオフラインの代替手段を用意してください。たとえば、印刷したウォレット画面、取引シナリオ、カードを使った演習、段階的なディスカッションなどです。接続に失敗しても、授業や準備が止まることがあってはなりません。


| ライブまたはオンラインでの体験 | オフラインまたはローテクの代替手段 |
| --- | --- |
| ウォレットの操作 | 順番に並べた印刷済みのウォレット画面、または予測のための一時停止を入れた録画の投影 |
| 送金と受け取り | アドレスまたはインボイスのカード、金額カード、紙による取引の流れ |
| QRコードの読み取り | 印刷した支払い情報のサンプルと目視による比較 |
| ブロックエクスプローラー | 事前に用意した公開取引の日付入りスクリーンショット |
| リアルタイムの価格、手数料、インフレのデータ | 出典と限界を明記した、事前に用意した日付入りのスナップショット |
| 加盟店またはコミュニティのマップ | 印刷した地域の地図と検証済みの掲載例 |
| ライトニング決済 | インボイスカードと経路を経由する支払いのシナリオ |
| 動画 | ナレーション付きの図、ストーリーボード、または教育者による説明 |
| 実際の取引 | シミュレーション、テスト環境、残高のない練習用ウォレット、または教育者によるデモンストレーション |


オフラインでの授業と評価も有効です。接続環境が限られている場合は、オフラインの理解度チェック、印刷したアクティビティ、ロールプレイ、シミュレーションを活用してください。任意の形成的な復習は認定の一部ではありません。

「Student Guide」は普遍的な概念を説明しています。手数料、法律、税金、利用可能なサービス、ウォレットの機能、加盟店の掲載情報を提示する前に、現在の地域の詳細を確認し、使用する情報には日付を記載してください。
