# 目的

本エデュケーターガイドは、実践的な指導の手引きです。本ガイドは、次のことに役立つよう作られています。

* 受講者グループと学習環境を準備すること
* 各モジュールの目的と範囲を説明できるようになること
* 対面の時間を、対話、実践、フィードバック、地域への応用に活用すること
* 難しい概念を初心者にもわかる言葉で説明すること
* 同意を求めることなく誤解を正すこと
* 適切なアクティビティを選び、進行すること
* ビットコイン・ディプロマで求められるコンピテンシーを変えることなく、事例を地域に合わせること
* ウォレット、トランザクション、復元、検証の安全な実習を準備すること
* 意義のある「地域の中のビットコイン」体験を選ぶこと
* コンピテンシーに沿ったエビデンスを学習の支援に活用すること
* 実践的なコンピテンシーを一貫して評価し、実践的な再評価の機会を設けること
* 学習者の[プライバシー](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)、自律性、安全を守ること、そして
* 学習者を適切な次のステップにつなぐこと。

本ガイドおよびビットコイン・ディプロマは教育用の資料です。金融、投資、法律、税務、会計、コンプライアンス、トレードに関する助言を提供するものではなく、個人の意思決定に用いるべきものではありません。

本ガイドは、エデュケーターの判断に代わるものではありません。その判断に、共通の目的、構成、安全基準を与えるものです。
