# 一目でわかる評価

26.10 Bitcoin Diplomaでは、教育者主導の評価モデルを採用しています。理論面と実践面の両方のコンピテンシーが必要です。任意の学習リソース、復習、振り返りは、評価の根拠としては扱いません。

評価は、よく設計されたアクティビティ、対話、実演、練習を通じて自然に行うことができます。教育者の役割は、各学習者が説明する、比較する、安全な判断を下す、または実践的な課題を完了することができるかどうかを見取ることです。すべてのコンピテンシーについて個別の試験を行う必要はありません。

以下の詳細な評価サポートでは、例、問いかけ、安全に関するガイダンス、アクセシビリティのアイデア、任意の記録方法を紹介しています。役立つ枠組みとしてご活用いただき、コンピテンシーと安全の基準を維持しながら、学習者、言語、環境、利用可能なツールに合わせて調整してください。

`C1`～`C7`は、記録対象となる評価コンピテンシーです。小数点付きの`C`番号は、コンピテンシーの基準および観察可能な着眼点であり、個別の結果行ではありません。`F1`と`F2`は、形成的コンピテンシーのみです。

初めて教える方は、このモデルを2つの修了ゲートとして覚えておくとよいでしょう。


| 学習者が示すもの | 主な根拠 | 修了ゲート |
| --- | --- | --- |
| 理論コンピテンシー（C1～C5） | アクティビティ、対話、教育者主導のやり取り | 5つの理論コンピテンシーすべてが基準を満たすこと |
| 実践コンピテンシー（C6～C7） | C6の両方の実技とC7のローカル課題に対する教育者による直接観察 | 2つの実践コンピテンシーの両方が基準を満たすこと |


これらは数値による成績ではありません。修了証を発行する前に、両方の構成要素が完了し、必須のすべてのコンピテンシーがそれぞれの基準を満たしている必要があります。
