# 7.18 よくある誤解とその答え方

| よくある誤解 | 初心者にもわかりやすい訂正 | フォローアップの質問 |
| --- | --- | --- |
| お金と富は同じものです。 | お金は、有用な財・サービス・時間・資源に対する請求権を測定し、交換するのに役立ちます。しかし、お金はあらゆる富と同一ではありません。 | 住まいとして役立つ家は、使い勝手のよいお金でなくても富になり得るでしょうか？ |
| 価値の保存手段は決して価値を失いません。 | 価値の保存は機能であって、保証ではありません。どの選択肢にも、対象となる期間とリスクがあります。 | 現金、金、またはその他の資産について、この機能を弱める要因として何が考えられますか？ |
| 物々交換はまったく機能しません。 | 物々交換は機能することもありますが、規模が大きくなると、欲しいもの・数量・タイミング・保管・価格の折り合いをつけることが難しくなります。 | 地域内で繰り返し取引する関係では、何が物々交換を容易にしますか？ |
| 希少であれば価値があります。 | 価値は、有用性、需要、情報、状況にも左右されます。 | 希少でも、人々が欲しがらないかもしれないものを挙げてください。 |
| 法定通貨は単なる偽物のお金です。 | 法定通貨は、政府の権限、制度、法律、受容性、ネットワーク効果によって支えられた現実の通貨制度です。そのルールやトレードオフは評価することができます。 | 法定通貨の記録や制度が機能しなくなった場合、地域のどのような支払いができなくなるでしょうか？ |
| 銀行は既存の顧客の現金だけを貸し出しています。 | 現代の銀行の貸出では、自己資本、流動性、規制、資金調達、リスク、需要といった制約の範囲内で、通常、貸出額に見合う預金が新たに生み出されます。 | 融資の後、銀行の資産と負債には何が計上されますか？ |
| 部分準備制度とは、銀行がどこでも同じ一定の割合を準備として保有することを意味します。 | 準備、流動性、自己資本に関する仕組みは国によって異なり、変わることもあります。 | 地域のどのルールを確認する必要がありますか？ |
| 値上がりはすべて、お金の増刷によって引き起こされるインフレです。 | 一般的なインフレ率は平均値であり、価格の変動には相互に作用する複数の原因が考えられます。 | この品目の価格を変える原因として、ほかに何が考えられますか？ |
| 公式の物価指数のバスケットは、すべての人の実感と一致するはずです。 | この指標は平均値であり、世帯ごとに支出の傾向は異なります。 | あなたが設定した架空の世帯では、どの品目区分がより重要ですか？ |
| どのCBDCも同じように監視や管理を行います。 | 機能は、設計、法律、インフラ、実装方法によって異なります。 | どの機能が一次資料によって確認されていますか？ |
