# 7.4 推奨される2時間の進行案

これは最小限の進行例です。受講者グループに経済的な背景知識や地域に即した議論がさらに必要な場合は、時間を延長してください。


| 時間 | 学習の流れ | 推奨される方法 |
| --- | --- | --- |
| 0〜12分 | 事前の考えを引き出す | 導入の質問をペアで話し合い、その後グループ全体で議論 |
| 12〜28分 | お金はなぜ存在するのか | 交換のシナリオと確認の質問 |
| 28〜45分 | 機能と特性 | 地域の事例とお金の特性の比較 |
| 45〜58分 | 物々交換と選択 | 「欲求の二重の一致」を体験する短いロールプレイ、希少性と機会費用についての振り返り |
| 58〜70分 | お金の歴史 | 地域の事例を加えた非直線的な年表 |
| 70〜92分 | 法定通貨システムにおける役割 | 地域での支払いの流れの追跡と機関のマップ |
| 92〜105分 | 銀行 | 貸借対照表の簡単な図解、または流動性・支払能力のシナリオ |
| 105〜115分 | インフレ、購買力、CBDC | 日付の明記された地域のデータに基づく議論 |
| 115〜120分 | 振り返りと次への橋渡し | 「お金が機能しなくなるのは…のときです」という説明 |


講座の時間に余裕がある場合は、このモジュールを2部に分けてください。まずお金の基礎を扱い、その後に現代のお金のトレードオフを扱います。
