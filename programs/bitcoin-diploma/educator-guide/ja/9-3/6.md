# 9.6 推奨される授業の進め方

可能であれば、学習パートを2つに分け、評価の時間を別途設けてください。

#### パートA：カストディの基礎


| 時間 | 学習ステップ | 推奨する方法 |
| --- | --- | --- |
| 0〜10分 | 安全に関する約束事を決める | 「公開してよい情報と秘密にすべき情報」の導入チェック |
| 10〜25分 | ウォレットとカストディ | 「ウォレットはインターフェースである」ことを示すデモンストレーション |
| 25〜40分 | アドレス、鍵、シードフレーズ | カード分類と解説 |
| 40〜58分 | カストディアル、セルフカストディ、ホット、コールド、ハードウェア | シナリオ比較 |
| 58〜80分 | 復元への備え | 教育者によるプレゼンテーション、ガイド付きシミュレーション、振り返り |
| 80〜105分 | 受け取り | 受け取り画面の説明と学習者による練習 |
| 105〜120分 | まとめ | 共有してよいもの、秘密にしなければならないもの、そして誰が鍵を管理しているかを説明する |


#### パートB：検証と安全


| 時間 | 学習活動 | 推奨される方法 |
| --- | --- | --- |
| 0〜15分 | 保管（カストディ）のルールの振り返り | 安全に関するシナリオ |
| 15〜40分 | 送金と確認 | 予測を交えた教育者によるデモンストレーション |
| 40〜58分 | 承認とエクスプローラー | 用意したトランザクションの検索 |
| 58〜73分 | アドレスの履歴と再利用 | 用意した公開アドレスを使った活動 |
| 73〜93分 | 詐欺と取り消せないミス | シナリオ別ステーション |
| 93〜108分 | 入手方法 | リスクマップによる比較 |
| 108〜120分 | オンチェーンとライトニング | 支払い経路の分類と「中断・相談」の振り返り |


正式な観察評価は、支援付きの練習を終えてから実施してください。
