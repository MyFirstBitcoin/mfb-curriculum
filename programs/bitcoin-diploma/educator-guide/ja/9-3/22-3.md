# 9.22 モジュール3の総合演習サーキット

各ステーションは、学習者がそれぞれのプロセスを一通り見た後に使用してください。


| ステーション | 学習者の課題 | 安全面の重点 |
| --- | --- | --- |
| 1. ウォレットと管理 | 誰が鍵を管理しているかを特定し、受け取り機能の場所を確認します | 「ウォレット」という言葉だけで管理形態を推測しないでください |
| 2. 公開情報か秘密情報か | 支払い情報と復元情報を分類します | 本物の秘密情報は決して明かさないでください |
| 3. 受け取り | 用意された請求を作成または確認し、その支払い経路を特定します | 共有するのは受け取り用の情報のみです |
| 4. 送金 | 受取人、ネットワーク、送金先、金額、単位、手数料、最終確認画面を検証します | 少しでも不一致があれば中止してください |
| 5. 復元 | 用意された復元準備の課題を順序立てる、または実施します | 人目のない場所で作業し、資金の入った本物のシードは使用しないでください |
| 6. エクスプローラー | 用意された取引のステータスと公開データを読み取ります | エクスプローラーのプライバシー上の問題と限界を認識してください |
| 7. 詐欺 | 緊急のサポート要請やアドレス変更の依頼に対応します | いったん立ち止まり、独自に確認してください |
| 8. 入手経路 | 地域で利用できる2つの入手方法または支払い方法を比較します | 推奨や助言は行いません |


具体的な課題、バリエーション、評価基準、記録が承認されていない限り、これらのステーションを正式な評価として使用しないでください。
