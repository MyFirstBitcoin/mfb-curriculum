# 9.23 よくある誤解とその答え方

| よくある誤解 | 初心者にも安全な訂正 | 確認のための質問 |
| --- | --- | --- |
| ビットコインはウォレットアプリの中に保管されている。 | ビットコインは共有された台帳に記録されています。ウォレットは鍵と取引情報を管理するものです。 | スマートフォンが壊れた場合、何が残るでしょうか？ |
| アドレスは秘密のパスワードである。 | アドレスは公開してよい受け取り用の情報です。ただし、身元と結び付けられるとプライバシーが損なわれる可能性があります。 | 支払いを承認するのはどの情報でしょうか？ |
| ウォレットが読み取るのだから、どんなQRコードでも安全である。 | QRコードには誤った送金先や請求内容が含まれている可能性があります。受取人、支払い経路、金額、最終確認画面を確認してください。 | 読み取った後、何と何を照合すべきでしょうか？ |
| アドレスを共有すると、他人に使われてしまう。 | 通常、支払いには秘密鍵が必要です。それでも、アドレスを共有すると取引同士の関係が明らかになる可能性があります。 | どのようなプライバシー上のリスクが残るでしょうか？ |
| シードフレーズは普通のパスワードである。 | 多くのウォレットでは、シードフレーズは完全な復元権限そのものです。これを持つ人は誰でも鍵を再現できる可能性があります。 | 正規のサポートがそれを必要とすることはあるでしょうか？ |
| 講師に自分のシードのバックアップを確認してもらうべきだ。 | 講師は、単語を見ることなく安全な手順を見守ることができます。 | シードを秘密にしたまま、準備ができていることをどのように示せるでしょうか？ |
| すべてのウォレットはセルフカストディである。 | ウォレットと呼ばれるアプリの中には、ユーザーに代わって鍵を保有するものもあります。 | 出金を承認し、復元を管理するのは誰でしょうか？ |
| ハードウェアウォレットを使えば、バックアップのリスクはなくなる。 | デバイスは鍵を隔離しますが、復元は依然として保護されたバックアップと正しい使い方にかかっています。 | デバイスが壊れたらどうなるでしょうか？ |
| 1回の承認（コンファメーション）があれば、どんな支払いも安全である。 | 承認は決済履歴をより確かなものにしますが、誤った送金先や詐欺を修正するものではありません。 | 承認する前に、どのような確認を行う必要があるでしょうか？ |
| ブロックエクスプローラーはビットコインそのものである。 | ブロックエクスプローラーは、公開データを閲覧するための第三者のインターフェースです。 | ノードはどのような、より強力な検証を提供できるでしょうか？ |
| 手数料は主に送るbitcoinの量で決まる。 | オンチェーンの手数料は、主に取引のデータ量とブロックスペースへの需要によって決まります。 | 少額の支払いでも、手数料が高くなることはあるでしょうか？ |
| ライトニングは常にセルフカストディで、手数料もかからない。 | ライトニングウォレットにはカストディ型とセルフカストディ型があり、ルーティング、サービス、流動性の状況によって手数料や送金失敗が生じることがあります。 | どのような2つの別々の質問をすべきでしょうか？ |
| KYCは常に安全である、あるいはKYCなしは常に安全である。 | どちらの方法にも、身元、サポート、取引相手、詐欺、法律、プライバシーに関するリスクのトレードオフがあります。 | どのリスクが減り、どのリスクが増えるでしょうか？ |
