# 9.20 オンチェーン決済とライトニング決済

支払いの経路と[カストディ（保管）](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody)を区別する比較を用いてください。


| 質問 | オンチェーン | ライトニング |
| --- | --- | --- |
| 決済はどこに記録されますか？ | ビットコインのブロックチェーンに直接記録されます | 支払いの更新はビットコインの上に構築されたネットワークを通じて行われます。チャネルは最終的にビットコインに依存しています |
| 初心者が一般的に使う受け取り情報 | オンチェーンアドレス | インボイス、対応しているライトニングアドレス、またはその他の承認された請求形式 |
| 主な用途 | ベースレイヤーでの決済。比較的大きな送金や頻度の低い送金が多いです | 地域のツールや流動性が対応している場合の、少額または頻繁な支払いが多いです |
| 所要時間 | 最初の承認はブロックへの取り込みに左右されます | 多くの場合すばやく完了しますが、支払いが失敗することもあります |
| 手数料と容量 | トランザクションのデータ量とブロックスペースの需要に左右されます | ウォレット、経路、流動性、サービス、支払い条件に左右されます |
| カストディ | カストディアルの場合もセルフカストディの場合もあります | カストディアルの場合もセルフカストディの場合もあります |
| 初心者が確認すべき主な点 | 正しいアドレス、ネットワーク、金額、手数料、承認 | 正しいインボイスまたは送金先、金額、有効期限、手数料、支払い結果 |


ライトニングは別のコインではありません。ライトニングでの支払いが成功しても、そのウォレットがより大きな残高に対して安全であることの証明にはなりません。チャネルの運用、ルーティングのインフラ、[流動性](https://curriculum.myfirstbitcoin.org/lexicon/en/#lightning-liquidity)の管理は、[上級学習（Advanced Learning）](https://curriculum.myfirstbitcoin.org/programs/advanced-modules/)の内容であり、Bitcoin Diplomaの範囲外です。
