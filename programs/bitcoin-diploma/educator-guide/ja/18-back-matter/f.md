# 付録F：実施マップの例

### 4セッション構成のコース


| セッション | 主な焦点 | 必須の対話・活動 | 評価エビデンスの計画 |
| --- | --- | --- | --- |
| 1 | お金を理解する | 導入の問いかけ、お金の特性の比較、自国の法定通貨と購買力についての話し合い | 教育者主導によるモジュール1の理論面のエビデンス |
| 2 | ビットコインの仕組み | 二重支払いのシナリオ、役割マップ、供給量と健全な通貨の比較 | 教育者主導によるモジュール2の理論面のエビデンス |
| 3 | ビットコインを安全に使う | カストディ、公開情報と秘密情報、復元、受け取りと送金、エクスプローラー、詐欺、今後の道筋に関する実習 | 教育者主導による理論面のエビデンスと、実技の直接観察 |
| 4 | つながる：地域社会におけるビットコイン | 承認済みの地域PPPモジュール、それまでの学習とのつながり、最終振り返り | 教育者が観察するC7（C7.1/C7.2を含む）、形成的評価F2の振り返り、必要に応じた再評価 |


このモデルでは、実技評価のための追加時間が必要になることがよくあります。

### 8セッション構成のコース


| セッション | 焦点 |
| --- | --- |
| 1 | お金が存在する理由、機能、特性、物々交換、選択 |
| 2 | 貨幣の歴史、自国の法定通貨制度、銀行、インフレ、CBDC、復習 |
| 3 | デジタルマネーの問題、ビットコインの目的、役割、分散化 |
| 4 | プルーフ・オブ・ワーク、供給量、sats、健全な通貨の比較、範囲、復習 |
| 5 | ウォレット、アドレス、鍵、シードフレーズ、カストディ、復元の実習 |
| 6 | 受け取り、送金、承認、エクスプローラー、プライバシー、詐欺、今後の道筋、実技評価 |
| 7 | 地域のニーズ、ツールと道筋の比較、発表、サポート付きのモジュール4の実習 |
| 8 | モジュール4の制作、評価、最終振り返り、補習、次のステップ |


### 1日集中コース

受講者グループと実施環境が継続的な学習に適している場合にのみ使用してください。休憩時間を確保し、告知したコースのスケジュール内に実技評価を組み込んでください。


| 時間帯 | 重点内容 |
| --- | --- |
| オープニング | 期待事項、評価の説明、お金に関する問いかけ |
| 午前1 | お金の基礎とお金の特性に関するアクティビティ |
| 午前2 | 法定通貨、銀行、購買力、およびモジュール1の復習 |
| 昼1 | ビットコインが解決する問題、役割、プルーフ・オブ・ワーク、供給量、およびsats |
| 昼2 | 健全な通貨の比較と、自己責任へのつなぎ |
| 午後1 | 保管（カストディ）、秘密情報、復元、受け取りと送金の実習 |
| 午後2 | 検証、詐欺、教育者が選定したモジュール4の「Connect」課題、および最後の振り返り |
| フォローアップ | 残っている教育者による評価、個別の実技観察、「Not yet」となった学習者へのサポート、教育者による形成的な支援、および認定の審査 |


必要な観察や評価が未完了のまま残っている場合は、短縮版の1日コースを修了したものとして扱わないでください。
