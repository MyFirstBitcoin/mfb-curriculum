# 付録A：1ページでわかる講座準備チェックリスト

### カリキュラム

* [ ] 4つのモジュールの流れと、学習者に約束する成果を説明できます。
* [ ] 評価対象となる必須コンピテンシーのすべてについて、その評価基準とエビデンスの種類を確認しました。
* [ ] 4つのモジュールすべてがBitcoin Diplomaの必修学習であること、**モジュール3**をどのように調整し、**モジュール4**の内容をどのように選定できるか、そして何が[発展学習](https://curriculum.myfirstbitcoin.org/programs/advanced-modules/)に属するかを理解しています。
* [ ] 必要に応じて[アクティビティ・ライブラリ](https://curriculum.myfirstbitcoin.org/activities/en/)を確認し、娯楽性だけでなく、明確なコンピテンシーを目的としてアクティビティを選びました。
* [ ] すべてのモジュールについて、振り返りと次への橋渡しを準備しました。

### 学習者とアクセス

* [ ] 受講グループの言語、読み書き能力、計算能力、使用端末についての前提を把握しています。
* [ ] アクセシビリティに関するニーズと配慮が手配されています。
* [ ] 学習者は、個人的な情報を開示する代わりに、架空のシナリオを使うことができます。
* [ ] スケジュールには、練習、評価、フィードバック、再評価が含まれています。

### 地域の状況

* [ ] 地域の法定通貨制度と銀行に関する情報は最新で、出典が明示されています。
* [ ] 公式の[インフレ](https://curriculum.myfirstbitcoin.org/lexicon/en/#inflation)指標と、その算出に使われる品目バスケットを確認しました。
* [ ] [CBDC](https://curriculum.myfirstbitcoin.org/lexicon/en/#cbdc)に関する説明は最新であり、個々の設計に即したものになっています。
* [ ] 地域のツール、手数料、サービス、資料、掲載情報には日付が記されています。
* [ ] 法律、税務、プライバシー、報告義務に関する状況は、助言にならない形で説明されています。
* [ ] 地域の専門家を招く場合、その専門家は宣伝禁止とプライバシーに関する境界線を説明できます。

### 安全とテクノロジー

* [ ] 学習者の実際の[シードフレーズ](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase)、鍵、認証情報、残高、履歴を必要とする課題はありません。
* [ ] 研修用の端末とウォレットは準備され、リセットされています。
* [ ] サンプルの支払い情報には「**サンプル — 支払わないでください**」と表示されています。
* [ ] ライブデモンストレーションは、最初から最後まで通してテスト済みです。
* [ ] 中止の条件とエスカレーションの手順が明確になっています。
* [ ] ライブまたはオンラインに依存するものには、すべてローテクの代替手段があります。
* [ ] 端末、電源、インターネット、充電、会場の準備が整っています。

### 評価

* [ ] 評価に用いるアクティビティは、学習者が各コンピテンシーを示すための明確で公平な機会を提供します。
* [ ] 受講グループの人数、利用できる時間、質問、トラブル対応、フィードバック、再評価について検討しました。
* [ ] 最終的な判断を下す前に、学習者はサポートを受けながら練習する機会を得られます。
* [ ] 何に注目すべきか、役立つフォローアップの質問をどのように行うか、そしていつ「**はい**」または「**まだ**」と記録するかを理解しています。
* [ ] 必要に応じて、オンライン、ローテク、アクセシビリティに配慮した実施方法が準備できています。
* [ ] 記録するメモはすべて[プライバシー](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)を保護し、必要最小限の有用な情報にとどめています。
* [ ] 参加証明または修了証明を適切に発行する方法を理解しています。
* [ ] 各受講者の結果を確認したうえで[証明書ツール](https://tools.myfirstbitcoin.org/certificate)を使用しており、配布前に証明書の内容を確認します。
