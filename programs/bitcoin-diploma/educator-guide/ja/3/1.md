# 3.1 明確な期待を示して講座を始める

ビットコイン・ディプロマは教育を目的としたものであることを説明してください。ビットコインの購入、売却、ビットコインを担保にした借り入れ、または保有を推奨するものではありません。また、[価格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)の上昇を約束したり、トレードを教えたりするものでもありません。受講者はビットコインを所有している必要はなく、所有しているかどうかを明かす必要もありません。

次の参加ルールを定めてください。

* 自分の言葉で考えを説明します
* 用語がわからないときは質問します
* 個人的な経験と一般的な根拠を区別します
* 人を攻撃することなく、考えに異議を唱えます
* わからないことは正直にそう伝えます
* 他の人の意見の背後にある理由に耳を傾けます
* お金、銀行、安全、テクノロジーについて、全員が同じ経験をしていると決めつけません
* 個人的な例を出すとプライベートに踏み込むと感じる場合は、架空のシナリオを使います
* 誰に対しても、お金やビットコインをどれだけ保有しているかを尋ねません
* 許可なく他の受講者の成果物や画面を撮影、録画、共有しません
* 次のものは決して明かしません：[シードフレーズ](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase)、[秘密鍵](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key)、パスワード、セキュリティ上の取り決め。そして
* 実演された手順と異なることが起きたときは、実習を中止します。
