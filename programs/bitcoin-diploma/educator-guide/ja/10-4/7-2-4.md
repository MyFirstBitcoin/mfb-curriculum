# 10.7 2時間で行うモジュール4の推奨進行案

| 時間 | 学習の段階 | 教育者の行動 |
| --- | --- | --- |
| 0〜12分 | 地域のニーズ | 課題と現在の方法を提示します。開示を求めることなく、学習者に経験を共有するよう促します。 |
| 12〜28分 | 学習内容を結びつける | モジュール1の課題、モジュール2の対応、モジュール3の安全な行動、お金の機能、保管（カストディ）、決済手段、そして現実的な既存の代替手段を特定します。 |
| 28〜48分 | 一連のデモンストレーション | 成功する場合と失敗する場合の両方の流れを示します。費用、プライバシー、復旧、中止の条件を説明します。 |
| 48〜70分 | 支援付きの練習 | 学習者はペアまたはステーションで、教育者からのフィードバックを受けながら練習します。 |
| 70〜90分 | 比較と地域におけるトレードオフ | 受取総額、時間、手数料、保管（カストディ）、プライバシー、取り消し可能性、失敗の観点から、ビットコインを使う方法と現在の代替手段を比較します。 |
| 90〜110分 | 制作または評価 | 承認された個人またはチームの課題を観察し、本人が特定できる証拠を保存します。 |
| 110〜118分 | 説明と相互質問 | 学習者が目的、利点、リスク、失敗しうる点、次のステップを説明します。 |
| 118〜120分 | コースへの橋渡し | 最後の振り返りと、必要に応じて再評価の準備をします。 |


直接観察を時間内に収められない場合は、実施前に予定している進行を見直してください。承認された評価者を増員する、受講者グループの人数を減らす、またはより長い統合型コースとして告知する、といった対応をとります。告知した Bitcoin Diploma の終了後に、評価のみを目的とした追加の回を設けないでください。
