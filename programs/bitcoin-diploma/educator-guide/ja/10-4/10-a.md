# 10.10 モジュールのオプションA：地域における決済経路の比較

**目的：**既存の地域の支払い方法、オンチェーンの経路、そして必要に応じてライトニングの経路について、支払いの全体的な流れを比較します。

**準備：**現実的な架空の支払い金額と受取人を設定してください。日付を明記した、地域の手数料、為替、所要時間、[カストディ（資産の保管・管理）](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody)、利用しやすさに関する情報を用意してください。データを検証できない場合は、仮定のものであることを明示してください。

**学習者の課題：**以下を記入してください。


| 項目 | 既存の方法 | オンチェーンのビットコイン | ライトニング（該当する場合） |
| --- | --- | --- | --- |
| 送金額 |  |  |  |
| 受取総額 |  |  |  |
| 所要時間と決済完了の見込み |  |  |  |
| 手数料とスプレッド |  |  |  |
| 各段階でのカストディ |  |  |  |
| 本人確認とプライバシー |  |  |  |
| 取り消しまたは返金 |  |  |  |
| 主な失敗ポイント |  |  |  |
| 地域のサポートまたは法律 |  |  |  |


**成果物：**学習者は架空のケースに対して経路を一つ選び、該当する支払いリクエストと確認の手順を実演するか順を追って示し、条件が変わった場合にはもう一方の経路の方が適している可能性がある理由を説明します。

**振り返り：**ビットコインは支払いの全体的な流れを改善したでしょうか、それとも目に見える一つの段階だけを改善したのでしょうか？価格変動、通貨換算、[カストディ](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody)、失敗のリスクを負うのは誰でしょうか？

**安全面：**実際の送金や特定の事業者は必要ありません。印刷した支払い情報を使用してください。
