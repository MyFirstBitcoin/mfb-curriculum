# 10.8 地域のビットコインツールのレビュー

地域で人気があるという理由だけでツールを実演しないでください。次の比較表を使用してください。


| 項目 | 確認すべき質問 |
| --- | --- |
| 目的 | そのツールはどのような問題を解決し、本当に必要ですか？ |
| 管理（カストディ） | 鍵と資金を管理しているのは誰ですか？ |
| 提供元 | 誰が公開しており、正規の提供元であることをどのように確認しましたか？ |
| コードと保守 | オープンソースで、レビューされ、保守され、安全に更新されていますか？ |
| 復元 | デバイス、サービス、または企業がなくなった場合、どうなりますか？ |
| プライバシー | 本人確認情報、連絡先、デバイス、位置情報、取引データのうち、どれが収集されますか？ |
| 費用 | 目に見える手数料、スプレッド、サブスクリプション料金、入金費用、出金費用のうち、どれがかかりますか？ |
| 互換性 | どのネットワーク、アドレス形式、インボイス、バックアップ、デバイスに対応していますか？ |
| サポート | 学習者は秘密情報を共有せずにサポートを受けられますか？ |
| 法律と記録 | 地域の規制、消費者保護ルール、税務、会計、報告義務のうち、関係しうるものは何ですか？ |
| 代替手段 | ツールが機能しない場合や利用できない場合、学習者は何を使えますか？ |
