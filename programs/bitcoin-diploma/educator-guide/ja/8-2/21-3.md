# 8.21 復習とモジュール3への橋渡し

| 法定通貨システムの課題 | ビットコインによる対応 | 新たな責任またはトレードオフ |
| --- | --- | --- |
| 政策によって供給量が変わり得る |  |  |
| 支払いが仲介者に依存している |  |  |
| 1つの台帳管理者が記録を管理している |  |  |
| 利用できるかどうかが機関に依存している |  |  |


次の点について明確な説明を求めてください：なぜ[ノード](https://curriculum.myfirstbitcoin.org/lexicon/en/#node)と[マイナー](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner)は異なる役割を持つのか。

次に、**モジュール2**の生徒用ガイドにある締めくくりの質問を使用してください。上記の、モジュールを締めくくる軽い振り返りに関するガイダンスに従い、回答は非公開または任意としてください。

橋渡し：

> ビットコインは口座運営者への依存を減らすことができますが、直接的な管理には、鍵、検証、復元、そして安全な判断が欠かせません。**モジュール3**では、その責任を実践に移します。
