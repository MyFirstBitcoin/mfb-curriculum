# 8.17 ビットコインの特性に関するFAQ

| 特性 | 学習者の質問 | 初心者向けの適切な回答 |
| --- | --- | --- |
| 希少性 | 「誰かが2,100万ビットコイン以上を作ることはできないのですか？」 | 誰かが別のソフトウェアを書くことはできますが、参加者がそれを実行する必要はありません。ビットコインのルールに従うノードは、上限を超える発行を拒否します。互換性のないルールが広く採用されれば、別のネットワークが生まれる可能性はあります。しかし、創設者、マイナー、開発者、企業、政府のいずれであっても、すべての人にとって有効な追加のビットコインをひそかに作り出すことはできません。 |
| 希少性 | 「供給が限られているということは、価格は必ず上がるのですか？」 | いいえ。価格は供給だけでなく需要にも左右され、需要は減ることもあります。供給が有限であることは貨幣としての特性であり、リターンを保証するものではありません。 |
| 分割可能性 | 「2,100万しかないなら、全員に行き渡るのですか？」 | 1ビットコインは100,000,000 satsに分割できます。より小さな単位を使えば、総供給量を増やすことなく少額を表すことができます。 |
| 分割可能性 | 「1ビットコイン丸ごと買う必要がありますか？」 | いいえ。学習者は1ビットコイン丸ごと所有していなくても、satsについて説明したり使ったりすることができます。また、Bitcoin Diplomaの受講にビットコインの所有は必要ありません。 |
| 耐久性 | 「スマートフォンが壊れたらどうなりますか？」 | ビットコインはスマートフォンの中に保存されているわけではありません。ネットワーク上の記録は存続しますが、アクセスできるかどうかは、鍵とリカバリー情報が安全に管理されているかにかかっています。端末を紛失しても復元できる場合がありますが、リカバリー情報を失ったり他人に知られたりすると、永久に失う可能性があります。 |
| 携帯性 | 「どこへでも無条件で送れるのですか？」 | 有効な送金には、ビットコインを運営する中央機関の承認は必要ありません。しかし、適切なウォレット、通信手段、正しい支払い情報、手数料、そして受け取ることのできる受取人は依然として必要です。また、各地域の法律やサービスによって制約が加わる場合があります。 |
| 代替可能性 | 「すべてのsatはまったく同じなのですか？」 | 同じ金額であれば、プロトコル上は同じ支出ルールに従います。しかし、公開されている取引履歴によって、一部のサービスや人々が特定の資金をどう扱うかが左右されることがあります。 |
| 検証可能性 | 「ウェブサイトを信頼しなければならないのですか？」 | エクスプローラーは第三者が提供する便利なインターフェースです。ノードを使えば、より確かな独立した検証が可能になります。一方で、初心者はウォレットやサービスの情報に頼ることもあるため、その依存関係を自覚しておくべきです。 |
| 受容性 | 「ビットコインが便利なら、なぜどこでも使えないのですか？」 | 技術的に可能であることが、普遍的な受け入れにつながるわけではありません。地域の習慣、ツール、コスト、規制、価格変動、教育、店舗側の需要などが利用に影響します。 |
| 分散性 | 「ビットコインは完全に分散化されているのですか？」 | 影響力やインフラは均等に分布しているわけではありません。より正確に言えば、どの参加者も単独で、すべての人にとって有効な残高やルールを一方的に変更することはできない、ということです。 |
| 信頼できる希少性 | 「コードをコピーして別のコインを作ればいいのではないですか？」 | コードをコピーしたり、供給上限を書き込んだりすることは可能です。しかし、信頼できるルールの執行、独立した検証、セキュリティ、歴史、ネットワークの普及、一方的な変更への耐性は、それとは別の問題です。 |
