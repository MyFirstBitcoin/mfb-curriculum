# 8.14 健全なデジタルマネーとしてのビットコイン

改めて、**モジュール1**で使用したお金の特性そのものに立ち返ってください。根拠と限定条件を求めてください。


| 特性 | 教育者に役立つ問い | 重要な限定条件 |
| --- | --- | --- |
| 耐久性 | 1台のデバイスが故障した場合、何が残りますか？ | アクセスは依然として、有効な鍵と復元手段に依存します。 |
| 携帯性 | 価値を移転するには何が必要ですか？ | デバイス、通信手段、正確な送金情報、手数料、受取人の対応能力は依然として重要です。 |
| 分割可能性 | sats（サトシ）は少額の取引をどのように支えていますか？ | 単位が小さいからといって、あらゆる決済手段が経済的であるとは限りません。 |
| 代替可能性 | プロトコル上の同じ単位は、同じルールのもとで使用できますか？ | 公開された取引履歴によって、サービスが特定の資金をどう扱うかが左右されることがあります。 |
| 希少性 | 発行上限は誰が確認していますか？ | 供給量が限られていても、需要や価格が保証されるわけではありません。 |
| 検証可能性 | ノードは何を独立して確認できますか？ | 多くの初心者は、依然としてウォレットやエクスプローラーの画面に頼っています。 |
| 受容性 | bitcoinは実際にどこで使えますか？ | 受け入れられている度合いは、コミュニティによって大きく異なります。 |


「[**健全なお金**](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money)」を、基準に基づく結論として扱ってください。学習者は、自身の状況において、ビットコインがある基準は強く満たし、別の基準は弱くしか満たさないと結論づけることもあります。

次のものを区別してください：

* 観察される市場[価格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)
* 地域における有用性や受容度
* 個人の[主観的価値](https://curriculum.myfirstbitcoin.org/lexicon/en/#subjective-value)、そして
* 個人としての支持。
