# 17.1 用語早見と誤解を招きやすい概念の区別

完全な定義については用語集（Lexicon）を参照してください。以下の区別は、話す内容、スライド、アクティビティ、評価のすべてにおいて一貫して用いてください。


| 用語 | 教育者が押さえるべき区別 |
| --- | --- |
| お金／通貨 | お金とは、交換、計算単位、時間を超えた価値の保存に用いられる、より広い意味での道具または資産です。通貨とは、特定の貨幣単位または貨幣制度を指します。 |
| 機能／特性 | 機能とはお金が果たす役割のことであり、特性とはその役割をどの程度うまく果たせるかに影響する性質のことです。 |
| 希少性／価値 | 希少性は入手可能性を制限するものです。価値は、それに加えて用途、需要、選好、情報、状況にも左右されます。 |
| 物価インフレ／単一の価格上昇 | インフレとは一般物価水準の持続的な上昇のことです。単一の価格は、さまざまな理由で変動することがあります。 |
| 銀行預金／現金 | 銀行預金は銀行が負う債務に対する請求権です。現金は、法域によって中央銀行または国家が発行する、別の形態のお金です。 |
| 流動性／支払能力 | 流動性は期限どおりに支払いができるかどうかに関わり、支払能力は資産が債務をまかなえるかどうかに関わります。 |
| CBDC／ビットコイン | CBDCは中央で発行されるデジタル法定通貨です。ビットコインには中央の発行者が存在せず、誰もが独立して検証できるルールに基づいています。 |
| ビットコイン（Bitcoin）／ビットコイン（bitcoin） | 大文字のBitcoinはネットワーク、プロトコル、またはプロジェクトを指し、小文字のbitcoinは資産または単位を指します。 |
| ビットコインのプロトコル／ビットコイン関連サービス | プロトコルは共有されたルールの体系です。ウォレット、取引所、エクスプローラー、決済会社は、それとは別のサービスまたはツールです。 |
| デジタル署名／暗号化 | 署名は鍵による承認を証明するものであり、暗号化は読み取り可能な内容を隠すものです。 |
| マイナー／ノード | マイナーはプルーフ・オブ・ワークによって候補ブロックを提案し、ノードはルールを検証します。 |
| 開発者の提案／ルールの変更 | 開発者はソフトウェアを提案し、参加者がそれを採用するかどうかを選択します。 |
| ブロック生成時間／スケジュール | 約10分というのは長期的な平均であり、正確な予定時刻ではありません。 |
| 有限の供給量／価格の保証 | 予測可能な上限は供給に関する特性であり、需要やリターンを保証するものではありません。 |
| 健全な貨幣／事実 | 健全な貨幣とは、明示された基準とトレードオフに基づいて下される判断です。 |
| ウォレット／ビットコインの保管 | ウォレットは鍵と取引を管理するものであり、ビットコインそのものは共有台帳に記録されたままです。 |
| アドレス／秘密鍵 | アドレスは受け取りに使い、秘密鍵は支出を承認します。 |
| シードフレーズ／パスワード | シードフレーズはウォレットの鍵を再生成できる場合があり、多くの場合、完全な復元アクセスを与えます。再設定できる通常のパスワードではありません。 |
| カストディアル／セルフカストディ | 違いは、誰が鍵を管理しているかです。 |
| ホット／コールド | 違いは、鍵がオンラインの汎用環境にさらされているかどうかです。 |
| オンチェーン／ライトニング | 違いは支払いの経路であり、保管方法ではありません。 |
| エクスプローラー／ノード | エクスプローラーは第三者が提供するインターフェースであり、ノードは独立してルールを検証します。 |
| 承認（コンファメーション）／正しい支払い | 承認は決済履歴をより確かなものにしますが、受取人の誤りを正したり、支払いの目的を正当化したりするものではありません。 |
| プライバシー／秘密 | プライバシーとは情報に対するコントロールのことです。ある活動に公開データや法的義務が一切ないという意味ではありません。 |
| KYC / no-KYC | これらの経路では収集される本人確認情報が異なり、サポート、プライバシー、カウンターパーティ、詐欺、法的側面においてそれぞれ異なるトレードオフが生じます。表記は全体を通して「no-KYC」を使用してください。 |
| 地域の事例 / 推奨 | 確認済みの地域の事例は学習の助けになりますが、普遍的な推奨ではありません。 |
