# 4.7 Registro di verifica locale

Compili una riga per ogni fatto, servizio o risorsa soggetti a cambiamento utilizzati in classe.


| Elemento | Perché è importante | Fonte o esperto locale | Data di verifica | Cosa può cambiare | Formulazione in classe o alternativa |
| --- | --- | --- | --- | --- | --- |
| Valuta locale e norme sui pagamenti | Discussione del Modulo 1 |  |  |  |  |
| Regolamentazione bancaria e tutela dei depositi | Sezione sulla riserva frazionaria |  |  |  |  |
| Misura ufficiale dell'Inflazione e paniere | Attività sul Potere d'acquisto |  |  |  |  |
| Stato o progettazione della CBDC | Confronto locale facoltativo |  |  |  |  |
| Wallet o strumento di pagamento | Esercitazione del Modulo 3 o 4 |  |  |  |  |
| Commissioni, spread e limiti | Confronto dei percorsi locali |  |  |  |  |
| Contesto legale, fiscale, di privacy o di segnalazione | Modulo locale |  |  |  |  |
| Esercente, mappa, meetup o risorsa di supporto | Scoperta della comunità |  |  |  |  |


Per le norme vigenti, privilegi fonti primarie autorevoli. Se le prove sono incomplete, lo dica. Non trasformi informazioni locali incerte in un'affermazione universale.
