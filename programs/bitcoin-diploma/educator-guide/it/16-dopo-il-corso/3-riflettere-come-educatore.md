# 16.3 Riflettere come educatore

Completi questa revisione finché il corso è ancora fresco nella memoria:


| Domanda | Note e azioni |
| --- | --- |
| Quale competenza ha richiesto più o meno tempo del previsto? |  |
| Quale idea errata si è presentata ripetutamente? |  |
| Quali voci tra i partecipanti sono state ascoltate di meno? |  |
| Quale esempio locale ha migliorato ciò che i partecipanti erano in grado di spiegare, confrontare o fare? |  |
| Quale esempio è diventato politico, promozionale o troppo personale? |  |
| Quale attività ha prodotto evidenze utili? |  |
| Quale attività ha generato una semplificazione fuorviante? |  |
| Tutte le condizioni di interruzione delle attività pratiche sono state efficaci? |  |
| Qualche strumento, link, commissione, regola o elenco è diventato obsoleto? |  |
| Quale giudizio di valutazione richiede una moderazione? |  |
| Quale adattamento per l'accessibilità o linguistico dovrebbe essere mantenuto? |  |
| Che cosa cambierà prima del prossimo gruppo di partecipanti? |  |
