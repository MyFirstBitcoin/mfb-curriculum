# 17.1 Terminologia in breve e distinzioni utili a prevenire i malintesi

Utilizzi il Lessico per le definizioni complete. Mantenga queste distinzioni coerenti nell'esposizione orale, nelle slide, nelle attività e nella valutazione.


| Termini | Distinzione per l'educatore |
| --- | --- |
| Denaro / valuta | Il denaro è lo strumento o l'asset più ampio usato per lo scambio, come unità di conto e come riserva di valore nel tempo; la valuta è una specifica unità o sistema monetario. |
| Funzione / proprietà | Una funzione è ciò che il denaro fa; una proprietà è una qualità che incide su quanto bene lo fa. |
| Scarsità / valore | La scarsità limita la disponibilità; il valore dipende anche da utilizzo, domanda, preferenze, informazioni e contesto. |
| Inflazione dei prezzi / aumento di un singolo prezzo | L'inflazione è un aumento persistente del livello generale dei prezzi; un singolo prezzo può variare per molte ragioni. |
| Deposito bancario / contante fisico | Un deposito bancario è un credito che la banca deve al depositante; il contante fisico è una forma diversa di moneta emessa dalla banca centrale o dallo Stato, a seconda della giurisdizione. |
| Liquidità / solvibilità | La liquidità riguarda la capacità di pagare nei tempi dovuti; la solvibilità riguarda se le attività coprono le obbligazioni. |
| CBDC / Bitcoin | Una CBDC è moneta fiat digitale emessa centralmente; Bitcoin non ha un emittente centrale e utilizza regole verificabili in modo indipendente. |
| Bitcoin / bitcoin | Bitcoin si riferisce alla rete, al protocollo o al progetto; bitcoin si riferisce all'asset o alle unità. |
| Protocollo Bitcoin / servizio Bitcoin | Il protocollo è il sistema di regole condiviso; un wallet, un exchange, un explorer o una società di pagamenti è un servizio o uno strumento distinto. |
| Firma digitale / crittografia | Una firma dimostra l'autorizzazione tramite chiave; la crittografia nasconde il contenuto leggibile. |
| Miner / nodo | Un miner propone blocchi candidati tramite la Proof of Work (PoW); un nodo verifica le regole. |
| Proposta degli sviluppatori / modifica delle regole | Gli sviluppatori propongono software; i partecipanti scelgono se adottarlo. |
| Tempo di blocco / orario prestabilito | Circa dieci minuti è una media di lungo periodo, non un appuntamento esatto. |
| Offerta finita / garanzia di prezzo | Un massimo prevedibile è una proprietà dell'offerta; non garantisce domanda né rendimenti. |
| Moneta sana / fatto | La moneta sana (sound money) è un giudizio formulato sulla base di criteri dichiarati e di compromessi. |
| Wallet / custodia dei bitcoin | Un wallet gestisce chiavi e transazioni; i bitcoin restano registrati sul ledger condiviso. |
| Indirizzo / chiave privata | Un indirizzo serve a ricevere; una chiave privata autorizza la spesa. |
| Seed phrase / password | Una seed phrase può ricreare le chiavi del wallet e spesso consente il pieno accesso al recupero; non è una normale password reimpostabile. |
| Custodial / self-custodial | La distinzione riguarda chi controlla le chiavi. |
| Hot / cold | La distinzione riguarda l'esposizione delle chiavi a un ambiente online di uso generale. |
| On-chain / Lightning | La distinzione riguarda il percorso del pagamento, non la custodia. |
| Explorer / nodo | Un explorer è un'interfaccia di terze parti; un nodo verifica le regole in modo indipendente. |
| Conferma / pagamento corretto | Una conferma rafforza lo storico di regolamento; non corregge il destinatario né convalida lo scopo. |
| Privacy / segretezza | La privacy è il controllo sulle informazioni; non significa che un'attività non comporti dati pubblici o obblighi di legge. |
| KYC / no-KYC | Questi percorsi raccolgono informazioni identificative diverse e comportano compromessi diversi in termini di assistenza, privacy, controparte, frodi e aspetti legali. Usi sempre il termine no-KYC. |
| Esempio locale / raccomandazione | Un esempio locale verificato favorisce l'apprendimento; non costituisce un'approvazione universale. |
