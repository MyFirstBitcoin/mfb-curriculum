# 4.7 स्थानीय सत्यापन रिकॉर्ड

कक्षा में उपयोग किए जाने वाले हर बदलते तथ्य, सेवा या संसाधन के लिए एक पंक्ति भरें।


| विषय | यह क्यों महत्वपूर्ण है | स्रोत या स्थानीय विशेषज्ञ | जाँच की तारीख | क्या बदल सकता है | कक्षा में कहने के लिए शब्दावली या वैकल्पिक उपाय |
| --- | --- | --- | --- | --- | --- |
| स्थानीय मुद्रा और भुगतान के नियम | मॉड्यूल 1 की चर्चा |  |  |  |  |
| बैंकिंग विनियमन और जमा राशि की सुरक्षा | आंशिक-आरक्षित बैंकिंग वाला खंड |  |  |  |  |
| मुद्रास्फीति का आधिकारिक माप और वस्तुओं व सेवाओं की टोकरी | क्रय-शक्ति संबंधी गतिविधि |  |  |  |  |
| CBDC की स्थिति या रूपरेखा | वैकल्पिक स्थानीय तुलना |  |  |  |  |
| वॉलेट या भुगतान साधन | मॉड्यूल 3 या 4 का अभ्यास |  |  |  |  |
| शुल्क, खरीद-बिक्री दरों का अंतर और सीमाएँ | स्थानीय विकल्पों की तुलना |  |  |  |  |
| कानून, कर, गोपनीयता या रिपोर्टिंग संबंधी संदर्भ | स्थानीय मॉड्यूल |  |  |  |  |
| व्यापारी, मानचित्र, सामुदायिक मिलन या सहायता संसाधन | समुदाय से परिचय |  |  |  |  |


वर्तमान नियमों के लिए प्रामाणिक प्राथमिक स्रोतों को प्राथमिकता दें। यदि साक्ष्य अधूरे हैं, तो इसे स्पष्ट रूप से बताएँ। अनिश्चित स्थानीय जानकारी को सार्वभौमिक दावे में न बदलें।
