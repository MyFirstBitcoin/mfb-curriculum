# 10.10 मॉड्यूल विकल्प A: स्थानीय भुगतान मार्गों की तुलना

**उद्देश्य:** किसी मौजूदा स्थानीय भुगतान के पूरे मार्ग, ऑन-चेन मार्ग और जहाँ उपयुक्त हो, लाइटनिंग मार्ग की तुलना करें।

**तैयारी:** भुगतान की एक यथार्थपरक काल्पनिक राशि और प्राप्तकर्ता का उपयोग करें। स्थानीय शुल्क, विनिमय, समय, [अभिरक्षा](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), और पहुँच की दिनांक सहित जानकारी तैयार करें। यदि आँकड़ों का सत्यापन नहीं किया जा सकता, तो उन्हें स्पष्ट रूप से काल्पनिक चिह्नित करें।

**शिक्षार्थी का कार्य:** पूरा करें:


| विवरण | मौजूदा तरीका | ऑन-चेन बिटकॉइन | लाइटनिंग, यदि प्रासंगिक हो |
| --- | --- | --- | --- |
| भेजी गई राशि |  |  |  |
| प्राप्त कुल राशि |  |  |  |
| समय और निपटान की अपेक्षा |  |  |  |
| शुल्क और विनिमय दर का अंतर |  |  |  |
| प्रत्येक चरण में अभिरक्षा |  |  |  |
| पहचान और गोपनीयता |  |  |  |
| लेनदेन पलटना या धनवापसी |  |  |  |
| विफलता का मुख्य बिंदु |  |  |  |
| स्थानीय सहायता या कानून |  |  |  |


**कार्य-प्रस्तुति:** शिक्षार्थी काल्पनिक मामले के लिए एक मार्ग चुनता है, संबंधित भुगतान अनुरोध और सत्यापन का प्रदर्शन करता है या उनके चरणों को क्रम में रखता है, और समझाता है कि परिस्थिति बदलने पर दूसरा मार्ग बेहतर क्यों हो सकता है।

**समीक्षा चर्चा:** क्या बिटकॉइन ने पूरे मार्ग में सुधार किया, या केवल एक दिखाई देने वाले चरण में? अस्थिरता, रूपांतरण, [अभिरक्षा](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), और विफलता का जोखिम कौन उठाता है?

**सुरक्षा:** किसी वास्तविक हस्तांतरण या किसी विशिष्ट प्रदाता की आवश्यकता नहीं है। भुगतान की मुद्रित जानकारी का उपयोग करें।
