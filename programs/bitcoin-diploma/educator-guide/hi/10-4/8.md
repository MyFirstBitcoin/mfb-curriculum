# 10.8 स्थानीय बिटकॉइन टूल की समीक्षा

किसी टूल का प्रदर्शन केवल इसलिए न करें कि वह स्थानीय स्तर पर लोकप्रिय है। इस तुलना का उपयोग करें:


| पहलू | प्रश्न |
| --- | --- |
| उद्देश्य | यह टूल किस समस्या को हल करता है, और क्या इसकी आवश्यकता है? |
| अभिरक्षा | कुंजियों और धन पर किसका नियंत्रण है? |
| स्रोत | इसे कौन प्रकाशित करता है, और असली स्रोत की पुष्टि कैसे की गई? |
| कोड और रखरखाव | क्या इसका स्रोत कोड खुला है, इसकी समीक्षा और रखरखाव किया जाता है, और इसे सुरक्षित ढंग से अपडेट किया जाता है? |
| पुनर्प्राप्ति | जब डिवाइस उपलब्ध नहीं रहता, सेवा बंद हो जाती है या कंपनी का अस्तित्व समाप्त हो जाता है, तो क्या होता है? |
| गोपनीयता | पहचान, संपर्क, डिवाइस, स्थान और लेन-देन से संबंधित कौन-सा डेटा एकत्र किया जाता है? |
| लागत | कौन-से प्रत्यक्ष शुल्क, खरीद-बिक्री मूल्य के अंतर, सदस्यता शुल्क, धन जमा करने की लागत और निकासी की लागत लागू होती हैं? |
| अनुकूलता | कौन-से नेटवर्क, पते के प्रकार, इनवॉइस, बैकअप और डिवाइस इसके साथ काम करते हैं? |
| सहायता | क्या शिक्षार्थी गोपनीय जानकारी साझा किए बिना सहायता प्राप्त कर सकते हैं? |
| कानून और अभिलेख | कौन-से स्थानीय प्रतिबंध, उपभोक्ता नियम, कर, लेखांकन या रिपोर्टिंग संबंधी दायित्व मायने रख सकते हैं? |
| विकल्प | यदि यह टूल काम न करे या उपलब्ध न हो, तो शिक्षार्थी किसका उपयोग कर सकते हैं? |
