# 17.1 संक्षिप्त शब्दावली और भ्रांतियों को ध्यान में रखकर किए गए भेद

पूरी परिभाषाओं के लिए शब्दावली का उपयोग करें। बोलते समय, स्लाइडों, गतिविधियों और मूल्यांकन में इन भेदों को एकसमान रखें।


| शब्द | शिक्षकों के लिए भेद |
| --- | --- |
| धन / मुद्रा | धन एक व्यापक साधन या परिसंपत्ति है जिसका उपयोग विनिमय, लेखांकन और समय के साथ मूल्य बनाए रखने के लिए होता है; मुद्रा एक विशिष्ट मौद्रिक इकाई या प्रणाली है। |
| कार्य / गुण | कार्य वह है जो धन करता है; गुण वह विशेषता है जो प्रभावित करती है कि धन उस कार्य को कितनी अच्छी तरह करता है। |
| दुर्लभता / मूल्य | दुर्लभता उपलब्धता को सीमित करती है; मूल्य उपयोग, माँग, पसंद, जानकारी और संदर्भ पर भी निर्भर करता है। |
| मूल्य मुद्रास्फीति / किसी एक कीमत में वृद्धि | मुद्रास्फीति सामान्य मूल्य स्तर में निरंतर वृद्धि है; किसी एक कीमत में बदलाव कई कारणों से हो सकता है। |
| बैंक जमा / भौतिक नकदी | बैंक जमा एक ऐसा दावा है जिसका भुगतान बैंक को करना होता है; भौतिक नकदी, क्षेत्राधिकार के अनुसार, केंद्रीय बैंक या राज्य द्वारा जारी धन का एक अलग रूप है। |
| तरलता / ऋणशोधन क्षमता | तरलता का संबंध समय पर भुगतान करने से है; ऋणशोधन क्षमता का संबंध इस बात से है कि परिसंपत्तियाँ देनदारियों को पूरा करने के लिए पर्याप्त हैं या नहीं। |
| CBDC / बिटकॉइन | CBDC केंद्रीय रूप से जारी डिजिटल फ़िएट मुद्रा है; बिटकॉइन का कोई केंद्रीय जारीकर्ता नहीं है और यह ऐसे नियमों का उपयोग करता है जिन्हें स्वतंत्र रूप से सत्यापित किया जा सकता है। |
| बिटकॉइन / बिटकॉइन | बिटकॉइन का पहला प्रयोग नेटवर्क, प्रोटोकॉल या परियोजना के लिए है; दूसरा प्रयोग परिसंपत्ति या उसकी इकाइयों के लिए है। |
| बिटकॉइन प्रोटोकॉल / बिटकॉइन सेवा | प्रोटोकॉल साझा नियम-प्रणाली है; वॉलेट, एक्सचेंज, एक्सप्लोरर या भुगतान कंपनी एक अलग सेवा या साधन है। |
| डिजिटल हस्ताक्षर / एन्क्रिप्शन | हस्ताक्षर कुंजी द्वारा दिए गए प्राधिकरण को प्रमाणित करता है; एन्क्रिप्शन पढ़ी जा सकने वाली सामग्री को छिपाता है। |
| माइनर / नोड | माइनर कार्य के प्रमाण के माध्यम से संभावित ब्लॉक प्रस्तावित करता है; नोड नियमों का सत्यापन करता है। |
| डेवलपर का प्रस्ताव / नियम में बदलाव | डेवलपर सॉफ़्टवेयर प्रस्तावित करते हैं; प्रतिभागी तय करते हैं कि उसे अपनाना है या नहीं। |
| ब्लॉक का समय / समय-सारणी | लगभग दस मिनट एक दीर्घकालिक औसत है, कोई निश्चित समय नहीं। |
| सीमित आपूर्ति / कीमत की गारंटी | पूर्वानुमान योग्य अधिकतम सीमा आपूर्ति का एक गुण है; यह माँग या प्रतिफल की गारंटी नहीं देती। |
| सुदृढ़ धन / तथ्य | धन को सुदृढ़ मानना एक निर्णय है जो बताए गए मानदंडों और लाभ-हानि के संतुलन के आधार पर लिया जाता है। |
| वॉलेट / बिटकॉइन का भंडारण | वॉलेट कुंजियों और लेनदेन का प्रबंधन करता है; बिटकॉइन साझा बहीखाते में दर्ज रहता है। |
| पता / निजी कुंजी | पता भुगतान प्राप्त करता है; निजी कुंजी खर्च करने की अनुमति देती है। |
| सीड फ़्रेज़ / पासवर्ड | सीड फ़्रेज़ से वॉलेट की कुंजियाँ दोबारा बनाई जा सकती हैं और यह अक्सर पूर्ण पुनर्प्राप्ति की सुविधा देता है; यह कोई साधारण पासवर्ड नहीं है जिसे रीसेट किया जा सके। |
| अभिरक्षात्मक / स्व-अभिरक्षात्मक | भेद इस बात का है कि कुंजियों पर नियंत्रण किसका है। |
| हॉट / कोल्ड | भेद इस बात का है कि कुंजियाँ सामान्य उपयोग वाले ऑनलाइन परिवेश के संपर्क में हैं या नहीं। |
| ऑन-चेन / लाइटनिंग | भेद भुगतान के मार्ग का है, अभिरक्षा का नहीं। |
| एक्सप्लोरर / नोड | एक्सप्लोरर किसी तीसरे पक्ष का इंटरफ़ेस है; नोड स्वतंत्र रूप से नियमों का सत्यापन करता है। |
| पुष्टि / सही भुगतान | पुष्टि निपटान के इतिहास को मज़बूत करती है; यह प्राप्तकर्ता को सही नहीं करती और न ही उद्देश्य की वैधता प्रमाणित करती है। |
| निजता / गोपनीयता | निजता का अर्थ जानकारी पर नियंत्रण है; इसका यह अर्थ नहीं है कि किसी गतिविधि से जुड़ा कोई सार्वजनिक डेटा या कानूनी दायित्व नहीं है। |
| KYC / no-KYC | ये तरीके पहचान से जुड़ी अलग-अलग जानकारी एकत्र करते हैं और सहायता, निजता, प्रतिपक्ष, धोखाधड़ी तथा कानूनी पहलुओं में अलग-अलग लाभ और जोखिम पैदा करते हैं। पूरे पाठ में no-KYC का ही उपयोग करें। |
| स्थानीय उदाहरण / अनुशंसा | जाँचा-परखा स्थानीय उदाहरण सीखने में सहायक होता है; यह हर परिस्थिति में उसका समर्थन नहीं है। |
