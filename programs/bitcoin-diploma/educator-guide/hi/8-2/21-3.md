# 8.21 पुनरावलोकन और मॉड्यूल 3 की ओर संक्रमण

शिक्षार्थियों से इसे पूरा करने को कहें:


| फ़िएट प्रणाली की समस्या | बिटकॉइन का समाधान | नई ज़िम्मेदारी या समझौता |
| --- | --- | --- |
| नीति के ज़रिए आपूर्ति बदल सकती है |  |  |
| भुगतान बिचौलियों पर निर्भर होते हैं |  |  |
| बहीखाता रखने वाला एक ही व्यक्ति या निकाय रिकॉर्ड नियंत्रित करता है |  |  |
| पहुँच किसी संस्था पर निर्भर होती है |  |  |


इस बात का स्पष्ट स्पष्टीकरण माँगें कि [नोड्स](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) और [माइनर्स](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) की भूमिकाएँ अलग-अलग क्यों होती हैं।

इसके बाद **मॉड्यूल 2** की विद्यार्थी मार्गदर्शिका के समापन प्रश्न का उपयोग करें। ऊपर दिए गए मॉड्यूल के अंत में संक्षिप्त चिंतन के मार्गदर्शन का पालन करते हुए, उत्तर को निजी या वैकल्पिक रखें।

अगले मॉड्यूल से जुड़ाव:

> बिटकॉइन किसी खाता संचालक पर निर्भरता कम कर सकता है, लेकिन प्रत्यक्ष नियंत्रण कुंजियों, सत्यापन, पुनर्प्राप्ति और सुरक्षित निर्णयों पर निर्भर करता है। **मॉड्यूल 3** उस ज़िम्मेदारी को व्यवहार में उतारता है।
