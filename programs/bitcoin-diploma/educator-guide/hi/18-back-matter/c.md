# परिशिष्ट C: व्यावहारिक प्रदर्शन की सुरक्षा योजना

| विवरण | योजना |
| --- | --- |
| प्रदर्शन का उद्देश्य और दक्षता |  |
| टूल, संस्करण, स्रोत और जाँच की तारीख |  |
| नेटवर्क और भुगतान का मार्ग |  |
| अभिरक्षा और पुनर्प्राप्ति का मॉडल |  |
| शामिल वास्तविक धनराशि, यदि कोई हो |  |
| अधिकतम नुकसान और उसके स्वीकार्य होने का कारण |  |
| उपयोग किया गया काल्पनिक या पहले से तैयार डेटा |  |
| निजी डेटा जो कभी भी दिखाई नहीं देना चाहिए |  |
| अपेक्षित क्रम और परिणाम |  |
| प्रदर्शित की जाने वाली विफलता की स्थितियाँ |  |
| तुरंत रोकने की स्थितियाँ |  |
| शिक्षक द्वारा पुनर्प्राप्ति या रीसेट की प्रक्रिया |  |
| बिना धनराशि वाला या मुद्रित वैकल्पिक उपाय |  |
| सुगम्यता के लिए अनुकूलन |  |
| उपयोग के बाद डिवाइस से डेटा हटाना |  |
| घटना या बाल-बाल टली घटना का रिकॉर्ड |  |
