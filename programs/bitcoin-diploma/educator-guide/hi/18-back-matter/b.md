# परिशिष्ट B: मॉड्यूल की पाठ-योजना का प्रारूप

| विवरण | योजना |
| --- | --- |
| मॉड्यूल, तिथि और शिक्षार्थी समूह |  |
| मार्गदर्शक प्रश्न |  |
| मूल्यांकन की जाने वाली आवश्यक दक्षता और दक्षता मानदंडों की पहचान संख्याएँ |  |
| शिक्षार्थी का प्रारंभिक स्तर |  |
| प्रमुख शब्द और अनुवाद संबंधी टिप्पणियाँ |  |
| स्थानीय तथ्य और उनकी जाँच की तिथि |  |
| आरंभिक पुनःस्मरण या चिंतन |  |
| संक्षिप्त व्याख्या |  |
| मुख्य संवाद या गतिविधि |  |
| संभावित गलत धारणा |  |
| प्रदर्शन और उसे रोकने की शर्तें |  |
| सहायता के साथ अभ्यास |  |
| कुछ तैयार करने या सीखने का प्रमाण प्रस्तुत करने का कार्य |  |
| शिक्षण संसाधन से वैकल्पिक जुड़ाव |  |
| सुगम्यता के लिए अनुकूलन |  |
| ऑफ़लाइन वैकल्पिक व्यवस्था |  |
| गतिविधि के बाद चर्चा के प्रश्न |  |
| पुनरावलोकन और अगले मॉड्यूल से जुड़ाव |  |
| मूल्यांकन या सीखने के प्रमाण का अभिलेख |  |
| अनुवर्ती कार्य और पुनर्मूल्यांकन |  |
