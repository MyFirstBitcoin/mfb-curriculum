# 16.3 एक शिक्षक के रूप में चिंतन करें

जब तक पाठ्यक्रम की यादें ताज़ा हैं, यह समीक्षा पूरी करें:


| प्रश्न | टिप्पणियाँ और कार्रवाई |
| --- | --- |
| किस दक्षता के लिए नियोजित समय से अधिक या कम समय लगा? |  |
| कौन-सी गलतफ़हमी बार-बार सामने आई? |  |
| किन शिक्षार्थियों की आवाज़ें सबसे कम सुनी गईं? |  |
| किस स्थानीय उदाहरण से शिक्षार्थियों की समझाने, तुलना करने या कार्य करने की क्षमता बेहतर हुई? |  |
| कौन-सा उदाहरण राजनीतिक, प्रचारात्मक या बहुत अधिक व्यक्तिगत हो गया? |  |
| किस गतिविधि से उपयोगी साक्ष्य मिले? |  |
| किस गतिविधि से भ्रामक सरलीकरण हुआ? |  |
| क्या व्यावहारिक गतिविधियों को रोकने की सभी शर्तें प्रभावी रहीं? |  |
| क्या कोई उपकरण, लिंक, शुल्क, नियम या सूचीबद्ध जानकारी पुरानी पड़ गई? |  |
| मूल्यांकन के किस निर्णय की मानकों में एकरूपता सुनिश्चित करने के लिए समीक्षा आवश्यक है? |  |
| सुगम्यता या भाषा से संबंधित किस अनुकूलन को बनाए रखना चाहिए? |  |
| अगले शिक्षार्थी समूह से पहले क्या बदलेगा? |  |
