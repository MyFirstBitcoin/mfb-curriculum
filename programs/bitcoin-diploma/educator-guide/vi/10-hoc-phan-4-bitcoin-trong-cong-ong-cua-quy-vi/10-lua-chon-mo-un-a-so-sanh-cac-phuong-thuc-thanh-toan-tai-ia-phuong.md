# 10.10 Lựa chọn mô-đun A: so sánh các phương thức thanh toán tại địa phương

**Mục đích:** So sánh toàn bộ lộ trình của một khoản thanh toán tại địa phương bằng phương thức hiện có, một lộ trình trên chuỗi và một lộ trình qua Lightning khi phù hợp.

**Chuẩn bị:** Sử dụng số tiền thanh toán và người nhận giả định nhưng sát thực tế. Chuẩn bị thông tin tại địa phương có ghi rõ ngày tháng về phí, quy đổi, thời gian, [lưu ký](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) và khả năng tiếp cận. Nếu không thể xác minh dữ liệu, hãy ghi rõ đó là dữ liệu giả định.

**Nhiệm vụ của học viên:** Hoàn thành:


| Tiêu chí | Phương thức hiện có | Bitcoin trên chuỗi | Lightning, nếu phù hợp |
| --- | --- | --- | --- |
| Số tiền gửi |  |  |  |
| Tổng số tiền nhận được |  |  |  |
| Thời gian và kỳ vọng về việc hoàn tất thanh toán |  |  |  |
| Phí và chênh lệch tỷ giá |  |  |  |
| Lưu ký ở từng giai đoạn |  |  |  |
| Danh tính và quyền riêng tư |  |  |  |
| Đảo ngược giao dịch hoặc hoàn tiền |  |  |  |
| Điểm dễ xảy ra sự cố nhất |  |  |  |
| Hỗ trợ hoặc pháp luật tại địa phương |  |  |  |


**Thực hành:** Học viên chọn một lộ trình cho tình huống giả định, trình diễn hoặc sắp xếp trình tự các bước yêu cầu thanh toán và xác minh tương ứng, đồng thời giải thích vì sao lộ trình còn lại có thể tốt hơn khi một điều kiện thay đổi.

**Thảo luận tổng kết:** Bitcoin đã cải thiện toàn bộ lộ trình hay chỉ một bước dễ thấy? Ai chịu rủi ro về biến động giá, quy đổi, [lưu ký](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) và sự cố?

**An toàn:** Không yêu cầu chuyển tiền thật hoặc nêu tên nhà cung cấp cụ thể. Sử dụng thông tin thanh toán được in trên giấy.
