| --- | --- |
| Mục đích trình diễn và năng lực cần đạt |  |
| Công cụ, phiên bản, nguồn và ngày kiểm tra |  |
| Mạng và tuyến thanh toán |  |
| Mô hình lưu ký và khôi phục |  |
| Giá trị thực được sử dụng, nếu có |  |
| Mức tổn thất tối đa và lý do có thể chấp nhận |  |
| Dữ liệu giả định hoặc được chuẩn bị sẵn để sử dụng |  |
| Dữ liệu riêng tư tuyệt đối không được xuất hiện |  |
| Trình tự và kết quả dự kiến |  |

| Điều chỉnh để bảo đảm khả năng tiếp cận |  |
| Xóa dữ liệu trên thiết bị sau khi sử dụng |  |
