# 4.7 Bản ghi xác minh cục bộ

Hãy điền một hàng cho mỗi thông tin thực tế, dịch vụ hoặc nguồn lực được sử dụng trong lớp có thể thay đổi.


| Hạng mục | Tại sao quan trọng | Nguồn thông tin hoặc chuyên gia địa phương | Ngày kiểm tra | Những gì có thể thay đổi | Cách diễn đạt trong lớp hoặc phương án thay thế |
| --- | --- | --- | --- | --- | --- |
| Các quy định về tiền tệ và thanh toán tại địa phương | Thảo luận trong Học phần 1 |  |  |  |  |
| Quy định về ngân hàng và bảo vệ tiền gửi | Phần về dự trữ một phần |  |  |  |  |
| Thước đo lạm phát chính thức và giỏ hàng hóa, dịch vụ | Hoạt động về sức mua |  |  |  |  |
| Tình trạng hoặc thiết kế của CBDC | So sánh với bối cảnh địa phương (tùy chọn) |  |  |  |  |
| Ví hoặc công cụ thanh toán | Thực hành trong Học phần 3 hoặc 4 |  |  |  |  |
| Phí, chênh lệch giá mua bán và hạn mức | So sánh các phương thức tiếp cận tại địa phương |  |  |  |  |
| Bối cảnh pháp lý, thuế, quyền riêng tư hoặc nghĩa vụ báo cáo | Học phần về địa phương |  |  |  |  |
| Đơn vị bán hàng, bản đồ, buổi gặp mặt hoặc nguồn hỗ trợ | Khám phá cộng đồng |  |  |  |  |


Hãy ưu tiên các nguồn sơ cấp có thẩm quyền khi tra cứu quy định hiện hành. Nếu bằng chứng chưa đầy đủ, hãy nêu rõ điều đó. Không biến thông tin địa phương chưa chắc chắn thành một khẳng định đúng ở mọi nơi.
