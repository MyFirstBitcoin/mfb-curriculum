# 16.3 Suy ngẫm với vai trò nhà giáo dục

Quý vị hãy hoàn thành phần nhìn lại này khi nội dung khóa học vẫn còn mới trong trí nhớ:


| Câu hỏi | Ghi chú và hành động |
| --- | --- |
| Việc phát triển năng lực nào mất nhiều hoặc ít thời gian hơn dự kiến? |  |
| Quan niệm sai lầm nào xuất hiện nhiều lần? |  |
| Tiếng nói của những học viên nào ít được lắng nghe nhất? |  |
| Ví dụ nào tại địa phương đã giúp học viên giải thích, so sánh hoặc thực hành tốt hơn? |  |
| Ví dụ nào đã trở nên mang tính chính trị, quảng bá hoặc quá riêng tư? |  |
| Hoạt động nào đã tạo ra minh chứng hữu ích? |  |
| Hoạt động nào đã đơn giản hóa vấn đề đến mức gây hiểu lầm? |  |
| Tất cả các điều kiện dừng hoạt động thực hành có phát huy hiệu quả không? |  |
| Có công cụ, liên kết, mức phí, quy định hoặc thông tin niêm yết nào đã lỗi thời không? |  |
| Nhận định đánh giá nào cần được rà soát để bảo đảm tính nhất quán? |  |
| Điều chỉnh nào về khả năng tiếp cận hoặc ngôn ngữ cần được duy trì? |  |
| Điều gì sẽ thay đổi trước khóa học tiếp theo? |  |
