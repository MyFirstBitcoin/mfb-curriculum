# 8.21 Ôn tập và chuyển tiếp sang Học phần 3

Yêu cầu học viên hoàn thành:


| Vấn đề của hệ thống tiền pháp định | Cách Bitcoin giải quyết | Trách nhiệm mới hoặc sự đánh đổi |
| --- | --- | --- |
| Nguồn cung có thể thay đổi thông qua chính sách |  |  |
| Các khoản thanh toán phụ thuộc vào bên trung gian |  |  |
| Một bên giữ sổ cái kiểm soát các bản ghi |  |  |
| Khả năng tiếp cận phụ thuộc vào một tổ chức |  |  |


Yêu cầu giải thích rõ vì sao [các nút](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) và [thợ đào](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) có vai trò khác nhau.

Tiếp theo, hãy sử dụng **Mô-đun 2** – câu hỏi kết thúc trong Tài liệu học viên. Giữ câu trả lời ở chế độ riêng tư hoặc để học viên tùy chọn trả lời, theo hướng dẫn suy ngẫm nhẹ nhàng khi kết thúc mô-đun ở trên.

Chuyển tiếp:

> Bitcoin có thể giảm sự phụ thuộc vào bên vận hành tài khoản, nhưng quyền kiểm soát trực tiếp phụ thuộc vào khóa, việc xác minh, khả năng khôi phục và những quyết định an toàn. **Mô-đun 3** đưa trách nhiệm đó vào thực hành.
