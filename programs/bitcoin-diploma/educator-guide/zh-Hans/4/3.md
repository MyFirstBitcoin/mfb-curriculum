# 4.3 可重复使用的两小时模块节奏

请将此作为规划模式使用，而非一成不变的脚本。


| 时间 | 目的 | 教育者行动 |
| --- | --- | --- |
| 0–10 分钟 | 欢迎与回顾 | 就先前所学提出一个简短问题，并让学员说出仍不确定之处。 |
| 10–30 分钟 | 第一个概念 | 简要讲解，使用图示或本地实例，并引导学员作出可观察的回应。 |
| 30–55 分钟 | 主要互动 | 组织一项比较、游戏、情境、角色图、演示或指导练习。 |
| 55–65 分钟 | 总结讨论 | 将体验与能力目标联系起来；纠正活动未能体现的内容。 |
| 65–80 分钟 | 第二个概念或演示 | 引入下一个核心概念，并在适当时示范完整流程。 |
| 80–105 分钟 | 练习与产出 | 学员在逐步减少的支持下进行应用、决策、解释或操作。 |
| 105–115 分钟 | 学习检查或实践证据 | 收集形成性反馈，请学员作出与能力目标相符、供教育者评判的回应，或观察一项实践技能。 |
| 115–120 分钟 | 复习与衔接 | 点明关键收获、尚未解决的问题，以及与下一模块的联系。 |


实践观察所需的时间往往超出此模式所能提供的时间。对于**模块 3**和**模块 4**，请在课程安排内规划分站活动、增派一名教育者或采用更小的分组。若您无法看清每位学员的决策和安全行为，请勿同时评估多名学员。

此模式并未规定由教育者主导的评估需要多少时间。请在课程安排中为个人证据、反馈、重新评估和记录预留充足时间。可选的形成性复习可以促进学习，且不会改变评估安排。
