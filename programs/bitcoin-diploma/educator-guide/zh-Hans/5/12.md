# 5.12 媒体与工具的备用方案

《学生指南》包含比特币文凭课程所需的定义、比较、安全规则和复习题。补充学习链接及用于访问这些链接的二维码均为可选内容。它们可能提供更新信息、回顾材料、源文件或交流渠道。学员无需使用这些补充资源即可完成课程。

如果经批准的等效途径能够保证能力的达成，那么任何必修的比特币文凭讲解、教师形成性检查、练习活动或直接观察的实践证据，都不应依赖于视频、在线网站、特定服务或学员自有设备。

当演示需要联网时，请尽可能准备离线替代方案，例如打印的钱包界面、交易情景、卡片练习或分步讨论。网络连接失败不应中断教学或准备工作。


| 实时或在线体验 | 离线或低技术等效方案 |
| --- | --- |
| 钱包操作导航 | 按顺序排列的打印钱包界面，或带有预测暂停环节的投影录屏 |
| 发送与接收 | 地址卡或发票卡、金额卡，以及纸质交易流程 |
| 二维码扫描 | 打印的示例付款信息及视觉对比 |
| 区块浏览器 | 预先准备的公开交易的截图，并注明日期 |
| 实时价格、手续费或通胀数据 | 预先准备并注明日期的数据快照，附来源及局限性说明 |
| 商户或社区地图 | 打印的本地地图及经核实的示例商户列表 |
| 闪电网络支付 | 发票卡及路由支付情景 |
| 视频 | 配有讲解的图示、故事板或教师讲解 |
| 实时交易 | 模拟、测试环境、空的培训钱包或教师演示 |


离线教学和评估同样有效。在网络连接受限时，请使用离线知识检查、打印活动、角色扮演和模拟练习。可选的形成性复习不属于认证内容。
