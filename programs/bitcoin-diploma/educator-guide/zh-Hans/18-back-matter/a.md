# 附录A：单页课程准备清单

### 课程内容

* [ ] 我能够阐述四个模块的整体脉络以及对学员的承诺。
* [ ] 我已审阅每一项必修考核能力、其能力标准及证据类型。
* [ ] 我了解全部四个模块均为 Bitcoin Diploma 的必修学习内容，也清楚我可以如何调整**模块 3**、如何精选**模块 4**的内容，以及哪些内容属于[进阶学习](https://curriculum.myfirstbitcoin.org/programs/advanced-modules/)。
* [ ] 我已在适当情况下查阅[活动库](https://curriculum.myfirstbitcoin.org/activities/en/)，并围绕明确的能力目标选择活动，而非仅为娱乐。
* [ ] 我已为每个模块准备了复习和衔接环节。

### 学员与参与条件

* [ ] 我了解该学员群体的语言、读写能力、计算能力及设备条件等前提情况。
* [ ] 无障碍需求和相应便利措施已安排妥当。
* [ ] 学员可以使用虚构情境，而无需披露个人隐私。
* [ ] 课程安排包含练习、考核、反馈和重新考核。

### 本地背景

* [ ] 本地法定货币体系和银行业信息为最新信息，且注明来源。
* [ ] 已核查官方[通货膨胀](https://curriculum.myfirstbitcoin.org/lexicon/en/#inflation)衡量指标及其商品篮子。
* [ ] [央行数字货币（CBDC）](https://curriculum.myfirstbitcoin.org/lexicon/en/#cbdc)相关说法为最新信息，且针对具体设计方案。
* [ ] 本地工具、费用、服务、资源和列表均已注明日期。
* [ ] 法律、税务、隐私和申报方面的背景介绍不构成任何建议。
* [ ] 任何本地专家都能说明不得推广及隐私保护的界限。

### 安全与技术

* [ ] 任何任务都不要求学员提供真实的[助记词](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase)、密钥、凭证、余额或历史记录。
* [ ] 培训用设备和钱包已准备就绪并已重置。
* [ ] 示例付款信息已标注为**「示例——请勿付款」**。
* [ ] 现场演示已进行端到端测试。
* [ ] 中止条件和上报步骤清晰明确。
* [ ] 每项依赖现场或网络的环节都有低技术替代方案。
* [ ] 设备、电源、网络、充电和场地安排均已就绪。

### 考核

* [ ] 用于考核的活动能让学员获得清晰、公平的机会来展示每项能力。
* [ ] 我已考虑学员人数、可用时间、提问、故障排除、反馈和重新考核等因素。
* [ ] 在我作出最终判断之前，学员将获得有指导的练习机会。
* [ ] 我知道应关注哪些表现、如何提出有帮助的追问，以及何时记录**「是」**或**「尚未达到」**。
* [ ] 已在需要时准备好线上、低技术和无障碍方案。
* [ ] 所有记录均保护[隐私](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)，并仅保留最低限度的必要信息。
* [ ] 我知道如何恰当地颁发参与证书或结业证书。
* [ ] 我在使用[证书工具](https://tools.myfirstbitcoin.org/certificate)之前已确认每位学员的结果，并将在发放前核对证书信息。
