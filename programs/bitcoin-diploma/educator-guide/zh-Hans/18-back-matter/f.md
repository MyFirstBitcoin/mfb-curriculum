# 附录F：课程实施路线图示例

### 四节课课程


| 课次 | 主要重点 | 核心互动 | 证据规划 |
| --- | --- | --- | --- |
| 1 | 理解货币 | 开场提问、货币属性比较、本地法定货币与购买力讨论 | 由教育者主导的模块1理论证据 |
| 2 | 比特币如何运作 | 双重支付情景、角色图、供应量与稳健货币比较 | 由教育者主导的模块2理论证据 |
| 3 | 安全使用比特币 | 保管、公开/秘密信息、恢复、接收/发送、区块浏览器、诈骗及后续路径练习 | 由教育者主导的理论证据及直接实践观察 |
| 4 | 连接：您所在社区中的比特币 | 经批准的本地PPP模块、与先前学习内容的联系以及最终反思 | 由教育者观察的C7，包括C7.1/C7.2；形成性F2反思；任何重新评估 |


此模式通常需要额外的实践评估时间。

### 八节课课程


| 课次 | 重点 |
| --- | --- |
| 1 | 货币为何存在；职能、属性、以物易物与选择 |
| 2 | 货币历史、本地法定货币体系、银行业、通货膨胀、央行数字货币（CBDC）及复习 |
| 3 | 数字货币问题、比特币的目的、角色与去中心化 |
| 4 | 工作量证明、供应量、聪（sats）、稳健货币比较、范围及复习 |
| 5 | 钱包、地址、密钥、助记词、保管及恢复练习 |
| 6 | 接收、发送、确认、区块浏览器、隐私、诈骗、后续路径及实践评估 |
| 7 | 本地需求、工具/路径比较、展示及有指导的模块4练习 |
| 8 | 模块4成果制作、评估、最终反思、补救及后续步骤 |


### 一日强化课程

仅在学员群体和场地条件能够支持持续学习时使用。请确保休息时间，并将实践评估纳入已公布的课程时间表之内。


| 时段 | 重点内容 |
| --- | --- |
| 开场 | 课程期望、评估说明、关于货币的提问 |
| 上午第一节 | 货币基础与货币属性活动 |
| 上午第二节 | 法定货币、银行业务、购买力及第1模块复习 |
| 中午第一节 | 比特币要解决的问题、各方角色、工作量证明、供应量及聪 |
| 中午第二节 | 稳健货币比较及责任衔接 |
| 下午第一节 | 托管、秘密信息、恢复，以及接收与发送练习 |
| 下午第二节 | 验证、诈骗、由教育者精选的第4模块「联结」任务及最终反思 |
| 后续跟进 | 任何尚未完成的教育者评估、个人实践观察、对评估结果为「尚未达标」的学员的支持、教育者的形成性辅导，以及认证审核 |


如果必需的观察或评估仍未完成，请勿将压缩式的一日课程描述为已完成。
