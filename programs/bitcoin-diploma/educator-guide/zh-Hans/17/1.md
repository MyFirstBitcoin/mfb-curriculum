# 17.1 术语速览与易生误解的概念辨析

完整定义请参阅术语表。在讲解、幻灯片、活动和评估中，请始终一致地保持以下区分。


| 术语 | 教育者须把握的区别 |
| --- | --- |
| 货币／通货 | 货币是用于交换、记账和跨时间保存价值的更广泛的工具或资产；通货则是某种特定的货币单位或货币体系。 |
| 职能／属性 | 职能是货币所发挥的作用；属性是影响货币能否很好地发挥这些作用的特性。 |
| 稀缺性／价值 | 稀缺性限制了可获得性；价值还取决于用途、需求、偏好、信息和具体情境。 |
| 价格通胀／单一价格上涨 | 通胀是一般价格水平的持续上涨；单一商品的价格可能因多种原因而变化。 |
| 银行存款／实物现金 | 银行存款是银行对储户所负的债权；实物现金则是另一种形式的货币，视司法管辖区不同，由中央银行或国家发行。 |
| 流动性／偿付能力 | 流动性关乎能否及时付款；偿付能力关乎资产能否覆盖负债。 |
| CBDC／比特币 | CBDC是中心化发行的数字法定货币；比特币没有中心化发行方，并采用可独立验证的规则。 |
| 比特币（Bitcoin）／比特币（bitcoin） | 首字母大写的Bitcoin指网络、协议或项目；小写的bitcoin指资产或单位。 |
| 比特币协议／比特币服务 | 协议是共享的规则体系；钱包、交易所、区块浏览器或支付公司则是独立的服务或工具。 |
| 数字签名／加密 | 签名证明密钥授权；加密则隐藏可读内容。 |
| 矿工／节点 | 矿工通过工作量证明提出候选区块；节点负责验证规则。 |
| 开发者提案／规则变更 | 开发者提出软件方案；参与者自行选择是否采用。 |
| 出块时间／时间表 | 约十分钟是长期平均值，而非精确的约定时间。 |
| 有限供应／价格保证 | 可预测的上限是一种供应属性；它并不保证需求或回报。 |
| 稳健货币／事实 | 稳健货币是依据明确标准和权衡取舍作出的判断。 |
| 钱包／比特币存储 | 钱包管理密钥和交易；比特币始终记录在共享账本上。 |
| 地址／私钥 | 地址用于接收；私钥用于授权支出。 |
| 助记词／密码 | 助记词可以重新生成钱包密钥，通常赋予完整的恢复权限；它不是可以重置的普通密码。 |
| 托管／自托管 | 区别在于由谁控制密钥。 |
| 热钱包／冷钱包 | 区别在于密钥是否暴露于联网的通用环境中。 |
| 链上／闪电网络 | 区别在于支付路径，而非托管方式。 |
| 区块浏览器／节点 | 区块浏览器是第三方界面；节点则独立验证规则。 |
| 确认／正确付款 | 确认会增强结算记录的可靠性；但它不会更正收款人，也不会验证付款目的。 |
| 隐私／保密 | 隐私是对信息的掌控；它并不意味着某项活动没有公开数据或不承担法律义务。 |
| KYC／no-KYC | 这两种途径收集的身份信息不同，在客户支持、隐私、交易对手、欺诈和法律方面也带来不同的权衡。请全程统一使用「no-KYC」这一写法。 |
| 本地示例／推荐 | 经过核实的本地示例有助于学习；但它并不代表普遍适用的背书。 |
