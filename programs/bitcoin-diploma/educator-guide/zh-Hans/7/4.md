# 7.4 建议的两小时课程流程

这是一条最低限度的教学路径。当学员群体需要更多经济学背景知识或本地化讨论时，可加以延展。


| 时间 | 学习环节 | 建议方法 |
| --- | --- | --- |
| 0–12 分钟 | 引出已有观念 | 先两人一组讨论开场问题，再进行全班讨论 |
| 12–28 分钟 | 货币为何存在 | 交换情境与随堂提问 |
| 28–45 分钟 | 职能与属性 | 本地实例加货币属性比较 |
| 45–58 分钟 | 物物交换与选择 | 简短的「需求双重巧合」角色扮演情境；稀缺性与机会成本复盘讨论 |
| 58–70 分钟 | 货币史 | 非线性时间轴，并补充本地内容 |
| 70–92 分钟 | 法定货币体系中的角色 | 本地支付流程追踪与机构关系图 |
| 92–105 分钟 | 银行业 | 资产负债表草图，或流动性／偿付能力情境 |
| 105–115 分钟 | 通货膨胀、购买力与央行数字货币（CBDC） | 注明日期的本地证据讨论 |
| 115–120 分钟 | 回顾与衔接 | 「货币可能在……时失灵」解释练习 |


如果课程时间较充裕，可将本模块分为两部分：先讲货币基础，再讲现代货币的利弊权衡。
