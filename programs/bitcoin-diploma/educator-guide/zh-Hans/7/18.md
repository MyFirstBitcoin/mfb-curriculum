# 7.18 常见误解及应对

| 常见误解 | 适合初学者的纠正 | 追问 |
| --- | --- | --- |
| 货币和财富是一回事。 | 货币帮助衡量和交换对有用的商品、服务、时间和资源的索取权；它并不等同于全部财富。 | 一套有用的住房能否是财富，却不是便利的货币？ |
| 价值储藏手段永远不会贬值。 | 价值储藏是一种职能，而非一种保证。每种选择都有其时间跨度和风险。 | 对于现金、黄金或其他资产，有哪些因素可能削弱这一职能？ |
| 以物易物从来行不通。 | 以物易物可以行得通，但在规模扩大后，匹配需求、数量、时间、储存和定价都会变得困难。 | 在反复往来的本地关系中，是什么让以物易物变得更容易？ |
| 稀有就意味着有价值。 | 价值还取决于有用性、需求、信息和具体情境。 | 请举出一样稀有但人们可能并不想要的东西。 |
| 法定货币不过是假钱。 | 法定货币是一种真实的货币安排，由政府权威、机构、法律、普遍接受度和网络效应共同支撑。其规则与利弊权衡可以加以评估。 | 如果法定货币的记录或机构失灵，哪一种本地支付会无法完成？ |
| 银行只会把客户已有的现金贷出去。 | 现代银行发放贷款时，通常会同时创造一笔对应的存款，但受到资本、流动性、监管、融资、风险和需求等方面的约束。 | 发放一笔贷款后，银行的资产和负债中会出现什么？ |
| 部分准备金制度意味着银行在任何地方都保持同一个固定比例。 | 准备金、流动性和资本方面的安排因国家而异，并且可能发生变化。 | 哪一条本地规则需要核实？ |
| 每一次涨价都是印钞造成的通货膨胀。 | 总体通货膨胀是一个平均值，而价格变化可能由多个相互作用的原因引起。 | 还有什么其他原因可能导致这件商品的价格变化？ |
| 官方的商品篮子应当与每个人的切身感受相符。 | 这一指标是平均值；各家庭的消费结构各不相同。 | 在您虚构的家庭中，哪一类支出更为重要？ |
| 每一种CBDC都具有完全相同的监控或控制功能。 | 其功能取决于设计、法律、基础设施和具体实施。 | 哪一项功能已由一手资料证实？ |
