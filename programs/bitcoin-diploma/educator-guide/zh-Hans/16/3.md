# 16.3 作为教育者进行反思

请趁课程记忆犹新时完成以下回顾：


| 问题 | 记录与行动 |
| --- | --- |
| 哪项能力所用时间多于或少于计划？ |  |
| 哪种误解反复出现？ |  |
| 哪些学员的声音最少被听到？ |  |
| 哪个本地示例提升了学员解释、比较或实践的能力？ |  |
| 哪个示例变得带有政治色彩、宣传性质或过于私人化？ |  |
| 哪项活动产生了有用的证据？ |  |
| 哪项活动造成了误导性的简化？ |  |
| 所有实践环节的停止条件是否都有效？ |  |
| 是否有任何工具、链接、费用、规则或列表已经过时？ |  |
| 哪项评估判断需要进行校准审核？ |  |
| 哪些无障碍或语言方面的调整应当保留？ |  |
| 在下一批学员开课前将做出哪些改变？ |  |
