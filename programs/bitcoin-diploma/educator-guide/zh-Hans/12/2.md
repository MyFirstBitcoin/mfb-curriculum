# 12.2 区分稳定的概念与不断变化的事实

| 稳定的课程概念 | 不断变化的本地事实 |
| --- | --- |
| 银行存款是对银行的债权 | 本地存款保险的保障上限与适用条件 |
| 通胀指标采用选定的商品篮子和计算方法 | 当前本地通胀率、篮子权重及发布方法 |
| CBDC是由中央银行发行的法定货币 | 本地中央银行是否正在研究、试点或发行CBDC |
| 托管意味着对密钥的控制 | 某一钱包当前版本的托管模式 |
| 手续费和流动性会影响支付路径 | 当前的手续费估算、服务价差以及闪电网络流动性 |
| KYC与无KYC会带来不同的利弊权衡 | 当前的身份认证规则和法律要求 |
| 地图上的商户信息可能会过时 | 某家本地商户如今是否接受比特币 |


请为不断变化的事实标注日期，并告知学员哪些内容可能发生变化。在准备本地示例时，您可以请[Bitcoin Diploma AI助手](https://ai.myfirstbitcoin.org)建议哪些说法需要核实，以及应寻找哪些证据。请您亲自查阅原始资料，确认其能够支持每一项说法，并记录来源和日期；AI的回答并不能证明某一事实仍然有效。
