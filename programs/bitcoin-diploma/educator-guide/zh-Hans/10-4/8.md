# 10.8 本地比特币工具评测

请勿仅因某工具在当地流行就进行演示。请使用以下对比：


| 方面 | 问题 |
| --- | --- |
| 用途 | 该工具解决什么问题？是否确有需要？ |
| 托管 | 谁控制密钥和资金？ |
| 来源 | 由谁发布？如何核实其来源真实可靠？ |
| 代码与维护 | 是否开源、经过审查、持续维护并安全更新？ |
| 恢复 | 如果设备、服务或公司不复存在，会发生什么？ |
| 隐私 | 会收集哪些身份、联系方式、设备、位置和交易数据？ |
| 费用 | 涉及哪些明面费用、价差、订阅费、充值成本和提现成本？ |
| 兼容性 | 支持哪些网络、地址类型、发票、备份和设备？ |
| 支持 | 学员能否在不泄露机密信息的情况下获得帮助？ |
| 法律与记录 | 哪些当地限制、消费者保护规定、税务、会计或申报义务可能相关？ |
| 替代方案 | 如果该工具失效或无法使用，学员可以改用什么？ |



> **Dark – 本地示例并非全球推荐**
>
> 此工具是一个有时效性的本地学习示例。在课堂上使用它并不代表 My First Bitcoin 在全球范围内推荐该工具，也不保证它将始终适用。
