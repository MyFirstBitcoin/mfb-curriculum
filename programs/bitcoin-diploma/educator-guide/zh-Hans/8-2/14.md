# 8.14 比特币：稳健的数字货币

请回到**第1单元**中使用的那些货币属性。要求学员提供证据并说明限定条件。


| 属性 | 对教师有用的提问 | 重要的限定条件 |
| --- | --- | --- |
| 耐久性 | 如果某一台设备损坏，还有什么能够保留下来？ | 能否访问仍取决于有效的密钥和恢复手段。 |
| 便携性 | 转移价值需要具备哪些条件？ | 设备、通信、正确的信息、手续费以及收款方的接收能力仍然很重要。 |
| 可分割性 | 聪如何支持小额金额？ | 单位很小并不能保证每一种支付渠道都经济划算。 |
| 可替代性 | 等量的协议单位是否按照相同的规则花费？ | 公开的交易历史可能会影响服务机构对待特定资金的方式。 |
| 稀缺性 | 由谁来核查发行上限？ | 供应有限并不能保证需求或价格。 |
| 可验证性 | 节点可以独立核查哪些内容？ | 许多初学者仍然依赖钱包或区块浏览器的界面。 |
| 可接受性 | 比特币实际上可以在哪里使用？ | 接受程度因社区不同而差异很大。 |


请将[**稳健货币**](https://curriculum.myfirstbitcoin.org/lexicon/en/#sound-money)视为基于标准得出的结论。学员可能会得出这样的结论：在其所处的环境中，比特币在某些标准上表现突出，而在另一些标准上表现较弱。

请区分：

* 观察到的市场[价格](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)
* 在当地的实用性或接受程度
* 个人的[主观价值](https://curriculum.myfirstbitcoin.org/lexicon/en/#subjective-value)；以及
* 个人的认可。
