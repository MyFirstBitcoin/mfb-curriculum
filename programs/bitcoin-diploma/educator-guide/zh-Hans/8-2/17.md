# 8.17 比特币特性常见问题

| 属性 | 学员提问 | 适合初学者的回答 |
| --- | --- | --- |
| 稀缺性 | 「难道就没人能造出超过2100万枚比特币吗？」 | 有人可以编写不同的软件，但参与者没有义务运行它。遵循比特币规则的节点会拒绝超额发行。如果不兼容的规则被广泛采用，可能会形成一个独立的网络；但没有任何创始人、矿工、开发者、公司或政府能够悄无声息地为所有人创造出额外的有效比特币。 |
| 稀缺性 | 「供应有限是否意味着价格一定会上涨？」 | 不是。价格既取决于供应，也取决于需求，而需求可能下降。有限供应是一种货币属性，而不是收益保证。 |
| 可分割性 | 「如果总量只有2100万枚，够所有人用吗？」 | 一枚比特币可分割为100000000聪（sats）。更小的单位让人们能够表示小额数量，而不会增加总供应量。 |
| 可分割性 | 「我需要买一整枚比特币吗？」 | 不需要。学员无需拥有一整枚比特币，也可以讲解或使用聪，而且获得Bitcoin Diploma并不要求持有比特币。 |
| 耐久性 | 「如果我的手机坏了怎么办？」 | 比特币并不存储在手机里。网络记录会持续存在，但能否访问取决于密钥的安全保管和恢复手段。设备丢失后可能可以恢复；但恢复信息一旦丢失或泄露，就可能造成永久损失。 |
| 便携性 | 「我可以无条件地把它发送到任何地方吗？」 | 一笔有效的转账不需要获得某个中央比特币运营方的批准，但仍需要合适的钱包、通信连接、正确的支付信息、手续费，以及一个能够接收的收款方。当地法律和服务也可能附加限制。 |
| 可替代性 | 「每一聪都完全相同吗？」 | 等额资金遵循相同的协议花费规则，但公开的交易历史可能会影响某些服务或个人对待特定资金的方式。 |
| 可验证性 | 「我必须信任某个网站吗？」 | 区块浏览器是一种便捷的第三方界面。节点能够实现更强的独立验证，而初学者可能仍需依赖钱包或服务提供的信息，并应意识到这种依赖关系。 |
| 可接受性 | 「如果比特币有用，为什么我不能在所有地方使用它？」 | 技术上的能力并不会带来普遍的接受度。当地习惯、工具、成本、监管、价格波动、教育和商家需求都会影响其使用。 |
| 去中心化 | 「比特币是完全去中心化的吗？」 | 影响力和基础设施并非均匀分布。更严谨的说法是：没有任何单一参与者能够单方面为所有人更改有效余额或规则。 |
| 可信的稀缺性 | 「为什么不复制代码再造一种币呢？」 | 复制代码或写入供应上限都是可以做到的。但可信的执行、独立验证、安全性、历史记录、网络采用度以及抵御单方面更改的能力，则是另外的问题。 |
