# 8.4 建议的两小时课程流程

| 时间 | 学习环节 | 建议方法 |
| --- | --- | --- |
| 0–10分钟 | 回顾模块1 | 说出一个货币问题及其带来的权衡 |
| 10–27分钟 | 为何去中心化数字货币曾难以实现 | 数字复制与双重支付情境 |
| 27–42分钟 | 比特币的综合解决方案 | 流程图：授权、广播、挖矿、验证、共享历史记录 |
| 42–62分钟 | 角色与去中心化 | 用户/节点/矿工/开发者角色任务 |
| 62–77分钟 | 工作量证明 | 「生成成本高、验证速度快」演示 |
| 77–92分钟 | 供应量、减半与聪 | 发行模型与单位偏差检验 |
| 92–110分钟 | 稳健货币比较 | 沿用模块1中的属性；补充优势与权衡 |
| 110–117分钟 | 范围与责任 | 比特币与稳定币/其他资产的比较；学习与投机的区别 |
| 117–120分钟 | 复习与衔接 | 法币问题 → 比特币的解决方案 → 新的责任 |
