# 9.22 模块3综合实践循环练习

请在学员了解每个流程之后再使用这些练习站。


| 练习站 | 学员任务 | 安全重点 |
| --- | --- | --- |
| 1. 钱包与托管 | 确认由谁控制密钥，并找到收款功能 | 不要仅凭「钱包」一词推断托管方式 |
| 2. 公开信息还是机密信息 | 对付款信息和恢复信息进行分类 | 切勿泄露真实的机密信息 |
| 3. 收款 | 生成或找到一个预先准备好的收款请求，并识别其付款路径 | 只分享收款信息 |
| 4. 付款 | 核对收款人、网络、目标地址、金额、单位、手续费和最终摘要 | 发现任何不一致时立即停止 |
| 5. 恢复 | 排列或完成一项预先准备好的恢复准备任务 | 私下操作；不得使用存有真实资金的助记词 |
| 6. 区块浏览器 | 读取预先准备好的交易状态和公开数据 | 认识区块浏览器的隐私问题和局限性 |
| 7. 诈骗 | 应对一个紧急的客服请求或更改地址的请求 | 暂停操作并独立核实 |
| 8. 途径 | 比较两种当地的获取或付款途径 | 不作任何推荐或建议 |


除非具体任务、变体、评估标准和记录均已获批准，否则请勿将这些练习站用作正式评估。
