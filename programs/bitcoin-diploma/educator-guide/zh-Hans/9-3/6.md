# 9.6 建议授课顺序

如条件允许，请将课程分为两个学习部分，并另设独立的评估时段。

#### A部分：托管基础


| 时间 | 学习环节 | 建议方法 |
| --- | --- | --- |
| 0–10分钟 | 确立安全约定 | 开场检查：公开信息与秘密信息 |
| 10–25分钟 | 钱包与托管 | 演示「钱包是一个界面」 |
| 25–40分钟 | 地址、密钥与助记词 | 卡片分类与讲解 |
| 40–58分钟 | 托管型、自托管型、热钱包、冷钱包与硬件钱包 | 情境比较 |
| 58–80分钟 | 恢复准备 | 教师讲解、引导式模拟、总结讨论 |
| 80–105分钟 | 接收 | 接收界面逐步讲解与学员练习 |
| 105–120分钟 | 复习 | 说明哪些信息可以分享、哪些必须保密，以及谁掌控密钥 |


#### B部分：验证与安全


| 时间 | 学习环节 | 建议方法 |
| --- | --- | --- |
| 0–15 分钟 | 回顾保管规则 | 安全情景 |
| 15–40 分钟 | 发送与验证 | 教师演示并请学员预测 |
| 40–58 分钟 | 确认与区块浏览器 | 查询预先准备的交易 |
| 58–73 分钟 | 地址历史与地址重复使用 | 预先准备的公开地址活动 |
| 73–93 分钟 | 诈骗与不可逆的错误 | 情景练习站 |
| 93–108 分钟 | 获取途径 | 风险图比较 |
| 108–120 分钟 | 链上与闪电网络 | 支付路径分类及「停止／寻求帮助」回顾 |


仅在有指导的练习之后再安排正式观察。
