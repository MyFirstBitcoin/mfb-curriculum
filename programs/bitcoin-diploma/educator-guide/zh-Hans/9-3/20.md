# 9.20 链上支付与闪电网络支付

请使用一种将支付路径与[托管方式](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody)区分开来的对比方式。


| 问题 | 链上 | 闪电网络 |
| --- | --- | --- |
| 结算记录在哪里？ | 直接记录在比特币区块链中 | 支付更新通过构建在比特币之上的网络进行；通道最终依赖于比特币 |
| 初学者常用的收款信息 | 链上地址 | 发票、受支持的闪电地址或其他经认可的收款请求类型 |
| 典型用途 | 基础层结算，通常用于金额较大或频率较低的转账 | 通常用于小额或频繁的支付，前提是当地工具和流动性能够支持 |
| 时间 | 首次确认取决于交易何时被打包进区块 | 通常很快，但支付可能失败 |
| 费用与容量 | 取决于交易数据量和区块空间需求 | 取决于钱包、路由、流动性、服务及支付条件 |
| 托管 | 可以是托管式，也可以是自托管 | 可以是托管式，也可以是自托管 |
| 初学者主要检查事项 | 地址、网络、金额、费用和确认情况是否正确 | 发票或收款目标、金额、有效期、费用和支付结果是否正确 |


闪电网络并不是一种独立的币。一次成功的闪电支付并不能证明该钱包适合存放更大的余额。通道运营、路由基础设施和[流动性](https://curriculum.myfirstbitcoin.org/lexicon/en/#lightning-liquidity)管理属于[进阶学习](https://curriculum.myfirstbitcoin.org/programs/advanced-modules/)内容，不在 Bitcoin Diploma 的范围之内。
