# 9.23 常见误解及应对

| 误解 | 适合初学者的纠正说明 | 检验问题 |
| --- | --- | --- |
| 比特币存储在钱包应用里。 | 比特币记录在共享账本上；钱包管理的是密钥和交易信息。 | 如果手机坏了，还会留下什么？ |
| 地址是一个秘密密码。 | 地址是公开的收款信息，不过将其与身份关联可能会降低隐私。 | 哪些信息能够授权花费？ |
| 任何二维码都是安全的，因为是钱包扫描的。 | 二维码可能编码了错误的目标或请求。请核实收款人、支付路径、金额以及最终确认界面。 | 扫描之后，您会核对哪些内容？ |
| 分享地址会让别人能够花费您的资金。 | 花费通常需要私钥。但分享地址仍可能暴露交易之间的关联。 | 还存在什么隐私风险？ |
| 助记词就是普通的密码。 | 对许多钱包而言，它就是完整的恢复权限。任何拥有它的人都可能重建密钥。 | 正规的客服会需要它吗？ |
| 教育者应该检查我的助记词备份。 | 教育者可以观察安全的操作流程，而无需看到助记词本身。 | 您如何在保密的同时证明自己已准备就绪？ |
| 所有钱包都是自托管的。 | 有些被称为钱包的应用会替用户保管密钥。 | 由谁批准提现、由谁掌控恢复？ |
| 硬件钱包消除了备份风险。 | 设备能隔离密钥，但恢复仍然依赖于受保护的备份和正确的使用。 | 如果设备坏了会怎样？ |
| 一次确认就能让每笔支付都安全。 | 确认会增强结算记录的可靠性；但无法挽回错误的目标地址或诈骗。 | 在批准之前必须进行哪些检查？ |
| 区块浏览器就是比特币。 | 它是访问公开数据的第三方界面。 | 节点能提供什么更可靠的验证？ |
| 手续费主要取决于发送了多少bitcoin。 | 链上手续费主要取决于交易数据量和区块空间的需求。 | 小额支付是否仍可能产生高额手续费？ |
| 闪电网络总是意味着自托管且没有手续费。 | 闪电钱包可能是托管的，也可能是自托管的；路由、服务或流动性状况都可能产生手续费或导致支付失败。 | 您应该分别提出哪两个问题？ |
| KYC总是安全的，或者无KYC总是安全的。 | 每种途径都是在身份、支持服务、交易对手、欺诈、法律和隐私等风险之间进行取舍。 | 哪种风险降低了，又增加了哪种风险？ |
