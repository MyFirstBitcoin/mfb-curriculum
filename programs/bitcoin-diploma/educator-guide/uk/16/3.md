# 16.3 Поміркуйте як викладач

Проведіть цей аналіз, поки враження від курсу ще свіжі:


| Запитання | Нотатки та дії |
| --- | --- |
| На формування якої компетентності пішло більше або менше часу, ніж планувалося? |  |
| Яке хибне уявлення виникало неодноразово? |  |
| Думки яких учасників навчання звучали найрідше? |  |
| Який приклад із місцевого контексту допоміг учасникам навчання краще пояснювати, порівнювати або виконувати певні дії? |  |
| Який приклад набув політичного, рекламного або надто особистого характеру? |  |
| Яка навчальна вправа дала корисні свідчення результатів навчання? |  |
| Яка навчальна вправа призвела до спрощення, що вводить в оману? |  |
| Чи всі умови припинення практичної роботи були дієвими? |  |
| Чи втратили актуальність якісь інструменти, посилання, комісії, правила або записи в переліках? |  |
| Яке рішення щодо оцінювання потребує узгодження з іншими викладачами? |  |
| Яку адаптацію для забезпечення доступності або мовну адаптацію слід зберегти? |  |
| Що зміниться до початку навчання наступної групи? |  |
