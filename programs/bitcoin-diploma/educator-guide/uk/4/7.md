# 4.7 Запис про локальну перевірку

Заповніть окремий рядок для кожного факту, сервісу чи ресурсу, що використовується на занятті й може змінюватися.


| Пункт | Чому це важливо | Джерело або місцевий експерт | Дата перевірки | Що може змінитися | Формулювання для заняття або запасний варіант |
| --- | --- | --- | --- | --- | --- |
| Місцева валюта та правила здійснення платежів | Обговорення в модулі 1 |  |  |  |  |
| Банківське регулювання та захист вкладів | Розділ про часткове резервування |  |  |  |  |
| Офіційний показник інфляції та споживчий кошик | Вправа з купівельної спроможності |  |  |  |  |
| Статус або модель цифрової валюти центрального банку | Додаткове порівняння з місцевим прикладом |  |  |  |  |
| Гаманець або платіжний інструмент | Практика в модулі 3 або 4 |  |  |  |  |
| Комісії, спреди та ліміти | Порівняння доступних на місці способів |  |  |  |  |
| Правові, податкові аспекти, питання конфіденційності або звітності | Модуль про місцеві особливості |  |  |  |  |
| Продавець, мапа, зустріч або ресурс підтримки | Знайомство зі спільнотою |  |  |  |  |


Надавайте перевагу авторитетним першоджерелам щодо чинних правил. Якщо підтверджувальні дані неповні, зазначте це. Не перетворюйте неперевірену місцеву інформацію на універсальне твердження.
