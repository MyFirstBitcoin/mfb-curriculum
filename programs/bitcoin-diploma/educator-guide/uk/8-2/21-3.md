# 8.21 Повторення та перехід до модуля 3

Попросіть учнів заповнити:


| Проблема фіатної системи | Відповідь Біткоїна | Нова відповідальність або компроміс |
| --- | --- | --- |
| Пропозиція грошей може змінюватися через політичні рішення |  |  |
| Платежі залежать від посередників |  |  |
| Один розпорядник реєстру контролює записи |  |  |
| Доступ залежить від установи |  |  |


Вимагайте чіткого пояснення, чому [вузли](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) та [майнери](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) виконують різні ролі.

Потім використайте **з Модуля 2** посібника для учнів завершальне запитання. Залиште відповідь приватною або зробіть її необов’язковою, дотримуючись наведених вище рекомендацій щодо ненав’язливої рефлексії наприкінці модуля.

Перехід:

> Біткоїн може зменшити залежність від оператора рахунку, але безпосередній контроль залежить від ключів, перевірки, відновлення та безпечних рішень. **Модуль 3** переводить цю відповідальність у практичну площину.
