# 10.8 Огляд місцевого інструмента для Біткоїна

Не демонструйте інструмент лише тому, що він популярний у вашій місцевості. Використовуйте такі критерії порівняння:


| Аспект | Запитання |
| --- | --- |
| Призначення | Яку проблему розв’язує інструмент і чи потрібен він? |
| Зберігання коштів | Хто контролює ключі та кошти? |
| Джерело | Хто його публікує і як було перевірено справжність джерела? |
| Код і супровід | Чи є його вихідний код відкритим, чи перевіряють його, чи забезпечують супровід і безпечне оновлення? |
| Відновлення | Що станеться, якщо пристрій, сервіс або компанія зникне? |
| Приватність | Які ідентифікаційні та контактні дані, дані про пристрій, місцеперебування й транзакції збираються? |
| Вартість | Які явні комісії, спреди, плата за підписки, витрати на поповнення та виведення коштів застосовуються? |
| Сумісність | Які мережі, типи адрес, платіжні запити, резервні копії та пристрої підтримуються? |
| Підтримка | Чи можуть учні отримати допомогу, не розкриваючи секретних даних? |
| Законодавство та облік | Які місцеві обмеження, правила захисту прав споживачів, податкові, облікові чи звітні обов’язки можуть мати значення? |
| Альтернатива | Чим можуть скористатися учні, якщо інструмент вийде з ладу або буде недоступний? |
