# 10.10 Варіант модуля A: порівняння місцевих способів оплати

**Мета:** Порівняйте повний шлях платежу за наявним місцевим способом, через блокчейн і через Lightning, де це доречно.

**Підготовка:** Використайте реалістичну вигадану суму платежу та вигаданого одержувача. Підготуйте датовану інформацію про місцеві комісії, обмін, строки, [зберігання коштів](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) та доступ. Якщо дані неможливо перевірити, чітко позначте їх як гіпотетичні.

**Завдання для учнів:** Заповніть:


| Поле | Наявний спосіб | Біткоїн через блокчейн | Lightning, якщо доречно |
| --- | --- | --- | --- |
| Надіслана сума |  |  |  |
| Загальна отримана сума |  |  |  |
| Очікувані строки та остаточність розрахунку |  |  |  |
| Комісії та спред |  |  |  |
| Зберігання коштів на кожному етапі |  |  |  |
| Ідентифікація особи та конфіденційність |  |  |  |
| Скасування платежу або повернення коштів |  |  |  |
| Основна точка можливого збою |  |  |  |
| Місцева підтримка або законодавство |  |  |  |


**Практична робота:** Учень обирає шлях платежу для вигаданого випадку, демонструє або описує послідовність дій для відповідного платіжного запиту та його перевірки й пояснює, чому інший шлях може бути кращим за зміни певної умови.

**Підсумкове обговорення:** Чи покращив Біткоїн увесь шлях платежу, чи лише один видимий етап? Хто несе ризики волатильності, конвертації, [зберігання коштів](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) та збоїв?

**Безпека:** Реальний переказ або конкретний постачальник послуг не потрібні. Використовуйте роздруковану платіжну інформацію.
