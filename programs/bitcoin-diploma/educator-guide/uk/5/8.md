# 5.8 Коротка рефлексія наприкінці модуля

Кожен модуль посібника для студентів завершується одним коротким риторичним запитанням. Використовуйте його після повторення матеріалу, наприкінці розділу, щоб допомогти студентам помітити, що змінилося в їхньому розумінні. Дайте 30–60 секунд на роздуми в тиші. Студент може залишити відповідь при собі, добровільно поділитися нею з партнером або просто перейти далі.

Не збирайте, не оцінюйте, не записуйте й не вимагайте відповідей. Не просіть студентів розкривати відомості про особисті фінанси, активи, рахунки чи наміри придбати або використовувати біткоїн. Це пауза для закріплення матеріалу, а не вихідне опитування, завдання для оцінювання чи підтвердження для сертифікації. Відокремлюйте її від передбаченої наприкінці курсу `F2` рефлексії.

За можливості використовуйте запитання з посібника для студентів без змін. Якщо переклад або вимоги доступності потребують адаптації, зберігайте його відкритий характер і спрямованість на рефлексію та не перетворюйте його на спонукання до згоди чи дії.
