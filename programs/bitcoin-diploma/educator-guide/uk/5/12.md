# 5.12 Резервні варіанти медіаматеріалів та інструментів

Посібник для учнів містить визначення, порівняння, правила безпеки та запитання для повторення, необхідні для курсу «Біткоїн-диплом». Додаткові навчальні посилання та QR-коди для доступу до них є необов’язковими. Вони можуть надавати оновлення, матеріали для повторення, вихідні файли або способи налагодження зв’язків. Учні можуть завершити курс без використання цих додаткових ресурсів.

Жодне обов’язкове пояснення в межах курсу «Біткоїн-диплом», формувальна перевірка викладачем, практична вправа чи безпосередньо спостережуване практичне підтвердження навичок не повинні залежати від відео, вебсайту з доступом у реальному часі, конкретного сервісу чи власного пристрою учня, якщо затверджений рівноцінний спосіб дає змогу зберегти відповідну компетентність.

Якщо для демонстрації потрібен доступ до інтернету, за можливості підготуйте офлайн-альтернативу, наприклад роздруківки екранів гаманця, сценарій транзакції, вправу з картками або покрокове обговорення. Збій з’єднання не повинен зупиняти навчання чи підготовку.


| Діяльність у реальному часі або онлайн | Офлайн-еквівалент або варіант із мінімальним використанням технологій |
| --- | --- |
| Навігація в гаманці | Послідовність роздрукованих екранів гаманця або показ запису на проєкторі з паузами для прогнозування наступних кроків |
| Надсилання й отримання | Картки з адресами або рахунками на оплату, картки із сумами та паперова схема проходження транзакції |
| Сканування QR-кодів | Роздруковані зразки платіжних даних і візуальне порівняння |
| Оглядач блоків | Знімки екрана заздалегідь підібраної публічної транзакції із зазначенням дати |
| Дані про ціну, комісії або інфляцію в реальному часі | Заздалегідь підготовлений зріз даних із зазначенням дати, джерела та обмежень |
| Мапа торговців або спільнот | Роздрукована місцева мапа та перевірені приклади записів у каталозі |
| Платіж через Lightning | Картки з рахунками на оплату та сценарій платежу з маршрутизацією |
| Відео | Схема з усним коментарем, розкадрування або пояснення викладача |
| Транзакція в реальному часі | Симуляція, тестове середовище, порожній навчальний гаманець або демонстрація викладача |


Офлайн-навчання та оцінювання є повноцінними. За обмеженого доступу до інтернету використовуйте офлайн-перевірки знань, друковані завдання, рольові ігри та симуляції. Необов’язкове формувальне повторення не є частиною сертифікації.

Посібник для учнів пояснює поняття, що не втрачають актуальності. Перевіряйте актуальні місцеві відомості, перш ніж розповідати про комісії, закони, податки, доступні сервіси, функції гаманців або записи в каталогах торговців, і зазначайте дату інформації, яку використовуєте.
