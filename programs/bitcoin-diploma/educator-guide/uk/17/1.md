# 17.1 Коротко про термінологію та відмінності, важливі для уникнення хибних уявлень

Повні визначення шукайте в Лексиконі. Послідовно дотримуйтеся цих розмежувань в усних поясненнях, на слайдах, у навчальних завданнях та під час оцінювання.


| Терміни | Розмежування для викладачів |
| --- | --- |
| Гроші / валюта | Гроші — це ширше поняття: інструмент або актив, що використовується для обміну, обліку та збереження вартості в часі; валюта — це конкретна грошова одиниця або система. |
| Функція / властивість | Функція — це те, що роблять гроші; властивість — це якість, яка впливає на те, наскільки добре вони це роблять. |
| Обмеженість / цінність | Обмеженість звужує доступність; цінність також залежить від використання, попиту, уподобань, інформації та контексту. |
| Цінова інфляція / зростання окремої ціни | Інфляція — це стійке зростання загального рівня цін; окрема ціна може змінюватися з багатьох причин. |
| Банківський депозит / фізична готівка | Банківський депозит — це вимога до банку, за якою він має зобов’язання; фізична готівка — це інша форма грошей, випущених центральним банком або державою, залежно від юрисдикції. |
| Ліквідність / платоспроможність | Ліквідність стосується своєчасності платежів; платоспроможність — того, чи покривають активи зобов’язання. |
| CBDC / Біткоїн | CBDC — це цифрові фіатні гроші з централізованою емісією; Біткоїн не має центрального емітента й використовує правила, дотримання яких можна перевірити незалежно. |
| Біткоїн / біткоїн | Біткоїн означає мережу, протокол або проєкт; біткоїн — актив або грошові одиниці. |
| Протокол Біткоїна / сервіс Біткоїна | Протокол — це спільна система правил; гаманець, біржа, оглядач або платіжна компанія — це окремий сервіс чи інструмент. |
| Цифровий підпис / шифрування | Підпис доводить авторизацію за допомогою ключа; шифрування приховує читабельний вміст. |
| Майнер / вузол | Майнер пропонує блоки-кандидати за допомогою доказу виконаної роботи; вузол перевіряє дотримання правил. |
| Пропозиція розробників / зміна правил | Розробники пропонують програмне забезпечення; учасники вирішують, чи використовувати його. |
| Час між блоками / розклад | Близько десяти хвилин — це середній показник за тривалий період, а не точно призначений час. |
| Обмежена пропозиція / гарантія ціни | Передбачувана максимальна кількість — це властивість пропозиції; вона не гарантує попиту чи дохідності. |
| Надійні гроші / факт | Надійність грошей — це оцінне судження, що ґрунтується на визначених критеріях і компромісах. |
| Гаманець / зберігання біткоїнів | Гаманець керує ключами й транзакціями; біткоїни залишаються записаними у спільному реєстрі. |
| Адреса / приватний ключ | Адреса слугує для отримання коштів; приватний ключ надає дозвіл на їх витрачання. |
| Сід-фраза / пароль | Сід-фраза може відтворити ключі гаманця й часто дає змогу повністю відновити доступ; це не звичайний пароль, який можна скинути. |
| Кастодіальний / із самостійним зберіганням ключів | Відмінність полягає в тому, хто контролює ключі. |
| Гарячий / холодний | Відмінність полягає в тому, чи перебувають ключі в середовищі загального призначення, підключеному до інтернету. |
| Ончейн / Lightning | Відмінність полягає у шляху проходження платежу, а не в тому, хто зберігає ключі. |
| Оглядач / вузол | Оглядач — це сторонній інтерфейс; вузол незалежно перевіряє дотримання правил. |
| Підтвердження / правильний платіж | Підтвердження зміцнює історію розрахунків; воно не виправляє одержувача й не засвідчує правомірності призначення платежу. |
| Приватність / таємність | Приватність — це контроль над інформацією; вона не означає, що діяльність не залишає публічних даних або не передбачає юридичних зобов’язань. |
| KYC / no-KYC | Ці підходи передбачають збирання різних ідентифікаційних даних і різні компроміси щодо підтримки, приватності, ризиків контрагента, шахрайства та правових аспектів. Послідовно використовуйте позначення no-KYC. |
| Місцевий приклад / рекомендація | Перевірений місцевий приклад допомагає в навчанні; він не є універсальною рекомендацією. |
