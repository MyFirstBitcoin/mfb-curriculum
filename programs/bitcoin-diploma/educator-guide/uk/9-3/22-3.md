# 9.22 Інтегрований цикл практичних вправ модуля 3

Використовуйте станції після того, як слухачі ознайомляться з кожним процесом.


| Станція | Завдання для слухачів | Акцент на безпеці |
| --- | --- | --- |
| 1. Гаманець і зберігання коштів | Визначте, хто контролює ключі, і знайдіть функцію отримання | Не робіть висновків про те, хто зберігає кошти, лише зі слова «гаманець» |
| 2. Публічне чи таємне | Класифікуйте платіжну інформацію та інформацію для відновлення | Ніколи не розкривайте справжніх секретних даних |
| 3. Отримання | Створіть або знайдіть підготовлений запит і визначте шлях платежу за ним | Діліться лише інформацією для отримання платежу |
| 4. Надсилання | Перевірте одержувача, мережу, адресу призначення, суму, одиницю виміру, комісію та остаточні зведені дані | Зупиніться за будь-якої невідповідності |
| 5. Відновлення | Упорядкуйте кроки підготовленого завдання з перевірки готовності до відновлення або виконайте його | Працюйте приватно; не використовуйте справжню сід-фразу гаманця з коштами |
| 6. Оглядач блоків | Прочитайте підготовлені дані про статус транзакції та публічні дані | Враховуйте ризики для приватності та обмеження оглядача блоків |
| 7. Шахрайство | Відреагуйте на терміновий запит від служби підтримки або на запит про зміну адреси | Зробіть паузу та перевірте інформацію незалежним способом |
| 8. Спосіб | Порівняйте два місцеві способи придбання або оплати | Без схвалення чи порад |


Не використовуйте станції для формального оцінювання, якщо конкретні завдання, варіанти, критерії та форми фіксації результатів не затверджено.
