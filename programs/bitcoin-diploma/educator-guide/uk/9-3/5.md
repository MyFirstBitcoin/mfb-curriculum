# 9.5 Підготуйтеся до заняття

* Прочитайте **модуль 3** посібника для учнів і відпрацюйте кожну демонстрацію.
* Виберіть конкретний підготовлений гаманець, симуляцію, тестове середовище або друковану послідовність дій.
* Перевірте джерело походження інструмента, його версію, мережу, [кастодіальну](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) модель, процедуру відновлення та процедуру скидання.
* Визначте, чи учні використовуватимуть симуляцію, тестове середовище, порожній навчальний гаманець, фізичну модель або схвалене викладачем середовище з реальними коштами, де ризик обмежений невеликими сумами. Для будь-якого середовища з реальними коштами підготуйте пояснення ризиків, процедуру добровільного вибору та рівноцінний варіант без використання коштів.
* Підготуйте зразки ончейн-адрес, [рахунків Lightning](https://curriculum.myfirstbitcoin.org/lexicon/en/#lightning-invoice), *[txid](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction-id)*, QR-кодів і знімків екрана з позначкою **ЗРАЗОК — НЕ ОПЛАЧУВАТИ**.
* Підготуйте картки для сортування на публічні та секретні дані.
* Підготуйте свідомо оприлюднену адресу або минулу транзакцію для вправи з історією адреси. Ніколи не використовуйте дані, пов’язані з учнями.
* Підготуйте несправжню [фразу відновлення](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) або одноразовий порожній навчальний гаманець для практики відновлення.
* Підготуйте сценарії шахрайства та підміни вмісту буфера обміну.
* Перегляньте [бібліотеку вправ](https://curriculum.myfirstbitcoin.org/activities/en/), щоб знайти доречні ідеї для практики, адаптуючи будь-яку вправу з гаманцем або платежами до наведених тут умов безпеки й оцінювання.
* Підготуйте порівняння способів придбання, актуальних для вашої місцевості, не надаючи переваги жодному постачальнику послуг.
* Для кожної вправи, яку використовуватимете для оцінювання, визначте допоміжні кроки, підтримку, межі безпеки, спосіб скидання та будь-які необов’язкові примітки.
* Облаштуйте приватний простір, де сторонні не зможуть без потреби бачити екрани учнів і докази виконання завдань.
* Переконайтеся, що кожне завдання з реальними коштами має друкований або рівноцінний варіант без використання коштів.
