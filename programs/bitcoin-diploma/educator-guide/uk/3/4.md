# 3.4 Забезпечуйте безпечну участь без примусу до розкриття інформації

Фінансовий досвід може бути делікатною темою. Запропонуйте три варіанти для осмислення місцевого контексту:

* особистий приклад, яким учень добровільно вирішує поділитися
* приклад із суспільного життя чи життя громади, який учень спостерігав; або
* реалістичний вигаданий сценарій.

Ніколи не вимагайте розкривати інформацію про доходи, борги, доступ до банківських послуг, статус документів, що посвідчують особу, активи, адреси, транзакції, податки, грошові перекази родині чи заходи безпеки.
