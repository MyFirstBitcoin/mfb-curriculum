# 4.7 Запись о локальной проверке

Заполните отдельную строку для каждого факта, сервиса или ресурса, используемого на занятиях и подверженного изменениям.


| Пункт | Почему это важно | Источник или местный эксперт | Дата проверки | Что может измениться | Формулировка для занятия или запасной вариант |
| --- | --- | --- | --- | --- | --- |
| Местная валюта и правила проведения платежей | Обсуждение в модуле 1 |  |  |  |  |
| Банковское регулирование и защита вкладов | Раздел о частичном резервировании |  |  |  |  |
| Официальный показатель инфляции и потребительская корзина | Задание на покупательную способность |  |  |  |  |
| Статус или устройство цифровой валюты центрального банка | Необязательное сравнение с местной ситуацией |  |  |  |  |
| Кошелёк или платёжный инструмент | Практика в модуле 3 или 4 |  |  |  |  |
| Комиссии, спреды и лимиты | Сравнение доступных на местном уровне способов |  |  |  |  |
| Местные условия в области права, налогообложения, конфиденциальности или отчётности | Модуль с учётом местных условий |  |  |  |  |
| Торговая точка, карта, встреча сообщества или ресурс поддержки | Знакомство с сообществом |  |  |  |  |


При проверке действующих правил отдавайте предпочтение авторитетным первоисточникам. Если сведения неполны, укажите это. Не превращайте неподтверждённую местную информацию в универсальное утверждение.
