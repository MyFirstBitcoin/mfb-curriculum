# 9.13 «Горячий», «холодный», «аппаратный» и «кастодиальный» — разные характеристики

Избегайте распространённой ошибки при разграничении категорий:

* **Кастодиальный / некастодиальный** — указывает на то, кто контролирует ключи.
* **Горячий / холодный** — указывает на то, доступны ли ключи подписи в среде общего назначения, подключённой к интернету.
* [**Аппаратный кошелёк**](https://curriculum.myfirstbitcoin.org/lexicon/en/#hardware-wallet) — обозначает специализированное устройство.
* **Ончейн / Lightning** — описывает способ проведения платежа, а не [модель хранения средств](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) саму по себе.

Кошелёк Lightning может быть кастодиальным или некастодиальным. [Аппаратный кошелёк](https://curriculum.myfirstbitcoin.org/lexicon/en/#hardware-wallet) тоже требует процедуры восстановления. Схема холодного хранения может быть плохо продумана. [Горячий кошелёк](https://curriculum.myfirstbitcoin.org/lexicon/en/#hot-wallet) может подходить для небольших повседневных платежей.
