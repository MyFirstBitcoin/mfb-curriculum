# 9.5 Подготовьтесь перед занятием

* Прочитайте **модуль 3** в руководстве для учащихся и отработайте каждую демонстрацию.
* Выберите конкретный заранее подготовленный кошелёк, симуляцию, тестовую среду или печатную пошаговую инструкцию.
* Проверьте источник инструмента, его версию, сеть, модель [хранения средств](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), процедуру восстановления и процедуру сброса.
* Решите, будут ли учащиеся использовать симуляцию, тестовую среду, пустой учебный кошелёк, физическую модель или одобренную преподавателем реальную среду с небольшими суммами. Для любой реальной среды подготовьте объяснение рисков, процедуру добровольного выбора и равноценный вариант без использования средств.
* Подготовьте образцы ончейн-адресов, [счетов Lightning](https://curriculum.myfirstbitcoin.org/lexicon/en/#lightning-invoice), *[txid](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction-id)*, QR-кодов и снимков экрана с пометкой **ОБРАЗЕЦ — НЕ ОПЛАЧИВАТЬ**.
* Подготовьте карточки для сортировки на общедоступные и секретные данные.
* Для задания по изучению истории адреса подготовьте адрес, намеренно сделанный общедоступным, или транзакцию из истории. Никогда не используйте данные, связанные с учащимися.
* Подготовьте вымышленную [сид-фразу](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) или одноразовый пустой учебный кошелёк для практики восстановления.
* Подготовьте сценарии мошенничества и подмены содержимого буфера обмена.
* Просмотрите [библиотеку заданий](https://curriculum.myfirstbitcoin.org/activities/en/), чтобы найти подходящие идеи для практики, адаптируя любые задания с кошельками или платежами к изложенным здесь требованиям безопасности и оценивания.
* Подготовьте сравнение способов приобретения с учётом местных условий, не указывая предпочтительного поставщика услуг.
* Для каждого задания, используемого для оценивания, определите полезные шаги, необходимую поддержку, границы безопасности, способ сброса и любые дополнительные примечания.
* Организуйте приватное пространство, где посторонние не смогут без необходимости видеть экраны учащихся и материалы, подтверждающие выполнение заданий.
* Убедитесь, что для каждого задания в реальной среде есть равноценный печатный вариант или вариант без использования средств.
