# 16.1 Заполнение документации и повторное оценивание

* Объедините результаты теоретической оценки, проведённой преподавателем, и записи о практической работе, за которой наблюдал преподаватель.
* Убедитесь, что по каждой обязательной оцениваемой компетенции в таблице оценивания, включая обязательные критерии этой компетенции, есть подтверждения из соответствующего компонента оценки.
* Свяжитесь с учащимися в индивидуальном порядке по поводу незавершённых заданий.
* Организуйте целенаправленную работу над пробелами и справедливое повторное оценивание.
* Предложите сертификат участия, если учащийся участвовал в курсе, но получил отметку **«Пока нет»** по одной или нескольким компетенциям; выдавайте сертификат об окончании курса только тогда, когда по всем компетенциям стоит отметка **«Да»**.
* После подтверждения каждого результата используйте [инструмент создания сертификатов](https://tools.myfirstbitcoin.org/certificate) для пакетного создания сертификатов, затем перед их выдачей проверьте имена учащихся, типы сертификатов и сведения о выдаче.
* Храните только минимум информации, необходимой преподавателю для ведения учёта. Краткие заметки о подтверждении результатов полезны, но необязательны.
