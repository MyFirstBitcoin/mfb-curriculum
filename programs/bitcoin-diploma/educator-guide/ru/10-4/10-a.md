# 10.10 Вариант модуля A: сравнение местных способов проведения платежей

**Цель:** Сравнить полный путь платежа при использовании существующего местного способа оплаты, перевода в блокчейне и перевода через Lightning, если это уместно.

**Подготовка:** Используйте реалистичные вымышленные сумму платежа и получателя. Подготовьте актуальную местную информацию с указанием даты о комиссиях, обмене, сроках, [хранении средств](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) и доступе. Если данные невозможно проверить, явно обозначьте их как гипотетические.

**Задание для учащегося:** Заполните:


| Параметр | Существующий способ | Биткоин в блокчейне | Lightning, если применимо |
| --- | --- | --- | --- |
| Отправленная сумма |  |  |  |
| Итоговая полученная сумма |  |  |  |
| Ожидаемые сроки и окончательность расчёта |  |  |  |
| Комиссии и спред |  |  |  |
| Хранение средств на каждом этапе |  |  |  |
| Идентификация и конфиденциальность |  |  |  |
| Отмена платежа или возврат средств |  |  |  |
| Основная точка возможного сбоя |  |  |  |
| Местная поддержка или законодательство |  |  |  |


**Практическая работа:** Учащийся выбирает путь платежа для вымышленной ситуации, демонстрирует соответствующий запрос на оплату и проверку платежа либо описывает последовательность этих действий, а также объясняет, почему другой путь может оказаться лучше при изменении одного из условий.

**Обсуждение итогов:** Улучшил ли биткоин весь путь платежа или только один видимый этап? Кто несёт риски волатильности, конвертации, [хранения средств](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) и сбоев?

**Безопасность:** Реальный перевод или использование услуг конкретного провайдера не требуются. Используйте распечатанные платёжные данные.
