# 7.1 Цель модуля

**Модуль 1** даёт учащимся терминологию и критерии, необходимые для изучения денег. Он не должен превращаться в пространную критику всех фиатных систем. Его задача — помочь учащимся объяснить, зачем существуют деньги, как работают различные системы денежного обращения, какие компромиссы они предполагают и какие проблемы впоследствии пытается решить биткоин.

Ключевой вопрос:

> Как деньги могут перестать работать?

Ожидаемый результат для учащегося:

> Я могу объяснить проблемы денег, на которые отвечает биткоин, и применить это понимание на практике.

**Если вы впервые преподаёте модуль 1:** Начните с вводных вопросов и привычного для вашей местности способа оплаты. Не начинайте с длинной лекции по истории. Дайте учащимся рассказать о том, что они уже знают, а затем вводите только те термины, которые нужны для следующего задания. Вернитесь к заметкам о местной фиатной валюте и банковской системе, когда группа дойдёт до соответствующих разделов.
