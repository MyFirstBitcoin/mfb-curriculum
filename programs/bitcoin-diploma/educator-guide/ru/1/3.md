# 1.3 Роли в курсе

* Каждый **обучающийся** изучает материал, обсуждает его, практикуется и демонстрирует компетентность через наблюдаемые объяснения, сравнения, рассуждения или действия.
* Каждый **преподаватель** содействует обучению, обеспечивает безопасную учебную среду, дополняет материал проверенной информацией о местном контексте, проводит теоретические занятия в соответствии с формируемыми компетенциями, даёт обратную связь по практическим заданиям и непосредственно оценивает практические компетенции по установленным критериям. Если обучение и оценивание распределены между разными преподавателями, оба должны придерживаться одинаковых условий выполнения заданий, критериев и порядка ведения записей.
* Любая **учебная группа** — это группа людей, которые учатся вместе. Задания можно выполнять в небольших командах, но там, где это требуется, должна сохраняться возможность определить, какие подтверждения компетентности для сертификации относятся к каждому обучающемуся.
* Программа **«Диплом по биткоину»** — это полная программа обучения и оценивания, а не только руководство для обучающихся.
