# 8.21 Повторение и переход к модулю 3

Попросите учащихся заполнить таблицу:


| Проблема фиатной системы | Решение биткоина | Новая ответственность или компромисс |
| --- | --- | --- |
| Объём денежной массы может меняться в результате денежно-кредитной политики |  |  |
| Платежи зависят от посредников |  |  |
| Записи контролирует единственный держатель реестра |  |  |
| Доступ зависит от организации |  |  |


Потребуйте чёткого объяснения того, почему [узлы](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) и [майнеры](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) выполняют разные роли.

Затем используйте **в модуле 2** заключительный вопрос из руководства для учащихся. Пусть ответ останется личным или будет добровольным — следуйте приведённым выше рекомендациям по краткой рефлексии в конце модуля.

Переход:

> Биткоин может снизить зависимость от оператора счёта, но непосредственный контроль зависит от ключей, проверки, восстановления доступа и безопасных решений. **Модуль 3** переводит эту ответственность в практические действия.
