# 8.4 Рекомендуемый план двухчасового занятия

| Время | Учебный этап | Предлагаемый метод |
| --- | --- | --- |
| 0–10 мин | Вспомните материал модуля 1 | Назовите одну проблему денег и компромисс, к которому она приводит |
| 10–27 мин | Почему было трудно создать децентрализованные цифровые деньги | Сценарий с цифровым копированием и двойной тратой |
| 27–42 мин | Комплексное решение биткоина | Схема процесса: авторизация, рассылка, майнинг, проверка, обмен историей |
| 42–62 мин | Роли и децентрализация | Задание по ролям: пользователь/узел/майнер/разработчик |
| 62–77 мин | Доказательство работы | Демонстрация: затратно выполнить, быстро проверить |
| 77–92 мин | Предложение, халвинг и сатоши | Модель эмиссии и проверка предубеждения в пользу целых единиц |
| 92–110 мин | Сравнение по критериям надёжных денег | Используйте свойства из модуля 1; добавьте преимущества и компромиссы |
| 110–117 мин | Границы применения и ответственность | Биткоин в сравнении со стейблкоинами/другими активами; обучение в сравнении со спекуляцией |
| 117–120 мин | Повторение и переход к следующей теме | Проблема фиатных денег → решение биткоина → новая ответственность |
