# 8.7 Объясните общий ответ

Используйте схему из пяти частей:

1. Кошелёк использует [закрытый ключ](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key) для авторизации транзакции с помощью [цифровой подписи](https://curriculum.myfirstbitcoin.org/lexicon/en/#digital-signature).
1. Транзакция [распространяется](https://curriculum.myfirstbitcoin.org/lexicon/en/#broadcast) через [одноранговую сеть](https://curriculum.myfirstbitcoin.org/lexicon/en/#peer-to-peer-network).
1. [Майнеры](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) собирают транзакции и используют [доказательство работы](https://curriculum.myfirstbitcoin.org/lexicon/en/#proof-of-work) для предложения блоков.
1. [Узлы](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) независимо проверяют транзакции, блоки, [доказательство работы](https://curriculum.myfirstbitcoin.org/lexicon/en/#proof-of-work) и правила эмиссии.
1. Участники приходят к согласию относительно действительной истории с наибольшим объёмом [накопленной работы](https://curriculum.myfirstbitcoin.org/lexicon/en/#accumulated-work).

Ни один отдельный компонент не обеспечивает биткоину гарантированную [ограниченность предложения](https://curriculum.myfirstbitcoin.org/lexicon/en/#scarcity) сам по себе. Избегайте утверждения «[блокчейн](https://curriculum.myfirstbitcoin.org/lexicon/en/#blockchain) решает всё».
