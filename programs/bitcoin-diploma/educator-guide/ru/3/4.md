# 3.4 Обеспечивайте безопасное участие без принуждения к раскрытию информации

Финансовый опыт может быть деликатной темой. Предложите три варианта для размышления с учётом местного контекста:

* личный пример, которым учащийся сам решит поделиться
* пример из общественной жизни или жизни местного сообщества, который учащийся наблюдал; или
* реалистичный вымышленный сценарий.

Никогда не требуйте раскрывать сведения о доходах, долгах, доступе к банковским услугам, статусе документов, удостоверяющих личность, активах, адресах, транзакциях, налогах, денежных переводах родственникам или мерах безопасности.
