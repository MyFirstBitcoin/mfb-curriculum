# 17.1 Краткий обзор терминологии и различий, помогающих избежать заблуждений

Полные определения вы найдёте в глоссарии. Последовательно соблюдайте эти различия в устной речи, на слайдах, в учебных заданиях и при оценивании.


| Термины | Различие для преподавателя |
| --- | --- |
| Деньги / валюта | Деньги — более широкое понятие: инструмент или актив для обмена, учёта и сохранения стоимости во времени; валюта — конкретная денежная единица или система. |
| Функция / свойство | Функция — это то, что делают деньги; свойство — качество, влияющее на то, насколько хорошо они это делают. |
| Ограниченность / ценность | Ограниченность сдерживает доступность; ценность также зависит от использования, спроса, предпочтений, информации и контекста. |
| Инфляция цен / повышение отдельной цены | Инфляция — устойчивый рост общего уровня цен; отдельная цена может меняться по многим причинам. |
| Банковский вклад / наличные деньги | Банковский вклад — требование к банку по его обязательству; наличные деньги — другая форма денег, выпускаемых центральным банком или государством в зависимости от юрисдикции. |
| Ликвидность / платёжеспособность | Ликвидность связана со своевременным исполнением платежей; платёжеспособность — с тем, покрывают ли активы обязательства. |
| Цифровая валюта центрального банка / биткоин | Цифровая валюта центрального банка — централизованно выпускаемые цифровые фиатные деньги; у биткоина нет центрального эмитента, а его правила можно проверить независимо. |
| Биткоин / биткоин | Биткоин может обозначать сеть, протокол или проект; биткоин также обозначает актив или денежные единицы. |
| Протокол биткоина / биткоин-сервис | Протокол — общая система правил; кошелёк, биржа, обозреватель блоков или платёжная компания — отдельный сервис или инструмент. |
| Цифровая подпись / шифрование | Подпись подтверждает авторизацию с помощью ключа; шифрование скрывает читаемое содержимое. |
| Майнер / узел | Майнер предлагает блоки-кандидаты с помощью доказательства работы; узел проверяет соблюдение правил. |
| Предложение разработчика / изменение правил | Разработчики предлагают программное обеспечение; участники решают, использовать ли его. |
| Время между блоками / расписание | Около десяти минут — среднее значение на длительном промежутке времени, а не точное расписание. |
| Ограниченное предложение / гарантия цены | Предсказуемый максимальный объём — свойство предложения; он не гарантирует спрос или доходность. |
| Надёжные деньги / факт | «Надёжные деньги» — оценочное суждение, основанное на заявленных критериях и компромиссах. |
| Кошелёк / хранение биткоинов | Кошелёк управляет ключами и транзакциями; биткоины остаются записанными в общем реестре. |
| Адрес / закрытый ключ | Адрес служит для получения средств; закрытый ключ позволяет авторизовать их расходование. |
| Сид-фраза / пароль | Сид-фраза позволяет воссоздать ключи кошелька и часто даёт возможность полностью восстановить доступ; это не обычный пароль, который можно сбросить. |
| Кастодиальный / некастодиальный | Различие заключается в том, кто контролирует ключи. |
| Горячий / холодный | Различие заключается в том, доступны ли ключи в подключённой к интернету среде общего назначения. |
| Ончейн / Lightning | Различие заключается в пути прохождения платежа, а не в том, кто контролирует ключи. |
| Обозреватель блоков / узел | Обозреватель блоков — сторонний интерфейс; узел независимо проверяет соблюдение правил. |
| Подтверждение / корректный платёж | Подтверждение укрепляет историю окончательных расчётов; оно не исправляет получателя и не подтверждает обоснованность назначения платежа. |
| Приватность / секретность | Конфиденциальность — это контроль над информацией; она не означает, что деятельность не оставляет общедоступных данных или не влечёт правовых обязательств. |
| KYC / no-KYC | Эти подходы предполагают сбор разных сведений о личности и разные компромиссы в вопросах поддержки, конфиденциальности, рисков контрагента, мошенничества и правовых аспектов. Во всём тексте используйте обозначение no-KYC. |
| Местный пример / рекомендация | Проверенный местный пример помогает обучению; он не является безусловной рекомендацией. |
