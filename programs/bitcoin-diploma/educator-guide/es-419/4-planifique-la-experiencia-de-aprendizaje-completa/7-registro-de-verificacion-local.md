# 4.7 Registro de verificación local

Complete una fila por cada dato, servicio o recurso utilizado en clase que pueda cambiar.


| Elemento | Por qué importa | Fuente o experto local | Fecha de verificación | Qué puede cambiar | Formulación para la clase o alternativa |
| --- | --- | --- | --- | --- | --- |
| Moneda local y normas de pago | Discusión del módulo 1 |  |  |  |  |
| Regulación bancaria y protección de depósitos | Sección sobre reserva fraccionaria |  |  |  |  |
| Medición oficial de la inflación y canasta de referencia | Actividad sobre el poder adquisitivo |  |  |  |  |

| Billetera o herramienta de pago | Práctica del módulo 3 o 4 |  |  |  |  |
| Comisiones, diferenciales y límites | Comparación de opciones locales |  |  |  |  |
| Contexto legal, fiscal, de privacidad o de obligaciones de reporte | Módulo local |  |  |  |  |
| Comercio, mapa, encuentro o recurso de apoyo | Exploración de la comunidad |  |  |  |  |


Dé preferencia a fuentes primarias autorizadas para consultar las normas vigentes. Si la evidencia está incompleta, indíquelo. No convierta información local incierta en una afirmación universal.
