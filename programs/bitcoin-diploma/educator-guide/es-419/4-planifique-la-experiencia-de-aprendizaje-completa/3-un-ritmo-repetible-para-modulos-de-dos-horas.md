# 4.3 Un ritmo repetible para módulos de dos horas

Use esto como un esquema de planificación, no como un guion rígido.


| Tiempo | Propósito | Acción del educador |
| --- | --- | --- |
| 0–10 min | Bienvenida y recuperación de conocimientos | Haga una pregunta breve sobre lo aprendido anteriormente y ponga de manifiesto las dudas. |
| 10–30 min | Primer concepto | Explique brevemente, use un recurso visual o un ejemplo local y propicie una respuesta observable del estudiante. |
| 30–55 min | Interacción principal | Facilite una comparación, un juego, un escenario, un mapa de roles, una demostración o una práctica guiada. |
| 55–65 min | Reflexión posterior | Conecte la experiencia con la competencia; corrija aquello que la actividad no pudo mostrar. |
| 65–80 min | Segundo concepto o demostración | Incorpore la siguiente idea esencial y demuestre el proceso completo cuando corresponda. |
| 80–105 min | Práctica y producción | Los estudiantes aplican, deciden, explican o ejecutan con cada vez menos apoyo. |
| 105–115 min | Verificación del aprendizaje o evidencia práctica | Recopile retroalimentación formativa, propicie una respuesta del educador alineada con la competencia u observe una habilidad práctica. |
| 115–120 min | Repaso y enlace | Señale los aprendizajes clave, las preguntas pendientes y la conexión con el siguiente módulo. |


La observación práctica suele requerir más tiempo del que permite este esquema. Para el **Módulo 3** y el **Módulo 4**, planifique estaciones, la participación de otro educador o grupos más pequeños dentro del horario del curso. No evalúe a varios estudiantes a la vez si no puede observar las decisiones y el comportamiento de seguridad de cada uno.

Este esquema no establece cuánto tiempo requiere la evaluación dirigida por el educador. Reserve suficiente tiempo dentro del horario para la evidencia individual, la retroalimentación, la reevaluación y el registro. El repaso formativo opcional puede apoyar el aprendizaje sin modificar el cronograma de evaluación.
