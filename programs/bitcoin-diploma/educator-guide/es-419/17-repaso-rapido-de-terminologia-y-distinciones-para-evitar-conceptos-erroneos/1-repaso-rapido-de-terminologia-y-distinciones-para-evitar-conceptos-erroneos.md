# 17.1 Repaso rápido de terminología y distinciones para evitar conceptos erróneos

Consulte el léxico para obtener las definiciones completas. Mantenga estas distinciones de manera coherente en sus explicaciones orales, diapositivas, actividades y evaluaciones.


| Términos | Distinción para docentes |
| --- | --- |
| Dinero / moneda | El dinero es la herramienta o el activo más amplio que se utiliza para el intercambio, como unidad de cuenta y para conservar valor a lo largo del tiempo; la moneda es una unidad o un sistema monetario particular. |
| Función / propiedad | Una función es lo que hace el dinero; una propiedad es una cualidad que influye en qué tan bien lo hace. |
| Escasez / valor | La escasez limita la disponibilidad; el valor también depende del uso, la demanda, las preferencias, la información y el contexto. |
| Inflación de precios / aumento de un solo precio | La inflación es un aumento sostenido del nivel general de precios; un solo precio puede cambiar por muchas razones. |
| Depósito bancario / efectivo físico | Un depósito bancario es un derecho de cobro frente al banco; el efectivo físico es una forma distinta de dinero emitido por el banco central o el Estado, según la jurisdicción. |
| Liquidez / solvencia | La liquidez se refiere a la capacidad de pagar a tiempo; la solvencia, a si los activos cubren las obligaciones. |
| CBDC / Bitcoin | Una CBDC es dinero fíat digital de emisión centralizada; Bitcoin no tiene un emisor central y utiliza reglas verificables de forma independiente. |
| Bitcoin / bitcoin | Bitcoin se refiere a la red, el protocolo o el proyecto; bitcoin se refiere al activo o a las unidades. |
| Protocolo de Bitcoin / servicio de Bitcoin | El protocolo es el sistema de reglas compartido; una billetera, una plataforma de intercambio, un explorador o una empresa de pagos es un servicio o una herramienta aparte. |
| Firma digital / cifrado | Una firma demuestra la autorización mediante una clave; el cifrado oculta el contenido legible. |
| Minero / nodo | Un minero propone bloques candidatos mediante la prueba de trabajo; un nodo verifica las reglas. |
| Propuesta de desarrolladores / cambio de reglas | Los desarrolladores proponen software; los participantes deciden si lo adoptan. |
| Tiempo entre bloques / horario fijo | Aproximadamente diez minutos es un promedio a largo plazo, no una cita exacta. |
| Oferta finita / garantía de precio | Un máximo predecible es una propiedad de la oferta; no garantiza la demanda ni los rendimientos. |
| Dinero sólido / hecho | Calificar al dinero como sólido es un juicio basado en criterios explícitos y en un balance de ventajas y desventajas. |
| Billetera / almacenamiento de bitcoin | Una billetera administra claves y transacciones; bitcoin permanece registrado en el libro contable compartido. |
| Dirección / clave privada | Una dirección recibe; una clave privada autoriza el gasto. |
| Frase semilla / contraseña | Una frase semilla puede recrear las claves de la billetera y suele permitir recuperar el acceso completo; no es una contraseña común que se pueda restablecer. |
| Con custodia / con autocustodia | La distinción radica en quién controla las claves. |
| Caliente / fría | La distinción radica en la exposición de las claves a un entorno de uso general conectado a internet. |
| En cadena / Lightning | La distinción radica en la ruta del pago, no en la custodia. |
| Explorador / nodo | Un explorador es una interfaz de terceros; un nodo verifica las reglas de forma independiente. |
| Confirmación / pago correcto | Una confirmación refuerza el historial de liquidación; no corrige el destinatario ni valida el propósito. |
| Privacidad / secreto | La privacidad es el control sobre la información; no significa que una actividad no tenga datos públicos ni obligaciones legales. |
| KYC / no-KYC | Estas opciones recopilan distintos datos de identidad e implican diferentes ventajas y desventajas en cuanto al soporte, la privacidad, la contraparte, el fraude y los aspectos legales. Use no-KYC de manera uniforme en todo el texto. |
| Ejemplo local / recomendación | Un ejemplo local verificado apoya el aprendizaje; no constituye un respaldo universal. |
