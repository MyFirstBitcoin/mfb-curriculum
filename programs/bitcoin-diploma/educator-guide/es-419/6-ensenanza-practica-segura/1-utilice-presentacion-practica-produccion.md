# 6.1 Utilice Presentación → Práctica → Producción

**Presentación:** Demuestre el proceso completo. Explique el propósito, los términos, las opciones, el resultado esperado, los posibles puntos de falla, las consecuencias para la privacidad y las condiciones para detenerse. Los estudiantes observan antes de manipular un dispositivo.

**Práctica:** Los estudiantes siguen un proceso guiado utilizando materiales preparados, una simulación, un entorno de prueba, una billetera de práctica vacía o un entorno real de bajo riesgo aprobado por el educador. Haga pausas para realizar verificaciones y brinde retroalimentación.

**Producción:** Los estudiantes completan una tarea práctica definida o toman las decisiones sin indicaciones paso a paso. Esta etapa puede aportar evidencia formal del desempeño práctico cuando la tarea y la rúbrica están aprobadas y un educador observa su realización.

Concluya con una reflexión:

* ¿Qué verificó?
* ¿Qué podría haber fallado?
* ¿Qué información se mantuvo privada?
* ¿Cuándo se detendría o pediría ayuda?
* ¿Cuál sería un siguiente paso seguro?
