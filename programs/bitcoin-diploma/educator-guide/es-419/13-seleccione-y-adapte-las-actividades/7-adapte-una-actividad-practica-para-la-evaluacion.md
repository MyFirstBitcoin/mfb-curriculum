# 13.7 Adapte una actividad práctica para la evaluación

Los educadores pueden adaptar una actividad práctica a los estudiantes y al contexto. No convierta una actividad en evidencia de una competencia que no demuestra. Conserve:

* la competencia y el verbo medible
* el tipo de evidencia
* la dificultad y la autonomía
* la secuencia y la verificación requeridas
* el estándar mínimo
* los errores críticos para la seguridad; y
* las notas opcionales y la vía de reevaluación.

Si la equivalencia es incierta, use la adaptación para practicar y seleccione una tarea de evaluación cuya evidencia y estándar correspondan claramente a la competencia.
