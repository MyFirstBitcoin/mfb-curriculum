# 9.19 Adquisición e intercambio: concientización, no asesoría financiera

El estudiante debe comparar las opciones disponibles, no recibir una recomendación.

Compare:

* ganar bitcoin
* un intercambio directo entre pares
* una plataforma de intercambio centralizada o un intermediario
* un cajero automático o un quiosco
* recibir bitcoin a través de un comerciante, una donación, un reembolso o una remesa; y
* un servicio que convierte entre bitcoin y dinero fíat.

Para cada opción, pregunte:

* ¿Qué monto total se recibe después de considerar el [precio](https://curriculum.myfirstbitcoin.org/lexicon/en/#price), el diferencial de precios y las comisiones?
* ¿Quién controla el bitcoin antes y después del intercambio?
* ¿Qué datos de identidad se recopilan?
* ¿Se puede revertir la parte de la transacción realizada en dinero fíat?
* ¿Se puede retirar el bitcoin a [autocustodia](https://curriculum.myfirstbitcoin.org/lexicon/en/#self-custody)?
* ¿Qué riesgos de contraparte y de fraude existen?
* ¿Qué riesgos para la seguridad física existen?
* ¿Qué ley, impuesto u obligación de informar de ámbito local podría aplicarse?

Use [**no-KYC**](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) de manera consistente para una opción que recopila menos información estándar de identidad o ninguna. No dé a entender que [no-KYC](https://curriculum.myfirstbitcoin.org/lexicon/en/#no-kyc) elimina los riesgos de fraude, legales, de contraparte o para la seguridad física. No aconseje evadir la ley local.
