# 9.24 Evidencia práctica del módulo 3

Para la evaluación práctica, observe si el estudiante puede completar la actividad correspondiente de manera segura y si puede:

* abrir el entorno preparado o acceder a él de manera segura
* navegar sin exponer información ajena a la actividad
* identificar el [modelo de custodia](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) utilizado
* distinguir la información para recibir pagos de la información secreta
* seleccionar la vía de pago y la red previstas
* localizar y verificar una dirección o una factura
* verificar el destinatario, el monto, la unidad, la comisión, el vencimiento y el resumen final, según corresponda
* completar o simular de manera segura un proceso de recepción o envío
* interpretar los estados pendiente, confirmado, fallido o recibido
* proteger la información de recuperación durante toda una tarea de preparación para la recuperación
* responder de manera segura ante una exposición de información, una discrepancia, una suplantación de identidad, una situación de urgencia o un fraude
* explicar el motivo de las verificaciones importantes; y
* detenerse o buscar ayuda cuando el proceso supere sus competencias.

Las conductas críticas para la seguridad no pueden compensarse mediante un promedio. Revelar información de recuperación, aprobar una discrepancia conocida, continuar ante una aparente estafa u omitir una verificación obligatoria da lugar a la calificación **Aún no** hasta que se realicen un refuerzo específico y una nueva evaluación.
