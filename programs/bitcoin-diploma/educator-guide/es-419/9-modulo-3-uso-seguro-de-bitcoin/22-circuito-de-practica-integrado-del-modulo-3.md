# 9.22 Circuito de práctica integrado del módulo 3

Utilice las estaciones después de que los estudiantes hayan visto cada proceso.


| Estación | Tarea del estudiante | Enfoque de seguridad |
| --- | --- | --- |
| 1. Billetera y custodia | Identifique quién controla las claves y localice la función de recibir | No deduzca quién tiene la custodia a partir de la palabra “billetera” |
| 2. Público o secreto | Clasifique la información de pago y recuperación | Nunca revele secretos reales |
| 3. Recibir | Genere o localice una solicitud preparada e identifique su vía de pago | Comparta únicamente información para recibir pagos |
| 4. Enviar | Verifique el destinatario, la red, el destino, el monto, la unidad, la comisión y el resumen final | Deténgase ante cualquier discrepancia |
| 5. Recuperación | Ordene los pasos o realice una tarea preparada para comprobar que está listo para la recuperación | Trabaje en privado; no utilice una semilla real asociada a fondos |
| 6. Explorador | Lea el estado de una transacción y los datos públicos preparados para la actividad | Reconozca las implicaciones de privacidad y las limitaciones del explorador |
| 7. Estafa | Responda a una solicitud urgente de soporte o de cambio de dirección | Haga una pausa y verifique de forma independiente |
| 8. Vía | Compare dos vías locales de adquisición o pago | Sin respaldo ni asesoramiento |


No utilice las estaciones como evaluación formal a menos que se hayan aprobado las tareas exactas, las variantes, los criterios y los registros.
