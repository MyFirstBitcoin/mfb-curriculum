# 9.23 Conceptos erróneos comunes y respuestas

| Idea equivocada | Corrección adecuada para principiantes | Pregunta de comprobación |
| --- | --- | --- |
| Bitcoin se almacena en la aplicación de la billetera. | Bitcoin se registra en el libro contable compartido; la billetera administra las claves y la información de las transacciones. | ¿Qué quedaría si el celular se dañara? |
| Una dirección es una contraseña secreta. | Una dirección es información pública para recibir fondos, aunque vincularla con una identidad puede reducir la privacidad. | ¿Qué información autoriza el gasto? |
| Cualquier código QR es seguro porque la billetera lo escanea. | Un código QR puede codificar un destino o una solicitud incorrectos. Verifique el destinatario, la vía de pago, el monto y la pantalla final. | ¿Qué compararía usted después de escanearlo? |
| Compartir una dirección permite que otra persona gaste los fondos. | Gastar los fondos normalmente requiere la clave privada. Aun así, compartir una dirección puede revelar relaciones entre transacciones. | ¿Qué riesgo para la privacidad permanece? |
| Una frase semilla es una contraseña común. | En muchas billeteras, otorga acceso completo para la recuperación. Cualquier persona que la tenga puede recrear las claves. | ¿Un servicio de soporte legítimo la necesitaría alguna vez? |
| El educador debería revisar mi respaldo de la frase semilla. | Un educador puede observar el proceso seguro sin ver las palabras. | ¿Cómo puede usted demostrar que está preparado sin revelar la frase semilla? |
| Todas las billeteras son de autocustodia. | Algunas aplicaciones llamadas billeteras custodian las claves por el usuario. | ¿Quién aprueba los retiros y controla la recuperación? |
| Una billetera de hardware elimina el riesgo relacionado con el respaldo. | El dispositivo aísla las claves, pero la recuperación sigue dependiendo de un respaldo protegido y de un uso correcto. | ¿Qué sucede si el dispositivo se daña? |
| Una confirmación hace que cualquier pago sea seguro. | Las confirmaciones refuerzan el historial de liquidación; no corrigen un destino incorrecto ni una estafa. | ¿Qué verificaciones deben realizarse antes de aprobar el pago? |
| Un explorador de bloques es Bitcoin. | Es una interfaz de un tercero que permite consultar datos públicos. | ¿Qué verificación más sólida puede ofrecer un nodo? |
| Las comisiones se basan principalmente en cuánto bitcoin se envía. | Las comisiones por transacciones en la cadena dependen principalmente de los datos de la transacción y de la demanda de espacio en los bloques. | ¿Un pago de bajo monto puede tener una comisión alta? |
| Lightning siempre implica autocustodia y ausencia de comisiones. | Las billeteras Lightning pueden ser de custodia o de autocustodia, y las condiciones de enrutamiento, servicio o liquidez pueden generar comisiones y fallas. | ¿Qué dos preguntas distintas debería hacer usted? |
| Usar KYC siempre es seguro, o no usar KYC siempre es seguro. | Cada opción implica un intercambio entre riesgos relacionados con la identidad, el soporte, la contraparte, el fraude, los aspectos legales y la privacidad. | ¿Qué riesgo se reduce y cuál se añade? |
