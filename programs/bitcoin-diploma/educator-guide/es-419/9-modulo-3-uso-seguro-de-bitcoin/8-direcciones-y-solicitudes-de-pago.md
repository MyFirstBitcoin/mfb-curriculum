# 9.8 Direcciones y solicitudes de pago

Enseñe que, en la cadena, una [dirección de Bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-address) es información pública para recibir fondos, generada a partir de las claves de una billetera. No es una contraseña, una credencial de acceso a una cuenta ni una prueba de que la persona que solicita el pago sea confiable.

Enseñe estos hábitos para principiantes:

* obtener la dirección de la billetera que debe recibir los fondos
* confirmar que se trata de Bitcoin y de la red correcta
* distinguir una dirección en cadena de una [factura de Lightning](https://curriculum.myfirstbitcoin.org/lexicon/en/#lightning-invoice) o una dirección de Lightning
* copiar o escanear en lugar de escribir manualmente
* comparar después de copiar
* verificar la dirección completa en una pantalla confiable para pagos importantes
* usar una dirección nueva para cada nueva recepción de fondos cuando la billetera la proporcione; y
* hacer una prueba con un monto pequeño cuando el monto o el proceso no resulte familiar.

No les diga a los estudiantes que comprobar que solo los primeros y últimos caracteres coincidan es suficiente ante cualquier riesgo. Es una comprobación rápida útil, pero verificar la dirección completa en una pantalla confiable ofrece mayor seguridad para los pagos importantes.

#### Actividad: ¿público o secreto?

Prepare tarjetas para:

* dirección en cadena
* código QR de una dirección
* [factura de Lightning](https://curriculum.myfirstbitcoin.org/lexicon/en/#lightning-invoice)
* [_txid_](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction-id)
* [clave pública](https://curriculum.myfirstbitcoin.org/lexicon/en/#public-key)
* [clave privada](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key)
* [frase semilla](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase)
* contraseña o PIN de la billetera
* captura de pantalla del saldo; y
* plan de seguridad o recuperación.

Los estudiantes las clasifican en:

* información pública para recibir fondos o del [libro mayor](https://curriculum.myfirstbitcoin.org/lexicon/en/#ledger) público
* información secreta para gastar fondos o acceder a ellos; e
* información que depende del contexto y que puede ser técnicamente pública, pero privada en el ámbito personal.

En la reflexión final, aclare que «público en el protocolo» no significa «seguro para asociarlo con la identidad de una persona». Un [_txid_](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction-id) o una dirección pueden revelar actividad y relaciones.
