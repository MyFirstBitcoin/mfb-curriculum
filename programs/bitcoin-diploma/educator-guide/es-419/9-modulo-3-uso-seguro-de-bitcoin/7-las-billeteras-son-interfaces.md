# 9.7 Las billeteras son interfaces

Use la oración:

> Una [billetera de Bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#bitcoin-wallet) administra claves e información de transacciones. No almacena bitcoin dentro del celular o dispositivo.

Muestre la separación entre:

* el [libro contable compartido de Bitcoin](https://curriculum.myfirstbitcoin.org/lexicon/en/#ledger)
* las claves y la función de firma de la billetera
* la interfaz y la conexión de red de la billetera; y
* cualquier servicio externo del que dependa la billetera.

Pregunte:

* Si el celular se daña, ¿qué sigue existiendo?
* ¿Qué hace que el acceso se pueda o no se pueda recuperar?
* ¿Una aplicación llamada «billetera» siempre le da al usuario el control de las claves?

Al comparar billeteras, use criterios consistentes:

* [custodia](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody)
* procedencia verificada y condición de código abierto
* recuperación y compatibilidad
* [privacidad](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) y dependencia de servidores
* tipos de pago admitidos
* continuidad y mantenimiento
* costo y adecuación al dispositivo; y
* soporte seguro disponible.

Dé preferencia al software de billeteras de código abierto con una trayectoria consolidada cuando se ajuste a las necesidades del estudiante, porque el código que cualquiera puede inspeccionar puede mejorar la transparencia. Considere esa preferencia como parte de una evaluación contextual, no como una regla ni una garantía. Toda billetera implica ventajas y desventajas, y el código abierto no demuestra que una herramienta sea segura, reciba mantenimiento, esté correctamente instalada o sea adecuada para un estudiante. Ayude a los estudiantes a identificar si el código puede ser inspeccionado públicamente y a contrastar ese aspecto con la custodia, la recuperación, la compatibilidad, la privacidad, el costo, el mantenimiento y el soporte local seguro. No cree una lista global de billeteras aprobadas dentro del curso ni presente una billetera como la opción universal.
