# 10.8 Revisión de herramientas locales de Bitcoin

No haga una demostración de una herramienta simplemente porque sea popular a nivel local. Use esta comparación:


| Área | Pregunta |
| --- | --- |
| Propósito | ¿Qué problema resuelve la herramienta y es necesaria? |
| Custodia | ¿Quién controla las claves y los fondos? |
| Fuente | ¿Quién la publica y cómo se verificó la autenticidad de la fuente? |
| Código y mantenimiento | ¿Es de código abierto, se revisa, se mantiene y se actualiza de forma segura? |
| Recuperación | ¿Qué sucede cuando el dispositivo, el servicio o la empresa desaparece? |
| Privacidad | ¿Qué datos de identidad, contacto, dispositivo, ubicación y transacciones se recopilan? |
| Costo | ¿Qué comisiones visibles, diferenciales de precios, suscripciones, costos de depósito de fondos y costos de retiro se aplican? |
| Compatibilidad | ¿Qué redes, tipos de direcciones, facturas, copias de seguridad y dispositivos funcionan? |
| Soporte | ¿Pueden los estudiantes obtener ayuda sin compartir información secreta? |
| Legislación y registros | ¿Qué restricciones locales, normas de protección al consumidor u obligaciones fiscales, contables o de presentación de informes pueden ser relevantes? |
| Alternativa | ¿Qué pueden usar los estudiantes si la herramienta falla o no está disponible? |



> **Dark – Los ejemplos locales no son recomendaciones globales**
>
> Esta herramienta es un ejemplo local correspondiente a una fecha específica para fines de aprendizaje. Su uso en clase no constituye una recomendación global de My First Bitcoin ni una promesa de que seguirá siendo adecuada.
