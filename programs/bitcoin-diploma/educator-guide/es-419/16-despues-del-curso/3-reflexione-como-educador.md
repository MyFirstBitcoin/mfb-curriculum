# 16.3 Reflexione como educador

Complete esta revisión mientras tenga el curso fresco en la memoria:


| Pregunta | Notas y acciones |
| --- | --- |
| ¿Qué competencia tomó más o menos tiempo del previsto? |  |
| ¿Qué idea equivocada apareció repetidamente? |  |
| ¿Qué voces de los estudiantes se escucharon menos? |  |
| ¿Qué ejemplo local mejoró lo que los estudiantes podían explicar, comparar o hacer? |  |
| ¿Qué ejemplo se volvió político, promocional o demasiado personal? |  |
| ¿Qué actividad produjo evidencia útil? |  |
| ¿Qué actividad generó una simplificación engañosa? |  |
| ¿Fueron eficaces todas las condiciones para detener las actividades prácticas? |  |
| ¿Alguna herramienta, enlace, comisión, regla o listado quedó desactualizado? |  |
| ¿Qué juicio de evaluación requiere moderación? |  |
| ¿Qué adaptación de accesibilidad o de lenguaje debería conservarse? |  |
| ¿Qué cambiará antes del próximo grupo? |  |
