# 17.1 Terminologia lyhyesti ja väärinkäsityksiä ehkäisevät erottelut

Katsokaa täydelliset määritelmät sanastosta. Pitäkää nämä erottelut johdonmukaisina puheessa, dioissa, tehtävissä ja arvioinnissa.


| Käsitteet | Erottelu opettajalle |
| --- | --- |
| Raha / valuutta | Raha on laajempi väline tai omaisuuserä, jota käytetään vaihdantaan, laskentayksikkönä ja arvon säilyttämiseen ajan kuluessa; valuutta on tietty rahayksikkö tai rahajärjestelmä. |
| Tehtävä / ominaisuus | Tehtävä tarkoittaa sitä, mitä raha tekee; ominaisuus on piirre, joka vaikuttaa siihen, kuinka hyvin raha täyttää tehtävänsä. |
| Niukkuus / arvo | Niukkuus rajoittaa saatavuutta; arvo riippuu myös käytöstä, kysynnästä, mieltymyksistä, tiedosta ja asiayhteydestä. |
| Hintainflaatio / yksittäisen hinnan nousu | Inflaatio on yleisen hintatason jatkuvaa nousua; yksittäinen hinta voi muuttua monista syistä. |
| Pankkitalletus / fyysinen käteinen | Pankkitalletus on saaminen pankilta; fyysinen käteinen on eri rahamuoto, jonka liikkeeseenlaskija on lainkäyttöalueesta riippuen keskuspankki tai valtio. |
| Maksuvalmius / vakavaraisuus | Maksuvalmius koskee maksujen suorittamista ajallaan; vakavaraisuus koskee sitä, kattavatko varat velvoitteet. |
| CBDC / Bitcoin | CBDC on keskitetysti liikkeeseen laskettua digitaalista fiat-rahaa; Bitcoinilla ei ole keskitettyä liikkeeseenlaskijaa, ja se käyttää riippumattomasti todennettavia sääntöjä. |
| Bitcoin / bitcoin | Bitcoin viittaa verkkoon, protokollaan tai hankkeeseen; bitcoin viittaa omaisuuserään tai rahayksiköihin. |
| Bitcoin-protokolla / Bitcoin-palvelu | Protokolla on yhteinen sääntöjärjestelmä; lompakko, pörssi, lohkoketjuselain tai maksuyritys on erillinen palvelu tai työkalu. |
| Digitaalinen allekirjoitus / salaus | Allekirjoitus todistaa avaimella annetun valtuutuksen; salaus piilottaa luettavan sisällön. |
| Louhija / solmu | Louhija ehdottaa lohkoehdokkaita työntodisteen avulla; solmu tarkistaa sääntöjen noudattamisen. |
| Kehittäjän ehdotus / sääntömuutos | Kehittäjät ehdottavat ohjelmistoa; osallistujat päättävät, ottavatko he sen käyttöön. |
| Lohkoaika / aikataulu | Noin kymmenen minuuttia on pitkän aikavälin keskiarvo, ei tarkasti sovittu ajankohta. |
| Rajallinen tarjonta / hintatakuu | Ennakoitava enimmäismäärä on tarjonnan ominaisuus; se ei takaa kysyntää tai tuottoa. |
| Terve raha / tosiasia | Rahan luonnehtiminen terveeksi on arvio, joka perustuu ilmoitettuihin kriteereihin sekä hyötyjen ja haittojen punnintaan. |
| Lompakko / bitcoinin säilytys | Lompakko hallinnoi avaimia ja siirtoja; bitcoin pysyy kirjattuna yhteiseen tilikirjaan. |
| Osoite / yksityinen avain | Osoite vastaanottaa varoja; yksityinen avain valtuuttaa niiden käytön. |
| Palautuslause / salasana | Palautuslauseella voidaan luoda lompakon avaimet uudelleen, ja se mahdollistaa usein lompakon täyden palauttamisen; se ei ole tavallinen, nollattavissa oleva salasana. |
| Säilytyspalveluun perustuva / itsehallinnoitu | Erona on se, kuka hallitsee avaimia. |
| Kuuma / kylmä | Erona on avainten altistuminen verkkoon yhdistetylle yleiskäyttöiselle ympäristölle. |
| Lohkoketjussa / Lightning | Erona on maksun kulkureitti, ei säilytyksen hallinta. |
| Lohkoketjuselain / solmu | Lohkoketjuselain on kolmannen osapuolen käyttöliittymä; solmu tarkistaa sääntöjen noudattamisen itsenäisesti. |
| Vahvistus / oikein suoritettu maksu | Vahvistus vahvistaa maksun lopullisen selvityksen historiaa; se ei korjaa vastaanottajaa eikä vahvista maksun tarkoituksen asianmukaisuutta. |
| Yksityisyys / salaisuus | Yksityisyys tarkoittaa tietojen hallintaa; se ei tarkoita, ettei toimintaan liity julkisia tietoja tai oikeudellisia velvoitteita. |
| KYC / no-KYC | Näissä toimintatavoissa kerätään erilaisia henkilöllisyystietoja, ja niihin liittyy erilaisia tukea, yksityisyyttä, vastapuolia, petoksia ja lainsäädäntöä koskevia kompromisseja. Käyttäkää johdonmukaisesti termiä no-KYC. |
| Paikallinen esimerkki / suositus | Tarkistettu paikallinen esimerkki tukee oppimista; se ei ole yleispätevä suositus. |
