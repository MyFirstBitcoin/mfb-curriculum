# 8.21 Kertaus ja siirtymä moduuliin 3

Pyytäkää oppijoita täydentämään:


| Fiat-järjestelmän ongelma | Bitcoinin vastaus | Uusi vastuu tai kompromissi |
| --- | --- | --- |
| Rahan määrä voi muuttua rahapoliittisilla päätöksillä |  |  |
| Maksut ovat riippuvaisia välittäjistä |  |  |
| Yksi tilikirjan pitäjä hallitsee kirjauksia |  |  |
| Pääsy riippuu instituutiosta |  |  |


Edellyttäkää selkeää selitystä sille, miksi [solmuilla](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) ja [louhijoilla](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) on erilaiset roolit.

Käyttäkää sitten **moduulin 2** opiskelijan oppaan päätöskysymystä. Pitäkää vastaus yksityisenä tai vastaaminen vapaaehtoisena ja noudattakaa edellä annettuja ohjeita moduulin päättävästä kevyestä pohdinnasta.

Siirtymä:

> Bitcoin voi vähentää riippuvuutta tilin ylläpitäjästä, mutta suora hallinta riippuu avaimista, varmentamisesta, palauttamisesta ja turvallisista päätöksistä. **Moduuli 3** vie tämän vastuun käytäntöön.
