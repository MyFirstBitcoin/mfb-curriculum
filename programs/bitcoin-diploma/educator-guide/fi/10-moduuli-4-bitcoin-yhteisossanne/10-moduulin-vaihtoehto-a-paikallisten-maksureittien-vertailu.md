# 10.10 Moduulin vaihtoehto A: paikallisten maksureittien vertailu

**Tarkoitus:** Verratkaa maksun koko kulkua käytössä olevalla paikallisella maksutavalla, lohkoketjussa ja tarvittaessa Lightning-verkossa.

**Valmistelu:** Käyttäkää realistista, kuvitteellista maksusummaa ja vastaanottajaa. Valmistelkaa päivätyt paikalliset tiedot maksuista, valuutanvaihdosta, ajoituksesta, [säilytyksestä](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) ja käyttömahdollisuuksista. Jos tietoja ei voida varmentaa, merkitkää ne selvästi oletuksiksi.

**Oppijan tehtävä:** Täyttäkää:


| Vertailukohta | Nykyinen maksutapa | Bitcoin-maksu lohkoketjussa | Lightning, jos soveltuu |
| --- | --- | --- | --- |
| Lähetetty summa |  |  |  |
| Vastaanotettu kokonaissumma |  |  |  |
| Odotettu kesto ja maksun lopullinen vahvistuminen |  |  |  |
| Maksut ja osto- ja myyntikurssin erotus |  |  |  |
| Varojen säilytys kussakin vaiheessa |  |  |  |
| Henkilöllisyys ja yksityisyys |  |  |  |
| Maksun peruminen tai palautus |  |  |  |
| Keskeisin mahdollinen epäonnistumiskohta |  |  |  |
| Paikallinen tuki tai lainsäädäntö |  |  |  |


**Tuotos:** Oppija valitsee kuvitteelliseen tapaukseen maksureitin, havainnollistaa siihen liittyvän maksupyynnön ja maksun varmentamisen tai esittää niiden vaiheet järjestyksessä sekä selittää, miksi toinen reitti voisi olla parempi olosuhteen muuttuessa.

**Yhteinen pohdinta:** Paransiko Bitcoin maksun koko kulkua vai vain yhtä näkyvää vaihetta? Kuka kantaa kurssivaihteluun, valuutanvaihtoon, [säilytykseen](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) ja maksun epäonnistumiseen liittyvät riskit?

**Turvallisuus:** Oikeaa siirtoa tai nimettyä palveluntarjoajaa ei tarvita. Käyttäkää tulostettuja maksutietoja.
