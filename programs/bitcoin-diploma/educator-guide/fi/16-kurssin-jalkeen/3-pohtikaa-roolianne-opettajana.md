# 16.3 Pohtikaa roolianne opettajana

Täyttäkää tämä arviointi, kun kurssi on vielä tuoreessa muistissa:


| Kysymys | Muistiinpanot ja toimenpiteet |
| --- | --- |
| Minkä osaamisalueen käsittelyyn kului suunniteltua enemmän tai vähemmän aikaa? |  |
| Mikä väärinkäsitys nousi esiin toistuvasti? |  |
| Keiden oppijoiden ääni kuului vähiten? |  |
| Mikä paikallinen esimerkki paransi oppijoiden kykyä selittää, vertailla tai toimia? |  |
| Mikä esimerkki muuttui poliittiseksi, mainosluonteiseksi tai liian henkilökohtaiseksi? |  |
| Mikä tehtävä tuotti hyödyllistä näyttöä oppimisesta? |  |
| Mikä tehtävä johti harhaanjohtavaan yksinkertaistukseen? |  |
| Toimivatko kaikki käytännön harjoitusten keskeyttämisehdot? |  |
| Vanhentuiko jokin työkalu, linkki, maksu, sääntö tai listaus? |  |
| Mikä arviointipäätös edellyttää yhteistä tarkistamista arvioinnin yhdenmukaisuuden varmistamiseksi? |  |
| Mikä saavutettavuutta tai kieltä koskeva mukautus tulisi säilyttää? |  |
