# 4.7 Paikallinen varmennustietue

Täyttäkää yksi rivi kutakin opetuksessa käytettävää muuttuvaa tietoa, palvelua tai resurssia kohden.


| Kohde | Miksi se on tärkeä | Lähde tai paikallinen asiantuntija | Tarkistuspäivä | Mikä voi muuttua | Opetuksessa käytettävä sanamuoto tai varavaihtoehto |
| --- | --- | --- | --- | --- | --- |
| Paikallinen valuutta ja maksamista koskevat säännöt | Moduulin 1 keskustelu |  |  |  |  |
| Pankkisääntely ja talletussuoja | Osittaisvarantojärjestelmää käsittelevä osio |  |  |  |  |
| Virallinen inflaatiomittari ja hyödykekori | Ostovoimaa käsittelevä tehtävä |  |  |  |  |
| Digitaalisen keskuspankkirahan tila tai rakenne | Valinnainen paikallinen vertailu |  |  |  |  |
| Lompakko tai maksuväline | Moduulin 3 tai 4 harjoitus |  |  |  |  |
| Palkkiot, osto- ja myyntihintojen erot sekä rajoitukset | Paikallisten toimintatapojen vertailu |  |  |  |  |
| Lainsäädäntöön, verotukseen, yksityisyyteen tai raportointiin liittyvä toimintaympäristö | Paikallinen moduuli |  |  |  |  |
| Kauppias, kartta, tapaaminen tai tukiresurssi | Yhteisöön tutustuminen |  |  |  |  |


Suosikaa ajantasaisia sääntöjä tarkistaessanne luotettavia ensisijaisia lähteitä. Jos näyttö on puutteellista, kertokaa se. Älkää muuttako epävarmaa paikallista tietoa yleispäteväksi väitteeksi.
