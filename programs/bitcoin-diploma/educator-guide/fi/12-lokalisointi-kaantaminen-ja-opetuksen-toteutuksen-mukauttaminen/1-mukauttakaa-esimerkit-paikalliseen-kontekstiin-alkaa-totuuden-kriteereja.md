# 12.1 Mukauttakaa esimerkit paikalliseen kontekstiin, älkää totuuden kriteerejä

<!-- card: light -->
> **Mukauttakaa esimerkki paikallisiin oloihin, älkää oppimisvaatimusta**
>
> Käyttäkää paikallisia esimerkkejä auttaaksenne oppijoita hahmottamaan yhteinen käsite. Kysykää jokaisen mukautuksen kohdalla:
>
> * Mitä osaamista tämä tukee?
> * Säilyykö taustalla oleva käsite muuttumattomana?
> * Onko esimerkki paikkansapitävä ja ajantasainen?
> * Aiheuttaako se poliittisen, oikeudellisen, yksityisyyteen liittyvän tai turvallisuusriskin?
> * Voivatko oppijat osallistua paljastamatta henkilökohtaisia tietojaan?
> * Sisältääkö se epäsuoran suosituksen?
> * Tuottaako arviointi edelleen vastaavan näytön osaamisesta?


Kirjatkaa olennaiset muutokset, jotta toinen opettaja näkee, mitä mukautettiin paikallisiin oloihin ja miksi.
