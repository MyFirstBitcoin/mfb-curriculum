# 17.1 מונחים בקצרה והבחנות למניעת תפיסות שגויות

עיינו במילון המונחים לקבלת הגדרות מלאות. הקפידו על עקביות בהבחנות האלה בדיבור, במצגות, בפעילויות ובהערכה.


| מונחים | הבחנה לאנשי הוראה |
| --- | --- |
| כסף / מטבע | כסף הוא הכלי או הנכס במובנו הרחב, המשמש לחליפין, כיחידת חשבון ולשמירת ערך לאורך זמן; מטבע הוא יחידה או מערכת מוניטרית מסוימת. |
| תפקיד / תכונה | תפקיד הוא מה שהכסף עושה; תכונה היא מאפיין המשפיע על מידת הצלחתו בביצוע התפקיד. |
| נדירות / ערך | נדירות מגבילה את הזמינות; ערך תלוי גם בשימוש, בביקוש, בהעדפות, במידע ובהקשר. |
| אינפלציית מחירים / עלייה במחיר יחיד | אינפלציה היא עלייה מתמשכת ברמת המחירים הכללית; מחיר יחיד עשוי להשתנות מסיבות רבות. |
| פיקדון בנקאי / מזומן פיזי | פיקדון בנקאי הוא זכות תביעה כלפי הבנק; מזומן פיזי הוא צורה אחרת של כסף המונפק בידי בנק מרכזי או מדינה, בהתאם לתחום השיפוט. |
| נזילות / כושר פירעון | נזילות נוגעת ליכולת לשלם במועד; כושר פירעון נוגע לשאלה אם הנכסים מכסים את ההתחייבויות. |
| CBDC / ביטקוין | CBDC הוא כסף פיאט דיגיטלי המונפק באופן מרכזי; לביטקוין אין מנפיק מרכזי, והוא פועל לפי כללים שניתן לאמת באופן עצמאי. |
| ביטקוין / ביטקוין | ביטקוין מתייחס לרשת, לפרוטוקול או למיזם; ביטקוין מתייחס גם לנכס או ליחידות המטבע. |
| פרוטוקול ביטקוין / שירות ביטקוין | הפרוטוקול הוא מערכת הכללים המשותפת; ארנק, בורסה, סייר בלוקים או חברת תשלומים הם שירות או כלי נפרד. |
| חתימה דיגיטלית / הצפנה | חתימה מוכיחה הרשאה באמצעות מפתח; הצפנה מסתירה תוכן קריא. |
| כורה / צומת | כורה מציע בלוקים מועמדים באמצעות הוכחת עבודה; צומת מאמת עמידה בכללים. |
| הצעת מפתחים / שינוי כללים | מפתחים מציעים תוכנה; המשתתפים בוחרים אם לאמץ אותה. |
| זמן בלוק / לוח זמנים | כעשר דקות הן ממוצע לטווח ארוך, לא מועד מדויק שנקבע מראש. |
| היצע סופי / הבטחת מחיר | תקרה מרבית שניתן לצפות מראש היא תכונה של ההיצע; היא אינה מבטיחה ביקוש או תשואה. |
| כסף איתן / עובדה | כסף איתן הוא שיפוט המבוסס על קריטריונים מפורשים ועל שקלול יתרונות וחסרונות. |
| ארנק / אחסון ביטקוין | ארנק מנהל מפתחות ועסקאות; הביטקוין נשאר רשום בספר החשבונות המשותף. |
| כתובת / מפתח פרטי | כתובת משמשת לקבלת כספים; מפתח פרטי מאשר את הוצאתם. |
| מילות שחזור / סיסמה | מילות שחזור עשויות לשחזר את מפתחות הארנק, ולעיתים קרובות מאפשרות גישה מלאה לשחזור; הן אינן סיסמה רגילה שניתן לאפס. |
| משמורת צד שלישי / משמורת עצמית | ההבחנה היא מי שולט במפתחות. |
| חם / קר | ההבחנה היא חשיפת המפתחות לסביבה מקוונת לשימוש כללי. |
| על השרשרת / לייטנינג | ההבחנה היא מסלול התשלום, לא המשמורת. |
| סייר בלוקים / צומת | סייר בלוקים הוא ממשק של צד שלישי; צומת מאמת עמידה בכללים באופן עצמאי. |
| אישור / תשלום נכון | אישור מחזק את היסטוריית הסליקה; הוא אינו מתקן את זהות הנמען או מאמת את מטרת התשלום. |
| פרטיות / סודיות | פרטיות היא שליטה במידע; אין פירושה שלפעילות אין נתונים פומביים או חובות משפטיות. |
| KYC / no-KYC | מסלולים אלה אוספים מידע מזהה שונה וכרוכים בפשרות שונות בתחומי התמיכה, הפרטיות, הצד שכנגד, ההונאה והמשפט. השתמשו במונח no-KYC לאורך כל המסמך. |
| דוגמה מקומית / המלצה | דוגמה מקומית שנבדקה תומכת בלמידה; אין בה משום המלצה גורפת. |
