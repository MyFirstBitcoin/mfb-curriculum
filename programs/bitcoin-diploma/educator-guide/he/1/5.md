# 1.5 הדרך מלומד למחנך

הציגו את מסלול הלמידה הרחב של My First Bitcoin בתחילת דיפלומת ביטקוין, וחזרו אליו כשהלומדים שוקלים את צעדיהם הבאים:

**[מבוא לביטקוין](https://myfirstbitcoin.org/learn/programs#intro) → דיפלומת ביטקוין → [תוכנית להכשרת אנשי חינוך](https://etp.myfirstbitcoin.org/) → הצטרפות אל [רשת החינוך לביטקוין](https://myfirstbitcoin.org/about/network)**

* [**מבוא לביטקוין**](https://myfirstbitcoin.org/learn/programs#intro) מציע היכרות ראשונית קצרה לאנשים המעוניינים להכיר את היסודות לפני דיפלומת ביטקוין.
* **דיפלומת ביטקוין** בונה בסיס רחב יותר למתחילים באמצעות הסברים, דיונים ולמידה מעשית בטוחה.
* [**תוכנית להכשרת אנשי חינוך**](https://etp.myfirstbitcoin.org/) מסייעת לאנשים המעוניינים ללמד לפתח את מיומנויות ההנחיה וההערכה שלהם.
* **הצטרפות אל [רשת החינוך לביטקוין](https://myfirstbitcoin.org/about/network)** מחברת אנשי חינוך עם עמיתים כדי לשתף מניסיונם, לתמוך זה בזה ולתרום לחינוך בהובלת הקהילה.

הציגו זאת כאפשרות להמשך מעבר לדיפלומת ביטקוין, ולא כהוראה, תרגול, הערכה או הסמכה הנדרשים כחובה. הלומדים זקוקים למדריך לתלמיד, לאיש חינוך ולחומרים ולמשאבים שאיש החינוך מציין; הם יכולים להתחיל בדיפלומת ביטקוין ולבחור אם להמשיך להוראה או להשתתפות ברשת. ספקו קישורים ישירים לכל תוכנית רלוונטית כדי שהלומדים יוכלו לבחור את הצעד הבא; [מסלולי הלמידה הזמינים](https://myfirstbitcoin.org/learn/programs) יכולים להישאר כסקירה כללית נוספת, במקום להחליף את הקישורים הישירים האלה. כשמישהו מעוניין להמשיך, עזרו לו למצוא את המידע הרלוונטי על התוכנית או הרשת ולבדוק את תנאי הקבלה או ההשתתפות שלה.
