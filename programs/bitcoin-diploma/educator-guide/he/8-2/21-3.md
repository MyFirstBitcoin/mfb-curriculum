# 8.21 חזרה ומעבר למודול 3

בקשו מהלומדים להשלים:


| בעיה במערכת הפיאט | המענה של ביטקוין | אחריות חדשה או פשרה |
| --- | --- | --- |
| ההיצע יכול להשתנות בעקבות מדיניות |  |  |
| תשלומים תלויים במתווכים |  |  |
| גורם יחיד המנהל את ספר החשבונות שולט ברישומים |  |  |
| הגישה תלויה במוסד |  |  |


דרשו הסבר ברור מדוע [צמתים](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) ו[כורים](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) ממלאים תפקידים שונים.

לאחר מכן השתמשו ב**מודול 2** של המדריך לתלמיד, בשאלת הסיום. השאירו את התשובה פרטית או אפשרו לבחור אם להשיב, בהתאם להנחיות לעיל להתבוננות קצרה בסיום המודול.

מעבר:

> ביטקוין יכול להפחית את התלות במפעיל חשבון, אך שליטה ישירה תלויה במפתחות, באימות, בשחזור ובהחלטות בטוחות. **מודול 3** מתרגם את האחריות הזאת למעשה.
