# 9.22 מסלול תרגול משולב למודול 3

השתמשו בתחנות לאחר שהלומדים נחשפו לכל אחד מהתהליכים.


| תחנה | משימת הלומדים | דגש בטיחותי |
| --- | --- | --- |
| 1. ארנק ומשמורת | זהו מי שולט במפתחות ואתרו את פונקציית הקבלה | אל תסיקו מהמילה ״ארנק״ מי מחזיק במשמורת |
| 2. פומבי או סודי | סווגו מידע הנוגע לתשלום ולשחזור | לעולם אל תחשפו סודות אמיתיים |
| 3. קבלה | צרו בקשת תשלום או אתרו בקשה שהוכנה מראש, וזהו את מסלול התשלום שלה | שתפו רק מידע המיועד לקבלת תשלום |
| 4. שליחה | אמתו את הנמען, הרשת, היעד, הסכום, היחידה, העמלה והסיכום הסופי | עצרו בכל מקרה של אי־התאמה |
| 5. שחזור | סדרו לפי הסדר את שלבי משימת המוכנות לשחזור שהוכנה מראש, או בצעו אותה | עבדו בפרטיות; אין להשתמש בסיד אמיתי של ארנק המכיל כספים |
| 6. סייר בלוקים | קראו סטטוס עסקה ונתונים פומביים שהוכנו מראש | הכירו את היבטי הפרטיות של סייר הבלוקים ואת מגבלותיו |
| 7. הונאה | הגיבו לבקשה דחופה לתמיכה או לשינוי כתובת | עצרו ואמתו באופן עצמאי |
| 8. מסלול | השוו בין שני מסלולים מקומיים לרכישה או לתשלום | ללא הבעת תמיכה או מתן ייעוץ |


אל תשתמשו בתחנות לצורך הערכה רשמית אלא אם כן אושרו המשימות המדויקות, הגרסאות החלופיות, הקריטריונים ורישומי התיעוד.
