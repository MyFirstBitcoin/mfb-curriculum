# 4.7 רשומת אימות מקומי

מלאו שורה אחת לכל עובדה, שירות או משאב העשויים להשתנות ומשמשים בכיתה.


| פריט | מדוע הוא חשוב | מקור או מומחה מקומי | תאריך הבדיקה | מה עשוי להשתנות | ניסוח לשימוש בכיתה או חלופה |
| --- | --- | --- | --- | --- | --- |
| המטבע המקומי וכללי התשלום | דיון במודול 1 |  |  |  |  |
| אסדרה בנקאית והגנה על פיקדונות | הסעיף על בנקאות ברזרבה חלקית |  |  |  |  |
| המדד הרשמי לאינפלציה וסל המוצרים והשירותים | פעילות בנושא כוח הקנייה |  |  |  |  |
| הסטטוס או התכנון של מטבע דיגיטלי של בנק מרכזי | השוואה מקומית לבחירה |  |  |  |  |
| ארנק או כלי תשלום | תרגול במודול 3 או 4 |  |  |  |  |
| עמלות, מרווחים ומגבלות | השוואת דרכי פעולה מקומיות |  |  |  |  |
| ההקשר המקומי בנושאי חוק, מיסוי, פרטיות או דיווח | מודול מקומי |  |  |  |  |
| בית עסק, מפה, מפגש או משאב תמיכה | היכרות עם הקהילה |  |  |  |  |


העדיפו מקורות ראשוניים מוסמכים לבדיקת הכללים העדכניים. אם הראיות אינן שלמות, ציינו זאת. אל תהפכו מידע מקומי שאינו ודאי לטענה כללית.
