# 10.8 סקירת כלי ביטקוין מקומי

אל תדגימו כלי רק משום שהוא פופולרי באזורכם. השתמשו בהשוואה הבאה:


| תחום | שאלה |
| --- | --- |
| מטרה | איזו בעיה הכלי פותר, והאם הוא נחוץ? |
| משמורת | מי שולט במפתחות ובכספים? |
| מקור | מי מפרסם אותו, וכיצד אומתה מהימנות המקור? |
| קוד ותחזוקה | האם הקוד שלו פתוח, נבדק, מתוחזק ומתעדכן באופן בטוח? |
| שחזור | מה קורה כשהמכשיר, השירות או החברה נעלמים? |
| פרטיות | אילו נתוני זהות, פרטי קשר, נתוני מכשיר, מיקום ועסקאות נאספים? |
| עלות | אילו עמלות גלויות, מרווחי שער, דמי מנוי, עלויות הפקדה ועלויות משיכה חלים? |
| תאימות | אילו רשתות, סוגי כתובות, בקשות תשלום, גיבויים ומכשירים נתמכים? |
| תמיכה | האם הלומדים יכולים לקבל עזרה בלי לחשוף מידע סודי? |
| חוק ורישום | אילו מגבלות מקומיות, כללי הגנת הצרכן, חובות מס, ניהול חשבונות או דיווח עשויים להיות רלוונטיים? |
| חלופה | במה יכולים הלומדים להשתמש אם הכלי כושל או אינו זמין? |
