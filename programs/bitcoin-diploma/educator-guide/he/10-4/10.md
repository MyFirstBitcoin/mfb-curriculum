# 10.10 אפשרות א׳ למודול: השוואת מסלולי תשלום מקומיים

**מטרה:** השוו את המסלול המלא של תשלום מקומי בשיטה קיימת, של תשלום ביטקוין על גבי השרשרת ושל תשלום בלייטנינג, כאשר הדבר מתאים.

**הכנה:** השתמשו בסכום תשלום ובנמען מומצאים אך מציאותיים. הכינו מידע מקומי מתוארך על עמלות, המרה, זמני ביצוע, [משמורת](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), ונגישות. אם לא ניתן לאמת את הנתונים, סמנו אותם בבירור כהיפותטיים.

**משימה ללומדים:** השלימו:


| שדה | השיטה הקיימת | ביטקוין על גבי השרשרת | לייטנינג, אם רלוונטי |
| --- | --- | --- | --- |
| הסכום שנשלח |  |  |  |
| הסכום הכולל שהתקבל |  |  |  |
| הזמן הצפוי והציפייה לסליקה סופית |  |  |  |
| עמלות ומרווח המרה |  |  |  |
| משמורת בכל שלב |  |  |  |
| זהות ופרטיות |  |  |  |
| ביטול עסקה או החזר כספי |  |  |  |
| נקודת הכשל העיקרית |  |  |  |
| תמיכה מקומית או חקיקה מקומית |  |  |  |


**תוצר:** הלומד בוחר מסלול למקרה המומצא, מדגים את בקשת התשלום הרלוונטית ואת אימותה או מציג את שלביהן לפי הסדר, ומסביר מדוע המסלול האחר עשוי להיות עדיף אם אחד התנאים ישתנה.

**דיון מסכם:** האם ביטקוין שיפר את המסלול המלא, או רק שלב גלוי אחד? מי נושא בסיכוני תנודתיות, המרה, [משמורת](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), וכשל?

**בטיחות:** אין צורך בהעברה אמיתית או בספק מסוים. השתמשו בפרטי תשלום מודפסים.
