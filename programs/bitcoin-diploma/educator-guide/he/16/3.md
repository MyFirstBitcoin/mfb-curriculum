# 16.3 ערכו רפלקציה כאנשי חינוך

השלימו סקירה זו כשהקורס עדיין טרי בזיכרונכם:


| שאלה | הערות ופעולה |
| --- | --- |
| פיתוח איזו כשירות ארך יותר או פחות זמן מהמתוכנן? |  |
| איזו תפיסה שגויה הופיעה שוב ושוב? |  |
| קולותיהם של אילו לומדים נשמעו הכי פחות? |  |
| איזו דוגמה מקומית שיפרה את יכולתם של הלומדים להסביר, להשוות או לפעול? |  |
| איזו דוגמה הפכה לפוליטית, לפרסומית או לאישית מדי? |  |
| איזו פעילות הניבה ראיות מועילות? |  |
| איזו פעילות יצרה פישוט מטעה? |  |
| האם כל תנאי העצירה בתרגולים היו יעילים? |  |
| האם כלי, קישור, עמלה, כלל או רישום כלשהם הפכו ללא עדכניים? |  |
| איזו החלטת הערכה דורשת כיול? |  |
| איזו התאמת נגישות או שפה כדאי לשמר? |  |
| מה ישתנה לפני המחזור הבא? |  |
