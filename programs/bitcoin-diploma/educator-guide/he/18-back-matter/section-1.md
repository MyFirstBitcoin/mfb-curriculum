# נספח א׳: רשימת תיוג להכנה לקורס בעמוד אחד

### תוכנית הלימודים

* [ ] באפשרותי להסביר את הקו הסיפורי של ארבעת המודולים ואת ההבטחות ללומדים.
* [ ] עברתי על כל כשירות נדרשת המוערכת בקורס, על הקריטריונים שלה ועל סוג הראיות להוכחתה.
* [ ] ידוע לי שכל ארבעת המודולים הם לימודי חובה במסגרת דיפלומת הביטקוין, כיצד באפשרותי להתאים את **מודול 3** ולבחור את התכנים של **מודול 4**, ומה שייך ל[למידה מתקדמת](https://curriculum.myfirstbitcoin.org/programs/advanced-modules/).
* [ ] עיינתי ב[ספריית הפעילויות](https://curriculum.myfirstbitcoin.org/activities/en/) במקומות שבהם הדבר מועיל, ובחרתי פעילויות המכוונות לכשירות ברורה ולא לבידור בלבד.
* [ ] הכנתי חזרה וקטע קישור לכל מודול.

### לומדים ונגישות

* [ ] מוכרות לי הנחות היסוד בנוגע לשפה, לאוריינות, למיומנויות החשבון ולמכשירים של קבוצת הלומדים.
* [ ] ניתן מענה לצורכי הנגישות והוסדרו ההתאמות הנדרשות.
* [ ] הלומדים יכולים להשתמש בתרחישים מומצאים במקום לחשוף מידע פרטי.
* [ ] לוח הזמנים כולל תרגול, הערכה, משוב והערכה חוזרת.

### הקשר מקומי

* [ ] המידע המקומי על מערכת כסף הפיאט ועל הבנקאות עדכני ומגובה במקורות.
* [ ] מדד ה[אינפלציה](https://curriculum.myfirstbitcoin.org/lexicon/en/#inflation) הרשמי וסל המוצרים נבדקו.
* [ ] [CBDC](https://curriculum.myfirstbitcoin.org/lexicon/en/#cbdc) — הטענות בנושא עדכניות ומתייחסות למאפייני התכנון הספציפיים.
* [ ] הכלים, העמלות, השירותים, המשאבים והרשימות המקומיים מצוינים בצירוף תאריך.
* [ ] ההקשר המשפטי וההקשר הנוגע למיסוי, לפרטיות ולדיווח מוצגים ללא מתן ייעוץ.
* [ ] כל מומחה מקומי יכול להסביר את הגבולות הנוגעים לאיסור קידום מסחרי ולשמירה על פרטיות.

### בטיחות וטכנולוגיה

* [ ] אף משימה אינה דורשת מהלומדים שימוש ב[מילות שחזור](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase), במפתח, בפרטי גישה, ביתרה או בהיסטוריה אמיתיים שלהם.
* [ ] מכשירי ההדרכה והארנקים הוכנו ואופסו.
* [ ] פרטי תשלום לדוגמה מסומנים בכיתוב **דוגמה — אין לשלם**.
* [ ] ההדגמות החיות נבדקו מקצה לקצה.
* [ ] התנאים לעצירה ושלבי ההסלמה ברורים.
* [ ] לכל רכיב שהפעילות תלויה בו בזמן אמת או באופן מקוון יש חלופה שאינה מצריכה טכנולוגיה מתקדמת.
* [ ] הסידורים הנוגעים למכשירים, לחשמל, לאינטרנט, לטעינה ולחדר מוכנים.

### הערכה

* [ ] הפעילויות המשמשות להערכה מעניקות ללומדים הזדמנות ברורה והוגנת להדגים כל כשירות.
* [ ] הבאתי בחשבון את גודל קבוצת הלומדים, את הזמן הזמין, שאלות, פתרון תקלות, משוב והערכה חוזרת.
* [ ] ללומדים יינתן תרגול מלווה בתמיכה לפני שאקבע הערכה סופית.
* [ ] ידוע לי מה לחפש, כיצד לשאול שאלת המשך מועילה ומתי לתעד **כן** או **עדיין לא**.
* [ ] פתרונות מקוונים, פתרונות בטכנולוגיה פשוטה ופתרונות נגישות מוכנים לשימוש במידת הצורך.
* [ ] כל ההערות שומרות על [הפרטיות](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) ומכילות רק את המידע המועיל המינימלי הנחוץ.
* [ ] ידוע לי כיצד להציע תעודות השתתפות או סיום באופן הולם.
* [ ] אישרתי את התוצאה של כל לומד ולומדת לפני הפעלת [כלי התעודות](https://tools.myfirstbitcoin.org/certificate) ואבדוק את פרטי התעודות לפני חלוקתן.
