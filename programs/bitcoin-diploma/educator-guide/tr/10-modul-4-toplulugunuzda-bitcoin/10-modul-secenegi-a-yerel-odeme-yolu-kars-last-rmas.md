# 10.10 Modül seçeneği A: yerel ödeme yolu karşılaştırması

**Amaç:** Mevcut bir yerel ödemenin, zincir üstü bir yolun ve uygun olduğu durumlarda bir Lightning yolunun tüm güzergâhını karşılaştırın.

**Hazırlık:** Gerçekçi, kurgusal bir ödeme tutarı ve alıcı kullanın. Tarihli yerel ücret, döviz kuru, süre, [saklama](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) ve erişim bilgilerini hazırlayın. Veriler doğrulanamıyorsa bunları açıkça varsayımsal olarak etiketleyin.

**Öğrenci görevi:** Aşağıdaki tabloyu doldurun:


| Alan | Mevcut yöntem | Zincir üstü Bitcoin | Lightning (uygunsa) |
| --- | --- | --- | --- |
| Gönderilen tutar |  |  |  |
| Alınan toplam tutar |  |  |  |
| Süre ve kesinleşme beklentisi |  |  |  |
| Ücretler ve kur farkı |  |  |  |
| Her aşamadaki saklama |  |  |  |
| Kimlik ve gizlilik |  |  |  |
| İptal veya iade |  |  |  |
| Başlıca başarısızlık noktası |  |  |  |
| Yerel destek veya mevzuat |  |  |  |


**Üretim:** Öğrenci kurgusal durum için bir yol seçer, ilgili ödeme talebini ve doğrulamayı gösterir ya da adım adım sıralar ve koşullar değiştiğinde diğer yolun neden daha iyi olabileceğini açıklar.

**Değerlendirme:** Bitcoin tüm güzergâhı mı iyileştirdi, yoksa yalnızca görünen tek bir adımı mı? Oynaklık, dönüşüm, [saklama](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) ve başarısızlık riskini kim üstleniyor?

**Güvenlik:** Gerçek bir transfer veya adı belirtilmiş bir sağlayıcı gerekmez. Basılı ödeme bilgilerini kullanın.
