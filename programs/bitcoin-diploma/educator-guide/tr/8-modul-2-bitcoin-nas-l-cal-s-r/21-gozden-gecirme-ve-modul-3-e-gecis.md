# 8.21 Gözden Geçirme ve Modül 3'e Geçiş

Öğrencilerden şunu tamamlamalarını isteyin:


| Fiat sistemindeki sorun | Bitcoin'in yanıtı | Yeni sorumluluk veya ödünleşim |
| --- | --- | --- |
| Arz, politika yoluyla değişebilir |  |  |
| Ödemeler aracılara bağlıdır |  |  |
| Kayıtları tek bir defter tutucu kontrol eder |  |  |
| Erişim bir kuruma bağlıdır |  |  |


Şunun açıkça açıklanmasını isteyin: [düğümler](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) ve [madenciler](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) neden farklı rollere sahiptir?

Ardından **Modül 2** Öğrenci Rehberi'ndeki kapanış sorusunu kullanın. Yukarıdaki hafif modül kapanışı değerlendirme yönergelerine uygun olarak yanıtları gizli veya isteğe bağlı tutun.

Köprü:

> Bitcoin, bir hesap işletmecisine olan bağımlılığı azaltabilir; ancak doğrudan kontrol; anahtarlara, doğrulamaya, kurtarmaya ve güvenli kararlara bağlıdır. **Modül 3** bu sorumluluğu uygulamaya dönüştürür.
