# 16.3 Bir Eğitimci Olarak Değerlendirme Yapın

Kurs henüz tazeyken bu değerlendirmeyi tamamlayın:


| Soru | Notlar ve eylem |
| --- | --- |
| Hangi yetkinlik planlanandan daha fazla veya daha az zaman aldı? |  |
| Hangi yanlış kavrayış tekrar tekrar ortaya çıktı? |  |
| Hangi öğrencilerin sesi en az duyuldu? |  |
| Hangi yerel örnek, öğrencilerin açıklayabildiklerini, karşılaştırabildiklerini veya yapabildiklerini geliştirdi? |  |
| Hangi örnek siyasi, tanıtım amaçlı veya fazla kişisel bir hâl aldı? |  |
| Hangi etkinlik faydalı kanıt üretti? |  |
| Hangi etkinlik yanıltıcı bir basitleştirmeye yol açtı? |  |
| Uygulamalı çalışmalardaki tüm durdurma koşulları etkili oldu mu? |  |
| Herhangi bir araç, bağlantı, ücret, kural veya listeleme güncelliğini yitirdi mi? |  |
| Hangi değerlendirme kararının moderasyona ihtiyacı var? |  |
| Hangi erişilebilirlik veya dil uyarlaması korunmalı? |  |
| Bir sonraki gruptan önce neler değişecek? |  |
