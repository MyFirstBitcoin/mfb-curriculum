# 4.7 Yerel doğrulama kaydı

Derste kullanılan, değişkenlik gösteren her bilgi, hizmet veya kaynak için bir satır doldurun.


| Öğe | Neden önemli | Kaynak veya yerel uzman | Kontrol tarihi | Neler değişebilir | Sınıfta kullanılacak ifade veya alternatif |
| --- | --- | --- | --- | --- | --- |
| Yerel para birimi ve ödeme kuralları | Modül 1 tartışması |  |  |  |  |
| Bankacılık düzenlemeleri ve mevduat güvencesi | Kısmi rezerv bölümü |  |  |  |  |
| Resmî enflasyon ölçütü ve sepeti | Satın alma gücü etkinliği |  |  |  |  |
| MBDP'nin durumu veya tasarımı | İsteğe bağlı yerel karşılaştırma |  |  |  |  |
| Cüzdan veya ödeme aracı | Modül 3 veya 4 uygulaması |  |  |  |  |
| Ücretler, alım-satım farkları ve limitler | Yerel yolların karşılaştırması |  |  |  |  |
| Hukuki, vergisel, gizlilik veya raporlama bağlamı | Yerel modül |  |  |  |  |
| İşletme, harita, buluşma veya destek kaynağı | Topluluğu keşfetme |  |  |  |  |


Güncel kurallar için yetkili birincil kaynakları tercih edin. Kanıtlar eksikse bunu açıkça belirtin. Kesin olmayan yerel bilgileri evrensel bir iddiaya dönüştürmeyin.
