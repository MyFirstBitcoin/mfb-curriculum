# 8.17 FAQs zu den Eigenschaften von Bitcoin

| Eigenschaft | Frage von Lernenden | Einsteigergerechte Antwort |
| --- | --- | --- |
| Knappheit | „Kann nicht einfach jemand mehr als 21 Millionen bitcoin erzeugen?“ | Jemand kann zwar andere Software schreiben, aber die Teilnehmenden müssen sie nicht ausführen. Nodes, die den Regeln von Bitcoin folgen, lehnen eine darüber hinausgehende Ausgabe ab. Eine breite Übernahme inkompatibler Regeln könnte ein separates Netzwerk hervorbringen; kein Gründer, Miner, Entwickler, kein Unternehmen und keine Regierung kann stillschweigend zusätzliche gültige bitcoin für alle erzeugen. |
| Knappheit | „Bedeutet das begrenzte Angebot, dass der Preis steigen muss?“ | Nein. Der Preis hängt sowohl von der Nachfrage als auch vom Angebot ab, und die Nachfrage kann sinken. Ein begrenztes Angebot ist eine monetäre Eigenschaft, keine Renditegarantie. |
| Teilbarkeit | „Wenn es nur 21 Millionen gibt, reicht das dann für alle?“ | Ein bitcoin lässt sich in 100.000.000 Sats teilen. Kleinere Einheiten ermöglichen es, kleine Beträge darzustellen, ohne das Gesamtangebot zu erhöhen. |
| Teilbarkeit | „Muss ich einen ganzen bitcoin kaufen?“ | Nein. Lernende können Sats erklären oder verwenden, ohne einen ganzen bitcoin zu besitzen, und für das Bitcoin Diploma ist kein Besitz erforderlich. |
| Beständigkeit | „Was ist, wenn mein Handy kaputtgeht?“ | Bitcoin wird nicht im Handy gespeichert. Die Aufzeichnung im Netzwerk bleibt bestehen, aber der Zugriff hängt von sicher verwahrten Schlüsseln und der Wiederherstellung ab. Der Verlust eines Geräts lässt sich möglicherweise beheben; verlorene oder offengelegte Wiederherstellungsinformationen können zu einem dauerhaften Verlust führen. |
| Übertragbarkeit | „Kann ich es ohne Bedingungen überallhin senden?“ | Eine gültige Übertragung benötigt keine Genehmigung durch einen zentralen Bitcoin-Betreiber, erfordert aber dennoch eine geeignete Wallet, eine Kommunikationsverbindung, korrekte Zahlungsinformationen, Gebühren und einen Empfänger, der sie empfangen kann. Lokale Gesetze und Dienste können zusätzliche Einschränkungen mit sich bringen. |
| Fungibilität | „Ist jeder Sat genau gleich?“ | Gleiche Beträge unterliegen denselben Ausgaberegeln des Protokolls, doch die öffentliche Transaktionshistorie kann beeinflussen, wie manche Dienste oder Personen bestimmte Mittel behandeln. |
| Überprüfbarkeit | „Muss ich einer Website vertrauen?“ | Ein Explorer ist eine praktische Schnittstelle eines Drittanbieters. Ein Node ermöglicht eine stärkere unabhängige Überprüfung, während Einsteiger sich möglicherweise weiterhin auf Informationen ihrer Wallet oder eines Dienstes verlassen und diese Abhängigkeit erkennen sollten. |
| Akzeptanz | „Wenn Bitcoin nützlich ist, warum kann ich es nicht überall ausgeben?“ | Technische Möglichkeiten schaffen keine allgemeine Akzeptanz. Lokale Gewohnheiten, Werkzeuge, Kosten, Regulierung, Volatilität, Bildung und die Nachfrage von Händlern beeinflussen die Nutzung. |
| Dezentralisierung | „Ist Bitcoin vollständig dezentralisiert?“ | Einfluss und Infrastruktur sind nicht gleichmäßig verteilt. Die engere Aussage lautet, dass kein einzelner Teilnehmer gültige Guthaben oder Regeln einseitig für alle ändern kann. |
| Glaubwürdige Knappheit | „Warum nicht den Code kopieren und einen weiteren Coin erschaffen?“ | Code zu kopieren oder eine Angebotsobergrenze festzuschreiben ist möglich. Glaubwürdige Durchsetzung, unabhängige Überprüfung, Sicherheit, Geschichte, Verbreitung des Netzwerks und Widerstandsfähigkeit gegen einseitige Änderungen sind davon getrennte Fragen. |
