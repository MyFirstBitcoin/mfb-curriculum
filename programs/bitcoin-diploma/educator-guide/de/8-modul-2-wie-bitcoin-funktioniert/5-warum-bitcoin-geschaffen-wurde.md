# 8.5 Warum Bitcoin geschaffen wurde

Beginnen Sie mit dem Ziel: direkte Online-Zahlungen ohne einen zentralen finanziellen [Vermittler](https://curriculum.myfirstbitcoin.org/lexicon/en/#intermediary). Fragen Sie dann, was dies schwierig macht.

Ein zentrales digitales Zahlungssystem kann ein einziges maßgebliches [Hauptbuch](https://curriculum.myfirstbitcoin.org/lexicon/en/#ledger) führen und eine zweite Ausgabe ablehnen. Ein dezentrales System braucht unabhängige Teilnehmer, die sich auf eine gültige Historie einigen, ohne einem einzigen Datenbankbetreiber vertrauen zu müssen.


<!-- micrographic: central-ledger-vs-bitcoin-01 -->
[Bei einem Zahlungsdienstleister führt eine einzige Organisation das Kontobuch und genehmigt jede Überweisung. Bei Bitcoin signiert der Sender eine Transaktion, unabhängige Nodes prüfen sie und Miner fügen sie einem gemeinsamen Kontobuch hinzu, sodass der Empfänger weniger von einer zentralen Instanz abhängt.](/micrographics/central-ledger-vs-bitcoin-01/de.md)


Fragen Sie:

> Wenn ich eine digitale Datei perfekt kopieren kann, was hindert mich daran, dieselbe digitale Einheit an zwei Personen zu senden?

Stellen Sie klar, dass das Problem nicht darin besteht, das Bild einer Münze zu kopieren. Es geht darum, zu entscheiden, welche Übertragung einer knappen digitalen Einheit gültig ist.
