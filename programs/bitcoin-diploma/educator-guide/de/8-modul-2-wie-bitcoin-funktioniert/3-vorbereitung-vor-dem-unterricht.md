# 8.3 Vorbereitung vor dem Unterricht

* Nutzen Sie erneut den Vergleich der Geldeigenschaften aus **Modul 1**.
* Bereiten Sie ein leicht verständliches Double-Spend-Szenario vor.
* Bereiten Sie Rollenkarten für Nutzer, [Node](https://curriculum.myfirstbitcoin.org/lexicon/en/#node), [Miner](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner), Entwickler und optional einen Dienstleister vor.
* Bereiten Sie eine [Node](https://curriculum.myfirstbitcoin.org/lexicon/en/#node)-Regelkarte vor, die Folgendes enthält: gültige Signatur, kein Double Spend, gültiger [Proof of Work (PoW)](https://curriculum.myfirstbitcoin.org/lexicon/en/#proof-of-work) und zulässige Emission.
* Bereiten Sie eine Visualisierung zum [Halving](https://curriculum.myfirstbitcoin.org/lexicon/en/#halving) oder zur Emission ohne [Preis](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)diagramm vor.
* Bereiten Sie [Sat](https://curriculum.myfirstbitcoin.org/lexicon/en/#satoshi)-Umrechnungsbeispiele vor, die keine aktuellen Markt[preise](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) voraussetzen.
* Wählen Sie eine historische Transaktion oder einen datierten Explorer-Screenshot aus, wenn Sie öffentliche Daten zeigen.
* Gehen Sie die FAQ und die Tabellen zu Missverständnissen unten durch.
* Bereiten Sie einen kurzen angeleiteten Vergleich zwischen Bitcoin, einem allgemeinen Stablecoin-Modell und einem weiteren vom Emittenten kontrollierten digitalen [Vermögenswert](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset) vor. Rufen Sie im Unterricht keine bestimmten Token auf und bewerben Sie keine.
* Entscheiden Sie, welche technischen Fragen auf die Liste „Fortgeschritten“ gehören.
