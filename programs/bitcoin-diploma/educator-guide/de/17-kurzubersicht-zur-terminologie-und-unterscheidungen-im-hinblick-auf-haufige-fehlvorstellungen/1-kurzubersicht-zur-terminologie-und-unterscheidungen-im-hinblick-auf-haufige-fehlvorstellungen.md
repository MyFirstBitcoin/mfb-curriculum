# 17.1 Kurzübersicht zur Terminologie und Unterscheidungen im Hinblick auf häufige Fehlvorstellungen

Nutzen Sie das Lexikon für vollständige Definitionen. Halten Sie diese Unterscheidungen in Vorträgen, Folien, Aktivitäten und Prüfungen einheitlich ein.


| Begriffe | Unterscheidung für Lehrkräfte |
| --- | --- |
| Geld / Währung | Geld ist das umfassendere Instrument oder der Vermögenswert, der für Tausch, als Recheneinheit und zur Wertaufbewahrung über die Zeit dient; eine Währung ist eine bestimmte Geldeinheit oder ein bestimmtes Geldsystem. |
| Funktion / Eigenschaft | Eine Funktion beschreibt, was Geld leistet; eine Eigenschaft ist ein Merkmal, das beeinflusst, wie gut es dies leistet. |
| Knappheit / Wert | Knappheit begrenzt die Verfügbarkeit; der Wert hängt außerdem von Nutzung, Nachfrage, Präferenzen, Information und Kontext ab. |
| Preisinflation / einzelne Preiserhöhung | Inflation ist ein anhaltender Anstieg des allgemeinen Preisniveaus; ein einzelner Preis kann sich aus vielen Gründen ändern. |
| Bankeinlage / Bargeld | Eine Bankeinlage ist eine Forderung gegenüber der Bank; Bargeld ist je nach Rechtsordnung eine andere Form von Zentralbankgeld oder staatlich ausgegebenem Geld. |
| Liquidität / Solvenz | Liquidität betrifft die fristgerechte Zahlung; Solvenz betrifft die Frage, ob die Vermögenswerte die Verbindlichkeiten decken. |
| CBDC / Bitcoin | Eine CBDC ist zentral ausgegebenes digitales Fiatgeld; Bitcoin hat keinen zentralen Herausgeber und nutzt unabhängig überprüfbare Regeln. |
| Bitcoin / bitcoin | Bitcoin bezeichnet das Netzwerk, das Protokoll oder das Projekt; bitcoin bezeichnet den Vermögenswert oder die Einheiten. |
| Bitcoin-Protokoll / Bitcoin-Dienst | Das Protokoll ist das gemeinsame Regelwerk; eine Wallet, eine Börse, ein Explorer oder ein Zahlungsunternehmen ist ein eigenständiger Dienst oder ein eigenständiges Werkzeug. |
| Digitale Signatur / Verschlüsselung | Eine Signatur belegt die Autorisierung durch einen Schlüssel; Verschlüsselung verbirgt lesbare Inhalte. |
| Miner / Node | Ein Miner schlägt mittels Proof of Work (PoW) Kandidatenblöcke vor; ein Node überprüft die Regeln. |
| Entwicklervorschlag / Regeländerung | Entwickler schlagen Software vor; die Teilnehmenden entscheiden, ob sie diese übernehmen. |
| Blockzeit / Fahrplan | Etwa zehn Minuten sind ein langfristiger Durchschnitt, kein exakter Termin. |
| Begrenztes Angebot / Preisgarantie | Ein vorhersehbares Maximum ist eine Eigenschaft des Angebots; es garantiert weder Nachfrage noch Renditen. |
| Solides Geld / Tatsache | Solides Geld ist ein Urteil, das anhand ausdrücklich benannter Kriterien und Zielkonflikte gefällt wird. |
| Wallet / Aufbewahrung von bitcoin | Eine Wallet verwaltet Schlüssel und Transaktionen; bitcoin bleibt im gemeinsamen Hauptbuch verzeichnet. |
| Adresse / privater Schlüssel | Eine Adresse empfängt; ein privater Schlüssel autorisiert das Ausgeben. |
| Seed-Phrase / Passwort | Eine Seed-Phrase kann Wallet-Schlüssel wiederherstellen und gewährt oft vollen Wiederherstellungszugriff; sie ist kein gewöhnliches, zurücksetzbares Passwort. |
| Verwahrt / selbstverwahrt | Entscheidend ist, wer die Schlüssel kontrolliert. |
| Hot / Cold | Entscheidend ist, ob die Schlüssel einer mit dem Internet verbundenen Allzweckumgebung ausgesetzt sind. |
| On-Chain / Lightning | Entscheidend ist der Zahlungsweg, nicht die Verwahrung. |
| Explorer / Node | Ein Explorer ist eine Schnittstelle eines Drittanbieters; ein Node überprüft die Regeln unabhängig. |
| Bestätigung / korrekte Zahlung | Eine Bestätigung festigt die Abwicklungshistorie; sie korrigiert weder den Empfänger, noch bestätigt sie den Zweck. |
| Privatsphäre / Geheimhaltung | Privatsphäre bedeutet Kontrolle über Informationen; sie bedeutet nicht, dass zu einer Aktivität keine öffentlichen Daten oder rechtlichen Pflichten bestehen. |
| KYC / no-KYC | Diese Wege erfassen unterschiedliche Identitätsinformationen und bringen unterschiedliche Abwägungen in Bezug auf Support, Privatsphäre, Gegenparteien, Betrug und Recht mit sich. Verwenden Sie durchgehend den Begriff „no-KYC“. |
| Lokales Beispiel / Empfehlung | Ein geprüftes lokales Beispiel unterstützt das Lernen; es ist keine allgemeingültige Empfehlung. |
