# 16.3 Reflektieren Sie als Lehrkraft

Führen Sie diese Auswertung durch, solange Ihnen der Kurs noch frisch in Erinnerung ist:


| Frage | Notizen und Maßnahmen |
| --- | --- |
| Welche Kompetenz hat mehr oder weniger Zeit als geplant in Anspruch genommen? |  |
| Welches Missverständnis ist wiederholt aufgetreten? |  |
| Welche Lernenden kamen am wenigsten zu Wort? |  |
| Welches lokale Beispiel hat verbessert, was die Lernenden erklären, vergleichen oder tun konnten? |  |
| Welches Beispiel wurde politisch, werblich oder zu persönlich? |  |
| Welche Aktivität hat aussagekräftige Nachweise geliefert? |  |
| Welche Aktivität hat zu einer irreführenden Vereinfachung geführt? |  |
| Waren alle praktischen Abbruchbedingungen wirksam? |  |
| Ist ein Tool, ein Link, eine Gebühr, eine Regel oder ein Eintrag veraltet? |  |
| Welche Bewertungsentscheidung muss abgestimmt werden? |  |
| Welche Anpassung für Barrierefreiheit oder Sprache sollte beibehalten werden? |  |
| Was wird sich vor der nächsten Kohorte ändern? |  |
