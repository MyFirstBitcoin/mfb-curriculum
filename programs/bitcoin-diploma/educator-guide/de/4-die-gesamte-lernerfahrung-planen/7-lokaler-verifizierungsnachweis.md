# 4.7 Lokaler Verifizierungsnachweis

Füllen Sie für jede veränderliche Tatsache, jeden Dienst oder jede Ressource, die im Unterricht verwendet wird, eine Zeile aus.


| Element | Warum es wichtig ist | Quelle oder lokale Fachperson | Prüfdatum | Was sich ändern kann | Formulierung im Unterricht oder Ausweichlösung |
| --- | --- | --- | --- | --- | --- |
| Landeswährung und Zahlungsvorschriften | Diskussion in Modul 1 |  |  |  |  |
| Bankenregulierung und Einlagensicherung | Abschnitt zum Teilreservesystem |  |  |  |  |
| Offizielles Inflationsmaß und Warenkorb | Aktivität zur Kaufkraft |  |  |  |  |
| Status oder Ausgestaltung des digitalen Zentralbankgelds (CBDC) | Optionaler lokaler Vergleich |  |  |  |  |
| Wallet oder Zahlungsmittel | Übung in Modul 3 oder 4 |  |  |  |  |
| Gebühren, Spreads und Limits | Vergleich lokaler Wege |  |  |  |  |
| Rechtlicher, steuerlicher, datenschutzbezogener oder meldepflichtiger Kontext | Lokales Modul |  |  |  |  |
| Händler, Karte, Meetup oder Unterstützungsangebot | Community entdecken |  |  |  |  |


Bevorzugen Sie für aktuelle Vorschriften maßgebliche Primärquellen. Wenn die Beweislage unvollständig ist, weisen Sie darauf hin. Machen Sie aus unsicheren lokalen Informationen keine allgemeingültige Aussage.
