# 4.3 Ein wiederholbarer Rhythmus für zweistündige Module

Verwenden Sie dies als Planungsmuster, nicht als starres Drehbuch.


| Zeit | Zweck | Vorgehen der Lehrkraft |
| --- | --- | --- |
| 0–10 Min. | Begrüßung und Wiederholung | Stellen Sie eine kurze Frage zum zuvor Gelernten und machen Sie Unsicherheiten sichtbar. |
| 10–30 Min. | Erstes Konzept | Erklären Sie kurz, nutzen Sie eine Visualisierung oder ein lokales Beispiel und regen Sie eine beobachtbare Reaktion der Lernenden an. |
| 30–55 Min. | Hauptinteraktion | Moderieren Sie einen Vergleich, ein Spiel, ein Szenario, eine Rollenübersicht, eine Demonstration oder eine angeleitete Übung. |
| 55–65 Min. | Nachbesprechung | Verknüpfen Sie die Erfahrung mit der Kompetenz; korrigieren Sie, was die Aktivität nicht zeigen konnte. |
| 65–80 Min. | Zweites Konzept oder Demonstration | Führen Sie die nächste zentrale Idee ein und machen Sie, wo sinnvoll, den vollständigen Ablauf vor. |
| 80–105 Min. | Übung und Umsetzung | Die Lernenden wenden an, entscheiden, erklären oder führen aus – mit abnehmender Unterstützung. |
| 105–115 Min. | Lernkontrolle oder praktischer Nachweis | Holen Sie formatives Feedback ein, fordern Sie eine kompetenzorientierte Antwort ein, die Sie als Lehrkraft beurteilen, oder beobachten Sie eine praktische Fertigkeit. |
| 115–120 Min. | Rückblick und Überleitung | Benennen Sie die wichtigsten Erkenntnisse, offene Fragen und die Verbindung zum nächsten Modul. |


Praktische Beobachtung erfordert oft mehr Zeit, als dieses Muster vorsieht. Planen Sie für **Modul 3** und **Modul 4** innerhalb des Kursplans Stationen, eine weitere Lehrkraft oder kleinere Gruppen ein. Bewerten Sie nicht mehrere Lernende gleichzeitig, wenn Sie nicht die Entscheidungen und das Sicherheitsverhalten jeder einzelnen Person beobachten können.

Dieses Muster legt nicht fest, wie viel Zeit eine von der Lehrkraft durchgeführte Bewertung benötigt. Reservieren Sie im Zeitplan ausreichend Zeit für individuelle Nachweise, Feedback, Wiederholungsprüfungen und Dokumentation. Eine optionale formative Wiederholung kann das Lernen unterstützen, ohne den Bewertungsplan zu verändern.
