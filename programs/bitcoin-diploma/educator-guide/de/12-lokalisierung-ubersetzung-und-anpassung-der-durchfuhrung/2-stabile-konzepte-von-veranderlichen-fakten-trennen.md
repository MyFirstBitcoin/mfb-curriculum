# 12.2 Stabile Konzepte von veränderlichen Fakten trennen

| Stabiles Lehrplankonzept | Veränderliche lokale Tatsache |
| --- | --- |
| Eine Bankeinlage ist eine Forderung gegenüber einer Bank | Lokale Obergrenze und Anspruchsberechtigung der Einlagensicherung |
| Inflationsmessungen beruhen auf einem ausgewählten Warenkorb und einer bestimmten Methode | Aktuelle lokale Rate, Gewichtungen im Warenkorb und Veröffentlichungsmethodik |
| Eine CBDC ist von der Zentralbank ausgegebenes Fiatgeld | Ob die lokale Zentralbank eine solche erforscht, erprobt oder ausgibt |
| Verwahrung bedeutet Kontrolle über die Schlüssel | Das Verwahrungsmodell einer aktuellen Wallet-Version |
| Gebühren und Liquidität beeinflussen Zahlungswege | Aktuelle Gebührenschätzungen, Spreads von Diensten und Lightning-Liquidität |
| KYC und No-KYC bringen unterschiedliche Zielkonflikte mit sich | Aktuelle Identifizierungsvorschriften und rechtliche Anforderungen |
| Karteneinträge können veralten | Ob ein lokaler Händler heute Bitcoin akzeptiert |


Versehen Sie veränderliche Tatsachen mit einem Datum und sagen Sie den Lernenden, was sich ändern kann. Wenn Sie ein lokales Beispiel vorbereiten, können Sie den [KI-Assistenten des Bitcoin Diploma](https://ai.myfirstbitcoin.org) bitten, vorzuschlagen, welche Aussagen überprüft werden müssen und nach welchen Belegen Sie suchen sollten. Öffnen Sie die Originalquellen selbst, vergewissern Sie sich, dass sie jede Aussage stützen, und halten Sie Quelle und Datum fest; eine KI-Antwort ist kein Beleg dafür, dass eine Tatsache aktuell ist.
