# 12.7 Präsenzunterricht

* Ordnen Sie die Sitzplätze so an, dass Gespräche und Arbeit in Kleingruppen möglich sind.
* Richten Sie einen geschützten Bereich für Prüfungen ein.
* Präsentieren Sie praktische Vorführungen so, dass die Lernenden alles sehen können, ohne dass Geheimnisse offengelegt werden.
* Setzen Sie Stationen nur ein, wenn eine zuverlässige Beobachtung gewährleistet bleibt.
* Bereiten Sie sowohl papierbasierte als auch gerätebasierte Abläufe vor.
* Planen Sie Pausen, das Aufladen der Geräte und die sichere Aufbewahrung der Ausrüstung ein.
