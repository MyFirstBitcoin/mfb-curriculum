# 7.19 Modul 1 – Von der Lehrkraft geleiteter theoretischer Impuls

Verwenden Sie eine genehmigte Kurzaufgabe, die Zusammenhänge statt bloßer Definitionen verlangt. So erhalten Sie einen lehrkraftgeleiteten theoretischen Nachweis. Eine starke Antwort verbindet:

* eine Erklärung in eigenen Worten, warum es Geld gibt
* einen Vergleich zweier Geldformen anhand von mindestens zwei relevanten Eigenschaften
* ein lokales oder realistisches Szenario zu Fiatgeldsystem, Bankwesen, [Inflation](https://curriculum.myfirstbitcoin.org/lexicon/en/#inflation) oder [CBDC](https://curriculum.myfirstbitcoin.org/lexicon/en/#cbdc); und
* einen Nutzen, ein Risiko oder einen Zielkonflikt.

Achten Sie auf:

* korrekte Verwendung von Funktionen und Eigenschaften
* eine realistische Erklärung von Koordination oder Tausch
* das Bewusstsein, dass Geldgeschichte und Bankregeln unterschiedlich sind
* keine Behauptung, [Inflation](https://curriculum.myfirstbitcoin.org/lexicon/en/#inflation) habe nur eine einzige Ursache
* einen klaren Zusammenhang zwischen dem Beispiel und dem Konzept; und
* benannte Unsicherheit, wo die Beweislage unvollständig ist.

Werten Sie die Vorliebe der lernenden Person für [Fiatgeld](https://curriculum.myfirstbitcoin.org/lexicon/en/#fiat-money) oder Bitcoin nicht als Lernnachweis. Wenden Sie das genehmigte Bewertungsraster für theoretische Kontrollpunkte an, dokumentieren Sie individuell zuordenbare Nachweise, geben Sie Feedback und bieten Sie bei Bedarf eine erneute Prüfung an. Wurde die Aufgabe nicht für die Leistungsbewertung genehmigt, setzen Sie sie nur formativ ein.
