# 10.8 Bewertung lokaler Bitcoin-Tools

Führen Sie ein Tool nicht einfach deshalb vor, weil es vor Ort beliebt ist. Nutzen Sie diesen Vergleich:


| Bereich | Frage |
| --- | --- |
| Zweck | Welches Problem löst das Tool, und wird es überhaupt benötigt? |
| Verwahrung | Wer kontrolliert die Schlüssel und die Guthaben? |
| Quelle | Wer veröffentlicht es, und wie wurde die Echtheit der Quelle überprüft? |
| Code und Wartung | Ist es Open Source, geprüft, gepflegt und wird es sicher aktualisiert? |
| Wiederherstellung | Was passiert, wenn das Gerät, der Dienst oder das Unternehmen verschwindet? |
| Datenschutz | Welche Identitäts-, Kontakt-, Geräte-, Standort- und Transaktionsdaten werden erhoben? |
| Kosten | Welche sichtbaren Gebühren, Spreads, Abonnements, Einzahlungs- und Auszahlungskosten fallen an? |
| Kompatibilität | Welche Netzwerke, Adresstypen, Rechnungen, Backups und Geräte funktionieren? |
| Support | Können Lernende Hilfe erhalten, ohne Geheimnisse preiszugeben? |
| Recht und Aufzeichnungen | Welche lokalen Beschränkungen, Verbraucherschutzvorschriften, Steuer-, Buchhaltungs- oder Meldepflichten können relevant sein? |
| Alternative | Was können Lernende verwenden, wenn das Tool ausfällt oder nicht verfügbar ist? |



<!-- card: dark -->
> **Lokale Beispiele sind keine globalen Empfehlungen**
>
> Dieses Tool ist ein lokales Beispiel mit Stand zu einem bestimmten Zeitpunkt, das dem Lernen dient. Sein Einsatz im Unterricht ist weder eine globale Empfehlung von My First Bitcoin noch ein Versprechen, dass es geeignet bleibt.
