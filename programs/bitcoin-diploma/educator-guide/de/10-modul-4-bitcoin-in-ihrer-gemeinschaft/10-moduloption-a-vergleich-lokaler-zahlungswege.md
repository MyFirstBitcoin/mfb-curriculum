# 10.10 Moduloption A: Vergleich lokaler Zahlungswege

**Zweck:** Vergleichen Sie den vollständigen Weg einer bestehenden lokalen Zahlung, eines On-Chain-Pfads und, wo sinnvoll, eines Lightning-Pfads.

**Vorbereitung:** Verwenden Sie einen realistischen, erfundenen Zahlungsbetrag und Empfänger. Bereiten Sie datierte lokale Informationen zu Gebühren, Wechselkursen, Zeitabläufen, [Verwahrung](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) und Zugang vor. Wenn Daten nicht überprüft werden können, kennzeichnen Sie sie deutlich als hypothetisch.

**Aufgabe für Lernende:** Füllen Sie aus:


| Feld | Bestehende Methode | On-Chain-Bitcoin | Lightning, falls relevant |
| --- | --- | --- | --- |
| Gesendeter Betrag |  |  |  |
| Insgesamt empfangener Betrag |  |  |  |
| Zeit und erwartete Abwicklung |  |  |  |
| Gebühren und Spread |  |  |  |
| Verwahrung in jeder Phase |  |  |  |
| Identität und Privatsphäre |  |  |  |
| Stornierung oder Rückerstattung |  |  |  |
| Hauptfehlerquelle |  |  |  |
| Lokale Unterstützung oder Rechtslage |  |  |  |


**Ergebnis:** Die lernende Person wählt einen Pfad für den erfundenen Fall, demonstriert die entsprechende Zahlungsanforderung und Überprüfung oder bringt sie in die richtige Reihenfolge und erklärt, warum der andere Pfad unter veränderten Bedingungen besser sein könnte.

**Nachbesprechung:** Hat Bitcoin den gesamten Weg verbessert oder nur einen sichtbaren Schritt? Wer trägt das Risiko von Volatilität, Umtausch, [Verwahrung](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) und Ausfällen?

**Sicherheit:** Es ist weder eine echte Überweisung noch ein namentlich genannter Anbieter erforderlich. Verwenden Sie ausgedruckte Zahlungsinformationen.
