# 9.23 Häufige Missverständnisse und passende Antworten

| Missverständnis | Anfängergerechte Richtigstellung | Kontrollfrage |
| --- | --- | --- |
| Bitcoin wird in der Wallet-App gespeichert. | Bitcoin wird im gemeinsamen Hauptbuch erfasst; die Wallet verwaltet Schlüssel und Transaktionsinformationen. | Was bliebe übrig, wenn das Telefon kaputtginge? |
| Eine Adresse ist ein geheimes Passwort. | Eine Adresse ist eine öffentliche Empfangsinformation, auch wenn ihre Verknüpfung mit der Identität die Privatsphäre verringern kann. | Welche Information autorisiert das Ausgeben? |
| Jeder QR-Code ist sicher, weil die Wallet ihn scannt. | Ein QR-Code kann ein falsches Ziel oder eine falsche Anforderung enthalten. Überprüfen Sie Empfänger, Zahlungsweg, Betrag und den letzten Bildschirm. | Was würden Sie nach dem Scannen vergleichen? |
| Wer eine Adresse teilt, ermöglicht anderen das Ausgeben. | Zum Ausgeben ist normalerweise der Private Schlüssel erforderlich. Das Teilen einer Adresse kann dennoch Transaktionsbeziehungen offenlegen. | Welches Datenschutzrisiko bleibt bestehen? |
| Eine Seed-Phrase ist ein gewöhnliches Passwort. | Bei vielen Wallets ermöglicht sie den vollständigen Wiederherstellungszugriff. Jeder, der sie besitzt, kann die Schlüssel neu erzeugen. | Würde ein seriöser Support sie jemals benötigen? |
| Die Lehrkraft sollte meine Seed-Sicherung überprüfen. | Eine Lehrkraft kann den sicheren Ablauf beobachten, ohne die Wörter zu sehen. | Wie können Sie Ihre Bereitschaft nachweisen und die Sicherung trotzdem geheim halten? |
| Jede Wallet ist eine Selbstverwahrungs-Wallet. | Manche Anwendungen, die als Wallets bezeichnet werden, verwahren die Schlüssel für den Nutzer. | Wer genehmigt Auszahlungen und kontrolliert die Wiederherstellung? |
| Eine Hardware Wallet beseitigt das Risiko bei der Sicherung. | Das Gerät isoliert die Schlüssel, doch die Wiederherstellung hängt weiterhin von einer geschützten Sicherung und der richtigen Nutzung ab. | Was passiert, wenn das Gerät kaputtgeht? |
| Eine einzige Bestätigung macht jede Zahlung sicher. | Bestätigungen festigen die Abwicklungshistorie; sie korrigieren jedoch weder ein falsches Ziel noch einen Betrug. | Welche Prüfungen müssen vor der Freigabe erfolgen? |
| Ein Block Explorer ist Bitcoin. | Er ist eine Schnittstelle eines Drittanbieters zu öffentlichen Daten. | Welche stärkere Überprüfung kann eine Node bieten? |
| Gebühren richten sich hauptsächlich danach, wie viel bitcoin gesendet wird. | On-Chain-Gebühren hängen hauptsächlich von den Transaktionsdaten und der Nachfrage nach Blockplatz ab. | Kann eine Zahlung mit geringem Wert trotzdem eine hohe Gebühr haben? |
| Lightning bedeutet immer Selbstverwahrung und keine Gebühren. | Lightning-Wallets können verwahrend oder selbstverwahrend sein, und Routing-, Dienst- oder Liquiditätsbedingungen können Gebühren und Fehlschläge verursachen. | Welche zwei getrennten Fragen sollten Sie stellen? |
| KYC ist immer sicher, oder ohne KYC ist es immer sicher. | Jeder Weg wägt Risiken in Bezug auf Identität, Support, Gegenpartei, Betrug, Recht und Privatsphäre gegeneinander ab. | Welches Risiko wird verringert und welches kommt hinzu? |
