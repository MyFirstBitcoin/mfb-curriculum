# 6.3 Allgemeingültige Abbruchbedingungen

<!-- card: callout -->
> **Sofort abbrechen, wenn eine Sicherheitsprüfung fehlschlägt**
>
> Abbrechen ist ein erfolgreiches Sicherheitsverhalten. Schützen Sie Menschen und Geheimnisse, prüfen Sie das Problem und nutzen Sie einen vorbereiteten sicheren Weg oder verschieben Sie die Aktivität. Beschämen Sie die lernende Person nicht, die ein Problem bemerkt.


Brechen Sie die Aktivität sofort ab, wenn:

* eine echte [Seed-Phrase](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase), ein [privater Schlüssel](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key), ein Passwort oder Zugangsdaten auftauchen
* jemand eine lernende Person auffordert, Wiederherstellungsdaten preiszugeben oder einzugeben
* eine Adresse, eine Rechnung, ein Empfänger, ein Netzwerk, ein Betrag oder eine Einheit nicht übereinstimmt
* eine Wallet oder Website nicht aus der verifizierten Quelle stammt
* eine Aufforderung Dringlichkeit, Geheimhaltung oder Druck erzeugt oder eine Rendite verspricht
* das Tool sich anders verhält oder einen unbekannten Wiederherstellungsschritt verlangt
* eine lernende Person unsicher ist, ob echtes Geld im Spiel ist
* eine Transaktion unnötige Finanz- oder Identitätsdaten offenlegen würde
* ein Ausfall von Internet, Strom oder Gerät eine erforderliche Sicherheitsprüfung unmöglich macht; oder
* die Lehrkraft nicht erklären kann, was als Nächstes passiert.
