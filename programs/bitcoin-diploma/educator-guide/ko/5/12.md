# 5.12 미디어 및 도구 대체 방안

학생 가이드에는 Bitcoin Diploma에 필요한 정의, 비교, 안전 수칙, 복습 문제가 담겨 있어요. 보충 학습 링크와 이에 접속하기 위한 QR 코드는 선택 사항이에요. 이러한 자료는 최신 정보, 요약 자료, 원본 파일 또는 소통 방법을 제공할 수 있어요. 학습자는 이러한 보충 자료를 사용하지 않고도 과정을 마칠 수 있어요.

승인된 동등한 방법으로 역량을 유지할 수 있는 경우, Bitcoin Diploma의 필수 설명, 교육자의 형성 평가 확인, 실습 활동, 직접 관찰하는 실기 증거 중 어느 것도 동영상, 실시간 웹사이트, 특정 서비스 또는 학습자 소유 기기에 의존해서는 안 돼요.

시연에 인터넷 연결이 필요한 경우, 가능하면 인쇄된 지갑 화면, 거래 시나리오, 카드 활동, 단계별 토론과 같은 오프라인 대안을 준비해 두세요. 연결이 끊기더라도 수업이나 준비가 중단되어서는 안 돼요.


| 실시간 또는 온라인 활동 | 오프라인 또는 저기술 대안 |
| --- | --- |
| 지갑 탐색 | 순서대로 정리한 인쇄 지갑 화면 또는 예측을 위해 잠시 멈추는 녹화 영상 화면 투사 |
| 송금과 수신 | 주소 또는 인보이스 카드, 금액 카드, 종이로 만든 거래 흐름도 |
| QR 스캔 | 인쇄된 결제 정보 예시와 시각적 비교 |
| 블록 탐색기 | 미리 준비한 공개 거래의 날짜가 표시된 스크린샷 |
| 실시간 가격, 수수료 또는 인플레이션 데이터 | 출처와 한계를 명시하고 날짜를 표시해 미리 준비한 스냅숏 |
| 가맹점 또는 커뮤니티 지도 | 인쇄된 지역 지도와 검증된 목록 예시 |
| 라이트닝 결제 | 인보이스 카드와 경로 결제 시나리오 |
| 동영상 | 해설을 곁들인 도표, 스토리보드 또는 교육자의 설명 |
| 실시간 거래 | 시뮬레이션, 테스트 환경, 빈 연습용 지갑 또는 교육자 시연 |


오프라인 수업과 평가도 유효해요. 인터넷 연결이 제한될 때는 오프라인 지식 확인, 인쇄 활동, 역할극, 시뮬레이션을 활용하세요. 선택 사항인 형성 평가 복습은 인증에 포함되지 않아요.

학생 가이드는 오래 유효한 개념을 설명해요. 수수료, 법률, 세금, 이용 가능한 서비스, 지갑 기능 또는 가맹점 목록을 소개하기 전에 현재 지역의 세부 사항을 확인하고, 사용하는 정보에 날짜를 표시하세요.
