# 9.22 모듈 3 통합 실습 순환 활동

학습자가 각 과정을 모두 살펴본 뒤에 스테이션을 활용하세요.


| 스테이션 | 학습자 과제 | 안전 중점 사항 |
| --- | --- | --- |
| 1. 지갑과 수탁 | 누가 키를 통제하는지 파악하고 받기 기능을 찾아요 | ‘지갑’이라는 단어만 보고 수탁 여부를 추측하지 마세요 |
| 2. 공개 정보 또는 비밀 정보 | 결제 정보와 복구 정보를 분류해요 | 실제 비밀 정보는 절대 공개하지 마세요 |
| 3. 받기 | 준비된 요청을 생성하거나 찾고, 그 결제 경로를 파악해요 | 받기 정보만 공유하세요 |
| 4. 보내기 | 수신자, 네트워크, 목적지, 금액, 단위, 수수료, 최종 요약을 확인해요 | 하나라도 일치하지 않으면 중단하세요 |
| 5. 복구 | 준비된 복구 대비 과제의 순서를 정하거나 직접 수행해요 | 다른 사람이 보지 않는 곳에서 진행하고, 실제 자금이 있는 시드는 사용하지 마세요 |
| 6. 익스플로러 | 준비된 거래의 상태와 공개 데이터를 읽어요 | 익스플로러의 프라이버시 문제와 한계를 인식하세요 |
| 7. 사기 | 긴급한 지원 요청이나 주소 변경 요청에 대응해요 | 잠시 멈추고 독립적으로 확인하세요 |
| 8. 경로 | 현지의 취득 경로나 결제 경로 두 가지를 비교해요 | 특정 경로를 추천하거나 조언하지 마세요 |


구체적인 과제, 변형 문항, 평가 기준, 기록 방식이 승인되지 않았다면 스테이션을 공식 평가로 사용하지 마세요.
