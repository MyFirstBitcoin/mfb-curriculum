# 9.24 모듈 3 실습 증빙 자료

실기 평가에서는 학습자가 해당 활동을 안전하게 완료할 수 있는지, 그리고 다음을 할 수 있는지 관찰해요:

* 준비된 환경을 열거나 안전하게 접근하기
* 관련 없는 정보를 노출하지 않고 탐색하기
* 사용 중인 [수탁](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) 모델 파악하기
* 수신 정보와 비밀 정보 구분하기
* 의도한 결제 경로와 네트워크 선택하기
* 주소나 인보이스를 찾아 확인하기
* 해당되는 경우 수신자, 금액, 단위, 수수료, 만료 시간, 최종 요약 확인하기
* 받기 또는 보내기 과정을 완료하거나 안전하게 모의 실행하기
* 대기 중, 확인됨, 실패, 수신됨 상태 해석하기
* 복구 준비 과제 전반에 걸쳐 복구 정보 보호하기
* 정보 노출, 불일치, 사칭, 긴급 압박, 사기에 안전하게 대응하기
* 중요한 확인 절차가 필요한 이유 설명하기, 그리고
* 과정이 자신의 역량을 넘어서는 경우 멈추거나 도움 요청하기.

안전과 직결된 행동은 다른 점수로 상쇄될 수 없어요. 복구 정보를 드러내거나, 알고 있는 불일치를 승인하거나, 명백한 사기임에도 계속 진행하거나, 필수 검증을 우회하면 결과는 **아직 미달**이며, 이는 집중적인 보완 학습과 재평가를 거칠 때까지 유지돼요.
