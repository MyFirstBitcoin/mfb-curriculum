# 9.6 권장 수업 진행 순서

가능하면 두 개의 학습 파트와 별도의 평가 시간을 운영하세요.

#### 파트 A: 수탁의 기초


| 시간 | 학습 활동 | 권장 방법 |
| --- | --- | --- |
| 0–10분 | 안전 약속 정하기 | 공개 정보와 비밀 정보 구분하기 도입 점검 |
| 10–25분 | 지갑과 수탁 | '지갑은 인터페이스다' 시연 |
| 25–40분 | 주소, 키, 시드 문구 | 카드 분류 활동과 설명 |
| 40–58분 | 수탁형, 자기 수탁형, 핫, 콜드, 하드웨어 지갑 | 시나리오 비교 |
| 58–80분 | 복구 준비 | 교육자 발표, 안내에 따른 모의 실습, 디브리핑 |
| 80–105분 | 받기 | 받기 화면 단계별 안내와 학습자 실습 |
| 105–120분 | 복습 | 공유해도 되는 것, 반드시 비밀로 지켜야 하는 것, 키를 누가 통제하는지 설명하기 |


#### 파트 B: 검증과 안전


| 시간 | 학습 활동 | 권장 방법 |
| --- | --- | --- |
| 0–15분 | 보관 규칙 되짚기 | 안전 시나리오 |
| 15–40분 | 송금과 확인 | 예측을 곁들인 교육자 시연 |
| 40–58분 | 컨펌과 블록 탐색기 | 미리 준비한 거래 조회 |
| 58–73분 | 주소 기록과 재사용 | 미리 준비한 공개 주소 활동 |
| 73–93분 | 사기와 되돌릴 수 없는 실수 | 시나리오 스테이션 |
| 93–108분 | 비트코인 획득 경로 | 위험 지도 비교 |
| 108–120분 | 온체인과 라이트닝 | 결제 경로 분류 및 멈춤/도움 요청 복습 |


공식 관찰 평가는 지원을 받는 연습을 마친 뒤에만 계획하세요.
