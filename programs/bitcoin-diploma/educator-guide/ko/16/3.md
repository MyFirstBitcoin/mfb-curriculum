# 16.3 교육자로서 성찰하기

과정의 기억이 생생할 때 이 검토를 완료하세요:


| 질문 | 메모 및 조치 |
| --- | --- |
| 어떤 역량이 계획보다 시간이 더 걸렸거나 덜 걸렸나요? |  |
| 어떤 오개념이 반복해서 나타났나요? |  |
| 어떤 학습자의 목소리가 가장 적게 들렸나요? |  |
| 어떤 지역 사례가 학습자가 설명하고, 비교하고, 실행할 수 있는 능력을 향상시켰나요? |  |
| 어떤 사례가 정치적이거나, 홍보성이거나, 지나치게 사적인 방향으로 흘렀나요? |  |
| 어떤 활동이 유용한 증거를 만들어 냈나요? |  |
| 어떤 활동이 오해를 불러일으키는 단순화를 낳았나요? |  |
| 모든 실습 중단 조건이 효과적이었나요? |  |
| 도구, 링크, 수수료, 규정 또는 목록 중에 더 이상 최신이 아닌 것이 있었나요? |  |
| 어떤 평가 판단에 조정이 필요한가요? |  |
| 어떤 접근성 또는 언어 관련 조정을 유지해야 하나요? |  |
| 다음 기수가 시작되기 전에 무엇을 바꿀 건가요? |  |
