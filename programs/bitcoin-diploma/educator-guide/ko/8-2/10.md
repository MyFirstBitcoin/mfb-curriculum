# 8.10 사용자, 노드, 채굴자, 개발자, 서비스

초보자를 위해 다음 경계를 정확히 사용하세요:


| 역할 | 초보자 수준의 주요 기능 | 의미하지 않는 것 |
| --- | --- | --- |
| 사용자 | 직접 또는 서비스를 통해 비트코인을 받고, 보유하고, 보내고, 검증하고, 수락할지 선택하는 것 | 네트워크의 모든 부분을 자동으로 운영하는 것 |
| 노드 | 자신의 규칙에 따라 거래와 블록을 독립적으로 확인하고 유효한 데이터를 전달하는 것 | 새 블록을 만들거나 모든 사람에게 규칙을 강요하는 것 |
| 채굴자 | 후보 블록을 구성하고 작업 증명을 수행해 블록의 순서를 제안하는 것 | 정직한 노드가 보기에 유효하지 않은 발행이나 거래를 유효하게 만들 수 있는 것 |
| 개발자 | 소프트웨어를 검토하고, 작성하고, 제안하는 것 | 참여자들에게 규칙 변경을 강제로 채택하게 할 수 있는 것 |
| 비트코인 서비스 | 지갑, 거래소, 탐색기, 결제 또는 기타 인터페이스를 제공하는 것 | 비트코인 프로토콜 그 자체인 것 |

#### 활동: 유효하지 않은 블록

학습자 한 명에게 [채굴자](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) 역할을 맡기고 [후보 블록](https://curriculum.myfirstbitcoin.org/lexicon/en/#candidate-block)을 하나 주세요. 이 블록은 [노드](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) 규칙 카드가 허용하는 것보다 더 많은 보조금을 생성해요. [노드](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) 역할을 맡은 학습자들이 이를 확인하고 거부해요.

정리하기:

* 이 활동에서 [채굴자](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner)는 실제로 작업을 했지만, 그렇다고 규칙을 어길 권한을 얻은 것은 아니에요.
* [노드](https://curriculum.myfirstbitcoin.org/lexicon/en/#node)는 독립적으로 규칙을 적용하지만, 실제 네트워크는 교실 투표가 아니라 소프트웨어와 통신으로 이루어져요.
* 개발자는 다른 규칙을 작성할 수 있지만, 채택은 자발적이며 호환되지 않는 규칙은 별개의 네트워크를 만들 수도 있어요.

질문하기:

> 왜 [노드](https://curriculum.myfirstbitcoin.org/lexicon/en/#node)는 거래를 검증할까요? 노드가 확인하는 규칙을 하나 이상 말해 보세요.
