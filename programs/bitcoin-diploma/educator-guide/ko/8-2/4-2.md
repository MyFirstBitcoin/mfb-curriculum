# 8.4 권장 2시간 진행 흐름

| 시간 | 학습 단계 | 제안 방법 |
| --- | --- | --- |
| 0–10분 | 모듈 1 복습 | 화폐 문제 하나와 그로 인해 생기는 상충 관계를 말해 보기 |
| 10–27분 | 탈중앙화된 디지털 화폐가 어려웠던 이유 | 디지털 복제 및 이중 지불 시나리오 |
| 27–42분 | 비트코인의 종합적인 해법 | 과정 지도: 승인, 전파, 채굴, 검증, 기록 공유 |
| 42–62분 | 역할과 탈중앙화 | 사용자/노드/채굴자/개발자 역할 과제 |
| 62–77분 | 작업 증명 | 만들기는 비용이 많이 들고 확인은 빠른 시연 |
| 77–92분 | 공급량, 반감기, 사토시(sats) | 발행 모델과 단위 편향 점검 |
| 92–110분 | 건전 화폐 비교 | 모듈 1의 속성을 다시 활용하고, 장점과 상충 관계 추가하기 |
| 110–117분 | 범위와 책임 | 비트코인과 스테이블코인/기타 자산 비교, 학습과 투기 구분 |
| 117–120분 | 복습 및 연결 | 법정화폐의 문제 → 비트코인의 해법 → 새로운 책임 |
