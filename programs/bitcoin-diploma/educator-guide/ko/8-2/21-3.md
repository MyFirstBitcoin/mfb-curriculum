# 8.21 복습 및 모듈 3으로 넘어가기

학습자에게 다음 표를 완성하도록 하세요:


| 법정화폐 시스템의 문제 | 비트코인의 대응 | 새로운 책임 또는 트레이드오프 |
| --- | --- | --- |
| 정책에 따라 공급량이 바뀔 수 있음 |  |  |
| 결제가 중개자에 의존함 |  |  |
| 하나의 장부 관리자가 기록을 통제함 |  |  |
| 접근 여부가 기관에 달려 있음 |  |  |


학습자가 왜 [노드](https://curriculum.myfirstbitcoin.org/lexicon/en/#node)와 [채굴자](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner)가 서로 다른 역할을 하는지 명확하게 설명하도록 하세요.

그런 다음 **모듈 2** 학생 가이드의 마무리 질문을 활용하세요. 앞서 안내한 가벼운 모듈 마무리 성찰 지침에 따라 답변은 비공개로 하거나 선택 사항으로 두세요.

연결:

> 비트코인은 계좌 운영자에 대한 의존을 줄일 수 있지만, 직접적인 통제는 키, 검증, 복구, 그리고 안전한 의사결정에 달려 있어요. **모듈 3**에서는 그 책임을 실천으로 옮겨요.
