# 8.3 수업 전 준비하기

* 화폐 속성 비교 자료는 **모듈 1**의 것을 다시 활용하세요.
* 이중 지불 상황을 쉬운 말로 설명하는 시나리오를 준비하세요.
* 사용자, [노드](https://curriculum.myfirstbitcoin.org/lexicon/en/#node), [채굴자](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner), 개발자, 그리고 선택적으로 서비스 제공자의 역할 카드를 준비하세요.
* 다음 항목을 포함한 [노드](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) 규칙 카드를 준비하세요: 유효한 서명, 이중 지불 없음, 유효한 [작업증명](https://curriculum.myfirstbitcoin.org/lexicon/en/#proof-of-work), 허용된 발행량.
* 시각 자료를 준비하세요: [반감기](https://curriculum.myfirstbitcoin.org/lexicon/en/#halving) 또는 발행량을 보여 주되, [가격](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) 차트는 넣지 마세요.
* 예시를 준비하세요: [sat](https://curriculum.myfirstbitcoin.org/lexicon/en/#satoshi) 환산 예시로, 현재 시장 [가격](https://curriculum.myfirstbitcoin.org/lexicon/en/#price)이 필요 없는 것이어야 해요.
* 공개 데이터를 보여 줄 경우, 과거 거래나 날짜가 표시된 탐색기 화면 캡처를 선택하세요.
* 아래의 FAQ와 오개념 표를 검토하세요.
* 비트코인, 일반적인 스테이블코인 모델, 그리고 발행자가 통제하는 또 다른 디지털 [자산](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset)을 간단히 비교하는 안내형 활동을 준비하세요. 수업 중에는 특정 토큰을 검색하거나 홍보하지 마세요.
* 어떤 기술적 질문을 심화 목록으로 돌릴지 정하세요.
