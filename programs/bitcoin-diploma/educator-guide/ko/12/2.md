# 12.2 변하지 않는 개념과 변하는 사실을 구분하세요

| 변하지 않는 커리큘럼 개념 | 변하는 현지 사실 |
| --- | --- |
| 은행 예금은 은행에 대한 청구권이에요 | 현지 예금자 보호 한도와 보호 대상 요건 |
| 인플레이션 지표는 선정된 품목 바구니와 산출 방법을 사용해요 | 현재 현지 물가상승률, 품목 바구니의 가중치, 공표 방법론 |
| CBDC는 중앙은행이 발행하는 법정화폐예요 | 현지 중앙은행이 CBDC를 연구 중인지, 시범 운영 중인지, 발행하고 있는지 여부 |
| 보관(커스터디)이란 키를 통제하는 것을 의미해요 | 현재 지갑 버전의 보관 모델 |
| 수수료와 유동성은 결제 경로에 영향을 줘요 | 현재 수수료 추정치, 서비스 스프레드, 라이트닝 유동성 |
| KYC와 비KYC는 서로 다른 장단점을 만들어요 | 현재 신원 확인 규정과 법적 요건 |
| 지도에 등록된 정보는 오래되어 맞지 않게 될 수 있어요 | 현지 가맹점이 오늘 현재 비트코인을 받는지 여부 |


변하는 사실에는 날짜를 표시하고, 학습자에게 무엇이 바뀔 수 있는지 알려 주세요. 현지 사례를 준비할 때는 [Bitcoin Diploma AI 어시스턴트](https://ai.myfirstbitcoin.org)에게 어떤 주장을 확인해야 하는지, 어떤 근거를 찾아야 하는지 제안해 달라고 요청할 수 있어요. 원본 출처를 직접 열어 보고 각 주장을 뒷받침하는지 확인한 다음, 출처와 날짜를 기록해 두세요. AI의 답변은 어떤 사실이 현재도 유효하다는 근거가 되지 않아요.
