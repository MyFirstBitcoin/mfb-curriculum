# 부록 A: 한 페이지 강의 준비 체크리스트

### 교육과정

* [ ] 네 개 모듈로 이어지는 흐름과 학습자에게 약속하는 성과를 설명할 수 있어요.
* [ ] 필수 평가 역량마다 역량 기준과 증거 유형을 모두 검토했어요.
* [ ] 네 개 모듈이 모두 비트코인 디플로마의 필수 학습이라는 점, **모듈 3**을 어떻게 조정하고 **모듈 4**의 내용을 어떻게 선별할 수 있는지, 그리고 무엇이 [심화 학습](https://curriculum.myfirstbitcoin.org/programs/advanced-modules/)에 속하는지 알고 있어요.
* [ ] 필요한 경우 [활동 라이브러리](https://curriculum.myfirstbitcoin.org/activities/en/)를 검토했고, 단순한 재미보다는 명확한 역량을 기르는 활동을 선택했어요.
* [ ] 모든 모듈마다 복습과 다음 내용으로 넘어가는 연결 활동을 준비했어요.

### 학습자와 접근성

* [ ] 참여 집단의 언어, 문해력, 수리력, 기기 보유 여부에 대한 전제를 파악하고 있어요.
* [ ] 접근성 요구와 편의 지원이 마련되어 있어요.
* [ ] 학습자는 개인 정보를 밝히는 대신 가상의 상황을 활용할 수 있어요.
* [ ] 일정에 연습, 평가, 피드백, 재평가가 포함되어 있어요.

### 지역 상황

* [ ] 지역의 법정화폐 제도와 은행 관련 정보가 최신이며 출처가 밝혀져 있어요.
* [ ] 공식 [인플레이션](https://curriculum.myfirstbitcoin.org/lexicon/en/#inflation) 지표와 산정 품목 구성을 확인했어요.
* [ ] [CBDC](https://curriculum.myfirstbitcoin.org/lexicon/en/#cbdc) 관련 주장은 최신이며 구체적인 설계에 근거하고 있어요.
* [ ] 지역의 도구, 수수료, 서비스, 자료, 목록에 날짜가 표시되어 있어요.
* [ ] 법률, 세금, 개인정보, 신고 관련 맥락을 조언 없이 설명하도록 구성했어요.
* [ ] 초청하는 지역 전문가는 홍보 금지와 개인정보 보호의 경계를 설명할 수 있어요.

### 안전과 기술

* [ ] 어떤 과제도 학습자의 실제 [시드 문구](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase), 키, 자격 증명, 잔액, 거래 내역을 요구하지 않아요.
* [ ] 교육용 기기와 지갑이 준비되어 있고 초기화되어 있어요.
* [ ] 예시 결제 정보에는 **예시 — 결제하지 마세요**라는 표시가 되어 있어요.
* [ ] 실시간 시연을 처음부터 끝까지 테스트했어요.
* [ ] 중단 조건과 상위 보고 절차가 명확해요.
* [ ] 실시간 또는 온라인 환경에 의존하는 모든 요소에 저기술 대안이 마련되어 있어요.
* [ ] 기기, 전원, 인터넷, 충전, 교실 배치가 준비되어 있어요.

### 평가

* [ ] 평가에 사용하는 활동은 학습자에게 각 역량을 보여 줄 명확하고 공정한 기회를 제공해요.
* [ ] 참여 인원, 가용 시간, 질문, 문제 해결, 피드백, 재평가를 고려했어요.
* [ ] 최종 판단을 내리기 전에 학습자는 지원을 받으며 연습할 기회를 갖게 돼요.
* [ ] 무엇을 살펴봐야 하는지, 도움이 되는 후속 질문을 어떻게 하는지, 그리고 언제 **예** 또는 **아직**로 기록해야 하는지 알고 있어요.
* [ ] 필요한 경우 온라인, 저기술 환경, 접근성 지원 방식이 준비되어 있어요.
* [ ] 모든 기록은 [개인정보](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy)를 보호하며, 꼭 필요한 최소한의 정보만 남겨요.
* [ ] 참여 인증 또는 수료 인증을 적절하게 제공하는 방법을 알고 있어요.
* [ ] 각 학습자의 결과를 먼저 확인한 뒤 [Certificate Tool](https://tools.myfirstbitcoin.org/certificate)을 사용했으며, 배포하기 전에 수료증 세부 정보를 점검할 거예요.
