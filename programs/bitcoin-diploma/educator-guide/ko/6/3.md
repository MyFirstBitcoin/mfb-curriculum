# 6.3 공통 중단 조건

<!-- card: callout -->
> **안전 확인에 실패하면 즉시 중단하세요**
>
> 중단하는 것은 성공적인 안전 행동이에요. 사람과 비밀 정보를 보호하고, 문제를 확인한 뒤, 미리 준비한 안전한 대안을 사용하거나 활동을 연기하세요. 문제를 알아챈 학습자에게 창피를 주지 마세요.


다음과 같은 경우 활동을 즉시 중단하세요.

* 실제 [시드 문구](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase), [개인 키](https://curriculum.myfirstbitcoin.org/lexicon/en/#private-key), 비밀번호 또는 인증 정보가 노출될 때
* 누군가 학습자에게 복구 정보를 공개하거나 입력하라고 요구할 때
* 주소, 인보이스, 수신자, 네트워크, 금액 또는 단위가 일치하지 않을 때
* 지갑이나 웹사이트가 검증된 출처가 아닐 때
* 요청이 긴급함, 비밀 유지, 압박감 또는 수익 약속을 만들어 낼 때
* 도구의 동작이 바뀌거나 익숙하지 않은 복구 단계를 요구할 때
* 학습자가 실제 자금이 관련되어 있는지 확신하지 못할 때
* 거래로 인해 불필요한 금융 정보나 신원 정보가 노출될 수 있을 때
* 인터넷, 전원 또는 기기 장애로 필수 안전 확인을 할 수 없게 될 때, 또는
* 교육자가 다음에 무슨 일이 일어날지 설명할 수 없을 때예요.
