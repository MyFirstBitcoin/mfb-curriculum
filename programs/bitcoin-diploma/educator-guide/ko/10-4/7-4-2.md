# 10.7 모듈 4 권장 2시간 진행 흐름

| 시간 | 학습 단계 | 교육자 활동 |
| --- | --- | --- |
| 0–12분 | 지역의 필요 | 문제와 현재 사용하는 방법을 제시해요. 학습자에게 개인 정보 공개를 요구하지 않으면서 경험을 나누도록 권해요. |
| 12–28분 | 학습 내용 연결 | 모듈 1의 문제, 모듈 2의 대응, 모듈 3의 안전한 행동, 화폐 기능, 보관 방식, 결제 경로, 그리고 현실적인 기존 대안을 확인해요. |
| 28–48분 | 전체 시연 | 성공 경로와 실패 경로를 모두 보여 줘요. 비용, 프라이버시, 복구, 중단 조건을 설명해요. |
| 48–70분 | 지원을 받는 실습 | 학습자가 짝을 이루거나 스테이션별로 연습하고 교육자가 피드백을 줘요. |
| 70–90분 | 비교와 지역별 장단점 | 총 수령액, 시간, 수수료, 보관 방식, 프라이버시, 취소 가능성, 실패 측면에서 비트코인 경로를 현재 대안과 비교해요. |
| 90–110분 | 결과물 제작 또는 평가 | 승인된 개인 또는 팀 과제를 관찰하면서 식별 가능한 증거를 보존해요. |
| 110–118분 | 설명과 동료 질문 | 학습자가 목적, 이점, 위험, 실패 지점, 다음 단계를 설명해요. |
| 118–120분 | 과정 연결 | 최종 성찰과 필요한 재평가를 준비해요. |


직접 관찰을 일정에 넣을 수 없다면, 진행하기 전에 예정된 경로를 다시 설계해요. 승인된 평가자를 추가하거나, 수강 인원을 줄이거나, 더 긴 통합 과정으로 안내하세요. 안내된 Bitcoin Diploma 이후에 평가만을 위한 후속 일정을 추가하지 마세요.
