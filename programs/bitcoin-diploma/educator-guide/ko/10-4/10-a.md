# 10.10 모듈 옵션 A: 지역 결제 경로 비교

**목적:** 기존 현지 결제 방식, 온체인 경로, 그리고 해당되는 경우 라이트닝 경로의 전체 흐름을 비교해요.

**준비:** 현실적인 가상의 결제 금액과 수취인을 정해요. 날짜가 명시된 현지 수수료, 환전, 소요 시간, [수탁](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), 접근성 정보를 준비해요. 검증할 수 없는 데이터는 가상의 정보라고 명확히 표시해요.

**학습자 과제:** 다음 표를 완성해요:


| 항목 | 기존 방식 | 온체인 비트코인 | 라이트닝(해당되는 경우) |
| --- | --- | --- | --- |
| 송금액 |  |  |  |
| 총 수령액 |  |  |  |
| 소요 시간 및 결제 완료 예상 |  |  |  |
| 수수료 및 스프레드 |  |  |  |
| 각 단계별 수탁 주체 |  |  |  |
| 신원 및 프라이버시 |  |  |  |
| 취소 또는 환불 |  |  |  |
| 주요 실패 지점 |  |  |  |
| 현지 지원 또는 법규 |  |  |  |


**결과물:** 학습자는 가상 사례에 맞는 경로를 선택하고, 관련 결제 요청과 검증 과정을 시연하거나 순서대로 정리한 뒤, 조건이 달라지면 다른 경로가 더 나을 수 있는 이유를 설명해요.

**마무리 토론:** 비트코인이 전체 경로를 개선했나요, 아니면 눈에 보이는 한 단계만 개선했나요? 가격 변동성, 환전, [수탁](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), 실패 위험은 누가 부담하나요?

**안전:** 실제 송금이나 특정 서비스 제공업체는 필요하지 않아요. 인쇄된 결제 정보를 사용해요.
