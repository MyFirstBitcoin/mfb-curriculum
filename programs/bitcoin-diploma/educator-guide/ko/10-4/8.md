# 10.8 지역 비트코인 도구 검토

지역에서 인기가 있다는 이유만으로 도구를 시연하지 마세요. 다음 비교표를 활용하세요:


| 항목 | 질문 |
| --- | --- |
| 목적 | 이 도구는 어떤 문제를 해결하며, 정말 필요한가요? |
| 보관 | 키와 자금은 누가 통제하나요? |
| 출처 | 누가 배포하며, 정품 출처는 어떻게 확인했나요? |
| 코드 및 유지 관리 | 오픈 소스이며, 검토를 거쳤고, 유지 관리되며, 안전하게 업데이트되나요? |
| 복구 | 기기, 서비스 또는 회사가 사라지면 어떻게 되나요? |
| 개인정보 보호 | 어떤 신원, 연락처, 기기, 위치, 거래 데이터가 수집되나요? |
| 비용 | 표시된 수수료, 스프레드, 구독료, 입금 비용, 출금 비용 중 어떤 것이 적용되나요? |
| 호환성 | 어떤 네트워크, 주소 유형, 인보이스, 백업, 기기와 호환되나요? |
| 지원 | 학습자가 비밀 정보를 공유하지 않고도 도움을 받을 수 있나요? |
| 법률 및 기록 | 어떤 지역 규제, 소비자 보호 규정, 세금, 회계 또는 신고 의무가 관련될 수 있나요? |
| 대안 | 도구가 작동하지 않거나 이용할 수 없을 때 학습자는 무엇을 사용할 수 있나요? |



> **Dark – 지역 사례는 전 세계적인 추천이 아니에요**
>
> 이 도구는 학습을 위한 특정 시점의 지역 사례예요. 수업에서 이 도구를 사용한다고 해서 My First Bitcoin이 이를 전 세계적으로 추천하거나 앞으로도 계속 적합할 것이라고 보장하는 것은 아니에요.
