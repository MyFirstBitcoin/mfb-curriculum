# 7.4 권장 2시간 진행 흐름

이것은 최소한의 진행 경로예요. 학습 집단에 더 많은 경제적 배경 지식이나 지역 관련 토론이 필요할 때는 시간을 늘려 주세요.


| 시간 | 학습 단계 | 권장 방법 |
| --- | --- | --- |
| 0–12분 | 사전 생각 끌어내기 | 짝을 지어 도입 질문을 나눈 뒤 전체 토론 |
| 12–28분 | 돈이 존재하는 이유 | 교환 시나리오와 즉석 질문 |
| 28–45분 | 기능과 속성 | 지역 사례와 함께 돈의 속성 비교 |
| 45–58분 | 물물교환과 선택 | 욕구의 이중 일치에 관한 짧은 역할 시나리오, 희소성과 기회비용에 대한 정리 토론 |
| 58–70분 | 화폐의 역사 | 지역 사례를 더한 비선형 연표 |
| 70–92분 | 법정화폐 시스템의 역할 | 지역 결제 흐름 추적과 기관 지도 |
| 92–105분 | 은행 업무 | 대차대조표 스케치 또는 유동성/지급 능력 시나리오 |
| 105–115분 | 인플레이션, 구매력, CBDC | 날짜가 명시된 지역 자료를 활용한 토론 |
| 115–120분 | 복습과 다음 모듈로의 연결 | “돈은 …할 때 망가질 수 있어요” 설명하기 |


과정에 시간이 더 있다면 이 모듈을 두 부분으로 나누어 주세요. 먼저 돈의 기초를 다룬 다음, 현대 화폐의 장단점을 다루면 돼요.
