# 17.1 간단한 용어 정리와 오해하기 쉬운 개념 구분

전체 정의는 용어집을 참고하세요. 말할 때나 슬라이드, 활동, 평가에서 이 구분을 일관되게 유지해 주세요.


| 용어 | 교육자를 위한 구분 |
| --- | --- |
| 돈 / 통화 | 돈은 교환, 계산, 그리고 시간에 걸친 가치 저장에 쓰이는 더 넓은 의미의 도구나 자산이에요. 통화는 특정한 화폐 단위나 화폐 제도를 말해요. |
| 기능 / 속성 | 기능은 돈이 하는 일이고, 속성은 돈이 그 일을 얼마나 잘 해내는지에 영향을 주는 성질이에요. |
| 희소성 / 가치 | 희소성은 구할 수 있는 양을 제한해요. 가치는 그 밖에도 쓰임새, 수요, 선호, 정보, 맥락에 따라 달라져요. |
| 물가 인플레이션 / 한 가지 가격의 상승 | 인플레이션은 전반적인 물가 수준이 지속적으로 오르는 현상이에요. 한 가지 가격은 여러 가지 이유로 바뀔 수 있어요. |
| 은행 예금 / 실물 현금 | 은행 예금은 은행이 갚아야 할 채권이에요. 실물 현금은 관할 지역에 따라 중앙은행이나 국가가 발행하는 별개 형태의 돈이에요. |
| 유동성 / 지급 능력 | 유동성은 제때 지급할 수 있는지에 관한 것이고, 지급 능력은 자산이 부채를 감당할 수 있는지에 관한 것이에요. |
| CBDC / 비트코인 | CBDC는 중앙에서 발행하는 디지털 법정화폐예요. 비트코인은 중앙 발행자가 없고, 누구나 독립적으로 검증할 수 있는 규칙을 사용해요. |
| 비트코인(Bitcoin) / 비트코인(bitcoin) | 대문자로 시작하는 Bitcoin은 네트워크, 프로토콜 또는 프로젝트를 가리키고, 소문자로 쓰는 bitcoin은 자산이나 단위를 가리켜요. |
| 비트코인 프로토콜 / 비트코인 서비스 | 프로토콜은 모두가 공유하는 규칙 체계예요. 지갑, 거래소, 익스플로러, 결제 회사는 그와 별개인 서비스나 도구예요. |
| 디지털 서명 / 암호화 | 서명은 키를 통한 승인을 증명하고, 암호화는 읽을 수 있는 내용을 숨겨요. |
| 채굴자 / 노드 | 채굴자는 작업 증명을 통해 후보 블록을 제안하고, 노드는 규칙을 검증해요. |
| 개발자 제안 / 규칙 변경 | 개발자는 소프트웨어를 제안하고, 참여자들이 그것을 채택할지 선택해요. |
| 블록 시간 / 정해진 일정 | 약 10분은 장기적인 평균이지, 정확히 정해진 시각이 아니에요. |
| 유한한 공급량 / 가격 보장 | 예측 가능한 최대치는 공급의 속성이에요. 그것이 수요나 수익을 보장하지는 않아요. |
| 건전화폐 / 사실 | 건전화폐는 명시된 기준과 장단점을 따져서 내리는 판단이에요. |
| 지갑 / 비트코인 보관 | 지갑은 키와 트랜잭션을 관리해요. 비트코인은 계속 공유 원장에 기록되어 있어요. |
| 주소 / 개인 키 | 주소는 받는 데 쓰이고, 개인 키는 지출을 승인해요. |
| 시드 문구 / 비밀번호 | 시드 문구는 지갑 키를 다시 만들어 낼 수 있고, 대개 지갑을 완전히 복구할 수 있는 권한을 줘요. 재설정할 수 있는 일반적인 비밀번호가 아니에요. |
| 수탁형 / 자기 수탁형 | 누가 키를 통제하느냐로 구분해요. |
| 핫 / 콜드 | 키가 온라인에 연결된 범용 환경에 노출되는지로 구분해요. |
| 온체인 / 라이트닝 | 수탁 여부가 아니라 결제 경로로 구분해요. |
| 익스플로러 / 노드 | 익스플로러는 제3자가 제공하는 인터페이스이고, 노드는 규칙을 독립적으로 검증해요. |
| 컨펌 / 올바른 결제 | 컨펌은 결제 확정 이력을 더 견고하게 해 줘요. 하지만 받는 사람을 바로잡아 주거나 결제 목적이 타당한지 검증해 주지는 않아요. |
| 프라이버시 / 비밀 유지 | 프라이버시는 정보에 대한 통제권이에요. 어떤 활동에 공개된 데이터나 법적 의무가 없다는 뜻은 아니에요. |
| KYC / no-KYC | 이 두 경로는 서로 다른 신원 정보를 수집하며, 지원, 프라이버시, 거래 상대방, 사기, 법적 측면에서 서로 다른 트레이드오프를 만들어요. 전체에 걸쳐 no-KYC라는 표현을 사용하세요. |
| 현지 사례 / 추천 | 검증된 현지 사례는 학습에 도움이 되지만, 보편적인 보증은 아니에요. |
