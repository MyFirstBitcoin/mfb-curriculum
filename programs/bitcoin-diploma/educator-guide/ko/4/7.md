# 4.7 로컬 검증 기록

수업에서 사용하는 사실, 서비스, 자료 중 변할 수 있는 항목마다 한 행씩 작성해 주세요.


| 항목 | 중요한 이유 | 출처 또는 현지 전문가 | 확인 날짜 | 변경될 수 있는 내용 | 수업용 표현 또는 대안 |
| --- | --- | --- | --- | --- | --- |
| 현지 통화 및 결제 규정 | 모듈 1 토론 |  |  |  |  |
| 은행 규제 및 예금자 보호 | 부분지급준비제도 섹션 |  |  |  |  |
| 공식 인플레이션 지표 및 품목 바구니 | 구매력 활동 |  |  |  |  |
| CBDC 현황 또는 설계 | 선택적 현지 비교 |  |  |  |  |
| 지갑 또는 결제 도구 | 모듈 3 또는 4 실습 |  |  |  |  |
| 수수료, 스프레드 및 한도 | 현지 경로 비교 |  |  |  |  |
| 법률, 세금, 개인정보 보호 또는 신고 관련 맥락 | 현지 모듈 |  |  |  |  |
| 가맹점, 지도, 밋업 또는 지원 자료 | 커뮤니티 탐색 |  |  |  |  |


현행 규정은 권위 있는 1차 출처를 우선적으로 참고해 주세요. 근거가 불완전하다면 그 사실을 밝혀 주세요. 불확실한 현지 정보를 보편적인 주장으로 바꾸지 마세요.
