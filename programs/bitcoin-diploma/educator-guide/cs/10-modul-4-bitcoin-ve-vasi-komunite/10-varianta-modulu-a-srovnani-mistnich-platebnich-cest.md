# 10.10 Varianta modulu A: srovnání místních platebních cest

**Účel:** Porovnejte celý průběh platby při použití stávajícího místního způsobu placení, platby na blockchainu a případně platby přes Lightning.

**Příprava:** Použijte realistickou smyšlenou částku platby a smyšleného příjemce. Připravte informace s uvedeným datem platnosti o místních poplatcích, směně, časové náročnosti, [úschově](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) a dostupnosti. Pokud údaje nelze ověřit, jasně je označte jako hypotetické.

**Úkol pro studující:** Vyplňte:


| Položka | Stávající způsob | Bitcoin na blockchainu | Lightning, je-li relevantní |
| --- | --- | --- | --- |
| Odeslaná částka |  |  |  |
| Celková přijatá částka |  |  |  |
| Očekávaná doba a způsob vypořádání |  |  |  |
| Poplatky a kurzové rozpětí |  |  |  |
| Úschova v jednotlivých fázích |  |  |  |
| Identita a soukromí |  |  |  |
| Storno nebo vrácení peněz |  |  |  |
| Hlavní bod možného selhání |  |  |  |
| Místní podpora nebo právní úprava |  |  |  |


**Výstup:** Studující zvolí pro smyšlený případ způsob platby, předvede příslušný platební požadavek a ověření nebo popíše pořadí jednotlivých kroků a vysvětlí, proč by při změně určité podmínky mohl být jiný způsob vhodnější.

**Závěrečná reflexe:** Zlepšil Bitcoin celý průběh platby, nebo jen jeden viditelný krok? Kdo nese rizika spojená s volatilitou, směnou, [úschovou](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) a selháním?

**Bezpečnost:** Není nutný žádný skutečný převod ani konkrétní poskytovatel. Použijte vytištěné platební údaje.
