# 16.3 Zamyslete se jako pedagog

Vyplňte toto ohlédnutí, dokud máte kurz v čerstvé paměti:


| Otázka | Poznámky a opatření |
| --- | --- |
| Která kompetence zabrala více či méně času, než bylo plánováno? |  |
| Která mylná představa se opakovaně objevovala? |  |
| Kteří účastníci dostávali nejméně prostoru se vyjádřit? |  |
| Který příklad z místního prostředí zlepšil to, co účastníci dokázali vysvětlit, porovnat nebo udělat? |  |
| Který příklad nabyl politického, propagačního nebo příliš osobního rázu? |  |
| Která aktivita přinesla užitečné doklady o učení? |  |
| Která aktivita vedla k zavádějícímu zjednodušení? |  |
| Byly všechny podmínky pro zastavení praktických činností účinné? |  |
| Přestal být některý nástroj, odkaz, poplatek, pravidlo či záznam v seznamu aktuální? |  |
| Který hodnoticí úsudek je třeba přezkoumat a sladit s ostatními hodnotiteli? |  |
| Kterou úpravu pro lepší přístupnost nebo jazykové porozumění je vhodné zachovat? |  |
| Co se změní před zahájením výuky další skupiny? |  |
