# 4.7 Záznam o místním ověření

Vyplňte jeden řádek pro každý proměnlivý údaj, službu nebo zdroj použitý ve výuce.


| Položka | Proč je důležitá | Zdroj nebo místní odborník | Datum ověření | Co se může změnit | Formulace pro výuku nebo náhradní řešení |
| --- | --- | --- | --- | --- | --- |
| Místní měna a pravidla pro platby | Diskuse v modulu 1 |  |  |  |  |
| Bankovní regulace a ochrana vkladů | Oddíl o částečných rezervách |  |  |  |  |
| Oficiální ukazatel inflace a spotřební koš | Aktivita zaměřená na kupní sílu |  |  |  |  |
| Stav nebo podoba CBDC | Volitelné srovnání s místní situací |  |  |  |  |
| Peněženka nebo platební nástroj | Praktické cvičení v modulu 3 nebo 4 |  |  |  |  |
| Poplatky, kurzová rozpětí a limity | Srovnání místních možností |  |  |  |  |
| Právní a daňový kontext, ochrana soukromí nebo oznamovací povinnosti | Modul věnovaný místním podmínkám |  |  |  |  |
| Obchodník, mapa, setkání nebo zdroj podpory | Poznávání komunity |  |  |  |  |


Při ověřování aktuálních pravidel upřednostňujte důvěryhodné primární zdroje. Pokud jsou podklady neúplné, uveďte to. Nezobecňujte nejisté místní informace na univerzálně platná tvrzení.
