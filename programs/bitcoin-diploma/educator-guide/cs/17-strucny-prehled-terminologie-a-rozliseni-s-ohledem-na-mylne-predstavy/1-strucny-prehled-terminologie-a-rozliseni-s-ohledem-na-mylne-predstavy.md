# 17.1 Stručný přehled terminologie a rozlišení s ohledem na mylné představy

Úplné definice naleznete v lexikonu. Tato rozlišení důsledně dodržujte při výkladu, v prezentacích, při aktivitách i při hodnocení.


| Pojmy | Rozlišení pro vyučující |
| --- | --- |
| Peníze / měna | Peníze jsou širším pojmem pro nástroj či aktivum sloužící ke směně, jako účetní jednotka a k uchování hodnoty v čase; měna je konkrétní peněžní jednotka nebo systém. |
| Funkce / vlastnost | Funkce vyjadřuje, co peníze dělají; vlastnost je charakteristika ovlivňující, jak dobře tuto funkci plní. |
| Vzácnost / hodnota | Vzácnost omezuje dostupnost; hodnota závisí také na využití, poptávce, preferencích, informacích a kontextu. |
| Cenová inflace / zvýšení jedné ceny | Inflace je trvalejší růst všeobecné cenové hladiny; jednotlivá cena se může měnit z mnoha důvodů. |
| Bankovní vklad / fyzická hotovost | Bankovní vklad je pohledávka vůči bance; fyzická hotovost je jinou formou peněz vydávaných centrální bankou nebo státem podle příslušné jurisdikce. |
| Likvidita / solventnost | Likvidita se týká schopnosti platit včas; solventnost se týká toho, zda aktiva pokrývají závazky. |
| CBDC / Bitcoin | CBDC je centrálně vydávaná digitální fiat měna; Bitcoin nemá centrálního emitenta a používá nezávisle ověřitelná pravidla. |
| Bitcoin / bitcoin | Bitcoin označuje síť, protokol nebo projekt; bitcoin označuje aktivum nebo jeho jednotky. |
| Protokol Bitcoinu / služba pro Bitcoin | Protokol je sdílený systém pravidel; peněženka, burza, průzkumník bloků nebo platební společnost představují samostatnou službu či nástroj. |
| Digitální podpis / šifrování | Podpis prokazuje autorizaci pomocí klíče; šifrování skrývá čitelný obsah. |
| Těžař / uzel | Těžař navrhuje kandidátní bloky prostřednictvím důkazu prací; uzel ověřuje dodržování pravidel. |
| Návrh vývojářů / změna pravidel | Vývojáři navrhují software; účastníci se rozhodují, zda jej přijmou. |
| Doba mezi bloky / časový plán | Přibližně deset minut je dlouhodobý průměr, nikoli přesně stanovený čas. |
| Omezená nabídka / záruka ceny | Předvídatelné maximum je vlastností nabídky; nezaručuje poptávku ani výnosy. |
| Zdravé peníze / fakt | Označení zdravé peníze je hodnotový soud založený na uvedených kritériích a zvážení výhod a nevýhod. |
| Peněženka / uchovávání bitcoinů | Peněženka spravuje klíče a transakce; bitcoin zůstává zaznamenán ve sdílené účetní knize. |
| Adresa / soukromý klíč | Adresa slouží k přijímání; soukromý klíč autorizuje utrácení. |
| Obnovovací fráze / heslo | Obnovovací fráze může znovu vytvořit klíče peněženky a často umožňuje úplnou obnovu přístupu; není to běžné heslo, které lze resetovat. |
| Úschova u správce / vlastní úschova | Rozdíl spočívá v tom, kdo ovládá klíče. |
| Horká / studená | Rozdíl spočívá v tom, zda jsou klíče vystaveny univerzálnímu online prostředí. |
| Na blockchainu / Lightning | Rozdíl spočívá v cestě platby, nikoli ve způsobu úschovy. |
| Průzkumník bloků / uzel | Průzkumník bloků je rozhraní třetí strany; uzel nezávisle ověřuje dodržování pravidel. |
| Potvrzení / správná platba | Potvrzení posiluje historii vypořádání; neopravuje příjemce ani nepotvrzuje oprávněnost účelu. |
| Soukromí / utajení | Soukromí znamená kontrolu nad informacemi; neznamená to, že s danou činností nejsou spojeny žádné veřejné údaje ani právní povinnosti. |
| KYC / no-KYC | Tyto postupy shromažďují různé údaje o totožnosti a přinášejí různé kompromisy v oblasti podpory, soukromí, rizik protistrany, podvodů a právních otázek. V celém textu používejte označení no-KYC. |
| Místní příklad / doporučení | Ověřený místní příklad podporuje učení; není univerzálním doporučením. |
