# 9.17 Block explorers and verification

A [block explorer](https://curriculum.myfirstbitcoin.org/lexicon/en/#block-explorer) is an interface to public Bitcoin information, not an authority over Bitcoin's rules.

Using a prepared [_txid_](https://curriculum.myfirstbitcoin.org/lexicon/en/#transaction-id), show:

* transaction status
* inputs and outputs at beginner depth
* amount and fee display
* block inclusion and [confirmation](https://curriculum.myfirstbitcoin.org/lexicon/en/#confirmation) count; and
* information that becomes public.

[A transaction waits unconfirmed in the pending pool, then is included in Block N as its first confirmation, and each later block adds one more.](/micrographics/confirmation-timeline-01/en.md)


Then ask:

* What can the explorer show?
* What can it not prove about legal identity, purpose, honesty, or ownership?
* What information does the explorer operator learn from the search?
* How does a local [node](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) change the trust and privacy relationship?

Avoid live searches containing learner-linked data.
