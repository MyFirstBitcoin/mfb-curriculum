# 8.19 Strong Module 2 activities

Choose two or three from these examples, not all. Browse the [Activity Library](https://curriculum.myfirstbitcoin.org/activities/en/) for additional options that fit the competency.

* double-spend scenario
* centralized versus decentralized payment map
* user/[node](https://curriculum.myfirstbitcoin.org/lexicon/en/#node)/[miner](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner)/developer role cards
* invalid-block rule check
* finite-supply and [halving](https://curriculum.myfirstbitcoin.org/lexicon/en/#halving) model
* [sats](https://curriculum.myfirstbitcoin.org/lexicon/en/#satoshi) and unit-bias check
* Bitcoin-properties comparison using the **Module 1** table
* fiat issue / Bitcoin response / new responsibility map
* Bitcoin origin timeline
* claim, evidence, reasoning, and trade-off discussion; or
* generic Bitcoin/stablecoin/other-asset comparison.

Use [consensus](https://curriculum.myfirstbitcoin.org/lexicon/en/#consensus) games, hashing activities, videos, and role-plays only when their purpose, timing, learner context, and debrief are strong. An activity supplies educator-led theoretical evidence only when it is a competency-aligned touchpoint with individual evidence, a rubric, and a recording process. Otherwise, use it formatively.
