# 4.7 سجل التحقق المحلي

أكملوا صفًا واحدًا لكل معلومة أو خدمة أو مورد قابل للتغيّر يُستخدم في الصف.


| البند | سبب أهميته | المصدر أو الخبير المحلي | تاريخ التحقق | ما قد يتغيّر | الصياغة المستخدمة في الصف أو البديل |
| --- | --- | --- | --- | --- | --- |
| العملة المحلية وقواعد الدفع | مناقشة الوحدة 1 |  |  |  |  |
| التنظيم المصرفي وحماية الودائع | قسم الاحتياطي الجزئي |  |  |  |  |
| المقياس الرسمي للتضخم وسلة السلع والخدمات | نشاط القوة الشرائية |  |  |  |  |
| وضع العملة الرقمية للبنك المركزي أو تصميمها | مقارنة محلية اختيارية |  |  |  |  |
| محفظة أو أداة دفع | التطبيق العملي في الوحدة 3 أو 4 |  |  |  |  |
| الرسوم وفروق الأسعار والحدود | مقارنة المسارات المحلية |  |  |  |  |
| السياق القانوني أو الضريبي أو المتعلق بالخصوصية أو بمتطلبات الإبلاغ | الوحدة المحلية |  |  |  |  |
| تاجر أو خريطة أو لقاء أو مورد للدعم | استكشاف المجتمع |  |  |  |  |


فضّلوا المصادر الأولية الموثوقة للاطلاع على القواعد السارية. إذا كانت الأدلة غير مكتملة، فاذكروا ذلك. لا تحوّلوا المعلومات المحلية غير المؤكدة إلى تعميم شامل.
