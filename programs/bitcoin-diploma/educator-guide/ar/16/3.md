# 16.3 تأمّلوا بصفتكم معلّمين

أكملوا هذه المراجعة بينما لا تزال الدورة حاضرة في أذهانكم:


| السؤال | ملاحظات وإجراءات |
| --- | --- |
| ما الكفاية التي استغرقت وقتًا أطول أو أقصر مما خُطِّط له؟ |  |
| ما المفهوم الخاطئ الذي تكرر ظهوره؟ |  |
| مَن المتعلمون الذين كانت أصواتهم الأقل حضورًا؟ |  |
| ما المثال المحلي الذي حسّن قدرة المتعلمين على الشرح أو المقارنة أو التطبيق؟ |  |
| ما المثال الذي اتخذ طابعًا سياسيًا أو ترويجيًا أو شخصيًا أكثر من اللازم؟ |  |
| ما النشاط الذي أتاح أدلة مفيدة؟ |  |
| ما النشاط الذي أدى إلى تبسيط مضلل؟ |  |
| هل كانت جميع شروط إيقاف الأنشطة العملية فعّالة؟ |  |
| هل أصبحت أي أداة أو رابط أو رسوم أو قاعدة أو معلومات مُدرجة غير محدّثة؟ |  |
| ما الحكم التقييمي الذي يحتاج إلى مراجعة لضمان اتساقه وعدالته؟ |  |
| ما التكييف المتعلق بإمكانية الوصول أو باللغة الذي ينبغي الإبقاء عليه؟ |  |
| ما الذي سيتغير قبل بدء الدفعة التالية؟ |  |
