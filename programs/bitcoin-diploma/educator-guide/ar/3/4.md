# 3.4 حماية المشاركة دون فرض الإفصاح

قد تكون التجارب المالية حساسة. قدّموا ثلاثة مسارات للتأمل في السياق المحلي:

* مثال شخصي يختار المتعلم مشاركته بحرية
* مثال مُلاحظ من الحياة العامة أو المجتمع المحلي؛ أو
* سيناريو متخيّل واقعي.

لا تطلبوا مطلقًا الإفصاح عن الدخل، أو الديون، أو إمكانية الوصول إلى الخدمات المصرفية، أو وضع الهوية، أو الحيازات، أو العناوين، أو المعاملات، أو الضرائب، أو التحويلات المالية العائلية، أو الممارسات الأمنية.
