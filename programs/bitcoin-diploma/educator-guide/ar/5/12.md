# 5.12 البدائل الاحتياطية للوسائط والأدوات

يحتوي دليل الطالب على التعريفات والمقارنات وقواعد السلامة وأسئلة المراجعة اللازمة لدبلوم بيتكوين. روابط التعلّم التكميلية ورموز الاستجابة السريعة المستخدمة للوصول إليها اختيارية. وقد توفّر تحديثات أو مواد تلخيصية أو ملفات مصدرية أو سبلًا للتواصل. يمكن للمتعلّمين إكمال الدورة دون استخدام هذه الموارد التكميلية.

ينبغي ألا يعتمد أي شرح مطلوب لدبلوم بيتكوين، أو تحقّق تكويني يجريه المعلّم، أو نشاط تدريبي، أو دليل عملي يُلاحظ مباشرةً، على مقطع فيديو أو موقع إلكتروني متاح مباشرةً أو خدمة محدّدة بالاسم أو جهاز يملكه المتعلّم، متى أمكن لمسار بديل معتمد ومكافئ أن يحافظ على الكفاية المستهدفة.

عندما يتطلّب عرض توضيحي اتصالًا بالإنترنت، أعدّوا بديلًا لا يتطلّب اتصالًا حيثما أمكن، مثل صور مطبوعة لشاشات المحفظة، أو سيناريو معاملة، أو تمرين بالبطاقات، أو مناقشة خطوة بخطوة. ينبغي ألا يؤدّي تعذّر الاتصال إلى توقّف التدريس أو التحضير.


| تجربة مباشرة أو عبر الإنترنت | بديل مكافئ دون اتصال أو بتقنيات بسيطة |
| --- | --- |
| التنقّل داخل المحفظة | صور مطبوعة متسلسلة لشاشات المحفظة، أو تسجيل يُعرض على شاشة مع توقّفات للتوقّع |
| الإرسال والاستلام | بطاقات عناوين أو فواتير، وبطاقات مبالغ، ومخطّط ورقي لسير المعاملة |
| مسح رموز الاستجابة السريعة | نماذج مطبوعة لمعلومات الدفع ومقارنة بصرية |
| مستكشف الكتل | لقطات شاشة مؤرّخة لمعاملة متاحة للعامة ومُعدّة مسبقًا |
| بيانات آنية للأسعار أو الرسوم أو التضخّم | لقطة بيانات مؤرّخة ومُعدّة مسبقًا، مع بيان المصدر والقيود |
| خريطة التجّار أو المجتمع | خريطة محلية مطبوعة ونماذج من إدراجات جرى التحقّق منها |
| الدفع عبر شبكة لايتنينغ | بطاقات فواتير وسيناريو لدفع موجّه عبر الشبكة |
| فيديو | رسم تخطيطي مع شرح صوتي، أو لوحة قصصية، أو شرح من المعلّم |
| معاملة مباشرة | محاكاة، أو بيئة اختبار، أو محفظة تدريبية فارغة، أو عرض توضيحي من المعلّم |


التدريس والتقييم دون اتصال بالإنترنت صالحان. استخدموا اختبارات التحقّق من المعرفة دون اتصال، والأنشطة المطبوعة، ولعب الأدوار، والمحاكاة عندما يكون الاتصال محدودًا. المراجعة التكوينية الاختيارية ليست جزءًا من متطلّبات نيل الشهادة.
