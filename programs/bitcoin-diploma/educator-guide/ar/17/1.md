# 17.1 لمحة سريعة عن المصطلحات وفروق دقيقة لتجنّب المفاهيم الخاطئة

استخدموا المعجم للاطلاع على التعريفات الكاملة. حافظوا على اتساق هذه الفروق في الشرح الشفهي والشرائح والأنشطة والتقييم.


| المصطلحات | الفرق الذي ينبغي للمعلّم توضيحه |
| --- | --- |
| النقود / العملة | النقود هي الأداة أو الأصل الأوسع مفهومًا، وتُستخدم للتبادل والحساب وحفظ القيمة عبر الزمن؛ أما العملة فهي وحدة نقدية أو نظام نقدي محدد. |
| الوظيفة / الخاصية | الوظيفة هي ما تؤديه النقود؛ أما الخاصية فهي صفة تؤثر في مدى كفاءتها في أداء تلك الوظيفة. |
| الندرة / القيمة | تحدّ الندرة من التوافر؛ أما القيمة فتعتمد أيضًا على الاستخدام والطلب والتفضيلات والمعلومات والسياق. |
| تضخم الأسعار / ارتفاع سعر واحد | التضخم هو ارتفاع مستمر في المستوى العام للأسعار؛ أما سعر واحد فقد يتغير لأسباب عديدة. |
| الوديعة المصرفية / النقد المادي | الوديعة المصرفية هي حق مالي مستحق على المصرف؛ أما النقد المادي فهو شكل مختلف من النقود يصدره المصرف المركزي أو الدولة، بحسب الولاية القضائية. |
| السيولة / الملاءة المالية | تتعلق السيولة بالسداد في الوقت المناسب؛ أما الملاءة المالية فتتعلق بما إذا كانت الأصول تغطي الالتزامات. |
| العملة الرقمية للبنك المركزي / بيتكوين | العملة الرقمية للبنك المركزي هي نقود إلزامية رقمية تصدر مركزيًا؛ أما بيتكوين فليس لها مُصدر مركزي، وتستخدم قواعد يمكن التحقق منها بصورة مستقلة. |
| بيتكوين / بيتكوين | يشير اسم بيتكوين إلى الشبكة أو البروتوكول أو المشروع؛ ويشير اسم بيتكوين أيضًا إلى الأصل أو الوحدات النقدية. |
| بروتوكول بيتكوين / خدمة بيتكوين | البروتوكول هو منظومة القواعد المشتركة؛ أما المحفظة أو منصة التداول أو المستكشف أو شركة المدفوعات فهي خدمة أو أداة منفصلة. |
| التوقيع الرقمي / التشفير | يثبت التوقيع التفويض باستخدام المفتاح؛ أما التشفير فيخفي المحتوى المقروء. |
| المُعدّن / العقدة | يقترح المُعدّن كتلًا مرشحة من خلال إثبات العمل؛ أما العقدة فتتحقق من الالتزام بالقواعد. |
| اقتراح المطوّرين / تغيير القواعد | يقترح المطوّرون البرمجيات؛ ويختار المشاركون ما إذا كانوا سيتبنّونها. |
| زمن الكتلة / الجدول الزمني | نحو عشر دقائق هو متوسط على المدى الطويل، وليس موعدًا دقيقًا. |
| المعروض المحدود / ضمان السعر | وجود حد أقصى يمكن التنبؤ به هو خاصية للمعروض؛ ولا يضمن الطلب أو العوائد. |
| النقود السليمة / الحقيقة | وصف النقود بأنها سليمة هو حكم يستند إلى معايير ومفاضلات معلنة. |
| المحفظة / تخزين بيتكوين | تدير المحفظة المفاتيح والمعاملات؛ وتظل بيتكوين مسجلة في السجل المشترك. |
| العنوان / المفتاح الخاص | يُستخدم العنوان للاستقبال؛ ويُستخدم المفتاح الخاص لتفويض الإنفاق. |
| عبارة الاسترداد / كلمة المرور | قد تتيح عبارة الاسترداد إعادة إنشاء مفاتيح المحفظة، وغالبًا ما تمنح إمكانية استرداد الوصول الكامل إليها؛ وهي ليست كلمة مرور عادية يمكن إعادة تعيينها. |
| الحفظ لدى طرف ثالث / الحفظ الذاتي | يكمن الفرق في الجهة التي تتحكم في المفاتيح. |
| الساخن / البارد | يكمن الفرق في مدى تعرّض المفاتيح لبيئة حوسبة عامة الأغراض متصلة بالإنترنت. |
| على السلسلة / شبكة لايتنينغ | يكمن الفرق في مسار الدفع، لا في الحفظ. |
| المستكشف / العقدة | المستكشف هو واجهة يوفرها طرف ثالث؛ أما العقدة فتتحقق من الالتزام بالقواعد بصورة مستقلة. |
| التأكيد / الدفع الصحيح | يعزز التأكيد سجل التسوية؛ لكنه لا يصحح المستلِم ولا يثبت صحة الغرض من الدفع. |
| الخصوصية / السرية | الخصوصية هي التحكم في المعلومات؛ ولا تعني أن النشاط يخلو من بيانات متاحة للعامة أو التزامات قانونية. |
| KYC / no-KYC | تجمع هذه المسارات معلومات مختلفة عن الهوية، وتنطوي على مفاضلات مختلفة تتعلق بالدعم والخصوصية والطرف المقابل والاحتيال والجوانب القانونية. استخدموا مصطلح no-KYC في جميع المواضع. |
| مثال محلي / توصية | يدعم المثال المحلي الذي جرى التحقق منه عملية التعلم؛ لكنه لا يُعدّ توصية عامة تصلح للجميع. |
