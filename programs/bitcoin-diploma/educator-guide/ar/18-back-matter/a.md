# الملحق A: قائمة تحقق من صفحة واحدة للتحضير للدورة التدريبية

### المنهج الدراسي

* [ ] أستطيع شرح السرد المترابط للوحدات الأربع والوعود المقدّمة للمتعلّمين.
* [ ] راجعت كل كفاية مطلوبة خاضعة للتقييم، ومعاييرها، ونوع الأدلة الخاصة بها.
* [ ] أعرف أن الوحدات الأربع كلها جزء إلزامي من تعلّم دبلوم بيتكوين، وكيف يمكنني تكييف **الوحدة 3** وانتقاء محتوى **الوحدة 4**، وما يندرج ضمن [التعلّم المتقدّم](https://curriculum.myfirstbitcoin.org/programs/advanced-modules/).
* [ ] راجعت [مكتبة الأنشطة](https://curriculum.myfirstbitcoin.org/activities/en/) حيثما كان ذلك مفيدًا، واخترت أنشطة تخدم كفاية واضحة بدلًا من الترفيه وحده.
* [ ] أعددت مراجعة وتمهيدًا انتقاليًا لكل وحدة.

### المتعلّمون وإمكانية الوصول

* [ ] أعرف لغة مجموعة المتعلّمين، ومستويات إلمامهم بالقراءة والكتابة والحساب، والافتراضات المتعلقة بأجهزتهم.
* [ ] جرى ترتيب احتياجات إمكانية الوصول والتيسيرات اللازمة.
* [ ] يمكن للمتعلّمين استخدام سيناريوهات متخيّلة بدلًا من الإفصاح عن معلومات خاصة.
* [ ] يتضمّن الجدول الزمني التدريب والتقييم والتغذية الراجعة وإعادة التقييم.

### السياق المحلي

* [ ] المعلومات المحلية عن نظام العملات النقدية الإلزامية والخدمات المصرفية محدّثة وموثّقة بالمصادر.
* [ ] المقياس الرسمي لـ[التضخم](https://curriculum.myfirstbitcoin.org/lexicon/en/#inflation) وسلّته خضعا للتحقّق.
* [ ] [العملات الرقمية للبنوك المركزية](https://curriculum.myfirstbitcoin.org/lexicon/en/#cbdc): الادعاءات المتعلقة بها محدّثة ومحدّدة بحسب التصميم.
* [ ] الأدوات والرسوم والخدمات والموارد والقوائم المحلية مرفقة بتواريخها.
* [ ] يُعرض السياق المتعلق بالقانون والضرائب والخصوصية والإبلاغ دون تقديم مشورة.
* [ ] يستطيع أي خبير محلي شرح ضوابط عدم الترويج وحماية الخصوصية.

### السلامة والتكنولوجيا

* [ ] لا تتطلب أي مهمة استخدام بيانات فعلية تخص المتعلّم، مثل [عبارة الاسترداد](https://curriculum.myfirstbitcoin.org/lexicon/en/#recovery-phrase) أو المفتاح أو بيانات الاعتماد أو الرصيد أو السجل.
* [ ] جرى تجهيز أجهزة التدريب والمحافظ وإعادة ضبطها.
* [ ] وُضعت على معلومات الدفع النموذجية علامة **نموذج — لا تدفع**.
* [ ] جرى اختبار العروض التوضيحية المباشرة من البداية إلى النهاية.
* [ ] شروط التوقف وخطوات التصعيد واضحة.
* [ ] لكل عنصر يُعتمد عليه في التنفيذ المباشر أو عبر الإنترنت بديل احتياطي بسيط تقنيًا.
* [ ] ترتيبات الأجهزة والكهرباء والإنترنت والشحن والقاعة جاهزة.

### التقييم

* [ ] تمنح الأنشطة المستخدمة للتقييم المتعلّمين فرصة واضحة وعادلة لإظهار كل كفاية.
* [ ] أخذت في الحسبان حجم مجموعة المتعلّمين، والوقت المتاح، والأسئلة، واستكشاف المشكلات وحلّها، والتغذية الراجعة، وإعادة التقييم.
* [ ] سيحصل المتعلّمون على تدريب مدعوم قبل أن أصدر حكمًا نهائيًا.
* [ ] أعرف ما الذي ينبغي ملاحظته، وكيف أطرح سؤال متابعة مفيدًا، ومتى أسجّل **نعم** أو **ليس بعد**.
* [ ] خيارات التعلّم عبر الإنترنت، وباستخدام تقنيات بسيطة، وخيارات تيسير الوصول جاهزة عند الحاجة.
* [ ] تحمي أي ملاحظات [الخصوصية](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy) وتقتصر على الحد الأدنى من المعلومات المفيدة.
* [ ] أعرف كيفية تقديم شهادات المشاركة أو إتمام الدورة على نحو مناسب.
* [ ] تحققت من نتيجة كل متعلّم قبل استخدام [أداة الشهادات](https://tools.myfirstbitcoin.org/certificate) وسأراجع تفاصيل الشهادات قبل توزيعها.
