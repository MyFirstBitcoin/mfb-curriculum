# 8.21 مراجعة وتمهيد للوحدة 3

اطلبوا من المتعلمين إكمال ما يلي:


| مشكلة في نظام النقود الورقية | استجابة بيتكوين | مسؤولية جديدة أو مفاضلة |
| --- | --- | --- |
| يمكن أن يتغير المعروض بفعل السياسات |  |  |
| تعتمد المدفوعات على الوسطاء |  |  |
| يتحكم مسؤول واحد عن دفتر الحسابات في السجلات |  |  |
| يعتمد الوصول على مؤسسة |  |  |


اطلبوا شرحًا واضحًا لسبب كون [العُقد](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) و [المُعدِّنين](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) يضطلعون بأدوار مختلفة.

ثم استخدموا **للوحدة 2** السؤال الختامي في دليل الطالب. اجعلوا الإجابة خاصة أو اختيارية، وفقًا للإرشادات الواردة أعلاه بشأن التأمل الختامي الموجز للوحدة.

التمهيد للوحدة التالية:

> يمكن لبيتكوين أن يقلل الاعتماد على الجهة المشغّلة للحساب، لكن التحكم المباشر يعتمد على المفاتيح والتحقق والاسترداد واتخاذ قرارات آمنة. **الوحدة 3** تحوّل هذه المسؤولية إلى ممارسة عملية.
