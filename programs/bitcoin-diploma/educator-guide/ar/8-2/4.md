# 8.4 سير مقترح لجلسة مدتها ساعتان

| الوقت | الخطوة التعليمية | الطريقة المقترحة |
| --- | --- | --- |
| 0–10 دقيقة | استرجاع محتوى الوحدة 1 | اذكروا مشكلة نقدية واحدة والمفاضلة التي تنشأ عنها |
| 10–27 دقيقة | لماذا كان إنشاء نقود رقمية لامركزية صعبًا | سيناريو النسخ الرقمي والإنفاق المزدوج |
| 27–42 دقيقة | استجابة بيتكوين المتكاملة | مخطط العملية: التفويض، البث، التعدين، التحقق، مشاركة سجل المعاملات |
| 42–62 دقيقة | الأدوار واللامركزية | مهمة حول دور المستخدم/العقدة/المعدّن/المطوّر |
| 62–77 دقيقة | إثبات العمل | عرض توضيحي لما يكون إنتاجه مكلفًا والتحقق منه سريعًا |
| 77–92 دقيقة | المعروض والتنصيف والساتوشيات | نموذج الإصدار وفحص التحيّز للوحدة |
| 92–110 دقيقة | مقارنة من منظور النقود السليمة | أعيدوا استخدام خصائص الوحدة 1؛ وأضيفوا المزايا والمفاضلات |
| 110–117 دقيقة | النطاق والمسؤولية | بيتكوين مقابل العملات المستقرة/الأصول الأخرى؛ التعلّم مقابل المضاربة |
| 117–120 دقيقة | المراجعة والتمهيد للانتقال | مشكلة في النقود الإلزامية → استجابة بيتكوين → مسؤولية جديدة |
