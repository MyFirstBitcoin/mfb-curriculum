# 10.10 خيار الوحدة أ: مقارنة مسارات الدفع المحلية

**الهدف:** مقارنة المسار الكامل لدفعة محلية بطريقة مستخدمة حاليًا، ومسار دفع على السلسلة، ومسار دفع عبر شبكة لايتنينغ حيثما كان ذلك مناسبًا.

**الإعداد:** استخدموا مبلغ دفع ومستلمًا افتراضيين واقعيين. أعدّوا معلومات محلية مؤرخة عن الرسوم، والصرف، والمدة الزمنية، [وحفظ الأموال](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody)، وإمكانية الوصول. إذا تعذّر التحقق من البيانات، فوضّحوا صراحةً أنها افتراضية.

**مهمة المتعلّم:** أكملوا ما يلي:


| البند | الطريقة المستخدمة حاليًا | بيتكوين على السلسلة | لايتنينغ، إن كانت ذات صلة |
| --- | --- | --- | --- |
| المبلغ المُرسَل |  |  |  |
| إجمالي المبلغ المُستلَم |  |  |  |
| المدة الزمنية والتوقعات بشأن التسوية |  |  |  |
| الرسوم وفارق سعر الصرف |  |  |  |
| حفظ الأموال في كل مرحلة |  |  |  |
| الهوية والخصوصية |  |  |  |
| إلغاء المعاملة أو ردّ المبلغ |  |  |  |
| نقطة الإخفاق الرئيسية |  |  |  |
| الدعم المحلي أو القانون المحلي |  |  |  |


**المُخرَج:** يختار المتعلّم مسارًا للحالة الافتراضية، ويوضّح عمليًا طلب الدفع المعني والتحقق منه أو يرتّب خطواتهما، ويشرح لماذا قد يكون المسار الآخر أفضل عند تغيّر أحد الظروف.

**المناقشة الختامية:** هل حسّنت بيتكوين المسار الكامل، أم خطوة ظاهرة واحدة فقط؟ من يتحمّل مخاطر التقلّب، والتحويل، [وحفظ الأموال](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody)، والإخفاق؟

**السلامة:** لا يلزم إجراء تحويل حقيقي أو تحديد مزوّد خدمة بعينه. استخدموا معلومات دفع مطبوعة.
