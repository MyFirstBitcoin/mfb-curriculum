# 4.7 Lokal verifikationsprotokol

Udfyld én række for hver oplysning, tjeneste eller ressource, der bruges i undervisningen, og som kan ændre sig.


| Emne | Hvorfor det er vigtigt | Kilde eller lokal ekspert | Kontroldato | Hvad kan ændre sig | Formulering til undervisningen eller alternativ |
| --- | --- | --- | --- | --- | --- |
| Lokal valuta og betalingsregler | Diskussion i modul 1 |  |  |  |  |
| Bankregulering og indskyderbeskyttelse | Afsnittet om brøkreservebankvæsen |  |  |  |  |
| Officielt inflationsmål og varekurv | Aktivitet om købekraft |  |  |  |  |
| Status for eller udformning af CBDC | Valgfri lokal sammenligning |  |  |  |  |
| Wallet eller betalingsværktøj | Praktisk øvelse i modul 3 eller 4 |  |  |  |  |
| Gebyrer, kursspænd og grænser | Sammenligning af lokale fremgangsmåder |  |  |  |  |
| Lokale forhold vedrørende lovgivning, skat, privatliv eller indberetning | Lokalt modul |  |  |  |  |
| Forhandler, kort, netværksmøde eller hjælperessource | Udforskning af fællesskabet |  |  |  |  |


Foretræk autoritative primærkilder til gældende regler. Hvis dokumentationen er ufuldstændig, skal De gøre opmærksom på det. Gør ikke usikre lokale oplysninger til en universel påstand.
