# 16.3 Reflektér som underviser

Udfyld denne evaluering, mens De stadig har kurset i frisk erindring:


| Spørgsmål | Noter og handling |
| --- | --- |
| Hvilken kompetence tog mere eller mindre tid end planlagt? |  |
| Hvilken misforståelse opstod gentagne gange? |  |
| Hvilke kursisters stemmer blev hørt mindst? |  |
| Hvilket lokalt eksempel forbedrede det, kursisterne kunne forklare, sammenligne eller gøre? |  |
| Hvilket eksempel blev politisk, reklamepræget eller for personligt? |  |
| Hvilken aktivitet gav brugbar dokumentation? |  |
| Hvilken aktivitet skabte en misvisende forenkling? |  |
| Fungerede alle stopbetingelser for de praktiske øvelser efter hensigten? |  |
| Blev et værktøj, et link, et gebyr, en regel eller en listeoplysning forældet? |  |
| Hvilken bedømmelse kræver fælles afstemning? |  |
| Hvilken tilpasning af tilgængelighed eller sprog bør bevares? |  |
| Hvad vil blive ændret inden næste hold? |  |
