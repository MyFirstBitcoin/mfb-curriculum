# 8.16 Ansvarlig læring kontra spekulation

Forklar grænsen:

* Undervisning undersøger, hvordan systemet fungerer, hvad der kan verificeres, hvilke risici der findes, og hvad den lærende sikkert kan demonstrere.
* Ansvarlig brug begynder med formål, [opbevaring](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), verificering, små tests og informerede valg.
* Handel forsøger at opnå gevinst gennem [kursmæssige](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) ændringer og kan indebære gearing, hurtige beslutninger, platformsrisiko og tab.
* Promovering af tokens skaber interessekonflikter og kan belønne overtalelse frem for klar argumentation.
* Spekulation kan få lærende til at forveksle [kursmæssige](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) bevægelser med teknisk eller social [værdi](https://curriculum.myfirstbitcoin.org/lexicon/en/#value).

Bitcoin Diploma underviser ikke i og bedømmer ikke [kursmæssige](https://curriculum.myfirstbitcoin.org/lexicon/en/#price) forudsigelser, porteføljesammensætning, handel, investeringsafkast eller valg af tokens.
