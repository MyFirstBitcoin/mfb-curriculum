# 8.21 Opsamling og overgang til modul 3

Bed kursisterne om at udfylde:


| Problem i fiatsystemet | Bitcoins svar | Nyt ansvar eller kompromis |
| --- | --- | --- |
| Pengemængden kan ændres gennem politiske beslutninger |  |  |
| Betalinger afhænger af mellemmænd |  |  |
| Én regnskabsfører kontrollerer registreringerne |  |  |
| Adgang afhænger af en institution |  |  |


Kræv en klar forklaring på, hvorfor [noder](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) og [minere](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) har forskellige roller.

Brug derefter **modul 2**'s afsluttende spørgsmål i elevvejledningen. Lad svaret være privat eller frivilligt i overensstemmelse med ovenstående vejledning om en kort refleksion ved modulets afslutning.

Overgang:

> Bitcoin kan mindske afhængigheden af en kontoudbyder, men direkte kontrol afhænger af nøgler, verificering, gendannelse og sikre beslutninger. **Modul 3** omsætter dette ansvar til praksis.
