# 10.10 Modulvalg A: sammenligning af lokale betalingsveje

**Formål:** Sammenlign hele betalingsforløbet for en eksisterende lokal betaling, en betaling på Bitcoin-blockchainen og en Lightning-betaling, hvor det er relevant.

**Forberedelse:** Brug et realistisk, opdigtet betalingsbeløb og en opdigtet modtager. Udarbejd daterede oplysninger om lokale gebyrer, veksling, tidsforbrug, [opbevaring](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) og adgang. Hvis oplysningerne ikke kan verificeres, skal de tydeligt mærkes som hypotetiske.

**Opgave til kursisten:** Udfyld:


| Felt | Eksisterende metode | Bitcoin på blockchainen | Lightning, hvis relevant |
| --- | --- | --- | --- |
| Afsendt beløb |  |  |  |
| Samlet modtaget beløb |  |  |  |
| Forventet tidsforbrug og endelig afvikling |  |  |  |
| Gebyrer og kursspænd |  |  |  |
| Opbevaring på hvert trin |  |  |  |
| Identitet og privatliv |  |  |  |
| Tilbageførsel eller refundering |  |  |  |
| Væsentligste punkt, hvor der kan opstå fejl |  |  |  |
| Lokal hjælp eller lovgivning |  |  |  |


**Produkt:** Kursisten vælger et betalingsforløb til det opdigtede tilfælde, demonstrerer eller opstiller trinene i den relevante betalingsanmodning og verificering og forklarer, hvorfor det andet betalingsforløb kan være bedre under ændrede betingelser.

**Opsamling:** Forbedrede Bitcoin hele betalingsforløbet eller kun ét synligt trin? Hvem bærer risikoen ved kursudsving, veksling, [opbevaring](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) og fejl?

**Sikkerhed:** Der kræves hverken en reel overførsel eller en navngiven udbyder. Brug udskrevne betalingsoplysninger.
