# 9.23 Συνήθεις παρανοήσεις και απαντήσεις

| Παρανόηση | Διόρθωση κατάλληλη για αρχάριους | Ερώτηση ελέγχου κατανόησης |
| --- | --- | --- |
| Το Bitcoin αποθηκεύεται στην εφαρμογή πορτοφολιού. | Το Bitcoin καταγράφεται στο κοινόχρηστο καθολικό· το πορτοφόλι διαχειρίζεται κλειδιά και πληροφορίες συναλλαγών. | Τι θα παρέμενε αν χαλούσε το τηλέφωνο; |
| Μια διεύθυνση είναι ένας μυστικός κωδικός πρόσβασης. | Μια διεύθυνση αποτελεί δημόσια πληροφορία για τη λήψη χρημάτων, αν και η σύνδεσή της με μια ταυτότητα μπορεί να μειώσει την ιδιωτικότητα. | Ποια πληροφορία επιτρέπει τη δαπάνη χρημάτων; |
| Κάθε κωδικός QR είναι ασφαλής επειδή το πορτοφόλι τον σαρώνει. | Ένας κωδικός QR μπορεί να κωδικοποιεί λανθασμένο προορισμό ή αίτημα. Επαληθεύστε τον παραλήπτη, τη διαδρομή πληρωμής, το ποσό και την τελική οθόνη. | Τι θα συγκρίνατε μετά τη σάρωση; |
| Η κοινοποίηση μιας διεύθυνσης επιτρέπει σε κάποιον να δαπανήσει χρήματα. | Η δαπάνη χρημάτων συνήθως απαιτεί το ιδιωτικό κλειδί. Ωστόσο, η κοινοποίηση μιας διεύθυνσης μπορεί να αποκαλύψει συνδέσεις μεταξύ συναλλαγών. | Ποιος κίνδυνος για την ιδιωτικότητα παραμένει; |
| Μια φράση ανάκτησης είναι ένας συνηθισμένος κωδικός πρόσβασης. | Για πολλά πορτοφόλια παρέχει πλήρη πρόσβαση για ανάκτηση. Όποιος την κατέχει μπορεί να αναδημιουργήσει τα κλειδιά. | Θα τη χρειαζόταν ποτέ μια νόμιμη υπηρεσία υποστήριξης; |
| Ο εκπαιδευτής πρέπει να ελέγξει το αντίγραφο ασφαλείας της φράσης ανάκτησής μου. | Ένας εκπαιδευτής μπορεί να παρακολουθήσει την ασφαλή διαδικασία χωρίς να δει τις λέξεις. | Πώς μπορείτε να αποδείξετε την ετοιμότητά σας διατηρώντας τη φράση απόρρητη; |
| Κάθε πορτοφόλι είναι αυτοθεματοφυλακής. | Ορισμένες εφαρμογές που ονομάζονται πορτοφόλια διατηρούν τα κλειδιά για λογαριασμό του χρήστη. | Ποιος εγκρίνει την ανάληψη και ελέγχει την ανάκτηση; |
| Ένα πορτοφόλι υλικού εξαλείφει τον κίνδυνο που σχετίζεται με το αντίγραφο ασφαλείας. | Η συσκευή απομονώνει τα κλειδιά, αλλά η ανάκτηση εξακολουθεί να εξαρτάται από ένα προστατευμένο αντίγραφο ασφαλείας και τη σωστή χρήση. | Τι συμβαίνει αν χαλάσει η συσκευή; |
| Μία επιβεβαίωση καθιστά κάθε πληρωμή ασφαλή. | Οι επιβεβαιώσεις ενισχύουν το ιστορικό διακανονισμού· δεν διορθώνουν έναν λανθασμένο προορισμό ούτε μια απάτη. | Ποιοι έλεγχοι πρέπει να γίνονται πριν από την έγκριση; |
| Ένας εξερευνητής μπλοκ είναι το Bitcoin. | Είναι μια διεπαφή τρίτου μέρους για την πρόσβαση σε δημόσια δεδομένα. | Ποια ισχυρότερη επαλήθευση μπορεί να προσφέρει ένας κόμβος; |
| Τα τέλη βασίζονται κυρίως στο πόσο bitcoin αποστέλλεται. | Τα τέλη για συναλλαγές εντός της αλυσίδας εξαρτώνται κυρίως από τα δεδομένα της συναλλαγής και τη ζήτηση για χώρο στα μπλοκ. | Μπορεί μια πληρωμή μικρής αξίας να έχει παρ’ όλα αυτά υψηλό τέλος; |
| Το Lightning σημαίνει πάντα αυτοθεματοφυλακή και μηδενικά τέλη. | Τα πορτοφόλια Lightning μπορεί να είναι θεματοφυλακής ή αυτοθεματοφυλακής, και οι συνθήκες δρομολόγησης, παροχής υπηρεσιών ή ρευστότητας μπορεί να επιφέρουν τέλη και αποτυχίες. | Ποιες δύο ξεχωριστές ερωτήσεις πρέπει να θέσετε; |
| Η χρήση KYC είναι πάντα ασφαλής, ή η μη χρήση KYC είναι πάντα ασφαλής. | Κάθε επιλογή ανταλλάσσει ορισμένους κινδύνους με άλλους, σε θέματα ταυτότητας, υποστήριξης, αντισυμβαλλομένου, απάτης, νομιμότητας και ιδιωτικότητας. | Ποιος κίνδυνος μειώνεται και ποιος προστίθεται; |
