# 9.13 Οι όροι «θερμό», «ψυχρό», «υλικού» και «θεματοφυλακής» αφορούν διαφορετικές διαστάσεις

Αποφύγετε ένα συνηθισμένο σφάλμα κατηγοριοποίησης:

* **Με θεματοφυλακή / με αυτοθεματοφυλακή** περιγράφει ποιος ελέγχει τα κλειδιά.
* **Θερμό / ψυχρό** περιγράφει αν τα κλειδιά υπογραφής είναι εκτεθειμένα σε ένα περιβάλλον γενικής χρήσης συνδεδεμένο στο διαδίκτυο.
* [**Πορτοφόλι υλικού**](https://curriculum.myfirstbitcoin.org/lexicon/en/#hardware-wallet) περιγράφει έναν σχεδιασμό συσκευής ειδικού σκοπού.
* **Στην αλυσίδα / Lightning** περιγράφει μια διαδρομή πληρωμής, όχι τη [θεματοφυλακή](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) αυτή καθαυτή.

Ένα πορτοφόλι Lightning μπορεί να είναι με θεματοφυλακή ή με αυτοθεματοφυλακή. Ένα [πορτοφόλι υλικού](https://curriculum.myfirstbitcoin.org/lexicon/en/#hardware-wallet) εξακολουθεί να χρειάζεται διαδικασία ανάκτησης. Μια ψυχρή διάταξη μπορεί να είναι κακοσχεδιασμένη. Ένα [θερμό πορτοφόλι](https://curriculum.myfirstbitcoin.org/lexicon/en/#hot-wallet) μπορεί να είναι κατάλληλο για καθημερινή χρήση μικρής κλίμακας.
