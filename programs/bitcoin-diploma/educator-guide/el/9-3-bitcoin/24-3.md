# 9.24 Ενότητα 3: Τεκμήρια πρακτικής εφαρμογής

Για την πρακτική αξιολόγηση, παρατηρήστε αν ο εκπαιδευόμενος μπορεί να ολοκληρώσει τη σχετική δραστηριότητα με ασφάλεια και αν μπορεί:

* να ανοίξει ή να αποκτήσει με ασφάλεια πρόσβαση στο προετοιμασμένο περιβάλλον
* να πλοηγηθεί χωρίς να εκθέσει άσχετες πληροφορίες
* να αναγνωρίσει το [θεματοφυλακτικό](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody) μοντέλο
* να διακρίνει τις πληροφορίες για τη λήψη πληρωμών από τα μυστικά στοιχεία
* να επιλέξει την προβλεπόμενη διαδρομή πληρωμής και το προβλεπόμενο δίκτυο
* να εντοπίσει και να επαληθεύσει μια διεύθυνση ή ένα αίτημα πληρωμής
* να ελέγξει τον παραλήπτη, το ποσό, τη μονάδα, το τέλος συναλλαγής, τη λήξη και την τελική σύνοψη, κατά περίπτωση
* να ολοκληρώσει ή να προσομοιώσει με ασφάλεια μια διαδικασία λήψης ή αποστολής
* να ερμηνεύσει την κατάσταση εκκρεμότητας, επιβεβαίωσης, αποτυχίας ή λήψης
* να προστατεύσει τις πληροφορίες ανάκτησης καθ’ όλη τη διάρκεια μιας εργασίας ελέγχου ετοιμότητας για ανάκτηση
* να αντιδράσει με ασφάλεια σε έκθεση πληροφοριών, αναντιστοιχία, πλαστοπροσωπία, πίεση για άμεση ενέργεια ή απάτη
* να εξηγήσει τον λόγο για τους σημαντικούς ελέγχους· και
* να σταματήσει ή να ζητήσει βοήθεια όταν η διαδικασία υπερβαίνει τις ικανότητές του.

Η συμπεριφορά που είναι κρίσιμη για την ασφάλεια δεν μπορεί να συμψηφιστεί με άλλες επιδόσεις. Η αποκάλυψη πληροφοριών ανάκτησης, η έγκριση μιας γνωστής αναντιστοιχίας, η συνέχιση παρά τις εμφανείς ενδείξεις απάτης ή η παράκαμψη μιας απαιτούμενης επαλήθευσης οδηγεί σε αξιολόγηση **Όχι ακόμη** μέχρι να πραγματοποιηθούν στοχευμένη διορθωτική εκπαίδευση και επαναξιολόγηση.
