# 17.1 Συνοπτική ορολογία και διακρίσεις για την αποφυγή παρανοήσεων

Χρησιμοποιήστε το Λεξικό για πλήρεις ορισμούς. Διατηρήστε αυτές τις διακρίσεις με συνέπεια στον προφορικό λόγο, στις διαφάνειες, στις δραστηριότητες και στην αξιολόγηση.


| Όροι | Διάκριση για εκπαιδευτικούς |
| --- | --- |
| Χρήμα / νόμισμα | Το χρήμα είναι το ευρύτερο εργαλείο ή περιουσιακό στοιχείο που χρησιμοποιείται για ανταλλαγές, ως λογιστική μονάδα και για διατήρηση αξίας στον χρόνο· το νόμισμα είναι μια συγκεκριμένη νομισματική μονάδα ή ένα συγκεκριμένο νομισματικό σύστημα. |
| Λειτουργία / ιδιότητα | Η λειτουργία είναι αυτό που κάνει το χρήμα· η ιδιότητα είναι ένα χαρακτηριστικό που επηρεάζει το πόσο καλά το κάνει. |
| Σπανιότητα / αξία | Η σπανιότητα περιορίζει τη διαθεσιμότητα· η αξία εξαρτάται επίσης από τη χρήση, τη ζήτηση, τις προτιμήσεις, την πληροφόρηση και το πλαίσιο. |
| Πληθωρισμός τιμών / αύξηση μίας τιμής | Ο πληθωρισμός είναι μια διαρκής άνοδος του γενικού επιπέδου τιμών· μία τιμή μπορεί να αλλάξει για πολλούς λόγους. |
| Τραπεζική κατάθεση / μετρητά σε φυσική μορφή | Μια τραπεζική κατάθεση είναι μια απαίτηση έναντι της τράπεζας· τα μετρητά σε φυσική μορφή είναι μια διαφορετική μορφή χρήματος που εκδίδεται από την κεντρική τράπεζα ή το κράτος, ανάλογα με τη δικαιοδοσία. |
| Ρευστότητα / φερεγγυότητα | Η ρευστότητα αφορά την έγκαιρη πληρωμή· η φερεγγυότητα αφορά το κατά πόσο τα περιουσιακά στοιχεία καλύπτουν τις υποχρεώσεις. |
| CBDC / Bitcoin | Ένα CBDC είναι ψηφιακό παραστατικό χρήμα που εκδίδεται κεντρικά· το Bitcoin δεν έχει κεντρικό εκδότη και χρησιμοποιεί κανόνες που μπορούν να επαληθευτούν ανεξάρτητα. |
| Bitcoin / bitcoin | Το Bitcoin αναφέρεται στο δίκτυο, στο πρωτόκολλο ή στο εγχείρημα· το bitcoin αναφέρεται στο περιουσιακό στοιχείο ή στις μονάδες του. |
| Πρωτόκολλο Bitcoin / υπηρεσία Bitcoin | Το πρωτόκολλο είναι το κοινό σύστημα κανόνων· ένα πορτοφόλι, ένα ανταλλακτήριο, ένας εξερευνητής ή μια εταιρεία πληρωμών είναι ξεχωριστή υπηρεσία ή εργαλείο. |
| Ψηφιακή υπογραφή / κρυπτογράφηση | Μια υπογραφή αποδεικνύει την εξουσιοδότηση μέσω κλειδιού· η κρυπτογράφηση αποκρύπτει το αναγνώσιμο περιεχόμενο. |
| Εξορύκτης / κόμβος | Ένας εξορύκτης προτείνει υποψήφια μπλοκ μέσω απόδειξης εργασίας· ένας κόμβος επαληθεύει την τήρηση των κανόνων. |
| Πρόταση προγραμματιστών / αλλαγή κανόνων | Οι προγραμματιστές προτείνουν λογισμικό· οι συμμετέχοντες επιλέγουν αν θα το υιοθετήσουν. |
| Χρόνος μπλοκ / χρονοδιάγραμμα | Τα περίπου δέκα λεπτά είναι ένας μακροχρόνιος μέσος όρος, όχι ένα ραντεβού με ακριβή ώρα. |
| Πεπερασμένη προσφορά / εγγύηση τιμής | Ένα προβλέψιμο ανώτατο όριο είναι ιδιότητα της προσφοράς· δεν εγγυάται ζήτηση ή αποδόσεις. |
| Υγιές χρήμα / γεγονός | Ο χαρακτηρισμός «υγιές χρήμα» είναι μια κρίση που διαμορφώνεται βάσει ρητά διατυπωμένων κριτηρίων και συμβιβασμών. |
| Πορτοφόλι / αποθήκευση bitcoin | Ένα πορτοφόλι διαχειρίζεται κλειδιά και συναλλαγές· το bitcoin παραμένει καταγεγραμμένο στο κοινό καθολικό. |
| Διεύθυνση / ιδιωτικό κλειδί | Μια διεύθυνση δέχεται πληρωμές· ένα ιδιωτικό κλειδί εξουσιοδοτεί τη δαπάνη. |
| Φράση ανάκτησης / κωδικός πρόσβασης | Μια φράση ανάκτησης μπορεί να αναδημιουργήσει τα κλειδιά του πορτοφολιού και συχνά παρέχει πλήρη πρόσβαση για ανάκτηση· δεν είναι ένας συνηθισμένος κωδικός πρόσβασης που μπορεί να επαναφερθεί. |
| Με θεματοφυλακή / με αυτοθεματοφυλακή | Η διάκριση έγκειται στο ποιος ελέγχει τα κλειδιά. |
| Θερμό / ψυχρό | Η διάκριση έγκειται στην έκθεση των κλειδιών σε ένα περιβάλλον γενικής χρήσης συνδεδεμένο στο διαδίκτυο. |
| Εντός αλυσίδας / Lightning | Η διάκριση έγκειται στη διαδρομή της πληρωμής, όχι στη θεματοφυλακή. |
| Εξερευνητής / κόμβος | Ένας εξερευνητής είναι μια διεπαφή τρίτου μέρους· ένας κόμβος επαληθεύει ανεξάρτητα την τήρηση των κανόνων. |
| Επιβεβαίωση / σωστή πληρωμή | Μια επιβεβαίωση ενισχύει το ιστορικό διακανονισμού· δεν διορθώνει τον παραλήπτη ούτε επικυρώνει τον σκοπό. |
| Ιδιωτικότητα / μυστικότητα | Η ιδιωτικότητα είναι ο έλεγχος των πληροφοριών· δεν σημαίνει ότι μια δραστηριότητα δεν έχει δημόσια δεδομένα ή νομικές υποχρεώσεις. |
| KYC / no-KYC | Αυτές οι επιλογές συλλέγουν διαφορετικές πληροφορίες ταυτοποίησης και συνεπάγονται διαφορετικούς συμβιβασμούς ως προς την υποστήριξη, την ιδιωτικότητα, τον κίνδυνο αντισυμβαλλομένου, την απάτη και τα νομικά ζητήματα. Χρησιμοποιείτε τον όρο no-KYC σε όλο το κείμενο. |
| Τοπικό παράδειγμα / σύσταση | Ένα ελεγμένο τοπικό παράδειγμα υποστηρίζει τη μάθηση· δεν αποτελεί καθολική σύσταση. |
