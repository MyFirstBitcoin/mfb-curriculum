# 7.4 Προτεινόμενη δίωρη ροή

Αυτή είναι η ελάχιστη διδακτική διαδρομή. Επεκτείνετέ την όταν η ομάδα χρειάζεται περισσότερες βασικές γνώσεις οικονομίας ή συζήτηση για την τοπική πραγματικότητα.


| Χρόνος | Μαθησιακό βήμα | Προτεινόμενη μέθοδος |
| --- | --- | --- |
| 0–12 λεπτά | Ανάδειξη προϋπαρχουσών ιδεών | Εισαγωγικές ερωτήσεις σε ζεύγη και έπειτα συζήτηση στην ολομέλεια |
| 12–28 λεπτά | Γιατί υπάρχει το χρήμα | Σενάριο ανταλλαγής και σύντομη ερώτηση επιτόπου |
| 28–45 λεπτά | Λειτουργίες και ιδιότητες | Τοπικά παραδείγματα και σύγκριση των ιδιοτήτων του χρήματος |
| 45–58 λεπτά | Αντιπραγματισμός και επιλογή | Σύντομο παιχνίδι ρόλων για τη διπλή σύμπτωση αναγκών· αναστοχαστική συζήτηση για τη σπανιότητα και το κόστος ευκαιρίας |
| 58–70 λεπτά | Νομισματική ιστορία | Μη γραμμικό χρονολόγιο με προσθήκες από την τοπική ιστορία |
| 70–92 λεπτά | Ρόλοι στο σύστημα παραστατικού χρήματος | Ιχνηλάτηση μιας τοπικής πληρωμής και χαρτογράφηση των θεσμών |
| 92–105 λεπτά | Τραπεζικό σύστημα | Σχηματική απεικόνιση ισολογισμού ή σενάριο ρευστότητας/φερεγγυότητας |
| 105–115 λεπτά | Πληθωρισμός, αγοραστική δύναμη και ψηφιακό νόμισμα κεντρικής τράπεζας | Συζήτηση τοπικών τεκμηρίων με συγκεκριμένη χρονολογία |
| 115–120 λεπτά | Ανασκόπηση και σύνδεση με την επόμενη ενότητα | Εξήγηση της φράσης «Το χρήμα μπορεί να πάψει να λειτουργεί όταν…» |


Αν υπάρχει περισσότερος χρόνος στο μάθημα, χωρίστε την ενότητα σε δύο μέρη: πρώτα οι βασικές αρχές του χρήματος και έπειτα οι συμβιβασμοί που συνεπάγεται το σύγχρονο χρήμα.
