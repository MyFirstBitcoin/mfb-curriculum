# 7.7 Λειτουργίες και ιδιότητες του χρήματος

Διδάξτε τη διαφορά με σαφήνεια:

* Μια **λειτουργία** περιγράφει τι κάνει το χρήμα: [μέσο συναλλαγών](https://curriculum.myfirstbitcoin.org/lexicon/en/#medium-of-exchange), [λογιστική μονάδα](https://curriculum.myfirstbitcoin.org/lexicon/en/#unit-of-account), ή [μέσο αποθήκευσης αξίας](https://curriculum.myfirstbitcoin.org/lexicon/en/#store-of-value).
* Μια **ιδιότητα** περιγράφει ένα χαρακτηριστικό που μπορεί να το καταστήσει χρήσιμο: [ανθεκτικότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#durability), [φορητότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#portability), [διαιρετότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#divisibility), [ανταλλαξιμότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#fungibility), [σπανιότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#scarcity), [αποδεκτότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#acceptability), ή [επαληθευσιμότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#verifiability).

Χρησιμοποιήστε διαφορετικούς σκοπούς. Ρωτήστε ποιες ιδιότητες έχουν σημασία για:

* την αγορά τροφίμων σήμερα
* την αποταμίευση για ένα έτος
* την πληρωμή κάποιου που βρίσκεται μακριά
* τη διατήρηση αποθέματος για έκτακτες ανάγκες· και
* την καταγραφή επιχειρηματικών [τιμών](https://curriculum.myfirstbitcoin.org/lexicon/en/#price).

Στη συνέχεια, ρωτήστε αν η ίδια μορφή χρήματος αποδίδει εξίσου καλά για κάθε σκοπό και σε κάθε τόπο.

#### Δραστηριότητα: σύγκριση ιδιοτήτων του χρήματος

**Σκοπός:** Προετοιμάστε τα κριτήρια που θα χρησιμοποιήσουν ξανά οι εκπαιδευόμενοι για το Bitcoin στην **Ενότητα 2**.

**Προετοιμασία:** Επιλέξτε τρεις ή τέσσερις οικείες μορφές, όπως τοπικά μετρητά, ένα τραπεζικό υπόλοιπο, ένα χρήσιμο εμπόρευμα, ένα πολύτιμο μέταλλο ή ένα άλλο κατάλληλο για το τοπικό πλαίσιο [περιουσιακό στοιχείο](https://curriculum.myfirstbitcoin.org/lexicon/en/#asset). Μην ορίσετε εκ των προτέρων ποια μορφή υπερέχει.

**Εργασία:** Οι ομάδες συγκρίνουν κάθε μορφή με βάση τις επτά ιδιότητες. Κάθε κρίση πρέπει να περιλαμβάνει μια αιτιολόγηση, μια προϋπόθεση ή ένα παράδειγμα.

**Αποτίμηση:** Ρωτήστε ποια ιδιότητα άλλαξε περισσότερο όταν άλλαξε ο σκοπός. Κρατήστε τη σύγκριση για την **Ενότητα 2**.

**Προσέξτε:** Την αντιμετώπιση μιας ιδιότητας ως απόλυτης. Τα μετρητά μπορεί να μεταφέρονται εύκολα μέσα σε μια γειτονιά, αλλά να είναι δύσκολο να μεταφερθούν διεθνώς. Ένα τραπεζικό υπόλοιπο μπορεί να γίνεται αποδεκτό μέσω τοπικών συστημάτων πληρωμών, αλλά η χρήση του να εξαρτάται από την πρόσβαση στον λογαριασμό.
