# 4.7 Αρχείο τοπικής επαλήθευσης

Συμπληρώστε μία γραμμή για κάθε μεταβαλλόμενο στοιχείο, υπηρεσία ή πόρο που χρησιμοποιείται στην τάξη.


| Στοιχείο | Γιατί έχει σημασία | Πηγή ή τοπικός ειδικός | Ημερομηνία ελέγχου | Τι μπορεί να αλλάξει | Διατύπωση στην τάξη ή εναλλακτική λύση |
| --- | --- | --- | --- | --- | --- |
| Τοπικό νόμισμα και κανόνες πληρωμών | Συζήτηση στην Ενότητα 1 |  |  |  |  |
| Τραπεζικό κανονιστικό πλαίσιο και προστασία καταθέσεων | Τμήμα για το σύστημα κλασματικών αποθεματικών |  |  |  |  |
| Επίσημος δείκτης πληθωρισμού και καλάθι αγαθών και υπηρεσιών | Δραστηριότητα για την αγοραστική δύναμη |  |  |  |  |
| Κατάσταση ή σχεδιασμός ψηφιακού νομίσματος κεντρικής τράπεζας | Προαιρετική σύγκριση με τα τοπικά δεδομένα |  |  |  |  |
| Πορτοφόλι ή εργαλείο πληρωμών | Πρακτική άσκηση στην Ενότητα 3 ή 4 |  |  |  |  |
| Προμήθειες, διαφορές τιμών αγοράς και πώλησης και όρια | Σύγκριση των τοπικά διαθέσιμων επιλογών |  |  |  |  |
| Πλαίσιο νομοθεσίας, φορολογίας, ιδιωτικότητας ή υποχρεώσεων αναφοράς | Ενότητα τοπικού περιεχομένου |  |  |  |  |
| Έμπορος, χάρτης, συνάντηση ή πόρος υποστήριξης | Γνωριμία με την κοινότητα |  |  |  |  |


Προτιμήστε έγκυρες πρωτογενείς πηγές για τους ισχύοντες κανόνες. Αν τα τεκμήρια είναι ελλιπή, δηλώστε το. Μη μετατρέπετε αβέβαιες τοπικές πληροφορίες σε καθολικό ισχυρισμό.
