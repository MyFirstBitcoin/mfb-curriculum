# 5.3 Ισχυρισμός, τεκμήρια, συλλογισμός και συμβιβασμός

Γράψτε έναν ισχυρισμό σε σημείο όπου μπορούν να τον δουν όλοι. Ζητήστε από τις ομάδες να συμπληρώσουν:

* **Ισχυρισμός:** Τι ακριβώς υποστηρίζεται;
* **Στοιχεία:** Ποια παρατήρηση ή αξιόπιστη πηγή θα μπορούσε να τον υποστηρίξει ή να τον αποδυναμώσει;
* **Συλλογισμός:** Πώς συνδέονται τα στοιχεία με τον ισχυρισμό;
* **Συμβιβασμός:** Ποιο κόστος, ποιος περιορισμός ή ποια εναλλακτική πρέπει να συμπεριληφθεί;
* **Αβεβαιότητα:** Τι είναι άγνωστο, μεταβάλλεται ή εξαρτάται από τις τοπικές συνθήκες;

Αυτό το σχήμα λειτουργεί για ισχυρισμούς σχετικά με [τον πληθωρισμό](https://curriculum.myfirstbitcoin.org/lexicon/en/#inflation), [την αποκέντρωση](https://curriculum.myfirstbitcoin.org/lexicon/en/#decentralization), την ενέργεια, την ταχύτητα πληρωμών, [την ιδιωτικότητα](https://curriculum.myfirstbitcoin.org/lexicon/en/#privacy), την υιοθέτηση, [τα ψηφιακά νομίσματα κεντρικών τραπεζών](https://curriculum.myfirstbitcoin.org/lexicon/en/#cbdc), και τα τοπικά εργαλεία.
