# 6.1 Χρησιμοποιήστε Παρουσίαση → Εξάσκηση → Παραγωγή

**Παρουσίαση:** Επιδείξτε ολόκληρη τη διαδικασία. Εξηγήστε τον σκοπό, τους όρους, τις επιλογές, το αναμενόμενο αποτέλεσμα, τα πιθανά σημεία αποτυχίας, τις συνέπειες για την ιδιωτικότητα και τις συνθήκες διακοπής. Οι εκπαιδευόμενοι παρατηρούν πριν χειριστούν κάποια συσκευή.

**Εξάσκηση:** Οι εκπαιδευόμενοι ακολουθούν μια διαδικασία με υποστήριξη, χρησιμοποιώντας προετοιμασμένο υλικό, μια προσομοίωση, ένα δοκιμαστικό περιβάλλον, ένα άδειο εκπαιδευτικό πορτοφόλι ή ένα πραγματικό περιβάλλον χαμηλού ρίσκου εγκεκριμένο από εκπαιδευτικό. Κάντε παύσεις για ελέγχους και δώστε ανατροφοδότηση.

**Παραγωγή:** Οι εκπαιδευόμενοι ολοκληρώνουν μια καθορισμένη πρακτική εργασία ή καθοδηγούν τη λήψη αποφάσεων χωρίς καθοδήγηση βήμα προς βήμα. Αυτό το στάδιο μπορεί να παρέχει επίσημα τεκμήρια πρακτικών δεξιοτήτων, όταν η εργασία και η κλίμακα αξιολόγησης έχουν εγκριθεί και ένας εκπαιδευτικός παρακολουθεί την εκτέλεσή της.

* Ποιες πληροφορίες παρέμειναν ιδιωτικές;
* Πότε θα σταματούσατε ή θα ζητούσατε βοήθεια;
* Ποιο είναι ένα ασφαλές επόμενο βήμα;
