# 8.17 Συχνές ερωτήσεις για τις ιδιότητες του Bitcoin

| Ιδιότητα | Ερώτηση εκπαιδευόμενου | Απάντηση κατάλληλη για αρχάριους |
| --- | --- | --- |
| Σπανιότητα | «Δεν μπορεί κάποιος απλώς να δημιουργήσει περισσότερα από 21 εκατομμύρια bitcoin;» | Κάποιος μπορεί να γράψει διαφορετικό λογισμικό, αλλά οι συμμετέχοντες δεν είναι υποχρεωμένοι να το εκτελέσουν. Οι κόμβοι που ακολουθούν τους κανόνες του Bitcoin απορρίπτουν την έκδοση πέραν του προβλεπόμενου ορίου. Η ευρεία υιοθέτηση ασύμβατων κανόνων θα μπορούσε να δημιουργήσει ένα ξεχωριστό δίκτυο· κανένας ιδρυτής, εξορύκτης, προγραμματιστής, εταιρεία ή κυβέρνηση δεν μπορεί να δημιουργήσει αθόρυβα επιπλέον bitcoin που να είναι έγκυρα για όλους. |
| Σπανιότητα | «Η περιορισμένη προσφορά σημαίνει ότι η τιμή πρέπει να αυξηθεί;» | Όχι. Η τιμή εξαρτάται τόσο από τη ζήτηση όσο και από την προσφορά, και η ζήτηση μπορεί να μειωθεί. Η πεπερασμένη προσφορά είναι μια νομισματική ιδιότητα, όχι εγγύηση απόδοσης. |
| Διαιρετότητα | «Αν υπάρχουν μόνο 21 εκατομμύρια, αρκούν για όλους;» | Ένα bitcoin διαιρείται σε 100.000.000 sats. Οι μικρότερες μονάδες επιτρέπουν την αναπαράσταση μικρών ποσών χωρίς να αυξάνεται η συνολική προσφορά. |
| Διαιρετότητα | «Χρειάζεται να αγοράσω ένα ολόκληρο bitcoin;» | Όχι. Ένας εκπαιδευόμενος μπορεί να εξηγήσει τι είναι τα sats ή να τα χρησιμοποιήσει χωρίς να κατέχει ένα ολόκληρο bitcoin, και η κατοχή bitcoin δεν αποτελεί προϋπόθεση για το Δίπλωμα Bitcoin. |
| Ανθεκτικότητα | «Τι θα συμβεί αν χαλάσει το τηλέφωνό μου;» | Το Bitcoin δεν αποθηκεύεται μέσα στο τηλέφωνο. Το αρχείο του δικτύου εξακολουθεί να υπάρχει, αλλά η πρόσβαση εξαρτάται από την ασφαλή φύλαξη των κλειδιών και τη δυνατότητα ανάκτησης. Η απώλεια της συσκευής μπορεί να αντιμετωπιστεί με ανάκτηση της πρόσβασης· η απώλεια ή η αποκάλυψη των στοιχείων ανάκτησης μπορεί να προκαλέσει μόνιμη απώλεια. |
| Φορητότητα | «Μπορώ να το στείλω οπουδήποτε χωρίς προϋποθέσεις;» | Μια έγκυρη μεταφορά δεν χρειάζεται έγκριση από κάποιον κεντρικό φορέα διαχείρισης του Bitcoin, αλλά εξακολουθεί να απαιτεί κατάλληλο πορτοφόλι, επικοινωνία, σωστά στοιχεία πληρωμής, τέλη και έναν παραλήπτη που να μπορεί να τη λάβει. Η τοπική νομοθεσία και οι υπηρεσίες ενδέχεται να επιβάλλουν επιπλέον περιορισμούς. |
| Ανταλλαξιμότητα | «Είναι κάθε sat ακριβώς το ίδιο;» | Τα ίσα ποσά υπόκεινται στους ίδιους κανόνες δαπάνης του πρωτοκόλλου, αλλά το δημόσιο ιστορικό συναλλαγών μπορεί να επηρεάσει τον τρόπο με τον οποίο ορισμένες υπηρεσίες ή άτομα αντιμετωπίζουν συγκεκριμένα κεφάλαια. |
| Επαληθευσιμότητα | «Πρέπει να εμπιστεύομαι έναν ιστότοπο;» | Ένας εξερευνητής αλυσίδας συστοιχιών είναι μια εύχρηστη διεπαφή που παρέχεται από τρίτο μέρος. Ένας κόμβος επιτρέπει πιο ισχυρή ανεξάρτητη επαλήθευση, ενώ οι αρχάριοι μπορεί να εξακολουθούν να βασίζονται σε πληροφορίες από πορτοφόλια ή υπηρεσίες και θα πρέπει να αναγνωρίζουν αυτή την εξάρτηση. |
| Αποδοχή | «Αν το Bitcoin είναι χρήσιμο, γιατί δεν μπορώ να το ξοδέψω παντού;» | Η τεχνική δυνατότητα δεν δημιουργεί καθολική αποδοχή. Οι τοπικές συνήθειες, τα εργαλεία, το κόστος, το ρυθμιστικό πλαίσιο, η μεταβλητότητα, η εκπαίδευση και η ζήτηση από τους εμπόρους επηρεάζουν τη χρήση. |
| Αποκέντρωση | «Είναι το Bitcoin πλήρως αποκεντρωμένο;» | Η επιρροή και οι υποδομές δεν κατανέμονται ισότιμα. Ο πιο περιορισμένος ισχυρισμός είναι ότι κανένας μεμονωμένος συμμετέχων δεν μπορεί να αλλάξει μονομερώς τα έγκυρα υπόλοιπα ή τους κανόνες για όλους. |
| Αξιόπιστη σπανιότητα | «Γιατί να μην αντιγράψει κάποιος τον κώδικα και να δημιουργήσει ένα άλλο νόμισμα;» | Η αντιγραφή του κώδικα ή ο ορισμός ενός ανώτατου ορίου προσφοράς στον κώδικα είναι εφικτά. Η αξιόπιστη επιβολή των κανόνων, η ανεξάρτητη επαλήθευση, η ασφάλεια, το ιστορικό, η υιοθέτηση του δικτύου και η αντίσταση σε μονομερείς αλλαγές είναι ξεχωριστά ζητήματα. |
