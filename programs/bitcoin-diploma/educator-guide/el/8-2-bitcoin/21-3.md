# 8.21 Ανασκόπηση και μετάβαση στην Ενότητα 3

Ζητήστε από τους εκπαιδευόμενους να συμπληρώσουν:


| Πρόβλημα του συστήματος παραστατικού χρήματος | Απάντηση του Bitcoin | Νέα ευθύνη ή συμβιβασμός |
| --- | --- | --- |
| Η προσφορά μπορεί να αλλάξει μέσω της νομισματικής πολιτικής |  |  |
| Οι πληρωμές εξαρτώνται από μεσάζοντες |  |  |
| Ένας μόνο διαχειριστής του καθολικού ελέγχει τις εγγραφές |  |  |
| Η πρόσβαση εξαρτάται από έναν οργανισμό |  |  |


Απαιτήστε μια σαφή εξήγηση του γιατί [οι κόμβοι](https://curriculum.myfirstbitcoin.org/lexicon/en/#node) και [οι εξορύκτες](https://curriculum.myfirstbitcoin.org/lexicon/en/#miner) έχουν διαφορετικούς ρόλους.

Στη συνέχεια, χρησιμοποιήστε την καταληκτική ερώτηση της **Ενότητας 2** του Οδηγού Σπουδαστή. Κρατήστε την απάντηση ιδιωτική ή προαιρετική, ακολουθώντας τις παραπάνω οδηγίες για έναν σύντομο αναστοχασμό στο κλείσιμο της ενότητας.

Μετάβαση:

> Το Bitcoin μπορεί να μειώσει την εξάρτηση από έναν διαχειριστή λογαριασμού, αλλά ο άμεσος έλεγχος εξαρτάται από τα κλειδιά, την επαλήθευση, την ανάκτηση και τις ασφαλείς αποφάσεις. **Η Ενότητα 3** μετατρέπει αυτή την ευθύνη σε πράξη.
