# 16.3 Αναστοχαστείτε ως εκπαιδευτικός

Συμπληρώστε αυτή την ανασκόπηση όσο το μάθημα είναι ακόμη πρόσφατο στη μνήμη σας:


| Ερώτηση | Σημειώσεις και ενέργειες |
| --- | --- |
| Ποια ικανότητα χρειάστηκε περισσότερο ή λιγότερο χρόνο από τον προβλεπόμενο; |  |
| Ποια παρανόηση εμφανίστηκε επανειλημμένα; |  |
| Ποιων εκπαιδευομένων οι φωνές ακούστηκαν λιγότερο; |  |
| Ποιο τοπικό παράδειγμα βελτίωσε όσα μπορούσαν να εξηγήσουν, να συγκρίνουν ή να κάνουν οι εκπαιδευόμενοι; |  |
| Ποιο παράδειγμα απέκτησε πολιτικό, διαφημιστικό ή υπερβολικά προσωπικό χαρακτήρα; |  |
| Ποια δραστηριότητα παρήγαγε χρήσιμα τεκμήρια; |  |
| Ποια δραστηριότητα οδήγησε σε παραπλανητική απλούστευση; |  |
| Ήταν αποτελεσματικές όλες οι συνθήκες διακοπής των πρακτικών δραστηριοτήτων; |  |
| Έπαψε κάποιο εργαλείο, σύνδεσμος, χρέωση, κανόνας ή καταχώριση να είναι επίκαιρο; |  |
| Ποια αξιολογική κρίση χρειάζεται επανεξέταση για τη διασφάλιση της συνέπειας της αξιολόγησης; |  |
| Ποια προσαρμογή προσβασιμότητας ή γλώσσας θα πρέπει να διατηρηθεί; |  |
| Τι θα αλλάξει πριν από την επόμενη ομάδα εκπαιδευομένων; |  |
