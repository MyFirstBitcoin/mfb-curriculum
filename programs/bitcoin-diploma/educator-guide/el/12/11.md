# 12.11 Μεγάλες ομάδες εκπαιδευομένων

Αξιοποιήστε την αλληλεπίδραση μεταξύ εκπαιδευομένων για μάθηση, όχι για πιστοποίηση μεταξύ τους.

* Αναθέστε ρόλους στην ομάδα, ώστε όλοι να μιλούν και να συμμετέχουν στις αποφάσεις.
* Χρησιμοποιήστε κάρτες απαντήσεων, σύντομες γραπτές απαντήσεις ή εξηγήσεις σε ζευγάρια, ώστε να ακούγονται περισσότεροι εκπαιδευόμενοι.
* Οργανώστε εναλλαγή στους σταθμούς πρακτικής εξάσκησης με υποστήριξη από εκπαιδευμένο προσωπικό.
* Αναθέστε την άμεση παρατήρηση αποκλειστικά στον εκπαιδευτή.
* Προγραμματίστε ξεχωριστή πρακτική αξιολόγηση, αν η δυνατότητα παρατήρησης είναι περιορισμένη.
* Διατηρήστε τον φόρτο εργασίας του εκπαιδευτή ανά εκπαιδευόμενο αρκετά χαμηλό, ώστε να μπορούν να λαμβάνονται τεκμηριωμένες αποφάσεις.
