# 12.1 Προσαρμόστε τα παραδείγματα στο τοπικό πλαίσιο, όχι τα κριτήρια αλήθειας

<!-- card: light -->
> **Προσαρμόστε το παράδειγμα στο τοπικό πλαίσιο, όχι το μαθησιακό πρότυπο**
>
> Χρησιμοποιήστε τοπικά παραδείγματα για να βοηθήσετε τους εκπαιδευόμενους να κατανοήσουν μια κοινή έννοια. Για κάθε προσαρμογή, αναρωτηθείτε:
>
> * Ποια ικανότητα εξυπηρετεί αυτή η προσαρμογή;
> * Παραμένει αμετάβλητη η υποκείμενη έννοια;
> * Είναι το παράδειγμα ακριβές και επίκαιρο;
> * Δημιουργεί κίνδυνο πολιτικής ή νομικής φύσης ή κίνδυνο για την ιδιωτικότητα ή την ασφάλεια;
> * Μπορούν οι εκπαιδευόμενοι να συμμετάσχουν χωρίς να αποκαλύψουν προσωπικές πληροφορίες;
> * Υπονοεί κάποια σύσταση;
> * Εξακολουθεί η αξιολόγηση να παρέχει ισοδύναμα τεκμήρια μάθησης;


Τεκμηριώστε τις ουσιώδεις αλλαγές, ώστε ένας άλλος εκπαιδευτικός να μπορεί να διαπιστώσει τι προσαρμόστηκε στο τοπικό πλαίσιο και γιατί.
