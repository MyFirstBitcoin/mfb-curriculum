# 12.3 Νομικό, φορολογικό, λογιστικό και κανονιστικό πλαίσιο

Μπορείτε να βοηθήσετε τους εκπαιδευόμενους να αναγνωρίσουν ότι υπάρχουν αυτοί οι τομείς και να εντοπίσουν πού χρειάζεται αξιόπιστη τοπική καθοδήγηση. Μπορείτε να εξηγήσετε έναν δημοσιευμένο κανόνα που έχετε ελέγξει, σε επίπεδο αρχαρίων, εφόσον διαθέτετε την απαραίτητη επάρκεια.

Μην:

* συμβουλεύετε έναν εκπαιδευόμενο πώς να διαρθρώσει μια συναλλαγή για να αποκομίσει φορολογικό ή νομικό όφελος
* λέτε σε έναν εκπαιδευόμενο ότι μια επιλογή είναι νόμιμη χωρίς τεκμηρίωση για τη συγκεκριμένη δικαιοδοσία
* ερμηνεύετε τις υποχρεώσεις ενός συγκεκριμένου εκπαιδευόμενου
* ενθαρρύνετε την καταστρατήγηση ή την απόκρυψη
* παρουσιάζετε μια πρακτική της κοινότητας ως απόδειξη συμμόρφωσης· ή
* επιτρέπετε σε έναν προσκεκλημένο να χρησιμοποιεί το μάθημα για να προσελκύσει πελάτες για τις επαγγελματικές του υπηρεσίες.

Χρησιμοποιήστε διατυπώσεις όπως:
