# 12.2 Διαχωρίστε τις σταθερές έννοιες από τα μεταβαλλόμενα δεδομένα

| Σταθερή έννοια του προγράμματος σπουδών | Μεταβαλλόμενο τοπικό δεδομένο |
| --- | --- |
| Μια τραπεζική κατάθεση αποτελεί απαίτηση έναντι μιας τράπεζας | Τοπικό όριο προστασίας καταθέσεων και προϋποθέσεις κάλυψης |
| Οι μετρήσεις του πληθωρισμού χρησιμοποιούν ένα επιλεγμένο καλάθι και μια συγκεκριμένη μέθοδο | Τρέχον τοπικό ποσοστό πληθωρισμού, συντελεστές στάθμισης του καλαθιού και μεθοδολογία δημοσίευσης |
| Ένα CBDC είναι παραστατικό χρήμα που εκδίδεται από κεντρική τράπεζα | Αν η τοπική κεντρική τράπεζα ερευνά, δοκιμάζει πιλοτικά ή εκδίδει ένα τέτοιο νόμισμα |
| Θεματοφυλακή σημαίνει έλεγχος των κλειδιών | Το μοντέλο θεματοφυλακής μιας τρέχουσας έκδοσης πορτοφολιού |
| Οι προμήθειες και η ρευστότητα επηρεάζουν τις διαδρομές πληρωμών | Τρέχουσες εκτιμήσεις προμηθειών, περιθώρια τιμών των υπηρεσιών και ρευστότητα του Lightning |
| Η χρήση και η μη χρήση KYC συνεπάγονται διαφορετικούς συμβιβασμούς | Ισχύοντες κανόνες ταυτοποίησης και νομικές απαιτήσεις |
| Οι καταχωρίσεις σε χάρτες μπορεί να πάψουν να είναι επίκαιρες | Αν ένας τοπικός έμπορος δέχεται Bitcoin σήμερα |


Σημειώστε την ημερομηνία των μεταβαλλόμενων δεδομένων και εξηγήστε στους εκπαιδευόμενους τι μπορεί να αλλάξει. Όταν προετοιμάζετε ένα τοπικό παράδειγμα, μπορείτε να ζητήσετε από τον [βοηθό τεχνητής νοημοσύνης του Bitcoin Diploma](https://ai.myfirstbitcoin.org) να προτείνει ποιοι ισχυρισμοί χρειάζονται έλεγχο και ποια τεκμήρια να αναζητήσετε. Ανοίξτε οι ίδιοι τις πρωτότυπες πηγές, επιβεβαιώστε ότι τεκμηριώνουν κάθε ισχυρισμό και καταγράψτε την πηγή και την ημερομηνία· μια απάντηση τεχνητής νοημοσύνης δεν αποτελεί τεκμήριο ότι ένα δεδομένο παραμένει επίκαιρο.
