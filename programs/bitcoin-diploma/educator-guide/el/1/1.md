# 1.1 Πέρα από την παρουσίαση πληροφοριών

Ο ρόλος σας δεν είναι να δώσετε μια τέλεια διάλεξη. Ο ρόλος σας είναι να βοηθήσετε τους εκπαιδευόμενους να εξηγούν, να εξασκούνται και να λαμβάνουν ασφαλείς αποφάσεις. Συντονίζετε την ομάδα, καθοδηγείτε τη μάθηση, προστατεύετε τους ανθρώπους και τις πληροφορίες, προσθέτετε επαληθευμένα στοιχεία από το τοπικό πλαίσιο και αξιολογείτε τα απαιτούμενα τεκμήρια.
