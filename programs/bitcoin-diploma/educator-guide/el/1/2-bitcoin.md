# 1.2 Ο σκοπός του Διπλώματος Bitcoin και η ευθύνη σας

Σκοπός του Διπλώματος Bitcoin είναι κάθε εκπαιδευόμενος να αναπτύξει και να επιδείξει τις απαιτούμενες ικανότητες. Ο ρόλος σας είναι να παρέχετε τις γνώσεις και την καθοδηγούμενη πρακτική εξάσκηση που υποστηρίζουν αυτές τις ικανότητες, να διασφαλίζετε ότι οι εκπαιδευόμενοι έχουν δίκαιες ευκαιρίες να τις αναπτύξουν κατά τη διάρκεια του κύκλου μαθημάτων και να αξιολογείτε την ατομική δυνατότητα, την ικανότητα και την πρακτική δεξιότητα κάθε εκπαιδευόμενου βάσει των καθορισμένων κριτηρίων.

Πριν χορηγήσετε σε έναν εκπαιδευόμενο πιστοποιητικό ολοκλήρωσης ή τον προτείνετε για τη χορήγησή του, επιβεβαιώστε ότι έχει επιδείξει κάθε απαιτούμενη ικανότητα μέσω των εγκεκριμένων αποδεικτικών στοιχείων: παρατηρήσιμης εξήγησης, σύγκρισης, συλλογισμού ή εφαρμογής για τη θεωρία και άμεσης παρατήρησης από τον εκπαιδευτικό για τις πρακτικές δεξιότητες. Η παρουσία, η αυτοπεποίθηση, η ανεξάρτητη επανάληψη της ύλης ή ο ισχυρισμός του ίδιου του εκπαιδευόμενου ότι διαθέτει μια ικανότητα δεν μπορούν να υποκαταστήσουν αυτά τα αποδεικτικά στοιχεία.

Είστε υπεύθυνοι να βοηθάτε τους εκπαιδευόμενους:

* να ενεργοποιούν όσα ήδη γνωρίζουν
* να κάνουν ερωτήσεις χωρίς να ντρέπονται
* να διακρίνουν τα γεγονότα, τις απόψεις, τις προτιμήσεις και την αβεβαιότητα
* να συγκρίνουν ισχυρισμούς χρησιμοποιώντας σταθερά κριτήρια
* να συνδέουν έννοιες από διαφορετικές ενότητες
* να εξασκούνται με ασφάλεια πριν ενεργήσουν αυτόνομα
* να μαθαίνουν από τα λάθη τους χωρίς να τα κρύβουν
* να εφαρμόζουν ιδέες στην τοπική καθημερινότητα χωρίς να αποκαλύπτουν προσωπικά οικονομικά στοιχεία
* να επιδεικνύουν όσα μπορούν να εξηγήσουν και να κάνουν· και
* να προσδιορίζουν ένα κατάλληλο επόμενο βήμα ή έναν λόγο για να διατηρούν την αβεβαιότητά τους.

Δεν είστε υπεύθυνοι να κάνετε τους εκπαιδευόμενους να συμφωνούν μαζί σας. Ένας εκπαιδευόμενος μπορεί να πληροί το πρότυπο του Διπλώματος Bitcoin διατηρώντας κριτική στάση απέναντι στο Bitcoin, στα συστήματα παραστατικού χρήματος, [στην αυτοθεματοφυλακή](https://curriculum.myfirstbitcoin.org/lexicon/en/#self-custody), ή σε μια τοπική περίπτωση χρήσης του Bitcoin, εφόσον μπορεί να εξηγεί τις έννοιες, να χρησιμοποιεί συναφή αποδεικτικά στοιχεία, να εξηγεί τους συμβιβασμούς μεταξύ πλεονεκτημάτων και μειονεκτημάτων και να επιδεικνύει τις απαιτούμενες ικανότητες ασφάλειας.
