# 3.3 Καλωσορίστε τη διαφωνία και διορθώστε τα λάθη

Όταν ένας εκπαιδευόμενος διαφωνεί:

1. Ζητήστε του να διατυπώσει τον ισχυρισμό του με ακρίβεια.
1. Ρωτήστε ποια στοιχεία ή ποια εμπειρία στηρίζουν τον ισχυρισμό του.
1. Εντοπίστε το κοινό ερώτημα που αφορά τα πραγματικά δεδομένα.
1. Συγκρίνετε τον ισχυρισμό με τον ορισμό που δίνεται στο μάθημα ή με μια επαληθευμένη πηγή.
1. Διαχωρίστε όσα μπορούν να επιλυθούν από όσα παραμένουν ζήτημα αξιολογικής κρίσης.
1. Καλέστε τον εκπαιδευόμενο να αναθεωρήσει, να μετριάσει ή να διατηρήσει το συμπέρασμά του.

Διορθώνετε τα λάθη που αφορούν πραγματικά δεδομένα με σαφήνεια και σεβασμό. Μην αποφεύγετε τη διόρθωση στο όνομα της ουδετερότητας. Η ουδέτερη διευκόλυνση της μάθησης σημαίνει να εφαρμόζετε δίκαια κριτήρια τεκμηρίωσης, όχι να αντιμετωπίζετε κάθε δήλωση ως εξίσου ακριβή.
