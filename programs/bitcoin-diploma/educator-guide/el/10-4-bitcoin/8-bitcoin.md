# 10.8 Αξιολόγηση τοπικού εργαλείου Bitcoin

Μην παρουσιάζετε ένα εργαλείο απλώς επειδή είναι δημοφιλές σε τοπικό επίπεδο. Χρησιμοποιήστε την ακόλουθη σύγκριση:


| Τομέας | Ερώτηση |
| --- | --- |
| Σκοπός | Ποιο πρόβλημα επιλύει το εργαλείο και είναι απαραίτητο; |
| Θεματοφυλακή | Ποιος ελέγχει τα κλειδιά και τα κεφάλαια; |
| Πηγή | Ποιος το δημοσιεύει και πώς επαληθεύτηκε η γνησιότητα της πηγής; |
| Κώδικας και συντήρηση | Είναι ανοικτού κώδικα, ελέγχεται, συντηρείται και ενημερώνεται με ασφάλεια; |
| Ανάκτηση | Τι συμβαίνει όταν η συσκευή, η υπηρεσία ή η εταιρεία πάψει να υπάρχει; |
| Ιδιωτικότητα | Ποια δεδομένα ταυτότητας, επικοινωνίας, συσκευής, τοποθεσίας και συναλλαγών συλλέγονται; |
| Κόστος | Ποιες εμφανείς χρεώσεις, διαφορές τιμών αγοράς και πώλησης, συνδρομές, κόστη χρηματοδότησης και κόστη ανάληψης ισχύουν; |
| Συμβατότητα | Ποια δίκτυα, τύποι διευθύνσεων, αιτήματα πληρωμής, αντίγραφα ασφαλείας και συσκευές υποστηρίζονται; |
| Υποστήριξη | Μπορούν οι εκπαιδευόμενοι να λάβουν βοήθεια χωρίς να αποκαλύψουν μυστικά στοιχεία; |
| Νομοθεσία και τήρηση αρχείων | Ποιοι τοπικοί περιορισμοί, κανόνες προστασίας καταναλωτών, φορολογικές ή λογιστικές υποχρεώσεις ή υποχρεώσεις υποβολής αναφορών ενδέχεται να έχουν σημασία; |
| Εναλλακτική | Τι μπορούν να χρησιμοποιήσουν οι εκπαιδευόμενοι αν το εργαλείο πάψει να λειτουργεί ή δεν είναι διαθέσιμο; |

> **Τα τοπικά παραδείγματα δεν αποτελούν συστάσεις παγκόσμιας ισχύος**
>
> Αυτό το εργαλείο αποτελεί ένα τοπικό παράδειγμα για εκπαιδευτικούς σκοπούς, το οποίο αφορά μια συγκεκριμένη χρονική στιγμή. Η χρήση του στην τάξη δεν αποτελεί σύσταση παγκόσμιας ισχύος από το My First Bitcoin ούτε υπόσχεση ότι θα παραμείνει κατάλληλο.
