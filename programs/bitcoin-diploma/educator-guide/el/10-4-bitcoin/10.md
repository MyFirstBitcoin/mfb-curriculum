# 10.10 Επιλογή Α για την ενότητα: σύγκριση τοπικών διαδρομών πληρωμής

**Σκοπός:** Συγκρίνετε την πλήρη διαδρομή μιας υφιστάμενης τοπικής πληρωμής, μιας πληρωμής στην αλυσίδα και μιας πληρωμής μέσω Lightning, όπου ενδείκνυται.

**Προετοιμασία:** Χρησιμοποιήστε ένα ρεαλιστικό, υποθετικό ποσό πληρωμής και έναν υποθετικό παραλήπτη. Προετοιμάστε τοπικές πληροφορίες με ημερομηνία αναφοράς σχετικά με τις προμήθειες, τη μετατροπή συναλλάγματος, τον χρόνο εκτέλεσης, τη [θεματοφυλακή](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), και την πρόσβαση. Εάν τα δεδομένα δεν μπορούν να επαληθευτούν, επισημάνετέ τα σαφώς ως υποθετικά.

**Εργασία εκπαιδευομένου:** Συμπληρώστε:


| Πεδίο | Υφιστάμενη μέθοδος | Bitcoin στην αλυσίδα | Lightning, εφόσον είναι σχετικό |
| --- | --- | --- | --- |
| Ποσό που αποστέλλεται |  |  |  |
| Συνολικό ποσό που λαμβάνεται |  |  |  |
| Αναμενόμενος χρόνος και διακανονισμός |  |  |  |
| Προμήθειες και διαφορά τιμής αγοράς–πώλησης |  |  |  |
| Θεματοφυλακή σε κάθε στάδιο |  |  |  |
| Ταυτότητα και ιδιωτικότητα |  |  |  |
| Αντιστροφή συναλλαγής ή επιστροφή χρημάτων |  |  |  |
| Κύριο σημείο αστοχίας |  |  |  |
| Τοπική υποστήριξη ή νομοθεσία |  |  |  |


**Παραγωγή έργου:** Ο εκπαιδευόμενος επιλέγει μια διαδρομή για την υποθετική περίπτωση, επιδεικνύει ή παρουσιάζει με τη σειρά τα βήματα του σχετικού αιτήματος πληρωμής και της επαλήθευσής του και εξηγεί γιατί η άλλη διαδρομή θα μπορούσε να είναι καλύτερη αν άλλαζε κάποια συνθήκη.

**Αναστοχασμός:** Βελτίωσε το Bitcoin την πλήρη διαδρομή ή μόνο ένα ορατό βήμα; Ποιος επωμίζεται τους κινδύνους που σχετίζονται με τη μεταβλητότητα, τη μετατροπή, τη [θεματοφυλακή](https://curriculum.myfirstbitcoin.org/lexicon/en/#custody), και την αποτυχία;

**Ασφάλεια:** Δεν απαιτείται πραγματική μεταφορά ούτε η αναφορά συγκεκριμένου παρόχου. Χρησιμοποιήστε έντυπες πληροφορίες πληρωμής.
