# 13.1 Ο σκοπός της δραστηριότητας έχει προτεραιότητα

Κάθε δραστηριότητα θα πρέπει να δηλώνει αν αποτελεί:

* μάθηση και εξάσκηση
* διαμορφωτικό έλεγχο θεωρητικών γνώσεων ή ανατροφοδότηση
* μια θεωρητική παρέμβαση υπό την καθοδήγηση του εκπαιδευτικού, ευθυγραμμισμένη με την επιδιωκόμενη επάρκεια
* μια πρακτική δραστηριότητα που μπορεί επίσης να παρέχει τεκμήρια αξιολόγησης· ή
* έναν εγκεκριμένο συνδυασμό διαμορφωτικής μάθησης και πρακτικής αξιολόγησης.

Οι δραστηριότητες στη [Βιβλιοθήκη δραστηριοτήτων](https://curriculum.myfirstbitcoin.org/activities/en/) μπορούν να υποστηρίζουν τη μάθηση, την εξάσκηση και την αξιολόγηση. Η χρήση τους δεν καθιστά κάθε δραστηριότητα αξιολόγηση. Όταν χρησιμοποιείτε μια δραστηριότητα ως τεκμήριο, βεβαιωθείτε ότι δίνει σε κάθε εκπαιδευόμενο μια δίκαιη ευκαιρία να επιδείξει την επάρκειά του, διατηρεί σαφή τα όρια ασφάλειας και σας επιτρέπει να καταγράψετε **Ναι** ή **Όχι ακόμη**. Δεν χρειάζεται να δημιουργείτε εκτενείς καταγραφές τεκμηρίων ή ξεχωριστή δοκιμασία.
