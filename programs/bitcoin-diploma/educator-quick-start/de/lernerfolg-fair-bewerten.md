# Lernerfolg fair bewerten

Die Zertifizierung erfordert zwei **nicht kompensierbare** Komponenten, die beide von einer Lehrkraft bewertet und dokumentiert werden:


| Komponente | Was zählt |
| --- | --- |
| Theoretisches Verständnis (50 %) | Eine genehmigte, auf die Lernziele abgestimmte Erklärung, ein Vergleich, eine Antwort auf ein Szenario oder eine ähnliche Interaktion der lernenden Person, bewertet anhand festgelegter Kriterien. |
| Praktische Kompetenz (50 %) | Direkte Beobachtung, wie eine lernende Person eine genehmigte Aufgabe, Simulation oder ein Rollenspiel sicher und gemäß dem zugehörigen Bewertungsraster ausführt. |


Anwesenheit, Engagement, selbstständige Wiederholung oder eine gewöhnliche Diskussion allein gelten nicht als Nachweis für die Zertifizierung. Machen Sie Lernziel, Sicherheitsgrenze, Aufgabe und Erfolgskriterien deutlich; unterrichten und üben Sie zunächst; beobachten Sie anschließend, geben Sie Feedback, dokumentieren Sie das Ergebnis und bieten Sie bei Bedarf eine faire Wiederholungsprüfung an. Die Module 3 und 4 erfordern eine direkte praktische Beobachtung.
