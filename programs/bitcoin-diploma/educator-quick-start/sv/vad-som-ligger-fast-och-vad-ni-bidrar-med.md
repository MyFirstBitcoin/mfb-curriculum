# Vad som ligger fast – och vad ni bidrar med

**Behåll oförändrat:** ordningsföljden för de fyra modulerna; huvudmålen; fokus enbart på Bitcoin; säkerhetsgränserna; den tvådelade bedömningen; och minimikraven för godkänt.

**Anpassa med eftertanke:** exempel, språk, aktiviteter, tempo, gruppindelning, tillgänglighetsstöd, lokala verktyg och **modul 4:s** scenarier. Lär ut att plånboksprogramvara med öppen källkod är att föredra med vissa förbehåll, eftersom kod som kan granskas kan öka transparensen, samtidigt som ni hjälper deltagarna att jämföra förvaring, återställning, kompatibilitet, integritet, underhåll, kostnader och support. Behandla namngivna plånböcker, börser, handlare, kartor och tjänster som tidsbundna lokala exempel – inte som globala rekommendationer. Kontrollera aktuella påståenden och lokala regler med hjälp av auktoritativa källor; om ni inte vet, säg det och kontrollera.

Lär deltagarna **hur de ska tänka, inte vad de ska tänka**. Välkomna respektfulla meningsskiljaktigheter. En deltagare behöver inte hålla med om ett påstående för att uppfylla kraven; deltagaren behöver kunna resonera, förklara relevanta avvägningar och visa de färdigheter som krävs på ett säkert sätt.
