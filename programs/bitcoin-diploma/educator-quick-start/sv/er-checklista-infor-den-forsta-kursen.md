# Er checklista inför den första kursen

* [ ] Lägg upp ett schema som omfattar minst åtta timmars undervisning, övning, bedömning, återkoppling och dokumentation, med mer tid när deltagarna behöver det.
* [ ] Läs [elevhandledningen](https://curriculum.myfirstbitcoin.org/programs/bitcoin-diploma/en/student-guide/), [lärarhandledningen](https://curriculum.myfirstbitcoin.org/programs/educator-guide/), samt relevanta mål.
* [ ] Välj aktiviteter och förbered bedömningsramverket, godkända uppgifter, bedömningsmatriser och dokumentation.
* [ ] Planera en säker uppgift för modul 4 med hjälp av lärarhandledningens verktyg för att skapa anpassade moduler; kontrollera aktuella lokala fakta och verktyg.
* [ ] Förbered material med låga tekniska krav och ett reservalternativ som inte kräver pengar; skydda deltagarnas integritet och säkerställ tillgänglighet.
* [ ] Uppmuntra frågor, för en lista över fördjupningsfrågor att följa upp och avsluta med att fråga deltagarna vad de nu kan förklara eller göra.
