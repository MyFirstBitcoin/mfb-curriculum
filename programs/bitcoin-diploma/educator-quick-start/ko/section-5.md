# 학습을 공정하게 평가하기

인증을 받으려면 두 가지 **상호 보완이 불가능한** 구성 요소를 모두 충족해야 하며, 두 요소 모두 교육자가 평가하고 기록해요.


| 구성 요소 | 인정되는 근거 |
| --- | --- |
| 이론적 이해 (50%) | 승인된, 학습 목표에 부합하는 학습자의 설명, 비교, 시나리오 응답 또는 이와 유사한 상호작용으로, 명시된 기준에 따라 평가해요. |
| 실무 역량 (50%) | 학습자가 승인된 과제, 시뮬레이션 또는 역할극을 안전하게 완수하는 모습을 직접 관찰하고, 해당 평가 기준표에 따라 평가해요. |


출석, 열의, 개별 복습 또는 일반적인 토론만으로는 인증 근거가 되지 않아요. 학습 목표, 안전 경계, 과제, 성공 기준을 명확히 제시하세요. 먼저 가르치고 연습하게 한 다음, 관찰하고 피드백을 주고 결과를 기록하며, 필요한 경우 공정한 재평가 기회를 제공하세요. 모듈 3과 4는 실무에 대한 직접 관찰이 필요해요.
