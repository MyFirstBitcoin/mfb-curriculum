# 첫 강좌를 위한 체크리스트

* [ ] 수업, 실습, 평가, 피드백, 기록을 포함해 최소 8시간이 되도록 일정을 세우고, 학습자에게 필요할 때마다 시간을 더 확보하세요.
* [ ] 다음 자료를 읽어 보세요: [학생 가이드](https://curriculum.myfirstbitcoin.org/programs/bitcoin-diploma/en/student-guide/), [교육자 가이드](https://curriculum.myfirstbitcoin.org/programs/educator-guide/), 관련 학습 목표.
* [ ] 활동을 선택하고 평가 체계, 승인된 과제, 루브릭, 기록 자료를 준비하세요.
* [ ] 교육자 가이드의 맞춤 모듈 빌더를 활용해 안전한 모듈 4 과제를 계획하고, 현재의 현지 정보와 도구를 확인하세요.
* [ ] 저기술 자료와 자금 없이도 진행할 수 있는 대체 방안을 준비하고, 학습자의 개인정보와 접근성을 보호하세요.
* [ ] 질문을 장려하고 심화 후속 목록을 관리하며, 마지막에는 학습자에게 이제 무엇을 설명하거나 할 수 있는지 물어보며 마무리하세요.
