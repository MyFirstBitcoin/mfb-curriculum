# Ձեր առաջին դասընթացի ստուգաթերթը

* [ ] Կազմեք ժամանակացույց, որը ներառում է առնվազն ութ ժամ՝ դասավանդման, գործնական աշխատանքի, գնահատման, հետադարձ կապի և գրանցումների համար՝ անհրաժեշտության դեպքում սովորողներին տրամադրելով լրացուցիչ ժամանակ։
* [ ] Կարդացեք [Սովորողի ուղեցույցը](https://curriculum.myfirstbitcoin.org/programs/bitcoin-diploma/en/student-guide/), [Դասավանդողի ուղեցույցը](https://curriculum.myfirstbitcoin.org/programs/educator-guide/) և համապատասխան նպատակները։
* [ ] Ընտրեք վարժությունները և պատրաստեք գնահատման շրջանակը, հաստատված առաջադրանքները, գնահատման սանդղակներն ու գրանցամատյանները։
* [ ] Պլանավորեք մոդուլ 4-ի անվտանգ առաջադրանք՝ օգտվելով Դասավանդողի ուղեցույցի՝ անհատականացված մոդուլ կազմելու գործիքից․ ստուգեք տեղական արդի փաստերն ու գործիքները։
* [ ] Պատրաստեք պարզ տեխնիկական միջոցներով օգտագործվող նյութեր և միջոցներ չպահանջող պահուստային տարբերակ․ պաշտպանեք սովորողների գաղտնիությունը և ապահովեք մատչելիությունը։
* [ ] Խրախուսեք հարցեր տալը, պահեք հետագա խորացված ուսումնասիրության հարցերի ցանկ և ավարտեք՝ հարցնելով սովորողներին, թե այժմ ինչ կարող են բացատրել կամ անել։
