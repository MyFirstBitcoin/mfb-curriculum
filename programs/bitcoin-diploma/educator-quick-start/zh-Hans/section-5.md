# 公平评估学习成果

认证要求两个**不可相互抵补的**组成部分，均须由教育者进行评估和记录：


| 组成部分 | 认可的证据 |
| --- | --- |
| 理论理解（50%） | 学习者作出的、经批准且与学习目标一致的解释、比较、情景应答或类似互动，并依据既定标准进行评估。 |
| 实践能力（50%） | 直接观察学习者安全地完成经批准的任务、模拟或角色扮演，并依据相应评分标准进行评估。 |


仅凭出勤、积极性、自主复习或普通讨论，不能作为认证证据。请明确学习目标、安全边界、任务及成功标准；先进行教学和练习；然后进行观察、给予反馈、记录结果，并在需要时提供公平的重新评估机会。模块3和模块4要求进行直接的实践观察。
