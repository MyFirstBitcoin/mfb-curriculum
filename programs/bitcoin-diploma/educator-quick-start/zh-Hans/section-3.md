# 固定不变的部分——以及您带来的部分

**保持不变：**四个模块的顺序；核心目标；只聚焦比特币；安全边界；两部分评估；以及最低结业标准。

**审慎调整：**示例、语言、活动、节奏、分组、无障碍支持、本地工具，以及**模块4**中的情景。将开源钱包软件作为有条件的优先选择来讲授，因为可审查的代码能够提高透明度；同时帮助学员比较托管方式、恢复、兼容性、隐私、维护、成本和支持。将具体提及的钱包、交易所、商家、地图和服务视为有时效性的本地示例，而非全球通用的推荐。请通过权威来源核实最新说法和当地法规；如果您不清楚，请如实说明并加以核实。

教会学员**如何思考，而不是思考什么**。欢迎相互尊重的不同意见。学员无需认同某一观点才能达到标准；他们需要做的是进行推理，解释相关的利弊权衡，并安全地展示所要求的技能。
