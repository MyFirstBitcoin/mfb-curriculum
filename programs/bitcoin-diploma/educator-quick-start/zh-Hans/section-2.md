# 学习路径

| 模块 | 学习者结业时应能够…… | 您的教学重点 |
| --- | --- | --- |
| 1. 认识货币 | 解释货币为何存在，并比较货币的各种形式及其利弊权衡。 | 从学习者的亲身经历出发；补充经过核实的本地背景信息。 |
| 2. 比特币如何运作 | 用通俗易懂的语言解释比特币为何被创造，以及其面向初学者的基本特性。 | 让概念之间的关联清晰可见；引导学习者围绕观点、证据和利弊权衡进行思考。 |
| 3. 安全使用比特币 | 解释托管与安全，然后展示初级的钱包使用、验证、恢复准备和安全技能。 | 先示范；再指导练习；保护好机密信息。 |
| 4. 社区中的比特币 | 展示比特币作为货币发挥作用的一种安全且贴合本地实际的方式，并解释其利弊权衡。 | 选择经过核实的本地需求，而不是推销某种产品。 |


请将这一顺序作为一个连贯的故事来讲授：**货币问题 → 比特币的回应 → 个人责任 → 本地应用**。模块1至3是共享的核心内容。模块4为必修但可定制：您可以选择合适的本地任务，同时保持其学习成果和证据标准不变。详细的技术、交易、投资、法律、税务、会计、合规和政策内容不属于初级核心内容的范围。
