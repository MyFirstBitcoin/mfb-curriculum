# 您的首次课程清单

* [ ] 制定日程安排，至少包含八小时的教学、练习、评估、反馈和记录时间；学员需要时，请安排更多时间。
* [ ] 阅读[《学生指南》](https://curriculum.myfirstbitcoin.org/programs/bitcoin-diploma/en/student-guide/)、[《教育者指南》](https://curriculum.myfirstbitcoin.org/programs/educator-guide/)以及相关学习目标。
* [ ] 选择活动，并准备评估框架、经批准的任务、评分标准和记录。
* [ ] 使用《教育者指南》中的自定义模块构建工具，规划一项安全的第4模块任务；核实当前的本地信息和工具。
* [ ] 准备低技术含量的材料和无需资金的备用方案；保护学员的隐私并确保无障碍访问。
* [ ] 鼓励学员提问，保留一份进阶跟进清单，最后请学员说说他们现在能够解释或做到什么。
