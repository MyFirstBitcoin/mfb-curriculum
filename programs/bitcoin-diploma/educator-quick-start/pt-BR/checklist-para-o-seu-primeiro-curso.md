# Checklist para o seu primeiro curso

* [ ] Defina um cronograma que inclua pelo menos oito horas de ensino, prática, avaliação, feedback e registro, com mais tempo sempre que os alunos precisarem.
* [ ] Leia o [Guia do Aluno](https://curriculum.myfirstbitcoin.org/programs/bitcoin-diploma/en/student-guide/), o [Guia do Educador](https://curriculum.myfirstbitcoin.org/programs/educator-guide/) e os objetivos pertinentes.
* [ ] Selecione as atividades e prepare a estrutura de avaliação, as tarefas aprovadas, as rubricas e os registros.
* [ ] Planeje uma tarefa segura para o Módulo 4 usando o Construtor de módulos personalizados do Guia do Educador; verifique os fatos e as ferramentas locais atuais.
* [ ] Prepare materiais de baixa tecnologia e uma alternativa sem uso de fundos; proteja a privacidade dos alunos e garanta a acessibilidade.
* [ ] Incentive perguntas, mantenha uma lista de acompanhamento para o nível Avançado e encerre perguntando aos alunos o que eles agora conseguem explicar ou fazer.
