# รายการตรวจสอบสำหรับหลักสูตรแรกของคุณ

* [ ] กำหนดตารางเวลาให้ครอบคลุมการสอน การฝึกปฏิบัติ การประเมิน การให้ข้อเสนอแนะ และการบันทึกข้อมูล รวมอย่างน้อยแปดชั่วโมง โดยเพิ่มเวลาเมื่อใดก็ตามที่ผู้เรียนต้องการ
* [ ] อ่าน [คู่มือผู้เรียน](https://curriculum.myfirstbitcoin.org/programs/bitcoin-diploma/en/student-guide/), [คู่มือผู้สอน](https://curriculum.myfirstbitcoin.org/programs/educator-guide/), และวัตถุประสงค์ที่เกี่ยวข้อง
* [ ] เลือกกิจกรรมและเตรียมกรอบการประเมิน งานที่ได้รับอนุมัติ เกณฑ์การให้คะแนน และแบบบันทึก
* [ ] วางแผนงานในโมดูล 4 ให้ปลอดภัยโดยใช้เครื่องมือสร้างโมดูลแบบกำหนดเองในคู่มือผู้สอน ตรวจสอบข้อเท็จจริงและเครื่องมือในท้องถิ่นให้เป็นปัจจุบัน
* [ ] เตรียมสื่อที่ใช้เทคโนโลยีพื้นฐานและแผนสำรองที่ไม่ต้องใช้เงิน คุ้มครองความเป็นส่วนตัวของผู้เรียนและดูแลให้ผู้เรียนทุกคนเข้าถึงการเรียนรู้ได้
* [ ] เปิดโอกาสให้ซักถาม จัดทำรายการหัวข้อขั้นสูงเพื่อติดตามต่อ และปิดท้ายด้วยการถามผู้เรียนว่าตอนนี้สามารถอธิบายหรือทำอะไรได้บ้าง
