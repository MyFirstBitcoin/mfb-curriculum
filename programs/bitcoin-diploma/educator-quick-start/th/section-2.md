# เส้นทางการเรียนรู้

| หน่วยการเรียนรู้ | เมื่อเรียนจบ ผู้เรียนควรสามารถ… | สิ่งที่ท่านควรเน้น |
| --- | --- | --- |
| 1. ทำความเข้าใจเรื่องเงิน | อธิบายว่าเหตุใดจึงมีเงิน และเปรียบเทียบรูปแบบต่าง ๆ ของเงินพร้อมข้อดีข้อเสียที่ต้องแลกกัน | เริ่มจากประสบการณ์ของผู้เรียน แล้วเสริมด้วยบริบทท้องถิ่นที่ตรวจสอบแล้ว |
| 2. บิตคอยน์ทำงานอย่างไร | อธิบายว่าเหตุใดบิตคอยน์จึงถูกสร้างขึ้น และอธิบายคุณสมบัติพื้นฐานของบิตคอยน์ด้วยภาษาที่เข้าใจง่าย | แสดงความเชื่อมโยงให้เห็นชัดเจน ชวนให้คิดถึงข้อกล่าวอ้าง หลักฐาน และข้อดีข้อเสียที่ต้องแลกกัน |
| 3. ใช้บิตคอยน์อย่างปลอดภัย | อธิบายเรื่องการเก็บรักษาบิตคอยน์และความปลอดภัย จากนั้นสาธิตทักษะพื้นฐานในการใช้กระเป๋าเงิน การตรวจสอบ การเตรียมพร้อมกู้คืน และการรักษาความปลอดภัย | สาธิตก่อน ดูแลการฝึกปฏิบัติ ปกป้องข้อมูลลับ |
| 4. บิตคอยน์ในชุมชนของท่าน | สาธิตวิธีหนึ่งที่บิตคอยน์สามารถทำหน้าที่เป็นเงินได้อย่างปลอดภัยและสอดคล้องกับบริบทท้องถิ่น พร้อมอธิบายข้อดีข้อเสียที่ต้องแลกกัน | เลือกความต้องการในท้องถิ่นที่ตรวจสอบแล้ว ไม่ใช่ผลิตภัณฑ์ที่จะนำมาโปรโมต |


สอนตามลำดับโดยร้อยเรียงเป็นเรื่องราวที่เชื่อมโยงกัน: **ปัญหาของเงิน → บิตคอยน์ตอบโจทย์อย่างไร → ความรับผิดชอบส่วนบุคคล → การประยุกต์ใช้ในท้องถิ่น**. หน่วยการเรียนรู้ที่ 1–3 เป็นเนื้อหาแกนกลางร่วมกัน หน่วยการเรียนรู้ที่ 4 เป็นหน่วยบังคับแต่ปรับตามบริบทได้ โดยท่านเลือกงานที่เหมาะสมกับท้องถิ่น พร้อมคงผลลัพธ์การเรียนรู้และมาตรฐานหลักฐานไว้ เนื้อหาเชิงลึกด้านเทคนิค การซื้อขาย การลงทุน กฎหมาย ภาษี การบัญชี การปฏิบัติตามกฎระเบียบ และนโยบาย ควรอยู่นอกเนื้อหาแกนกลางสำหรับผู้เริ่มต้น
