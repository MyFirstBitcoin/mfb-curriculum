# تهيئة بيئة صفية آمنة ونشطة

> **Callout – احموا المتعلمين قبل بدء النشاط العملي**
>
> لا تطلبوا أبدًا عبارة استرداد حقيقية أو مفتاحًا خاصًا حقيقيًا أو كلمة مرور حقيقية أو معلومات مالية غير ضرورية، ولا تطّلعوا عليها أو تصوّروها أو تنسخوها أو تسجّلوها أو تخزّنوها. لا تضغطوا على أي شخص لشراء بيتكوين أو بيعها أو الاحتفاظ بها أو استخدامها. توقّفوا مؤقتًا كلما كان أحد المتعلمين غير متأكد، أو واقعًا تحت ضغط، أو معرّضًا لعملية احتيال محتملة.


* استخدموا شروحات موجزة، ومناقشات، وسيناريوهات، وعروضًا توضيحية، وتدريبات عملية، وشروحات يقدّمها المتعلمون. ومن الأسئلة المفيدة لتحفيز التفكير: «ما الذي تتوقعون حدوثه بعد ذلك، ولماذا؟»
* لا تطلبوا أبدًا عبارة استرداد حقيقية أو مفتاحًا خاصًا حقيقيًا أو كلمة مرور حقيقية أو معلومات مالية غير ضرورية، ولا تطّلعوا عليها أو تصوّروها أو تنسخوها أو تسجّلوها أو تخزّنوها. استخدموا محافظ مُعدّة مسبقًا، أو محاكاة، أو صورًا مطبوعة للشاشات، أو بيئات اختبار، أو تدريبات عملية محدودة المخاطر.
* تحقّقوا من المستلِم، والشبكة، والعنوان أو الفاتورة، والمبلغ، وحالة المعاملة قبل الإرسال. توقّفوا مؤقتًا عندما يكون أحد المتعلمين غير متأكد، أو واقعًا تحت ضغط، أو معرّضًا لعملية احتيال محتملة.
* لا تضغطوا على أي شخص لشراء بيتكوين أو بيعها أو الاحتفاظ بها أو استخدامها. يقدّم برنامج دبلوم بيتكوين تعليمًا، وليس مشورة مالية أو استثمارية أو قانونية أو ضريبية أو محاسبية أو متعلقة بالامتثال أو التداول.
* جهّزوا بديلًا لكل نشاط رقمي: صورة مطبوعة للشاشة، أو رسمًا توضيحيًا، أو محاكاة بأدوات ملموسة، أو شرحًا شفهيًا خطوة بخطوة، أو عرضًا توضيحيًا يقدّمه المعلّم.
