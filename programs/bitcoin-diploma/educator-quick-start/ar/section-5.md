# قيّموا التعلّم بإنصاف

يتطلب نيل الشهادة استيفاء عنصرين **لا يعوّض أحدهما الآخر** يتولى المعلّم تقييمهما وتوثيقهما:


| العنصر | ما يُعتدّ به |
| --- | --- |
| الفهم النظري (50%) | شرح أو مقارنة أو استجابة لسيناريو أو تفاعل مماثل يقدّمه المتعلّم، على أن يكون معتمدًا ومتوافقًا مع الهدف، ويُقيَّم وفق معايير محددة. |
| الكفاءة العملية (50%) | الملاحظة المباشرة للمتعلّم أثناء إتمامه بأمان مهمة معتمدة أو محاكاة أو نشاط تقمّص أدوار، وتقييم أدائه وفق سُلّم التقدير الخاص بالنشاط. |


لا يُعدّ الحضور أو الحماس أو المراجعة المستقلة أو النقاش العادي وحده دليلًا يؤهّل لنيل الشهادة. وضّحوا الهدف وحدود السلامة والمهمة ومعايير النجاح؛ وابدؤوا بالتدريس والتدريب؛ ثم راقبوا الأداء، وقدّموا التغذية الراجعة، وسجّلوا النتيجة، وأتيحوا إعادة تقييم عادلة عند الحاجة. تتطلب الوحدتان 3 و4 ملاحظة مباشرة للأداء العملي.
