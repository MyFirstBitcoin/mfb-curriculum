# თქვენი პირველი კურსის საკონტროლო სია

* [ ] შეადგინეთ განრიგი, რომელიც მოიცავს სულ მცირე რვა საათს სწავლებისთვის, პრაქტიკისთვის, შეფასებისთვის, უკუკავშირისა და შედეგების აღრიცხვისთვის; საჭიროების შემთხვევაში მოსწავლეებს დამატებითი დრო დაუთმეთ.
* [ ] წაიკითხეთ [სტუდენტის გზამკვლევი](https://curriculum.myfirstbitcoin.org/programs/bitcoin-diploma/en/student-guide/), [მასწავლებლის გზამკვლევი](https://curriculum.myfirstbitcoin.org/programs/educator-guide/), ასევე შესაბამისი მიზნები.
* [ ] შეარჩიეთ აქტივობები და მოამზადეთ შეფასების ჩარჩო, დამტკიცებული დავალებები, შეფასების რუბრიკები და აღრიცხვის ფორმები.
* [ ] დაგეგმეთ უსაფრთხო დავალება მოდული 4-ისთვის მასწავლებლის გზამკვლევში მოცემული მორგებული მოდულის შექმნის ინსტრუმენტის გამოყენებით; გადაამოწმეთ ადგილობრივი ფაქტებისა და ინსტრუმენტების აქტუალურობა.
* [ ] მოამზადეთ მარტივი ტექნიკური საშუალებებით გამოსაყენებელი მასალები და სარეზერვო ვარიანტი, რომელიც თანხას არ საჭიროებს; დაიცავით მოსწავლეთა კონფიდენციალურობა და უზრუნველყავით მათთვის სასწავლო პროცესის ხელმისაწვდომობა.
* [ ] წაახალისეთ კითხვების დასმა, აწარმოეთ გაღრმავებული საკითხების სია შემდგომი განხილვისთვის და დასასრულს ჰკითხეთ მოსწავლეებს, რისი ახსნა ან გაკეთება შეუძლიათ ახლა.
