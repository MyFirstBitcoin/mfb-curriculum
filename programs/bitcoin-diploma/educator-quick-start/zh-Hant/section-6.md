# 您的首次課程檢查清單

* [ ] 安排一份課程時間表，涵蓋至少八小時的教學、練習、評量、回饋與紀錄，並在學員需要時增加時間。
* [ ] 閱讀[《學員指南》](https://curriculum.myfirstbitcoin.org/programs/bitcoin-diploma/en/student-guide/)、[《教師指南》](https://curriculum.myfirstbitcoin.org/programs/educator-guide/)及相關學習目標。
* [ ] 選定活動，並準備評量架構、核准的作業、評分規準與紀錄。
* [ ] 運用《教師指南》中的「自訂模組建構工具」，規劃一項安全的第4模組作業；並查證當地最新的資訊與工具。
* [ ] 準備低科技的教材，以及不涉及資金的備用方案；保護學員的隱私，並確保無障礙。
* [ ] 鼓勵學員提問，保留一份進階追蹤清單，並在課程結束時詢問學員，他們現在能夠解釋或做到哪些事。
