# 學習路徑

| 單元 | 學習者完成後應能…… | 您的重點 |
| --- | --- | --- |
| 1. 認識貨幣 | 說明貨幣存在的原因，並比較其各種形式與利弊取捨。 | 從學習者的經驗出發；補充經過查證的在地背景。 |
| 2. 比特幣如何運作 | 以淺顯的語言說明比特幣誕生的原因及其入門層級的特性。 | 讓各項關聯清楚可見；引導學習者思考主張、證據與利弊取捨。 |
| 3. 安全使用比特幣 | 說明保管與安全，接著實際展示入門級的錢包、驗證、復原準備及安全技能。 | 先行示範；督導練習；保護機密資訊。 |
| 4. 社區中的比特幣 | 實際展示一種安全且貼近在地的方式，呈現比特幣如何發揮貨幣功能，並說明其利弊取捨。 | 選擇經過查證的在地需求，而非要推銷的產品。 |


請將這個順序當作一個環環相扣的故事來教授：**貨幣問題 → 比特幣的回應 → 個人責任 → 在地應用**。單元 1–3 是共同的核心課程。單元 4 為必修但可自訂：您可選擇合適的在地任務，同時維持其學習成果與證據標準。詳細的技術、交易、投資、法律、稅務、會計、法規遵循及政策內容，不屬於入門核心課程的範圍。
