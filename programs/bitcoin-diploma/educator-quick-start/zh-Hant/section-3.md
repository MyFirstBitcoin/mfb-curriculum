# 哪些保持不變——以及您能帶來什麼

**保持不變：**四個模組的順序；核心目標；僅聚焦比特幣；安全界線；兩部分的評量；以及最低結業標準。

**審慎調整：**範例、語言、活動、進度、分組、無障礙支援、在地工具，以及**模組 4**的情境。教授開源錢包軟體時，應將其視為有條件的優先選擇，因為可供檢視的程式碼能提升透明度；同時協助學員比較保管方式、復原、相容性、隱私、維護、成本與支援。將特定名稱的錢包、交易所、商家、地圖與服務視為具時效性的在地範例，而非全球通用的推薦。請透過權威來源查證最新說法與當地法規；若您不確定，請如實說明並加以查證。

教導學員**如何思考，而非思考什麼**。歡迎彼此尊重的不同意見。學員不必認同某項主張才能達到標準；他們需要能夠推理、說明相關的取捨，並安全地展示所需技能。
