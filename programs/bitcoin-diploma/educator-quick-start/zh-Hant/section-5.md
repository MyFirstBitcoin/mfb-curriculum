# 公平評量學習成效

取得認證須通過兩個**不可相互補償**的評量項目，兩者皆須由教育者評估並記錄：


| 評量項目 | 認可的證據 |
| --- | --- |
| 理論理解（50%） | 學習者針對學習目標所做的經認可之說明、比較、情境回應或類似互動，並依既定標準進行評量。 |
| 實務能力（50%） | 直接觀察學習者依評分規準安全地完成經認可的任務、模擬或角色扮演。 |


僅憑出席、熱忱、自主複習或一般討論，均不足以作為認證證據。請清楚說明學習目標、安全界線、任務及成功標準；先進行教學與練習；接著觀察、給予回饋、記錄結果，並於必要時提供公平的重新評量機會。第 3 與第 4 單元須進行直接的實務觀察。
