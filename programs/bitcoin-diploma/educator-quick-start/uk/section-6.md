# Контрольний список для вашого першого курсу

* [ ] Складіть розклад, що передбачає щонайменше вісім годин для викладання, практики, оцінювання, зворотного зв’язку та фіксації результатів, і виділяйте додатковий час, коли учням це потрібно.
* [ ] Прочитайте [Посібник для учнів](https://curriculum.myfirstbitcoin.org/programs/bitcoin-diploma/en/student-guide/), [Посібник для викладачів](https://curriculum.myfirstbitcoin.org/programs/educator-guide/), а також відповідні навчальні цілі.
* [ ] Виберіть види діяльності та підготуйте систему оцінювання, затверджені завдання, критерії оцінювання та форми для фіксації результатів.
* [ ] Сплануйте безпечне завдання для Модуля 4 за допомогою конструктора власних модулів із Посібника для викладачів; перевірте актуальність місцевих даних та інструментів.
* [ ] Підготуйте матеріали, що потребують мінімуму технічних засобів, і запасний варіант без використання коштів; подбайте про конфіденційність даних учнів і доступність навчання.
* [ ] Заохочуйте запитання, ведіть список тем для подальшого поглибленого вивчення, а наприкінці запитайте учнів, що вони тепер можуть пояснити або зробити.
