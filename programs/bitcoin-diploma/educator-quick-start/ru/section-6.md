# Ваш чек-лист для первого курса

* [ ] Составьте расписание, предусматривающее не менее восьми часов на обучение, практику, оценивание, обратную связь и фиксацию результатов; выделяйте дополнительное время, когда оно требуется учащимся.
* [ ] Прочитайте [Руководство для учащихся](https://curriculum.myfirstbitcoin.org/programs/bitcoin-diploma/en/student-guide/), [Руководство для преподавателей](https://curriculum.myfirstbitcoin.org/programs/educator-guide/), а также соответствующие учебные цели.
* [ ] Выберите учебные активности и подготовьте систему оценивания, утверждённые задания, критерии оценивания и формы учёта результатов.
* [ ] Спланируйте безопасное задание для модуля 4 с помощью конструктора пользовательского модуля из Руководства для преподавателей; проверьте актуальность местных данных и инструментов.
* [ ] Подготовьте материалы, не требующие сложных технологий, и запасной вариант без использования денежных средств; обеспечьте конфиденциальность данных учащихся и доступность обучения.
* [ ] Поощряйте вопросы, ведите список тем для последующего углублённого изучения и в завершение спросите учащихся, что они теперь могут объяснить или сделать.
