# 学習の道のり

| モジュール | 学習者が修了時にできるようになること | 指導の重点 |
| --- | --- | --- |
| 1. お金を理解する | お金が存在する理由を説明し、その形態とトレードオフを比較できる。 | 学習者の経験から始め、確認済みの地域の文脈を加えます。 |
| 2. ビットコインの仕組み | ビットコインが生まれた理由と、初心者向けの基本的な特性をわかりやすい言葉で説明できる。 | つながりを目に見える形で示し、主張・根拠・トレードオフについて考えるよう促します。 |
| 3. ビットコインを安全に使う | 自己管理（カストディ）と安全性について説明し、初心者向けのウォレット、検証、復元への備え、安全対策のスキルを実演できる。 | まず実演し、練習を見守り、秘密情報を守ります。 |
| 4. 地域社会におけるビットコイン | ビットコインがお金として機能しうる、安全で地域に即した方法を1つ実演し、そのトレードオフを説明できる。 | 宣伝する製品ではなく、確認済みの地域のニーズを選びます。 |


この流れを、つながりのあるストーリーとして教えてください：**お金の問題 → ビットコインによる解決策 → 個人の責任 → 地域での活用**。モジュール1～3は共通のコアです。モジュール4は必修ですがカスタムであり、その成果と評価基準を保ちながら、地域に適した課題を選んでいただきます。詳細な技術、トレーディング、投資、法律、税務、会計、コンプライアンス、政策に関する内容は、初心者向けのコアには含めません。
