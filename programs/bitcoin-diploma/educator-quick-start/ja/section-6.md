# 初めての講座に向けたチェックリスト

* [ ] 指導、演習、評価、フィードバック、記録を含めて少なくとも8時間を確保したスケジュールを組み、受講者が必要とする場合はさらに時間を延ばしてください。
* [ ] まず、[『Student Guide』](https://curriculum.myfirstbitcoin.org/programs/bitcoin-diploma/en/student-guide/)、[『Educator Guide』](https://curriculum.myfirstbitcoin.org/programs/educator-guide/)、および関連する学習目標を読んでください。
* [ ] アクティビティを選び、評価の枠組み、承認済みの課題、ルーブリック、記録を準備してください。
* [ ] 『Educator Guide』のカスタムモジュール作成ツールを使って、安全なモジュール4の課題を計画し、最新の地域の情報やツールを確認してください。
* [ ] ローテクな教材と、資金を使わない代替案を準備し、受講者のプライバシーとアクセシビリティを守ってください。
* [ ] 質問を歓迎し、発展的な内容のフォローアップリストを作成しておき、最後に受講者が今では何を説明できるか、何ができるようになったかを尋ねて締めくくってください。
