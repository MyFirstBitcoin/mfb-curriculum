# 学習を公正に評価する

認定には、**相互に補い合うことのできない**2つの構成要素が必要です。いずれも教育者が評価し、記録します。


| 構成要素 | 評価の対象となるもの |
| --- | --- |
| 理論的理解（50%） | 承認済みで学習目標に沿った、学習者による説明、比較、シナリオへの回答、またはそれに類するやり取りであり、明示された基準に照らして評価されるもの。 |
| 実践的能力（50%） | 承認済みの課題、シミュレーション、またはロールプレイを学習者が安全に完了する様子を、そのルーブリックに照らして直接観察するもの。 |


出席、熱意、自主的な復習、または通常のディスカッションだけでは、認定の根拠にはなりません。学習目標、安全上の境界、課題、達成基準を明確にしてください。まず教えて練習させ、その後に観察し、フィードバックを行い、結果を記録し、必要に応じて公正な再評価の機会を設けてください。モジュール3と4では、実践の直接観察が必要です。
