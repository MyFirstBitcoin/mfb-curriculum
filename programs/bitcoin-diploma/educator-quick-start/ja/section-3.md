# 変わらないもの――そして、皆さまがもたらすもの

**固定する項目：**4つのモジュールの順序、コア目標、ビットコインのみに焦点を当てること、安全上の境界、2部構成の評価、そして最低修了基準です。

**慎重に調整する項目：**例、言語、アクティビティ、進行ペース、グループ分け、アクセシビリティ支援、地域のツール、そして**モジュール4**のシナリオです。オープンソースのウォレットソフトウェアは、コードを検証できることで透明性が高まり得るため、条件付きの推奨として教えてください。同時に、学習者がカストディ、復元、互換性、プライバシー、メンテナンス、コスト、サポートを比較できるよう支援してください。特定のウォレット、取引所、店舗、マップ、サービスの名称は、世界共通の推奨ではなく、時点の限られた地域の例として扱ってください。最新の主張や地域の規則は、信頼できる情報源で確認してください。わからない場合は、そのことを伝えたうえで確認してください。

学習者には、**何を考えるかではなく、どのように考えるか**を教えてください。敬意ある反対意見を歓迎してください。学習者は、基準を満たすためにある主張に同意する必要はありません。必要なのは、論理的に考え、関連するトレードオフを説明し、求められるスキルを安全に実演することです。
